## 4. 호출 계층

```
FLUXES → [HIGH_ORDER 분기] CONSTRUCTION{_HO/_HO_minmod/_HO_MLP/_WENO}
            → CONSTRUCT_*_X/Y (재구성 L/R 쌍)
       → WAVE_SPEED (Zhou Roe)
       → FLUX_AT_INTERFACE_HLL → HLL ×6
       → BOUNDARY_CONDITION
DERIVATIVE_* : 직접 fluxes 밖, 분산항(dispersion.F)·SGS 확산에서 호출
```
