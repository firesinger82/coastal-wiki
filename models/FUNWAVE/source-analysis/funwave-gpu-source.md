# FUNWAVE-GPU (CUDA Fortran 판) 전수분석

> GPU 원자료는 공개 HEAD `7f892ba`(2019-11-26)와 `src/Makefile_cuda`·`src/mod_cuda.F`·`src/etauv_solver_gpu.F`의 로컬 미커밋 수정을 포함한다. [10-18 대조 정정]
> GPU 사본의 비 CUDA 파일은 현재 TVD 파일과 다르다. 근거: [theory-numerics §4 FT1-287](../../../_staging/recovery/compare/funwave-theory-numerics-vs-code.md#4-노트-대조와-수정안). [10-18 대조 정정]
> GPU 공통 소스의 최근접 TVD 커밋은 `e42e17d`(2019-02-24)다. 이 판단은 2019-11 이전 TVD 401커밋과 공통 29파일의 행 대조에 근거한다. 근거: [gpu-vs-tvd §4 FG1-900](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md#4-노트-대조와-수정안). [10-18 대조 정정]
> 기존 판독 목록은 `mod_cuda.F`와 일곱 `*_gpu.F`다. recovery 보고서는 `moment_gpu.F`·`mgpu_utilities.F`·`exchange_gpu0819.F`와 CPU 파일을 포함한 41파일을 대조한다. 근거: [gpu-vs-tvd §4 FG1-901](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md#4-노트-대조와-수정안). [10-18 대조 정정]

## 2. init_gpu.F (596) — GPU 초기화
- `AssignDevice`(:25 MGPU): `cudaSetDevice`, 노드내 rank→GPU(MPI_COMM_SPLIT_TYPE SHARED)
- `CudaMemUse`는 단일 GPU에서 `IF (RUSEDMEM > 0.8*RTOTALMEM) THEN`이면 경고 뒤 `STOP`을 실행한다. MGPU에서는 rank 0이 `IF (MAXUSEDMEM > 0.8*RTOTALMEM) THEN`을 검사한다. 이 조건의 본문도 경고 뒤 `STOP`을 실행한다. 근거: `FUNWAVE-GPU/src/init_gpu.F:64–87`, callflow:RF-039. [10-18 대조 정정]
- `stream_init`(:92): `cudaStreamCreate` ×8+d2h
- `ALLOCATE_VARIABLES_GPU`(:112): ~80 `_d` 배열 device allocate
- `INITIALIZATION_GPU`는 host→device 복사와 정수 `WaveMakerCode` 변환을 수행한다. `TriSolver==1`이면 `cusparse_init`을 호출한다. `WK_DATA2D`의 입력·배열 할당 문자열은 GPU 정수 코드 선택 문자열과 다르다. `WK_TIME`의 `WAVE_COMP_d`는 할당·복사 경로가 없다. 근거: `FUNWAVE-GPU/src/init_gpu.F:489–558`, [gpu-vs-tvd §4 FG1-605](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md#4-노트-대조와-수정안). ## 3. etauv_solver_gpu.F (2019) — ★시간적분+분산 tridiagonal (핵심)
`ESTIMATE_HUV_GPU(ISTEP)`(:86): ① `HUV_BAR_KERNEL`(eta·Ubar·Vbar RK 업데이트) ② TriSolver별 tridiagonal ③ `post_tridiagonal_kernel`(Froude cap·HU/HV).

**커널(attributes(global))**:
- `HUV_BAR_KERNEL`은 3단계 RK의 각 `ISTEP`에서 Eta·Ubar·Vbar를 갱신한다. flux 재구성과 HLL은 `moment_gpu.F`의 별도 커널이 계산한다. 근거: `FUNWAVE-GPU/src/main.F:303`, `FUNWAVE-GPU/src/etauv_solver_gpu.F:1358,1387,1409`, [gpu-vs-tvd §4 FG1-442](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md#4-노트-대조와-수정안). [10-18 대조 정정] [10-18 전수 검증 보완]
- `triDx_init_kernel`(:1427)/`triDy_init_kernel`(:1589): tridiagonal 계수 2D 병렬 구성(`Γ₁·MASK9_d·dep²·DX²`)
- `triDx_cusparse_init_kernel`(:1502)/`triDy_cusparse_init_kernel`(:1683): cuSPARSE용 1D 평면화(strided batch 패킹 `RowIndex=(i−NGhost)+(j−NGhost−1)(Mloc−2NGhost)`)
- `transpose_kernel`(:1955): x방향 Thomas용 행렬전치(coalesced access)
- `post_tridiagonal_kernel`(:1975): 건조셀·HU/HV·Froude

**솔버 2경로**:

기본값은 `FUNWAVE-GPU/src/mod_cuda.F:17`의 `integer,parameter :: TriSolver = 0    ! 0, 1-cusparse`다. `FUNWAVE-GPU/src/etauv_solver_gpu.F:156`은 `! So, stick to Trisolver = 0, donot try 1 at current version`이라고 적는다. 근거: [gpu-vs-tvd §4 FG1-878](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md#4-노트-대조와-수정안). [10-18 대조 정정]
- **TriSolver==0 Thomas**: `triDx_triDy_cuda`(:565) — transpose→`triDx_cuda_kernel`(streamID2)+`triDy_cuda_kernel`(streamID3, 각 행/열=1스레드 직렬 Thomas)→deviceSync→역transpose

- **MGPU**: `triDxDy_mgpu_cuda_v1`(:183 비주기, X/Y streamID2/3 병렬+MPI 경계교환)·`_v2`(:321 주기 Y1/Y2 분리)·`periodic_triDx_triDy_cuda`(:597 Sherman-Morrison)·`triD{x,y}_mgpu_cuda`(`cudaMemcpy2dAsync` D2H→MPI→H2D)

cuSPARSE v2 호출은 공개 `7f892ba`에 없는 로컬 미커밋 변경이다. 반복 할당·x/y 버퍼 공유·정밀도·주기 helper의 조건부 결함 후보는 [gpu-vs-tvd §2.5](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md#25-코드-결함-후보와-반대-근거)의 FG1-608·609·610·616에 기록되어 있다. 근거: callflow:RF-038, gpu-vs-tvd:FG1-878. [10-18 대조 정정] [10-18 전수 검증 보완]

비주기 MGPU v1의 남쪽 역대입 전송은 `myFy_d` 대신 `Y1_d`를 읽는다. `Y1_d`는 주기 경로에서 할당한다. 근거: `FUNWAVE-GPU/src/etauv_solver_gpu.F:290–309,609–615`, gpu-vs-tvd:FG1-607. [10-18 대조 정정]

- `EXCHANGE_GPU`(:800): 주변수 ghost → `PHI_COLL_GPU`+`!$cuf` U_d*=MASK_d
- `PHI_COLL_GPU`(:967): 6 VTYPE ghost, `!$cuf kernel do(2) <<<*,(4,64)>>>`(NGhost=3 얇은 x에 최적 block), MGPU `cudaMemcpy2D`+`MPI_SENDRECV`, `phi_exch_cuda`

## 5. 물리 커널 (CPU판 GPU화)
- **breaker_gpu.F**의 `AGE_BREAKING0_d=AGE_BREAKING_d`는 이전 연령 스냅숏을 만든다. `Age_sh`는 그 스냅숏을 읽는다. shared 메모리의 외곽 적재 범위는 이웃 접근 범위를 덮지 않는다. DXg·DYg의 조건부 정의와 갱신 전 연령의 점성 선택도 별도 결함 후보다. 근거: `FUNWAVE-GPU/src/breaker_gpu.F:38,149–162,195,257`, gpu-vs-tvd:FG1-602·614. [10-18 대조 정정]
- **masks_gpu.F**의 `UPDATE_MASK_GPU`는 `MGPU`가 정의되면 초기 교환을 수행한다. 이어서 습윤건조 커널을 실행한다. `VISCOSITY_BREAKING`이 거짓이면 MASK9 커널을 실행한다. `MGPU`가 정의되면 최종 교환을 수행한다. 이 호출은 RK 반복 전에 있다. `UPDATE_MASK_GPU`에는 `CHECK_MASS_CONSERVATION`의 전역 수위 보정이 없다. 근거: `FUNWAVE-GPU/src/masks_gpu.F:127–179`, `FUNWAVE-GPU/src/main.F:270`, [callflow §6](../../../_staging/recovery/flow/FUNWAVE-callflow.md#6-기존-노트-대조와-수정안), [gpu-vs-tvd §4 FG1-760](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md#4-노트-대조와-수정안). [10-18 대조 정정] [10-18 전수 검증 정정]
- **mixing_gpu.F**의 시간 평균·파고 국소 식은 CPU와 대응한다. GPU 평균 누적 배열은 첫 누적 전에 값을 정의하지 않는다. 같은 초기화 누락은 CPU에도 남아 있다. 근거: `FUNWAVE-GPU/src/mixing_gpu.F:73–78,125–146`, gpu-vs-tvd:FG1-606. [10-18 대조 정정]
- `MIXING_STUFF_GPU`는 `IF( time >= STEADY_TIME )THEN`에서 `CALL CALCULATE_MEAN_GPU`를 실행한다. 근거: `FUNWAVE-GPU/src/mixing_gpu.F:146`, gpu-vs-tvd:FG1-606. [10-18 대조 정정]
- **sponge_gpu.F**는 `IF(MASK_d(I,J)>0)THEN`에서 Eta를 SPONGE로 나눈다. U·V는 MASK 조건 밖에서 나눈다. 근거: `FUNWAVE-GPU/src/sponge_gpu.F:26–31`, gpu-vs-tvd:FG1-452. [10-18 대조 정정]

### 5.1 moment_gpu.F와 기능 범위

`moment_gpu.F`는 분산·미분·flux·source 커널을 제공한다. Cartesian 분산 계산에서 GPU V2의 첫 항은 CPU의 U 대신 V를 사용한다. 이 행은 강한 코드 결함 후보다. 근거: `FUNWAVE-GPU/src/moment_gpu.F:754`의 `V2_d(I,J)=ken1*(tV*HUxxHVxy+tV*HUxyHVyy) &`, `FUNWAVE-TVD/src/dispersion.F:461`의 `V2(I,J)=ken1*(U(I,J)*HUxxHVxy+V(I,J)*HUxyHVyy) &`, gpu-vs-tvd:FG1-600. [10-18 대조 정정]

GPU driver는 VESSEL_FORCING·METEO_FORCING 호출을 제거했다. GPU source는 해당 압력·풍응력 항도 비활성으로 둔다. GPU breaking 커널에는 VIS_DEPTH_RATIO 분기가 없다. 근거: [gpu-vs-tvd §4 FG1-486·760](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md#4-노트-대조와-수정안). [10-18 대조 정정]

MAX_MIN_PROPERTY는 device의 HeightMin·VelocityMax·MomentumFluxMax를 갱신한다. var_d2h_output은 이 세 배열을 host로 복사하지 않는다. 근거: `FUNWAVE-GPU/src/misc.F:343–373`, `FUNWAVE-GPU/src/mod_cuda.F:183–211`, gpu-vs-tvd:FG1-611. [10-18 대조 정정]

현재 TVD와 GPU의 주 프로그램 호출 순서는 서로 다르다. GPU 마스크 갱신은 RK 반복 전에 실행한다. GPU 지형 변화는 `# if defined (SEDIMENT)` 안에서 `IF(Bed_Change)THEN`이면 RK 단계 안에서 실행한다. 근거: `FUNWAVE-GPU/src/main.F:270,303,331–335`, callflow:RF-002·033·047. [10-18 대조 정정]

분기 기준은 [gpu-vs-tvd §1.1](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md#11-판본과-분기-기준)에 있다. 루틴 목록은 같은 보고서 §2.2·2.3에 있다. 국소 식의 대응은 §2.4에 있다. 조건부 결함 후보는 §2.5에 있다. 기능 범위와 TO DO는 §3.1·3.4에 있다. 로컬 수정 원문은 §3.3에 있다.

## 6. CPU판 vs GPU판 핵심 차이

| 항목 | CPU (FUNWAVE-TVD) | GPU (FUNWAVE-GPU) |
|---|---|---|
| tridiagonal | TRIDx/y J루프 직렬 Thomas | TriSolver0 행별 병렬 Thomas(+transpose) / TriSolver1 **cuSPARSE batched** |
| halo 교환 | `PARALLEL`에서 MPI 사용 | `!$cuf kernel do`/cudaMemcpy2D + host 버퍼·MPI(MGPU). [10-18 대조 정정] |
| 쇄파 AGE | 직접 덮어쓰기 | 이전 연령 스냅숏·shared 소비. 외곽 적재 후보는 gpu-vs-tvd:FG1-602에 기록한다. [10-18 대조 정정] |
| DT | 단일루프 min | `!$cuf` reduction + MPI_ALLREDUCE |
| WaveMaker 분기 | character 비교 | 정수 WaveMakerCode. 문자열 대응 후보는 gpu-vs-tvd:FG1-605에 기록한다. [10-18 대조 정정] |
| x-Thomas | — | transpose_kernel(coalesced) |

TVD의 CPU halo 교환도 PARALLEL에서 MPI를 사용한다. 근거: `FUNWAVE-TVD/src/bc.F:1268`, `FUNWAVE-TVD/src/parallel.F:74`, callflow:RF-048. [10-18 대조 정정]

CUDA 요소: `attributes(global)` 물리커널 / `!$cuf kernel do` 단순루프 / `shared`(Age·MASK·U/V/Eta) / `constant`(Beta_ref·alpha/beta·법선) / `streamID(8)` 비동기 / `cusparseSgtsv2StridedBatch`.
