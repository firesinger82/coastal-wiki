# FUNWAVE GPU 판과 TVD 판의 코드 차이

## 범위와 근거 보고서

이 노트는 [배정표](../../../_staging/recovery/assign/FUNWAVE-note-job-7.tsv)가 지정한 GPU 계산의 생략·변경과 코드 결함 후보를 수록한다.
결론과 원문 인용의 근거는 [theory-numerics 보고서](../../../_staging/recovery/compare/funwave-theory-numerics-vs-code.md), [aux-docs-build 보고서](../../../_staging/recovery/compare/funwave-aux-docs-build-vs-code.md), [gpu-vs-tvd 보고서](../../../_staging/recovery/compare/funwave-gpu-vs-tvd.md)의 차이 결론 절이다.
호출 흐름의 근거는 [callflow 보고서](../../../_staging/recovery/flow/FUNWAVE-callflow.md)의 4·8절이다.
최종 분류는 각 보고서 끝의 10-18 전수 검증 기록과 최종 집계를 따른다.
gpu-vs-tvd 보고서의 C는 GPU가 계산을 생략하거나 변경한 범위이다.
GPU와 TVD의 코드만 대조한 행은 문서 원문 칸에 `—`를 쓴다.
