## 1. 지배방정식·수치기법 요약

Celeris는 동일 FV(유한체적) 골격 위에서 **3개 방정식 계열**을 config로 전환한다 (`NLSW_or_Bous`). 셰이더 fetch 분기는 `js/main.js:1537-1593` — 계열 선택은 `NLSW_or_Bous` 지만 NLSW 안에서 `grid_type == 2` 이면 구면 변형이 선택되고, 이때 `constants_load_calc.js:454-469` 가 `NLSW_or_Bous=0`·`Accuracy_mode=0`·`useSedTransModel=0`·`useBreakingModel=0` 을 강제한다, 패스 시퀀스 설명은 `docs/architecture/SIMULATION_PIPELINE.md`.

| 계열 | 활성 Pass3 셰이더 | 분산항(dispersive) | 암시적 PCR solve |
|---|---|---|---|
| **NLSW** (비선형 천수) | `Pass3_NLSW.wgsl` (285) — `grid_type == 2`(구면 격자)이면 `Pass3_NLSW_Spherical.wgsl` (267) 선택 (`js/main.js:1558-1563`) | 없음 | skip — 중간상태를 `txNewState`로 copy (`Run_Tridiag_Solver.js:37-39`) |
| **Boussinesq** | `Pass3_Bous.wgsl` (430) | `Bcoef`·3차 미분항 (`Pass3_Bous.wgsl:282-286`) | x·y 양방향 PCR |
| **COULWAVE** | `Pass3A/B_COULWAVE.wgsl` + `Pass3_COULWAVE.wgsl` | 단일 z-α의 보조량 저장 층 6개 (`shaders/Pass3A_COULWAVE.wgsl:44`; `js/main.js:514–521`) | x·y 양방향 PCR (COULWAVE 변형). [11-04 대조 정정] |

`txCW_groupings`의 여섯 층은 보조 변수의 저장 층이다 (`js/main.js:514–521`). [11-04 대조 정정]
z-α 평가 표고는 셀마다 하나다 (`shaders/Pass3A_COULWAVE.wgsl:44`). [11-04 대조 정정]
이 저장 구조는 물리적 수직 다층 모델을 뜻하지 않는다 (`shaders/Pass3A_COULWAVE.wgsl:44`; `js/main.js:514–521`). [11-04 대조 정정]

위 모드 표는 본판 범위다 ([callflow §6.1](../../../_staging/recovery/flow/Celeris-callflow.md#61-네-핵심-노트)). [11-04 대조 정정]
transect 판은 y PCR을 실행하지 않는다 (`transect_version/js/Run_Tridiag_Solver.js:31–75`; [CT1-357 최종 근거](../../../_staging/recovery/compare/Celeris-conclusion-verify-CT1c.md)). [11-04 대조 정정]
단면판의 호출 구조는 [단면판 대조](celeris-transect-version.md)를 참조한다. [11-04 대조 정정]

수치 골격 (각 timestep, `SIMULATION_PIPELINE.md` §Timestep + `main.js:2638-2924`):

```
Pass0   neighbor 수심 (dry/wet helper, txHnear)        Pass0.wgsl
Pass1   면(face) 재구성: H,U,V,C @ N/E/S/W            Pass1.wgsl | Pass1_HighOrder.wgsl
Pass2   면 수치플럭스 (HLL류 Riemann) → txXFlux/txYFlux Pass2.wgsl | Pass2_HighOrder_HLLC/HLLEM
[Break] breaking age/eddy-viscosity                    Pass_Breaking.wgsl
[CW]    COULWAVE 보조항 패킹 → txCW_groupings          Pass3A/B_COULWAVE.wgsl
Pass3   플럭스발산+마찰+압력+분산+breaking+pred/corr    Pass3_NLSW|Bous|COULWAVE
Bndry   경계조건·wet/dry cleanup (1차)                  BoundaryPass.wgsl
[분산]  x-solve → y-solve                              TriDiag_PCRx/y* [11-04 대조 정정]
[분산]  경계조건 재적용 (2차)                           BoundaryPass.wgsl [11-04 대조 정정]
```

NLSW는 첫 경계 출력 복사를 재사용한다 (`js/main.js:2723–2732,2856–2861`). [11-04 대조 정정]
분산 모델만 풀이 뒤 경계 패스를 다시 호출한다 (`js/main.js:2723–2732,2856–2861`; [RF-009 최종 근거](../../../_staging/recovery/compare/Celeris-conclusion-verify-CP3RF.md)). [11-04 대조 정정]
COULWAVE는 예측·보정의 첫 경계 뒤 계수를 갱신한다 (`js/main.js:2702–2704,2832–2834`; [RF-023 최종 근거](../../../_staging/recovery/compare/Celeris-conclusion-verify-CP3RF.md)). [11-04 대조 정정]

- **Riemann 수치플럭스**: `Pass2.wgsl:34-40` `NumericalFlux` 함수는 HLL 형태 `(a⁺F⁻−a⁻F⁺+a⁺a⁻ΔU)/(a⁺−a⁻)`. 본판 고차 경로는 `if (calc_constants.Accuracy_mode == 1)`에서 HLLC를 선택한다 (`js/main.js:1546–1548`). [11-04 대조 정정] [11-04 전수 검증 정정]
  - transect 판은 `Pass2_HighOrder.wgsl`의 HLLEM 함수를 선택한다 (`transect_version/js/main.js:1040–1042`). [단면판 대조](celeris-transect-version.md)를 참조한다. [11-04 대조 정정]
- **시간 적분은 Euler, AB3 예측, AB3 예측과 AM4 보정 중에서 선택한다.** (`shaders/Pass3_Bous.wgsl:399–409`) [11-04 대조 정정]
  - `timeScheme==0`: 단일 explicit `U + dt·d_by_dt` (l.400)
  - predictor (`pred_or_corrector==1`): `U + dt/12·(23·dⁿ − 16·dⁿ⁻¹ + 5·dⁿ⁻²)` (l.404) — AB3
  - corrector (`pred_or_corrector==2`): `U + dt/24·(9·dⁿ⁺¹ + 19·dⁿ − 5·dⁿ⁻¹ + dⁿ⁻²)` (l.409) — AM4 (Adams–Moulton). [11-04 대조 정정]
  - 미분 이력(`oldGradients`/`oldOldGradients`/`predictedGradients`)·분산 이력(`F_G_star_old*`)을 텍스처로 유지 (`SIMULATION_PIPELINE.md` §Time Integration).
  - 현재 호스트는 선택한 보정 단계를 한 번 호출한다 (`js/main.js:2757–2865`; `Tavakkol 2017 p.3 §2.3`). [11-04 대조 정정]
  - 현재 F*·G* 시간 미분은 우변 도함수에 포함되어 AB·AM 가중을 받는다 (`shaders/Pass3_Bous.wgsl:283,286,392–409`; `471c581:shaders/Pass3_Bous.wgsl:234,237`; `Tavakkol 2017 p.3 식 (16)–(20)`). [11-04 대조 정정]
- **PCR(Parallel Cyclic Reduction) 삼중대각 암시 solve**: `Run_Tridiag_Solver.js:48-91`. x-방향 `Px`회, y-방향 `Py`회 log-스텝 reduction (`s = 1<<p`, l.50). 계수 copy 없이 ping-pong 바인드그룹(`BaseToA`/`BToA`)으로 핸드오프 (l.57, l.82 — CODEX 주석). 마지막 패스만 해 텍스처 `txtemp2_PCR*` 작성 → `txNewState` copy (l.66, l.91).

예측 쇄파·COULWAVE B는 직전 시간 단계의 마지막 Pass3가 남긴 도함수를 읽는다 (`shaders/Pass_Breaking.wgsl:55`; `shaders/Pass3B_COULWAVE.wgsl:191`; `js/main.js:2649–2679`). [11-04 대조 정정]
첫 시간 단계에는 이전 Pass3 결과가 없다 ([RF-015 최종 근거](../../../_staging/recovery/compare/Celeris-conclusion-verify-CP3RF.md)). [11-04 대조 정정]
보정 호출은 이번 예측 Pass3의 도함수를 읽는다 (`js/main.js:2685,2783–2812`). [11-04 대조 정정]
Pass2도 이번 쇄파 갱신보다 먼저 txBreaking을 읽는다 (`js/main.js:2649–2679`; [RF-015 최종 근거](../../../_staging/recovery/compare/Celeris-conclusion-verify-CP3RF.md)). [11-04 대조 정정]
