# ROMS 수평 혼합 (hmixing.F)

> `hmixing.F`는 시간에 따라 변하는 3차원 수평 혼합 계수를 계산한다 (`ROMS/Nonlinear/hmixing.F:5,13-14`). `UV_SMAGORINSKY` 경로의 운동량 계수는 `visc3d_r`에 저장한다 (`ROMS/Nonlinear/hmixing.F:334-347`). `TS_SMAGORINSKY` 경로의 추적자 계수는 `diff3d_r`에 저장한다 (`ROMS/Nonlinear/hmixing.F:388-401`). 연직 혼합은 [roms_vertical_mixing](roms_vertical_mixing.md)을 참조한다. [10-14 전수 검증 정정]

## 1. Smagorinsky (hmixing.F:19) ★

**Smagorinsky 1963** — 변형률 기반 subgrid viscosity:
```
A_M = C·Δx·Δy·|D|,   |D| = √((∂u/∂x−∂v/∂y)² + (∂v/∂x+∂u/∂y)²)
```
- 흐름 deformation(전단·신장)이 큰 곳(front·eddy)에서 viscosity↑ → 수치 안정 + 물리적 혼합. 격자크기(Δx·Δy) 의존. harmonic(2차, visc2).

## 2. 격자 크기와 Smagorinsky 계수

`VISC_GRID`·`DIFF_GRID`는 초기 coefficient의 grid-size rescaling이다 (`ROMS/Utility/ini_hmixcoef.F:301–312,340–364`; [수정안 RMF1-928](../../../_staging/recovery/compare/roms-mixing-bc-forcing-vs-code.md#4-노트-대조와-수정안)). [10-14 전수 검증 보완]
`VISC_GRID`의 `UV_VIS2` 분기는 `visc2_r(i,j)=cff*grdscl(i,j)`를 설정한다 (`ROMS/Utility/ini_hmixcoef.F:308–312`).
`VISC_GRID`의 `UV_VIS4` 분기는 `visc4_r(i,j)=cff*grdscl(i,j)**3`를 설정한다 (`ROMS/Utility/ini_hmixcoef.F:323–327`).
변형률에 따른 Smagorinsky coefficient는 `UV_SMAGORINSKY`·`TS_SMAGORINSKY`의 별도 경로로 설명한다 (`ROMS/Nonlinear/hmixing.F:334–347`, `ROMS/Nonlinear/hmixing.F:388–401`).
`UV_SMAGORINSKY`의 `UV_VIS2` 분기는 `SmagorCoef*omn(i,j)*DefRate`를 더한다 (`ROMS/Nonlinear/hmixing.F:338–340`).
`UV_SMAGORINSKY`의 `UV_VIS4` 분기는 `PecletCoef*(omn(i,j)**2)*DefRate`를 더한다 (`ROMS/Nonlinear/hmixing.F:341–343`).
`UV_SMAGORINSKY`의 `UV_VIS4` 분기는 계수의 제곱근을 저장한다 (`ROMS/Nonlinear/hmixing.F:347` `visc3d_r(i,j,k)=SQRT(visc3d_r(i,j,k))`).

## 3. 옵션·적용

- `UV_VIS2/TS_DIF2`는 harmonic 연산을 선택한다 ([수정안 RMF1-929](../../../_staging/recovery/compare/roms-mixing-bc-forcing-vs-code.md#4-노트-대조와-수정안)).
- `UV_VIS4/TS_DIF4`는 biharmonic 연산을 선택한다 ([수정안 RMF1-929](../../../_staging/recovery/compare/roms-mixing-bc-forcing-vs-code.md#4-노트-대조와-수정안)).
- momentum mixing 방향은 S·geopotential이다 (`ROMS/Include/cppdefs.h:219–220`; [결론 RTN-279](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md#5-차이-결론)).
- tracer mixing은 S·geopotential·epineutral이다 ([결론 RTN-279](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md#5-차이-결론)).
- **vegetation**(:82): 식생이 수평 viscosity 증가(canopy drag 난류).
- `Hviscosity`는 `hmixing_tile`의 운동량 계수 입력이다 (`ROMS/Nonlinear/hmixing.F:194-195`). 추적자 계수 입력은 `Hdiffusion`이다 (`ROMS/Nonlinear/hmixing.F:191-192`). 수평 혼합의 호출부는 `rhs3d`의 `uv3dmix2`·`uv3dmix4`와 `t3dmix2`·`t3dmix4`이다 (`ROMS/Nonlinear/rhs3d.F:108-122,200-210`). [10-14 전수 검증 정정]

`TS_MIX_STABILITY`는 nrhs 차분의 0.75와 nstp 차분의 0.25를 합친다 (`ROMS/Nonlinear/t3dmix2_s.h:212–218`).
이 옵션이 없고 `TS_MIX_CLIMA`를 정의한 경우에 `LtracerCLM`이 참이면 tracer anomaly를 혼합한다 (`ROMS/Nonlinear/t3dmix2_s.h:219–225`).
인용한 두 전처리 분기는 동시에 실행되지 않는다 (`ROMS/Nonlinear/t3dmix2_s.h:212` `#if defined TS_MIX_STABILITY`; `ROMS/Nonlinear/t3dmix2_s.h:219` `#elif defined TS_MIX_CLIMA`).

## 4. 위치

- 수평 혼합 = 수치 안정(advection [roms_advection](roms_advection.md) 의 수치확산 보완) + 물리(meso-scale eddy 혼합). 연직([roms_vertical_mixing](roms_vertical_mixing.md) GLS/KPP)과 독립.

## 5. 연결

- [roms_advection](roms_advection.md) — 수평 확산이 advection 수치확산 보완
- [roms_vertical_mixing](roms_vertical_mixing.md) — 연직 혼합(독립)
- [roms_baroclinic_3d](roms_baroclinic_3d.md) — 운동량과 추적자의 수평 혼합은 `rhs3d`에서 호출한다 (`ROMS/Nonlinear/rhs3d.F:108-122,200-210`). [10-14 전수 검증 정정]
- Smagorinsky 1963 / Griffies-Hallberg 2000
