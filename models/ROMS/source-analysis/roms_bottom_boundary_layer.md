# ROMS bottom boundary layer (BBL) — wave-current 저면응력

> 소스는 `ROMS/Nonlinear/BBL/`이다.
> 관련 노트는 [연직혼합](roms_vertical_mixing.md), [퇴적물](sediment/roms_sediment.md), [파랑 효과](roms_wec.md)이다.

## 1. 3 scheme dispatch (bbl.F:16-21)

```fortran
# if defined SSW_BBL
#  include "ssw_bbl.h"
# elif defined MB_BBL
#  include "mb_bbl.h"
# elif defined SG_BBL
#  include "sg_bbl.h"
```

include 순서는 `SSW_BBL`·`MB_BBL`·`SG_BBL`이다(`ROMS/Nonlinear/BBL/bbl.F:16–21`).
운동량 경계에 쓰는 field는 face의 `bustr`·`bvstr`이다(`ROMS/Nonlinear/BBL/ssw_bbl.h:862–886`).
rho의 `bustrc`·`bvstrc`는 current stress 진단이다(`ROMS/Nonlinear/BBL/ssw_bbl.h:887–903`).
`Ubot`·`Vbot`·`Ur`·`Vr`도 이 SSW 함수에서 계산하는 output field이다(`ROMS/Nonlinear/BBL/ssw_bbl.h:894–903`). [10-14 전수 검증 정정]
입력 `Uwave_rms`·`Pwave_bot`·`Dwave`·`Hwave`와 구분한다([mixing-bc-forcing:RMF1-948](../../../_staging/recovery/compare/roms-mixing-bc-forcing-vs-code.md#5-차이-결론)).

## 2. SSW (Sherwood-Signell-Warner) — madsen94 ★

현재 파일 머리말은 `M94WC`를 정의한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:2`).
`SGWC` 경로는 `#undef SGWC`로 제외한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:4`).
현재 M94WC의 파랑·흐름 결합 분기는 `madsen94`를 호출한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:719`, `ROMS/Nonlinear/BBL/ssw_bbl.h:727–730`).

```fortran
            Tauc(i,j)=m_ustrc*m_ustrc
            Tauw(i,j)=m_ustrwm*m_ustrwm
            Taucwmax(i,j)=m_ustrr*m_ustrr
            znotc(i,j)=min( m_zoa, zoMAX )
```

원문 대입은 `ROMS/Nonlinear/BBL/ssw_bbl.h:731–734`이다.

### 2.1 Moveable bed roughness

`SSW_CALC_ZNOT`에서 기본 거칠기는 `zoN`이다(`ROMS/Nonlinear/BBL/ssw_bbl.h:501`, `ROMS/Nonlinear/BBL/ssw_bbl.h:563`).
`SSW_ZOBL`은 `zoST`를 더한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:564–565`).
`SSW_ZORIP`은 `zoBF`를 더한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:567–568`).
`SSW_ZOBIO`는 `zoBIO`를 더한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:570–571`).
`SSW_CALC_ZNOT`가 없으면 `ZoBot`에서 받은 `zoDEF`에 `absolute_zoMIN` 하한을 적용한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:499–501`, `ROMS/Nonlinear/BBL/ssw_bbl.h:572–579`).

파일은 `N92_RIPRUF`를 정의한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:3`).
계수 선언의 첫 분기는 `GM82_RIPRUF`이다(`ROMS/Nonlinear/BBL/ssw_bbl.h:304`).
`GM82_RIPRUF`가 없을 때 `N92_RIPRUF` 분기의 `ar = 0.267_r8`을 선택한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:306–307`).
`GM82_RIPRUF`가 정의되어 있으면 `ar = 27.7_r8/30.0_r8`이 우선한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:304–305`).
`R88_RIPRUF`는 앞선 두 분기가 선택되지 않을 때의 분기이다(`ROMS/Nonlinear/BBL/ssw_bbl.h:308–309`).

## 3. MB / SG scheme

- `MB_BBL`은 Meinte Blaas의 구현이다([sediment-ice-vegetation:RN1-037](../../../_staging/recovery/compare/roms-sediment-ice-vegetation-vs-code.md#5-차이-결론)).
- 결합응력은 Soulsby 1997 근사를 사용한다(`ROMS/Nonlinear/BBL/mb_bbl.h:397–406`).
- 인용한 파랑 분기의 조건은 `IF (Ub(i,j).gt.0.01_r8) THEN`이다(`ROMS/Nonlinear/BBL/mb_bbl.h:389`).
- 실제 결합 응력 계산에는 `scf4 = 1.2_r8`과 `scf5 = 3.2_r8`이 들어간다(`ROMS/Nonlinear/BBL/mb_bbl.h:234–235`, `ROMS/Nonlinear/BBL/mb_bbl.h:399–400`).
- `SG_BBL`의 소스 머리말은 파랑 경계층 해에 2층 와점성 분포를 사용한다고 설명한다(`ROMS/Nonlinear/BBL/sg_bbl.h:10–13`). [10-14 전수 검증 정정]

## 4. 결합 — momentum & sediment

운동량의 bottom drag는 `bustr`·`bvstr`를 소비한다(`ROMS/Nonlinear/step2d_LF_AM3.h:2177–2189`).
rho-point current stress `bustrc`·`bvstrc`와 구분한다(`ROMS/Nonlinear/BBL/ssw_bbl.h:887–903`).
운동량 연결은 [3D 운동량 노트](roms_baroclinic_3d.md)와 [순압 노트](roms_barotropic_2d.md)를 참조한다.
퇴적물 연결은 [퇴적물 노트](sediment/roms_sediment.md)를 참조한다.
파랑 입력 연결은 [파랑 효과 노트](roms_wec.md)를 참조한다.

## 5. BBL 선택 근거

BBL 선택의 성능·적용 권고에는 해당 사례 근거를 붙인다([sediment-ice-vegetation:RN1-038](../../../_staging/recovery/compare/roms-sediment-ice-vegetation-vs-code.md#5-차이-결론)).
정적 코드 구조를 성능 보장으로 사용하지 않는다([sediment-ice-vegetation:RN1-038](../../../_staging/recovery/compare/roms-sediment-ice-vegetation-vs-code.md#5-차이-결론)).
BBL 외 단순 bottom drag는 [연직혼합 노트](roms_vertical_mixing.md)를 참조한다.
