# ROMS sea-ice 모델 (Budgell)

> `ROMS/Nonlinear/SeaIce/`(7682 라인) 직접 read. ROMS 의 **동적-열역학 해빙(sea-ice) 모델** (W. Paul Budgell 2002-2026, MIT/X license, ROMS Group). `ICE_MODEL` CPP 활성. thermodynamics(성장/소멸) + dynamics(EVP rheology) + 해빙-해양 결합(stress·brine). 고위도 해역용 — 한국 연안엔 비핵심이나 ROMS 의 완전한 도메인.

## 1. 구성 — 2 축

| 축 | CPP | 핵심 파일 |
|---|---|---|
| **thermodynamics** | `ICE_THERMO` | `ice_thermo.F`/`ice_mk.h`(Mellor-Kantha), `ice_enthalpy.F`, `ice_albedo.F` |
| **dynamics** | `ICE_MOMENTUM` | `ice_evp.F`(EVP), `ice_elastic.F`, `ice_evp_sig.F`(stress) |
| 이류 | `ICE_ADVECT` | `ice_advect.F`/`ice_smolar.h`, `ice_limit.F` |
| 결합 | | `ice_spdiw.F`(혼합층 평균 해류·상대속도), `ice_vbc.F`(ice-water stress), BC `ice_tibc/uibc/vibc.F`, `ice_bc2d.F` |

EVP 동역학은 `ICE_MOMENTUM`에서 활성화한다. (`ROMS/Include/globaldefs.h:804-805`)
해빙 이류는 `ICE_ADVECT`에서 활성화한다. (`ROMS/Include/globaldefs.h:801-802`)
`ICE_MODEL`과 `ICE_THERMO`를 선택해도 정규 드라이버는 `ice_frazil`을 호출하지 않는다. ([RN1-001](../../../_staging/recovery/compare/roms-sediment-ice-vegetation-vs-code.md#4-노트-대조와-수정안))

상태변수: 빙 두께 `hi`·농도(concentration) `ai`·snow·빙 속도 `ui/vi`·enthalpy/온도.

## 2. Thermodynamics — Mellor-Kantha (ice_mk.h) ★

`ice_thermo`(ice_mk.h:108) = **빙 성장/소멸**(growth/decay)을 표면·저면 열속으로 계산:
- 표면 열수지는 눈·얼음 상부의 융해 계산에 쓰인다. 적설 입력은 강수에서 얻은 `snow`이다. (`ROMS/Nonlinear/SeaIce/ice_mk.h:515-519,537-554`; [roms_bulk_flux_coare](roms_bulk_flux_coare.md)) [10-14 전수 검증 정정]
- 저면 성장·융해율 `icW_io`는 얼음의 전도 열속과 해양의 열 전달을 사용한다. (`ROMS/Nonlinear/SeaIce/ice_mk.h:673-676`) [10-14 전수 검증 보완]
- 열역학은 한 개의 내부 온도 상태를 갱신한다. (`ROMS/Nonlinear/SeaIce/ice_mk.h:429-437`)
- `ice_enthalpy.F`는 이류 전에 두께와 온도의 곱을 저장한다. (`ROMS/Nonlinear/SeaIce/ice_enthalpy.F:98-101`)
- 결정빙 식은 `ice_frazil.F`에 있다. (`ROMS/Nonlinear/SeaIce/ice_frazil.F:181-183`)
- 결정빙 호출 누락은 `RIF1-001`의 강한 코드 결함 후보이다. ([RN1-001·RIF1-001](../../../_staging/recovery/compare/roms-sediment-ice-vegetation-vs-code.md#5-차이-결론))
- **brine rejection**: 빙 결빙 시 염 배출 → 해양 표층 salt flux(밀도↑, 대류). 융해 시 담수 flux.
- Mellor & Kantha 1989 빙 열역학.

## 3. Dynamics — EVP rheology (ice_evp.F)

빙 운동량 = **Elastic-Viscous-Plastic(EVP) rheology**(Hunke & Dukowicz 1997):
- 빙 momentum: wind stress + ocean-ice stress(`ice_spdiw`) + Coriolis + sea-surface tilt + **internal ice stress**(rheology).
- **EVP**: 빙을 viscous-plastic(Hibler 1979) 으로 모델링하되 elastic 항을 추가해 explicit subcycling 으로 효율 해(원 VP 의 implicit 회피). `ice_evp_sig.F` = stress tensor(σ) 진화.
- **advection**(`ice_advect.F`/`ice_smolar.h`): 빙 두께·농도를 **Smolarkiewicz MPDATA**([roms_advection](roms_advection.md) 와 동족)로 수송한다. (`ROMS/Nonlinear/SeaIce/ice_smolar.h:10-17`) [10-14 전수 검증 보완]
- `ice_limit.F`는 농도를 `[0,max_ai(ng)]`로 제한한다. (`ROMS/Nonlinear/SeaIce/ice_limit.F:101-102`)
- 얼음·눈·융해수 두께에는 0 하한을 적용한다. (`ROMS/Nonlinear/SeaIce/ice_limit.F:103-105`)

압력·항력 차이는 아래 표의 `RIM1-008`·`RIM1-015`를 참조한다. ([RN1-004](../../../_staging/recovery/compare/roms-sediment-ice-vegetation-vs-code.md#4-노트-대조와-수정안))

## 4. 해빙-해양 결합

- `ice_spdiw.F`는 혼합층 평균 해류와 얼음의 상대속도 크기를 계산한다. (`ROMS/Nonlinear/SeaIce/ice_spdiw.F:183-219`)
- `ice_vbc.F`는 그 값을 사용해 얼음-해양 응력을 계산한다. (`ROMS/Nonlinear/SeaIce/ice_vbc.F:308-310`)
- 해빙-해양 결합은 얼음 농도에 따른 가중과 성장·융해 플럭스로 표면 열·운동량·염 플럭스를 수정한다. (`ROMS/Nonlinear/SeaIce/ice_mk.h:738-788`; `ROMS/Nonlinear/SeaIce/ice_vbc.F:301-310`; [roms_baroclinic_3d](roms_baroclinic_3d.md)) [10-14 전수 검증 정정]
- brine/freshwater flux → 표층 염분·밀도 → 대류·성층.
