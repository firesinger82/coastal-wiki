# ROMS 일반화 안정성이론(GST) & 관측 영향

> ROMS의 OP 드라이버는 전파자의 특이벡터로 해양 순환의 민감도와 안정성을 분석한다 (`ROMS/Drivers/op_roms.h:10–16`). 관측 민감도 드라이버는 지정한 순환 지표에 대한 각 관측의 영향을 계산한다 (`ROMS/Drivers/obs_sen_i4dvar_analysis.h:10–16`). 모델 구조는 [roms_adjoint_framework](roms_adjoint_framework.md)에 정리한다. 변분 자료동화는 [roms_4dvar](roms_4dvar.md)에 정리한다. [10-14 전수 검증 정정]

## 1. GST — propagator 고유값/특이값 분석 ★

TLM(전파연산자 R)·ADM(R*)의 spectrum 을 **ARPACK Arnoldi**(`propagator_*.h`)로 계산:

| driver | 분석 | 의미 |
|---|---|---|
| **FTE** `fte_roms` | Finite Time **Eigenmodes** of R | 유한시간 정상모드(가장 빨리 성장) |
| **AFTE** `afte_roms` | **Adjoint** FTE (R*) | adjoint eigenmode(수용성, biorthogonal) |
| **OP** `op_roms` | **Optimal Perturbations**(=Singular Vectors of R) | 최대 오차성장 초기교란(predictability·ensemble seed) |
| **FSV** `fsv_roms` | **Forcing** Singular Vectors | forcing 에 대한 최적 반응(stochastic forcing) |
| **SO** `so_roms` | **Stochastic Optimals** | 시변 random forcing 의 최적 분산 구조 |
| **SO_SEMI** `so_semi_roms` | SO seminorm 추정 | 부분공간 norm |
| **HOP/HSO** `propagator_hop/hso` | **Hessian** optimal pert/stochastic | 4D-Var 분석오차 공분산의 Hessian eigenstructure |

- **OP(singular vector)** = `R*·R` 의 최대 고유벡터 → 주어진 norm 에서 최대 성장 초기교란. **ensemble forecast seed·target observation** 의 이론적 기반.
- `propagator_fte.h`는 접선형 모델을 정방향으로 적분한다 (`ROMS/Drivers/propagator_fte.h:12–16`). `propagator_op.h`는 접선형 정방향 적분 뒤 수반 역방향 적분을 수행한다 (`ROMS/Drivers/propagator_op.h:12–17`). OP 드라이버의 반복문이 ARPACK 호출과 `propagator_op` 호출을 수행한다 (`ROMS/Drivers/op_roms.h:401–430`, `ROMS/Drivers/op_roms.h:487`). [10-14 전수 검증 정정]

### NCV 입력 검사

AFTE에서는 `IF (NCV.lt.(2*NEV+1)) THEN`이면 `exit_flag=5`로 종료한다 (`ROMS/Utility/read_phypar.F:635–640`).
`PROPAGATOR`의 NCV 전단 조건에는 `# if defined FT_EIGENMMODES || defined AFT_EIGENMODES`가 있다 (`ROMS/Utility/read_phypar.F:628`, `ROMS/Utility/read_phypar.F:635`).
`FT_EIGENMMODES` 오타 때문에 `FT_EIGENMODES`의 NCV 전단 검사가 선택되지 않는 결함 후보이다 (`ROMS/Utility/read_phypar.F:635–636`, `Master/roms_kernel.F:119`).
근거 강도는 강함이다 ([da-4dvar:DA1-025](../../../_staging/recovery/compare/roms-da-4dvar-vs-code.md#5-차이-결론)).

## 2. Observation 영향·설계

- **obs_sen_{i4dvar/r4dvar/rbl4dvar}_analysis.h**: **Observation Sensitivity** — 관측이 분석/예보(cost·forecast metric)에 미치는 영향(adjoint of forecast aspect). OSE/OSSE, 관측 영향 진단(FSO, Forecast Sensitivity to Observations).
- **obs_sen_rbl4dvar_forecast.h**: 예보 민감도(forecast error → 관측 기여).
- **optobs_roms.h**(Optimal Observation): 최적 **관측 배열 설계**(어디서 관측하면 분석 개선 최대 — OP/SV 기반 adaptive observation).

## 3. 보조 driver

- `pert_roms.h`는 INNER_PRODUCT 또는 SANITY_CHECK로 접선형·수반 모델의 관계를 검사한다 (`ROMS/Drivers/pert_roms.h:12–31`). `tlcheck_roms.h`는 접선형 모델의 선형화를 검사한다 (`ROMS/Drivers/tlcheck_roms.h:10–13`). `split_i4dvar_roms.h`, `split_r4dvar_roms.h`, `split_rbl4dvar_roms.h`는 해당 4D-Var 알고리즘을 여러 실행 파일로 나눈다 (`ROMS/Drivers/split_i4dvar_roms.h:17–36`, `ROMS/Drivers/split_r4dvar_roms.h:18–37`, `ROMS/Drivers/split_rbl4dvar_roms.h:18–37`). [10-14 전수 검증 정정]

## 4. ★ ad_/tl_/rp_ 커널 파일 — class 커버 명시

`ad_step3d_t.F`는 수반 추적자 방정식을 시간전진한다 (`ROMS/Adjoint/ad_step3d_t.F:14–18`). `tl_step3d_t.F`는 접선형 추적자 방정식을 시간전진한다 (`ROMS/Tangent/tl_step3d_t.F:14–18`). `rp_step3d_t.F`는 representer의 접선형 추적자 방정식을 시간전진한다 (`ROMS/Representer/rp_step3d_t.F:14–18`). 접선형·수반 모델의 전치 관계를 검사하는 드라이버는 `pert_roms.h`이다 (`ROMS/Drivers/pert_roms.h:12–26`). 모델 구조는 [roms_adjoint_framework](roms_adjoint_framework.md)에 정리한다. [10-14 전수 검증 정정]
