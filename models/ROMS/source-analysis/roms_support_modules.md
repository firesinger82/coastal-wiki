# ROMS 지원 모듈 맵 (Nonlinear/)

> ROMS `Nonlinear/` 의 **지원·제어·I/O 모듈** 종합(핵심 physics solver 외). 전 소스 커버 완결용 map.

## 1. Wetting/drying — wetdry.F(928)

- `wetdry`(:21): **wet/dry masking** 계산 — `rmask_wet`/`umask_wet`/`vmask_wet`(cell/edge 침수 여부, `Dcrit` 임계수심). 침수/노출 갯벌·조간대. flux mask 로 dry cell 운동량/transport 차단. `MASKING`+`WET_DRY` CPP.

## 2. Lagrangian floats — step/interp/vwalk_floats

- `step_floats.F`(1055): **부유체(float) 궤적** 시간전진(`FLOATS` CPP) — 흐름으로 입자 advect. **vertical random walk**(`vwalk_floats.F`, 연직 확산을 무작위 보행으로) optionally. `interp_floats.F`(543): float 위치로 흐름장 보간. 입자추적·확산 진단.

위치 입력은 12열이다.
출처는 [입력 대조 보고서의 RI1-1055](../../../_staging/recovery/compare/roms-inputs-vs-code.md#4-노트-대조와-수정안)이다.
시작 시각 변환의 원문은 `ROMS/Utility/read_fltpar.F:240`의 `DRIFTER(ng)%Tinfo(itstr,nc)=(dstart+Ft0(i,ng))*day2sec`이다.
station 경위도 좌표 변환의 조건 원문은 `ROMS/Utility/grid_coords.F:206`의 `IF (spherical) THEN`이다. [10-14 전수 검증 정정]
station의 FLAG 조건 원문은 `ROMS/Utility/grid_coords.F:209`의 `IF (SCALARS(ng)%Sflag(l).gt.0) THEN`이다. [10-14 전수 검증 정정]
출처는 [입력 대조 보고서의 RI1-1055](../../../_staging/recovery/compare/roms-inputs-vs-code.md#4-노트-대조와-수정안)이다.

## 3. 출력·평균 — set_avg.F(5800)

- `set_avg`: **시간평균 출력**(`AVERAGES` CPP) — `Aout`으로 선택한 변수의 출력 간격 평균 누적(수위·수심평균 유속의 조건부 처리: `set_avg.F:295-345`). + `AVERAGES_DETIDE`(조석 제거, [`roms_tidal_forcing`](roms_tidal_forcing.md) §3).

## 4. 주기 경계 복사와 MPI halo 교환

Nonlinear/exchange_*는 주기 경계 값을 복사한다. (`ROMS/Nonlinear/exchange_2d.F:11,132`, `ROMS/Nonlinear/exchange_3d.F:12`, `ROMS/Nonlinear/exchange_4d.F:12`)
Utility/mp_exchange*는 MPI 이웃 rank 사이의 halo를 교환한다. (`ROMS/Utility/mp_exchange.F:520`)
출처는 [결합 대조 보고서의 RCN-1983](../../../_staging/recovery/compare/roms-coupling-nesting-parallel-vs-code.md#4-노트-대조와-수정안)이다.

주기 경계 복사의 원문은 `ROMS/Nonlinear/exchange_2d.F:132`의 `A(Lm(ng)+1,j)=A(1,j)`이다.
MPI 수신의 원문은 `ROMS/Utility/mp_exchange.F:520`의 `CALL mpi_irecv (recvW, EWsize, MP_FLOAT, Wtile, Etag,           &`이다.

## 5. 초기화 — ini_fields/set_zeta/post_initial/set_grid/get_idata/get_data

ini_fields.F는 초기장(운동량·tracer)을 설정한다. (`ROMS/Nonlinear/ini_fields.F:12–14,547–563`) [10-14 전수 검증 보완]
set_zeta.F는 자유표면 ζ를 빠른 시간 간격의 평균값으로 설정한다. (`ROMS/Nonlinear/set_zeta.F:13,103–104`) [10-14 전수 검증 정정]
post_initial.F는 초기화 후 처리를 수행한다. (`ROMS/Nonlinear/post_initial.F:13–16`) [10-14 전수 검증 보완]
출처는 [비선형 호출 흐름 보고서의 초기화·단계 흐름](../../../_staging/recovery/flow/ROMS-callflow-nonlinear.md#4-계산-흐름도)이다.

set_grid는 ANA_GRID가 참이면 해석 함수로 격자·수심을 준비한다. (`ROMS/Utility/set_grid.F:63,65`)
MASKING일 때 마스크도 준비한다. (`ROMS/Utility/set_grid.F:66–67`)
ANA_GRID가 거짓이면 get_grid를 호출한다. (`ROMS/Utility/set_grid.F:76,79,81`)
CORRELATION이 거짓이고 Lnudging이 참이면 ANA_NUDGCOEF에 따라 너징 계수를 계산하거나 읽는다. (`ROMS/Utility/set_grid.F:163,170–183`)
출처는 [비선형 호출 흐름의 RF1-026](../../../_staging/recovery/flow/ROMS-callflow-nonlinear.md#6-기존-노트-대조와-수정안)이다.

get_idata의 원문은 `ROMS/Nonlinear/get_idata.F:11`의 `!  This routine reads input data that needs to be obtained only once.  !`이다.
get_idata의 조석 주기 읽기는 SSH_TIDES 또는 UV_TIDES가 참이고 LprocessTides가 참이며 iic가 0일 때 실행한다. (`ROMS/Nonlinear/get_idata.F:120,128–130,136`)
get_data는 시간 레코드가 있는 외력·기후장 등 입력을 처리한다. (`ROMS/Nonlinear/get_data.F:11–14`)
출처는 [비선형 호출 흐름의 RF1-026](../../../_staging/recovery/flow/ROMS-callflow-nonlinear.md#6-기존-노트-대조와-수정안)이다.

## 6. Adjoint/4D-Var 보조 — obc_adjust/frc_adjust

- `obc_adjust.F`는 4D-Var 경계 증분을 비선형 모델의 개방경계 배열에 더한다. (`ROMS/Nonlinear/obc_adjust.F:13–16`) `frc_adjust.F`는 4D-Var 표면 외력 증분으로 비선형 모델의 표면 외력을 조정한다. (`ROMS/Nonlinear/frc_adjust.F:13–16`) 관련 노트는 [`roms_4dvar`](roms_4dvar.md)이다. [10-14 전수 검증 정정]

## 7. 난류 BC — tkebc_im.F(702)

- `tkebc_im`은 난류 운동에너지와 난류 길이 척도의 측면 경계조건을 설정한다. (`ROMS/Nonlinear/tkebc_im.F:12–14`) 관련 노트는 [`roms_vertical_mixing`](roms_vertical_mixing.md)이다. [10-14 전수 검증 정정]

## 8. 기타

- `hmixing.F` → [`roms_horizontal_mixing`](roms_horizontal_mixing.md)(별도). `set_tides.F` → [`roms_tidal_forcing`](roms_tidal_forcing.md)(별도).
