# ROMS 조석 forcing (set_tides.F)

`set_tides`는 boundary·climatology의 tide를 계산한다(`ROMS/Nonlinear/set_tides.F:273–295`; [mixing-bc-forcing 대조 보고서](../../../_staging/recovery/compare/roms-mixing-bc-forcing-vs-code.md#4-노트-대조와-수정안), RMF1-934).
astronomical body force는 별도 `TIDE_GENERATING_FORCES`와 `equilibrium_tide` 경로이다(`ROMS/Nonlinear/prsgrd32.h:285–286` `#ifdef TIDE_GENERATING_FORCES` / `          P(i,j,N(ng))=P(i,j,N(ng))-g*eq_tide(i,j)`).

## 1. 조석 추가 (set_tides.F:12)

> "adds tidal elevation (m) and tidal currents (m/s)"
- **SSH_TIDES**: `set_tides`는 `cos(2π(time-tide_start day2sec)/Tperiod-SSH_Tphase)`를 사용한다([theory-numerics 대조 보고서](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md#5-차이-결론), RTN-248).
- **UV_TIDES** 입력은 `UV_Tmajor`·`UV_Tminor`·`UV_Tangle`·`UV_Tphase`이다(`ROMS/Nonlinear/set_tides.F:443–452`; mixing-bc-forcing:RMF1-935).
- `Tperiod` = 분조 주기(M2/S2/K1/O1 등), `mod_tides` 가 조화상수 보관.

`SSH_TIDES`의 위상 합산 원문은 다음과 같다(theory-numerics:RTN-396).

- `ROMS/Nonlinear/set_tides.F:280` `        cff=2.0_r8*pi*(time(ng)-tide_start*day2sec)`
- `ROMS/Nonlinear/set_tides.F:282` `          IF (Tperiod(itide).gt.0.0_r8) THEN`
- `ROMS/Nonlinear/set_tides.F:283` `            omega=cff/Tperiod(itide)`
- `ROMS/Nonlinear/set_tides.F:286` `                Etide(i,j)=Etide(i,j)+                                  &`
- `ROMS/Nonlinear/set_tides.F:287` `     &                     ramp*SSH_Tamp(i,j,itide)*                    &`
- `ROMS/Nonlinear/set_tides.F:288` `     &                     COS(omega-SSH_Tphase(i,j,itide))`

## 2. 위상 시간 원점과 nodal factor

`TIDE_START`는 조석 위상 0의 시간 원점이다([theory-numerics 대조 보고서](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md#4-노트-대조와-수정안), RTN-396).
단위는 일이다(`ROMS/Modules/mod_scalars.F:292` `        real(dp) :: tide_start = 0.0_dp                  ! days`).
모델은 `time-tide_start*day2sec`를 사용한다(`ROMS/Nonlinear/set_tides.F:280` `        cff=2.0_r8*pi*(time(ng)-tide_start*day2sec)`).
파일을 만드는 단계의 천문 보정은 이 시간 원점 설명과 구분한다.

`ANA_TIDES`가 정의되지 않고 `TIDE_GENERATING_FORCES`·`SSH_TIDES`·`UV_TIDES` 중 하나 이상이 정의된 `tides_date` 경로는 조석 파일의 `zero_phase_date`를 찾으면 `tide_start`를 그 날짜와 모델 기준 날짜의 차이로 다시 정한다(`ROMS/Utility/tides_date.F:2–4,140–173`; theory-numerics:RTN-358). [10-14 전수 검증 정정]
`RAMP_TIDES`의 `ramp`는 모델 시작 날짜부터의 1일 척도를 쓴다.

- `ROMS/Nonlinear/set_tides.F:245–253` `      NEEDED : IF (LprocessTides(ng)) THEN` / `# ifdef RAMP_TIDES` / `        ramp=TANH((tdays(ng)-dstart)/1.0_r8)` / `# else` / `        ramp=1.0_r8` / `# endif`

`set_tides`는 입력 경계 조화상수를 시간에 따른 위상으로 합산한다(mixing-bc-forcing:RMF1-936).
해당 루프는 입력 조화상수의 nodal factor를 매번 다시 계산하지 않는다(`ROMS/Nonlinear/set_tides.F:437–452`).
별도 `TIDE_GENERATING_FORCES` 경로는 기준 tide 날짜를 써서 `harmonic_constituents`를 호출한다(`ROMS/Utility/set_grid.F:194–202` `# ifdef TIDE_GENERATING_FORCES` / `      CALL harmonic_constituents (Lnodal)`).
`IF (Lnodal) THEN`에서 nodal factor를 계산하고 ELSE에서는 1로 둔다(`ROMS/Utility/equilibrium_tide.F:304–318`; mixing-bc-forcing:RMF1-936).

## 3. AVERAGES_DETIDE — de-tiding (set_tides.F:32-48)

detiding fit의 계수 합은 reset하지 않는다(`ROMS/Nonlinear/set_avg.F:5286–5295`; [mixing-bc-forcing 대조 보고서](../../../_staging/recovery/compare/roms-mixing-bc-forcing-vs-code.md#4-노트-대조와-수정안), RMF1-938).
출력 averaging window와 누적 fitting 구간을 구분한다.

`ROMS/Nonlinear/set_avg.F:5295–5305` 원문:

```fortran
        IF (DOMAIN(ng)%SouthWest_Test(tile)) THEN
          Hcount(ng)=Hcount(ng)+1
          DO nk=1,NTC
            SinW_avg(nk)=SinOmega(nk)
            CosW_avg(nk)=CosOmega(nk)
            SinW_sum(nk)=SinW_sum(nk)+SinOmega(nk)
            CosW_sum(nk)=CosW_sum(nk)+CosOmega(nk)
            DO mk=1,NTC
              SinWSinW(mk,nk)=SinWSinW(mk,nk)+SinOmega(mk)*SinOmega(nk)
              CosWCosW(mk,nk)=CosWCosW(mk,nk)+CosOmega(mk)*CosOmega(nk)
              SinWCosW(mk,nk)=SinWCosW(mk,nk)+SinOmega(mk)*CosOmega(nk)
```

## 4. 위치

- `set_tides`는 [경계 조석](roms_open_boundaries.md)과 기후장을 처리한다. `TIDE_GENERATING_FORCES`의 평형 조석은 별도 압력 항에 들어간다. (`ROMS/Nonlinear/set_tides.F:301–304,330–347`; `ROMS/Nonlinear/prsgrd32.h:285–286`; mixing-bc-forcing:RMF1-934) [10-14 전수 검증 정정]
- 조석 조화상수는 외부(TPXO/FES/OTPS) → ROMS forcing 파일.

## 5. 연결
