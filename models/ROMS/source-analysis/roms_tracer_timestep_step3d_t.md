# ROMS tracer 시간적분 엔진 — `step3d_t.F`

> 소스: [`ROMS/Nonlinear/step3d_t.F`](../raw/source_code/roms/ROMS/Nonlinear/step3d_t.F)(1976, `#if !defined TS_FIXED && (defined NONLINEAR && defined SOLVE3D)`, author Shchepetkin).
> `step3d_t`는 `NONLINEAR`와 `SOLVE3D`가 참이고 `TS_FIXED`가 거짓일 때의 추적자 수정 루틴이다 (`ROMS/Nonlinear/step3d_t.F:3`; [callflow-nonlinear:RF1-024](../../../_staging/recovery/flow/ROMS-callflow-nonlinear.md)).

## 0. 추적자 corrector 입력 계약 (:21-28)

진입 시 `t(:,:,:,nnew,:)`는 층 두께를 곱한 `m*Tunits` 상태이다 (`ROMS/Nonlinear/step3d_t.F:23–25`; [theory-numerics:RTN-386](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
시점 3의 `t(:,:,:,3,:)`는 이류 predictor의 `Tunits` 농도이다 (`ROMS/Nonlinear/step3d_t.F:27–28`, `ROMS/Nonlinear/pre_step3d.F:899–901`).
원 헤더의 diffusion predictor 설명은 현재 `lambda=1`의 명시 확산 기여 0과 함께 설명한다 ([theory-numerics:RTN-386](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
`pre_step3d`는 MPDATA·HSIMT와 다른 이류 선택에서 `Gamma`를 다르게 정한다 (`ROMS/Nonlinear/pre_step3d.F:622–626`; [callflow-nonlinear:RF1-024](../../../_staging/recovery/flow/ROMS-callflow-nonlinear.md)).
MPDATA와 HSIMT는 같은 중간 `Γ=1/2` 분기를 사용한다 ([theory-numerics:RTN-168](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
현행 tracer 적분은 `Γ=1/6`의 predictor와 보존형 corrector를 사용한다 ([theory-numerics:RTN-127](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
MPDATA·HSIMT는 별도 경로이다 ([theory-numerics:RTN-127](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
`oHz(i,j,k)=1.0_r8/Hz(i,j,k)`로 층 두께의 역수를 계산한다 (`ROMS/Nonlinear/step3d_t.F:388`, `ROMS/Nonlinear/step3d_t.F:396`). [10-14 전수 검증 정정]

## 1. 수평 advection → conservative flux-form 갱신

수평 이류 flux는 [roms_advection](roms_advection.md)의 스킴별 분기를 따른다 (`ROMS/Nonlinear/step3d_t.F:432–770`). 아래 보존형 갱신은 수평 MPDATA를 제외한 경로이다 (`ROMS/Nonlinear/step3d_t.F:873`, `ROMS/Nonlinear/step3d_t.F:899–909`). [10-14 전수 검증 정정]
```fortran
                cff=dt(ng)*pm(i,j)*pn(i,j)
                cff1=cff*(FX(i+1,j)-FX(i,j))
                cff2=cff*(FE(i,j+1)-FE(i,j))
                cff3=cff1+cff2
                t(i,j,k,nnew,itrc)=t(i,j,k,nnew,itrc)-cff3
```
위 식은 `ROMS/Nonlinear/step3d_t.F:905–909`의 원문이다 ([theory-numerics:RTN-392](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
flux 발산은 층 두께 가중 tracer 상태 `Hz*C`를 갱신한다 (`ROMS/Nonlinear/pre_step3d.F:998–1000`).
물질 밀도 `rho`로 가중하지 않는다 ([theory-numerics:RTN-392](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
단위 `m*Tunits`는 이 층 두께 가중과 대응한다 ([theory-numerics:RTN-392](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
수평 MPDATA는 중간 결과를 `Ta(i,j,k,itrc)=t(i,j,k,nnew,itrc)-cff3`에 저장한다 (`ROMS/Nonlinear/step3d_t.F:873–880`). [10-14 전수 검증 정정]

## 2. 연직 advection (:922-1186)
spline(:938)·Akima(:987)·centered-2(:1029)·MPDATA(:1048-1063)·HSIMT(:1071)·centered-4(:1147).
연직 first-order upstream flux는 MPDATA 분기의 첫 단계이다 (`ROMS/Nonlinear/step3d_t.F:1048–1063`; [theory-numerics:RTN-375](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).

## 3. ★이중 implicit tridiagonal (OMEGA_IMPLICIT) — advection 먼저, 확산 나중

### 3.1 implicit 연직 advection (:1556-1655)
`FC=dt·Wi·pm·pn`(off-diag :1559), diagonal `BC`(:1583), tridiagonal solve(:1597)+back-sub(:1612) — **확산보다 먼저**.

### 3.2 implicit 연직 diffusion — 현재 lambda=1 (:1657-1789)

현행 공통 `lambda`는 1이다 (`ROMS/Modules/mod_scalars.F:761,764`).
현재 단계 확산 기여 `dt*(1-lambda)`는 0이다 (`ROMS/Nonlinear/pre_step3d.F:917`; [theory-numerics:RTN-384](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
미래 단계는 backward implicit으로 계산한다 ([theory-numerics:RTN-384](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
`lambda=0.5`일 때만 Crank–Nicolson이라고 적는다 (`ROMS/Modules/mod_scalars.F:756–764`; [theory-numerics:RTN-384](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).

```fortran
FC(i,k) = -dt*lambda/(z_r(k+1)-z_r(k))*Akt(i,j,k,ltrc)   ! :1730-1734 off-diag
BC(i,k) = Hz(i,j,k) - FC(i,k) - FC(i,k-1)                 ! :1747 diagonal
DC(i,k) = t(i,j,k,nnew,itrc)                              ! :1748 RHS
! Thomas: forward elim (:1755-1764) + back-sub (:1769) → 최종 t(nnew)
```
spline 확산과 표준 확산은 서로 다른 삼대각 행렬을 조립한다 (`ROMS/Nonlinear/step3d_t.F:1664–1696`, `ROMS/Nonlinear/step3d_t.F:1730–1748`; [theory-numerics:RTN-387](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)). [10-14 전수 검증 정정]
두 확산 경로는 삼대각 소거·전진 대입·후진 대입을 사용한다 (`ROMS/Nonlinear/step3d_t.F:1686–1709`, `ROMS/Nonlinear/step3d_t.F:1752–1788`). [10-14 전수 검증 보완]
해석: `CF_k=c_k/(b_k-a_k*CF_{k-1})`와 `DC_k=(d_k-a_k*DC_{k-1})/(b_k-a_k*CF_{k-1})`는 삼대각 LU 소거의 같은 재귀식이다 ([theory-numerics:RTN-387](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).

## 4. MPDATA anti-diffusion (:1371-1458)
MPDATA는 `mpdata_adiff_tile`로 보정 속도를 계산한다 (`ROMS/Nonlinear/step3d_t.F:1376–1397`). 수평 보정 flux는 `Ta`를 사용한다 (`ROMS/Nonlinear/step3d_t.F:1406–1417`). 수평 갱신은 1425–1429줄에서 수행한다. 연직 보정 flux는 1447–1450줄에서 계산한다. 연직 갱신은 1468–1469줄에서 수행한다. TLM·RPM·ADM의 MPDATA 미지원은 접선형 루틴 주석에 명시되어 있다 (`ROMS/Tangent/tl_step3d_t.F:25`). [10-14 전수 검증 정정]

MPDATA의 수평·연직 선택이 모두 참이면 `Ta` 중간장과 별도 보정 플럭스를 사용한다 (`ROMS/Nonlinear/step3d_t.F:1376–1377,1429`; [callflow-nonlinear:RF1-024](../../../_staging/recovery/flow/ROMS-callflow-nonlinear.md)).

## 5. Point source + SED_MORPH (:1485-1554)
LwSrc tracer 주입(:1485-1526, `LTracerSrc` 시 유입농도 Tsrc, else 체적보상). SED_MORPH bed 변화 mass 를 1/N 분배(:1528-1554). ★MPDATA(:1223-1240 Ta 증분) vs non-MPDATA(:1528 체적보상) **경로 이원**.

## 6. Mean-age + LBC + nudging (:1804-1928)
수평·연직 MPDATA에서 mean-age 생성항은 `t(i,j,k,nnew,iage)=t(i,j,k,nnew,iage)+                  &`와 연속행 `&                             dt(ng)*t(i,j,k,nnew,inert(itrc))`이다 (`ROMS/Nonlinear/step3d_t.F:1822–1825`). 그 외 분기는 `dt(ng)*t(i,j,k,3,inert(itrc))`를 사용한다 (`ROMS/Nonlinear/step3d_t.F:1826–1828`). [10-14 전수 검증 정정]
`AGE_MEAN&&T_PASSIVE`에서 inert 추적자를 두 개씩 짝짓는다 ([inputs:RI1-1056](../../../_staging/recovery/compare/roms-inputs-vs-code.md)).
짝수 추적자에 `dt` 곱한 보존 추적자의 농도를 더한다 ([inputs:RI1-1056](../../../_staging/recovery/compare/roms-inputs-vs-code.md)).
`AGE_MEAN`과 `T_PASSIVE`를 켜면 `NPT`는 짝수여야 한다 (`ROMS/Utility/read_phypar.F:324–325`; [inputs:RI1-1056](../../../_staging/recovery/compare/roms-inputs-vs-code.md)).

`t3dbc_tile`이 측면 경계조건을 적용한다 (`ROMS/Nonlinear/step3d_t.F:1858–1862`). 이후 `IF (LtracerCLM(itrc,ng).and.LnudgeTCLM(itrc,ng)) THEN`에서 기후값 누징을 적용한다 (`ROMS/Nonlinear/step3d_t.F:1866–1874`). MASKING은 육지·바다 마스크를 적용한다 (`ROMS/Nonlinear/step3d_t.F:1880–1891`). DIAGNOSTICS_TS는 추적자 변화량을 기록한다 (`ROMS/Nonlinear/step3d_t.F:1892–1906`). 주기 경계 교환은 `EWperiodic(ng).or.NSperiodic(ng)`일 때 `exchange_r3d_tile`을 호출한다 (`ROMS/Nonlinear/step3d_t.F:1910–1914`). DISTRIBUTE는 `mp_exchange4d`를 호출한다 (`ROMS/Nonlinear/step3d_t.F:1916–1925`). [10-14 전수 검증 정정]

## 7. 주요 findings
- OMEGA_IMPLICIT의 음해 연직 이류는 `IF (.not.Vadvection(itrc,ng)%MPDATA) THEN`에서 계산한다 (`ROMS/Nonlinear/step3d_t.F:1553–1567`). 연직 확산은 이 전처리 조건 블록이 끝난 뒤 별도 계산한다 (`ROMS/Nonlinear/step3d_t.F:1654–1664`). [10-14 전수 검증 정정]
- spline과 표준 확산은 다른 삼대각 행렬을 조립한다 ([theory-numerics:RTN-387](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
- 해법 이름 Thomas와 삼대각 LU를 서로 배제하지 않는다 ([theory-numerics:RTN-387](../../../_staging/recovery/compare/roms-theory-numerics-vs-code.md)).
- **MPDATA private Ta 중간장**(:870, in-place 아님) → TLM/ADM 미지원 근본원인.
- **SED_MORPH mass 이중경로**(MPDATA Ta vs non-MPDATA 1/N 보상).
- **nudging = LBC 후, LtracerCLM&LnudgeTCLM 만**(:1852,1866).
