# SWASH 난류 closure — k-ε·Reynolds stress·eddy viscosity·log-law·anti-creep

> SWASH 의 3D 연직 혼합은 표준 k-ε(Launder & Spalding 1974), 수평 혼합은 Smagorinsky/혼합길이, 벽 마찰은 log-law, 그리고 sigma 격자 인공확산은 anti-creep + z-plane MUSCL 로 보정한다. (경로: raw/source_code/swash/src/)

## 0. 디스패치 구조

| 호출 | 분기 | 파일:라인 |
|---|---|---|
| `SwashComputTurb` | 1D → `SwashKepsMod1DH`, 2D → `SwashKepsMod2DH` (둘 다 `iturb /= 0` 일 때) | `SwashComputTurb.ftn90:76-102` |
| `SwashCompUTurb` | 삼각망: `iturb == 1` → `SwashUKepsMod` | `SwashCompUTurb.ftn90:75-82` |

`SwashComputTurb` 의 Method 주석은 closure 의 정체를 명시한다: *"The well-known standard k-epsilon closure of Launder and Spalding (1974) is employed for vertical mixing with which 3D turbulence is mainly generated by vertical velocity gradients and bottom friction. Typically, its length scale is smaller than the water depth."* (`SwashComputTurb.ftn90:44-50`). 출력용 평균 통계는 `SwashAverOutp(3)` 으로 갱신 (`SwashComputTurb.ftn90:106`).

`iturb` 값의 의미는 `iturb==1`(선형 k-ε), `iturb==3`(비선형 Reynolds stress) 이 본 코드 분기들에서 드러난다 (`SwashReynoldsStress.ftn90:245,656`). ⚠ `iturb==2` 의 정확한 의미는 본 파일군에서 직접 확인 안 됨(source-needed).

## 1. 표준 k-ε 모델 (KepsMod) — closure 상수

1DH·2DH·삼각망(U) 세 변형 모두 동일한 표준 상수를 `parameter` 로 박아둔다:

| 상수 | 값 | 의미 | 인용 |
|---|---|---|---|
| $C_{\varepsilon 1}$ | 1.44 | $\varepsilon$ 생성 계수 | `SwashKepsMod1DH.ftn90:84` |
| $C_{\varepsilon 2}$ | 1.92 | $\varepsilon$ 소산 계수 | `SwashKepsMod1DH.ftn90:85` |
| $C_\mu$ | 0.09 | eddy viscosity 계수 | `SwashKepsMod1DH.ftn90:86` |
| $\sigma_k$ | 1.0 | TKE Prandtl-Schmidt 수 | `SwashKepsMod1DH.ftn90:87` |
| $\sigma_\varepsilon$ | 1.3 | $\varepsilon$ Prandtl-Schmidt 수 | `SwashKepsMod1DH.ftn90:88` |
| $\sigma_\rho$ | 0.5 | buoyancy 항 계수 | `SwashKepsMod1DH.ftn90:89` |
| $\gamma$ | 0.34 | 다공질 added-mass 경험계수 | `SwashKepsMod1DH.ftn90:94` |

2DH·U 변형도 동일 (`SwashKepsMod2DH.ftn90:80-90`, `SwashUKepsMod.ftn90:72-77`). `rtur(:,:,1)` = $k$ (TKE), `rtur(:,:,2)` = $\varepsilon$ (소산율). 반복용 상수: `maxit=100`, `reps=0.5e-4` (`SwashKepsMod1DH.ftn90:91-92`).

## 2. 연직 eddy viscosity (VertVisc)

`SwashVertVisc` 는 표준 k-ε relation 으로 연직 점성을 산출:

$$\nu_{3D} = C_\mu \frac{k^2}{\varepsilon + \epsilon},\quad C_\mu=0.09,\ \epsilon=10^{-8}$$

verbatim 코드: `vnu3d(:,:) = cmu * rtur(:,:,1) * rtur(:,:,1) / ( rtur(:,:,2) + eps )` (`SwashVertVisc.ftn90:72`; 상수 `:56-58`). Method 주석: *"The standard k-eps model is utilized to account for vertical mixing"* (`SwashVertVisc.ftn90:44`).

`iturb == 1` 일 때만 후처리 적용 (`SwashVertVisc.ftn90:74-88`):
1. 배경 점성 하한: `vnu3d = max( vnu3d, bvisc )` (`:78`)
2. 분자 점성 추가: `vnu3d = vnu3d + kinvis` (`:82`)
3. 상한 클리핑: `vnu3d = min( vnu3d, maxvisc )`, `maxvisc=10.` (`:86,58`)

비선형(`iturb==3`)에서는 이 하한/상한 후처리를 건너뛴다(분기 조건 `:74`).

## 3. k-ε 방정식 구성·해법 (KepsMod1DH 정독)

Method 주석(`SwashKepsMod1DH.ftn90:47-61`): 완전 음해(fully implicit), 1차 time-splitting. **1단계** 수평이류만 음해 + 1차 upwind, 연직 decoupled, 양방향 Gauss-Seidel 2-sweep(`:253-377`). **2단계** 연직 이류·확산 + 소스/싱크 음해(sink implicit, source explicit), 수평 decoupled, 삼중대각 double sweep(`:851-877`).

### 3.1 수평·연직 수송
- 시간미분 `1/dt` (`:207`), 수평 1차 upwind: `ctrml=0.5*(u+|u|)/dx`, `ctrmr=0.5*(u-|u|)/dx` (`:213-218`).
- 연직 이류 1차 upwind: `ctrkb`, `ctrkt` 를 `wom`(상대 연직속도)으로 (`:457-466`).
- 연직 확산: 계면 점성 평균을 $\sigma$(=psm) 로 나눔: `ctrkb = 0.5*(vnu3d(k)+vnu3d(k+1))/(psm*dz*hks(k+1))` (`:472-473`). $\sigma$ 는 $l=1$ 일 때 $\sigma_k$, $l=2$ 일 때 $\sigma_\varepsilon$ (`:409-410`).

### 3.2 연직 전단 (생성항 기반)
$$\left(\partial u/\partial z\right)^2:\quad \text{dudz}=\frac{u(k)+u_{m-1}(k)-u(k{+}1)-u_{m-1}(k{+}1)}{h_k+h_{k+1}},\ \ \text{zshear}=\text{dudz}^2$$
(`SwashKepsMod1DH.ftn90:397-399`).

### 3.3 TKE 방정식 ($l=1$) 소스/싱크
- **생성**: `rhst += vnu3d * zshear` → $P_k=\nu_t (\partial_z u)^2$ (`:499`)
- **소산(Newton 선형화)**: 대각에 `+2*ε/(k+eps)`, rhs 에 `+ε` (`:503-504`). 즉 $\varepsilon$ 을 $2\varepsilon/k\cdot k - \varepsilon$ 형태로 선형화.
- **buoyancy** (`idens/=0`): `buotke = vnu3d*grav*drhodz/(rhow*sigrho)`; 양이면 source, 음이면 sink(대각에 `-buotke/(k+eps)`) (`:524-536`).
- **식생**(`iveg/=0`): `prodveg` 를 항력 `cvegu·u²` 로 만들어 `rhst += cfk*prodveg` (`cfk=pturb(2)`) (`:546-574,381`).
- **다공질**(`iporos==1`): $\varepsilon_\infty=39(1-n)^{2.5}n^2 |U|^3/d$ 를 TKE 소스로 (`:601-603`).

### 3.4 ε 방정식 ($l=2$) 소스/싱크
- **생성**: `rhst += ceps1*cmu*rtur(k,1)*zshear` → $C_{\varepsilon1}C_\mu k\,(\partial_z u)^2$ (`:625`). (= $C_{\varepsilon1}\frac{\varepsilon}{k}P_k$ 를 $\nu_t=C_\mu k^2/\varepsilon$ 로 치환한 형태)
- **소산(Newton)**: `fac=ceps2*ε/(k+eps)`; 대각 `+2*fac`, rhs `+fac*ε` (`:629-632`).
- buoyancy: drhodz>0 일 때만 `+ceps1*cmu*k*grav*drhodz/(rhow*sigrho)` (`:654-656`).
- 식생: `+ceps1*cfe*prodveg*ε/(k+eps)` (`cfe=pturb(3)`) (`:688,382`).
- 다공질: `+ceps2*epsinf²/(tkeinf+eps)`, $\text{tkeinf}=3.7(1-n)n^{1.5}|U|^2$ (`:723-726`).

### 3.5 경계 조건
| 위치 | 양 | 식 | 인용 |
|---|---|---|---|
| 자유표면 TKE | Neumann형 | `amatt(0,1)=1+rtur(2,1)/(rtur(0,1)+eps)`, `amatt(0,3)=-2` | `:748-751` |
| 자유표면 ε | Dirichlet | $\varepsilon_0 = C_\mu^{3/4} k^{3/2}/(\kappa z_s)$ | `:772` |
| 바닥 TKE (`irough/=4`) | Dirichlet | $k=u_*^2/\sqrt{C_\mu}$, $u_*^2=\frac14(c_f{+}c_f')(u_d^2{+}u_d'^2)$ | `:801-804` |
| 바닥 TKE (`irough==4`, log-law) | 생성+소산 | 생성 `+0.25*logfrc(1)*(u+u')²/zs`, 소산 대각 `+C_\mu^{3/4}\sqrt{k}\,logfrc(2)/zs` | `:812-816` |
| 바닥 ε | Dirichlet | $\varepsilon = C_\mu^{3/4} k^{3/2}/(\kappa z_s)$ | `:839` |

log-law(`irough==4`) 일 때 바닥에서 TKE 방정식을 푸므로 `kend=kmax`, 아니면 `kend=kmax-1` (`:181-188, 412-416`). 음수값 발생 시 `eps` 로 클리핑 (`:881-910`).

### 3.6 변형별 차이
- **2DH** (`SwashKepsMod2DH.ftn90`): 동일 상수·소스항(`:80-90, 863-867, 990, 1040, 1082, 1094, 1119`), x·y 양방향 수평이류 추가. 표면 ε `:1040`, 바닥 TKE Dirichlet `:1082`, log-law `:1094`, 바닥 ε `:1119` 가 1DH 와 동일 식.
- **삼각망 U** (`SwashUKepsMod.ftn90`): Method 주석상 시간적분이 **반음해(semi-implicit)** — 수평이류는 **명시적**(explicit), 연직만 음해(`:44-53`). 상수 동일(`:72-77`). cell/face 자료구조로 flux 누적(`:148-159`).

## 4. Reynolds stress 텐서 (선형/비선형)

`SwashReynoldsStress` 는 응력 텐서 성분(`rsuu, rsuw, rswu, rsww` 등)을 계산. Method 주석이 두 옵션을 명시(`SwashReynoldsStress.ftn90:56-64`): *"The first option is the linear k-epsilon model of Launder and Spalding (1974) ... The second option is the nonlinear k-epsilon model of Speziale (1987)"*.

### 4.1 선형부 (항상 계산)
$$-\overline{u'u'} = (\nu_{k-1}+\nu_k)\,\frac{u(k)-u_{m-1}(k)}{\Delta x}$$
(`:176`). 전단 응력: `rsuw = 0.5*(vnu3d(nm)+vnu3d(nmu))*(dudz+dwdx)` (`:200`). 2D 에서는 곡선격자 metric `gvv/guu/gvu` 사용, `rsuv = lvisc*(dudy+dvdx)` (`:473`).

### 4.2 비선형부 (`iturb == 3`)
Speziale 의 2차 구성식. closure 상수(`:78-81`):

| 상수 | 값 | 인용 |
|---|---|---|
| $c_1$ | 0.4536 | `:78` |
| $c_2$ | 0.3024 | `:79` |
| $c_3$ | -0.1512 | `:80` |
| $C_\mu$ | 0.09 | `:81` |

비선형 계수: `fac = lvisc²/(cmu*ltke)` = $\nu_t^2/(C_\mu k)$ (`:268`). 세 종류 mean strain 텐서 $S^{(1)},S^{(2)},S^{(3)}$ 를 속도구배로 구성하고(예 `s1xx=dudx²+dudz²`, `:276-283`), 편차(deviatoric) 형태로 빼준다:
$$-\overline{u'u'} \mathrel{-}= \text{fac}\left[c_1(S^1_{xx}-\tfrac{S^1_{xx}+S^1_{zz}}{3}) + c_2(\cdots) + c_3(\cdots)\right]$$
(`:285-287`). 2D 는 trace 에 $S_{yy}$ 포함, 9성분 전부 구성(`:701-715`). 전단성분은 trace 보정 없이 `-fac*(c1*s1xz+c2*s2xz+c3*s3xz)` (`:326`).

## 5. 수평 eddy viscosity (HorzVisc)

Method 주석(`SwashHorzVisc.ftn90:45-48`): *"The mixing length model is employed to account for wave breaking. The Smagorinsky model is utilized to account for subgrid turbulent mixing."* `ihvisc` 가 모델 선택:

| `ihvisc` | 모델 | 식 | 인용 |
|---|---|---|---|
| 2 | Smagorinsky | $\nu_h = C_s^2\,\Delta x\,\Delta y\sqrt{|S|^2}$ | `:226` |
| 3 | 혼합길이(고정 $l_{mix}$) | $\nu_h = l_{mix}^2\sqrt{|S|^2}$ | `:230` |
| 4 | 수심기반 breaking | $\nu_h = \tfrac1{16}\,p_{surf,3}\,(\sum h_s)^2\sqrt{|S|^2}$ (breaking cell 만) | `:234-236` |

전단 크기 제곱: `xshear = 2*( (du/dx) )² + 2*( (dv/dy) )² + ( dv/dx + du/dy )²` (`:220-222`). `csmag`(Smagorinsky 계수)·`lmix` 는 모듈 입력 변수(여기선 parameter 아님). 1DH 전용 분기(`ihvisc==3,4`)는 $l_{mix}^2|du/dx|/dx$ 또는 breaking 시 $p_{surf,3}h_s^2|du/dx|/dx$ (`:131-147`).

**안정성 클리핑**: `stabmx = 1/(2*dt*(1/dx²+1/dy²))`, 초과 시 `vnu2d=stabmx` 후 불안정점 카운트(`:246-251`); 비율 1% 초과면 warning(`:330-337`). 1DH 는 `stabmx=0.5*dx²/dt` (`:120`).

**삼각망**(`SwashUHorzVisc.ftn90`): 동일 3모델 — Smagorinsky `vnu2d=csmag²*lf*sqrt(shrm)/rdx` (`:270`), 혼합길이 `lmix²*sqrt(shrm)` (`:307`), breaking `psurf(3)*h²*sqrt(shrm)` (`:346`); 고정값 `hvisc` 옵션 (`:233`). 면 기반 안정성 `stabmx=(면적가중)/(3*rdx*lf*dt)` (`:235,272,309,354`). 정점에서 속도구배 계산 후 면으로 보간(`:127-159` 정점 루프).

## 6. log-law 벽함수 (LogLaw)

Method 주석(`SwashLogLaw.ftn90:42-96`)에 전체 알고리즘이 명시. closure 상수(`:111-115`):

| 상수 | 값 | 의미 | 인용 |
|---|---|---|---|
| $C_\mu$ | 0.09 | k-ε 상수 | `:111` |
| $E_{rough}$ | 33.0 | 거친 벽 log-law 상수 | `:112` |
| $E_{smooth}$ | 9.0 | 매끈한 벽 log-law 상수 | `:113` |
| $e_v$ | 11.6 | 점성 부층 경계 ($\ln(E\,e_v)/\kappa = e_v$ 해) | `:114` |
| $h_{min}$ | 0.05 m | 최소 수심(이하면 점성 부층 가정) | `:115` |

마찰속도·무차원거리:
$$u_* = C_\mu^{1/4}\sqrt{k},\quad z^+ = \frac{u_* z_s}{\nu},\quad R = \frac{u_* h_r}{\nu}$$
(`:186-189`). $R > e_v$ 이면 거친 벽(`hr=fricf/pbot`), 아니면 매끈($hr=0$) (`:191-195`). $z_0 = h_r/E_{rough}$ (`:197`).
- **거친 벽**: $z_s \le z_0$ 면 $z_s \mathrel{+}= z_0$ (바닥 시프트), $u^+ = \ln(z_s/z_0)/\kappa$ (`:201-205`).
- **매끈한 벽**: $z^+ > e_v$ 면 log 층 $u^+ = \ln(E_{smooth}z^+)/\kappa$, 아니면 점성층 $u^+ = z^+$ (`:207-211`).

출력: `logfrc(nm,1) = u_*/u^+` (마찰계수), `logfrc(nm,2) = u^+` (`:221-222`). $h_s \le h_{min}$ 이면 $u_*=1$ dummy + 점성층 처리(`:213-218`).

**부유사 성층 보정** (`lsed>0 .and. psed(13)>0`): Adams & Weatherly(1981) — 안정 성층 BBL 에서 Karman 상수 실효 감소. gradient Richardson 수 `richn = -grav*drhodz/(shear*rhow)`, 안정계수 `fac = psed(13)*max(0,min(0.2,richn))`, `logfrc(1)/=（1+fac)`, `logfrc(2)*=(1+fac)` (`:300-312`).

**닫힌 경계 벽전단** (`iturb>1`, 매끈한 벽 가정): 4 측벽(`logwlb/logwlt/logwll/logwlr`)에서 `yplus = 0.5*guu*ustar/kinvis`, `uplus = ln(esmoot*yplus)/vonkar`, `logwl* = ustar/uplus` (`:584-703`). 삼각망 ULogLaw 도 동일 상수·식(`SwashULogLaw.ftn90:108-110,169,180-192`).

## 7. anti-creep — sigma 격자 인공확산 보정 (AntiCreep)

Method 주석(`SwashAntiCreep1DH.ftn90:44-55`): *"In case of steep bottom slopes and strong stable stratification, the horizontal diffusion term must be transformed, generating some curvature terms. When these so-called anti-creep terms are neglected, this may lead to artificial mixing of constituent in vertical direction."* 출처: WAQUA/TRIWAQ 기술문서 SIMONA report 99-01 (Zijlema), pg.31-33(유도)·90(이산화).

유효 수평 확산계수: 사용자 `hdiff>0` 이면 그대로, 아니면 `ihvisc∈{2,3}` 시 `dif2d = 0.5*(vnu2d(nm)+vnu2d(nmu))/psm` (Smagorinsky/혼합길이 점성을 Prandtl-Schmidt 로 나눔), 그 외 0 (`:143-159`). 클리핑 `stabmx=0.5*dx²/dt` (`:119,163`).

세 곡률항(코드의 Eq 번호 인용):
- **flux 부(Eq. 4.83)**: $d(D\,h_k\,\frac{dz_k}{dx}\frac{dc_{k-1/2}}{dz})/dx$ — cell-face 에서 flux 누적 후 `rhsc -= rdx*(flux(nm)-flux(nmd))` (`:124-212`).
- **2부(Eq. 4.85, 명시적)**: `ctrm3 = dif2d*ctrm1*ctrm2`, $\text{ctrm1}=\frac12\frac{dz_k}{dx}$, $\text{ctrm2}=\frac12\frac{dc}{dx}$ → rhsc 두 층에 ±부호로 (`:267-288`).
- **3부(Eq. 4.88, 음해적)**: `ctrm4 = 2*dif2d*ctrm1²/(hkso(k)+hkso(k+1))` → 대각·off-diagonal 에 분배 (`:281-295`).
계면 농도 보간 `wrk` (Eq. 4.87, `:217-225`). 2DH(`SwashAntiCreep2DH.ftn90`)는 x·y 양방향에 동일 Eq.4.82-88 구조(`:128,217,344,359,439`).

## 8. z-plane 수평확산 (HDiffZplane)

`SwashHDiffZplane1DH` 는 anti-creep 의 대안 — **엄밀 수평면(strictly horizontal plane)** 을 따라 명시적 확산. Method 주석(`SwashHDiffZplane1DH.ftn90:44-51`): *"Horizontal diffusion is computed explicitly along strictly horizontal planes using the MUSCL limiter to avoid artificial vertical upwelling"*, 출처 Stelling & van Kester (IJMF 18, 915-935, 1994).

알고리즘: 두 인접 wl-점의 층계면 z 좌표를 병합(merge, `:172-196`)→ flux 점 위치(`:198-202`)→ 각 flux 좌우 농도점 k-index 결정(`:204-225`)→ 선형보간 `cl/cr`(`:236-272`)→ **MUSCL 제한자**:
```
grad = min( grmin, 0.25*grsum )   ! grad1>=0
grad = max( grmax, 0.25*grsum )   ! grad1<0
grad = 2*grad
```
