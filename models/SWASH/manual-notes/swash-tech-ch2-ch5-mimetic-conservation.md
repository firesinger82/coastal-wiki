# swashtech Ch2·Ch5 — Hamiltonian·mimetic 이산화·보존 증명

> 제2장의 증명은 비점성·정수압 반이산 계를 대상으로 한다 (swashtech PDF p.59, 인쇄 51). [10-15 대조 정정]
> mimetic 실행 옵션은 기본 비활성이다 (`src/SwashInit.ftn90:401`). [10-15 대조 정정]
> `MIME`는 `mimetic = .true.`를 설정한다 (`src/SwashReadInput.ftn90:2010–2011`). [10-15 대조 정정]
> `SwashCheckPrep`는 반암시적 시간적분을 선택·검사한다 (`src/SwashCheckPrep.ftn90:610,712`). [10-15 대조 정정]
> `SwashComputFlow`는 mimetic 선택에서 M 루틴을 호출한다 (`src/SwashComputFlow.ftn90:93–96`). [10-15 대조 정정]
> mimetic 경로도 시간 분할 때문에 시간에서 에너지를 정확히 보존하지 않는다 (`src/SwashImpDepM1DHflow.ftn90:44–47`). [10-15 대조 정정]
> 제5장은 산술 운반 속도와 산술 질량 플럭스 수심을 사용한 반이산식의 보존 성질을 증명한다 (swashtech PDF p.77–78,90–91, 인쇄 69–70,82–83). [10-15 대조 정정]
> 기본 비구조 코드는 상류 이류와 별도 면 수심에 고차 보정을 사용한다 (swashuse PDF p.95–96, 인쇄 87–88; `src/SwashExpDepUflow.ftn90:280–288`; `src/SwashUpdateUDepths.ftn90:202–243,324`). [10-15 대조 정정]

## 1. 지배방정식과 Hamiltonian 구조 (§2.2-2.3, swashtech PDF p.19-25 (인쇄 11-17)) [10-15 대조 정정]

- **비점성·정수압 SWE(플럭스형)**: `\partial h/\partial t+\nabla\cdot\mathbf q=0` (Eq. 2.1)·`\partial h\mathbf u/\partial t+\nabla\cdot(\mathbf q\otimes\mathbf u)=-gh\nabla\zeta` (Eq. 2.2), `h=\zeta+d`·`\mathbf q=h\mathbf u` (swashtech PDF p.19 (인쇄 11); 비정수압 항 `\int\nabla p\,dz` 는 Ch3 Eq. 3.2, swashtech PDF p.63 (인쇄 55) 에서 등장 — Ch2 는 정수압 뼈대). [10-15 대조 정정]
- **Hamiltonian**: `H(h,m_x,m_y)=\tfrac12\int_\Omega[(m_x^2+m_y^2)/h+g\zeta^2]\,dxdy` (swashtech PDF p.22 (인쇄 14), `\mathbf m=h\mathbf u`) — 심플렉틱형 `\partial p/\partial t=J\,\delta H/\delta p` (Eq. 2.11, swashtech PDF p.22 (인쇄 14)), Poisson 텐서 `J` 는 Lie-Poisson 형·상태 선형·skew-adjoint·Jacobi 조건 만족 (Eq. 2.12, swashtech PDF p.23 (인쇄 15)). 전개하면 (2.1)-(2.2) 정확 재생 (swashtech PDF p.23 (인쇄 15)). [10-15 대조 정정]
- **에너지 보존 = J 의 반대칭성**: `dH/dt=\langle\delta H/\delta p,J\,\delta H/\delta p\rangle=0` (swashtech PDF p.23-24 (인쇄 15-16); Noether 정리의 발현으로 서술). [10-15 대조 정정]
- **항등식 Eq. 2.8**: `\langle f,\nabla\cdot\mathbf v\rangle=-\langle\nabla f,\mathbf v\rangle` (swashtech PDF p.21, 인쇄 13). [10-15 대조 정정]
  발생행렬의 음전치 관계를 명시한다: `\tilde{\mathbb D}^{n-1}=-(\mathbb D^0)^{\mathsf T}` (swashtech PDF p.41, 인쇄 33). [10-15 대조 정정]
  점 유속·수위 차분에서는 길이·면적 가중 내적의 수반 관계를 사용한다 (`src/SwashExpDep2DHflow.ftn90:4418`). [10-15 대조 정정]
  경계항이 0이라는 문서 조건을 제거하지 않는다 ([theory-framework:ST1-055](../../../_staging/recovery/compare/swash-theory-framework-vs-code.md)). [10-15 대조 정정]
- **이류 연산자 조건 (swashtech PDF p.25 (인쇄 17))**: `A\mathbf u:=\nabla\cdot(\mathbf q\otimes\mathbf u)` 에 대해 `A+\tfrac12(\partial h/\partial t)I` 가 반대칭이어야 에너지 보존 — `A=\tfrac12C-\tfrac12C^\mathsf T+\tfrac12(\nabla\cdot\mathbf q)I` (`C` 반대칭, Eq. 2.13-2.14). 압력구배·이류가 **각각 개별로** 에너지 보존해야 하고, 도수(hydraulic jump)·조석 bore 는 **의도적 소산 추가**가 필요함을 명시 (swashtech PDF p.25 (인쇄 17)). [10-15 대조 정정]

## 2. Mimetic 이산화의 의미 (§2.1·2.4-2.5, swashtech PDF p.13-52 (인쇄 5-44)) [10-15 대조 정정]

- **정의**: 이산 grad/curl/div 를 (계량 없는) **incidence 행렬**로 구성해 벡터해석 항등식 curl grad `=0`·div curl `=0` 과 대칭관계 div `=-`gradᵀ·이산 부분적분·곱규칙을 **정확히** 재현 (swashtech PDF p.14-15·17-18 (인쇄 6-7·9-10)). 미분형식·일반화 Stokes 정리(§2.4)·대수적 위상(§2.5: cell complex·chain/boundary·cochain/coboundary·Hodge star·de Rham 복합체)이 그 기반. [10-15 대조 정정]
- **분리 원리 (swashtech PDF p.18 (인쇄 10))**: PDE 의 위상적 부분(보존 법칙)은 **이산화 오차 없이 정확히**, 계량/구성 관계(Hodge star 행렬)만 근사 — 오차의 소재를 구조적으로 한정. [10-15 대조 정정]
- **Arakawa C-grid 는 귀결**: primal(외향)·dual(내향) 격자 구조에서 staggering 이 자연히 나옴 — Arakawa & Lamb 스킴을 자유수면 흐름 최초기 mimetic 이산화로 자리매김 (swashtech PDF p.17,53–54, 인쇄 9,45–46). [10-15 대조 정정] [10-15 전수 검증 보완]

## 3. 직교격자 반이산계와 전역 에너지 보존 (§2.6.2, swashtech PDF p.54-61 (인쇄 46-53)) [10-15 대조 정정] [10-15 전수 검증 정정]

- 연속: `d\nu^{(n)}/dt+\mathbb D^{n-1}\phi^{(n-1)}=0` (Eq. 2.22, swashtech PDF p.55 (인쇄 47)) — incidence 행렬 발산이라 **셀별 질량 정확 보존**. [10-15 대조 정정] [10-15 전수 검증 정정]
- 압력구배: `\nabla\tfrac12gh^2=gh\nabla\zeta+gh\nabla d`를 **산술평균 수심** `\bar h_{\tilde e}=\tfrac12(h_l+h_r)`로 정확 이산화한다 (swashtech PDF p.56, 인쇄 48). [10-15 대조 정정]
  이산 기울기는 `\tilde{\mathbb D}^0=-(\mathbb D^{n-1})^\mathsf T`이다 (swashtech PDF p.56, 인쇄 48). [10-15 대조 정정]
  스칼라 수위 기울기의 curl-free 성질과 수심을 곱한 힘 전체를 구별한다 (swashtech PDF p.56, 인쇄 48). [10-15 대조 정정]
- 흐름·구성·최종계: Eq. 2.23 (swashtech PDF p.57 (인쇄 49))·Eq. 2.24 (swashtech PDF p.58 (인쇄 50), "이산 에너지 보존 달성의 본질 단계")·Eq. 2.25 (swashtech PDF p.59 (인쇄 51))·Eq. 2.26-2.27 (swashtech PDF p.59 (인쇄 51) — C-grid 의 발현, Ch3 직선·Ch4 곡선·Ch5 삼각 격자의 공통 기반). [10-15 대조 정정]
- **전역 에너지 보존 증명**은 swashtech PDF p.59–61(인쇄 51–53)에 있다. [10-15 대조 정정]
  증명은 이산 대류 연산자의 반대칭성을 요구한다 (swashtech PDF p.61, 인쇄 53). [10-15 대조 정정]
  증명은 발생행렬의 음전치 관계를 사용한다 (swashtech PDF p.61, 인쇄 53). [10-15 대조 정정]
  면 질량플럭스는 면직교속도와 산술평균 수심의 곱이다 (Eq. 2.24; swashtech PDF p.58,61, 인쇄 50,53). [10-15 대조 정정]
  p.59의 운동에너지 둘째 인자는 수심을 곱한 `\phi^{(n-1)}`이다 (swashtech PDF p.59, 인쇄 51). [10-15 대조 정정]
  p.60의 정의에는 그 수심 인자가 없다 (swashtech PDF p.60, 인쇄 52; theory-framework:ST1-244). [10-15 대조 정정]
  식 (2.28)의 수심 가중치는 총에너지 가중치와 같아야 한다 (swashtech PDF p.60, 인쇄 52; theory-framework:ST1-245). [10-15 대조 정정]
  C 연산자의 혼합 내적은 [theory-framework의 ST1-249](../../../_staging/recovery/compare/swash-theory-framework-vs-code.md)의 수학 표기 규약을 따른다. [10-15 대조 정정]

## 4. 삼각격자 보존 증명 (Ch5 §5.7, swashtech PDF p.83-91 (인쇄 75-83)) — 로컬까지 확장 [10-15 대조 정정]

대상 스킴: 셀 기반 연속 Eq. 5.28·질량플럭스 Eq. 5.29-5.30(`\bar h_f=\tfrac12(h_l+h_r)`)·엣지 기반 운동량 Eq. 5.31-5.32 (swashtech PDF p.80-81 (인쇄 72-73); 직교 삼각격자 형식적 1차·균일격자 2차, 실측 supraconvergence §5.6.2). [10-15 대조 정정]

- **질량 (§5.7.1, p.75-76)**: 로컬 = (5.28) 이 플럭스형이라 자동 — **어떤 질량플럭스 이산화에도 성립**. 전역 = 내부면 쌍소거, 경계 플럭스만 잔존.
  §5.7.1의 인쇄 p.75–76은 swashtech PDF p.83–84에 대응한다 ([theory-framework:ST1-311](../../../_staging/recovery/compare/swash-theory-framework-vs-code.md)). [10-15 대조 정정]
- **운동량 (§5.7.2, swashtech PDF p.84–86, 인쇄 76–78)**: staggered 격자엔 이산 운동량 벡터 방정식이 없어 **Perot [76] 재구성**으로 구성 — Eq. 5.33-5.35 + 기하 항등식(Eq. 5.26-5.27)으로 셀 운동량 방정식 유도 (swashtech PDF p.85, 인쇄 77). **로컬 보존**: 이류+압력 플럭스가 인접 셀 간 유일 → "불연속 존재 시 약해로의 수렴 보장" (swashtech PDF p.85, 인쇄 77). [10-15 대조 정정]
  문서의 운동량 보존 증명은 식 (5.23)의 단일 면 운동량 플럭스를 전제로 한다 (swashtech PDF p.78,85–86, 인쇄 70,77–78). [10-15 대조 정정]
  실제 비구조 코드는 유입 상류 속도차와 고차 보정을 사용한다 (`src/SwashExpDepUflow.ftn90:230,280–296,370,482–485`). [10-15 대조 정정]
  swashuse PDF p.96(인쇄 88)은 상류 기법의 국소 운동량 플럭스 보존 목적을 설명한다. [10-15 대조 정정]
  이 목적과 제5장의 증명 조건을 구분한다 ([theory-unstructured:ST2-048](../../../_staging/recovery/compare/swash-theory-unstructured-vs-code.md)). [10-15 대조 정정]
  문서의 전역 운동량 수지 증명은 평탄한 바닥(`\nabla d=0`)과 외력 부재를 전제로 한다 (swashtech PDF p.86, 인쇄 78; theory-unstructured:ST2-081). 이 조건에서 총운동량은 경계 운동량 플럭스로 변한다 (같은 쪽; ST2-084). 바닥 경사·바람·바닥 마찰·코리올리 힘은 §5.8.2에서 다룬다 (같은 쪽). [10-15 전수 검증 정정]
  격자 직교성 불요 (swashtech PDF p.86, 인쇄 78). [10-15 대조 정정]
- **에너지 (§5.7.3, swashtech PDF p.87–91, 인쇄 79–83)**: §2.6.2가 전역만 증명한 것과 달리 **로컬+전역** (swashtech PDF p.87, 인쇄 79). 연속 대상 Eq. 5.36(에너지수두 `h_e=\zeta+\mathbf u\cdot\mathbf u/2g`)의 이산 대응은 **Eq. 5.41**이다 (swashtech PDF p.90, 인쇄 82). [10-15 대조 정정]
  운동부는 `\bar{\mathbf u}_f`를 **단순평균** `\tfrac12(\mathbf u_c+\mathbf u_{nc})`로 두면 이류 연산자가 반대칭이다 (swashtech PDF p.89, 인쇄 81). [10-15 대조 정정]
  위치부는 **이산 곱규칙 Eq. 5.40**을 사용한다 (swashtech PDF p.89, 인쇄 81). [10-15 대조 정정]
  문서의 전역 에너지 합에는 경계 플럭스가 남는다 (swashtech PDF p.90, 인쇄 82). [10-15 대조 정정]
  총에너지 비증가에는 순에너지 유입이 없다는 조건이 필요하다 (swashtech PDF p.90, 인쇄 82; `src/SwashExpDepUflow.ftn90:1731`). [10-15 대조 정정]
- **문서의 에너지 보존형 이산화 조건 (swashtech PDF p.90–91, 인쇄 82–83)**: ①Perot 셀속도 재구성(Eq. 5.24 — 비본질, 이류 이산화의 귀결) ②`\bar{\mathbf u}_f` 단순평균(임의 격자) ③질량플럭스 = 산술평균 수심 × 면직교속도(Eq. 5.29-5.30) ④이산 곱규칙(Eq. 5.40) = 압력구배와 질량플럭스 발산이 서로의 음전치. [10-15 대조 정정]
  산술 운반 속도와 산술 질량 플럭스 수심은 문서의 에너지 보존형 이산화 조건이다 (swashtech PDF p.91, 인쇄 83). [10-15 대조 정정]
  기본 비구조 구현은 상류 속도와 상류 수위에 고차 보정을 사용한다 (swashuse PDF p.95–96, 인쇄 87–88; `src/SwashExpDepUflow.ftn90:280–288,482–485`; `src/SwashUpdateUDepths.ftn90:202–243,324`). [10-15 대조 정정]
  수심의 저속 분기와 중앙 기법 선택은 [theory-unstructured의 ST2-033](../../../_staging/recovery/compare/swash-theory-unstructured-vs-code.md)과 같다. [10-15 대조 정정]
