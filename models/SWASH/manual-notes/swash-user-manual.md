## 3. 모델 개요·범위 (Ch 2)

- **정체** (§2.2.1, p.3): "general-purpose numerical tool for simulating non-hydrostatic, free-surface, rotational flows and transport phenomena in one, two or three dimensions." 지배방정식 = **비선형 천수방정식 + 비정수압 + transport 식**. 약어 SWASH = **S**imulating **WA**ves till **SH**ore (p.4).
- **수치 핵심** (§2.2.2, p.4-5): explicit 2차 staggered 유한차분, 이산레벨 mass·momentum 엄밀 보존 → 쇄파 위치 추적·bore 재현. 압력을 hydrostatic + non-hydrostatic 으로 분리(projection method), 시간적분은 2차 leapfrog 또는 θ-method semi-implicit. semi-implicit 은 leapfrog 대비 시간스텝 5~10배(p.5).
- **Boussinesq 모델과 차이** (§2.2.4, p.8): SWASH 는 Boussinesq 가 아님. 도함수 차수 증가 대신 **연직 layer 수 증가**로 dispersion 개선. 공간 도함수 최대 2차, 시·공간 모두 최대 2차 정확. 설명서의 부정은 단파 불안정 제거 목적에 한정된다. 현재 코드는 비정형·baroclinic 조건의 checkerboard 모드를 배경 점성으로 완화한다. evanescent 파형 성분 필터도 조건부로 사용한다. (swashuse PDF p.17; `src/SwashCheckPrep.ftn90:909–913`; `src/SwashBCshortwave.ftn90:136–146`; [inputs-setup:SI1-042 수정안](../../../_staging/recovery/compare/swash-inputs-setup-vs-code.md#4-노트-대조와-수정안)) [10-15 대조 정정] [10-15 전수 검증 보완]
- **순환모델과 관계** (§2.2.5, p.9): WAQUA·Delft3D-FLOW·ADCIRC·ROMS·FVCOM·UNTRIM·SLIM·SUNTANS 와 유사하나 비정수압. v7.01 이후 unstructured 삼각망 지원.
- **물리현상** (§2.2.3, p.7-8): wave shoaling/refraction/diffraction, depth-limited wind growth, 비선형 wave-wave(surf beat·triad), breaking, runup/rundown, moving shoreline, bottom friction, partial reflection/transmission, 구조물·이동강체 상호작용, wave-current·wave-induced current, 연직 난류 혼합, subgrid 난류, 난류 비등방, vegetation damping, 급변류, tidal/bore/flood wave, 풍성류, 밀도류, 부유사 수송, turbidity flow, tracer 수송.
- **한계·내부 시나리오** (§2.3, p.9-10): SWASH 는 종료 대신 robust 한 내부 시나리오 invoke — (a) 수위가 bottom 아래면 drying/flooding 최소수심 조정, (b) Courant 기반 동적 시간스텝(PRINT 파일 기록), (c) 수평 eddy viscosity 명시적 처리 안정성 위해 매 스텝 최대 eddy viscosity 제한(불안정점 비율이 1% 이상이면 PRINT 경고). 근본적 한계(난류 모델링)·미발견 coding bug 존재 가능. (`src/SwashHorzVisc.ftn90:334`) [10-15 대조 정정]
- **단위/좌표** (§2.4, p.10-11): 모든 입력 S.I. (m, kg, s, N, Pa). 방향·구면좌표는 도(°). Cartesian 또는 spherical.

- 설명서 기본 maxmes는 200이다. 코드도 200을 초기화한다. 현재 코드에서 메시지 수로 계산을 중단하는 처리는 없다. (`src/SwashInit.ftn90:474`; `src/SwashReadInput.ftn90:530`) [10-15 대조 정정]
- 설명서 기본 중력가속도는 9.81 m/s²이다. 코드 초기값은 9.813 m/s²이다. SET GRAV를 생략하면 코드 초기값을 유지한다. 9.813을 소수 둘째 자리로 반올림하면 9.81이다. (`src/SwashInit.ftn90:135`; `src/SwashReadInput.ftn90:533`) [10-15 대조 정정]
- RHOWAT 생략값은 조건부이다. 밀도 수송 외력이 없으면 SET의 수온·염분 값으로 Eckart 실제 밀도를 계산한다. 밀도 수송 외력이 있으면 참조 밀도 1000 kg/m³를 사용한다. 이미 지정한 `RHOWAT`에는 이 두 대입을 적용하지 않는다. (`src/SwashReadInput.ftn90:535–536`; `src/SwashCheckPrep.ftn90:889–905`) [10-15 대조 정정] [10-15 전수 검증 정정]
- DYNVIS는 역학 점성계수이다. 단위는 kg/(m·s)이다. 코드는 이를 밀도로 나누어 동점성계수 kinvis를 구한다. (`src/SwashCheckPrep.ftn90:918`) [10-15 대조 정정]
- BACKVISC 미지정 시 일반 조건의 배경 점성은 0 m²/s이다. 비정형·baroclinic 조건은 5×10⁻⁵ m²/s이다. `SET BACKVISC 0`을 명시하면 이 자동값을 쓰지 않는다. (`src/SwashCheckPrep.ftn90:909–913`) [10-15 대조 정정] [10-15 전수 검증 정정]

### MODE (§4.4, p.27)
`MODE NONSTationary < TWODimensional | ONEDimensional >`. 문서는 NONSTATIONARY를 필수로 적는다. 파서는 그 키워드 없이도 기본 비정상 모드를 유지한다. STA는 정상 모드를 선택한다. DYN은 NONST와 같은 비정상 모드를 선택한다. DYNAMIC·SKIPMOM·LINEAR는 설명서 부록 C에도 있다. (swashuse PDF p.35·155; `src/SwashReadInput.ftn90:397–432`) [10-15 대조 정정] [10-15 전수 검증 정정]

### COORDINATES (§4.4, p.27-28)
`CARTesian`(기본) / `SPHErical < CCM | QC >`. 구면시 regular grid 는 항상 E-W·N-S 정렬 필수(alpc=alpinp=alpfr=0), unstructured 미지원 (p.28). CCM·QC는 mproj 선택값만 바꾼다. 현재 코드에서 서로 다른 두 투영법의 계산 효과는 구현하지 않는다. 구면 metric은 kspher·위도에 따른다. (swashuse PDF p.36; `src/SwashReadInput.ftn90:608–614`; `src/SwashGeometrics.ftn90:105`) [10-15 대조 정정]

## 6. 계산격자 (§4.5.1)

### CGRID (필수, §4.5.1, p.28-30)
`CGRID < REGular [xpc][ypc][alpc][xlenc][ylenc][mxc][myc] | CURVilinear [mxc][myc] (EXCeption [xexc][yexc]) | UNSTRUCtured > (REPeating < X | Y >)`
- 문서 순서는 EXCEPTION 뒤 REPEATING이다. 현 파서의 입력 순서는 REPEATING 뒤 EXCEPTION이다. 두 옵션을 함께 쓰는 경우 코드 결함 후보로 표시한다. 판정은 E 유지(중간)이다. (swashuse PDF p.36; `src/SwashReadInput.ftn90:2236–2268`) [10-15 대조 정정]
- `[mxc],[myc]` = **mesh 수 = 격자점 수 − 1**. 1D-mode 는 `[myc]=0`, `[ylenc]=0`.
- 기본값: `[xpc]=[ypc]=0.0`(Cartesian; 구면은 필수입력), `[alpc]=0.0`.
- CURVILINEAR 은 READGRID COOR, UNSTRUCTURED 는 READGRID UNSTRUC 로 좌표 제공(p.30-31).
- REPEATING: 한 방향 주기경계(한 끝 유출=반대 끝 유입), 기본 X. 1D·unstructured 불가.
- 유효 각도는 0° 초과·180° 미만이다. 45–135°는 권고이다. 일직선 점의 `DET=0` 오류와 90° 삼각형 품질 경고를 구분한다. (swashuse PDF p.39; `8756667:src/swanser.ftn:486`) [10-15 대조 정정]

### VERTICAL (선택, §4.5.1, p.32-33) — multi-layered mode
`VERTical [kmax] < [thickness] < M | -> PERC > >`
- layer 번호 = top(1) → bottom([kmax]). `[thickness]` 단위: M(고정 m) / **PERC(가변 %, 기본)**.
- 미지정 시 등간격 분포. PERC 합 = 100, **최소 1개 가변 layer 필수**. 모두 가변이면 sigma plane 과 동일.
- 단파 모의는 **가변 두께·등간격 권장**. 문서는 비정형 고정 두께층을 미지원이라고 적는다. 현재 비정형 코드에는 공통 고정 두께층 변환 경로가 있다. SUBGRID의 고정층 금지는 별도 제약이다. (swashuse PDF p.40; `src/SwashLayUIntfaces.ftn90:108`; `src/SwashServices.ftn90:545–571`) [10-15 대조 정정]

CONSTANT의 wlev·vx·vy 기본은 0이다. tke·epsilon 최초값은 10⁻⁷이다. STEADY에는 초기 수위장이 필요하다. 초기 속도장이 있으면 STEADY를 끈다. 초기 Chezy 속도는 Froude 0.9999로 제한한다. (`src/SwashInitCond.ftn90:479–483`; `src/SwashInit.ftn90:215–216`; `src/SwashCheckPrep.ftn90:405–415`; `src/SwashInitSteady.ftn90:157–159`) [10-15 대조 정정]

## 8. 경계조건 (§4.5.3)

### BOUND SHAPESPEC (§4.5.3, p.47-48) — 스펙트럼 형상
`BOUnd SHAPespec < PM | -> JONswap [gamma] | TMA > < -> SIG | RMS > < -> PEAK | MEAN > DSPR < -> POWer | DEGRees >`
- 기본: **JONSWAP [gamma]=3.3**, 특성파고 SIG, 특성주기 PEAK, 방향폭 POWER (cosᵐθ 분포). TMA = 유한수심 보정 JONSWAP.
기본 PEAK 상태에서 주파수 모양 키워드를 생략한 `BOU SHAP MEAN`을 두 번 읽으면 PEAK 상태로 돌아간다. 같은 조건에서 MEAN 뒤의 `BOU SHAP PEAK`은 부호를 양수로 되돌리지 않는다. 매번 JON·PM·TMA를 명시하면 앞 분기가 양수로 재설정하므로 이 문제를 피한다. 현 파서의 MEAN 부호 반전·PEAK 무보정은 결함 후보이다. 판정은 E 유지(강함)이다. (swashuse PDF p.56; `src/SwashBounCond.ftn90:272–296`; `src/SwashBCspectrum.ftn90:132–137`) [10-15 대조 정정] [10-15 전수 검증 정정]

### BOUNDCOND (§4.5.3, p.48-58)
- 경계 미지정 시 = closed(법선속도 0) (p.50). SOURCE(내부 wave 생성)와 병용 불가.
- 위치: `SIDE < N|NW|W|SW|S|SE|E|NE >`(structured 직선변) 또는 `SEGMENT < XY [x][y] | IJ [i][j] >`(곡선·부분변). SEGMENT XY는 위치 수치를 받는다. 이름을 붙일 때는 XP·YP를 사용한다. (`src/SwashBounCond.ftn90:398`) [10-15 대조 정정]
- **BTYPE (경계조건 종류)**:
  - `WLEV` 수위 / `VEL` 법선속도 / `DISCH` 단위폭 유량
  - `RIEMANN` Riemann 불변량 $u \pm 2\sqrt{gh}$ (초임계류·hydraulic jump용)
  - `LRIEMANN` 선형화 Riemann $u \pm \zeta\sqrt{g/d}$ (ζ≪d 인 아임계 심해; 대륙붕·항만 조류)
  - `WEAKREFL` 약반사 경계
  - `SOMMERFELD` 방사조건(천해 near-linear 장파)
  - `OUTFLOW` 수심을 bottom 에 정렬(초임계 S2 배수곡선, structured 한정)
  - `LAYER [k]` / `LOGARITHMIC` 연직 분포 지정

### BREAKING (§4.5.4, p.79-80) — depth-limited 쇄파 제어

(swashuse PDF p.88; `src/SwashReadInput.ftn90:917`; `src/SwashCheckPrep.ftn90:1076–1106`) [10-15 대조 정정]

## 10. 수치 command (§4.5.5) — reference + 기본값

### NONHYDROSTATIC (§4.5.5, swashuse PDF p.89–93, 인쇄 81–85) — 비정수압 압력 [10-15 대조 정정]
미사용시 정수압 가정. (소스 대응: [swash-nonhydrostatic-pressure-solver](../source-analysis/swash-nonhydrostatic-pressure-solver.md)) [10-15 대조 정정]
- **연직 압력경사 스킴**: `STAndard`(중앙차분; 연직구조 중요·밀도류·undertow·급변바닥) vs `BOX`(Keller-box; **기본**, 단파 2~3 layer, 등간격 권장).
- `[theta]` θ-method (0.5=Crank-Nicolson, 1=implicit Euler). swashuse PDF p.90은 `[0.5,1]`만 허용한다고 적는다. `if ( pnums(5) > 0. .and. pnums(5) < 0.5 .or. pnums(5) > 1. ) then`이면 -1로 되돌린다. 이후 `if ( pnums(5) < 0. ) then`에서 1로 바꾼다. 0은 이 두 검사를 통과한다. (`src/SwashCheckPrep.ftn90:1273–1285`) [10-15 대조 정정]
- `SUBGrid [pmax]`: 압력/속도 연직해상도 분리(structured 한정, 가압류 불가). SUBGRID의 pmax 생략은 초기 `kpmax=kmax`에서 RQI 오류를 낸다. 오류 뒤 kmax로 복구한다. 기존 kpmax가 다른 값이면 그 값을 유지할 수 있다. (swashuse PDF p.93; `src/SwashReadInput.ftn90:1528,1821`; `src/ocpcre.ftn:824–825`) [10-15 대조 정정]
- `REDuced [qlay]`: Poisson rank 축소(BOX 병용 필수). reduced 2-layer(qlay=1)는 ~30% CPU 절감. `[qlay]` 기본 1.
- `SOLVer [rhsaccur] [initaccur] [maxiter] [relax]`: 명시적 구조 격자 2DH 수심평균 비정수압 Poisson 식은 SIP로 푼다. 명시적 수심평균 1DH의 예외는 tridiag이다. NONHYD SOLV를 쓰고 MAXITER를 생략하면 100을 쓴다. SOLV 자체를 생략하면 초기 `pnums(25) = 500.`을 유지한다. SOLV 내부의 `RHSACCUR=0.01`·`INITACCUR=0`과 `RELAX=-1` 표지는 별도 매개변수다. (swashuse PDF p.92–93; `src/SwashExpDep2DHflow.ftn90:4090–4092`; `src/SwashExpDep1DHflow.ftn90:1265`; `src/SwashReadInput.ftn90:1540–1547`; `src/SwashInit.ftn90:458`) [10-15 대조 정정]
- relax 생략값 보정은 `pnums(27)<0`일 때만 수행한다. 구조 격자의 `kmax>1`·`ihydro≠3`·`qmax=1`에서는 0.93이다. `qmax≠1`의 STANDARD 부유체 ILU에서는 0이다. (`src/SwashCheckPrep.ftn90:1340–1358`) [10-15 대조 정정]
- `PREConditioner < ILUDS | ILUD | ILU | NONE >`: PRECOND는 ILUDS·ILUD·ILU·NONE을 읽는다. 전처리자가 미지정이면 일반 구조격자에서 ILUD이고 비정형격자·부체에서는 ILU다. NONE은 `PRECFQ=-1`로 설정한다. (swashuse PDF p.91·160; `src/SwashReadInput.ftn90:1553–1561`; `src/SwashCheckPrep.ftn90:640–647`) [10-15 대조 정정]
- `PROJection ITERative [tol] [maxiter]`: Chorin(1968) 1차 projection(가압류·부유체) 또는 Van Kan(1986) 2차 pressure correction(기본). `[tol]` 기본 0.0001, `[maxiter]` 기본 50.
ITERATIVE는 semi-implicit에서만 유지한다. 반복 표지가 꺼지면 projection 반복 상한을 1로 바꾼다. projection ITERATIVE의 상한은 별도 50이다. (`src/SwashCheckPrep.ftn90:651–656`; [inputs-physics-numerics 수정안](../../../_staging/recovery/compare/swash-inputs-physics-numerics-vs-code.md#4-노트-대조와-수정안)) [10-15 대조 정정]

### DISCRETIZATION (§4.5.5, p.85-89) — 공간 이산화
`DISCRETization < UPWind <UMOM MOMentum|HEAD <Horizontal|Vertical> | WMOM <H|V>> | CORRdep | TRANSPort <H|V> | ACURrent <Umom|Wmom> > < NONe | FIRstorder | HIGherorder [kappa] | LIMiter <SWEBy [phi]|RKAPpa [kappa]|PLKAPpa [kappa][mbound]> | FROmm | BDF|LUDs | QUIck | CUI | MINMod | SUPerbee | VANLeer | MUScl | KORen | SMArt >` [10-15 대조 정정]
- κ-formulation (−1≤κ≤1): BDF(κ=−1), QUICK(κ=½), CUI(κ=⅓, 3차정확), Fromm(κ=0), 중앙차분(κ=1).
- DISCRET 기본값은 대상별로 적는다. 일반 수평 UMOM은 BDF다. BREAK `beta=0.3`이고 수평 UMOM 스킴이 미지정이면 중앙차분이다. CORRDEP와 연직 UMOM·WMOM은 MUSCL이다. TRANSP는 Van Leer다. WMOM 스킴 기본값은 이류항 활성 자체를 뜻하지 않는다. 파서는 수송 TVD 의무를 강제하지 않는다. MIMETIC 이름은 부록 p.160에 있다. 본문에는 semi-implicit 적용 조건 설명이 없다. MIMETIC은 semi-implicit을 요구한다. (`src/SwashInit.ftn90:411–427`; `src/SwashCheckPrep.ftn90:1088–1106,712`; swashuse PDF p.160) [10-15 대조 정정]
- unstructured = Casulli-Zanolli(2005) r-ratio.

### BOTCEL (§4.5.5, p.89-90) — cell center bottom level
`BOTCel < MIN | -> MEAN | MAX | SHIFt >`. 기본 **MEAN**. 급경사·tidal flat·수직벽 overtopping 정확도 위해 MIN(tiled bottom) 등 사용. 하향양수 기준(MIN=최천 bottom). 설명서는 비정형 사용을 금지한다. 실제 비정형 코드는 MIN과 MEAN을 지원한다. MAX와 SHIFT는 비정형에서 오류이다. 부유체 준비 경로는 SHIFT를 강제한다. (swashuse PDF p.97; `src/SwashFlowUDP.ftn90:81–168`; `src/SwashCheckPrep.ftn90:1147`) [10-15 대조 정정]

### TIME INTEGRATION (§4.5.5, swashuse PDF p.98–101, 인쇄 90–93) [10-15 대조 정정]
`TIMEI METH < EXPL [cfllow][cflhig] | IMPL [thetac][thetas] SOLVer [tol][maxiter][weight] NEWTon > VERTical [thetau][thetaw][thetat]`
- **EXPLICIT**: structured 기본. 장파속도 Courant 제한. 고파·비선형·급경사 구조물은 **최대 Courant 0.5 권장**. `nstatc == 1`과 `mtimei == 1`에서 Courant 상한을 넘으면 시간간격을 반으로 줄인다. 하한 미만이면 `if ( .not. istep < 20 ) then`에서만 두 배로 늘린다. 시간간격 변경 때 istep를 0으로 되돌린다. 변경은 `timco = timco + dt`보다 앞이다. CFLLOW·CFLHIG의 입력 기본값은 각각 0.4·0.8이다. (swashuse PDF p.99–100; `src/SwashMain.ftn90:271–297`; `src/SwashReadInput.ftn90:1882–1883`) [10-15 대조 정정]
- **IMPLICIT**(semi-implicit): unstructured 기본. semi-implicit은 장파속도의 시간 간격 제약을 줄인다. explicit 수평 이류의 시간 간격 제약은 남는다.
