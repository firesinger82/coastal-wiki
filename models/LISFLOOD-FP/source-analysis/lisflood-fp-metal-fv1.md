# LISFLOOD-FP Metal FV1

이 노트는 최종 대조 기록의 결론을 옮긴 AI 정리이다.
표의 원문 인용은 결론 문장과 구분한다.
`cpu-gpu-swe` 행의 문서 원문 칸은 구현 대조의 CPU 원문을 싣는다.
해당 행의 코드 원문 칸은 CUDA·Metal 원문을 싣는다.
코드 인용의 기준은 `../raw/source_code/LISFLOOD-FP/`이다.
`v8.0:`·`v8.1:`·`v8.2:`는 해당 이전 배포본을 뜻한다.
`../LISFLOOD-FP-8.3-package/` 인용은 코드 기준 경로의 형제 패키지를 뜻한다.

## 실행 선택과 연결

Metal FV1은 v8.3 추가이다 (`VersionHistory.h:31–32`).
`cuda`와 `metal`은 같은 GPU 플래그를 켠다 (`pars.cpp:965–969`).
Apple 분기에서 `if(METAL_FRAMEWORK AND FOUNDATION_FRAMEWORK)`를 통과해야 Metal 구현을 컴파일한다 (`CMakeLists.txt:232–237`, `metal/CMakeLists.txt:3–6`).
`METAL_ENABLED`가 정의된 FV1 분기는 `if (Statesptr->cuda == ON && metal_is_available())`일 때 Metal FV1을 실행한다 (`lisflood.cpp:778–788`). [10-21 전수 검증 정정]
Metal shader 초기화 실패 뒤 CPU FV1으로 자동 전환한다고 쓰지 않는다 (`metal/fv1/metal_fv1_simulate.mm:1356–1365`; `metal/metal_integrate.cpp:7–14`; `lisflood.cpp:780–788`). [10-21 전수 검증 보완]

CPU·CUDA·Metal의 수치 형식과 첫 시간 간격은 [구현 차이 노트](lisflood-fp-cpu-gpu-differences.md)에 정리한다.
실행 분기 목록은 [아키텍처 맵](lisflood-fp-architecture-source-map.md)에 정리한다.
