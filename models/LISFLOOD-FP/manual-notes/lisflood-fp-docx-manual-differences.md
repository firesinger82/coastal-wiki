# LISFLOOD-FP user manual.docx의 차이

이 노트는 최종 대조 기록의 결론을 옮긴 AI 정리이다.
표의 원문 인용은 결론 문장과 구분한다.
Word 쪽 번호는 변환본의 쪽 번호이다.
코드 인용의 기준은 `../raw/source_code/LISFLOOD-FP/`이다.

## 판과 변경 추적

Word의 CUDA 적용 범위는 v8.0 선택 분기에 맞는다 (`v8.0:lisflood.cpp:403–418`, user manual.docx p.20(변환본)).
FV2·ACC·acc_nugrid 선택은 v8.1에 있다 (`v8.1:lisflood.cpp:418–448`).
HWFV1·MWDG2의 adaptive 선택은 v8.2부터 있다 (`v8.2:lisflood.cpp:424–447`).
Word의 FV1 기본값 10⁻⁶은 v8.0 코드에 맞는다 (`v8.0:pars.cpp:571–577`, user manual.docx p.23(변환본)).
FV1 선택 시 대입하는 10⁻³ m은 v8.1부터 확인된다 (`v8.1:pars.cpp:582–588`).

Metal FV1의 입력·출력 범위는 [Metal FV1 노트](../source-analysis/lisflood-fp-metal-fv1.md)에 정리한다.
