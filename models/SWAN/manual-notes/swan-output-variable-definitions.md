# SWAN output variable definitions (swanuse Appendix A) — verified

> swanuse Appendix A (User Manual 41.51, p.115-120 / node35) 직접 read. SWAN **BLOCK/TABLE/QUANTITY 출력 quantity 의 공식 정의**(적분식). 본 노트 = output **변수의 의미**(canonical), [swan-output-formats](../source-analysis/swan-output-formats.md) = output **파일 dispatch 메커닉**(source-code), [swan-command-numerics-output-reference](swan-command-numerics-output-reference.md) = output **command 구문**.

> 모든 적분은 표기상 $\iint = \int_0^{2\pi}\int_0^\infty$이다. $E$는 variance density spectrum이다. σ를 적분 좌표로 쓰면서 절대 주기의 ω 가중치를 유지할 수 있다. 전체 에너지의 변수 변환과 주파수 모멘트의 정의를 구분한다. 흐름이 있을 때 절대주기와 상대주기는 같지 않다. (`src/swanout1.ftn:4409` `OMEG = SPCSIG(IS) + WK(IS) * UXD`; swanuse PDF 123–124쪽 / 인쇄 115–116쪽.)

## 1. 파고 (height)

| 변수 | 정의 |
|---|---|
| **HSIGN** | Significant wave height $H_s$ (m): $H_s = 4\sqrt{\iint E(\omega,\theta)\,d\omega\,d\theta}$. 편의상 $H_s = 4\sqrt{\iint E(\sigma,\theta)\,d\sigma\,d\theta}$. (= swantech **Eq 2.11** $H_s=4\sqrt{m_0}$, [swan-tech-ch2-governing-equations](swan-tech-ch2-governing-equations.md)) |
| **HSWELL** | swell(저주파) significant height: $H_{s,\rm swell}=4\sqrt{\int_0^{\omega_{\rm swell}}\int_0^{2\pi}E\,d\omega\,d\theta}$. $f_{\rm swell}=0.1$ Hz **default**(QUANTITY 로 변경). |

문서 식은 절대주파수 절단을 표시한다. 현재 코드는 상대 주파수 경계를 사용한다. 흐름이 있으면 두 정의를 같은 것으로 쓰지 않는다. (`src/swanout1.ftn:3525` `FSWELL = PI2 * OUTPAR(5)`; `src/swanout1.ftn:3529` `IF (SPCSIG(IS).LE.FSWELL) THEN`; swanuse PDF 123쪽 / 인쇄 115쪽.)

## 2. 주기 (period) — 절대 $\omega$ vs 상대 $\sigma$ ★

전류 있으면 **절대(absolute, $\omega$) ≠ 상대(relative, $\sigma$)**; 무전류 시 동일.

| 변수 | 정의 (moment 비) |
|---|---|
| **TMM10** | $T_{m-10}=2\pi\frac{\iint \omega^{-1}E\,d\omega\,d\theta}{\iint E\,d\omega\,d\theta}$ (절대, energy period) |
| **TM01** | $T_{m01}=2\pi\left(\frac{\iint \omega E\,d\omega\,d\theta}{\iint E\,d\omega\,d\theta}\right)^{-1}$ (절대) |
| **TM02** | $T_{m02}=2\pi\left(\frac{\iint \omega^2 E\,d\omega\,d\theta}{\iint E\,d\omega\,d\theta}\right)^{-1/2}$ (절대, zero-crossing) |
| **RTMM10 / RTM01** | 위의 $\sigma$(상대) 버전. 무전류 시 = TMM10/TM01 |
| **RTP** | Relative peak period (s) of $E(\sigma)$ — **이산 스펙트럼 absolute max bin** 기준(실제 peak 와 다를 수 있음) |
| **TPS** | TPS는 최대 bin과 양쪽 한 bin씩의 세 bin으로 포물선을 맞춘다. (`src/swanout1.ftn:3801` `SIG1 = SPCSIG(ISIGM-1)`; `src/swanout1.ftn:3802` `SIG2 = SPCSIG(ISIGM+1)`; swanuse PDF 124쪽 / 인쇄 116쪽.) |
| **PER** | $T_{m,p-1,p}=2\pi\frac{\iint \omega^{p-1}E}{\iint \omega^p E}$ (절대). **QUANTITY 의 $p$**: $p=1$(default)→PER=TM01, $p=0$→PER=TMM10 |
| **RPER** | PER 의 $\sigma$ 버전. $p=1$→RTM01, $p=0$→RTMM10 |

TPS는 내부 최대 bin에서 `IF (A.LT.0) THEN`이면 꼭짓점을 쓴다. 나머지는 `SIGP = SIG3`을 쓴다. 첫 bin은 그 bin의 주기를 쓴다. 마지막 bin 또는 양의 최대값이 없는 경우는 예외값을 쓴다. (`src/swanout1.ftn:3800–3821` `IF (ISIGM.GT.1 .AND. ISIGM.LT.MSC) THEN`, `IF (A.LT.0) THEN`, `SIGP = SIG3`, `ELSE IF (ISIGM.EQ.1) THEN`; swanuse PDF 124쪽 / 인쇄 116쪽.)

코드의 TM01·TM02·TMM10은 Doppler 변환한 절대주파수를 쓴다. RTM01·RTMM10은 상대주파수를 쓴다. (`src/swanout1.ftn:4409` `OMEG = SPCSIG(IS) + WK(IS) * UXD`; swanuse PDF 123–124쪽 / 인쇄 115–116쪽.)

→ TM01/TM02/TMM10 정의는 swantech **Eq 2.12** ([swan-tech-ch2-governing-equations](swan-tech-ch2-governing-equations.md) §moments)와 동일.

## 3. 방향 (direction) — Kuik et al. 1988

| 변수 | 정의 |
|---|---|
| **DIR** | 문서 정의: Mean wave direction (°, Cartesian/Nautical): $\rm DIR=\frac{180}{\pi}\arctan\left(\frac{\int\sin\theta E\,d\sigma\,d\theta}{\int\cos\theta E\,d\sigma\,d\theta}\right)$. **wave crest 에 수직** 방향. (Kuik et al. 1988) |
| **PDIR** | Peak direction of $E(\theta)=\int E\,d\omega=\int E\,d\sigma$ (°) |
| **TDIR** | Direction of **energy transport** (°). 전류 있으면 DIR 과 다름 |

DIR은 ATAN2로 사분면을 보존한 뒤 방향 규약을 적용한다. (`src/swanout1.ftn:3903` `DIRDEG = ATAN2(EEY,EEX) * 180./PI`; swanuse PDF 124쪽 / 인쇄 116쪽.)

## 4. 스펙트럼 폭·형태 (spread / shape)

| 변수 | 정의 |
|---|---|
| **FSPR** | Normalized frequency width (frequency spreading), Battjes-Van Vledder 1984: $\rm FSPR=\frac{\lvert\int_0^\infty E(\omega)e^{i\omega\tau}d\omega\rvert}{E_{\rm tot}}$, $\tau=T_{m02}$ |
| **DSPR** | One-sided directional width (directional spreading / std, °): $\rm DSPR^2=(\frac{180}{\pi})^2\int_0^{2\pi}(2\sin\frac{\theta-\bar\theta}{2})^2 D(\theta)d\theta$. WAVEC pitch-and-roll buoy 관례(Kuik et al. 1988): $(\rm DSPR\frac{\pi}{180})^2=2(1-\sqrt{(\frac{\int\sin\theta E}{\int E})^2+(\frac{\int\cos\theta E}{\int E})^2})$ |
| **QP** | 문서 정의: Peakedness (Goda): $Q_p=2\frac{\iint \sigma E^2\,d\sigma\,d\theta}{(\iint E\,d\sigma\,d\theta)^2}$. 문서의 물리 해석은 **작을수록 wide spectrum / 더 random**(짧은 wave group), 클수록 narrow / 조직적(긴 group) |
| **MS** | BOUNDPAR/BOUNDSPEC 입력 시 방향분포 $D(\theta)=A(\cos\theta)^m$ 의 power $m$(정수 아니어도 됨). DSPR 와 **Table A.1** 대응 |

QP의 구현은 방향 적분 스펙트럼 E₁(σ)를 먼저 구한 뒤 2∫σE₁(σ)²dσ/r₀²를 계산한다. (`src/swanout1.ftn:4082` `EADD = EADD + SIG * ACLOC(ID,IS) * DDIR`; `src/swanout1.ftn:4084` `ESTOT = ESTOT + SIG**2 * EADD**2 * FRINTF`; swanuse PDF 125쪽 / 인쇄 117쪽.)

MS 분포는 코사인이 양수인 반평면에서 거듭제곱을 계산한다. 입력 m은 양수여야 한다. (`src/swanser.ftn:4217` `IF (ACOS .GT. 0.) THEN`; `src/swanpre2.ftn:3635` `IF (SPPARM(4).LE. 0.) THEN`; swanuse PDF 125쪽 / 인쇄 117쪽.)

**Table A.1** (MS ↔ DSPR°): 1→37.5 / 2→31.5 / 3→27.6 / 4→24.9 / 5→22.9 / 6→21.2 / 7→19.9 / 8→18.8 / 9→17.9 / 10→17.1 / 15→14.2 / 20→12.4 / 30→10.2 / 40→8.9 / 50→8.0 / 60→7.3 / 70→6.8 / 80→6.4 / 90→6.0 / 100→5.7 / 200→4.0 / 400→2.9 / 800→2.0.

## 5. 에너지 수지 (energy balance) — 단위 W/m² 또는 m²/s (SET 의존)

| 변수 | 정의 |
|---|---|
| **PROPAGAT** | PROPAGAT는 전파 성분별·빈별 기여의 절댓값을 더한다. `src/swancom5.ftn:5095` `ATRANSP(1) = ATRANSP(1) + ABS(ACONTR)`. |
| **GENERAT** | GENERAT·GENWIND의 누적은 원천항의 부호를 유지한다. `src/swancom5.ftn:5080` `AGENERT(II) = AGENERT(II) + ACONTR`. |
| **REDIST** | REDIST는 quadruplet·triad·Bragg·QC의 네 재분배 성분을 포함한다. 각 성분은 bin별 절댓값을 적분한다. `src/swancom5.ftn:5088` `AREDIST(II) = AREDIST(II) + ABS(ACONTR)`; `src/swancom5.ftn:5135` `REDSXY(KCGRD(1)) = REDSXY(KCGRD(1)) + SUM(AREDIST)`. |
| **DISSIP** | DISSIP은 whitecapping·surf breaking·bottom friction·swell·vegetation·turbulence·mud·ice의 여덟 소산 성분을 합한다. `src/swancom5.ftn:5126` `DISSXY(KCGRD(1)) = DISSXY(KCGRD(1)) + SUM(ADISSIP)`. |
| **RADSTR** | 문서 정의: $\int_0^{2\pi}\int_{\sigma_{\mathrm{low}}}^{\sigma_{\mathrm{high}}}\left\lvert S_{\mathrm{tot}} - \frac{\partial E}{\partial t} - \nabla_{\vec{x}}\cdot\left[(\vec{c}_g+\vec{U})E\right] - \nabla_{(\sigma,\theta)}\cdot(\vec{c}_{(\sigma,\theta)}E)\right\rvert d\sigma d\theta$ (swanuse PDF 126쪽 / 인쇄 118쪽.) |

RADSTR의 문서 정의는 원천항에서 시간 변화와 전체 전파를 뺀 잔차의 절댓값 적분이다. 코드의 누적 ABS 순서에는 별도의 결함 후보가 있다. (`src/swancom5.ftn:5112` `ARADSTR    = ABS(ARADSTR)`.)

## 6. 수송·force·radiation stress

| 변수 | 정의 |
|---|---|
| **TRANSP** | 문서 정의: Energy transport $P_x=\rho g\iint c_x E\,d\sigma\,d\theta$, $P_y=\rho g\iint c_y E\,d\sigma\,d\theta$. 벡터 성분의 기본 기준은 문제 좌표이다. QUANTITY FRAME을 지정한 경우에 프레임 좌표로 회전한다. `src/swanout1.ftn:1030` `IF (EQREAL(OUTPAR(4),1.)) THEN`. |
| **VEL / WIND** | BLOCK와 FRAME을 사용해도 기본 벡터 성분은 문제 좌표를 따른다. QUANTITY FRAME을 지정한 경우에 프레임 좌표로 회전한다. `src/swanout1.ftn:1030` `IF (EQREAL(OUTPAR(4),1.)) THEN`. |
| **FORCE** | wave-induced force(radiation stress gradient): $F_x=-\frac{\partial S_{xx}}{\partial x}-\frac{\partial S_{xy}}{\partial y}$, $F_y=-\frac{\partial S_{yx}}{\partial x}-\frac{\partial S_{yy}}{\partial y}$ |

TRANSP의 기본 단위는 m³/s다. INRHOG=1일 때 ρg를 곱한다. (`src/swanout1.ftn:4258` `IF (INRHOG.EQ.1) THEN`; `src/swanout1.ftn:4259` `SX = SX * RHO * GRAV`; swanuse PDF 36쪽 / 인쇄 28쪽, PDF 112쪽 / 인쇄 104쪽.)

**Radiation stress tensor** (= swantech **Eq 3.59-3.61**, [swan-tech-ch3-qc-curvilinear](swan-tech-ch3-qc-curvilinear.md)):
$$S_{xx}=\rho g\int(n\cos^2\theta+n-\tfrac12)E\,d\sigma\,d\theta,\quad S_{xy}=S_{yx}=\rho g\int n\sin\theta\cos\theta\,E,\quad S_{yy}=\rho g\int(n\sin^2\theta+n-\tfrac12)E$$
$n$ = group velocity / phase velocity ($n=c_g k/\omega$, Eq 3.62).

## 7. 저면·breaking·setup

| 변수 | 정의 |
|---|---|
| **URMS** | rms orbital velocity near bottom: $U_{\rm rms}=\sqrt{\int_0^{2\pi}\int_0^\infty\frac{\sigma^2}{\sinh^2 kd}E\,d\sigma\,d\theta}$ |
| **UBOT** | $U_{\rm bot}=\sqrt2\,U_{\rm rms}$ (orbital motion maxima 의 rms, m/s) |
| **TMBOT** | near-bottom period $T_b=\sqrt2\pi a_b/U_{\rm rms}$, $a_b=\sqrt{2\int\int\frac{1}{\sinh^2 kd}E\,d\sigma\,d\theta}$ (bottom excursion amplitude) |
| **STEEPNESS** | 문서 정의는 HSIG/WLEN이다. STEEPNESS는 내부 적분으로 파고와 파장을 다시 계산한다. 출력 HSIGN/WLEN의 비와 항상 같은 이산값이라고 보장하지 않는다. `src/swanout1.ftn:4364` `VOQ(IP,VOQR(IVTYPE)) = 4.* SQRT(ETOT*DDIR) / WLMEAN`. |
| **WLEN** | 문서 정의: mean wave length $\rm WLEN=2\pi\left(\frac{\iint k^p E}{\iint k^{p-1}E}\right)^{-1}$, $p=1$ default (QUANTITY) |
| **BFI** | Benjamin-Feir index (steepness-over-randomness): $\rm BFI=\sqrt{2\pi}\times STEEPNESS\times QP$. **freak wave 확률** 정량화 |
| **QB** | TG83의 쇄파 비율 정의는 swantech PDF 36쪽 / 인쇄 28쪽 식 (2.72)에 있다. 코드는 양의 에너지에서 ISURF=4이면 TG83의 WH를 1로 제한하여 저장한다. 그 외 경로는 FRABRE를 호출한다. 출력은 저장된 QB를 보간한다. `src/swancom1.ftn:6004` `WH = (2.*SQRT(2.*ETOT)/HM)**PSURF(5)`; `src/swancom1.ftn:6005` `WH = MIN(1.,WH)`. |
| **SETUP** | radiation stress gradient 에 의한 평균수위 상승(still water level 대비) |
| **LEAK** | directional sector 경계 $\theta_1$/$\theta_2$(CGRID)를 가로지르는 $c_\theta E$ 수치 에너지 손실 |

WLEN은 주파수 범위를 생략하면 2π(K₀/Kₚ)¹/ᵖ를 쓴다. 범위를 지정하면 문서와 같은 2πKₚ₋₁/Kₚ를 쓴다. p≠1에서 평균의 정의가 달라지는 강한 정적 결함 후보이다. (`src/swanout1.ftn:4302` `WLMEAN = PI2 * (ETOT / EKTOT) ** (1./OUTPAR(3))`; `src/swanout1.ftn:4319` `WLMEAN = PI2 * ETOT / EKTOT`; swanuse PDF 127쪽 / 인쇄 119쪽.)

## 9. 방향 convention (Appendix A 말미 verbatim) ★

- **Cartesian**: 벡터와 +$x$축 사이 각, **반시계**. = 파/바람이 **향하는(going to)** 방향.
- **Nautical**: 지리적 북(N)에서 **시계**. = 파/바람이 **오는(coming from)** 방향.

→ [swan-usage-general](swan-usage-general.md) §2.5 units/convention 와 동일(SET NAUTICAL/CARTESIAN). 계산격자 방향은 항상 Cartesian.
