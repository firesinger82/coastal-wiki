# Roelvink et al. (2020) — 모델 기술 논문 발췌

> Roelvink, Huisman, Elghandour, Ghonim, Reyns (2020) "Efficient Modeling of Complex Sandy Coastal Evolution at Monthly to Century Time Scales", *Front. Mar. Sci.* 7:535, doi:10.3389/fmars.2020.00535. ShorelineS 의 사실상 이론 매뉴얼.

## 1. 지배방정식 (PDF 3쪽 / 인쇄 3, "Basic Equation")

$$\frac{\partial n}{\partial t} = -\frac{1}{D_c}\frac{\partial Q_s}{\partial s} - \frac{RSLR}{\tan\beta} + \frac{1}{D_c}\sum q_i \quad (\text{Eq.1})$$

- n은 횡단(cross-shore) 좌표이다. s는 연안 좌표이다. Dc는 능동 단면고이다. Qs는 연안수송[m³/yr]이다. tanβ는 사구 또는 배리어 마루에서 폐합수심까지의 평균 단면경사이다. RSLR은 상대해수면상승률[m/yr]이다. qi는 소스·싱크 항[m³/m/yr]이다. (2020 논문 PDF 3쪽 / 인쇄 3, 식 (1)) 코드 원문은 `functions/coastline_change.m:317` `COAST.dndt(i)=-COAST.dSds(i)/COAST.h0(i);`; `functions/coastline_change.m:365` `dn=(COAST.dndt(i)+COAST.dndtnour(i)-CC.SLRo/COAST.tanbeta)*TIME.dt;`이다. [10-12 전수 검증 정정]
- 계보(p.2): Pelnard-Considère one-line → 고각도 불안정(HAWI, Ashton et al. 2001; Falqués LAWI) → 격자기반 CEM 대비 **벡터 기반 free-form** 이 신규성(p.5).

## 2. 수치 스킴 (PDF 6쪽 / 인쇄 6, "Coastline Evolution")

$$\Delta n_i^j = -\frac{1}{D_c}\frac{2(Q_{s,i}^j - Q_{s,i-1}^j)}{L_i}\Delta t \quad (\text{Eq.5})$$

- 길이 하한이 작동하지 않는 내부점에서 ds=L_i/2이다. 근거: `functions/coastline_change.m:314` `COAST.ds(i)=hypot(COAST.x(ip1)-COAST.x(im1),COAST.y(ip1)-COAST.y(im1))/2;`; `functions/coastline_change.m:315` `COAST.ds(i)=max(COAST.ds(i),eps);`.
- 국소 해안방위는 인접 2점으로 정의한다. 각 세그먼트에서 수송을 계산한다. (2020 논문 PDF 6쪽 / 인쇄 6)

## 3. 고각도 불안정 (PDF 6쪽 / 인쇄 6, "High-Angle Instability")

- suppresshighangle=1은 각도를 제한한다. get_upwindcorrection은 `if COAST.clockwise==1 && TRANSP.suppresshighangle~=1` 조건에서 상류 보정을 수행한다. 근거: `functions/wave_angles.m:133` `WAVE.dPHItdp(kk,:)=sign(WAVE.dPHItdp(kk,:)).*min([abs(WAVE.dPHItdp(kk,:));WAVE.dPHIcrit],[],1);`; `functions/get_upwindcorrection.m:90` `if COAST.clockwise==1 && TRANSP.suppresshighangle~=1`; `functions/ShorelineS.m:176` `[TRANSP]=get_upwindcorrection(COAST,WAVE,TRANSP);`. 전이점 upwind의 근거는 get_upwindcorrection.m:168~185이다. ([R1:K032](../../../_staging/recovery/compare/ShorelineS-theory-vs-code.md#K032))
- 차폐(shadowing): 타 해안·구조물에 의한 파랑 차단, 구조물 스케일≫파장 가정 — 아니면 회절 활성(Elghandour 2018) (2020 논문 PDF 6쪽 / 인쇄 6).

## 4. 배리어/스핏 월류 (PDF 6쪽 / 인쇄 6, "Barrier or Spit Overwash")

- 노트의 파향 transect 표현은 find_overwash_mc.m:6의 헤더 주석을 따랐다. 활성 탐색선은 COAST.PHIcxy를 사용한 육측 법선이다. default 방법에서 파향은 이동량의 cosine 계수에 들어간다. 근거: `functions/find_overwash_mc.m:6` `% The model will for each coastline point construct a transect in the direction of the waves.`; `functions/find_overwash_mc.m:86` `x_nl=[COAST.x-eps*sind(COAST.PHIcxy);COAST.x-SPIT.spitwidth*sind(COAST.PHIcxy)];`; `functions/find_overwash_mc.m:87` `y_nl=[COAST.y-eps*cosd(COAST.PHIcxy);COAST.y-SPIT.spitwidth*cosd(COAST.PHIcxy)];`; `functions/find_overwash_mc.m:136` `dn_sea  = -TIME.dt/SPIT.owtimescale*max(SPIT.spitwidth-SPIT.width(i),0)*max(cosd(phiw_coast(i)-COAST.PHIcxy(i)),0);`.

## 5. 기타 (개관)

- 능동 단면고 = "beach berm height plus ..." 폐합수심 결합(p.13 부근), 검증 케이스: 10년 서향 직선해안 안정성 시험(p.9)·Sand Motor 등.
- 한계·전망(p.17-18): 회절·굴절 근사 향상, cross-shore 과정(Vitousek 2017·Robinet 2018·Antolínez 2019·Palalane-Larson 2020 등) 통합 검토(p.3).
- 수송공식 목록은 2020 논문의 Table 1(PDF 4쪽 / 인쇄 4)이다. 2020 논문의 공식 목록과 현재 코드의 여덟 수송 분기를 구분한다. ([R1:FT1a·FT1b·FT1c·FT1d](../../../_staging/recovery/compare/ShorelineS-theory-vs-code.md#5-차이-결론); [R2:N14](../../../_staging/recovery/compare/ShorelineS-inputs-vs-code.md#4-노트-대조와-수정안))
