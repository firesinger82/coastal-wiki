# 종결 라운드 — 잔여 소진

## 1. wave_diffraction.m 기하 파이프라인 (928줄 본문)

섹션 순서(%% 마커 전수): 구조물별 회절점(tip) 결정(:162 — 좌/우 tip :203/:227, revetment 은 양끝점만 :241, 원거리 구조물 제거 :290) → 각 transport 점에서 tip 까지 각도 φtip·영향각 ω 계산(:316-340, groyne 은 구조물 방위 기준 별도식) → **방향 회전 om**(:367-374) → **Kd**(:377-384, [wave_diffraction_coeff](shorelines-wave-dune-spit-modules.md) §1) → 수중 breakwater 투과 결합(:386-438) → 영향구역 판정(:440)·타 구조물에 가린 tip 차폐(:476)·모델 밖 구조물은 최근접만(:554) → **구조물 사이 gap 보정**(:599-651) → 측면별 지배 구조물 1개 채택(:652) → 해안이 회절점을 '볼 수 있는지' 차폐 검사(:696-761) → 이안제 한정 극사각 입사 감쇠(:781) → 영향구역 경계 gradient 완화·`diffsmooth` 평활(:860-869) → 출력 `PHItdp−om`(nautical 부호)·`HStdp·min(kd,1)`(:880-883).

- S.rotfac는 STRUC.rotfac에 저장된다. wave_diffraction은 이 필드를 읽지 않고 지역 rotfac를 계산한다. (functions/prepare_structures.m:114 `STRUC.rotfac=S.rotfac;`; functions/wave_diffraction.m:106 `rotfac_longcrested = 0.8;   % at dirspr = 12° (default)`; functions/wave_diffraction.m:108 `rotfac_shortcrested = 0.8;  % at dirspr = 32°`; functions/wave_diffraction.m:113 `rotfac = (1-alfa)*rotfac_longcrested + alfa*rotfac_shortcrested;`)
- 방향 퍼짐 혼합 계수는 min(max(dirspr-12,0),32)/20이다. (functions/wave_diffraction.m:105 `alfa=min(max(WAVE.dirspr-12,0),32)/20;`)
- Roelvink 방향 처리에서 dirspr=32°이면 omegat=-35°이다. 같은 처리에서 dirspr>=44°이면 omegat=-44°이다. (functions/wave_diffraction.m:107 `omegat_longcrested = -20;    % at dirspr = 12° (default)`; functions/wave_diffraction.m:109 `omegat_shortcrested = -35;   % at dirspr = 32°`; functions/wave_diffraction.m:114 `omegat = (1-alfa)*omegat_longcrested + alfa*omegat_shortcrested;`; functions/wave_diffraction.m:115–118) [10-12 전수 검증 정정]
- dirspr는 방향 퍼짐으로 쓴다. dispersion은 분산으로 쓴다. (매뉴얼 PDF 61쪽 / 인쇄 61 of 66: `directional spreading of the wave`)
- 투과파의 초기 om3=0은 transmdir 보정 뒤의 최종 방향을 뜻하지 않는다. (functions/wave_diffraction.m:425 `sinkd1=kd1(j,:).^2.*sind(om1(j,:))+kd1_ratio.*kd3(j,:).^2.*sind(om3(j,:));`; functions/wave_diffraction.m:426 `coskd1=kd1(j,:).^2.*cosd(om1(j,:))+kd1_ratio.*kd3(j,:).^2.*cosd(om3(j,:));`; functions/wave_diffraction.m:430 `sinkd2=kd2(j,:).^2.*sind(om2(j,:))+kd2_ratio.*kd3(j,:).^2.*sind(om3(j,:));`; functions/wave_diffraction.m:431 `coskd2=kd2(j,:).^2.*cosd(om2(j,:))+kd2_ratio.*kd3(j,:).^2.*cosd(om3(j,:));`; functions/wave_diffraction.m:375 `om3=zeros(size(om1));  % this assumes the wave direction does not change over the breakwater after wave transmission`; functions/wave_diffraction.m:396 `if STRUC.transmdir==1 % determines wave propagation direction shoreward of breakwater`; functions/wave_diffraction.m:404 `om3(j,:)=sign(om3(j,:)).*min(abs(om3(j,:)),min(abs(om1(j,:)),abs(om2(j,:)))).*(1-kd3(j,:));`) [10-12 전수 검증 보완]

## 2. transport_mud.m 전문 (:83-199)

1. 점착성 유속은 urms를 포함한 이차방정식으로 계산한다. (functions/transport_mud.m:122 `urms     = sqrt(g/8/WAVE.dnearshore)*WAVE.HStdp;`; functions/transport_mud.m:126 `aa       = 1./urms.^2;bb=1.16^2;cc=-arg.^2;`; functions/transport_mud.m:127 `v        = sqrt((-bb+sqrt(bb.^2-4*aa.*cc))/2./aa).*sign(arg);`)
   functions/transport_mud.m:123 `A        = 0.5*B.*WAVE.dnearshore;`
   functions/transport_mud.m:124 `Fws      = rhow*g/32*WAVE.HStdp.^2.*sind(2*(WAVE.dPHItdp))/B;`
   functions/transport_mud.m:125 `arg      = (rhoa*Cd*uwind.^2.*sind(phic-phiwnd)+Fws)/rhow/cf./urms;`
   functions/transport_mud.m:128 `Q        = A.*v;`
2. 소스항의 하천 공급은 qriv*rhos/spyr이다. (functions/transport_mud.m:152 `r(i)=M*B*max((tau(i)-taucr),0)/taucr+qriv(i)*rhos/spyr;`)
   functions/transport_mud.m:154 `a(1)=0;b(1)=-1;c(1)=1;r(1)=0;`
   functions/transport_mud.m:155 `a(n)=-1;b(n)=1;c(n)=0;r(n)=0;`
   functions/transport_mud.m:156 `C=tridiag(a,b,c,r,n);`
   functions/transport_mud.m:160 `C=max(C,0);`
   표사 체적 환산에는 공극률이 없다. (functions/transport_mud.m:167 `TRANSP.QS(i)=(TRANSP.C(i-1)*TRANSP.Q(i))/rhos*spyr; % [m3/yr]`; functions/transport_mud.m:169 `TRANSP.QS(i)=(TRANSP.C(i)*TRANSP.Q(i))/rhos*spyr;   % [m3/yr]`)
3. Bfm의 실제 갱신율은 dBfmdt-dBmdt이다. (functions/coastline_change.m:345 `COAST.Bfm=COAST.Bfm+(COAST.dBfmdt-COAST.dBmdt)*TIME.dt;`)
   functions/transport_mud.m:178 `dBmdt(i)=2*qm(i)/dm;`
   functions/transport_mud.m:179 `dndt(i)=(-dQsds(i)-qm(i)+qriv(i))/d(i);`
   functions/transport_mud.m:181 `dBfmdt(i)=(Bf(i)-Bfm(i))/Tfm;`
   functions/transport_mud.m:116 `P        = (0.5*Bm+Bfm)*(MHW-MSL);         % Tidal prism in mangrove`
   functions/transport_mud.m:117 `qmoverC  = 700/spyr*P.*max(min((Bf-Bfcrit)/Bfcrit,1),0);`

transport_mud는 COAST.dndt_mud를 생산한다. PHASE 2의 필드 복원에는 이름 불일치가 있다. (functions/transport_mud.m:195 `COAST.dndt_mud = dndt;`; functions/get_segmentdata.m:134 `[ COAST.dndt_mud ] = get_one_polygon( COAST.dndt_mudmc,i_mc);`; [코드 결함 후보](shorelines-architecture-map.md#코드-결함-후보-정적-판독), R3:V01)
- 관찰: `HStdp(|φ|>90°)=0.1`(:118) — 모래식(0 처리)과 달리 잔존 0.1 m 부여.

## 3. 위상 처리 3파일
