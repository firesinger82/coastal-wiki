## 2. 회절 2차항 dHS (`transport.m:102-122`)

## 4. 적응 시간간격 (`get_timestep.m:51-77`)

- get_timestep의 기본 안정성 기준값은 매뉴얼 식 (7)의 오른쪽과 같은 분모 4Qmax를 사용한다. 실제 dt는 추가 제한을 거친다. (functions/get_timestep.m:61 `adt=dsmin^2*h0min / (4*max(abs(TRANSP.QSmax)));`; 매뉴얼 PDF 14쪽 / 인쇄 14 of 66, 식 (7))
