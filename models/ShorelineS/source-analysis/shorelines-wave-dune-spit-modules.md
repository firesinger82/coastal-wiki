# 파랑·사구·스핏·mud 모듈

## 1. 회절·투과 (`wave_diffraction.m` 928줄 + `wave_diffraction_coeff.m`)

- 대상: groyne·이안제·revetment 배후(헤더 :4-8). Kd 공식은 Kamphuis와 Roelvink이다. (functions/wave_diffraction_coeff.m:62 `fac1=0.5;`; functions/wave_diffraction_coeff.m:63 `pwr=4;`; functions/wave_diffraction_coeff.m:65 `kdi=1-exp(-abs((fac1./om_x).^pwr));`; functions/wave_diffraction_coeff.m:66 `kdi(omr<-90)=1;`)
- wdform의 Dabees 계열에는 dabees·hurst·kamph 문자열 경로가 있다. (functions/wave_diffraction.m:115 `if ~isempty(findstr(lower(STRUC.wdform),'dabees')) || ~isempty(findstr(lower(STRUC.wdform),'hurst')) || ~isempty(findstr(lower(STRUC.wdform),'kamph'))`)
- **Kd 공식**(`wave_diffraction_coeff.m:59-77`):
  - Roelvink형: `kd = 1 − exp(−|(0.5/ω_x)⁴|)`, ω_x=(ω+90)/180 — 매끄러운 지수형(:61-66).
  - Kamphuis의 곡선 각은 omk=-omr이다. (functions/wave_diffraction_coeff.m:70 `omk=-omr;   % Note: we define omega positive towards shadow zone`)
  - functions/wave_diffraction_coeff.m:74 `kdi(omk < -86.25 ) = 0;`
  - functions/wave_diffraction_coeff.m:75 `kdi(omk <= 0 & omk >=-86.25) = max(0.69+0.008*omk(omk <= 0 & omk >=-86.25),0);`
  - functions/wave_diffraction_coeff.m:76 `kdi(omk > 0 & omk <= 40) = 0.71+0.356686*sind(omk(omk >  0 & omk <= 40));`
  - functions/wave_diffraction_coeff.m:77 `kdi(omk > 40 & omk <= 90) = min(0.83+0.17*sind(omk(omk > 40 & omk <= 90)),1);`
- dirspr는 방향 퍼짐으로 쓴다. dispersion은 분산으로 쓴다. (매뉴얼 PDF 61쪽 / 인쇄 61 of 66: `directional spreading of the wave`)
- functions/wave_diffraction_coeff.m:53 `dirout=[-50:5:50];`
- functions/wave_diffraction_coeff.m:55 `prob=get_dirspr_prob(dspr,dirout);`
- functions/wave_diffraction_coeff.m:81 `kdiprob=kdi.^2.*repmat(prob(:),[1,size(kdi,2)]);`
- functions/wave_diffraction_coeff.m:82 `kd(j,:)=(sum(kdiprob,1)).^0.5;`
- **투과**(헤더 :22-28): 이안제 3공식 `transmform`='angr'(d'Angremond)|'gent'(Van Gent)|'seabrhall'(Seabrook-Hall) — 마루고·마루폭·사면경사·armour d50 입력.

## 2. 사구 침식·성장 (`dune_erosion.m` 등)

- 사구 침식은 제한한 경사와 초과 수위 및 가용 재고를 사용한 뒤 해빈 공급과 월파로 분할한다. (functions/dune_erosion.m:99 `ero=SWL+R>dfelev;`; functions/dune_erosion.m:127 `qs(ero)=qd(ero)./(1+alfa(ero));`; functions/dune_erosion.m:129 `ql(ero)=qd(ero).*alfa(ero)./(1+alfa(ero));`)
- Cstill·xtill·perctill 입력의 존재와 점착성 침식의 정상 작동을 구분한다. (functions/dune_erosion.m:23 `%    cstill          : erosion coefficient of the dunes during storms for dunes with consolidated till layers, which scales the rate of erosion`; functions/dune_erosion.m:110 `qdmax=xtill.*DH/dtnum;`; functions/dune_erosion.m:25 `%    perctill        : percentage of till (0 to 100) of the cohesive dune, with the sand percentage being 100-perctill`)
- 점착성 침식에는 MU20b와 MU20c의 결함 후보가 있다. ([코드 결함 후보](shorelines-architecture-map.md#코드-결함-후보-정적-판독), R1:MU20b·R1:MU20c)
- functions/dune_erosion.m:84 `R = runupfactor*1.1*sqrHsL0.*(0.35*slope + sqrt(0.563*(slope.^2) + 0.004)/2);`
- functions/dune_erosion.m:87 `R = runupfactor*slope.*sqrHsL0;`
- functions/dune_erosion.m:92 `R = runupfactor*0.158*sqrHsL0;`
- qs는 해빈에 도달하는 전체 침식물이다. qss는 그중 모래이다. (functions/dune_flux.m:196 `COAST.qs=COAST.qs+qs*Prob;         % compute average qs, i.e. dune erosion that is beneficial for the beach`; functions/dune_flux.m:197 `COAST.qss=COAST.qss+qss*Prob;      % compute average qss, i.e. dune erosion that is beneficial for the beach (i.e. the sandy part, discarding the till part)`)
- ql은 월파에 의한 사구 침식률이다. ql은 해빈에 직접 기여하지 않는 사구 침식분이다. (functions/dune_erosion.m:129 `ql(ero)=qd(ero).*alfa(ero)./(1+alfa(ero));`; functions/dune_flux.m:198 `COAST.ql=COAST.ql+ql*Prob;         % compute average ql, i.e. dune erosion that is not beneficial for the beach`) [10-12 전수 검증 정정]
- qw는 해빈에서 사구로 가는 풍성 표사이다. qd=qs+ql이다. (functions/dune_erosion.m:127 `qs(ero)=qd(ero)./(1+alfa(ero));`; functions/dune_erosion.m:129 `ql(ero)=qd(ero).*alfa(ero)./(1+alfa(ero));`; functions/coastline_change.m:325 `COAST.dndt=COAST.dndt+(COAST.qss-COAST.qw)./COAST.h0;`)
- find_overwash_mc의 dune_overwash 방법은 ql을 배후 퇴적에 사용한다. (functions/find_overwash_mc.m:142 `case ('dune_overwash')`; functions/find_overwash_mc.m:144 `dn_back = TIME.dt*COAST.ql(i)/(COAST.dcelev(i)+SPIT.Dbb);`)

## 3. 스핏/배리어 월류 (`find_overwash_mc.m` 206줄)

- find_overwash_mc의 헤더 주석은 탐색선을 파향 방향으로 설명한다. (functions/find_overwash_mc.m:6 `% The model will for each coastline point construct a transect in the direction of the waves.`) [10-12 전수 검증 정정]
- 월류 폭 탐색선은 파향이 아니라 해안선의 육측 법선이다. default 방법의 파향은 이동량 계수에 사용된다. (functions/find_overwash_mc.m:86 `x_nl=[COAST.x-eps*sind(COAST.PHIcxy);COAST.x-SPIT.spitwidth*sind(COAST.PHIcxy)];`; functions/find_overwash_mc.m:87 `y_nl=[COAST.y-eps*cosd(COAST.PHIcxy);COAST.y-SPIT.spitwidth*cosd(COAST.PHIcxy)];`) [10-12 전수 검증 정정]
- 폭은 배후 교차 구간의 절점 거리로 구한다. (functions/find_overwash_mc.m:116 `distance           = hypot(xcr2-COAST.x(i),ycr2-COAST.y(i));`; functions/find_overwash_mc.m:118 `[SPIT.width(i)]    = min(distance);`)
- default 방법의 파향은 이동량의 코사인 가중치에 들어간다. (functions/find_overwash_mc.m:136 `dn_sea  = -TIME.dt/SPIT.owtimescale*max(SPIT.spitwidth-SPIT.width(i),0)*max(cosd(phiw_coast(i)-COAST.PHIcxy(i)),0);`; functions/find_overwash_mc.m:134 `case ('default')`) [10-12 전수 검증 정정]
- 현재 이동량 식에는 격자 간격의 10% 상한이 없다. (functions/find_overwash_mc.m:139 `dn_sea  = -SPIT.owscale*max(SPIT.spitwidth-SPIT.width(i),0)*max(cosd(phiw_coast(i)-COAST.PHIcxy(i)),0);`; R3:M16)
- 해측 이동의 법선 인덱스에는 K022의 결함 후보가 있다. ([코드 결함 후보](shorelines-architecture-map.md#코드-결함-후보-정적-판독), R1:K022)

## 4. mud 해안·조석

- 점착성 해안 경로는 바람·파랑 구동 유량과 조석 프리즘 기반 맹그로브 교환량을 계산한다. ([회절·mud·위상 노트](shorelines-diffraction-mud-topology.md), R1:K034)
- `tide_1d_ana_anycomp.m`(92줄): 임의 분조(진폭 eta·위상 phi·연안파수 k·연안경사 ss)의 **해석적 1D 조류 프로파일**(h[nx,nt]·vt[nx,nt]) — TIDEPROF transport 의 유속원(transport.m:208-212).
- transport_mud는 COAST.dndt_mud를 생산한다. PHASE 2의 필드 복원에는 이름 불일치가 있다. (functions/transport_mud.m:195 `COAST.dndt_mud = dndt;`; [회절·mud·위상 노트](shorelines-diffraction-mud-topology.md), R3:N12)
