# STR3D FEM 코어 (구조·지반)

> 멀티스케일 사슬의 구조 컴포넌트 — CADMAS 유체압을 받아 구조 변형·응력을 FEM 으로 풀고 변형 위치를 CADMAS-2F 로 환류([cadmas-2f-structure-coupling](cadmas-2f-structure-coupling-cutcell.md)). 본 노트=FEM 코어(시간적분·요소·구성식). solver·접촉·유체결합은 자매노트. 경로 루트: `raw/.../Simulators/STR3D/Source code/`(하위 src/·seq/·main/·module/·contact/).

## 1. 시간적분 — Newmark-β 음함수 동해석 (β=1/3)

메인의 `ASTEA_MECHANICAL` 호출은 `STR3D/main/main.f:86·92`에 있다. Newmark β 기본값은 `STR3D/main/main.f:45`의 `RR(4)  = 1.D0/3.D0      ! BETA`다. 압력 가중 α 기본값은 `STR3D/main/main.f:48`의 `RR(7)  = 1.D0           ! ALPHA`다. `KK(1)=0`은 구조–침투 동시 해석이다. `KK(1)≠0`은 구조–침투 분리 해석이다 (`STR3D/main/astea_mechanical.f:110–120`). 지반 요소 타입은 `IELM(2,:)=6`이다 (`STR3D/src/ist_updt.f:15`). [11-04 대조 정정]

`KK(1)`의 명시 초기값은 0이다 (`STR3D/main/main.f:31`). SOL 종류에 따른 `KK(1)` 설정은 주석이다 (`STR3D/input/Read_data/Read_data.f:31–49`). `IF( KK(1) == 0 ) THEN`이면 `NL_TRANSIENT`를 호출한다. 이 분기의 `NL_STATIC` 호출에는 `KK(84) <= 0` 조건이 있다. ELSE 분기는 `NL_TRANSIENT_S`를 호출한다. 이 분기의 `NL_STATIC_S` 호출에도 `KK(84) <= 0` 조건이 있다 (`STR3D/main/astea_mechanical.f:110–120`). [11-04 대조 정정]

공개 STR3D 배포본에는 `NL_TRANSIENT`의 활성 호출과 필수 `nl_transient.o` 빌드 항목이 있다 (`STR3D/main/astea_mechanical.f:114`, `STR3D/src/makefile:37`). 대응 `nl_transient.f`는 배포본에 없다. 이 소스 배포 결함 후보의 강도는 강함이다 (`STR3D/src/makefile:55–60`, `STR3D/makefile:27–30,80–81`; [최종 근거](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KU1.md)의 KU1-765·916). [11-04 대조 정정]

**음함수 동해석 Newmark-β, 3변위레벨**(`UG1/UG2/UG3`=u_{n-1}/u_n/u_{n+1}, `module/m_val.f90:126-128`, roll `nl_transient_s.f:316-317`), 가변스텝 `DT1/DT2`·`DT12=½(DT1+DT2)`. 잔차(동적 내력 `FTI`, `seq/npforce_s.f:65-72`):
```
FTI = (FCM3/DT2 - (1/DT2+1/DT1)FCM2 + FCM1/DT1)/DT12     ! M·a (중심 2차차분)
    + 질량비례감쇠 + 강성비례감쇠
    + (β·FCK3 + (1-2β)·FCK2 + β·FCK1)                     ! Newmark-β 가중 K·u
```
강성비례 감쇠계수는 `GE = AMAT(4,IMAT) / W4`다. 질량비례 감쇠계수는 `CM = AMAT(5,IMAT)`다 (`STR3D/contact/npforced.f:47–48`, `STR3D/seq/npforce_s.f:48`). 부록 2의 `[B] = C_K[K]`는 `CM=0`인 강성비례 감쇠 조건에 대응한다 (`STR instructions p.104–105`). 접선강성의 원문은 `ESTF(1:N2) = ( 1.D0/DT2 + .5D0*CM ) / DT12 * EMASS(1:N2)`와 연속행 `&               + ( .5D0/DT2*GE + BETA ) * ESTF(1:N2)`다 (`STR3D/contact/npforced.f:50–51`). [11-04 대조 정정]

Newton-Raphson 내부루프(`nl_transient_s.f:123`) + 접촉 외부루프(`:111`). 대회전 director는 Rodrigues 회전(`src/dirupdt.f:30-35`, `IGNL>0`).

`UG1`·`UG2`·`UG3`은 세 시간 레벨이다 (`STR3D/module/m_val.f90:126–128`). `_S` 루틴은 분리법의 지역 구현 근거다 (`STR3D/seq/nl_transient_s.f:316–321`). 배열 크기와 병렬 추가 공간의 문서 표는 `STR instructions p.73–74·76`에 있다. [11-04 대조 정정]

> 지반(`ITYP=6`)의 분리 경로는 `IF( IDYN == 1 ) THEN`에서 `ELHM(1:NN) = ECPP(1:NN) / DT12 * .5D0 + ALP * EKPP(1:NN)`을 계산한다 (`STR3D/seq/glbstfg_s.f:30–33`). `DT12 = .5D0 * ( DT1 + DT2 )`다. 압력 평균은 `P(:) = ( 1.D0 - ALP ) * PG1(KN(:)) + ALP * PG3(KN(:))`다. 압력 미분은 `PD(:) = ( PG3(KN(:)) - PG1(KN(:)) ) / DT12 * .5D0`다. `ALP=1`이면 평균은 `PG3`이다. 압력 미분은 n-1부터 n+1까지 두 시간 간격을 사용한다 (`STR3D/seq/gnpflw_s.f:17–31`). [11-04 대조 정정]

## 2. 요소 라이브러리

요소 입력기는 shell 카드와 `ITYP=1`을 구성한다 (`STR3D/input/Read_data/Read_data.f:629–643`, `STR3D/input/Set_table/St_ELEM.f:25–39`). 공개 `ESTFMTX`의 요소 유형 분기는 `CASE( 2, 6 )`, `CASE( 3 )`, `CASE( 4 )`다. 이 디스패처에는 shell 유형인 `ITYP=1`의 강성 호출이 없다 (`STR3D/src/estfmtx.f:8–28`). solid족은 te1(4)/te2(10)/pn1(6)/pn2(15)/hx1(8)/hx2(20)이다 (`STR3D/src/estfmtx.f:11–22`). [11-04 대조 정정]

- **형상함수 도함수·Gauss**: `derhx2.f`(hex 8/20, 2³ 또는 3³ Gauss `gauss_ln_3.h`)·`derpn2.f`(prism, `gauss_pn_73.h` 7×3)·`derte2.f`(tet 10, `gauss_te_5.h` 5점)·`dertr2/derqu2`(tri/quad). Jacobian `det3.f`(|J|<1e-20 abort :23-26)
- **강성 B/D**: `BLMTX`(`blmtx.f:17-25` 6×3N 변형-변위 B행렬, `IGNL>0` 시 TL 대변형 비선형항 :30-41). 요소접선 `estfhx2.f:42-55`: `ESTF=Σ_gp(Bᵀ·D·B + Sᵀ·E)·|J|·W` — 재료강성 + 기하(초기응력)강성(`IGNL>0`)
- **질량 `emass*.f`**: 질량행렬 주석과 코드 분기는 일치한다 (`STR3D/src/emasste1.f:7,29–45`). `LUMP .EQ. 0`이면 집중질량 값 4개를 계산한다. 그 밖의 분기는 일관질량행렬 값 16개를 계산한다. 드라이버는 `KK(30) = 1`을 선택한다 (`STR3D/main/astea_mechanical.f:27`; `STR instructions p.56`). [11-04 대조 정정]
- **하중**: `efrcp.f`(유체압 `PPND`→`FCP`, [§유체결합](str3d-contact-and-fluid-coupling.md))·`efp*.f`(면압)·`bdf*.f`/`bdyfc.f`(체적력)

## 3. 구성식 (재료)

**선형탄성 + von Mises/Drucker-Prager 탄소성(등방경화) + 평활 인장균열 + Rayleigh 감쇠.** Cam-Clay·Mohr-Coulomb 파일 없음(DP=MC 평활 cone).

- **탄성 D행렬**: `dsol0.f:22-24`(E,ν 등방 3D), 균열 D `dsol1.f`(균열법선 `D=E·1e-4` smeared-crack)
- **항복함수** `yfunc.f`: `IYLD=1`→**von Mises** `F=√(3·J2D)`(`:14-15`), `IYLD=2`→**Drucker-Prager** `F=A(α·J1+√J2D)`, `A=1/(1/√3-α)`(`:16-19`), `α=AMAT(13)`
- **유동법칙** `dfdsg.f`(∂F/∂σ 연관, von Mises :9-21 / DP :25-31)
- **탄소성 접선** `sol2.f:16-26`: `Dᵉᵖ=Dᵉ-(Dᵉ a aᵀ Dᵉ)/(H+aᵀ Dᵉ a)`, 경화 `HD=AMAT(12)`
- **인장균열** `sol0.f:7-25`: 주응력 `PR(1)≥ST`(인장강도 `AMAT(14)`)이면 `KOJI3D`(`koji3d.f` 주응력 고유해)로 주축회전→균열 D `DSOL1`→역변환
- 상태갱신 `ist_updt.f:18-35`(`E/ν/HD/α/ST` 읽고 `IST_SOL/TRS/BEAM` 디스패치)

**재료표 `AMAT` 열**: E·ν·GE·CM·H′·α·σt의 저장 위치는 각각 AMAT의 1·2·4·5·12·13·14행이다 (`STR3D/src/ist_updt.f:19–25`). AMAT(3)은 `( 1.D0 - POR ) * RHO + POR * 1.D3`로 계산한 혼합 밀도다. AMAT(6)은 CADMAS용 공극률이다. AMAT(7)은 지반 공극률이다. AMAT(9)은 `RK / 9.8D3`다 (`STR3D/input/Read_data/Rd_MAT1.f:10–37`; `STR instructions p.63`). RHO 입력은 입자 자체의 밀도다. 일반 다공성재료는 NC를 사용한다. 지반은 N으로 혼합 밀도를 다시 계산한다 (`STR instructions p.6·37`; [최종 근거](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KT1b.md)의 KT1-843). [11-04 대조 정정]

## 4. 전역 데이터 구조 (module/)

- `m_val.f90`: 중앙 전역상태 — 연결 `IELM`·좌표 `GRID`·재료 `MAT/AMAT`·3변위 `UG1/2/3`·beam director `VG`·력벡터 `FCK/FCD/FCM`·pore압 `PG1/2/3`·Gauss 변형/응력 `EPSG/SIGG`·속도 `VELG`
- `FRCI`의 크기는 `FRCI(3,NNOD)`다. `WRK2`의 크기는 `WRK2(6,NNOD+NIGSF)`다 (`STR3D/main/alloc.f:77–81`). `PND`의 크기는 `PND(NNOD,NPTIM)`다 (`STR3D/main/rdpress.f:67–68`). 문서의 NPITM과 NGCPSC는 각각 NPTIM과 NCGSPC의 철자 오기다 (`STR instructions p.73·75·76`). [11-04 대조 정정]
- `m_part.f90`: 영역분할/MPI 파티션 테이블 + 파티션간 통신 인덱스
- `input_work.f90`: NASTRAN형 카드(GRID·CTRIA/CQUAD·CTETRA/CHEXA·CROD·CBAR) 파싱 스테이징
- `mavbl.f90`/`mused.f90`: 메모리 budget 회계

> 코어: Newmark-β 음함수 동해석 + 탄소성-균열 구성식 + Biot 지반. CADMAS 유체압이 외력(`efrcp.f`)으로 진입, 변형이 환류. solver→[str3d-linear-solvers](str3d-linear-solvers.md), 접촉·결합→[str3d-contact-and-fluid-coupling](str3d-contact-and-fluid-coupling.md).
