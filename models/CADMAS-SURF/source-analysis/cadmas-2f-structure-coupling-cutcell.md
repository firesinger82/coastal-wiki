# CADMAS-2F 유체-구조 결합 (sf_* cut-cell 공극엔진)

> 3D2F의 `sf_*.f`·`sf_*.f90` 목록은 144개 파일이다. 구조물 교차체적은 셀·면 공극률을 바꾼다. 그 뒤 셀·면 상태와 경계조건·유체장을 재구성한다 (`3D2F/sf_str_obst.f:63–74`, `3D2F/sf_str2.f:22–43`, `3D2F/sf_bc_reset.f:67–75`, `3D2F/sf_cinit.f:40–54`). 근거는 [KD1-900](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KD1f.md)이다. 기상 계산은 [기액 2상 노트](cadmas-2f-twophase-compressible-gas.md)에 있다. [11-04 대조 정정]

## 1. 정체 — 구조커플링이지 2상 아님

`sf_*`는 `vf_*`와 달리 `CDT` 헤더 스타일 다름. `SF_STRUCT.h` COMMON `/SF_STRUCT/`: `ICPL`(결합플래그)·`NELM/NNOD`(FE 요소·절점수)·`NPFC`(면수)·`ISTM`(가동상). `SF_TYPE`(`sf_type.f90`): `SPACE{IFIX;N;ID;P}` 요소별 sub-cell 다면체. 산출물은 단상/2상 공통 `VF_*` solver 의 공극 입력.

`2F manual p.79–80`의 자료 구조 목록에는 `SF_STRUCT`가 없다 (`3D2F/SF_STRUCT.h:1–5`). 근거는 [KF2-351](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KF2.md)이다. [11-04 대조 정정]

## 2. 기하 클리핑 커널 (cut-cell 부피적분)

클리핑 대상은 모서리 절점과 면 중심으로 만든 사면체 다면체다. 2차 요소의 중간 절점 곡면을 적분하지 않는다. 좌표·체적 허용오차도 사용한다. 정확하다는 표현은 이 다면체 분할에 한정한다 (`3D2F/sf_tetdiv.f:7–28`, `3D2F/sf_gsfhx.f:4–15`, `3D2F/sf_cut3x.f:11–28`). 근거는 [KT1-856](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KT1b.md)이다. [11-04 대조 정정]
- `SF_TETDIV`(`sf_tetdiv.f`): FE 요소→사면체 분해(tet→1, penta→11 `SF_MKTEPN` :18, hex→24 `SF_MKTEHX` :24)
- `SF_CUT3`(`sf_cut3.f`): 사면체를 6 셀면 평면 `XG/YG/ZG`에 `SF_CUT3X` 6중 클리핑(`:18-34`), `SF_TETVOL` 체적합(`:36`) → 클립체적 `VV` + 3 절단면적 `SX/SY/SZ`. `EPSV=Δx·Δy·Δz·1e-9`(`:12`)
- `SF_CUT3X`는 사면체를 한 평면으로 절단한다. 4정점을 분류한 뒤 `IST`로 재분할한다 (`3D2F/sf_cut3x.f:35–60`). 절단 기하는 위의 다면체 분할에 한정한다. 근거는 [KT1-856](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KT1b.md)이다. [11-04 대조 정정]
- `SF_CUT2/2X/2TR`(`sf_cut2*.f`): 2D 삼각형↔셀edge 클립(면적, `sf_pface3.f` 면적분용)
- 기하 헬퍼: `SF_TETVOL`(부호 사면체체적 3×3 행렬식/6 `sf_tetvol.f:19-21`)·`SF_S34`(삼각/사각 부호면적)·`SF_STRIA`(삼각면적)

## 3. 공극(개방률) 산출 — sf_mdporo.f

cut 기하 → 셀 분율 감소(`sf_mdporo.f`):
```
:151  CALL SF_CUT3(V,SX,SY,SZ,P(1,1,IT),XG,YG,ZG,EPS)   ! 유일 체적 caller
:305  GGV(I,J,K) = (1 - VV(I,J,K)/VV0)*GGV(I,J,K)       ! 공극 감소
:316  GGX(I,J,K) = (1 - SSX(I,J,K)/SSX0)*GGX(I,J,K)     ! 면적투과율 (GGY/GGZ 동형)
```
`P`는 FE 절점(`SF_TETDIV`)·`XG/YG/ZG`는 셀edge 좌표. 드라이버 `sf_str_obst.f:63 SF_MDPORO → :72 VF_CGLV → :74 VF_CGLXYZ` (분율을 VF solver 가상질량/관성공극에 전달). 가동상은 `SF_MDPORO_H`(`sf_mdporo_h.f`).

## 4. FSI 드라이버 (sf_str*) + 가동상 (sf_stm*)

- `SF_STR0`·`SF_STR1`·`SF_STR3`는 `ICPL.GT.0`에서 호출한다. 시간 반복의 `SF_STR2`는 `ICPL.EQ.2`에서 호출한다 (`3D2F/vf_a1main.f:749–753,995–999,1096–1100,1140–1144`). 근거는 [RF-010](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-RF.md)이다. [11-04 대조 정정]
- `SF_STM*`는 STM의 수심·지형 연성을 처리한다. STM 연성과 STOC 직접 접속을 구분한다 (`3D2F/mod_comm.f90:26,35,58`, `3D2F/sf_stm1.f:14`, `3D2F/sf_stm2.f:8–14`, `3D2F/sf_stm_comm_init.f:1–69`). 근거는 [KD1-901](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KD1f.md)이다. [11-04 대조 정정]

## 5. 외부 구조 solver MPI 결합 (FSI)

`TNEXT = TNOW + DT`이다. `IF( TNEXT > TSTR2 ) THEN` 안의 루트 프로세스에서 송수신한다. `POS20`은 절점 위치다. `IF( IGEO == 1 )`일 때 `DVEL20`으로 지반 Darcy 유속을 수신한다. `IF( ICON == 1 ) THEN`일 때 `AFC`와 `IPND0`를 송신한다 (`3D2F/sf_pos_update2.f:28–49`). 이후 `SF_POS_UPDT`가 작은 위치 변화를 제한한다 (`3D2F/sf_pos_update2.f:85–98`, `3D2F/sf_pos_updt.f:44–60`). 근거는 [KT1-857](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KT1b.md)과 [RF-011](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-RF.md)이다. [11-04 대조 정정]

## 6. 보조 — 법선·면·전치

- 법선 분류는 `IF( IELM(3,IE) == 2 ) THEN`인 요소 표면에 적용한다. `CR1 = -DSIN( 85.D0 / 180.D0 * PI )`이다. `CR2 =  DSIN( 15.D0 / 180.D0 * PI )`이다. `IF( E(3) < CR1 ) THEN`이면 `IRFACE`를 1로 둔다. `ELSEIF( E(3) > CR2 ) THEN`이면 `IRFACE`를 2로 둔다. 첫 조건은 거의 아래를 향하는 법선이다 (`3D2F/sf_rface0.f:13–30`). 근거는 [KD1-903](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KD1f.md)이다. [11-04 대조 정정]
- `AFC`는 구조 표면에서 압력을 적용할 면적의 비율이다. 유체 셀면 개방률 `GGX`·`GGY`·`GGZ`와 구분한다. 접촉면에 덮인 면적을 빼고 하한보다 작으면 0으로 바꾼다 (`3D2F/sf_pface3.f:16–26,102–106`). 근거는 [KT1-858](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KT1b.md)이다. [11-04 대조 정정]
- 전치/프레임: `SF_TRNS1/2`(국소면 좌표변환)·`SF_TRM1/2`(회전행렬, "trm"=transform-matrix)
- 토폴로지: `SF_COL3/4/COLTR`(공유면 매칭)·`SF_MEAN4`(절점중심)

## 7. MPI·IO·메모리

- MPI: `sf_bcast_*`·`sf_comm_*`·`sf_reduce_*`·`sf_mpi_*`/`sf_c_mpi_*`/`sf_stm_c_mpi_*`(send/recv/isend/irecv/wait/reduce/allreduce/barrier)
- IO: `sf_ens_geom/out`(EnSight)·`sf_send_surf/rst`·`sf_rd/wt_restart`
- 메모리: `sf_alloc0/1`·`sf_dealloc`·`sf_realloc`·`sf_dcopy/icopy`

> `sf_*`는 고체 다면체의 간섭 체적·면적을 계산한다. 정확성의 범위는 모서리 절점과 면 중심을 사용한 다면체 기하이다. 근거는 [KT1-834·856](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KT1b.md)이다. [11-04 대조 정정]
