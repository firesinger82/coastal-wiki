# CADMAS-2F 기액 2상 (압축성 기상)

> 3D2F 사본은 3D 사본에 2상·기상 압축성·구조·STM·HIDEM을 추가한다. 내부 조파 소스·행렬2·자동 재시작·STOC 직접 경로 일부는 3D 사본에만 있다. 이 비교는 두 사본의 차이다. 근거는 [KD1-893](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KD1f.md)이다. 경로 루트는 `raw/.../Simulators/CADMAS-SURF-3D2F/Source code/`이다. [11-04 대조 정정]
>
> `sf_*`는 [유체-구조 결합](cadmas-2f-structure-coupling-cutcell.md)을 처리한다. 기본 VOF 이류는 donor–acceptor이다. `COMP SCHM FF-SLOPE`를 선택하면 기울어진 계면을 선분·평면으로 재구성한다 (`3D2F/vf_iicomp.f:42–46`, `3D2F/vf_f1cal.f:131–139`). 근거는 [2f-theory §4의 PLIC 정정](../../../_staging/recovery/compare/cadmas-2f-manual-theory-vs-code.md#4-노트-대조와-수정안)이다. [11-04 대조 정정]

## 1. 메인 정체 (vf_a1main.f:1-9)

```
CDT   VF_A1MAIN:CADMAS-SURF/3D-2Fのメインルーチン
CD      (1)解析対象:自由表面を含む気液2相3次元非圧縮性流体
```
메인 주석은 기액 2상 비압축성 유체라고 적는다. `ISTATE=0`은 상수 기상 밀도를 쓴다. `ISTATE=1`은 등온 기상 EOS와 밀도변화 압력항을 쓴다 (`3D2F/vf_v1eos.f:63–74`, `3D2F/user_eos.f:23–38`). 신규 배열은 `RHOG`·`DRHODP`·`DRHODT`·`RHOGO`이다 (`3D2F/vf_a1main.f:364–367`). 근거는 [KD1-894](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KD1f.md)이다. [11-04 대조 정정]

## 2. 기상 상태방정식 EOS (신규)

`USER_EOS`(`user_eos.f:23-34`) — **등온 이상기체**:
```
RHOG   = (PP + P0)/(RCONS·TCONS)      ρ = (p+P0)/(R·T)
DRHODP = 1.0/(PP + P0)                (dρ/dp)/ρ
```
`DRHODT`는 코드의 `GGV` 가중 시간항과 기상 밀도 이류항을 `RHOG`로 나눈 값이다. 이 배열에는 `1-F`를 미리 곱하지 않는다. 압력항은 `AVL=(1-FF)*셀체적`을 따로 곱한다 (`3D2F/vf_v1eos.f:168–172`, `3D2F/vf_vpdrdt.f:95–96,154–156`). 근거는 [KD1-895](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KD1f.md)이다. [11-04 대조 정정]

밀도 이류 계수의 추가 `GGV/GLV`는 중간 강도의 코드 결함 후보이다. 표면 셀의 액체 방향 밀도 복사도 중간 강도의 코드 결함 후보이다. `ISTATE=0`이면 이 EOS 계산 전에 반환한다 (`3D2F/vf_v1eos.f:63–172`). 근거는 [KF2-003·360](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KF2.md)이다. [11-04 대조 정정]

EOS는 `INDC≠-1`에서 호출한다. 밀도 시간·이류 미분은 `NF>0`에서 계산한다. 근거는 [2f-theory §4의 VF_V1EOS 조건 정정](../../../_staging/recovery/compare/cadmas-2f-manual-theory-vs-code.md#4-노트-대조와-수정안)이다. [11-04 대조 정정]

## 3. 변밀도 one-fluid VOF (단일 운동량장)

액상 상수밀도 `RHO0(1)`와 기상 가변밀도 `RHOG`를 VOF로 혼합한 단일 운동량장을 쓴다. `RHO0(2)`를 쓰는 `!!` 대안도 상수 밀도 기상을 갖는 2상식이다. 3D 사본은 스칼라 `RHO0`의 역수를 쓴다 (`3D/vf_vgene.f:80`, `3D2F/vf_vgene.f:100–103`). 근거는 [KD1-896](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KD1f.md)이다. [11-04 대조 정정]
실행식은 `RI=1.0D0/(FX(I,J,K)*RHO0(1)+(1.0D0-FX(I,J,K))*RHO02)`이다 (`3D2F/vf_vpcoef.f:169–173`). 근거는 [2f-theory KF1-205](../../../_staging/recovery/compare/cadmas-2f-manual-theory-vs-code.md#3-코드에만-있는-처리)이다. [11-04 대조 정정]
동일 패턴 `vf_vgene.f:100-103`·`vf_vmodif.f:105-108`. 역밀도 `RI=1/(F·ρ_liq+(1-F)·ρ_gas_face)`가 압력구배항을 곱함(예측자·보정자). 재료헤더 `RHO0(1)`=액상·`RHO0(2)`=기상·`ANU0(1/2)` 액/기 점성(`VF_APHYSR.h:26-27`, 파싱 `vf_iimate.f:38-58`).

## 4. 준압축성 압력-Poisson (핵심 신규)

기상 압축성을 **별도 압축성 solver 가 아니라 SMAC 압력-Poisson 변형**으로 처리(단일 압력장 유지). `VF_VPDRDT`(헤더 `…密度変化による項` `vf_vpdrdt.f:8`). 변형 연속식(in-code 유도 `:78-88`):
```
div v + (1-F)·(Dρ/Dt)/ρ = 0   ← (1-F)(Dρ/Dt)/ρ 를 Poisson에 가산
ρ^new = ρ^old + (dρ/dp)^old·Δp
```
Poisson 대각·RHS 증강(`vf_vpdrdt.f:110-156`):
```
AD += AVLT·DRHODP/DTNOW
AD -= AVLT·DRHODP·DRHODT
BB += AVL·DRHODT
```
→ 발산구속이 `∇·v = -(1-F)(Dρ/Dt)/ρ`로 대체, `∂ρ/∂p` Jacobian 을 행렬에 implicit 반영 = **low-Mach/준압축성** 기상. `ISTATE=0`이면 표준 비압축 Poisson 으로 환원(`:77`).

대각·RHS뿐 아니라 6개 방향 이류 계수도 조립한다. 음의 x 흐름에서 `AUI(I,J,K) = AUI(I,J,K) + DCOEF*DRHODP(I-1,J,K)`는 강한 코드 결함 후보이다. `ISTATE`가 0이 아닌 현재 압력 계산 경로에서 실행 가능하다 (`3D2F/vf_vpdrdt.f:77,93–150`, `3D2F/vf_v1cal.f:357–360`). 근거는 [KF1-204](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KF1.md)이다. [11-04 대조 정정]

## 5. EOS↔압력 Picard 결합 루프 (신규)

`DO LL=1,MAXITR`에서 EOS·완화·유속·압력 계산을 반복한다. 기체셀 오차는 완화 이전 밀도로 계산한다. 내부 셀 밀도에 완화를 적용한다. `VF_V1CAL` 호출 뒤 `IF(SERR.LE.SERROR) EXIT`를 적용한다. 기본 `MAXITR=1`이다 (`3D2F/vf_a1main.f:1347–1386`, `3D2F/vf_a2dflt.f:48`). 근거는 [KD1-897](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KD1f.md)이다. [11-04 대조 정정]

`TNOW`는 LL 반복 전에 증가한다. 최대 횟수 소진 시 수렴 성공을 보장하는 별도 검사는 없다. 근거는 [2f-program §4의 KF2-007·027·342 수정안](../../../_staging/recovery/compare/cadmas-2f-manual-program-vs-code.md#4-노트-대조와-수정안)이다. [11-04 대조 정정]

## 7. 기액 경계정합 + 음향 CFL 무시

- `VF_CSET2F`(헤더 `気相と液相の境界条件の整合性を調整` `vf_cset2f.f:5`) — 기상↔액상 경계조건 정합.
- 시간 간격 루틴은 실제 `RHOG` 대신 상수 `RHO0(1/2)`의 FF 혼합밀도를 열확산 제한에 쓴다. 기상 경계 유량도 이류 제한에 포함한다. 음향 파속 제한식은 두 사본의 diff에 추가하지 않는다 (`3D2F/vf_cdtcal.f:75–89,115–145`). 근거는 [KD1-898](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KD1f.md)이다. [11-04 대조 정정]

물성을 한 값만 주면 기체에 액체 값을 복사한다 (`3D2F/vf_iimate.f:41–47,55–61`). 기체 초기값은 `MATE I.C. VG`와 `MATE I.C. KG`로 지정한다. 기체 경계 선택자는 `VG`·`KG`·`EG`이다 (`3D2F/vf_iimate.f:118–140`, `3D2F/vf_iiboun.f:153–156,264–267,310–313`). 근거는 [KU1-222·800·801](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KU1.md)이다. [11-04 대조 정정]

`PORO-BC`·`MAX-VELOCITY`·`FILE MAM`·`SEA-BOTTOM`·좌표계 입력은 2F A11111의 누락 항목이다. 해당 구현은 아래 KU1-802·807·808·810·811에 기록한다. 근거는 [tutorials-build §4](../../../_staging/recovery/compare/cadmas-tutorials-build-vs-code.md#4-노트-대조와-수정안)이다. [11-04 대조 정정]
