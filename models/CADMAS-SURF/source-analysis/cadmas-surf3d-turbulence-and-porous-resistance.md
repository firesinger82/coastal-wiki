# CADMAS-SURF/3D 난류·포러스 저항·파력

> 세 서브시스템: **(A) k-ε 2방정식 난류**(표준 Launder-Spalding), **(B) 포러스 body 저항**(Morison 2차 drag + 가상질량 관성 — 소파블록/투과방파제), **(C) 파력 적분**(구조물 표면압 -P·dS). 경로 루트 → [architecture-source-map](cadmas-surf3d-architecture-source-map.md).

## B. 포러스 body 저항 (소파블록·투과방파제)

CADMAS 의 투과성 소파구조 모델링 핵심. 두 부분으로 분리:

**(B-1) 2차 drag 力 (Morison형)** — `VF_VGENE`(헤더 `流速に関する生成消滅項` `vf_vgene.f:7`, [SMAC 단계②](cadmas-surf3d-smac-velocity-pressure-solver.md#1-smac-시퀀스-vf_v1calf-드라이버)). x운동량:
```
vf_vgene.f:108 :  UVW = SQRT(U*U+V*V+W*W)
vf_vgene.f:110 :  QU = QU - 0.5*CD*XX(5,I)*(1-GGX(I,J,K))*U*UVW
```
x면 이차 저항은 `-\frac{C_D(1-\gamma_x)u\sqrt{u^2+v^2+w^2}}{2\delta x_i}`이다(`3D/vf_vgene.f:109–110`, 3D manual p.11·31). y·z도 각 중심 간격으로 나눈다(`3D/vf_vgene.f:186·262`). CD는 셀 중심 CD0를 면으로 보간한 값이다(`3D/vf_vgene.f:92·168·244`). [11-04 대조 정정]
- **대안 Dupuit-Forchheimer 저항법칙**(`IDRGN>0` 분기, `vf_vgene.f:111-`): α=`DRGAP`·β=`DRGBT`·돌직경 `DRGDR`(`VF_APHYSR.h:107-110`), 돌크기 테이블 룩업(`:122-124`). → CADMAS 는 2가지 포러스 저항 closure 제공(기본 2차 C_D / Dupuit-Forchheimer α·β).

**(B-2) 가상질량 관성(CM)** — 명시적 力이 아니라 **운동량 시간미분항을 곱하는 유효 공극** `GLV` 로 folding:
셀 중심 관성은 `GLV(I,J,K)=GGV(I,J,K)+(1.0D0-GGV(I,J,K))*CM0(I,J,K)`로 계산한다(`3D/vf_cglv.f:34`). 일반 x면은 `CM=XX(6,I)*(XX(2,I)*CM0(I,J,K)+XX(2,I-1)*CM0(I-1,J,K))`로 계수를 보간한다(`3D/vf_cglxyz.f:64`). 이어서 `GLX(I,J,K)=GGX(I,J,K)+(1.0D0-GGX(I,J,K))*CM`을 계산한다(:65). 장애물 셀·면의 GL은 1이다. 경계면은 유체 쪽 CM0 하나를 쓴다(`3D/vf_cglv.f:31–35`, `3D/vf_cglxyz.f:60–94`). [11-04 대조 정정]
전처리는 GLV와 면 계수를 설정한다(`3D/vf_a1main.f:723–725`). 속도·압력 하위 반복의 `IF (IPRNT.GT.1) THEN`에서 새 GGV0로 GLV0를 계산한다(:1052–1055). VF_V1CAL은 같은 조건에서 GLV와 GLV0를 교환한다(`3D/vf_v1cal.f:233–247`). 그 다음 면 계수를 다시 계산한다. [11-04 대조 정정]

> 관성·저항의 입력 키워드는 `POROUS CM`과 `POROUS CD`이다(`3D/vf_iiporo.f:191–239`, 3D manual p.118–119). 뒤에 시작점·끝점의 I,J,K와 계수를 쓴다. 배열 이름은 CM0와 CD0이다. 실제 대입 조건은 `IF (NF(I-IP,J-JP,K).NE.-1)`이다(:211·239). 두 배열은 3차원 배열이다(`3D/vf_a1main.f:65–66·234`). 두 배열의 최초 작업값은 0이다(:501–502). FILE L/P ON의 CM0와 CD0는 리스트 출력 선택이다(`3D/vf_iifile.f:101–104`). [11-04 대조 정정]

## C. 파력 적분 (구조물 작용 波力)

`VF_CFORCE`(헤더 `指定範囲内の流体と構造物間の波力を計算する` `vf_cforce.f:6`) — **drag 루틴이 아니라** 구조물 표면 압력적분 후처리. 6 방향력 `ISW=1..6`(`vf_cforce.f:25-31`)에 대해 유체/장애물(`NF=-1`) 계면면의 `−P·dS` 합산(`vf_cforce.f:75-77·101-103`), VOF 부분셀 `FF` 가중(`:78-97`), MPI reduce(`VF_P1SUMD` `:278`). **CM·CD·u|u| drag 항 없음** — 내파설계의 작용파력(방파제 케이슨 활동·전도 검토용) 산출이 목적.

## 물리상수 헤더

`VF_APHYSR.h`는 물리상수를 선언한다. GRZ0는 기본값 +9.8인 중력가속도 크기다(`3D/vf_a2dflt.f:163`, 3D manual p.10). z 운동량에는 `QW(I,J,K)=QW(I,J,K)-GV*GRZ0`으로 적용한다(`3D/vf_vgene.f:301`). 기존의 RHO0·ANU0·k-ε·Dupuit-Forchheimer·VVMAX 선언 위치는 `3D/VF_APHYSR.h:23–40·107–111`이다. [11-04 대조 정정]

> ⚠️ provenance 주의(서브에이전트 전제 교정): `vf_cforce.f`=파력 적분(drag 아님), 포러스 drag 는 `vf_vgene.f`. `VF_APARAR.h`=병렬분할 격자경계(물리상수 아님). 부력생성 `C₃ε` 항은 `GT=0` 으로 비활성.
