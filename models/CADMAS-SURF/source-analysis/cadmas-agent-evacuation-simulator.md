# CADMAS AGENT 쓰나미 피난 시뮬레이터

> AGENT는 STOC·CADMAS의 침수 자료를 직접 받는 격자 기반 potential-field 피난 모델이다(`AGENT/ReadMe.md:2`, `AGENT/read_cadmas.f90:195–205`). CADMAS에서 받는 `uu_c·vv_c`는 수직 적분 유량이다(`3D/vf_om1trn.f:80–88`). 모델 표지는 `agent_ver3.5`이다(`AGENT/main.f90:13`). MPMD 모델 번호 `l_mlt_agent`는 13이다(`AGENT/mod_comm.f90:26·41`). AGENT의 Fortran 파일은 40개이다. 기본 빌드 목록은 39개이다(`AGENT/Makefile:11–56`). [11-04 대조 정정]

## 1. 드라이버·시간루프 (main.f90 → solver.f90)

`AGENT/main.f90:17`은 `init_mpmd`를 호출한다. 이후 `read_condition`(:31), `read_agent`(:36), `allocate_potential`(:41), `read_potential`(:46), `read_cadmas(0)`(:51), `solver`(:61)를 순서대로 호출한다. [11-04 대조 정정]

실제 시간적분은 `AGENT/solver.f90:66–99`의 `do nstep=1,maxstep` 반복이다. `read_cadmas(1)`(:70), `update_rw`(:73), `make_potential_mob`(:78), `move_agent`(:83), `update_attribute`(:86), `output(1)`(:89)을 순서대로 호출한다. 종료문은 `if( time.ge.time_end .or. time_end-time.lt.eps) exit`이다(:97). `eps`는 `1.0d-10`이다(:17). 물리·입출력 모듈 8개는 `m_agent·m_cadmas·m_danger·m_potential·m_prob·m_flag·m_timectl·m_output`이다. 빌드 목록은 별도 통신 모듈 `mod_comm`을 포함한 모듈 파일 9개를 사용한다(`AGENT/Makefile:42–50`). [11-04 대조 정정]

## 2. 에이전트 모델 (m_agent·move_agent)

표현(`m_agent.f90:6-43`): 셀 `i/j_agent`·위치 `agent_x/y/z`·속도 `agent_u/v·vel`·**상태 `agent_status` 0=피난완료·1=이동·2=수중이동·3=사망**(`:17`)·`deadline`(허용 최대수심, 초과 시 사망 :21)·랜덤워크 `rw_sigma/theta/dt`·행동가중 `weight_signpost/shelter/mob/danger`·`agent_start`(출발시각). `vertical_evacuation_speed=0.479 m/s`(피난소 등반 :43). `agent_age·agent_height`는 할당·대입 후 고정속성으로 출력한다(`AGENT/m_agent.f90:95–103`, `AGENT/output.f90:54–57`). 이동 계산에는 사용하지 않는다. [11-04 대조 정정]

이동 루틴은 `if(time<=agent_start(n)) return`에서 전체를 반환한다(`AGENT/move_agent.f90:32`). 입력 순서상 뒤 사람의 이동도 해당 단계에서 계산하지 않는다. 피난완료·사망 상태는 건너뛴다(:43). 상태 2의 감속식은 `velocity=vel(n)*(1.0d0-depth(i_agent(n),j_agent(n))/deadline(n))`이다(:59). 방향 선택은 `get_direction`을 호출한다(:61). 표지와 랜덤워크는 그 뒤 방향을 바꾼다(:65–70). [11-04 대조 정정]

**예시 하이킹 함수**는 `if( n_slope==1 ) then` 경로에서 사용한다(`AGENT/move_agent.f90:74–104`). 원문 주석은 `! サンプル：ハイキング関数`이다(`AGENT/slope_function.f90:22`). 원문 식은 `F=1.191246*exp(-3.5d0*abs(S+0.05d0))`이다(:23). [11-04 대조 정정]

> `underwater_function.f90`의 수심비·유속비 감속표는 현재 실행 경로에서 호출되지 않는다. 기본 Makefile도 이 파일을 링크하지 않는다(`AGENT/underwater_function.f90:27–92`, `AGENT/Makefile:11–40`; agent:KA1-420, tutorials-build:KU1-818). 실제 감속은 `AGENT/move_agent.f90:59`의 수심 비례식이다. `weight_danger`는 할당하지만 `pot_total`에서는 사용하지 않는다(`AGENT/m_agent.f90:82–103`, `AGENT/pot_total.f90:20–32`). `read_danger.o`의 선행조건 행은 남아 있다. 대응 소스와 기본 빌드 대상은 없다(`AGENT/Makefile:11–56·85`; tutorials-build:KU1-907). [11-04 대조 정정]

## 3. potential-field 항법 (재귀 비용 완화) <!-- [11-04 대조 정정] -->

피난소별 지도는 8방향 비용 완화를 재귀 호출하여 만든다(`AGENT/recursive_search_shelter.f90:27–52·56–239`). 에이전트는 총 포텐셜의 최소값을 선택한다(`AGENT/get_direction.f90:27–40`). [11-04 대조 정정]

- `make_potential_shelter.f90`은 사면·연직 비용을 지도에 반영한다(`AGENT/make_potential_shelter.f90:70–80`). `n_potential(n,i,j)=-1.0d0/n_potential(n,i,j)`로 음수 역수 포텐셜을 만든다(:143). 음수 역수의 최소화는 역수의 최대화와 같은 선택 순서이다. 개인 속도를 반영하지 않은 시간 비교 문제는 agent:KA1-428에 해당한다. [11-04 대조 정정]
- `recursive_search_shelter`는 8방향 비용 완화를 재귀 호출한다(`AGENT/recursive_search_shelter.f90:27–52·56–239`). `pot_shelter(inext,jnext)=dnext` 대입 뒤 `call recursive_search_shelter(dnext,inext,jnext,ierr)`를 실행한다(:51–52). [11-04 대조 정정]
- flag0은 시작 셀의 비용이 최소인 피난소를 고른다(`AGENT/make_n_potential.f90:44–76`). 해당 피난소의 전체 지도를 그 사람의 지도에 복사한다. 셀마다 최근접 피난소를 다시 고르지 않는다. danger는 prob보다 우선한다(`AGENT/make_potential_shelter.f90:87–138`). 확률 모형에서는 WPprob가 RPprob보다 우선한다(:99·114). [11-04 대조 정정]
- `get_direction`의 원문 대각 보정은 `pot=(pot_total(n,i,j,ierr)-potnow)/root2+potnow`이다(`AGENT/get_direction.f90:95`). 전개식은 `U_next/√2+(1−1/√2)U_now`이다. [11-04 대조 정정]
- **`pot_total.f90`**: `n_potential·weight_shelter + pot_mob_revise·weight_mob`(:20-32)
- 표지 준수 추첨은 초기 사람·표지 쌍마다 한 번 정한다(`AGENT/make_signpost.f90:24–60`). 반경은 정수 셀 수로 절단한다. 표지 범위가 겹치면 뒤 표지 번호로 덮어쓴다. [11-04 대조 정정]
- 군중 지도는 셀 인원 수와 셀 거리를 쓴다(`AGENT/make_potential_mob.f90:20–59`). 사망 상태 3만 제외한다. 피난 완료 상태 0도 센다. 자기기여는 `pot_mob_revise(i,j)=pot_mob(i,j)+1.0d0/rr`로 제거한다(`AGENT/make_potential_mob_revise.f90:44`). [11-04 대조 정정]

## 4. CADMAS 결합 + 익사판정

- CADMAS는 수심과 수직 적분 유량을 전달한다(`3D/vf_om1trn.f:80–88`, `AGENT/read_cadmas.f90:195–205`). MPI 온라인 경로와 Fortran 순차 비서식 binary 파일 경로가 있다(`AGENT/read_cadmas.f90:61–149·193–249`). 파일은 `open(300+m,file=trim(cadfile(m)),status='old',form='unformatted',err=99)`로 연다(:102). [11-04 대조 정정]
- 원본 격자는 `xc·yc`로 나눈 직교 불등간격 격자이다(`AGENT/m_cadmas.f90:24–34`). `remesh`는 지형·수심·수직 적분 유량을 균일 에이전트 격자로 쌍선형 보간한다(`AGENT/remesh.f90:52–85·145–158·193–231`). 최대 수심은 `max_depth(ip,jp) = depth(ip,jp)`로 갱신한다(:195–197). [11-04 대조 정정]
- 일반 셀의 상태 갱신은 `if(agent_status(n)==1 .or. agent_status(n)==2)then`에 속한다(`AGENT/update_attribute.f90:28–94`). `if(depth(i_agent(n),j_agent(n))<=0.0d0) then`과 `elseif(depth(i_agent(n),j_agent(n))<deadline(n)) then`의 각 분기는 최대 수심 초과도 검사한다. 두 조건이 모두 거짓인 else에서는 상태 3으로 정한다. 피난소 셀은 그 전에 별도 높이 조건으로 처리한다. 높이 기준 혼용의 결함 후보는 agent:KA1-429에 해당한다. [11-04 대조 정정]

## 5. 확률·통계

- 방향 무작위 각도의 평균은 0이다. 표준편차는 `rw_sigma`이다(`AGENT/random_normal.f90:20–31`, AGENT manual p.29). [11-04 대조 정정]
- signpost 준수: Bernoulli(`random_number` vs `weight_signpost` :33-34)
- 출발시각 `agent_start`(에이전트별 입력)·확률 쓰나미회피(`m_prob` flag2)

## 6. 입출력·통신 보조 루틴 [11-04 대조 정정]

`mod_comm.f90`(MPMD)·`initialize.f90`(전루프 리셋)·`read_condition/agent/potential/move_boundary/shelter/signpost.f90`(입력)·`allocate_cadmas/potential.f90`·`output.f90`(binary agent.out+statistics csv)·`open_file.f90`(debug.txt)·`errmsg/errstop.f90`(mpi_abort).

> AGENT는 유체장 수신 갈래이다(`AGENT/ReadMe.md:2`, `AGENT/read_cadmas.f90:195–205`). 핵심 처리는 수심에 따른 상태 갱신, 예시 하이킹 함수, 재귀 비용 완화이다(`AGENT/update_attribute.f90:28–94`, `AGENT/slope_function.f90:21–23`, `AGENT/recursive_search_shelter.f90:27–52`). [11-04 대조 정정]
