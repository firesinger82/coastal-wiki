# CADMAS-STR(STR3D) 영문 매뉴얼 — FEM 이론·입력

Manual은 FEMAP 입력·운영 지침이다(`STR manual p.5·13–14`). [11-04 대조 정정]
Program Instructions는 구조·지반 정식화와 입력 지침이다(`STR instructions p.4·6·28·54`). [11-04 대조 정정]
CADMAS용 Program Instructions는 유체 측 연성 변수와 루틴 지침이다(`STR coupling instructions p.1·3–4·12–14`). [11-04 대조 정정]
Program Instructions의 본문 PDF p.4–54는 인쇄 p.1–51에 대응한다. [11-04 대조 정정]
Appendix 1–3의 PDF p.103–113은 인쇄 p.100–110에 대응한다. [11-04 대조 정정]
데이터 표는 `STR instructions p.55–94`에 있다. [11-04 대조 정정]
처리 흐름은 `STR instructions p.95–102`에 있다. [11-04 대조 정정]

이 노트의 `STR manual`, `STR instructions`, `STR coupling instructions`는 각각 `CADMAS-STR_Manual_English.pdf`, `CADMAS-STR_Program Instructions_English.pdf`, `CADMAS-STR_Program Instructions(CADMAS)_English.pdf`를 뜻한다.
`p.N`은 PDF 쪽이다.
코드의 `STR3D/`와 `3D2F/`는 각각 `Simulators/STR3D/Source code/`와 `Simulators/CADMAS-SURF-3D2F/Source code/`를 기준으로 한다.
본문 정정의 근거는 [KT1 최종 결론](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KT1b.md)의 KT1-844–850과 [KT2 최종 결론](../../../_staging/recovery/compare/CADMAS-SURF-conclusion-verify-KT2.md)의 KT2-576–580이다.

## 1. FEM 정식화 (Program Instructions §2)

- **지배식**은 `∇·σ+ρg=ρü`다(`STR instructions p.6`, 인쇄 p.3). 유효응력은 `σ′=σ+p·I`다. 반이산 구조계는 `[M]{Ü}+{F}−{F^p}={R}`다(`STR instructions p.8`, 인쇄 p.5, 식 ④). 강성 증분은 `{ΔF}=[K]{ΔU}`다. 강성행렬은 `[K]=∫[B]ᵀ[D][B]dV`다(`STR instructions p.9`, 인쇄 p.6). 감쇠항은 `C₁[M]{U̇}+C₂{Ḟ}`다(`STR instructions p.10`, 인쇄 p.7). [11-04 대조 정정]
- **시간적분 Newmark-β**는 3레벨을 쓴다(`STR instructions p.8`, 인쇄 p.5). β 범위는 `0.25≤β<0.5`다. 중간력은 `{F̃}=β{F}_{n+1}+(1−2β){F}_n+β{F}_{n-1}`다. 침투해석의 별도 α 범위는 `0≤α≤1`이다(`STR instructions p.15`, 인쇄 p.12). 코드의 β 기본값은 `RR(4)  = 1.D0/3.D0`다(`STR3D/main/main.f:45`). [11-04 대조 정정]
- **요소**는 solid CTETRA/CPENTA/CHEXA의 1차·2차 요소와 rod CROD 및 직사각 단면 beam CBAR를 포함한다(`STR instructions p.4·31–36`, 인쇄 p.1·28–33). PENTA 전단의 참고문헌은 MacNeal PENTA 메모다. [11-04 대조 정정]
- **구성식**은 선형탄성 MAT1과 bilinear 탄소성 MATS1을 포함한다(`STR instructions p.9·38`, 인쇄 p.6·35). MATS1의 YF=1은 von Mises 번호 1이다(`STR3D/input/Read_data/Rd_MATS1.f:11–13`). YF=4는 Drucker-Prager 번호 2다(`STR3D/input/Read_data/Rd_MATS1.f:17–18`). STR 판독기는 `IF( ALP == 0.D0 ) ALP = 7.D-2`를 적용한다(`STR3D/input/Read_data/Rd_MATS1.f:26`). 0이 아닌 ALP는 보존한다(`STR3D/input/Read_data/Rd_MATS1.f:27`). 재료 분류 0/1/2는 MAT(2,:)에 저장한다(`STR instructions p.63`; `STR3D/input/Set_table/St_MATS1.f:10–14`). Drucker-Prager 계수는 AMAT(13,:)에 저장한다(`STR3D/input/Set_table/St_MATS1.f:10–14`). Manual p.5의 문구는 `fixed at 0.07 regardless of the input value`다. 이 문구는 FEMAP의 NASTRAN 내보내기 문맥에 있다. beam은 von Mises만 쓴다. 인장균열을 지원한다. [11-04 대조 정정]
- **지반 Biot 압밀**은 u-p 완전결합을 쓴다(`STR instructions p.13–17`, 인쇄 p.10–14). Darcy 식은 `ẇ=k(−∇p+ρ_wg−ρ_wü)`다(식 ⑧). 질량보존식은 `∇·ẇ=−∇·u̇−C_fwṗ`다(식 ⑨). 결합계는 `STR instructions p.18`(인쇄 p.15)의 식 ⑮에 있다. KK(1)의 0/1은 동시법과 분리법을 구분한다(`STR instructions p.55`, 인쇄 p.52). porous 재료는 침투를 해석하지 않는다(`STR instructions p.20`, 인쇄 p.17). porous 재료의 압력은 CADMAS 셀에서 보간한다. [11-04 대조 정정]
- **접촉**은 MPC 변환 `{U}=[λ]{Ũ}`와 `K̃=[λ]ᵀ[K][λ]`를 쓴다(`STR instructions p.21–27`, 인쇄 p.18–24). master/slave 관입투영은 삼각면·사각면의 무게중심 절점·edge·point를 다룬다(`STR instructions p.24–25`, 인쇄 p.21–22). 마찰은 정마찰 μ₀와 동마찰 μ_d의 stick-slip 모델이다(`STR instructions p.27`, 인쇄 p.24). 소스에는 KK(96)의 arctangent 선택도 있다. [11-04 대조 정정]
- **유체결합**의 CADMAS 표면압은 `∫N_i p n dS`의 절점력으로 전달한다(`STR instructions p.103`, 인쇄 p.100). STR의 변형 절점 위치는 SEND_POS로 CADMAS에 전달한다. Total-Lagrange 대변형은 2nd PK 응력과 Green-Lagrange 변형률을 쓴다(`STR instructions p.106–113`, 인쇄 p.103–110). 접선강성은 `[K_L]+[K_NL]`이다. 입력은 `PARAM,LGDISP=1`이다. [11-04 대조 정정]

## 3. 입력 — NASTRAN bulk data (§3, PDF p.28–54; 인쇄 p.25–51) [11-04 대조 정정]

입력은 Case Control 뒤에 `BEGIN BULK`와 Bulk Data를 둔다(`STR instructions p.28–54`). [11-04 대조 정정]
카드는 절점 GRID, 요소 CTETRA/CPENTA/CHEXA·CROD·CBAR, 특성 PSOLID/PROD/PBARL, 재료 MAT1·MATS1, 구속 SPC1/SPC/SPCD, 정하중 FORCE/MOMENT/PLOAD4/GRAV, 동하중 DLOAD/TLOAD1/TABLED2, 접촉 BCTSET/BCTPARA/BSURFS, 제어 TSTEP·PARAM을 포함한다(`STR instructions p.28–54`). [11-04 대조 정정]
MATS1는 SY·ALP도 읽는다(`STR3D/input/Read_data/Rd_MATS1.f:7`). [11-04 대조 정정]
BCTPARA의 정마찰·동마찰 값은 공개 코드에서 6·8칸이다(`STR3D/input/Read_data/Read_data.f:840–843`). [11-04 대조 정정]
유체용 CADMAS 하위 키워드는 PART·PLOWER2·GMIN·FMIN이다(`3D2F/sf_rd_obst.f:155–163`). [11-04 대조 정정]
MID<100은 일반 재료다(`STR instructions p.37`). [11-04 대조 정정]
MID≥100은 지반재료다(`STR instructions p.37`). [11-04 대조 정정]
`-M` 기본 8000과 `-S` 기본 4는 명령행 기본값이다(`STR3D/main/getprm.f:6–28`). [11-04 대조 정정]
해석유형은 direct transient와 static 초기조건을 포함한다(`STR instructions p.4·55`). [11-04 대조 정정]
KK(2)는 기하비선형을 제어한다(`STR instructions p.55`). [11-04 대조 정정]
KK(80)는 재료비선형을 제어한다(`STR instructions p.57`). [11-04 대조 정정]
KK(1)는 지반결합을 제어한다(`STR instructions p.55`). [11-04 대조 정정]
분할은 METIS를 쓴다(`STR instructions p.4`). [11-04 대조 정정]
실행 구성은 MPMD를 포함한다(`STR manual p.18`). [11-04 대조 정정]
