- canonical 노트(concepts/models)는 KDS의 **특정 값·표번호를 인용**하고 여기로 링크 (예: 정온도 노트 → `kds-64/kds-64-40-10-수역시설.md` 해설표 4.3-1).
- KDS 변환본은 **원문 그대로**(요약·해석 아님) — 인용·검증의 1차 자료.
- 갱신: KDS 개정 시 해당 PDF 재변환.
