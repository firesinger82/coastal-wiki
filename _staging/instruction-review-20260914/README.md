**가장 먼저 바꿀 것은 모든 작업에 붙는 문서 읽기와 모호한 중단 규칙이다.** 사용자가 제공한 Eric Provencher의 글을 기준으로 저장소 진입 지침 2개, 로컬 스킬 2개의 설명·관련 규칙, 현재 검토 프롬프트를 확인했다. 모델 전수 감사나 설치된 모든 플러그인 감사로 확대하지 않았다.

공식 [GPT-6 Astra 지침](https://developers.openai.com/api/docs/guides/latest-model)의 Instruction following·Initiative and follow-through·Testing and verification 절도 지침 충돌 점검, 요청한 결과까지 지속, 변경에 맞는 검사를 권한다. 이 권고는 아래 수정 방향의 참고 근거다. 모델 성능 향상을 이유로 과학 주장 검증이나 기존 사람 승인 조건을 없애는 근거로 사용하지 않는다. 사용자 제공 글의 원문 전체는 복제하지 않았다.

## 검토할 수 있는 변경안

[proposed-instructions.patch](proposed-instructions.patch)는 AGENTS.md와 CLAUDE.md만 바꾸는 적용 가능한 초안이다. **미적용** 상태이며 [basis.json](basis.json)에 원본 SHA를 기록했다. 이번 추가 입력을 지침 점검 요청으로 해석했고, 영구 운영 규칙 변경까지 확정된 것으로 보지는 않았다. 별도 스킬 개정·모델 선택·전역 설정 변경은 이 패치에 포함하지 않는다.

패치는 다음 원칙을 유지한다: 객관 주장 출처, AI 요약 구분, 단일 writer, 사용자 지시 우선, MPI/Jumpshot 내부로 범위 이탈 금지, 고정된 전체 감사 범위와 사람 게이트. 큰 변경의 기존 검토 절차도 유지한다.

## 앞으로 사용할 작업 프롬프트

긴 과거 진행 이력 대신 목표·대상·완료 조건·필수 제한을 명시한다. 이번 실제 다음 작업 예시는 다음과 같다.

> ADCIRC 조석 입력 두 노트의 입력 순서·단위·위상/시간 기준과 ETRF 설명을 원문에 대조하고 정정안을 작성하라. 두 노트와 필요한 원문 구간에 한정하고 외부 DB 규약은 근거 미확보 시 미확정으로 표시하라. 발견한 모순을 정정안에서 해소하고 변경에 맞는 검토를 마칠 때까지 진행하라. 적용되는 별도 승인 조건이 있으면 검토 가능한 변경안을 먼저 완성하고 그 단계에서 필요한 결정을 요청하라. 모델 전체 감사·부속 의존성 조사로 확대하지 말라.

이미 끝난 검토를 같은 내용으로 다시 돌리는 지시는 추가하지 않는다. 기존 모델 준비 상태 조사와 검토 결과는 [별도 보고서](../model-readiness-20260913/README.md)에 보존한다.
