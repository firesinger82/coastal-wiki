# ADCIRC 기능 지도와 조석 입력 근거 범위

사용자 승인: 직전 다음 단계(ADCIRC 기능 지도·근거 상태·조석 입력 품질/검증 근거 범위)에 대해 진행 지시. Claude는 claude-fable-5-1만 사용한다.

산출물: 기존 source-analysis/adcirc-topic-map.md를 공식 기능 분류와 기존 노트 연결을 담는 기능/근거 지도로 갱신, models/ADCIRC/README.md에 탐색 포인터, 기존 조석 노트에 필요한 경우 입력 품질/실행·수치·물리 검증 확인 방법 링크 보강. 이번에는 외부 데이터 세트나 케이스가 지정되지 않았으므로 실제 자료 품질, 실행, 수치/물리 검증은 미수행이며 기준/확보할 근거를 구체화한다. 기능마다 별도 문서를 양산하지 않는다.

조사: 공식 ADCIRC 기능 개요·사용자 가이드 분류·현재 문서의 해당 절을 확인하고, 로컬 소스 HEAD 및 기존 61개 노트의 근거 위치/갭을 연결한다. 전체 노트 재감사나 원자료 전량 판독으로 확대하지 않는다. 각 기능 포함/보류/대상외 이유, 문서지원/코드구현/실행확인/수치검증/물리검증/입력품질 수준을 분리. 문서 사이트와 코드 snapshot 판본 불일치를 숨기지 않는다. 입력 형식/노드순서/위상/시간 조석 정정은 이미 적용되어 재사용한다.

과거 노트 verified/HG를 새 주장에 상속하지 않는다. 새 지도는 검토 범위와 갭을 밝히고 source-needed를 사용할 수 있다. 기능 부재를 노트 부재로 단정하지 않는다. 비교노트 생성, 다른 모델, 옛 감사 재개, MPI/Jumpshot 내부, 실제 계산/개인결과의 wiki 저장은 범위 밖. 기존 plan.md 미커밋 6줄과 interfaces-20260912는 보존/커밋 제외.

완료: 공식 분류 대응과 기존 근거/미확인 수준이 있는 지도, 조석 입력의 구체적 확인 항목·출처·다음 수행 경계, Fable 실제모델 확인 및 독립 검토, 변경 링크/frontmatter/필수 훅 검사, 정확한 대상만 반영 후 commit/pull/push.
