## 범위와 산출물

1. 기존 `models/ADCIRC/source-analysis/adcirc-topic-map.md`를 기능·근거 지도로 갱신한다. 과거 토픽 순서표는 git 이력과 before 사본으로 보존하고 현재 준비 상태로 남기지 않는다. 신규 지도는 `citation_status: source-needed`; 과거 verified/사람 승인은 새 주장에 상속하지 않는다.
2. `models/ADCIRC/source-analysis/tide/adcirc-tide-harmonic-prep.md`에 입력 품질·실행 확인·수치/물리 검증 확인 방법을 한정 보강한다. `adcirc-tide-forcing-implementation.md`에는 그 절의 탐색 링크만 둔다. 기존 다른 주장·미확정 DB 규약은 재검증된 것으로 취급하지 않는다.
3. `models/ADCIRC/README.md`에 기능 지도와 조석 확인 방법 포인터를 추가한다. 새 지도 때문에 이전 노트 수·종결 기록이 현재 검증 상태로 오해되지 않도록 역사적 집계임을 명시한다.
4. `_staging/adcirc-feature-map-20260914/`에 계획·원문 범위/해시·61개 기존 노트 대응·후보·검토·적용 기록을 둔다. plan.md는 현재 포인터만 갱신하며 기존 미커밋 6줄은 보존·커밋 제외한다.

## 단계와 완료 조건

1. 원문 선정 범위·해시와 노트 인벤토리를 고정한다. 준비된 발췌와 원문으로 본문을 작성한다.
2. 지도 각 행에 기능·공식 분류·포함/보류/대상외와 이유·판본·문서지원/코드구현 확인 한계·미해결 내용을 적는다. 실행확인·수치검증·물리검증·개별 입력품질은 이번 미수행으로 공통 표시하되 공개 근거 위치/판독 여부는 별도로 남긴다.
3. 조석에는 분조·노드순서·단위·기준면·시각뿐 아니라 자료 범위/해상도/결측/오차, 변환/보간의 독립 확인, 노달보정 중복, 입력/출력 규약과 관측 독립성·허용오차 미확정을 포함한다. 구체적 설정을 바꾸는 공식 개요 오류는 상세 정의·코드에 대조한 범위만 설명한다.
4. 공식 quarter-annular 회귀예제와 전지구 M2 예제, 수치 검증과 독립 관측검증의 서로 다른 역할을 명시한다. 기준파일 존재만으로 검증 완료라 하지 않는다.
5. Fable 5.1 실제 응답 모델을 확인하고 검토 지적을 반영한다. 정확한 변경 후보와 설치 manifest를 Codex로 최종 검토한다.
6. 변경 링크/frontmatter/해시와 필수 훅을 검사하고 승인된 좁은 파일 설치 후 commit → pull --ff-only → push한다. 새로 고친 부분의 필요한 검사만 반복한다.

완료는 위 지도·구체적 확인 방법·리뷰·반영까지다. 외부 조석 DB/관측자료 선정, 실제 실행, 해석해·관측 대조는 다음 별도 기능 작업이며 미수행으로 남긴다. 비교노트 생성·다른 모델·과거 전체 감사·MPI/Jumpshot 내부·개인 run 결과의 wiki 저장은 이번 대상외다.
