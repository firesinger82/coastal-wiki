## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 58–62: SPONGE_DAMPING의 MASK>ZERO 조건은 ETA 감쇠에만 적용한다. U·V 감쇠는 조건 밖이다.
- 132–146: TIDAL_BC_GEN_ABS 조건에서는 서쪽 조석 ETA/U/V를 입력장에 더한다. ETA의 SPONGE_TIDE_WEST 완화는 이 조건 밖에서 실행된다. U·V 완화 대입은 주석이며 HU·HV는 현재 U·V로 계산한다.
- 79·113–116: Phase_Ser를 가져오지만 이 변수를 포함한 시간 위상식은 주석이다. 실행 시간 위상식에는 Phase_Ser가 없다.
- 190–209·636–655·664–683·703–722·732–751: 감쇠계수 지수의 분자·분모는 정수 변수와 정수 리터럴로 구성된다. 분모는 Iwidth-1이다. 이 루틴들에는 Iwidth>1 검사 조건이 없다. CALCULATE_SPONGE_MAKER의 I 루프는 Iwidth를 상한으로 직접 사용한다(195).
- 223–395·405–580: 마찰·확산 루틴은 인수 R_sponge·A_sponge를 선언하지만 실행식에서 사용하지 않는다. DXg·DYg는 각각 대입된 뒤 이 두 루틴의 계산식에서 참조되지 않는다. xx는 지역 선언만 있다(249·431).
- 264–266·317–325·329–392: 마찰 스펀지는 처음 SPONGE·작업 배열 둘을 0으로 만든다. 동서 최댓값 결합 뒤 남북 계산에서도 같은 작업 배열을 재사용하며 그 사이 전체 0 초기화는 없다. 확산·일반 스펀지도 같은 작업 배열 재사용 구조이다(435–578·621–765).
- 435–436·448–511·570–578: 확산 스펀지의 SPONGE는 INTENT(INOUT)이다(428). 입력 SPONGE는 활성 방향의 lim에 사용되지만, 두 작업 배열은 0으로 시작하며 동서·남북 결합 루프는 방향 활성 조건 밖에서 SPONGE를 대입한다.
- 807–825·851–853·934: tmp_glob 할당·해제는 모든 프로세스에서 실행된다. PARALLEL 정의 쪽의 tmp_glob 전체 0 초기화·계수 계산은 프로세스 0 조건 안이다. 다른 프로세스의 국소 계수는 이후 mpi_irecv에서 받는다(915–922).
