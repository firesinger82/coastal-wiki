아래 항목은 이 LaTeX 원고 안에서 확인한 표기·서술 사실이다. 실제 Fortran 구현과 실행 결과는 확인하지 않았다.

- 208·715·1002·1006: Version 3.0 변경 이력과 프로그램 흐름 설명은 implicit iteration 또는 ITERATION 옵션을 제거했다고 적는다. Time stepping 문단은 source 갱신의 수렴을 위한 반복이 필요하다고 적는다.
- 277: V1 식의 대괄호 안에 `\eta A_{ t })`라는 닫는 소괄호가 있다. 이 부분 앞에는 대응하는 여는 소괄호가 없다.
- 322·343·350: 앞의 운동량식에는 `\ua \cdot \nabla \utwo`가 있다. eq22의 350행에는 `\ua \cdot \utwo`라고 적혀 있다.
- 470·474: 변환된 u 운동량식은 `= 0`으로 끝난다. 변환된 v 운동량식의 474행에는 등호와 우변이 없다.
- 788·790: L-D 감쇠계수 식은 `\gamma_x`를 사용한다. 바로 뒤의 자유 매개변수 설명과 권고값은 `\gamma_s`를 사용한다.
- 767·771: 오른쪽 마른 셀과 왼쪽 마른 셀의 파속식은 각각 L·R 상태를 사용한다. 두 식 모두 sL의 제곱근 계수는 -1이고 sR의 제곱근 계수는 +2이다.
- 297·1309: 이론 본문은 `\beta = 1 + \zeta = 0.47`이라고 적는다. 입력 `Beta\_ref` 설명은 기준면의 beta 매개변수라면서 `-0.531`을 적는다. 두 입력·기호가 실제 구현에서 대응하는 방식은 확인하지 않았다.
- 1070·1139: 재시작 설명의 키 표기는 `INI\_UVZ`이다. 초기조건 목록의 키 표기는 `INT\_UVZ`이다.
- 1185·1231: WK_REG 설명은 `Time\_ramp (factor of period)`라고 적는다. 개별 항목 설명은 `time ramp (s)`라고 적는다.
- 1199·1228: Gaussian 초기 융기(hump)의 조파기 목록 값은 `GAUSIAN`이다. WID 설명은 조건 값으로 `INI\_GAU`를 적는다.
- 208·1263: Version 3.0 변경 이력은 주기 경계를 병렬 코드에 구현했다고 적는다. 입력 설명은 남북 주기 경계에 `ONLY FOR SERIAL CODE IN THE PRESENT VERSION.`이라고 적는다.
- 1036·1420·1461: 컴파일 목록과 중첩 입력 주석의 플래그는 `-DCOUPLING`이다. 중첩 절차 첫 항목의 표기는 `-Dcoupling`이다.
- 1062·1317·1319·1326·1534–1536: 입력 설명은 이름의 대소문자를 구분한다고 명시하고 `FRICTION\_MATRIX`, `FRICTION\_FILE`, `Cd\_fixed`를 나열한다. 해변 쇄파 예제는 `Friction\_Matrix=F`, `Cd\_file= cd.txt`, `Cd = 0.0`을 적는다.
- 1337·1540·1664: CONSTRUCTION 설명은 `HLL`일 때 HLL, 그 외는 평균 방식이라고 적는다. 예제의 값은 `HLLC`이다.
- 1333·1663: 공간 차수 옵션 목록은 `THIRD`를 적는다. 무작위파 예제의 대입문은 `HIGH\_ORDER = THRID`이다.
- 1362·1547: 관측점 입력 설명은 `STATION\_FILE`을 적는다. 해변 쇄파 예제는 `STATIONS\_FILE`을 적는다.
- 1379·2097: 최대 수면 출력 키 목록은 `HMAX`를 적는다. 원뿔 섬 예제는 `Hmax = T`를 적는다.
- 1774·1808–1809: Vincent·Briggs 예제 본문은 격자 크기를 `760 x 500`으로 적는다. 같은 예제 입력은 `Mglob = 760`, `Nglob = 501`을 적는다.
- 1786–1796: 비쇄파 그림 파일 `vincent_briggs_nobrk.eps`의 label은 `vincent_briggs_vis`이다. 쇄파 그림 파일 `vincent_briggs_vis.eps`의 label은 `vincent_briggs_nonbrk`이다. caption은 각각 비쇄파·쇄파라고 적는다.
- 2093·2100: 원뿔 섬 예제의 NumberStations는 16이다. 뒤 문장은 `seven gauges`와 저장 범위 `sta\_0001 ... sta\_0016`을 함께 적는다. 같은 문장은 비교 파일에 `sta\_0022 (gauge 22)`도 적는다.
- 2227·2279·2328: 중첩 예제 본문은 초기 고립파 진폭을 `1m`로 적는다. Grid_A·Grid_B 입력은 모두 `AMP = 0.1`을 적는다.
- 1343·1345·2379: 입력 목록은 MinDepth를 젖음·마름 최소수심, MinDepthFrc를 마찰 제한 최소수심으로 설명한다. 불안정 대응 문단은 MinDepthFrc를 `wetting-drying threshold`라고 적고 기본값 `0.001 m`를 제시한다.
- 285·290·2618·2633·2652–2656: 이론 본문은 와도 보정을 omega2로 적는다. Appendix A는 U3·V3에 omega1을 사용하고 omega1을 별도로 정의한다.
