## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 17·351–365: TriSolver는 parameter 값 0이다. cuSPARSE 생성·파괴 루틴의 실행 조건은 TriSolver==1이다.
- 45–49·243–259: DX_d·DY_d 선언은 CARTESIAN 정의 시 스칼라이다. ESTIMATE_DT_GPU의 CARTESIAN 미정의 분기에는 DX_d(I,J)·DY_d(I,J) 접근이 있다. 70행의 CARTESIAN 미정의 경로에서 배열 이름은 Dx_d·Dy_d이다. [10-17 전수 검증 정정]
- 232–234: CelerityTmp와 DT_tmp 관련 작업 변수를 선언한다. CelerityTmp는 이 루틴의 실행식에서 사용되지 않고 참조 예시만 주석으로 남아 있다(242).
- 23·367–371: TotalKernelTime은 save 변수로 선언되어 출력된다. 이 파일에는 TotalKernelTime에 값을 대입하는 실행문이 없다.
- 309–323: cudaGetDeviceCount와 cudaGetDeviceProperties의 반환값은 ierr에 저장한다. 이 루틴에는 ierr를 검사하는 조건문이 없다.
- 383–385·408–410: 비교 출력은 j=100·200을 직접 접근한다. 해당 접근 앞에는 Nloc>=200 조건이 없다.
