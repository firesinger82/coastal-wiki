## 확인 범위와 집계

LaTeX 기록의 수정 구간 행은 38개이다.
그중 정정 표식이 있는 구간 행은 11개이다.
보완 표식이 있는 구간 행은 36개이다.
두 표식이 모두 있는 구간 행은 9개이다.
LaTeX 기록에서 수정하지 않은 구간 행은 69개이다.
두 Makefile 기록은 각각 8개 구간 행에서 이상이 없었다.
이 수들은 위 기록 표의 데이터 행과 수정 표식을 세었다.

모든 구간의 연속성과 원문 마지막 행까지의 범위를 확인했다.
기록의 frontmatter와 구간 경계는 변경하지 않았다.
각 원문의 SHA-256은 기록 frontmatter의 값과 일치했다.
수식의 세로줄에 사용한 Markdown 표 이스케이프는 원문의 세로줄로 대조했다.
원문에 없는 C 전처리 조건이나 CUDA·ACC·OMP 지시의 적용을 추정하지 않았다.
모델을 실행하지 않았다.
원문·노트·git은 수정하지 않았다.
