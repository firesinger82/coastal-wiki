# FUNWAVE 코드 전수 검증 — code-18

각 기록의 frontmatter `file:`이 가리키는 원문을 구간별 `nl -ba <원문> | sed -n 'A,Bp'`로 대조했다.
각 원문 출력은 200행 이하로 열었다.
대조한 행 수는 기록의 구간 표 행 수이다.
원문 행 수는 각 구간에 포함된 원문 행 수의 합이다.
정정과 보완은 각 유형이 붙은 구간 표 행 수로 센다.
하단 코드 사실 항목의 수정은 해당 구간의 정정에 포함한다.
한 구간에 두 유형이 있으면 각각 한 건으로 센다.
이상 없음은 두 유형 모두 없는 구간 표 행 수이다.
원문·노트·git은 수정하지 않았다.
모델은 실행하지 않았다.
