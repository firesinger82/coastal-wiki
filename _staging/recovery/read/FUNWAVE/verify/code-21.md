# FUNWAVE-TVD 판독 기록 전수 검증 — code-21

원문은 각 기록의 frontmatter `file:` 경로를 따른다.
원문은 기록의 구간마다 `nl -ba <원문> | sed -n 'A,Bp'`로 열었다.
한 번에 연 원문 구간은 200행 이하이다.
집계 단위는 판독 표의 구간 행이다.
정정은 기존 오류를 고친 구간 행 수이다.
보완은 기존 오류 없이 누락을 채운 구간 행 수이다.
정정 구간에 함께 넣은 누락 보완은 정정으로 집계한다.
정정과 보완을 함께 적용한 구간에는 두 표식을 모두 붙였다.
이상 없음은 수정하지 않은 대조 완료 구간 행 수이다.
모델을 실행하지 않았다.
판독 표의 구간 행 105개를 모두 대조했다.
해당 구간의 원문 행 수 합계는 3,463행이다.
구간 경계와 frontmatter는 수정 전과 같다.
원문 파일의 SHA-256은 각 기록의 값과 일치한다.
행 번호를 붙인 백틱 인용은 해당 원문 행과 대조했다.
대상 원문에는 CUDA Fortran·OpenACC·OpenMP 지시가 없다.
판독 표 아래의 코드 사실 목록도 해당 원문과 대조했다.
원문·노트·git은 수정하지 않았다.
