# FUNWAVE 판독 기록 전수 대조 — code-20

대상은 사용자 지정 판독 기록 5개이다.
각 기록의 `file:` 원문을 `nl -ba <원문> | sed -n 'A,Bp'`로 구간마다 열어 대조했다.
각 원문 출력은 200행 이하로 제한했다.
구간 경계와 frontmatter는 유지했다.
모델은 실행하지 않았다.

기록 경로의 기준은 `_staging/recovery/read/FUNWAVE/FUNWAVE-TVD/src/`이다.
대조한 구간 행 수는 각 기록의 구간 표에서 센다.
원문 행 수는 각 구간의 끝 행에서 시작 행을 빼고 1을 더한 값의 합이다.
정정과 보완은 각각 해당 표지가 붙은 구간 행 수로 센다.
같은 구간에 두 표지가 있으면 두 항목에 각각 센다.
