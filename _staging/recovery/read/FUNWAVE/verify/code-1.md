# FUNWAVE 코드 판독 기록 전수 검증 — code-1

대상 기록의 `file:`이 지정한 원문을 구간별로 대조했다.
원문은 `nl -ba <원문> | sed -n 'A,Bp'`로 구간마다 열었다.
아래 원문 행 수에는 빈 행과 주석 행을 포함한다.
정정 수와 보완 수는 각 표시가 붙은 본문 행 수다.
구간 표 아래의 후속 사실 행도 정정·보완 수에 포함한다.
한 본문 행에 두 표시가 있으면 정정과 보완에 각각 센다.
이상 없음 수는 수정하지 않은 구간 행 수다.
기록 경로의 공통 접두사는 `_staging/recovery/read/FUNWAVE/FUNWAVE-GPU/src/`다.
아래 집계의 합계는 기록 11개와 구간 134행과 원문 3,498행이다.
각 기록의 frontmatter와 구간 경계를 유지했다.
대상 원문 11개의 SHA-256은 작업 시작 때와 같다.
원문·노트·git은 수정하지 않았다.
모델은 실행하지 않았다.
