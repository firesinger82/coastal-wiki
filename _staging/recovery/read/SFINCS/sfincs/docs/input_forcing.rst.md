| 1–20 | User manual - forcing / Overview — 여러 텍스트·바이너리 입력 파일을 주 입력 파일에 연결한다고 설명한다(7–11). HydroMT-SFINCS 설정 함수 예제에 대한 NOTE를 포함한다(13). 그림 지시문·폭·정렬·캡션을 포함한다(15–19). 그림을 직접 열었다(15). 그림은 전체 입력 파일과 Domain·Model settings·Forcing·Structures 상자를 보인다. 그림은 초록색을 필수 파일, 주황색을 선택 파일로 표시한다. 모델 설정의 시간·출력 옵션은 초록색이고 수치 매개변수는 주황색이다. Forcing 상자의 화살표는 Water levels·Discharges·Meteo 상자를 향한다. 적어도 한 종류의 외력을 주도록 적는다. 그림 내부 문구: `green is required file` (15행 그림 내부); `orange is optional` (15행 그림 내부); `Force at least one type:` (15행 그림 내부); `Time and output options` (15행 그림 내부); `Numerical parameters` (15행 그림 내부). Domain의 격자 특성은 `in sfincs.inp`, 활성 셀은 `mskfile`, 표고는 `depfile (*)`, 셀 색인은 `indexfile (**)`, subgrid 표는 `sbgfile (***)`로 표시한다(15행 그림 내부). Domain의 선택 입력은 초기 수위 `inifile`, 재시작 `rstfile`, 거칠기 `manningfile`, 일정 침투 `qinffile`, Curve Number 침투 `scsfile`, 관측점 `obsfile`로 표시한다(15행 그림 내부). 조건 문구: `(*) only required for regular mode` (15행 그림 내부); `(**) only required if inputformat=bin` (15행 그림 내부); `(***) only required for subgrid mode` (15행 그림 내부). Structures는 thin dam `thdfile`, levee `weirfile`, pump/culvert `drnfile`을 주황색으로 표시한다(15행 그림 내부). Water levels는 위치 `bndfile`과 시계열 `bzsfile` 또는 `netbndbzsbzifile`을 보이고 Waves는 시계열 `bzifile`을 보인다(15행 그림 내부). Discharges는 위치 `srcfile`과 시계열 `disfile` 또는 `netsrcdisfile`을 보인다(15행 그림 내부). Meteo는 spiderweb, 격자, 공간 균일, gridded netcdf-FEWS 형식을 `or`로 구분한다(15행 그림 내부). 원문: `The input for SFINCS is supplied using various text and binary files, which are linked through the main input file: sfincs.inp.` (7); `Below an example is given of this file, which uses a keyword/value layout. ` (10); `For more information regarding specific parameters see the pages 'Input parameters' or 'Output parameters'.` (11); `**NOTE - In the manual below, blocks named 'Python example using HydroMT-SFINCS' are included, referring to easy setup functions of the HydroMT-SFINCS Python toolbox: https://deltares.github.io/hydromt_sfincs/latest/**` (13); `.. figure:: ./figures/SFINCS_documentation_forcing.png` (15); `   :width: 800px` (16); `   :align: center` (17); `   Overview of input file of SFINCS with indication whther they are required or not` (19). |

| 31–42 | Water levels — 수위 시계열을 줄 경계 셀의 입력 위치를 먼저 지정한다고 적는다(34). 각 경계점은 가장 가까운 두 입력 위치의 가중 평균으로 보간한다고 적는다(35). 그림 지시문·폭·정렬·캡션을 포함한다(37–41). 그림을 직접 열었다(37). 그림은 5열·5행 격자와 오른쪽으로 향하는 x축, 위로 향하는 y축을 보인다(37행 그림 내부). 상태 범례: `0=inactive` (37행 그림 내부); `1=active` (37행 그림 내부); `2=boundary` (37행 그림 내부); `3=outflow` (37행 그림 내부). 맨 위 행은 모두 0이다. 중간 세 행의 왼쪽 네 열은 1이다. 오른쪽 열의 위쪽 두 경계 셀은 2이다. 맨 아래 행의 왼쪽 네 셀은 3이고 오른쪽 열의 아래 두 셀은 0이다(37행 그림 내부). 주황색 화살표는 `bnd 01`과 `bnd 02`에서 위쪽 2 셀로 향하고 `bnd 02`와 `bnd 03`에서 아래쪽 2 셀로 향한다(37행 그림 내부). 그림에는 가중치의 수식이나 수치가 적혀 있지 않다(37행 그림 내부). 원문: `To specify water-level time-series to the boundary cells (msk=2), first the input locations have to be specified in 'sfincs.bnd'.` (34); `For every boundary point there is interpolated with a weighted average between the two closest input locations.` (35); `.. figure:: ./figures/SFINCS_boundary_input_grid.PNG` (37); `   :width: 400px` (38); `   :align: center` (39); `   Example of the weighted interpolation of boundary input locations to the msk=2 boundary cells.` (41). |
