Domain의 grid characteristics는 `in sfincs.inp`, (in)active cells는 `mskfile`, elevation은 `depfile`, cell indexation은 `indexfile`, subgrid tables는 `sbgfile`이다. 해당 항목은 녹색이다. 선택 항목인 varying initial waterlevel·restartfile·varying roughness·constant infiltration·curve number infiltration·observation points는 각각 `inifile`·`rstfile`·`manningfile`·`qinffile`·`scsfile`·`obsfile`이다. 그림의 적용 조건 원문은 `(*) only required for regular mode`, `(**) only required if inputformat=bin`, `(***) only required for subgrid mode`이다. 별표들은 각각 depfile·indexfile·sbgfile에 붙어 있다. Model settings는 sfincs.inp의 `Time and output options`를 녹색, `Numerical parameters`를 주황색으로 표시한다. Forcing 상자는 `Force at least one type:`라는 조건 아래 waterlevels and waves·discharges·wind, pressure, rain을 열거한다. 화살표는 Forcing에서 아래의 Water levels·Discharges·Meteo 상자로 갈라진다. Water levels의 input locations·time-series는 `bndfile`·`bzsfile`이고 대안은 `Netcdf_FEWS format:`의 `netbndbzsbzifile`이다. Waves의 time-series는 `bzifile`이다. Discharges의 input locations·time-series는 `srcfile`·`disfile`이고 대안 Netcdf_FEWS 입력은 `netsrcdisfile`이다. Meteo는 `Spiderweb (/incl rain): spwfile`, `Gridded wind: amufile + amvfile`, `Gridded pressure: ampfile`, `Gridded rain: amprfile`, `Uniform wind: wndfile`, `Uniform rain: precipfile`, `Gridded netcdf-FEWS format:`의 `netamuamvfile`·`netampfile`·`netamprfile`을 or로 구분하여 제시한다. Structures는 선택 입력으로 `Thin dam: thdfile`·`Levee: weirfile`·`Pump/culvert: drnfile`을 표시한다. 그림에 좌표축과 수식은 없다. 원문: `The input for SFINCS is supplied using various text and binary files, which are linked through the main input file: sfincs.inp.` (7); `Within this section of the user manual all different types of structures to reduce flood hazards with input settings and files are discussed.` (8); `The figure below gives an overview of all different types of input files and whether they are required or not.` (9); `Below an example is given of this file, which uses a keyword/value layout. ` (10); `For more information regarding specific parameters see the pages 'Input parameters' or 'Output parameters'.` (11); `**NOTE - In the manual below, blocks named 'Python example using HydroMT-SFINCS' are included, referring to easy setup functions of the HydroMT-SFINCS Python toolbox: https://deltares.github.io/hydromt_sfincs/latest/**` (13); `.. figure:: ./figures/SFINCS_documentation_structures.png` (15); `   :width: 800px` (16); `   :align: center` (17); `   Overview of input file of SFINCS with indication whther they are required or not` (19). |

The discharge rate is defined using the par1 parameter.` (145); `For culverts, par1 represents the discharge capacity. This gradient determines how much water flows through the culvert based on the capacity defined in par1.` (147); `The check valve requires the same par1 discharge capacity input as a culvert, but only allows flow in one direction, preventing backflow (e.g. for a one-way tide gate). | 203–219 | Calculating Culvert Discharge Capacity — culvert의 par1 capacity 식을 제시한다(205–207). mu의 무차원 loss coefficient와 통상 범위, A의 개구 면적·단위, g의 중력 가속도·수치·단위를 설명한다(211–213). 문서는 Bernoulli Equation에서 head difference에 따른 흐름을 추정하는 식을 유도했다고 적는다(215). mu가 1일 때는 마찰·길이에 따른 손실 없이 head difference만으로 흐르고 mu가 1보다 작을 때는 추가 에너지 손실을 고려한다고 적는다(217–218). 식의 LaTeX·RST 백틱, 기호·범위·수치·단위·분기 조건을 그대로 옮긴다. 이 구간은 par1 자체의 단위를 적지 않는다. 원문: `For culverts, par1 (discharge capacity) can be calculated as:` (205); ``` ``par1 = \(\mu \cdot A \cdot \sqrt{2g}\)`` ``` (207); `where:` (209); `* \(\mu\) = dimensionless culvert loss coefficient, typically between 0 and 1` (211); `* \(A\) = area of the culvert opening (m²)` (212); `* \(g\) = gravitational acceleration (9.81 m/s²)` (213); `This formula is derived from the Bernoulli Equation, which estimates flow based on the head difference.` (215); `* If \(\mu = 1\), the flow is assumed to be driven entirely by the head difference, with no friction or length-based losses.` (217); `* If \(\mu < 1\), it accounts for additional energy losses, such as friction and entry/exit losses.` (218). |
