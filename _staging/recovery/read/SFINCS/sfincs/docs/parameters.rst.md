# parameters.rst — 판독 구간 기록

구간은 1행부터 680행까지 빈틈없이 이어진다. 빈 줄·절 밑줄·마크업·지시문도 해당 구간에 포함한다.

한국어 설명은 AI의 판독 설명이다. 원문 인용은 백틱 안에 해당 행의 내용을 그대로 옮겼다.
