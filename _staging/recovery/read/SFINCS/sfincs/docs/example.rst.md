# example.rst — 판독 구간 기록

| 1–17 | Setting up models / Introduction — 제목·구분선·빈 줄을 포함한다(1–6). 원문은 SFINCS 입력을 ASCII 텍스트 또는 이진 파일로 만들 수 있고, Fortran으로 작성된 모델의 입력 생성에는 텍스트 편집기·Matlab·Python을 사용할 수 있다고 설명한다(7–8). 모델 구성 도구 목록은 HydroMT와 hydromt_sfincs를 2023년부터 강하게 권장한다(9–11). 목록은 Matlab Delft Dashboard GUI와 Matlab Open Earth Toolbox 스크립트를 폐기 대상으로 표시한다(12·14). 목록은 Python Delft Dashboard GUI를 개발 중으로 표시한다(13). 맞춤 모델 구성은 연락을 요청한다(16). 원문: `SFINCS models can be set up using simple ascii text and/or binary input files, which can be generated on whatever platform suiting you as a user best.` (7); `* Python script framework called **'HydroMT'**, with its dedicated plugin **'hydromt_sfincs'** --> highly recommended to use since 2023` (11); `* Graphical User Interface (GUI) to make SFINCS models interactively: **'Delft Dashboard'** --> the Matlab DDB GUI is currently depricated` (12); `* Graphical User Interface (GUI) to make SFINCS models interactively: **'Delft Dashboard Python'** --> the Python DDB GUI is currently being developed` (13); `* Matlab scripts toolbox in the **'Open Earth Toolbox'** --> the Matlab OET scripts are currently depricated` (14). |
| 18–31 | HydroMT-SFINCS — HydroMT를 Python 명령행 대안으로 소개하고 Eilander et al. (2022)의 DOI를 적는다(18–21). 전 지구 DEM 외에 토지 이용 지도 기반 공간 가변 침투·Manning 조도 자료를 얻을 수 있다고 설명한다(22). 하천을 지형에 반영하거나 Wflow가 하천 유량 경계를 제공하는 오프라인 결합 모델을 구성할 수 있다고 설명한다(23). v2.0.0부터 component 기반 API로 바뀌었다는 주의문을 그대로 옮긴다(25). 플러그인·HydroMT·v2 이관·Python 모델 생성 예제 링크를 제공한다(27–30). 원문: `Besides globally available DEMs it can also retrieve spatially varying infiltration and manning roughness data based on landuse maps.` (22); `Also, it is possible to burn in rivers or setup a offline coupled model together with the hydrological Wflow model that will provide boundary conditions as river discharge.` (23); ```**NOTE - As of HydroMT-SFINCS v2.0.0, the API uses a component-based architecture. The old ``setup_*`` methods (e.g. ``setup_grid``, ``setup_dep``) have been replaced by component methods (e.g. ``sf.grid.create()``, ``sf.elevation.create()``). See the migration guide for details.**``` (25). |
| 32–38 | Delft Dashboard — Van Ormondt et al. (2020)의 DOI와 함께 SFINCS 모델 구성 GUI를 소개한다(32–35). Matlab 또는 독립 실행 파일로 실행할 수 있고, 전 지구 DEM을 이용하여 기본 모델을 대화식으로 구성한다고 설명한다(36). Python GUI로 변환하는 작업이 진행 중이라고 적는다(37). 원문: `The tool can be run on Matlab or as standalone executable and has all the basic functionality to setup your basic model using globally available DEMs in an interactive way.` (36); `In ongoing work, DDB is converted into a Python based GUI!` (37). |
| 39–46 | Executable — 미리 컴파일된 SFINCS를 직접 사용할 수 있다고 적는다(39–42). Windows 다운로드와 Docker를 통한 플랫폼 독립 실행 링크를 제시한다(44–45). 플랫폼 목록은 원문 그대로 옮긴다. 원문: `* Windows: https://download.deltares.nl/en/sfincs  ` (44); `* Platform independent through Docker (Windows/linux/singularity/HPC): https://hub.docker.com/r/deltares/sfincs-cpu ` (45). |
| 47–61 | Compiling yourself — Windows에서 개선 사항을 시험하려고 직접 컴파일하는 경우 Visual Studio와 Intel Fortran compiler가 필요하다고 적는다(47–50). 시험된 무료 조합의 제품 이름·버전을 제시한다(51–54). 설치·설정 후 로컬 컴파일과 기능 추가를 설명한다(56). GitHub checkout과 VS solution 파일 열기를 안내한다(57). GNU GPL-v3.0 라이선스에 따라 개선 사항을 pull request로 공유하라고 적는다(59). 원문: `If you want to compile SFINCS yourself for windows to test certain improvements, you need Visual Studio and an Intel Fortran compiler.` (50); `* Visual Studio Community 2022 - freely available from: https://visualstudio.microsoft.com/vs/community/` (53); `* Intel Fortran Compiler Classic and Intel Fortran Compiler for Windows* 2022.1.0 - freely available from: https://www.intel.com/content/www/us/en/developer/articles/tool/oneapi-standalone-components.html` (54); `Make a checkout of the SFINCS github page, and open the VS solution file to do this: https://github.com/Deltares/SFINCS/blob/main/source/sfincs.sln` (57); `To collaborate together and under the GNU GPL-v3.0 license SFINCS comes with, share any improvements with us as pull request on Github: https://github.com/Deltares/SFINCS/pulls` (59). |
| 62–67 | Running SFINCS — 로컬·HPC·클라우드 등 여러 플랫폼에서 실행할 수 있다고 적는다(62–65). Windows 배치 파일 실행을 가장 간단한 방법이라고 소개한다(66). |
| 68–85 | On windows (standard) / Using batch-file — 입력 파일 폴더에 배치 파일을 복사하고 실행 파일 경로를 맞추라고 설명한다(68–73). 일반 출력 텍스트를 sfincs_log.txt에 쓰는 run.bat 예제를 제시한다(73·78–84). 코드 지시문과 파일 생성 안내·명령을 그대로 옮긴다(80·82·84). 원문: `This batch file you copy to the folder where your input files to be used by SFINCS are located.` (72); `The batch file simply calls the executable (add the right path to the folder where sfincs.exe is located) and the general output text file is written to a new text file called 'sfincs_log.txt', see below for an example.` (73); `.. code-block:: text	` (80); `	make a text file called 'run.bat' and add here:` (82); `		call "c:\..\folder_where_exe_is_located\sfincs.exe">sfincs_log.txt	` (84). |
| 86–95 | On linux / Dedicated linux compiled version — Linux HPC 시스템에서는 Docker 또는 Singularity 실행을 일반적이고 성공적인 방법으로 설명한다(86–92). 전용 Linux 빌드가 필요한 경우 연락하면 해당 사용자를 위한 버전을 만들 수 있다고 적는다(93). Deltares 자체 클러스터에서의 경험을 원문 작성자가 언급한다(94). 원문: `Generally for Linux (HPC) systems, running using Docker or Singularity is the most generic and succesfull way.` (92); `In case you need a dedicated Linux build, get in touch and we can create a version specifically for you.` (93); `We have experience doing this for our own Deltares cluster.` (94). |
| 96–103 | Using Docker — Windows·Mac·Linux·클라우드 클러스터에서 최신 빌드를 이용하는 방법으로 Docker 컨테이너 실행을 소개한다(96–99). 로컬 데스크톱이나 Docker를 지원하는 클러스터에서 사용할 수 있고, Singularity 안내는 뒤에 있다고 적는다(100). Windows 실행 파일과 같은 GNU GPL-v3 라이선스를 적용한다고 적는다(102). 원문: `For always using the last build version of SFINCS on Windows, Mac, Linux or a cloud based cluster a convenient solution is running a Docker container version of SFINCS.` (99); `This can be done on a local desktop or in a cloud based cluster supporting docker (or using singularity, see below).` (100); `**Note that this Docker version of SFINCS is available under the same GNU GPL-v3 License as the windows executable.**` (102). |
| 104–125 | Local desktop version — 운영체제에 맞는 Docker Desktop 설치 후 모델 실행 예제를 제공한다(104–111). 컨테이너 가져오기와 입력 폴더 마운트 명령을 그대로 옮긴다(113·115). 마운트 경로가 SFINCS 입력 폴더라는 설명과 절대 경로 의무·Linux/Mac 경로 표기를 그대로 옮긴다(117·119·121). 자동 컴파일 최신 버전 대신 확인된 태그 릴리스를 가져올 수도 있다고 적고 Cauberg 릴리스 명령을 예시로 든다(123–124). 원문: `.. code-block:: text` (111); `	docker pull deltares/sfincs-cpu` (113); `	docker run -vC:/Users/../SFINCS:/data deltares/sfincs-cpu` (115); `	(here 'C:/Users/../SFINCS' is the folder where the SFINCS input files to be used are located)` (117); `	NOTE - you have to supply the full path, not a relative path!` (119); `	NOTE - For Linux/Mac you do the same, but write the path as /Users/../SFINCS/` (121); `Instead of using the latest automatically cmpiled version, you can also pull a verified tagged release from: https://hub.docker.com/r/deltares/sfincs-cpu/tags` (123); `This can be for instance the open source release version 'docker pull deltares/sfincs-cpu:sfincs-v2.0.3-Cauberg'.` (124). |
| 126–130 | Cloud based cluster — Docker 컨테이너 실행을 지원하는 클라우드 클러스터에서도 같은 원리를 사용할 수 있다고 적는다(126–129). 마지막 빈 줄까지 포함한다(130). 원문: `The same principle is also possible on a cloud based cluster that supports running docker containers` (129). |
| 131–158 | Using Singularity — Singularity를 지원하는 Surfsara·Azure·Amazon 같은 클러스터에서 Docker 컨테이너 버전 SFINCS를 직접 실행할 수 있다고 적는다(131–134). 적용 사례에 따라 컨테이너를 한 번 가져와 새 이미지로 저장하고 여러 번 실행하는 방법이 유용할 수 있다고 적는다(135–136). GNU GPL-v3 라이선스 안내를 반복한다(138). 즉시 실행 예제와 이미지 생성 후 실행 예제의 코드 지시문·명령을 그대로 옮긴다(140–153). 최신 자동 컴파일 버전 대신 확인된 태그 릴리스도 사용할 수 있고 Cauberg를 예시로 든다(155–156). 원문: `On cloud based clusters like Surfsara/Azure/Amazon that **supports singularity**, it is possible to run the Docker container version of SFINCS directly.` (134); `Depending on the application it could be wise to pull the docker container once and save as new image, after which this image can be run multiple times.` (135); `This prevents unnesissarily loading the Docker container every time a simulation is performed.` (136); `**Note that this Docker version of SFINCS is available under the same GNU GPL-v3 License as the windows executable.**` (138); `.. code-block:: text	` (142); `	Pulling and running the docker container immediately:` (144); `		singularity run -B$(pwd):/data --nv docker://deltares/sfincs-cpu` (146); `	First pulling the docker container and creating a singularity image, then running this image:` (149); `		singularity pull docker://deltares/sfincs-cpu sfincs-cpu.img` (151); `		singularity run -B$(pwd):/data sfincs-cpu.img` (153); `Also here, instead of using the latest automatically cmpiled version, you can also pull a verified tagged release from: https://hub.docker.com/r/deltares/sfincs-cpu/tags` (155); `This can be for instance the open source release version 'sfincs-v2.0.3-Cauberg'.` (156). |
| 159–169 | Courses learning SFINCS — 전문가가 모델 구성과 이론·철학을 설명하는 교육을 제공한다고 적는다(159–162). DSD 교육은 매년 계획되며 일정 확인 링크를 제공한다(164). 미국·캐나다 사용자의 Deltares USA 온라인 교육 링크를 제공한다(166). 일정이 맞지 않거나 고급 교육을 원하면 맞춤 교육을 위해 연락하라고 적는다(168). |
| 170–179 | Questions and support — Deltares가 프로젝트 기반 NGO이고 모델을 무료로 제공하므로 모든 질문을 끝까지 지원할 수는 없다고 적는다(170–173). 반복적으로 모델 구성 질문이 있는 경우 Software Service Package를 고려하라고 적고 software@deltares.nl을 제시한다(175–176). 전문가가 최초 모델 프레임워크를 구성하는 협업 문의 주소로 sfincs@deltares.nl을 제시한다(178). |
| 180–188 | Contributing / Documentation — 문서 코드의 GitHub 주소를 제시한다(180–186). 매뉴얼 개선 제안은 연락하거나 개선 pull request를 제출하라고 적는다(187). 링크가 실제로 열리는지는 이번 판독에서 확인하지 않았다. 원문: `The code of this documentation is available from https://github.com/Deltares/SFINCS/docs.` (186); `Get in touch if you have suggestions how to improve this manual, or put in a pull request with improvements yourself: https://github.com/Deltares/SFINCS/pulls` (187). |
| 189–195 | Code — SFINCS 코드가 16-11-2022부터 공개 소스라고 적고 코드 링크를 제공한다(189–192). 개발 참여를 원하면 연락하거나 GitHub 개선 pull request를 제출하라고 적는다(194). 마지막 빈 줄을 포함한다(195). 원문: `The SFINCS code is open source as of 16-11-2022, see: https://github.com/Deltares/SFINCS/source` (192); `Get in touch if you would like to join us in developing the SFINCS code, or put in a pull request on Github with improvements yourself: https://github.com/Deltares/SFINCS/pulls` (194). |
