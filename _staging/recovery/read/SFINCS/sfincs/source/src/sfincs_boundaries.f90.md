## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 63–66·83–86·229–232: ASCII 행 수 루프는 stat<0일 때만 빠져나온다. stat>0에 대한 분기는 없다.
- 135–139: bzi 첫 열의 시간은 dummy로 읽는다. bzi 시간과 t_bnd가 같은지 검사하는 문장은 이 블록에 없다.
- 143–162: 시간 범위 보정의 내부 조건은 if/else이다. 첫 시간과 마지막 시간이 모두 범위를 벗어나도 이 호출에서는 두 보정 중 하나만 실행한다.
- 199–211: 값 검사 조건은 -99.0보다 작거나 990.0보다 큰 비교이다. 경고 문구에는 NaN도 적혀 있지만 이 검사에는 명시적인 NaN 함수 호출이 없다.
- 302–303·362–366: 조석 세트 수 불일치에는 ERROR를 출력한다. 이 분기에는 stop_sfincs, return 또는 오류값 설정이 없다.
- 396–435: 두 번째 bca 판독은 current_set/current_component를 증가시켜 배열에 저장한다. 이 저장 블록에는 세트 수와 성분 수에 대한 상한 검사가 없다.
- 543–577·591–613: 최근접 검색의 초기 거리는 1.0e10이고 인덱스는 0이다. 검색 조건은 dst가 초기 거리보다 작은지 비교한다.
- 625–659: Neumann 내부 셀 검색은 네 방향을 차례로 모두 실행한다. 유효 셀을 찾은 뒤 빠져나오는 문장이 없으므로 뒤 방향의 유효 셀이 같은 nmi_gbp 원소를 덮어쓴다.
- 761–780·782–915: update_boundary_conditions는 dt 인수를 선언하지만 실행문에서 참조하지 않는다.
- 820–824: 기압 수위 보정은 중력 상수로 숫자 9.81을 직접 쓴다. 같은 파일 경계 flux 식은 g를 쓴다(1019–1020).
- 828–829·855–866: 이 루틴에서 zsetup의 대입값은 0.0뿐이다. 이후 수위 합산식에는 zsetup이 들어간다.
- 941–943·1081–1093: dt/btfilter와 dt/btrelax 계산은 필터 사용 조건보다 먼저 수행한다. 이 두 나눗셈 앞에는 분모 0 검사 조건이 없다.
- 968–1115: 경계 flux 갱신의 본체는 bndtype==1 분기 안에 있다. 이 조건에는 elseif나 else가 없다.
- 1075–1077: 주석은 속도 제한이 flux를 바꾸지 않는다고 적는다. 실제 대입 대상은 uv이며 제한 숫자는 -4.0과 4.0이다.
- 1237–1238: find_sfincs_cell은 quadtree 검색 결과 nmq를 바로 index_sfincs_in_quadtree의 인덱스로 쓴다. 이 함수 내부에는 nmq 검사 조건이 없다.
