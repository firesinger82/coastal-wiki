## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 38·43: srcfile에 대한 check_file_exists 호출이 같은 분기에 두 번 있다.
- 46–51·78–82·113–118: 행 수 계산 루프는 stat<0에서만 종료한다. stat>0을 처리하는 분기는 없다.
- 61–64·130–155: NetCDF 분기에는 기간 경고가 있다. 공통 nsrc>0 분기도 같은 기간 조건을 검사한다. 공통 보정은 if/else이므로 한 번의 호출에서 첫 시간과 마지막 시간을 함께 보정하지 않는다.
- 34·354–360: itsrclast의 초기값은 1이다. 보간식은 itsrc-1을 참조한다. 이 보간 블록에는 itsrc>1 검사나 시간 간격이 0인지 검사하는 문장이 없다.
- 61·121–124·134: tsrc의 첫·마지막 원소 접근 전에 ntsrc>0 또는 ntsrc>=2를 검사하는 조건문은 이 파일에 없다.
- 198–201: 모든 배수 구조물의 거리 초기값은 0, 개방률은 1, 상태는 1이다. 개방률 초기화 주석에는 zmin/zmax에 맞추어 수정해야 한다는 문구가 있다.
- 209–213·248–253: 유형을 먼저 읽는 read의 stat는 바로 검사하지 않는다. stat 오류 처리는 매개변수까지 다시 읽은 뒤에 있다.
- 221·531–532: 입력 판독 주석은 4·5번 유형의 4·5번째 매개변수를 zmin/zmax로 설명한다. update_discharges의 case(5)는 이를 tclose/topen으로 사용한다.
- 291–298·435–440·518·535–540·614: 거리 계산은 두 인덱스가 양수인지 검사한다. 두 수문 분기의 식은 drainage_distance·tcls·wdt·hgate의 거듭제곱으로 나눈다. 해당 분기에는 이 분모들의 양수 여부를 검사하는 조건문이 없다.
- 488·503·584·599: 닫힘 완료 조건은 frac<0이고 열림 완료 조건은 frac>1이다. frac가 정확히 0 또는 1인 경우에는 해당 조건으로 상태를 바꾸지 않는다.
- 384–620·422·625: 구조물 select에는 case(1)..case(5)가 있고 case default는 없다. case(3)의 비음수 제한은 select 뒤의 공통 완화식보다 먼저 실행된다.
- 23·27·345: read_discharges의 nm·m·iref·message와 update_discharges의 idir는 선언 이후 사용되지 않는다.
