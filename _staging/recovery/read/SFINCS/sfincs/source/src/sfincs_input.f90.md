## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 23·38: icoriolis·iwavemaker_spectrum은 지역 정수로 선언된다. 두 변수는 이 파일의 입력 호출·대입·조건에 등장하지 않는다.
- 35–37·389–392·550–556·632: imanning2d·isubgrid·iwavemaker는 선언과 대입에 등장한다. 이 지역 변수 값을 읽는 실행문은 이 파일에 없다.
- 52–53·385–386: dx·dy 입력 기본값은 0.0이다. 후속 계산은 1.0/dx와 1.0/dy이다. 이 파일에는 해당 계산 앞의 0 검사 조건이 없다.
- 96–97: 같은 epsg 키를 정수 epsg와 문자 epsg_code로 각각 판독한다.
- 121–134·137–165: wavemaker 파일 키는 새 키가 none이면 이전 키를 읽는다. wavemaker 수치·신호 키는 이전 키를 먼저 읽고 그 값을 새 키의 기본값으로 넘긴다.
- 302–303: 진행률 범위 주석은 (0,100)이라고 적는다. 제한식은 0과 100을 포함하는 값을 산출할 수 있다.
- 323–328: 풍속 항력 기본 표는 풍속 0·28·50과 계수 0.0010·0.0025·0.0015로 고정되어 있다.
- 330–335: cd_nr가 0이 아닌 else의 주석도 Use defaults라고 적는다. 실행문은 cdwnd·cdval 배열 입력 호출이다.
- 365–368: t0 앞의 time_difference 호출은 tref와 tstart의 차이를 구한다. t0 대입 뒤 주석은 tstop과 tstart의 차이라고 적는다. t1 앞의 호출은 tref와 tstop의 차이를 구한다.
- 73·372–374: manning 입력 기본값은 0.04이다. subgrid용 gn2 식은 9.81*0.02*0.02로 고정되어 있다.
- 406–410·435–436: 투영 좌표의 latitude가 -0.01보다 크고 0.01보다 작으면 coriolis를 false로 설정한다. 투영 좌표이고 coriolis가 false이면 이유를 latitude 미지정으로 적는 로그를 출력한다.
- 280·511–514: storecumprcp 입력 기본값은 0이다. 이 파일에서 store_cumulative_precipitation의 초기값은 false이다. storecumprcp가 1일 때 true로 바뀐다.
- 532–535: outputtype_map 또는 outputtype_his 중 하나라도 nil이면 두 값을 모두 outputtype으로 덮어쓴다.
- 537·542: global 초기화 대입의 주석은 ampr 파일을 block으로 사용한다는 설명이다. 같은 주석이 ampr_block 초기화에도 있다.
- 707–741: bathtub는 dthisout을 bathtub_dt로 덮어쓴다. 이 분기는 여러 강제력·침투·속도 저장 변수를 false로 설정한다. snapwave가 true였을 때만 bathtub_snapwave=true 대입을 실행한다.
