## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 32–50·971–979: 파일 형식 선택 조건은 nf90_open의 반환 상태가 아니라 net_file_sbg%ncid>0이다. handle_err는 −51 상태의 출력을 생략한다. 다른 오류 상태에서는 메시지만 출력한다. 이 루틴에는 stop이나 오류 종료 호출이 없다.
- 40·646·650·758·831: huthresh=0.0 대입은 NetCDF 선택 분기에 있다. 구형 binary 루틴은 havg 기본값과 quadtree 입력 하한으로 huthresh를 사용한다. 구형 binary 루틴 내부에는 huthresh 대입이 없다.
- 124–131·150–155·166–272: NetCDF의 np·npuv 일치 검사는 주석 처리되어 있다. uv_index·z_index의 전체 초기화는 없다. 재배치 루프 끝에서 채운 인덱스 개수와 할당 크기를 비교하는 조건은 없다.
- 317·374–386·401–409·422–431·888·892: NetCDF 속도점 보정 일부는 max(zmax,zmin+0.01)을 사용한다. NetCDF 셀 보정은 기존 zmax에 0.01만 더한다. 구형 binary 셀·속도점 보정은 기존 zmax에 0.001만 더한다. 각 가산 보정 뒤 높이 차이를 다시 검사하는 루프는 없다.
- 329·347·658·781·854: NetCDF 조도 변환은 하한 0.0001을 사용한다. 구형 binary quadtree 변환은 0.005를 사용한다. 구형 binary 일반 격자 변환은 0.0001을 사용한다.
- 515·698·352–356: 구형 binary의 subgrid_uv_pwet는 전체 1.0으로 설정한다. NetCDF 경로는 uv_pwet 표를 읽는다. 구형 binary fnfit 기본값은 0.0이다(514·697).
- 624·712·929·931: 구형 binary 첫 높이 수준과 전체 습윤 체적 증가식은 −20.0을 하한으로 사용한다.
- 500·662·681·790·863·867·939–947: 구형 binary는 읽은 bin 수에 1을 더해 수준 수로 사용한다. 첫 수준 nrep에 두 번째 수준을 복사한다. 초기 체적 보간은 subgrid_nlevels−1로 나눈다. 이 파일에는 수준 수가 2 이상인지 검사하는 실행 조건이 없다.
