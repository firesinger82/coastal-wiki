## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 69–84: initialize_processes는 use_quadtree를 먼저 false로 설정한다. qtrfile 조건에서 이를 true로 바꾼다. waves는 파일 입력 조건 없이 false로 설정한다.
- 193–207·288–295: kcsg 할당은 use_quadtree의 else 안에 있는 ASCII 분기에 있다. 후속 inputtype=='asc' 마스크 복사는 use_quadtree 조건 밖에 있다. 이 파일에는 두 입력 선택의 조합을 검사하는 조건문이 없다.
- 347–348·427–435: index_quadtree_in_sfincs를 할당한 다음 0으로 설정하는 배열 이름은 index_sfincs_in_quadtree이다. 이후 재매핑 루프는 두 배열을 모두 채운다.
- 545–549·569–573·581–585·1028·1070·1143·1185: combined 점 계산의 주석은 방향 플래그 1을 세밀한 이웃으로 설명한다. uv 이웃 계산의 >-1 조건 주석은 성기거나 같은 이웃으로 설명한다. >-1 조건에는 플래그 1도 포함된다.
- 887–889·935–937: 위쪽 동일 수준 분기는 uv_flags_dir=1에 u point 주석을 붙인다. 위쪽 성긴 이웃 분기는 같은 방향값 1에 v point 주석을 붙인다.
- 184·1273: initialize_mesh의 okay는 선언과 true 대입만 있다. 이 루틴에는 okay를 참조하는 조건이나 계산식이 없다.
- 1401·1429·1440·1462·1471·1524·1982·2018·2027–2035: 격자 거리 변환은 111111.1을 사용한다. 코리올리 식은 7.2921e-05를 사용한다. 시간 간격 상한식과 조도식은 9.81을 직접 사용한다.
- 1403–1541: initialize_mesh의 dtmax와 dtmin 계산은 crsgeo 조건의 projected else 안에 있다. crsgeo 참 분기는 dxymin을 갱신하지만 이 루틴에서 dtmax나 dtmin을 대입하지 않는다.
- 1545–1584: nuvisc 할당은 viscosity 조건 밖에 있다. nuvisc 값 대입은 viscosity 참 분기 안에만 있다.
- 1694–1704: 서로 다른 refinement의 zbuv 가중치는 0.3333과 0.6667이다. 이 두 분기에는 1/3 또는 2/3을 계산하는 식이 없다.
- 1720–1736: subgrid·nonhydrostatic 조건 안에서 use_quadtree가 false이면 오류 문자열을 write_log에 전달한다. 문자열은 quadtree grid with nr_levels > 1 조합 미지원이라고 적는다. 해당 분기에는 nr_levels 검사나 stop_sfincs 호출이 없다.
- 1784·1871–1876·1901: kcs=6 설명 주석은 uv 경계점에 추가하지 않는다고 적는다. 실행 코드는 kcuv=6의 nkcuv2를 증가시키고 경계 uv 배열 작성 조건에 kcuv=6을 포함한다.
- 1994–1998·2089–2093: NetCDF 파일 구분은 파일명의 마지막 두 문자가 소문자 nc인지 검사한다. 이 부분에는 nchar>=2 검사나 대소문자 변환이 없다.

- 2303·2315–2316·2346: set_initial_conditions 호출 뒤 combined q와 uv를 평균한다. 이후 uv 전체를 0으로 다시 설정한다. q 전체를 같은 위치에서 다시 0으로 설정하는 문장은 없다.
- 2285–2298·2303·2324–2344: initialize_hydro는 qmax와 tsunami_arrival_time을 조건부로 할당한다. 이 루틴에는 두 배열의 값 대입이 없다. 호출되는 set_initial_conditions 내부는 이번 판독 대상에 포함하지 않았다.
