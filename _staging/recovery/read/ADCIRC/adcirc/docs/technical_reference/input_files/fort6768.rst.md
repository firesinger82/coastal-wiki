| 1–9 | Fort.67, Fort.68: Hot Start Files — 재시작(hot start) 파일을 번갈아 써서 한 파일을 쓰다가 계산기가 중단되어도 다른 파일로 재시작할 수 있게 한다(6). 일반적으로 시간상 최신 파일을 사용한다(6). 쓰기 버퍼(write buffer)가 비워지지 않아 다른 출력이 뒤처진 경우에는 이전 파일로 재시작해야 할 수 있다(8). 읽을 파일은 IHOT가 결정한다(8). 원문: `These files are used to hot start the model. Hot start output is written to fort.67 and fort.68 on an alternating basis so that if the computer crashes in the process of writing one of these files, the other will be unaffected and can be used to hot start the model. Normally, the most current (in time) of the fort.67 or fort.68 files is used to hot start the model.` (6); ``On certain computers, the write buffer may not be emptied on a crash and other output files (e.g., time series output files fort.63, fort.64) may not be caught up to the time when the latest hot start file was written. In this case it would be necessary to restart the model using the earlier of the hot start files. Which (if either) hot start file is read in is determined by the parameter :ref:`IHOT <IHOT>` in the :doc:`Model Parameter and Periodic Boundary Condition File <fort15>`.`` (8). |
| 10–22 | Parameter Changes During Hot Start — 재시작 기능으로 실행 중 일부 매개변수를 바꾸는 방법을 설명한다(13). 시간 간격과 시계열(time series) 또는 조화 출력(harmonic output) 관련 매개변수는 바꿀 수 없다(15–17). 시계열 종료 시각은 예외적으로 바꿀 수 있다(19). 이 경우 파일 앞의 출력 자료 집합 수를 갱신할 수 없어 실제 수와 다를 수 있으므로 분석·표시 전에 해당 수를 수동으로 고쳐야 한다(19). 파일 쓰기는 NHSTAR와 NHSINC가 제어한다(21). 원문: `It is often convenient to change parameter values in the Model Parameter and Periodic Boundary Condition File during the course of an ADCIRC run. (For example the duration of the run may be extended, nonlinear terms may be turned on or off, the value of the horizontal viscosity may be changed, etc.) A convenient way to accomplish this is via the hot start feature.` (13); `**Limitations:**` (15); ``* Cannot change the model time step (:ref:`DTDP <DTDP>`)`` (16); `* Cannot change parameters related to time series or harmonic output` (17); `**Exception:** The ending time of a time series output file may be changed (e.g., if the length of the run is increased). However, this has one undesirable consequence since the number of output data sets contained in the file is written at the beginning of the file. After a hot start, it is not possible to change this value in the time series output file, and therefore it may not match the actual number of output data sets in the file. In this case it would be necessary to edit this number by hand in any affected time series output file before using the file in analysis or display software.` (19); ``Writing hot start output files is controlled by the parameters :ref:`NHSTAR <NHSTAR>` and :ref:`NHSINC <NHSINC>` in the :doc:`Model Parameter and Periodic Boundary Condition File <fort15>`.`` (21). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 76행: `l(k,j)`에는 다른 인접 상태 변수와 달리 참조 지시문이 없다. 이 파일은 해당 변수의 뜻을 정의하지 않는다.
- 96행: `FNAM8(2)`의 참조 대상은 `FNAM8(1)`로 적혀 있다. 같은 행의 `FNAM8(1)`도 같은 대상을 참조한다.
