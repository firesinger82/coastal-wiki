# time_varying_weirs.rst — 판독 구간 기록

구간은 1행부터 89행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–7 | Fort.142: Time Varying Weirs Input File — 모의 중 높이가 바뀌는 보(weir)의 절점마다 한 줄을 둔다(6). 내부 장벽 경계(internal barrier boundary)는 절점 쌍을 사용한다(6). 원문: `The Time Varying Weirs Input File contains one line for each weir node (or node pair, for internal barrier boundaries) that will change its elevation during the course of the simulation.` (6). |
| 8–12 | File Structure — 첫 줄은 파일에 들어갈 시간 가변 보 절점 또는 절점 쌍의 수이다(11). 이후 줄은 높이 변화 변수를 쉼표로 구분하며 한 줄 안의 변수 순서는 자유롭다(11). 원문: `The first line of the file contains the number of time varying weir nodes (or node pairs) that will appear in the file. Each subsequent line contains a comma separated list of variables that describes how the elevation of that weir node (or node pair) should change during the simulation. The variables on a particular line can appear in any order.` (11). |
| 13–27 | Required Variables — 각 줄에 X1과 Y1이 필요하다(16–19). 내부 경계 유형 24에는 X2와 Y2도 필요하다(21–24). ADCIRC가 좌표에 해당하는 보 절점을 격자에서 찾으며 찾지 못하면 종료한다(26). 원문: `The following variables are required for each line:` (16); `- X1 – x-coordinate location of the first node as part of this weir` (18); `- Y1 – y-coordinate location of the first node as part of this weir` (19); `For internal boundaries (type 24), two additional parameters are required:` (21); `- X2 – x-coordinate location of the second node as part of this weir` (23); `- Y2 – y-coordinate location of the second node as part of this weir` (24); `ADCIRC searches the mesh to associate the X1, Y1 coordinates (and X2, Y2 if specified) with the locations of weir nodes. If a weir node is not found at those coordinates, the code will terminate.` (26). |
| 28–36 | Elevation Change Types — VARYTYPE이 높이 변화의 계기 또는 시기를 지정한다(31). 1은 시간에 따른 한 번의 변화이다(33). 2는 수면 높이(water surface elevation, WSE)에 따른 한 번의 변화이다(34). 3은 일정에 따른 변화이다(35). 원문: `The VARYTYPE parameter specifies the trigger or timing of the elevation change for that node:` (31); `1. One time elevation change based upon time (VARYTYPE=1)` (33); `2. One time elevation change based upon water surface elevation (WSE) (VARYTYPE=2)` (34); `3. Schedule based elevation change (VARYTYPE=3)` (35). |
| 37–54 | VARYTYPE=1 Parameters — 시간 매개변수는 선택 사항이지만 조합이 시작 시각과 종료 시각을 모두 정의해야 한다(40). Hot의 기본값과 각 시각 성분의 단위를 제시한다(42–50). ZF는 필수이며 격자 기준면(mesh datum) 대비 미터 단위의 최종 보 높이이다(52–53). 양의 방향은 위이다(53). 원문: `VARYTYPE=1 Parameters` (37); `The following parameters are all optional except that some combination of them must define both a start time and an end time:` (40); `- Hot – 1 if time trigger is relative to hot start time, 0 if relative to cold start time (default: 0)` (42); `- TimeStartDay – number of days before start of weir node elevation change` (43); `- TimeStartHour – number of hours before start of weir node elevation change` (44); `- TimeStartMin – number of minutes before start of weir node elevation change` (45); `- TimeStartSec – number of seconds before start of weir node elevation change` (46); `- TimeEndDay – number of days before end of weir node elevation change` (47); `- TimeEndHour – number of hours before end of weir node elevation change` (48); `- TimeEndMin – number of minutes before end of weir node elevation change` (49); `- TimeEndSec – number of seconds before end of weir node elevation change` (50); `Additional required parameter:` (52); `- ZF – final weir elevation in meters relative to the mesh datum (positive up)` (53). |
| 55–67 | VARYTYPE=2 Parameters — ZF와 파괴를 일으키는 ETA_MAX가 필수이다(58–60). 파괴 지속시간(failure duration)은 일·시간·분·초 매개변수의 어떤 조합으로든 반드시 지정해야 한다(62–66). 원문: `VARYTYPE=2 Parameters` (55); `Required parameters:` (58); `- ZF – final weir elevation in meters relative to the mesh datum` (59); `- ETA_MAX – water surface elevation that triggers the simulated weir failure` (60); `Failure duration parameters (some combination must be specified):` (62); `- FailureDurationDay – Time in days for duration of failure` (63); `- FailureDurationHour – Time in hours for duration of failure` (64); `- FailureDurationMin – Time in minutes for duration of failure` (65); `- FailureDurationSec – Time in seconds for duration of failure` (66). |
| 68–81 | VARYTYPE=3 Parameters — ScheduleFile은 필수이다(71–72). Loop와 NLoops 및 재시작(hotstart) 이후 높이 변화 시작 시각 성분은 선택 사항이다(74–80). 반복 선택값과 기본값을 제시한다(75–76). 원문: `VARYTYPE=3 Parameters` (68); `Required parameter:` (71); `- ScheduleFile – name of the Schedule File that describes when and how much the weir nodes should change their height` (72); `Optional parameters:` (74); `- Loop – Set to 1 to repeat schedule, 0 for no repeat (default), -1 for infinite repeat` (75); `- NLoops – Number of times the schedule should repeat` (76); `- TimeStartDay – number of days since hotstart when weir node elevation starts to change` (77); `- TimeStartHour – number of hours since hotstart when weir node elevation starts to change` (78); `- TimeStartMin – number of minutes since hotstart when weir node elevation starts to change` (79); `- TimeStartSec – number of seconds since hotstart when weir node elevation starts to change` (80). |
| 82–89 | Notes — 보 높이는 해당 절점의 지형 높이 아래로 내려가지 않는다(85). 두 절점의 내부 보는 어느 절점의 지형 높이 아래로도 내려가지 않는다(86). 재시작 모의는 이전 높이 변화를 알지 못한다(87). 입력은 첫 ADCIRC 시간 단계 전에 일어나는 일을 가정해서는 안 된다(88). 현재 모의 시작 전에 지정된 변화는 고려하지 않는다(89). 원문: `- The weir will not decrease below the topographic elevation specified at the node` (85); `- For internal weirs with two nodes, the weir height will not decrease below the topographic elevation of either node` (86); `- A hot start simulation will not have any knowledge of previous weir elevation changes` (87); `- The time varying weir input file should not assume anything happens prior to the first ADCIRC time step` (88); `- Weir elevation changes prescribed before the start of the current simulation will not be considered ` (89). |
