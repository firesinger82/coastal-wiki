| 8–16 | Input Files for Meteorological Forcing — 선택한 NWS에 따라 입력 파일이 달라진다(11). 대부분의 옵션은 fort.22를 사용한다(13). fort.200과 fort.221-224의 적용 조건을 제시한다(14–15). 원문: `Depending on the NWS value selected, ADCIRC uses different input files:` (11); `* **fort.22**: Primary meteorological forcing file for most NWS options` (13); `* **fort.200**: Used for NWS=10 (AVN model) and NWS=11 (ETA model)` (14); `* **fort.221-224**: Used for NWS=12 (OWI format)` (15). |
| 17–46 | Meteorological Forcing Types — 직접 입력, 격자 자료, 매개변수형 허리케인 모델(parametric hurricane model), 자료 동화(data-assimilated) 모델, 결합 모델(coupled model)의 다섯 종류를 나눈다(22–45). 각 종류의 NWS 값과 모델 이름을 원문대로 열거한다(23–45). 원문: `ADCIRC meteorological forcing can be categorized into several types:` (20); `1. **Direct Meteorological Input**` (22); `   - NWS=1,2,-2: Wind stress and pressure specified directly` (23); `   - NWS=5,-5: Wind velocity and pressure at all nodes` (24); `   - NWS=4,-4: Wind velocity and pressure at selected nodes` (25); `2. **Gridded Meteorological Data**` (27); `   - NWS=3: US Navy Fleet Numeric format` (28); `   - NWS=6: Rectangular grid of wind/pressure` (29); `   - NWS=7,-7: Regular grid of stress/pressure` (30); `   - NWS=10: NWS Aviation (AVN) model` (31); `   - NWS=11: NWS ETA 29km model` (32); `   - NWS=12: OWI format (nested grids)` (33); `3. **Parametric Hurricane Models**` (35); `   - NWS=8: Dynamic Holland model` (36); `   - NWS=19: Asymmetric hurricane vortex` (37); `   - NWS=20: Generalized Asymmetric Holland Model (GAHM)` (38); `4. **Data-Assimilated Hurricane Models**` (40); `   - NWS=15,-15: HWind files from NOAA HRD` (41); `5. **Coupled Model Systems**` (43); `   - NWS=100-199: Wave radiation stress with meteorological forcing` (44); `   - NWS=300-399: SWAN+ADCIRC coupled model` (45). |
| 47–91 | Format Comparison — 형식별 입력 단위, 보간(interpolation), 공간 포괄 범위(coverage), 장점, 제한을 비교한다(50–90). 직접 입력은 시간 보간만 한다(61–66). 격자 자료는 공간·시간 보간을 한다(67–72). 매개변수형 모델은 실행 중 생성한다(73–78). 자료 동화는 스냅샷(snapshot) 사이를 시간 보간하며 폭풍 영역만 포괄한다(79–84). 결합 모델의 보간은 모델에 의존한다(85–90). 원문: `.. list-table:: Format Comparison` (50); `   :widths: 15 15 15 15 20 20` (51); `   :header-rows: 1` (52); `   :class: tight-table` (53); `   * - Format Type` (55); `     - Input Unit` (56); `     - Interpolation` (57); `     - Coverage` (58); `     - Advantages` (59); `     - Limitations` (60); `   * - Direct Input` (61); `     - Grid nodes` (62); `     - Temporal only` (63); `     - Full domain` (64); `     - Precise control` (65); `     - Large file sizes` (66); `   * - Gridded Data` (67); `     - Regular grid` (68); `     - Spatial & temporal` (69); `     - Must cover domain` (70); `     - Standard formats` (71); `     - Interpolation errors` (72); `   * - Parametric Models` (73); `     - Track data` (74); `     - Generated on-the-fly` (75); `     - Full domain` (76); `     - Small input files` (77); `     - Idealized storm structure` (78); `   * - Data-Assimilated` (79); `     - Snapshots` (80); `     - Temporal between snapshots` (81); `     - Storm area only` (82); `     - Real observations` (83); `     - Limited spatial coverage` (84); `   * - Coupled Models` (85); `     - Multiple sources` (86); `     - Model-dependent` (87); `     - Full domain` (88); `     - Physical consistency` (89); `     - Computational cost` (90). |
| 92–111 | Selecting the Appropriate Forcing — 자료 가용성, 모델 영역, 계산 자원을 선택 기준으로 제시한다(95–110). 역사 모의·예측·연구의 자료 선택 경향을 구분한다(97–100). 작은 고해상도 영역은 직접 입력의 이점을 얻을 수 있다고 적는다(102–105). 저장 요구와 결합 모델 계산 비용을 비교한다(107–110). 원문: `When choosing a meteorological forcing option:` (95); `1. **Consider data availability**:` (97); `   - Historical simulations often use reanalysis or observation-based options` (98); `   - Forecasts typically use forecast model output or parametric models` (99); `   - Research applications may use idealized forcing` (100); `2. **Consider model domain**:` (102); `   - Large domains benefit from gridded data or parametric models` (103); `   - Small, high-resolution domains may benefit from direct input` (104); `   - Hurricane simulations typically use parametric or data-assimilated models` (105); `3. **Consider computational resources**:` (107); `   - Parametric models reduce I/O and storage requirements` (108); `   - Direct input may require large storage for forcing files` (109); `   - Coupled models incur additional computational cost` (110). |
| 112–122 | Common Challenges — 격자 기상 자료가 ADCIRC 영역을 완전히 덮어야 한다고 적는다(115). 시간 동기화(time synchronization), 정확한 형식, 단위 호환, 일부 NWS의 재시작(hot start) 요구를 확인하도록 한다(116–119). NWS와 fort22·fort200의 상세 설명을 연결한다(121–122). 원문: `1. **Ensuring proper coverage**: Gridded meteorological data must completely cover the ADCIRC domain` (115); `2. **Time synchronization**: Pay careful attention to start times and time intervals` (116); `3. **Format consistency**: Follow exact format specifications for each NWS option` (117); `4. **Unit compatibility**: Ensure units are consistent with ADCIRC expectations` (118); `5. **Hot start considerations**: Some NWS options have specific requirements for hot starts` (119); ``For detailed descriptions of each NWS option, see the :ref:`NWS <NWS>` parameter documentation.`` (121); ``For file format details, see :doc:`fort22` and :doc:`fort200` documentation. `` (122). |
