## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 3·21·23행: 제목의 파일 번호는 `255/277`이며 본문의 얼음 자료 파일 번호는 `fort.225`, `fort.227`이다.
- 18–19행: 형식에 있는 `numBlankIceSnaps`의 의미와 값 범위는 이 문서에서 설명하지 않는다.
- 37·47행: 두 LaTeX 수식의 뺄셈 위치에 en dash 문자 `–`가 있다.
- 39·49행: IC를 개방수역 0.0부터 완전 피복 1.0까지의 값으로 설명하면서 뒤 설명의 IC 값은 `0`, `50`, `100`이다.
- 47·49행: IceCube 식의 IC=0 상수항은 `0.075`에 `10^{-2}`를 곱하는 표기이며 49행의 IC=0 값 표기는 `(.000075)`이다.
