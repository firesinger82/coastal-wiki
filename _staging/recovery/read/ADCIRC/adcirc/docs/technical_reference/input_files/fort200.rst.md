| 32–50 | GFS (NWS=10) Notes — T1534 Gaussian 격자(Gaussian grid)의 크기와 공간 보간(interpolation)을 설명한다(35–37). 순차 파일 이름·시간 간격 제약·초기 실행(cold start)과 재시작(hot start)의 첫 자료 시각·시간 보간과 단위를 제시한다(38–49). 원문: `- Meteorological data is input to a T1534, Gaussian grid (NWLON*NWLAT = 3072*1536 = 4,718,592)` (35); `- Data is interpolated in space onto the ADCIRC mesh` (36); `- Data are ordered in these files the same way they are generated by the degribbing program` (37); `- Files are named sequentially: fort.200, fort.200+N, fort.200+2*N, etc.` (38); `  - N = WTIMINC/3600 (time interval in hours between data files)` (39); `  - WTIMINC must be evenly divisible by 3600` (40); `- For cold starts:` (41); `  - Winds are assumed at rest at TIME=STATIM` (42); `  - First data file (fort.200+N) corresponds to TIME=STATIM+WTIMINC` (43); `- For hot starts:` (44); `  - Initial file (fort.200) required at TIME=HOT START TIME` (45); `- Data is interpolated in time to the ADCIRC time step` (46); `- Units:` (47); `  - Wind velocity (@ 10m): m/s` (48); `  - Surface pressure: Pascals (N/m²)` (49). |
| 51–67 | GFS / Wind Stress Calculation / Pressure Conversion — 풍속 크기·항력계수(drag coefficient)·상한·풍응력과 Pascal 압력을 수두(water head)로 바꾸는 식을 원문 그대로 제시한다(54–66). 원문: `.. parsed-literal::` (54); `    WIND_SPEED = magnitude of WIND_VEL` (56); `    DRAG_COEFF = 0.001*(0.75+0.067*WIND_SPEED)` (57); `    If (DRAG_COEFF.gt.0.003) DRAG_COEFF=0.003` (58); `    WIND_STRESS = DRAG_COEFF*0.001293*WIND_VEL*WIND_SPEED` (59); `.. parsed-literal::` (64); `    PRESSURE{m H2O} = PRESSURE{Pascal}/(GRAVITY*DENSITY of H2O)` (66). |
| 68–85 | Eta-29 (NWS=11) Notes — Eta-29 E 격자(E grid)의 크기, 경위도 좌표 의무와 일별 파일 이름을 제시한다(71–73). 3시간 간격 여덟 집합·03:00–24:00 자료·초기 실행 및 재시작의 시각·이진 순차 비형식(binary sequential unformatted) 파일·바람과 압력 단위를 설명한다(74–84). 원문: `- Meteorological data is input to the standard Eta-29 "E" grid (NWLON*NWLAT = 181*271 = 49,051)` (71); `- ADCIRC grid must be in lon, lat coordinates` (72); `- Files are named sequentially: fort.200, fort.201, fort.202, etc.` (73); `- Each file contains 8 data sets spaced 3 hours apart (WTIMINC = 10800 sec)` (74); `- Data sets correspond to 03:00 to 24:00 hours on the day of the file` (75); `- For cold starts:` (76); `  - Winds are assumed at rest at TIME=STATIM` (77); `  - First data set in fort.201 corresponds to TIME=STATIM+WTIMINC` (78); `- For hot starts:` (79); `  - Initial file (fort.200) required with last data set at TIME=HOT START TIME` (80); `- File type: binary (ACCESS='sequential', FORM='unformatted')` (81); `- Units:` (82); `  - Wind velocity (@ 10m): m/s (E grid coordinate directions)` (83); `  - Surface pressure: millibars` (84). |

| 103–112 | General Notes — 전 실행 기간의 자료 제공 의무와 읽되 무시하는 날짜·시간 필드를 명시한다(106–107). 시간 보간 및 NWS=11의 일별 여덟 집합·첫끝 시각·WTIMINC 관련 제공 문구와 일별 파일 의무를 제시한다(108–112). 원문: `- Meteorological data must be provided for the entire model run, otherwise the run will crash` (106); `- IYEAR, IMONTH, IDAY, IHOUR values are read but ignored by ADCIRC` (107); `- Data is interpolated in time to the ADCIRC time step` (108); `- For NWS=11, each file contains 8 data sets for a total of 1 day of data per file` (109); `- The first and last data sets in each NWS=11 file correspond to 03:00 hrs and 24:00 hrs, respectively` (110); `- For NWS=11, 8 sets of meteorological data must be provided every WTIMINC in each file` (111); `- For NWS=11, appropriately named files must be provided for each day of the model run` (112). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)
