| 18–61 | Plotting Considerations — 도구 선택은 프로젝트 목적과 자원·소프트웨어에 달린다고 적는다(23–25). 대화형(interactive)과 정적 이미지(static image), 데이터 전송, 처리 속도, NetCDF와 ASCII 형식, 투영(projection), 표시할 파일, 사용자 구현 노력과 비용을 비교할 항목으로 든다(27–53). 격자·절점 속성 입력은 ASCII여야 하고 출력은 ASCII 또는 NetCDF일 수 있다고 적는다(34–36). 여러 프로그램의 NetCDF4 동시 읽기, 출력 파일 자체의 격자·연결·경계 정보, 코딩 학습 난도를 설명한다(38–44). 바람·파향 벡터장(vector field), 항공 영상, 확대 범위 안 등고선 한계의 자동 계산, 셰이프파일(shapefiles) 중첩을 기능 예시로 든다(55–60). 필수 형식과 선택 조건을 원문대로 옮긴다. 원문: ` -  NetCDF vs. ASCII data – while ADCIRC mesh and nodal attributes input files ` (34); `    must take ASCII form, outputs can be ASCII or NetCDF.
