| 1–31 | Vertical Element Walls (VEWs) / What are Vertical Element Walls? — 수직 요소 벽(Vertical Element Walls, VEWs)은 급경사 수로와 수직 지형을 표현하는 특수 경계 조건이라고 설명한다(9–15). 좁은 수로, 급경사·제방, 하천 수로와 범람원(floodplain)의 복합 홍수(compound flooding)를 용도로 든다(11–13). VEWs와 절점 속성(nodal attribute) condensed_nodes는 집중 명시적 모드(lumped explicit mode)를 실행하는 IM 값에서만 구현된다고 적는다(17–18). 그림 20행을 직접 열었다. 왼쪽 (a) Conventional Trapezoidal Approach는 경사진 양쪽 수로 벽과 평평한 바닥을 검은 선으로 그린다. 오른쪽 (b) New Discontinuous Depth / Vertical Element Wall Approach는 양쪽 벽을 녹색 수직선으로 그린다. 검은 원은 지형 선 위의 점을 표시한다. 연한 파란 수평선과 역삼각형은 수면을 표시한다. 왼쪽의 보라색 파선은 수로 바닥 양 끝에서 위로 이어진다. 두 Channel 화살표는 위쪽 수로 바닥을 가리킨다. 그림에는 좌표축과 수치 눈금이 없다. 그림 26행을 직접 열었다. Case 1) Complete submergence는 높은 지반과 낮은 지반 위로 이어지는 파란 수면 선을 보인다. Case 2) Submerged higher-ground side는 양쪽 지반 위의 서로 다른 수면 높이를 보인다. Case 3) Submerged lower-ground side는 낮은 지반 쪽에만 수면 선을 보인다. 검은 선·원은 지반을 표시한다. 수직 파선은 VEW를 표시한다. 파란 선·원과 역삼각형은 수면을 표시한다. 그림 캡션은 낮은 지반에 물이 없는 경우를 낮은 지반 총 수심이 0인 Case 2와 Case 3의 변형으로 설명한다. 그림에는 좌표축, 수치 눈금, 흐름 방향 화살표가 없다. 그림 지시문, 크기, 대체 텍스트, 캡션과 빈 줄을 포함한다(20–31). 원문: ` .. note:: ` (17); ``    VEWs and the :ref:`condensed_nodes` nodal attribute are implemented only for :ref:`IM` values that run ADCIRC in the lumped explicit mode. `` (18); ` .. figure:: ../../_static/images/user_guide/special_features/vertical_element_walls/vertical_element_walls_schematic.png ` (20); `    :width: 600 ` (21); `    :alt: Comparison between conventional trapezoidal approach and vertical element walls ` (22); `    Schematic comparison of traditional trapezoidal channel representation (left) and vertical element wall approach (right).  ` (24); ` .. figure:: ../../_static/images/user_guide/special_features/vertical_element_walls/vertical_element_walls_schematic_3.png ` (26); `    :width: 600 ` (27); `    :alt: Water in a channel, on a floodplain, and their seemless interaction ` (28); `    Water in a channel and on a floodplain seamlessly interact through vertical element walls under various flow conditions, including normal flow, overtopping, and flooding scenarios. ` (30). |
