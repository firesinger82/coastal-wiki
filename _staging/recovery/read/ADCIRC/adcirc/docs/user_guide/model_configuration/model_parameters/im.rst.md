| 138–158 | IM=111112 / IMDigit-6=3 — 명시적 집중 질량행렬일 때 A00·B00·C00를 0.0 1.0 0.0으로 설정해야 한다는 조건을 옮긴다(138–148). 계산 시간·안정성 차이는 문서 진술로 기록한다. v55+의 여섯째 자릿수 3과 기본값 1의 전체/정수 수심 처리 차이, 얕은 수심 CFL 위반 및 음의 초기 수심에서 행렬 대각성(matrix diagonality) 문제가 생길 수 있다는 표현을 옮긴다(150–157). 원문: ``` A common code combination is ``IM=111112``, which is identical to the default ``` (138); ``` ``111111`` (same as ``IM=0``), but simulates in explicit mass-lumping mode. Lumped explicit mode is a useful alternative ``` (141); ` to the (default) semi-implicit consistent GWCE mass matrix mode, because the ` (142); ` latter requires a matrix solve that increases computational time and memory. By ` (143); ` comparison, the explicit mass-lumping mode is about twice as fast and scales to ` (144); ` fewer grid nodes per computational core. [3]_ Moreover, for model setups that ` (145); ` are sufficiently resolved in space and time, differences in the solution between ` (146); ` approaches should be small. Though, many users have reported somewhat lower ` (147); ` stability in lumped explicit mode. ` (148); ` The most recent version (55+) also has an option that improves the (default) ` (150); ` semi-implicit consistent GWCE mass matrix mode to compute the complete (total ` (151); ` depth) gravity wave term (free surface gradient) implicitly; toggled by setting ` (152); ` IMDigit-6 to 3.
