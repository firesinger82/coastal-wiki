## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 24·44: 입력 형식 목록과 파일 이름 목록에 각각 `<...to be expanded in new verions>` 및 `...to be expanded in new versions`라는 확장 예정 문구가 있다.
- 66–89·109–110: NWBS 예제는 `86400th time step`, `172800th time step`, `-86400th time step`을 사용하고 이 숫자 차이를 WTIMINC=900으로 나눈다. WTIMINC 절은 단위를 seconds라고 정의한다. 예제 숫자의 시간 단계 길이는 이 파일에 없다.
