## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 101–116·204–205·212–214: 요약표는 −1의 Minimum=0.002·Maximum=0.005, −2의 Minimum=0.002를 적는다. 상세 −1 규칙에는 0.005와 0.020이 적혀 있고 상세 −2 규칙의 각 분기에는 0.005, 1/depth, 1이 적혀 있다.
- 212–214: −2 상세 분기는 depth>=200, 1<depth<200, depth<1이다. depth=1의 분기가 없다.
- 289–290: 값 생성 규칙은 depth<10m과 depth>10m만 적는다. depth=10m의 분기가 없다.
- 235: Tau0Min이 식에 들어 있지만 이 파일은 그 기호를 따로 정의하지 않는다.
- 224·227·253: 절점 기본값 이름은 TAU0Base와 Tau0Base 두 대소문자 표기로 적혀 있다.
- 237: 전역 상하한의 참조 문자열에는 세 개의 시작 백틱과 두 개의 끝 백틱이 쓰인 이름이 있다. 원문 표기를 수정하지 않았다.
