In ADCIRC, the user can either specify a `` (22); ` constant in time horizontal eddy viscosity or employ the Smagorinsky model to ` (23); ` update the horizontal eddy viscosity based on local flow conditions with each ` (24); ` time step. In both cases the horizontal eddy viscosity or Smagorinsky ` (25); ` coefficient can be either spatially constant or spatially varying. ` (26). |
| 28–49 | User-Specified Constant in Time Eddy Viscosity / Usage Notes — ESLM과 average_horizontal_eddy_viscosity_in_sea_water_wrt_depth 절점 속성(nodal attribute)을 원문대로 옮긴다(33–37). 통상 1–50 m²/s 및 시작값 10, 해상도·난류·육지 영역에 관한 가능성, 너무 큰 값도 불안정을 일으킬 수 있다는 원문을 옮긴다(42–48). 원문: ``` A spatially constant eddy viscosity can be supplied via the ``ESLM`` parameter ``` (33); `` in the `fort.15 file <fort.15_file>`__. By the nature of ` (43); ` turbulence closure, one might expect the value to be smaller as mesh resolution ` (44); ` increases. However, this may not always be the case since areas with high ` (45); ` resolution may also be more turbulent. In particular, some modelers use a larger ` (46); ` value in overland areas, which can also improve stability. There are currently two slightly different ways ` (57); `   of enabling this in the model. One is by specifying a negative value for ` (58); ``   :ref:`ESLM` <ESLM>` in the :ref:`fort.15 file <fort15>`. If this is done, `` (59); `   the Smagorinsky turbulence closure is enabled and the absolute value of ` (60); ```   ``ESLM`` is used as the coefficient. The ``` (66); `   namelist also allows the user to optionally specify lower and upper bounds on ` (67); `   the actual eddy viscosity determined via the Smagorinsky formulation.
