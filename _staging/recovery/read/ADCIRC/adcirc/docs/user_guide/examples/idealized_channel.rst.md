| 1–18 | Idealized Channel Problem — 메타 지시문과 제목을 포함한다(1–6). 중앙 수로가 있는 경사 해빈에서 일주조(diurnal tide), 측면 주기 경계(lateral periodic boundary), 흡수·생성 스펀지층(absorption-generation sponge layer)을 시험한다고 적는다(8–11). 2개 프로세서의 6시간 모의에 약 8분을 적는다(12–13). 시험 시간을 제한하기 위해 짧게 정했으며 사용자가 유입 파의 침수 단계를 더 모의하도록 연장할 수 있다고 설명한다(13–17). 원문: `This example tests ADCIRC version 55 (and beyond). It tests the simulation of a` (8); `diurnal tide on a sloping beach with a channel along its centerline (adapted` (9); `from [1]_). It tests lateral periodic boundary conditions and the` (10); `absorption-generation sponge layer [2]_ [3]_. The test finishes in about 8` (11); `minutes in parallel ADCIRC (2 processors) for 6 hours of simulation. Note that` (12); `the short 6 hour length of the test is chosen only to limit simulation time for` (13); ``the `GitHub test`` (14); ``suite <https://github.com/adcirc/adcirc-cg-testsuite/tree/v55/adcirc/adcirc_ideal_channel-2d-parallel>`__`` (15); `where the test case been found. Users may extend the simulation length to` (16); `simulate more of the inundating phase of the incoming wave.` (17). |
