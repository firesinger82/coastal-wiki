## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 133·137·170·2105: WindX·WindY·WindMag·WDragCo·WTRatio, PRDIFF·PRBCKGRND_MH2O, CD·CDQ·QWIND, tempp·temp1·temp2는 이 파일에서 해당 지역 변수 선언 외에 참조가 없다.
- 335–340·343–360: ASCII 경로의 파랑 자료 생략 분기는 `IHOTSTP=IHOTSTP+4*np_g` (336) 또는 `IHOTSTP=IHOTSTP+8*np_g` (339)로 카운터만 바꾼다. 이 두 else에는 READ가 없다. 이후 출력 카운터는 순차 READ로 읽는다.
- 311–316·526–533·769–772: 바이너리 경로에는 `H1 = DP + IFNLFA*ETA1` (532); `H2 = DP + IFNLFA*ETA2` (533)가 있다. ASCII 경로의 ETA1·ETA2 판독 뒤에는 이 H1·H2 계산문이 없다. 공통 초기화는 `QX2(I)=UU2(I)*H2(I)` (771); `QY2(I)=VV2(I)*H2(I)` (772)로 H2를 사용한다. 다른 모듈 내부의 H1·H2 설정은 이번 판독 범위에 포함하지 않았다.
