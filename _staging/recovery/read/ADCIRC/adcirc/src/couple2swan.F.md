## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 125–126·130·137: ComputeRadiationStresses의 IT·JunkR는 선언 뒤 사용되지 않는다. ADCIRC_SXX 할당은 STAT=IERR를 받지만 이후 IERR 검사는 없다.
- 261–287: 응력 미계산 시 힘을 0으로 만든다는 설명 아래의 조건은 고정 .FALSE.다. 실제 실행 경로는 else이며 ADCIRC_SXX·SXY·SYY의 allocated 검사 없이 값을 참조한다.
- 389–393·399–427: Marcel의 건조 요소 분기는 RSNX2·RSNY2를 0으로 설정하고 CYCLE outer한다. 해당 절점의 SWAN_RSNX2·SWAN_RSNY2에는 이미 누적된 값이 있을 수 있으며 이 분기에서 두 SWAN 배열을 0으로 다시 설정하는 문장은 없다.
- 365–422: TOTALAREA는 0으로 시작한다. 인접 요소 루프 종료 뒤 두 SWAN 힘을 TOTALAREA로 나누기 전에 별도 0 검사는 없다.
- 253–256·426–427: 힘 상한 UL은 999D0으로 선언된 parameter다. 0.1D0 대안은 주석이며 실제 제한 식은 -UL..UL이다.
- 474–475: SWAN_WDragCo는 NP_G 크기로 할당한다. NodeNumber로 대입하기 전에 인덱스 범위 검사나 전체 배열 초기화는 이 루틴에 없다.
- 504–515: Manning2Madsen은 H**(1/6) 식을 계산하기 전에 H의 하한 검사를 하지 않는다. 결과 검사는 Z0<=0이며 해당 조건의 기본값은 0.05D0이다.
- 631–681·842–843: SWAN_RTYPE은 길이 4의 지역 문자열이다. 이 파일에는 SWAN_RTYPE에 값을 대입하는 문장이 없으며 SWOEXD 인수로 전달한다. SWOEXD 내부의 인수 처리는 이 파일에서 확인하지 않았다.
- 754–764·799–839·864: SWAN_MAX와 SWAN_VOQ의 첫 차원은 NP다. 초기화·기초 출력량 조립 루프는 nverts를 사용하고 출력 배열 추출 루프는 NP를 사용한다.
- 818–825·833·849: SWAN_VOQ의 수심은 H0로 하한을 제한한다. DEPXY는 별도로 DP+ETA2를 계산하며 이 블록에서 H0 제한을 적용하지 않는다. SWOEXA에는 DEPXY를 전달한다.
- 851·854·912–925: UpdateMax는 매 호출 0으로 초기화한다. HS 출력의 증가 조건만 UpdateMax=1로 설정한다. 다른 파랑량 최대값은 이 플래그가 1일 때 같은 시각의 값으로 복사한다. 풍속 최대값도 풍속 증가 조건과 이 플래그를 함께 검사한다.
- 533–622·768–781·851–940: SwanOutput은 최초 처리에서 ABS(NOUTGW)=1 또는 4일 때 OPEN_GBL_FILE을 호출한다. 본문에는 현재 출력량·최대값 배열 계산이 있다. 가져온 writeOutArrayMinMax·sendDataToWriter를 호출하는 문장은 이 파일에 없다.
- 84·743–785·933–936: Processed26은 최초 처리 뒤 .TRUE.로 유지된다. IGSW·Names·FileName·SWAN_VOQ는 SwanOutput 종료 전에 해제한다. Processed26을 .FALSE.로 되돌리는 문장은 이 파일에 없다.
- 1185–1190·1213–1218: ICETIMEFRAC 계산은 CICE_TIMINC로 나눈다. 해당 분모 검사와 비율의 0..1 제한은 이 블록들에 없다. SWAN_IICE=3 분기의 SWAN_PIC 계산 결과는 그 분기에서 후속 조건이나 대입식에 사용되지 않는다.
- 1087·1090–1099·1242–1246: CouplingInterval은 정수이며 SWAN_DT/DT 결과를 대입한다. RunStartDateTime에 '-'가 있으면 SwanTimeStep=0으로 설정하고 없으면 DTRETI 결과로 단계 수를 계산한다. 실행 시 InterpoWeight는 0.5D0으로 설정한다.
