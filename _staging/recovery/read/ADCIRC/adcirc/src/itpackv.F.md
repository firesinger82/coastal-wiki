## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 68·459–470: jcg의 j·nandex·lnans·gnans·iimax는 선언 뒤 실행문에서 참조하지 않는다(63–456). itjcg의 j·rhotmp·vic1·vic2도 선언 뒤 실행문에서 참조하지 않는다(459–604).
- 470·525·551–552·581·856–857: itjcg의 q1 선언에는 초기값이 없다. save 문장은 지역 상태를 유지한다. itjcg는 pstop_nrms 호출 전에 q1을 조건식에서 참조한다. pstop_nrms의 0번째 반복 경로는 q1을 false로 설정한다.
- 613·644: peror는 work(n)을 선언한다. 인수 설명 주석은 work 길이를 2*n으로 적는다.
- 809·813·838·869: pstop_nrms는 입력 unrm을 받으며 udnm에 복사한다. 인수 설명 주석은 u를 현재 해 추정값으로 적는다.
- 975·998·1011–1024: chgcon의 레이블 120은 상대 변화 조건에서 진입한다. 레이블 130으로 이동하는 실행 조건은 `if (ier.ne.0) go to 130` (998)이다. 레이블 130 앞 주석은 cme>1을 중단 이유로 적는다(1015–1016).
- 1051–1053: determ는 n==2 검사 전에 wk2(n-1)·wk1(n-1)을 사용한다. 이 함수에는 n<2인 입력을 반환하는 선행 조건이 없다.
- 1586–1587·2856·2876–2881: eqrt1s는 `i = ismin(n-k+1,d(k),1)` (1586)의 반환값을 `delta = min(qp,d(i))` (1587)에 그대로 사용한다. ismin의 incx=1 경로는 전달된 sx 배열의 1..n 위치를 반환한다. eqrt1s에는 반환 위치에 k-1을 더하는 보정문이 없다.
- 1154: 실행문은 `iparm(12) = 3 !jgf46.00 changed to -3, was 0`이다. 같은 행의 주석은 -3으로 바꾸었다고 적는다.
- 1774·1825–1839: parcon의 ibmth는 인수로 선언되지만 실행문에서 참조하지 않는다. ibmth별 gamma 분기와 isym별 rho 분기는 주석 처리되어 있다. 실행 gamma 식은 1826행에 조건 없이 남아 있다.
- 1977–1981·1994·1998–2000: pmult의 주석은 c=a*b와 단위 대각을 적는다. 실행문은 b를 c에 복사한 뒤 `c(i) = c(i) - coef(i,j)*b(jcoef(i,j))` (2000)를 수행한다. coef의 외부 구성은 이 판독에서 확인하지 않았다.
- 2335–2356: scal는 첫 저장 열이 대각이 아니고 maxnz<2일 때 ier=402를 설정한다. maxnz>=2의 검색 루프 뒤에는 대각 성분을 찾았는지 검사하는 조건이나 ier=402 대입이 없다.
- 2359–2364·2424–2479: scal는 음수 대각 행의 계수와 rhs 부호를 뒤집고 지역 nsgncg를 늘린다. unscal에는 그 행들의 부호를 다시 뒤집는 실행문이 없다.
- 2386·2472: scal는 비대각 저장 열의 jcoef<=0을 자기 행 인덱스로 바꾼다. unscal는 비대각 저장 열에서 자기 행을 가리키는 jcoef를 0으로 바꾼다. 원래 인덱스 값을 별도로 저장하는 실행문은 두 루틴에 없다.
- 2790–2802·2805–2817: whenige·whenilt는 inc 인수를 선언한다. 두 루틴의 실행 루프는 i=1..n이며 inc를 참조하지 않는다.
- 2828–2845: sdot는 incx·incy를 선언한다. 내적 누적은 sx(i)·sy(i)를 사용하며 두 증가폭을 참조하지 않는다.
- 2858·2863–2871: ismin의 incx!=1 경로는 `ns = n*incx` (2863)와 `do 20 i = 1,ns,incx` (2865)를 사용한다. incx=0 검사와 음수 증가폭의 시작 인덱스 보정은 이 함수에 없다.
- 2850·2852·2891·2893: ismin과 scopy의 배열은 real(8)이다. 두 설명 주석은 single precision이라고 적는다.
- 2897–2908·2915–2937: scopy의 세 경로는 incx만으로 선택한다. incx=1 경로는 sy(i)=sx(i)를 사용한다. incx>1 경로도 같은 인덱스 i를 두 배열에 사용한다. 두 경로에는 incy를 사용하는 실행문이 없다.
