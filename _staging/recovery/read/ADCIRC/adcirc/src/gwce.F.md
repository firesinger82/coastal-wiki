## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 163–164·182–223: 주석은 conventional GWCE와 predictor-corrector GWCE를 상호 배타적인 선택으로 설명한다. 실행부는 CPRECOR와 CGWCE_New를 각각 독립된 IF로 검사한다. 두 플래그 설정 위치는 이 파일 밖이므로 판독하지 않았다.
- 643–650·712–716: 일관 행렬의 CMPI 경로는 EP=PSDOT(...) 뒤 SQRT(RNP_GLOBAL*EP)를 사용한다. 비-CMPI 경로와 집중 행렬 경로는 대각 제곱 합 뒤 SQRT(EP/NP)를 사용한다. PSDOT 내부는 이 파일 밖이므로 판독하지 않았다.
- 680–688·728–741: 대각이 0이면 EP로 대체한다. DIE는 대각이 음수일 때만 true로 바뀐다. 종료 메시지는 대각이 <=0이라고 적는다.
- 690–702: debug.txt를 unit 899로 열고 닫는다. 그 사이 노드·요소·면적 write의 출력 unit은 6이다. 해당 블록에는 unit 899로 쓰는 문장이 없다.
- 1326–1329: Cfac 계산 전의 Ma2는 G*DPavg/Cs2이다. CfacS0 계산 전에도 Ma2는 G*DPavg/Cs2로 대입한다. CfacS0의 거듭제곱 항은 DPavgS0를 사용한다.
- 1659–1673: 비주기 수위 경계의 TimeLoc>ETIME2 검사는 IF이다. 참 분기는 입력 시간 경계를 한 번 ETIMINC만큼 이동한다. ETRATIO=(TimeLoc-ETIME1)/ETIMINC를 계산한 뒤 이 블록에는 ETRATIO를 0..1로 제한하는 문장이 없다.
- 1697–1701: 역기압 경계 수위 보정은 기준 기압으로 101300.d0를 직접 사용한다. 흡수층 내부 기압 대체는 PRBCKGRND_MH2O를 사용한다(1162·1165·1168).
- 2003–2005·2034: GWCE_New는 JCG에서 IER를 받는다. 호출 뒤 GWCE_New의 실행부에는 IER를 검사하는 조건이 없다. ITPACKV 내부의 오류 처리는 이 파일 밖이므로 판독하지 않았다.
- 2292·2361·2379·2450·2665–2670: 수정자 응력장 구성 조건은 대칭 선택 CGWCE_LS_2PartSV·CGWCE_LS_2PartSQ를 포함한다. 이후 MX·MY를 계산하는 2 Part 조건은 CGWCE_LS_2PartQ·CGWCE_LS_2PartV만 포함한다. GWCE_New의 대응 조건에는 네 플래그 모두 있다(1267–1268).
- 2673–2678·2734–2736: 수정자 DispX·DispY 계산은 C3D 조건 안에 있다. DispXAvg·DispYAvg 대입 조건은 C3D.or.(CBaroclinic.and.abs(IDEN).eq.5)이다. 해당 루틴의 선언에는 DispX·DispY 초기값이 없고, 그 밖에 이 두 변수에 값을 대입하는 실행문은 없다.
- 2597–2625·2708–2713: 수정자 BSX0N·BSY0N·BSX2N·BSY2N 대입은 C2DDI 분기 안에 있다. C3D 분기는 현재 BSXN·BSYN만 대입한다. 시간 0·2 저면 응력 평균 계산은 두 분기 밖에 있다.
- 2488–2491: 수정자 비선형 항 가중값 timewtgwce0/1/2는 매 호출 0.33d0·0.34d0·0.33d0로 직접 대입한다. timeagflag는 1.0d0로 직접 대입한다.
- 1649·1671–1672·2945·2963–2964: GWCE_New와 수정자는 주기 수위를 Eta2에 누적한다. GWCE_New의 비주기 수위 대입은 기존 Eta2에 보간값을 더한다. 수정자의 비주기 수위 대입은 보간값으로 Eta2를 덮어쓴다.
- 1758–1760·1799–1801·2997–2999: GWCE_New의 코드 32 경계는 QN2−QN0, 2*ETAS, EN2−EN0와 DT2를 사용한다. 수정자의 첫 경계 노드 코드 32는 QN1−QN0, ETAS, EN1−EN0와 DT를 사용한다.
- 483–495·1213–1228·2309–2315·2631–2638: GWCE_New는 요소의 SFMXEle·SFMYEle 등으로 미분 계수를 조정한다. 수정자는 노드 SFAC 평균과 X·Y 좌표 차분으로 미분 계수를 직접 계산한다.
- 2984–3003·3010–3028: 수정자의 QFORCEJ 분기는 코드 <=29·64·30·32·40·41을 검사한다. 이 수정자 경계 블록에는 코드 52 분기가 없다. GWCE_New에는 코드 52 분기가 있다(1767–1775·1808–1816).
- 1821–1831·3032–3036: GWCE_New의 코드 64는 NodeCode 곱 없이 노드별 3*QForce 가중치를 적용한다. 수정자의 경계 적분은 코드 64를 따로 나누지 않고 NCI*NCJ와 2*QForceI+QForceJ 형태를 사용한다.
- 3047–3071: 수정자 수위 경계 처리는 OBCCOEF를 사용한다. 수정자 해법은 ILump 조건 없이 COEF와 JCG를 사용한다. GWCE_New는 ILump=0의 JCG와 ELSE의 COEFDTemp 나눗셈을 구분한다(2000–2022).
- 2007·2020·3075: GWCE_New의 새 수위 계산은 ETAS에 dynamicWaterLevelCorrectionDelta를 더한다. 수정자의 새 수위 계산은 NODECODE*ETAS+ETA1이다.
- 3070–3088: GWCE_new_pc도 JCG에서 IER를 받는다. 호출 뒤 해당 루틴에는 IER 검사 조건이 없다.
- 3265: APPLY_SLOPE_LIMITS의 LOG_SCOPE_TRACED 문자열은 "check_slopes"이다. check_slopes 루틴도 같은 문자열을 사용한다(3128).
- 3262–3271: elevSum은 SAVE allocatable 배열이다. firstCall=true일 때 LocNP 크기로 한 번 할당한다. 이후 호출에서 LocNP 변화에 따라 재할당하는 분기는 이 루틴에 없다.
