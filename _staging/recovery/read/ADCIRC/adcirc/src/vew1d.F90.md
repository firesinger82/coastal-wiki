## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 151·189·293: 정방향 회전의 반환 조건은 `if (.not. NCondensedNodes(IND) /= 2) return` (151)이다. 역방향 회전은 `if (NCondensedNodes(IND) /= 2) return` (189)이다. 법선 제거는 `if (NCondensedNodes(IND) /= 2) return` (293)이다. 정방향 조건에만 .not.가 붙는다.
- 350–352: ROTATE_OR_NOT의 경계 코드 조건은 `else if (LBCODEI(IBND) == 0 .or. LBCODEI(IBND) == 1 .or. &` (350); `LBCODEI(IBND) == 10 .or. LBCODEI(IBND) == 1 .or. &` (351); `LBCODEI(IBND) == 20 .or. LBCODEI(IBND) == 21) then` (352)이다. 코드 1 검사가 두 번 들어 있다(350·351).
- 124–132: 흐름 방향은 두 절점 쌍 중점의 차를 LEN으로 나누어 정규화한다. LEN=0을 검사하는 분기는 이 계산 블록에 없다.
- 49–52·59–67·69–105·119–132: GET_STREAMDIRECTION_AT_ELEMENT의 실패 경로는 STATUS=-1을 설정하고 반환한다. 첫 실패 경로(59–67)는 다른 INTENT(OUT) 인수에 값을 대입하지 않는다. 중점 좌표·SX·SY 대입은 모든 실패 검사 뒤에 있다(124–132).
- 259–270: ROTATEBACK_AT_CONDENSEDNODES_ALL은 GET_STREAMDIRECTION_AT_ELEMENT에서 CAX·CAY·CBX·CBY·SX·SY를 받는다. 이후 세 역회전 호출에는 이 값을 전달하지 않는다. 후속 실행문은 STATUS를 검사하고 각 절점 번호를 전달한다.
- 365–371: CondensedNodePairFound의 참조 행 선택 조건은 `if (CondensedNodes(N1, 1) < 0) then` (365)이다. 음수 분기의 인덱스 식은 `N = abs(CondensedNodes(N1, 1))` (366)이다. 이 함수에는 N의 배열 범위를 검사하는 분기가 없다. 검색 횟수는 CondensedNodesNoOfVals로 고정한다.
- 393·397–410: FIND_IB2는 비양수 요소 인덱스를 CYCLE로 건너뛴다. 양수 요소의 세 꼭짓점 중 N1이 없으면 문자 메시지가 있는 STOP으로 종료한다(410).
