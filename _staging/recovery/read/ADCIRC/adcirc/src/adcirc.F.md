## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 6–9·67–68: 머리말은 LGPL 3 이상에 따른 재배포·수정을 허용한다고 적는다. 뒤의 기존 주석은 저자 서면 허가 없는 복제·재배포를 금지한다고 적는다. 문구 차이만 확인했다.
- 118–119: SIZES의 ONLY 목록에 mnwproc가 두 번 등장한다.
- 178–201·214–219·233–236: 명령행 옵션 처리의 myproc=0 검사는 MSG_INIT 호출과 직렬 MYPROC=0 대입보다 앞에 있다. 이 파일 밖 myproc 초기화는 확인하지 않았다.
- 165·170·443·532–534: iargc는 선언 뒤 호출하지 않는다. 각 루틴의 start_time·end_time은 선언 뒤 사용하지 않는다. ADCIRC_Final의 I도 선언 뒤 사용하지 않는다.
- 321–329: IHOT의 CASE DEFAULT는 화면 출력 조건과 오류 WRITE만 갖는다. 이 분기에는 EXIT 또는 terminate 호출이 없다.
