## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 100–102·1473: CkCd 설명 주석의 첫 항은 0.00055*Vmax이다. 실행 적합식의 첫 항은 0.00055d0*Vm**2d0이다.
- 346–350: 파일 열림 검사라는 주석 아래 inquire는 IOSTAT만 받는다. OPENED 또는 ACTION 값을 받는 인수는 이 문장에 없다.
- 388–391: CLE15의 WindMultiplier 경고 조건은 WindMultiplier-1.0d0>eps이다. 1보다 작은 배율을 별도로 경고하는 분기는 없다.
- 480–485·529–534·742–783: 초기화 배경 계수, 주 모델 호출, 이동 속도 선택의 select에는 case default가 없다. 문자열에서 식별자로 변환하는 함수에는 case default와 terminate가 있다(162–172·219–229·276–286).
- 606·1201·1582: update_storm_eye_position의 선언 순서는 lat, lon, EyeLon, EyeLat, FoundEye이다. HollandGet 호출은 lon, lat, EyeLon, EyeLat, FoundEye 순서이다. CLE15GET 호출은 lat, lon, EyeLat, EyeLon, FoundEye 순서이다.
- 844–853·857–866: 시각 초과 시 카운터 증가문은 한 번 실행되는 if 안에 있다. LonOut/LatOut은 WTRATIO 갱신문보다 먼저 계산된다. CALM을 포함하는 else에는 WTRATIO 대입이 없다(867–874).
- 925–930·1062·1093·464·848: 경로 배열은 전체 입력 행 수 nl로 할당한다. 중복 제거 후 실제 자료 길이는 pl로 저장한다. 종료 시각 검사는 castTime(pl)을 쓰지만 초기화와 시각 진행의 경계 검사는 size(CastTime)을 쓴다. 이 루틴에는 pl로 배열을 축소하는 문장이 없다.
- 897·966–968·978–1009: iNowcastCPress/iNowcastRMW/iNowcastRRP는 선언과 BEST에서의 값 저장 뒤 다른 실행식에서 사용되지 않는다. OFCL의 중심 기압 또는 RMW가 0이면 이전 값을 복사하는 대신 terminate를 호출한다.
- 905·934–950·999–1000·1029·1093: pl의 초기값은 huge(1)이다. 빈 자료 또는 자료 개수 2 미만을 별도로 검사하는 문장은 이 루틴에 없다. 예보 증분이 0이 아닌 경로는 CastTime(i-1)을 참조한다.
- 660·680·745–746·1269·1507–1511: Holland 식은 RAD와 RMW, 이동 속도 가중식은 spd를 분모로 쓴다. 해당 식 앞의 0 분모 검사는 없다. 내부 풍속 반경 배열은 0부터 시작하고 전체 배열을 r로 나눈 뒤 res(1)=0을 대입한다. CLE15 풍속은 정수 km 인덱스로 가져오며 이 접근에서 보간하지 않는다.
- 673·705–707·1258–1301: HollandGet은 WindMultiplier와 기압/풍속 제한식을 적용한다. CLE15GET의 해당 계산에는 WindMultiplier 대입이나 같은 기압/풍속 제한식이 없다.
- 1383–1398·1416–1432: 교차점 없는 종료의 실행 조건은 풍속 차<0.1d0인데 주석에는 가장 가까운 점 풍속<.5로 적혀 있다. 접합 인덱스 차 조건은 <=0인데 주석에는 3개 반경 격자 이내로 적혀 있다. 반경 경계 차 조건은 <=1인데 주석에는 3개 격자로 적혀 있다. num_its>=50은 경계 차 조건과 함께 쓰이며 단독 반복 상한은 없다.
- 1390–1398·1424–1431·1441–1442: 두 경계 폭 종료 경로는 풍속 배열을 계산한 뒤 중간 반경을 갱신하고 그 반경을 r0에 저장한다. 루프 뒤 r_N은 r0로 계산한 직후 size(Vinner)로 다시 대입된다.
- 89·358·699–702·1296–1299·1501–1510·1552: 평균 시간의 설명은 1분 또는 10분이지만 입력값 범위 검사는 이 파일에 없다. 풍속 변환은 값이 1일 때만 실행된다. 입력 CkCd 경로에는 compute_ckcd의 0.4..1.4 제한이 적용되지 않는다. 외부 풍속 식은 w_cool을 분모로 쓰며 이 파일에는 w_cool=0 검사가 없다.
