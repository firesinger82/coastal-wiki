## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 94·114–120·164–166: ierr는 intent(out)이다. first=false이고 115행 재캐시 조건이 거짓이면 116·119행 ierr 대입을 건너뛴다. match=true이면 165행 대입도 건너뛴다. 이 경로에서 ierr를 설정하는 별도 문장은 없다.
- 193·215–218·247: recache_data는 NetCDF 파일을 연 뒤 자료 시각 범위 밖이면 ierr=2로 즉시 return한다. 이 return 전에 nf90_close를 호출하는 문장은 없다.
- 116·119·122–126·140–170: 좌표 조회 루틴은 재캐시 결과 ierr를 검사하여 반환하는 문장이 없이 순위 탐색을 계속한다. match=false이면 MoonSunCoor를 채우는 interpolate 호출을 건너뛴다. 태양 거리의 km2AU 곱셈은 match 조건 밖에 있다.
- 129–138: 보간 인덱스 선택은 j=3..len_times-2, j=2, j=len_times를 처리한다. len_times가 4 이상일 때 j=1과 j=len_times-1을 처리하는 분기는 없다.
- 115·131–137·235: 조회는 times(len_times-4)와 4개 보간 인덱스를 사용한다. recache_data가 계산하는 len_times에 최소 길이를 검사하는 문장은 이 파일에 없다.
- 114–120·233–234: first=false인 조회의 재캐시 조건은 상단 시각 times(len_times-4) 초과이다. 캐시 시작 시각 tbeg(1)보다 이전의 요청을 별도로 재캐시하는 조건은 이 조회 블록에 없다.
- 359·370–381: GET_RANK_UNIFORM은 arr(2)-arr(1)을 ds로 사용한다. 길이 2 이상·ds의 0 여부·전체 표의 등간격 여부를 검사하는 문장은 이 함수에 없다.
- 321–322: 라그랑주 항의 분모는 x(k)-x(i)이다. 같은 좌표값 중복으로 분모가 0이 되는 경우를 검사하는 문장은 이 루틴에 없다.
- 174–176: 가져온 nf90_strerror는 이 파일의 실행문에서 참조하지 않는다.
