## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 103–115·148–155: Rmax 상수 지정이 백분율 지정보다 우선한다는 주석이 있다. 두 지정이 모두 참이면 백분율을 쓰지 않는다는 경고를 출력한다.
- 199–207·243–270: 입력 레코드의 ipn을 읽지만 이동속도 처리 루프에서 먼저 1013으로 덮어쓴다. 중심기압이 1012보다 크면 ipn을 중심기압+1로 다시 설정한다.
- 273–307·313–326: 첫 사이클 이동속도 대입은 뒤에 다른 CycleTime이 있을 때만 실행된다. 다른 시각을 찾지 못하면 이 블록에는 첫 사이클 uTrans/vTrans/h_speed 대입이 없다. 다음 루프는 h_speed를 참조한다.
- 377–395·512–531: 양의 반경 수가 0일 때 ATCF RMW도 0이면 작업 반경을 40으로 설정한다. 결측 반경 1개를 채우는 식은 이웃 합의 0.5배이며, 해당 case 주석은 이웃 평균의 절반이라고 적는다.
- 613–623·627–634: approach=1의 유효 반경 초과 분기에서는 gamma 제한식이 주석 처리되어 있다(618). 해당 분기의 결측 반경 else에서는 gamma를 0..1로 제한한다(632).
- 742–743: approach=2의 결측 반경 else에서 U_Vr와 V_Vr 모두 `Vr * sin(h_dir(ient)*deg2rad)`를 대입한다.
- 806–813·833–836·966–981: 잘못된 approach·nws·method 분기는 오류 메시지를 출력한다. 이 분기들에는 stop 또는 return이 없다. method default의 메시지는 실행이 종료되었다고 적지만 뒤의 결측 Rmax 루프가 이어진다.
- 897–907·923–934·953–961: method 2·3·4의 사분면 선택은 0이 아닌 플래그 개수 0..3을 case로 다룬다. method 2·3은 실제 ivr 값을 검사하지 않고 첫 레코드 또는 첫 두 레코드의 플래그를 지운다.
- 53–54·199–203·1059–1075: ns/ew는 배열이 아닌 모듈 문자 변수이다. 입력 루프에서 매 레코드 읽고 출력 루프에서 모든 레코드에 같은 ns/ew 변수를 쓴다.
- 1001–1011·1057–1082: 출력 파일을 여는 조건은 인수 nwswrite를 쓴다. 출력 레코드 형식 선택은 모듈 변수 abs(nws)를 쓴다. 두 선택에 불일치 여부를 검사하는 문장은 이 루틴에 없다.
- 1024·1034·1073–1078: NWS19/20 출력 FORMAT의 해역 접두사는 AL로 고정되어 있다. PhiFactors 출력 파일 open·WRITE는 주석 처리되어 있고 NWS20 WRITE 인수에는 PhiFactors가 없다.
- 1196·1445–1447·1637–1643·1813–1818·2142–2148·2539–2545·2880–2883: -F 옵션은 frame을 읽는다. 모든 진단 루틴이 호출하는 initializeDiagnosticOutput은 frame을 0으로 다시 대입한다. 각 진단 루틴의 프레임 선택 조건은 이 초기화 호출 뒤에 있다.
