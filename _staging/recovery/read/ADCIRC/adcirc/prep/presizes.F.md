## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 74–76: memory_alloc은 currmem에 nbytes를 먼저 더한다. 최고값 갱신 조건이 참이면 갱신된 currmem에 nbytes를 다시 더한 값을 highmem에 대입한다.
- 178·429–435·547–560: NBYTE 상수는 8이다. SIZEUP14의 NNEIGH·NM 사용량 식은 요소당 4를 곱한다. SIZEUP14에는 NNEIGH의 명시적 DEALLOCATE 문과 memory_dealloc 호출이 없다.
- 236–237·493–496: BndBCRiver와 NRIVBCN 선언에는 초기값이 없다. 이 파일에서 BndBCRiver 대입은 하천 유형 분기의 true 설정뿐이다. NRIVBCN 대입은 기존 값에 NBN을 더하는 식뿐이다.
- 427–450·462–465·524–527: 연결표 판독값 N은 NM의 인덱스이다. N1·N2·N3과 경계 판독값 IBN은 NNEIGH의 인덱스이다. 해당 배열 접근 앞에 판독 인덱스 범위 조건 검사는 없다.
- 272–274·731–737: SWANOutputControl에는 출력 플래그 일곱 개가 있다. `IF (IOS.ne.0) THEN` (732) 분기는 HS·TPS·DIR 세 플래그만 true로 대입한다. 같은 분기에서 TM01·WIND·TM02·TMM10을 대입하는 문장은 없다.
- 623·761–775: found_tvw_nml 선언에는 초기값이 없다. TVWControl 판독 후 플래그를 대입하는 바깥 분기는 `IF(IOS.GT.0)THEN` (763)과 `ELSEIF(IOS.EQ.0) then` (771)뿐이다. 음수 상태값을 처리하는 분기는 없다.
- 752–757·780–786·795–801·843–888: metControl·waveCoupling·owiWindNetcdf·WarnElevControl·InterpInset·AliDispersionControl·densityControl·nws08Control·baroclinic3D의 판독 상태 검사는 IOS>0이다. 각 검사의 else 분기는 발견 플래그를 true로 설정한다. 이 else 분기에는 음수 상태값도 들어간다.
- 307·312·315·325·624–627: PRESIZES 모듈과 SIZEUP15 지역 선언에 found_WarnElev_nml·found_AliDisp_nml·found_density_nml·found_nws8_nml이라는 같은 이름의 변수가 각각 있다. 각 선언의 기본값은 false이다. 대소문자는 원문에서 다르게 적혀 있다.
- 851–855: READ가 지정하는 이름목록은 InterpInset이다. `IF (IOS.gt.0) THEN` (852) 분기의 미발견 메시지는 WarnElevControl을 가리킨다.
- 1045·1086–1089·1093–1127·1130–1155·1157–1178: MNWP의 기본값은 1이다. NWS2·대형 기상 유형 분기·NWS3·NWS6/7에는 MNWP=MNP 대입이 있다. NWS29·NWS30·NWS17 분기에는 MNWP 대입이 없다.
- 1094·1100·1106·1108·1559·1565: 대형 기상 유형의 바깥 조건은 NWS의 부호를 유지한 값을 8·19와 직접 비교한다. 같은 분기 안의 NWS8·NWS20 검사는 ABS(NWS)를 사용한다. NWS8·NWS19의 안내 출력 검사도 ABS(NWS)를 사용한다.
- 1116–1117: NCICE>=1이며 NRS가 1·2·4·5인 판독문은 WTIMINC·RSTIMINC·CICE_TIMINC를 읽는다. 원문은 이 판독문에 `! NEED TO BE FIXED FOR NWS=20` 주석을 붙인다.
- 1261–1268·1294–1301·1328–1335·1363–1371: 외부 관측점 파일의 OPEN 문은 IOSTAT와 ERR 레이블을 지정한다. 관측점 수를 읽는 READ 문에는 IOSTAT나 ERR가 없다. 뒤의 상태 검사는 OPEN의 ios_stations를 사용한다.
- 242–245·1317–1345·1352–1381·1584–1585: USE_CONC_STAT_FILE과 USE_MET_STAT_FILE 선언에는 초기값이 없다. 농도 플래그 대입은 `IF(IM.EQ.10) THEN` (1317) 분기 안에 있다. 기상 플래그 대입은 `IF(NWS.NE.0) THEN` (1352) 분기 안에 있다. 마지막 안내 출력은 이 모델·기상 조건 밖에서 두 플래그를 검사한다.
- 1256–1277·1289–1310·1323–1344·1358–1380·1477–1495: 2차원 관측점 처리는 음수 개수로 외부 파일을 선택하고 abs로 수를 바꾼다. 3차원 관측점 처리는 수가 0이 아닌지 검사한 뒤 원래 수를 DO 루프의 상한으로 사용한다. 이 3차원 블록에는 abs 변환과 외부 관측점 파일 OPEN 문이 없다. 원문 주석은 세 조건을 2차원 옵션에 맞게 바꿨다고 적는다.
