## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 제목에는 파일명 뒤에 `??`가 남아 있다(403·405).
- 개요는 GFS 조건을 `[NWS](http://adcirc.org/home/documentation/users-manual-v50/parameter-definitions#NWS)=10`, Eta29 조건을 `[NWS](http://adcirc.org/home/documentation/users-manual-v50/parameter-definitions#NWS)=11`로 적는다(407). 입력 배치에는 각각 `110`과 `111`도 포함한다(411·419). 개요에서 추가 값은 설명하지 않는다.
- 개요의 `NWS` 링크는 User’s Manual V50을 가리킨다(407). 탐색 경로는 User’s Manual V51이다(403).
- 개요의 상대 링크 `../model-parameter-and-periodic-boundary-condition-file-fort-15`는 이 Markdown 파일의 디렉터리에서 해석하면 로컬 대상이 없다(407). 같은 입력 파일 설명 디렉터리에는 해당 이름의 `.md` 파일이 있다.
- 변수 링크의 `../../parameter-definitions`는 이 Markdown 파일의 디렉터리에서 해석하면 로컬 대상이 없다(411·413·415·419·425·427·438·442·444·462·466–467). V51 디렉터리의 `parameter-definitions.md`와 `parameter-definitions/index.md`는 존재한다. 대상 문서 내용은 읽지 않았다.
- 입력 반복문은 `LONB\*LATB`를 사용한다(413·425). 격자 크기 설명은 `NWLON\*NWLAT`를 사용한다(440·464). 두 이름의 대응 관계는 이 파일에서 설명하지 않는다.
- Eta 설명은 파일당 하루 자료를 이루는 8개 데이터 세트와 3시간 간격을 명시한다(466). 이어서 `8 sets of met. data must be provided every`와 `WTIMINC`를 적는다(466–467). 두 주기 표현의 관계는 이 파일에서 설명하지 않는다.
- 풍응력 식의 계수 `0.001293`에 대한 단위와 의미를 설명하지 않는다(456·481).
