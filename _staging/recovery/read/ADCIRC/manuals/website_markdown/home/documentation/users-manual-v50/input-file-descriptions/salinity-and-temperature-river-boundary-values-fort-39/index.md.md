If IDEN=2, then the salinity boundary condition values should be used for bc(j,k). If IDEN=3, then the temperature boundary condition values should be used for bc(j,k). If IDEN=4, then the bc(j,k) should be replaced with salbc(j,k),tempbc(j,k).` (423). |
