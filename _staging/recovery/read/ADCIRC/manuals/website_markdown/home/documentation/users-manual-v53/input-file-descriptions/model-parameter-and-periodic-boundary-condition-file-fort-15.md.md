## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 504: NTIF 링크의 앵커는 `#IMparameter-definitions#NTIF`로 적혀 있다.
- 538·554·556: `#Grid_and_Boundary_File`을 가리키는 문서 내부 링크가 있다. 이 파일에는 해당 앵커 정의가 없다.

- 544: `FFACE(k)`에는 변수 정의 링크가 붙어 있지 않다.
- 588: XEC(k) 링크의 앵커에는 `#XEC TARGET=`가 들어 있다.
- 659: `NSPO3DSD`의 링크 앵커는 `#TO3DSDF`이다.
- 723·725·727: 같은 적용 조건 뒤 첫 입력 행은 `TTBCTIMEINC, TTBCSTATIM`을 제시한다(725). 두 번째 입력 행은 `TTBCTIMEINC`를 다시 제시한다(727).
- 779: `&subdomainModeling`의 링크 앵커는 `#submdomainModeling`으로 적혀 있다.
- 783: `inunThresh`의 링크 앵커는 `#inununThresh`로 적혀 있다.
- 785: `nspool\_TVW`의 링크 앵커는 `#TVWControl`이다.
