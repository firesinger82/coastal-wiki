## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 511–518: NWS 값 `120`의 WTIMINC 줄에는 `BLAd`가 적혀 있다(512). 같은 자료 형식의 나머지 행에는 `BLAdj`가 적혀 있다(511·513–518). 문서에는 두 표기의 관계 설명이 없다.
- 410–518: WTIMINC 줄에 나오는 매개변수는 외부 정의 페이지 링크 또는 이름으로 제시한다. 이 파일 본문에는 각 매개변수의 기본값과 범위가 없다. `RSTIMINC`의 fort.23 자료 간격 단위는 `in seconds`라고 적혀 있다(556). 결합 파랑 모형 호출 간격 설명에는 단위가 명시되어 있지 않다(558).
- 166·202·300·368·370·374·375·387·389: CSS의 이미지 경로 3개와 탐색 메뉴의 사진 링크 6개에 대해 그림 파일 없음. `models/ADCIRC/raw/manuals/website_markdown/` 아래에서 해당 로컬 이미지 사본을 찾지 못했다.
