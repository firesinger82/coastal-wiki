- 660: 표시 변수 `NSPO3DSD`의 링크 앵커는 `#TO3DSDF`이다.
- 724·726·728: 두 줄을 읽는다는 조건 뒤 첫 입력 줄은 `TTBCTIMEINC, TTBCSTATIM`이고 둘째 입력 줄은 다시 `TTBCTIMEINC` 하나이다.
