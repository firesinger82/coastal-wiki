| 404–409 | Time-Varying Weir Input File — 시간 변화 위어(time varying weir)의 입력 레코드(record)를 설명한다(404–406). 내부 장벽 경계(internal barrier boundary)에서는 노드 쌍(node pair)을 대상으로 한다(406). 첫 줄의 개수, 뒤따르는 쉼표 구분(comma separated) 변수 줄 및 변수 순서 규칙은 원문과 같다(408). 원문: `The time varying weir input file contains one line for each weir node (or node pair, for internal barrier boundaries) that will change its elevation during the course of the simulation.` (406); `The first line of the file contains the number of time varying weir nodes (or node pairs) that will appear in the file. Each subsequent line contains a comma separated list of variables that describes how the elevation of that weir node (or node pair) should change during the simulation. The exact content of each line depends on the type of elevation change specified for that node (or node pair). The variables on a particular line can appear in any order.` (408). |
| 410–429 | 필수 좌표·변화 유형 — 위어 노드(node)의 위치를 지정하는 필수 좌표(coordinate)를 설명한다(410–418). 내부 경계(internal boundary)의 적용 조건은 원문과 같다(415). 격자(mesh) 검색에서 해당 위치의 위어 노드를 찾지 못하면 코드가 종료된다(420). 표고(elevation) 변화의 계기 또는 시점을 지정하는 유형 목록이 이어진다(422–428). 원문: `The following variables are required for each line:` (410); `**X1** – This is the x-coordinate location of the first node as part of this weir  ` (412); `**Y1** – This is the y-coordinate location of the first node as part of this weir` (413); `If the weir is an internal boundary, a type 24, there are two more required parameters:` (415); `**X2** – This is the x-coordinate location of the second node as part of this weir  ` (417); `**Y2** – This is the y-coordinate location of the second node as part of this weir` (418); `ADCIRC searches the mesh to associate the X1, Y1 coordinates (and X2, Y2 if specified) with the locations of weir nodes. If a weir node is not found at those coordinates, the code will terminate.` (420); `**VARYTYPE** – Specifies the trigger or timing of the elevation change for that node:` (422); `1. One time elevation change based upon time` (424); `2. One time elevation change based upon water surface elevation (WSE)` (425); `3. Schedule based elevation change` (426); `The value of the VARYTYPE variable dictates the additional variables that are required on that line as described in the following sections.` (428). |
| 430–447 | One Time Elevation Change Based Upon Time — 시간에 따른 일회성 표고 변화의 매개변수를 설명한다(430–444). 개별 시간 매개변수는 선택 사항이지만 그 조합은 시작 시각과 종료 시각을 모두 정해야 한다(432). 재시작(hot start) 또는 초기 시작(cold start)에 대한 시간 기준과 기본값은 원문과 같다(434–436). 시작 시간 항과 종료 시간 항은 각각 합산한다(446). 시간 단위와 합산 예는 원문과 같다(437–446). 원문: `One Time Elevation Change Based Upon Time (VARYTYPE=1)` (430); `The following parameters are all optional except that some combination of them must define both a start time and an end time.` (432); `The “Hot” parameter should be set to 1 if the start and end time for the weir elevation change are relative to the simulation hot start time, or set to 0 if they are relative to the simulation cold start time. The Hot parameter is optional and the default value is 0 (times all relative to cold start).` (434); `**Hot** – 1 if time trigger is relative to hot start time, 0 if relative to cold start time  ` (436); `**TimeStartDay** – number of days before start of weir node elevation change  ` (437); `**TimeStartHour** – number of hours before start of weir node elevation change  ` (438); `**TimeStartMin** – number of minutes before start of weir node elevation change  ` (439); `**TimeStartSec** – number of seconds before start of weir node elevation change  ` (440); `**TimeEndDay** – number of days before end of weir node elevation change  ` (441); `**TimeEndHour** – number of hours before end of weir node elevation change  ` (442); `**TimeEndMin** – number of minutes before end of weir node elevation change  ` (443); `**TimeEndSec** – number of seconds before end of weir node elevation change` (444); `The “start” and “end” parameters are additive; for example, specifying TimeStartDay=3.0 and TimeStartHour=12.0 represents a start time of 3.5 days.` (446). |
| 448–453 | 필수 최종 표고·지형 표고 조건 — 최종 위어 표고(weir elevation)의 기준면(datum), 단위 및 양의 방향을 설명한다(448–450). 변화 도중 fort.14의 표고에서 최종 표고까지 시간에 대해 선형 보간(linear interpolation)한다(450). 노드의 지형 표고(topographic elevation)보다 낮아지지 않는 조건을 설명한다(452). 내부 위어의 노드 쌍에도 적용되는 조건은 원문과 같다(452). 원문: `The following additional parameter is required for this type of elevation change:` (448); `**ZF** – This is the final weir elevation in meters relative to the mesh datum (positive up). During elevation change, the weir height elevations will be linearly interpolated in time from the elevation found in the fort.14 file to this elevation.` (450); `The weir will not decrease below the topographic elevation specified at the node. In the case of an internal weir with two nodes, the weir height will not decrease below the topographic elevation of either node.` (452). |
| 454–468 | One Time Elevation Change Based Upon Water Surface Elevation — 높은 수위 또는 해일로 인한 제방(levee)의 갑작스러운 파괴(failure)를 이 유형으로 모의할 수 있다고 적는다(454–456). 최종 표고와 파괴를 일으키는 수면고(water surface elevation, WSE) 매개변수를 요구한다(456–458). 파괴 지속시간(duration)을 정하는 시간 항의 조합을 요구한다(460). 지속시간 항은 합산한다(467). 적용 유형, 단위 및 합산 예는 원문과 같다(454–467). 원문: `One Time Elevation Change Based Upon Water Surface Elevation (VARYTYPE=2)` (454); `The sudden failure of a levee due to high stage or surge could be simulated using this type of weir height variation. The ZF parameter is required for VARYTYPE=2, and the following additional parameters are also required:` (456); `**ETA\_MAX** – Water surface elevation at this weir node which triggers the simulated weir failure at this weir node.` (458); `Some combination of the following parameters must be used specify the duration of weir failure:` (460); `**FailureDurationDay** – Time in days for duration of failure  ` (462); `**FailureDurationHour** – Time in hours for duration of failure  ` (463); `**FailureDurationMin** – Time in minute for duration of failure  ` (464); `**FailureDurationSec** – Time in seconds for duration of failure` (465); `The failure duration parameters are all additive; for example, setting FailureDurationHour to 2.0 and FailureDurationMin to 30.0 results in a failure duration of 2.5 hours.` (467). |
| 469–485 | Schedule Based Elevation Change — 일정(schedule)에 따른 표고 변화는 일정 파일(schedule file)의 이름을 요구한다(469–471). 파일 이름의 기본값이 없으며 매개변수를 생략하면 ADCIRC가 오류 메시지와 함께 중단된다(471). 일정 반복과 시작 시점의 선택 매개변수를 제시한다(473–482). 반복 값, 기본값, 시간 단위 및 시간 기준에 관한 설명은 원문과 같다(475–484). 원문: `Schedule Based Elevation Change (VARYTYPE=3)` (469); `The schedule based elevation change requires an additional ScheduleFile parameter that provides the name of the Schedule File that describes when and how much the weir nodes should change their height. There is no default file name; if this parameter is not specified, ADCIRC will stop with an error message.` (471); `The following parameters are optional for each weir node (or node pair) for VARYTYPE=3 in the Time Varying Weirs Input File:` (473); `**Loop** – Set to 1 if the schedule should repeat from the beginning after it has completed. The default value is 0. Setting Loop to -1 specifies that the schedule should repeat indefinitely.` (475); `**NLoops** – The number of times the schedule should repeat.` (477); `**TimeStartDay** – number of days since hotstart when weir node elevation starts to change  ` (479); `**TimeStartHour** – number of days since hotstart when weir node elevation starts to change  ` (480); `**TimeStartMin** – number of days since hotstart when weir node elevation starts to change  ` (481); `**TimeStartSec** – number of days since hotstart when weir node elevation starts to change` (482); `Notes for VARYTYPE=3: The “TimeStartDay/Hour/etc parameters are relative to either hotstart or coldstart depending on if the line includes the “HOT” parameter and provide a buffer from the start of the current simulation. Using the HOT parameter would offset the schedule.` (484). |
| 486–489 | Important Consideration for use of this file — 재시작 모의는 이전 모의에서 발생한 위어 표고 변화를 알지 못한다고 적는다(486–488). 현재 모의를 위한 새 입력 파일에서 달리 지정하지 않으면 fort.14의 표고를 사용한다(488). 현재 모의 시작 전에 지정된 위어 표고 변화는 재시작 중에도 고려하지 않는다고 적는다(488). 첫 ADCIRC 시간 단계(time step) 전의 사건을 가정하지 말라는 지시도 포함한다(488). 원문: `**Important Consideration for use of this file:**` (486); `A hot start simulation will not have any knowledge of the change in weir elevations that occurred in the previous simulation and will always use the fort.14 elevation unless specified otherwise in a new time varying weir input file tailored to the current simulation. The time varying weir input file should not assume anything happens prior to the first ADCIRC time step and weir elevation changes prescribed before the start of the current simulation, even during hot start, will not be considered` (488). |
| 490–504 | 웹페이지 끝부분 — 유틸리티 호출과 링크 미리 가져오기(prefetch) 설정이 들어 있다(492–494). 쿠키 안내문, jQuery 코드 및 New Relic 정보가 이어진다(497–504). 주변 빈 줄도 이 구간에 포함한다(490–504). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 438–440·480–482행: 시간 기반 유형의 `TimeStartHour`, `TimeStartMin`, `TimeStartSec` 설명은 각각 hours, minutes, seconds이다. 일정 기반 유형의 같은 이름 설명은 모두 `number of days`이다.
- 479–482행: 일정 기반 시작 시간 항은 `since hotstart`로 설명한다. 484행은 `HOT` 포함 여부에 따라 hotstart 또는 coldstart 기준이라고 설명한다.
- 434·436·484행: 시간 기준 매개변수는 434·436행에서 `Hot`으로 표기한다. 484행에서는 `HOT`으로 표기한다.
