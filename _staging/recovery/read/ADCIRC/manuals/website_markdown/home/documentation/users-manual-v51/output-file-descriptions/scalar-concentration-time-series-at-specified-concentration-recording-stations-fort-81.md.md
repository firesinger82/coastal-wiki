## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 411·413·415–425·429: 411행은 NOUTC에 따른 ascii/binary 출력을 설명한다. 413행은 `Not supported yet.`라고 적지만 지원되지 않는 대상을 명시하지 않는다. 뒤에는 파일 구조와 binary 출력의 번호 제외 조건이 이어진다.
