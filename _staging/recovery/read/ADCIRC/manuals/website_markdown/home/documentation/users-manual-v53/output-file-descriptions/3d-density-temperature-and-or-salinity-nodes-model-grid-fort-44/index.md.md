## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 416·434·452·470행: 첫 출력 형식의 둘째 머리글 마지막 변수는 `IDEN`이다. 나머지 출력 형식의 같은 위치에는 `IRTYPE`이 적혀 있다. 두 이름의 관계는 이 파일 본문에 설명하지 않는다.
- 438·456·474행: 438·456행의 괄호 안 반복 항에는 `SIGMA(N)`이 두 번 적혀 있다. 474행의 같은 반복 항에는 `SIGMA(N)`이 세 번 적혀 있다. 474행의 반복 항 밖에는 `SIGMA(NFEN)`이 두 번 적혀 있다. 같은 항을 반복하는 이유는 이 파일 본문에 설명하지 않는다.
