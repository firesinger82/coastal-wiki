## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 402행: 이동 경로의 Home과 Documentation 사이에 내용 없는 항목을 나타내는 연속 구분자 `»  »`가 있다.
- 416행: 첫 주파수 변수의 링크 표시가 `[**HAFREQ(****k)**]`로 적혀 있다. 여는 괄호와 첨자 k 사이에 별표 네 개가 들어 있다.
- 408·412–426행: 원문은 매개변수 정의 페이지에 연결한다. 이 파일 안에는 주파수 정보 변수와 유속 조화 성분 변수의 단위 및 `PHASEDU(k,j)`·`PHASEDV(k,j)`의 위상 기준이 적혀 있지 않다.
