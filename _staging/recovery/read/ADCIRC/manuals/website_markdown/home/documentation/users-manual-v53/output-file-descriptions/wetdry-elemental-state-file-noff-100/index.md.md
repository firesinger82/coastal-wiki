## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 412행: 일정 설명 문장 끝은 `i.e., the values of TOUTSGE, TOUTFGE, are used NSPOOLGE.`이다. 이 문장은 `NSPOOLGE`가 앞의 두 값과 어떻게 연결되는지 별도로 설명하지 않는다.
- 402·416–424행: 본문 경로 표시는 `User’s Manual – v53`이다(402). 파일 형식 예시의 변수 정의 링크는 `users-manual-v52` 경로를 사용한다(416·418·420·422·424).
