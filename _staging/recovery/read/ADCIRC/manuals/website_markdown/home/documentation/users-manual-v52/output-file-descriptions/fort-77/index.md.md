When this file is written in sparse format and therefore only receiving data for a small portion of the nodes (the weirs) the numbering will be referenced to the global node number. Only the change in elevation from the original fort.14 specified elevation will be written to the file.` (406)이다. 굵은 변수 줄·빈 줄·반복문(loop)과 변수 정의 링크의 읽는 방법을 설명한다(408). |

| 421–436 | 웹페이지 바닥의 공통 스크립트와 빈 줄. 유틸리티 표시 호출(424), 링크 미리 가져오기(prefetch) 설정(426), CDATA 경계 주석과 쿠키 안내 설정(429–431), Soliloquy의 jQuery 호출(435), New Relic 계측 정보(436)를 포함한다. |
