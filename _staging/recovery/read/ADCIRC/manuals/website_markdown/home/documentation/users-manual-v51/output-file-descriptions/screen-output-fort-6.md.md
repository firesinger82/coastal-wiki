# screen-output-fort-6.md — 판독 구간 기록

구간은 1행부터 421행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–12 | 웹 계측 스크립트 — New Relic 브라우저 계측(browser instrumentation)의 초기 설정과 축약된 JavaScript가 있다(1–2). 뒤의 빈 줄도 이 구간에 포함한다(3–12). |
| 13–60 | 페이지 양식 / 검색·제목·외곽 — 스타일 시트(CSS)가 검색 입력란과 검색 버튼의 크기 및 여백을 정한다(13–25). 링크·제목·본문의 색과 글꼴을 정한다(26–51). 외곽 컨테이너의 폭과 최소 크기를 정한다(52–60). |
| 61–111 | 페이지 양식 / 머리글·본문 — 머리글과 태그 표시의 배치를 정한다(61–70). 본문 열과 내용 영역의 배치를 정한다(71–93). 문단과 링크의 표시를 정한다(94–111). |
| 112–142 | 페이지 양식 / 탐색 경로·인용·열 — 오른쪽 목록과 탐색 경로(breadcrumb)의 표시를 정한다(112–125). 활성 탐색 링크, 인용문, 소제목과 본문 열의 표시를 정한다(126–142). |
| 143–200 | 페이지 양식 / 메뉴 배치 — 기본 메뉴의 폭과 목록 배치를 정한다(143–167). 메뉴 링크와 하위 메뉴의 위치·크기·표시를 정한다(168–200). |
| 201–230 | 페이지 양식 / 메뉴 상태·이미지 크기 — 마우스를 올린 메뉴와 현재 페이지 메뉴의 표시를 정한다(201–225). 슬라이드 영역·메뉴 글자·태그 표시를 정한다(226–228). 자동 크기 이미지에 사용할 내재 크기를 정한다(230). |
| 231–240 | 페이지 제목·구조화 메타데이터 — 페이지 제목이 있다(232). JSON-LD 메타데이터가 페이지 주소·제목·발행일·탐색 경로와 사이트 검색 동작을 담는다(235). 빈 줄도 이 구간에 포함한다(231·233–234·236–240). |
| 241–258 | 이모지 표시 스크립트·양식 — WordPress 이모지(emoji) 주소 설정과 지원 여부 검사 스크립트가 있다(241–245). 이모지 이미지의 크기·정렬·여백을 정한다(248–258). |
| 259–284 | WordPress 기본 양식 — 자동 생성 표시와 버튼 양식이 있다(261–262). 기본 비율·색·글자 크기·간격·그림자와 블록 배치 양식이 있다(265–268). 앞뒤 빈 줄도 이 구간에 포함한다(259–260·263–264·269–284). |
| 285–302 | 관리 표시·방문 계측·배경 — 관리 지원 표시의 배경색을 정한다(285–287). 방문 계측용 데이터 배열과 설정 호출이 있다(291–297). 사이트 배경 이미지의 주소와 반복 표시 양식이 있다(299). 공백 행도 이 구간에 포함한다(288–290·298·300–302). |
| 303–320 | 사이트 머리글·공동체 탐색 — 빈 제목 표시, ADCIRC 사이트 링크, 공식 사이트 표제와 탐색 건너뛰기 링크가 있다(303–309). 공동체(Community) 메뉴가 개발 그룹·협력 기관을 나열한다(311–320). |
| 321–357 | 문서 탐색 — 사용자 메뉴 링크가 있다(321). Documentation 메뉴가 V50·V51·v52·v53 사용자 설명서, 입력·출력 설명, 버전 이력과 컴파일·명령행·FAQ 문서를 나열한다(322–347). 예제·보고서·개발 안내·이론 보고서·얼음 피복 수정 자료·하위 영역 모델링 링크가 있다(348–357). |
| 358–392 | 관련 소프트웨어·소식 탐색 — 유틸리티 프로그램과 격자 생성기 링크가 있다(358–360). 소식 메뉴가 사용자 모임·발표·사진·워크숍 자료·예보·허리케인 예제 링크를 나열한다(361–392). |
| 393–402 | 제품 탐색·현재 경로 — 제품 메뉴가 조석 데이터베이스·관련 논문·격자·폭풍해일 예보·표층 기름 이동 링크를 나열한다(393–398). ASGS 링크가 있다(399). 탐색 경로가 현재 문서까지 이어진다(401). 빈 줄도 이 구간에 포함한다(400·402). |
| 403–406 | 화면 출력(Screen output, fort.6) — 절 제목이 있다(403). 모델 매개변수 및 주기 경계조건 파일(Model Parameter and Periodic Boundary Condition File)에 지정한 `NSCREEN` 값에 따라 제한된 실행 정보(run time information)를 화면에 출력한다고 설명한다(405). 적용 조건 원문은 `Depending on the value assigned to [**NSCREEN**](../../parameter-definitions#NSCREEN) in the [Model Parameter and Periodic Boundary Condition File](../../input-file-descriptions/model-parameter-and-periodic-boundary-condition-file-fort-15), limited run time information is printed on the screen.` (405)이다. 빈 줄도 이 구간에 포함한다(404·406). |
| 407–421 | 사이트 끝 스크립트 — 유틸리티 표시 호출이 있다(409). 문서 링크 사전 가져오기(prefetch) 설정이 있다(411). 쿠키 고지 문구와 버튼 설정이 있다(414–416). 슬라이드의 no-js 클래스를 제거하고 New Relic 계측 정보를 설정한다(420–421). 나머지 빈 줄도 이 구간에 포함한다(407–408·410·412–413·417–419). |
