| 157–230 | 웹 페이지 스타일 / 하위 메뉴 — 목록과 하위 메뉴의 위치·크기·호버(hover) 표시, 현재 메뉴의 글자색, 이미지의 내재 크기 규칙을 지정한다(157–230). 메뉴 구분 배경 그림 `images/primary\_nav\_divider.gif`(166)와 호버 배경 그림 `images/primary\_nav\_bg\_repeat\_on.gif`(202)은 그림 파일 없음. |

| 357–398 | 사이트 메뉴 / Related software·News·Products·ASGS — 유틸리티와 격자 생성 소프트웨어를 연결한다(357–359). 뉴스 메뉴는 2020–2008년 회의·교육·발표·일정·단체 사진과 허리케인 예측·모의 자료를 연결한다(360–391). 사진 링크 6개의 로컬 사본은 그림 파일 없음(366·368·372–373·385·387). 제품 메뉴는 조석 데이터베이스(tidal database), 논문, 격자, 폭풍해일 안내와 표면 기름 이동을 연결한다(392–397). ASGS 저장소 링크를 담는다(398). |
| 399–415 | User’s Manuals, Compile Options, FAQs, Wiki / 본문 링크 목록 — 이동 경로와 절 제목을 담는다(400–402). 본문은 소개·ADCIRC 구조·위키·v50·v51·v52 매뉴얼을 연결한다(404–409). 컴파일 시 동작·명령행 옵션·FAQ·v52 FAQ·ADCIRC와 SWAN 결합 실행을 연결한다(410–414). 이 구간은 링크 목록이며 옵션 값이나 입력 파일 예제 본문을 제공하지 않는다(404–414). |
| 416–430 | 페이지 끝 / 웹 유틸리티·쿠키·감시 설정 — 빈 줄과 웹 유틸리티 호출을 포함한다(416–418). 링크 미리 가져오기(prefetch) 대상·제외 규칙, 쿠키 사용 동의 안내, 슬라이드 컨테이너 초기화와 New Relic 정보가 들어 있다(420–430). |
