| 403–423 | Ice Coverage Input Files / 해빙 입력·파일 선택 — 해빙장(ice field)이 풍속과 해빙 피복률(ice coverage percentage)에 따른 바람 항력계수(wind drag coefficient) 변경에만 영향을 준다고 설명한다(407). Garratt와 IceCube 계수 중 큰 값을 택하되 항력 상한(drag cap) 이하이어야 한다고 적는다(409). 해빙이 없는 지역의 항력계수는 Garratt와 같다고 적는다(409). fort.15 변경, 초 단위 시간 간격, 시간 선형 보간(linear interpolation)과 최소 자료 수를 제시한다(411). fort.25의 매개변수 행과 fort.225·fort.227 선택 조건을 제시한다(413–418). 해빙 백분율과 육지·자료 없음의 처리 규칙을 제시한다(418). fort.221과 같은 OWI 형식을 사용한다(420). OWI 기상 자료와 해빙 자료의 격자 크기·자료 시간 간격은 같을 필요가 없다고 적는다(422–423). 원문: `ADCIRC has the ability to incorporate ice fields into the computation of wind drag coefficients. The only influence that these ice fields has on ADCIRC’s solution procedure is that they are used to modify the wind drag coefficients based on wind speed and percentage of ice coverage.` (407); `When using ice fields, the wind drag coefficient is first computed by the usual Garratt formula based on wind speed, then a wind drag coefficient is computed by a new function called IceCube that is based solely on the percent of ice coverage, then the maximum of the Garratt and IceCube drag coefficients is taken but must still be less than or equal to the drag cap in ADCIRC. If there is no ice in a particular area, then the drag coefficient is the same as Garratt.` (409); `In order to use ice field data, two changes are required to an existing fort.15: the ten thousands place must be set to 12 (see the NWS Simplified Table of Values for details), and the time increment of the ice field data (CICE\_TIMINC) in seconds must be supplied on the WTIMINC line (see the Supplemental Meteorology/Wave/Ice Parameters table for details). Ice coverage datasets are linearly interpolated in time by ADCIRC, as a result, at least two datasets are required.` (411); `The ASCII text fort.25 file is only used to specify two general parameters for the Ice coverage data. The file format is as follows:` (413); `[numIceFields](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions/#numIceFields)  ` (415); `[numBlankIceSnaps](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions/#numBlankIceSnaps)` (416); `If n[numIceFields](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions/#numIceFields) in the fort.25 file is set to 1, only the fort.225 file will be read; if [numIceFields](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions/#numIceFields) in the fort.25 file is set to 2 then both the fort.225 and fort.227 files will be read. The fort.225 (the basin scale, i.e., large scale coarse grid) and optional fort.227 (the region scale, i.e., smaller scale finer grid) files contain the actual ice percentage values (0.0 to 100.0%) and a value of -1.0 which means land or no data available. A value of -1.0% is treated as 0.0% ice in ADCIRC.` (418); `These files are formatted exactly like the fort.221 barometric pressure files for the OWI win/pre meteorological data format (NWS=12). The data represent the percentage of area covered by ice within a grid cell. Grid dimensions and cell sizes are contained in the header lines of the fort.225 files.` (420); `If OWI-formatted meteorological forcing and ice coverage data are both used, the grid dimensions for ice coverage and meteorological data do not have to be the same; nor do the time increments  ` (422); `between data sets.` (423). |
| 424–448 | Method for Specifying the Coefficient of Drag — 해빙의 공기역학적 거칠기(aerodynamic roughness) 영향을 다룬 문헌을 소개한다(427–431). 기본값이 아닌 RaysIce의 이차식과 IC 범위 및 DragLawString 선택을 제시한다(433–435). 피복률 50%에서 최대 항력계수이며 50%를 중심으로 대칭이라고 설명한다(437). 해빙 계수가 표준 Garratt 값보다 크면 표준 계수를 대체한다고 설명한다(441). DragLawString 미지정 또는 IceCube·default 지정 시 IceCube를 사용한다(443). 기본 IceCube 삼차식과 IC별 값·기울기를 제시한다(445–447). 수식은 LaTeX가 아닌 원문 텍스트로 옮긴다. 원문: `The ADCIRC model ordinarily uses the wind drag coefficient formulation of Garratt (1977) in the calculation of surface wind stresses. It is a widely-used formulation and it has been found to work well for storm surge applications.` (427); `More recent work (Birnbaum and Lupkes (2002) and Garbrecht et. al. (2002)) has formalized the effect of form drag on the specification of wind drag coefficients within marginal ice zones. From their work, Chapman et. al. (2005) utilized an empirical fit to the range of field data for the air-ice-water wind drag coefficient, CDF, and suggested:` (431); `CDF = [0.125 + 0.5 IC (1.0 – IC)] 10^-2 (RaysIce formulation, this is not the default)` (433); `in which IC is the ice concentration varying from 0.0 to 1.0 for open water and complete ice cover conditions, respectively. To specify this quadratic formulation for the wind drag, set the DragLawString parameter in the fort.15 file to “RaysIce”.` (435); `Inspection of the air-ice-water wind drag coefficient formula shows that a maximum value of 0.0025 occurs with 50% ice coverage. This value is very close to the Macklin (1983) measurement of 0.0028 for first year ice. Furthermore, it is seen that the value of the drag coefficient is symmetrical about 50% ice coverage suggesting that drag coefficient needed to represent 75% ice coverage is close to that of 25% ice coverage.` (437); `An alternative linear fit dependence on ice concentration has been applied by Danard et. al. (1989). These notions regarding variation of wind drag coefficient with ice cover have been supported by a number of Chukchi and Beaufort Sea storm surge simulations (Henry and Heaps, 1976; Kowalik, 1984; and Schafer, 1966) in which, wind drag coefficients greater than or equal to 0.0025 where utilized.` (439); `The method adopted for inclusion in ADCIRC considers the increased wind drag due to the presence of ice as developed by Chapman et. al. (2005). The method requires reading ice field concentration files into ADCIRC and calculating the wind drag coefficient values (variable over the model domain) using the form specified above. If ice cover is present, and the increased drag coefficient exceeds the value calculated using the standard Garratt (1997) formulation, the standard Garratt drag coefficient is replaced with the increased value associated with ice cover.` (441); `The IceCube formulation is used if the DragLawString is not specified in the fort.15, or is specified as “IceCube” or “default”. IceCube is a cubic function that represents a smoother transition between Garratt and the RaysIce formulation for low ice cover percentages and low wind speeds. This function is as follows:”` (443); `CDF = [0.075 + 0.75 IC – 0.9 IC^2 + 0.2 IC^3 ] 10^-2 (IceCube formulation, this is the default)` (445); `When IC = 0 the drag coefficient is equal to the minimum value for Garratt (.000075), when IC = 50 it has a value of 0.0025 and a zero gradient, and when IC = 100 it has a value of 0.00125.` (447). |
