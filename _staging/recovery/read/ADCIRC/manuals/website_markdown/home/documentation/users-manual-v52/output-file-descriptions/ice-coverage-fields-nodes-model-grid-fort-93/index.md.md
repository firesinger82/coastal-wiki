This file is only generated when ice fields are used and when global meteorology output is specified for outputting. The settings for global meteorology output are ([NOUTGW](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#NOUTGW), [TOUTSGW, TOUTFGW, NSPOOLGW](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#NOUTGW)) in the ADCIRC fort.15 input file.` (406)이다. 굵은 변수명은 출력 행을 나타낸다(408). 빈 줄은 가독성을 위한 표시이다(408). 반복문(loop)은 여러 출력 행을 나타낸다(408). 형식 선택은 `Output may be in ascii or binary format depending on how [NOUTGW](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#NOUTGW) is set in the [Model Parameter and Periodic Boundary Condition File](../../input-file-descriptions/model-parameter-and-periodic-boundary-condition-file-fort-15)` (410)이다. |
