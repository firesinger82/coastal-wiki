| 405–410 | Rivers Above Sea Level Initialization File (fort.88) / 목적·읽기 — 다른 입력 파일과 같은 디렉터리에 파일이 있으면 냉시작(cold start) 때 자동으로 읽는다(407). 하상이 평균 해수면(mean sea level)보다 높은 하천의 물 표면고(water surface elevation)를 초기화한다(409). ADCIRC는 보통 이런 지역을 처음에 건조 상태로 지정한다고 적는다(409). 건조 하상에 유입 경계 조건(influx boundary condition)으로 초기화하기 어렵다는 설명을 포함한다(409). 원문: `The ADCIRC Initialization File for Rivers Above Mean Sea Level (fort.88) will be read in automatically upon cold start if it is found in the same directory as the other input files.` (407); `This file is used to initialize the water surface elevation for rivers whose bed rises above mean sea level. Normally ADCIRC would automatically designate such areas as initially dry. In addition, these areas are difficult to initialize properly with an influx boundary condition on a dry river bed. As a result of these difficulties, the fort.88 file was created.` (409). |
| 411–414 | fort.88 / 적용 조건 — 절점 속성(nodal attribute) `sea\_surface\_height\_above\_geoid`를 읽었으면 그 조정을 적용한 뒤 냉시작에서만 fort.88 값을 적용한다(411). 이 속성을 읽은 경우 fort.88 물 표면고가 속성 값보다 클 때만 적용한다(411). fort.88 값이 0 이하이면 어떤 경우든 무시한다(413). 원문: `The values found in the fort.88 file are applied only at cold start, after applying the adjustment resulting from the loading of the sea\_surface\_height\_above\_geoid nodal attribute (if any). If this nodal attribute has been loaded, then the water surface elevation value from the fort.88 will only be applied if it is greater than the nodal attribute value.` (411); `If a water surface elevation value from the fort.88 file is zero or less, it will be ignored in any case.` (413). |
