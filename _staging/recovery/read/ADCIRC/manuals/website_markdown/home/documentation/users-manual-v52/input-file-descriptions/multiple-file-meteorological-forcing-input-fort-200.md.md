In either case, additional sets of meteorological data must be provided every [WTIMINC](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#WTIMINC), in appropriately named files. Meteorological data is interpolated in time to the ADCIRC time step.` (443); `Wind velocity (@ 10 m above the water surface) must be input in units of m/s. Surface atmospheric pressure must be input in units of Pascals = Newtons/square meter.` (445). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 232·237·402·404: 제목의 파일 목록은 `fort.200, ??`로 적혀 있다. `??`의 뜻은 이 파일에 정의되어 있지 않다.
- 412·424·439·463: 입력 반복문은 `LONB\*LATB`를 사용한다(412·424). 격자 크기 설명은 `NWLON\*NWLAT`를 사용한다(439·463). 이 두 표기의 관계는 이 파일에 정의되어 있지 않다.
- 465–466: 한 파일에는 3시간 간격의 8개 자료 세트가 들어 있어 하루 자료를 포함한다고 적는다(465). 같은 설명의 뒤 문장은 `8 sets of met. data must be provided every` (465)와 WTIMINC를 잇는다(466). 두 표현을 원문 그대로 기록했다.
