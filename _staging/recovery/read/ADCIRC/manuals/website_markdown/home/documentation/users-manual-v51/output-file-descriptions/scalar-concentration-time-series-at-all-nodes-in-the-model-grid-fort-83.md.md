## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 405·407·419·427: 표제와 설명은 전체 격자 절점을 출력 대상으로 제시한다. 루프 상한은 `NP`이다(419). 427행은 같은 번호 `k`를 `station number (k)`라고 부른다.
