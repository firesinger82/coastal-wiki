## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 504: NTIF 링크의 fragment가 `#IMparameter-definitions#NTIF`로 적혀 있다.
- 538·554·556: Grid and Boundary Information File 링크는 `#Grid_and_Boundary_File`을 가리킨다. 이 파일에는 그 이름의 앵커(anchor)가 없다.
- 538·554·556: NFFR 입력 조건은 IBTYPE에 `52`를 포함한다(538). 뒤 두 경계 값 입력 행의 조건에는 `2, 12, 22`와 `32`만 적혀 있다(554·556). 이 두 행에는 IBTYPE = 52의 입력 형태가 없다.
- 544: `FFACE(k)`에는 변수 정의 링크가 없다.
- 588: XEC(k) 링크의 fragment는 `#XEC TARGET=`로 적혀 있다.
- 659: NSPO3DSD 링크는 같은 행의 TO3DSDF와 동일한 `#TO3DSDF`를 가리킨다.
- 725·727: 첫 입력 행에는 `TTBCTIMEINC`와 `TTBCSTATIM`이 있다(725). 다음 입력 행은 `TTBCTIMEINC`를 다시 적는다(727).
- 779: 표시 이름은 `&subdomainModeling`이고 링크 fragment는 `#submdomainModeling`이다.
- 783: 표시 이름은 `inunThresh`이고 링크 fragment는 `#inununThresh`이다. 같은 행의 형식 자리표시자는 `logicalValue0`이다.
- 785: nspool_TVW 링크는 `#TVWControl`을 가리킨다.
