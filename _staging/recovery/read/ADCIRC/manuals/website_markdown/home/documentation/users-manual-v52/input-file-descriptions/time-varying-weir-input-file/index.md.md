| 406–421 | Time-Varying Weir Input File / 파일 구조·필수 좌표 — 시간 변화 보(weir)의 절점 또는 내부 장벽 경계(internal barrier boundary)의 절점 쌍에 대한 레코드를 설명한다(406–408). 필수 좌표와 격자 검색 실패 시 종료 조건을 제시한다(410–420). 원문: `The time varying weir input file contains one line for each weir node (or node pair, for internal barrier boundaries) that will change its elevation during the course of the simulation.` (406); `The first line of the file contains the number of time varying weir nodes (or node pairs) that will appear in the file. Each subsequent line contains a comma separated list of variables that describes how the elevation of that weir node (or node pair) should change during the simulation. The exact content of each line depends on the type of elevation change specified for that node (or node pair). The variables on a particular line can appear in any order.` (408); `The following variables are required for each line:` (410); `**X1** – This is the x-coordinate location of the first node as part of this weir  ` (412); `**Y1** – This is the y-coordinate location of the first node as part of this weir` (413); `If the weir is an internal boundary, a type 24, there are two more required parameters:` (415); `**X2** – This is the x-coordinate location of the second node as part of this weir  ` (417); `**Y2** – This is the y-coordinate location of the second node as part of this weir` (418); `ADCIRC searches the mesh to associate the X1, Y1 coordinates (and X2, Y2 if specified) with the locations of weir nodes. If a weir node is not found at those coordinates, the code will terminate.` (420). |
| 422–429 | VARYTYPE / 높이 변화 종류 — 높이 변화의 계기(trigger) 또는 시점에 대한 선택지를 나열한다(422–426). 선택한 종류에 따라 추가 필수 변수가 결정된다고 설명한다(428). 원문: `**VARYTYPE** – Specifies the trigger or timing of the elevation change for that node:` (422); `1. One time elevation change based upon time` (424); `2. One time elevation change based upon water surface elevation (WSE)` (425); `3. Schedule based elevation change` (426); `The value of the VARYTYPE variable dictates the additional variables that are required on that line as described in the following sections.` (428). |
| 430–453 | One Time Elevation Change Based Upon Time — 시각 기준 단일 높이 변화의 시간 기준·단위·기본값·합산 예를 제시한다(430–446). 최종 보 높이(final weir elevation)의 단위·격자 기준면(mesh datum)·양의 방향·시간 보간(time interpolation)을 설명한다(448–450). 지형고(topographic elevation)에 따른 하강 제한을 제시한다(452). 원문: `One Time Elevation Change Based Upon Time (VARYTYPE=1)` (430); `The following parameters are all optional except that some combination of them must define both a start time and an end time.` (432); `The “Hot” parameter should be set to 1 if the start and end time for the weir elevation change are relative to the simulation hot start time, or set to 0 if they are relative to the simulation cold start time. The Hot parameter is optional and the default value is 0 (times all relative to cold start).` (434); `**Hot** – 1 if time trigger is relative to hot start time, 0 if relative to cold start time  ` (436); `**TimeStartDay** – number of days before start of weir node elevation change  ` (437); `**TimeStartHour** – number of hours before start of weir node elevation change  ` (438); `**TimeStartMin** – number of minutes before start of weir node elevation change  ` (439); `**TimeStartSec** – number of seconds before start of weir node elevation change  ` (440); `**TimeEndDay** – number of days before end of weir node elevation change  ` (441); `**TimeEndHour** – number of hours before end of weir node elevation change  ` (442); `**TimeEndMin** – number of minutes before end of weir node elevation change  ` (443); `**TimeEndSec** – number of seconds before end of weir node elevation change` (444); `The “start” and “end” parameters are additive; for example, specifying TimeStartDay=3.0 and TimeStartHour=12.0 represents a start time of 3.5 days.` (446); `The following additional parameter is required for this type of elevation change:` (448); `**ZF** – This is the final weir elevation in meters relative to the mesh datum (positive up). During elevation change, the weir height elevations will be linearly interpolated in time from the elevation found in the fort.14 file to this elevation.` (450); `The weir will not decrease below the topographic elevation specified at the node. In the case of an internal weir with two nodes, the weir height will not decrease below the topographic elevation of either node.` (452). |
| 454–468 | One Time Elevation Change Based Upon Water Surface Elevation — 수면고(water surface elevation, WSE)에 의한 보 파괴(weir failure)의 필수 변수와 지속시간 지정 의무를 제시한다(454–460). 지속시간의 단위별 필드와 합산 예를 제시한다(462–467). 원문: `One Time Elevation Change Based Upon Water Surface Elevation (VARYTYPE=2)` (454); `The sudden failure of a levee due to high stage or surge could be simulated using this type of weir height variation. The ZF parameter is required for VARYTYPE=2, and the following additional parameters are also required:` (456); `**ETA\_MAX** – Water surface elevation at this weir node which triggers the simulated weir failure at this weir node.` (458); `Some combination of the following parameters must be used specify the duration of weir failure:` (460); `**FailureDurationDay** – Time in days for duration of failure  ` (462); `**FailureDurationHour** – Time in hours for duration of failure  ` (463); `**FailureDurationMin** – Time in minute for duration of failure  ` (464); `**FailureDurationSec** – Time in seconds for duration of failure` (465); `The failure duration parameters are all additive; for example, setting FailureDurationHour to 2.0 and FailureDurationMin to 30.0 results in a failure duration of 2.5 hours.` (467). |
| 469–485 | Schedule Based Elevation Change — 일정(schedule) 파일명 지정 의무와 누락 시 종료 조건을 제시한다(469–471). 반복 설정과 기본값, 시작 시점 필드, 재시작(hot start)·초기 시작(cold start) 기준에 관한 주석을 제시한다(473–484). 원문: `Schedule Based Elevation Change (VARYTYPE=3)` (469); `The schedule based elevation change requires an additional ScheduleFile parameter that provides the name of the Schedule File that describes when and how much the weir nodes should change their height. There is no default file name; if this parameter is not specified, ADCIRC will stop with an error message.` (471); `The following parameters are optional for each weir node (or node pair) for VARYTYPE=3 in the Time Varying Weirs Input File:` (473); `**Loop** – Set to 1 if the schedule should repeat from the beginning after it has completed. The default value is 0. Setting Loop to -1 specifies that the schedule should repeat indefinitely.` (475); `**NLoops** – The number of times the schedule should repeat.` (477); `**TimeStartDay** – number of days since hotstart when weir node elevation starts to change  ` (479); `**TimeStartHour** – number of days since hotstart when weir node elevation starts to change  ` (480); `**TimeStartMin** – number of days since hotstart when weir node elevation starts to change  ` (481); `**TimeStartSec** – number of days since hotstart when weir node elevation starts to change` (482); `Notes for VARYTYPE=3: The “TimeStartDay/Hour/etc parameters are relative to either hotstart or coldstart depending on if the line includes the “HOT” parameter and provide a buffer from the start of the current simulation. Using the HOT parameter would offset the schedule.` (484). |
| 486–491 | Important Consideration for use of this file — 재시작 시 이전 실행의 보 높이 변화를 알지 못하는 제한을 설명한다(486–488). 현재 실행 시작 전에 지정한 보 높이 변화의 처리 제한을 설명한다(488). 489–491행은 빈 줄이다. 원문: `**Important Consideration for use of this file:**` (486); `A hot start simulation will not have any knowledge of the change in weir elevations that occurred in the previous simulation and will always use the fort.14 elevation unless specified otherwise in a new time varying weir input file tailored to the current simulation. The time varying weir input file should not assume anything happens prior to the first ADCIRC time step and weir elevation changes prescribed before the start of the current simulation, even during hot start, will not be considered` (488). |
| 492–504 | 페이지 끝 스크립트 — 사이트 유틸리티 호출(492), 링크 미리 읽기 설정(494), 쿠키 안내문 설정과 주석(497–499)을 포함한다. 표시 클래스 변경(503)과 계측 정보(504)를 포함한다. 나머지 행은 빈 줄이다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 437–440·479–482: 첫 시간 기준 분기는 `TimeStartDay`, `TimeStartHour`, `TimeStartMin`, `TimeStartSec`의 단위를 각각 days, hours, minutes, seconds로 적는다. 일정 기준 분기는 네 필드의 단위를 모두 `number of days`로 적는다.
- 479–484: 일정 기준 분기의 시작 시점 필드 설명은 모두 `since hotstart`로 적는다. 뒤 주석은 시간 기준이 `HOT` 포함 여부에 따라 hotstart 또는 coldstart라고 적는다.
- 434–436·484: 시간 기준 매개변수의 표기는 앞 설명에서 `Hot`, 일정 기준 주석에서 `HOT`이다.
