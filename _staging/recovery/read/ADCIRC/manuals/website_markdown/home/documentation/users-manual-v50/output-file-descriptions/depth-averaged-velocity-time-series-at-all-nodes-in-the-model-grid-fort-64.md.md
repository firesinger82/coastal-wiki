ASCII 또는 바이너리(binary) 출력의 선택 조건은 `Output may be in ascii or binary format depending on how [NOUTGV](../../parameter-definitions#NOUTGV) is set in the [Model Parameter and Periodic Boundary Condition File](../../input-file-descriptions/model-parameter-and-periodic-boundary-condition-file-fort-15)` (411)이다. |

| 425–427 | 바이너리 출력의 번호 제외 조건. 주석 제목 `**Note:**` (425) 다음에 `If binary output is specified, the node number (k) is not included in the output.` (427)이 있다. 426행은 빈 줄이다. |
