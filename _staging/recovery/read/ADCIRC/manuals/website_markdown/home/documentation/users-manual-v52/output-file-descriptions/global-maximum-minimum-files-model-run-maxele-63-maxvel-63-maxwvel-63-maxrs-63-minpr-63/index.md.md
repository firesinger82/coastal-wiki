| 402–408 | 전체 모의의 전역 최대·최소 파일(global maximum and minimum files). 이동 경로(402)와 파일 이름들을 나열한 절 제목 `# Global Maximum and Minimum files for the Model Run (maxele.63, maxvel.63, maxwvel.63, maxrs.63, minpr.63)` (404)를 포함한다. 전 영역(full domain) 시계열(time series)은 파일이 매우 커질 수 있고 관측 지점 시계열은 전 영역을 포괄하지 못하며 짧은 극값(extreme value) 사건을 담으려면 잦은 저장이 필요하다고 설명한다(406). 매 시간 단계(time step)의 극값 수집 대상, 파랑 복사 응력(wave radiation stress)의 사용 가능 조건, 마지막 시간 단계 이후의 파일 쓰기 조건은 `As a result, ADCIRC collects extreme values at every time step for water surface elevation, water velocity, wind velocity, wave radiation stress (if available), and barometric pressure for the files listed above. The files are then written out after the last time step of the simulation is complete.` (408)이다. |
| 409–414 | 핫스타트(hotstart)와 버전별 데이터 집합(data set). 모의를 시작할 때 실행 디렉터리의 극값 파일을 읽으려 시도한다(410). 파일을 찾으면 이전 극값에서 시작하여 이전 실행 부분과 핫스타트 실행 부분의 극값을 결합한다(410). 데이터 집합 수, 두 번째 집합의 콜드스타트(cold start) 이후 초 단위 시간, 이전 버전의 차이는 `In ADCIRC version 51, these files contain two full domain data sets: the first contains the extreme value at each node, while the second contains time (in seconds since cold start) that the extreme value occurred at each node. In previous ADCIRC versions, only the first data set appears in the file.` (412)이다. 굵은 변수 줄·빈 줄·반복문(loop)과 변수 정의 링크의 읽는 방법을 설명한다(414). |
| 415–428 | 출력 형식과 첫 번째 데이터 집합. ASCII 또는 이진(binary) 출력의 적용 조건은 `Output may be in ascii or binary format depending on how [NOUTGE](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#NOUTGE) is set in the [Model Parameter and Periodic Boundary Condition File](../../input-file-descriptions/model-parameter-and-periodic-boundary-condition-file-fort-15)` (416)이다. 파일 첫머리 줄은 `[**RUNDES**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#RUNDES), [**RUNID**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#RUNID), [**AGRID**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#AGRID)` (418)이다. 두 번째 줄은 `**2**, [**NP**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#NP), **[DTDP](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#DTDP)\*[NSPOOLGE](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#NSPOOLGE)**, [**NSPOOLGE**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#NSPOOLGE), [**IRTYPE**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#IRTYPE)` (420)이다. 첫 항의 두 데이터 집합 수와 곱 표현을 원문 그대로 옮겼다(420). 첫 집합의 뒤따르는 줄·반복 구조·극값 출력 줄은 `[**TIME**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#TIME), [**IT**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#IT)` (422); `for k=1, [NP](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#NP)` (424); `**k**, **extreme**` (426); `end k loop` (428)이다. 빈 줄을 포함한다(415–428). |
| 429–436 | 두 번째 데이터 집합: 극값 발생 시간. 시간 줄, 절점 반복문, 절점 번호와 극값 발생 시간의 출력 줄, 반복문 종료는 `[**TIME**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#TIME), [**IT**](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#IT)` (430); `for k=1, [NP](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions#NP)` (432); `**k**, **time\_of\_extreme(k)**` (434); `end k loop` (436)이다. 앞뒤 빈 줄을 포함한다(429–436). |
| 437–452 | 웹페이지 바닥의 공통 스크립트와 빈 줄. 유틸리티 표시 호출(440), 링크 미리 가져오기(prefetch) 설정(442), CDATA 경계 주석과 쿠키 안내 설정(445–447), Soliloquy의 jQuery 호출(451), New Relic 계측 정보(452)를 포함한다. |
