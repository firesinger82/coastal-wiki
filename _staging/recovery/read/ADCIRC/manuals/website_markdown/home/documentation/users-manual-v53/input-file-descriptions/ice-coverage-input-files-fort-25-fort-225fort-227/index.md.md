| 404–423 | Ice Coverage Input Files / 적용과 파일 형식 — 얼음 피복(ice coverage) 자료는 바람 속도와 피복 비율에 따라 풍항력 계수(wind drag coefficient)를 수정하며, 이것만이 ADCIRC 해법에 미치는 영향이라고 적는다(406). Garratt 계수와 IceCube 계수 중 최대를 취하되 ADCIRC 항력 상한(drag cap) 이하이어야 한다(408). 얼음이 없는 영역에서는 Garratt 계수와 같다고 적는다(408). fort.15 변경, 자료의 초 단위 시간 간격, 시간 선형 보간(linear interpolation)에 필요한 자료 집합 수를 명시한다(410). fort.25의 ASCII(American Standard Code for Information Interchange) 형식과 fort.225·fort.227 선택 조건을 제시한다(412–417). 얼음 자료는 OWI 기상 자료의 fort.221 기압 파일과 같은 형식이라고 적는다(419). 두 자료의 격자 크기와 시간 간격은 같을 필요가 없다(421–422). 적용 조건·매개변수·입력 형식 원문: `ADCIRC has the ability to incorporate ice fields into the computation of wind drag coefficients. The only influence that these ice fields has on ADCIRC’s solution procedure is thaaat they are used to modify the wind drag coefficients based on wind speed and percentage of ice coverage.` (406); `When using ice fields, the wind drag coefficient is first computed by the usual Garratt formula based on wind speed, then a wind drag coefficient is computed by a new function called IceCube that is based solely on the percent of ice coverage, then the maximum of the Garratt and IceCube drag coefficients is taken but must still be less than or equal to the drag cap in ADCIRC. If there is no ice in a particular area, then the drag coefficient is the same as Garratt.` (408); `In order to use ice field data, two changes are required to an existing fort.15: the ten thousands place must be set to 12 (see the NWS Simplified Table of Values for details), and the time increment of the ice field data (CICE\_TIMINC) in seconds must be supplied on the WTIMINC line (see the Supplemental Meteorology/Wave/Ice Parameters table for details). Ice coverage datasets are linearly interpolated in time by ADCIRC, as a result, at least two datasets are required.` (410); `The ASCII text fort.25 file is only used to specify two general parameters for the Ice coverage data. The file format is as follows:` (412); `[numIceFields](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions/#numIceFields)  ` (414); `[numBlankIceSnaps](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions/#numBlankIceSnaps)` (415); `If n[numIceFields](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions/#numIceFields) in the fort.25 file is set to 1, only the fort.225 file will be read; if [numIceFields](https://adcirc.org/home/documentation/users-manual-v52/parameter-definitions/#numIceFields) in the fort.25 file is set to 2 then both the fort.225 and fort.227 files will be read. The fort.225 (the basin scale, i.e., large scale coarse grid) and optional fort.227 (the region scale, i.e., smaller scale finer grid) files contain the actual ice percentage values (0.0 to 100.0%) and a value of -1.0 which means land or no data available. A value of -1.0% is treated as 0.0% ice in ADCIRC.` (417); `These files are formatted exactly like the fort.221 barometric pressure files for the OWI win/pre meteorological data format (NWS=12). The data represent the percentage of area covered by ice within a grid cell. Grid dimensions and cell sizes are contained in the header lines of the fort.225 files.` (419); `If OWI-formatted meteorological forcing and ice coverage data are both used, the grid dimensions for ice coverage and meteorological data do not have to be the same; nor do the time increments  ` (421); `between data sets.` (422). |
| 424–441 | Method for Specifying the Coefficient of Drag / RaysIce — 표면 바람 응력(surface wind stress)에 사용하는 Garratt 식과 얼음 영역의 관측·형상 항력(form drag) 연구를 소개한다(426–430). RaysIce 식은 기본값이 아니며 IC의 범위와 DragLawString 설정을 제시한다(432–434). 최대값과 대칭성, 선형 적합 연구, 얼음 항력이 표준 Garratt 계수를 넘을 때의 대체 조건을 적는다(436–440). 수식·범위·값·적용 조건 원문: `CDF = [0.125 + 0.5 IC (1.0 – IC)] 10^-2 (RaysIce formulation, this is not the default)` (432); `in which IC is the ice concentration varying from 0.0 to 1.0 for open water and complete ice cover conditions, respectively. To specify this quadratic formulation for the wind drag, set the DragLawString parameter in the fort.15 file to “RaysIce”.` (434); `Inspection of the air-ice-water wind drag coefficient formula shows that a maximum value of 0.0025 occurs with 50% ice coverage. This value is very close to the Macklin (1983) measurement of 0.0028 for first year ice. Furthermore, it is seen that the value of the drag coefficient is symmetrical about 50% ice coverage suggesting that drag coefficient needed to represent 75% ice coverage is close to that of 25% ice coverage.` (436); `An alternative linear fit dependence on ice concentration has been applied by Danard et. al. (1989). These notions regarding variation of wind drag coefficient with ice cover have been supported by a number of Chukchi and Beaufort Sea storm surge simulations (Henry and Heaps, 1976; Kowalik, 1984; and Schafer, 1966) in which, wind drag coefficients greater than or equal to 0.0025 where utilized.` (438); `The method adopted for inclusion in ADCIRC considers the increased wind drag due to the presence of ice as developed by Chapman et. al. (2005). The method requires reading ice field concentration files into ADCIRC and calculating the wind drag coefficient values (variable over the model domain) using the form specified above. If ice cover is present, and the increased drag coefficient exceeds the value calculated using the standard Garratt (1997) formulation, the standard Garratt drag coefficient is replaced with the increased value associated with ice cover.` (440). |
| 442–447 | Method for Specifying the Coefficient of Drag / IceCube — DragLawString을 지정하지 않거나 해당 문자열로 지정할 때의 기본 3차 함수를 제시한다(442–444). 낮은 얼음 피복 비율과 낮은 바람 속도에서 더 매끄러운 전환을 나타낸다고 설명한다(442). IC 값별 항력 계수와 기울기를 그대로 적는다(446). 수식·기본값·적용 조건·값 원문: `The IceCube formulation is used if the DragLawString is not specified in the fort.15, or is specified as “IceCube” or “default”. IceCube is a cubic function that represents a smoother transition between Garratt and the RaysIce formulation for low ice cover percentages and low wind speeds. This function is as follows:”` (442); `CDF = [0.075 + 0.75 IC – 0.9 IC^2 + 0.2 IC^3 ] 10^-2 (IceCube formulation, this is the default)` (444); `When IC = 0 the drag coefficient is equal to the minimum value for Garratt (.000075), when IC = 50 it has a value of 0.0025 and a zero gradient, and when IC = 100 it has a value of 0.00125.` (446). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 414–417: v53 페이지의 numIceFields·numBlankIceSnaps 링크는 `users-manual-v52` 주소를 사용한다. 링크 대상의 본문은 이번 판독에서 읽지 않았다.
- 417: 첫 조건의 변수 링크 앞에는 `n`이 붙어 있어 `n[numIceFields]`로 적혀 있다. 414행과 같은 행의 두 번째 조건은 numIceFields로 적는다.
- 434·446: IC의 정의 범위는 `0.0 to 1.0`이다(434). 뒤 값 설명은 `IC = 0`, `IC = 50`, `IC = 100`을 사용한다(446).
- 444·446: IceCube 식의 상수항은 `[0.075 + ...] 10^-2`이다(444). 뒤 설명은 IC가 0일 때의 계수를 `(.000075)`로 적는다(446).
- 426·440·462: Garratt 연도는 일반식 설명과 참고문헌에서 1977이다(426·462). 얼음 항력 대체 설명에서는 `Garratt (1997)`로 적는다(440).
- 428·436·438·448–468: 본문은 Macklin (1983), Pease et. al. (1983), Henry and Heaps (1976)를 인용한다(428·436·438). References 목록에는 이 문헌의 항목이 없다(448–468).
