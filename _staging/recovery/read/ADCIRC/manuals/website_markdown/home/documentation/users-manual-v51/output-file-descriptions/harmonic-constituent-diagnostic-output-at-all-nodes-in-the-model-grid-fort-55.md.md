| 407–412 | Harmonic Constituent Diagnostic Output at All Nodes in the Model Grid (fort.55) / 출력 개요 — 모델이 생성한 수위(elevation)·유속(velocity) 시계열(time series)의 평균(mean)과 분산(variance)을 비교한다(407). 비교 대상은 계산된 조화 성분(harmonic constituent)에서 다시 합성한 시계열의 평균과 분산(variance)이다(407). 이 비교는 조화 분석(harmonic analysis)이 어느 정도 완전했는지 나타내는 지표라고 설명한다(407). 굵은 변수명은 출력 행을 나타낸다(409). 구조 설명의 빈 줄은 가독성을 위한 것이다(409). 반복문(loop)은 여러 출력 행을 뜻한다(409). 변수 정의는 링크로 연결한다(409). 출력은 ASCII 형식이다(411). 원문: `Comparison between the mean and variance of the elevation and velocity time series generated by the model and the mean and variance of a time series resynthesized from the computed harmonic constituents. This gives an indication of how complete the harmonic analysis was.` (407); `Output format is ascii.` (411). |
