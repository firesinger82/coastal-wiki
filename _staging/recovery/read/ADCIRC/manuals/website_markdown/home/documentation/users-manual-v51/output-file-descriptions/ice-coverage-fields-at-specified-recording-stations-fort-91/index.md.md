## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 407·411·413–421: NOUTM과 출력 변수의 정의는 외부 parameter-definitions 링크로 연결된다. 이 파일에는 해당 변수의 기본값·범위·단위를 직접 제시한 설명이 없다. 링크 대상의 본문은 이번 판독 범위에 포함되지 않는다.
