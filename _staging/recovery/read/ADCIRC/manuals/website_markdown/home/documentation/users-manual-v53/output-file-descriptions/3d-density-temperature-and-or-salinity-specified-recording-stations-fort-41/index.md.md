## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 416·453·471: 표시 이름 `NSPO3DSD`인 링크의 앵커(anchor)는 `#I3DSD`이다. 435행의 같은 표시 이름 링크는 `#NSPO3DSD`를 사용한다. 링크 대상의 정의 페이지는 이번 판독에서 읽지 않았다.
- 439·457·475: 439행과 457행의 출력 형식은 `SIGMA(N)`을 각각 두 번 적는다. 475행은 `SIGMA(N)`을 세 번 적고 `SIGMA(NFEN)`을 두 번 적는다.
- 475: 두 번째 `SIGMA(N)` 링크의 대상 문자열은 `https://adcirc.org/home/documentation/users-manual-v53/parameter-definitions#SIGMA TARGET=`이다. 이 문자열은 공백과 `TARGET=`를 포함한다.
- 424·443·461·479: 출력 필드 `J`에는 정의 링크가 없다. 이 문서 본문에는 `J`의 별도 정의가 없다.
