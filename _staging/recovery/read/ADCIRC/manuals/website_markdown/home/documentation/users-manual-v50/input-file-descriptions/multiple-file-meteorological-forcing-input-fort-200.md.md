## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 232·237·403·405: 페이지 제목의 파일명 뒤에 `??`가 남아 있다.
- 413·425·440·462: 입력 반복문의 격자 크기 표기는 `LONB\*LATB`이고 설명 문단의 고정 격자 크기 표기는 `NWLON\*NWLAT`이다. 본문은 두 이름의 관계를 정의하지 않는다.
- 464–465: 같은 문단은 각 파일의 8개 데이터셋이 3시간 간격으로 하루를 구성한다고 적는다. 뒤 문장은 `8 sets of met. data must be provided every`와 `WTIMINC`로 이어진다.
