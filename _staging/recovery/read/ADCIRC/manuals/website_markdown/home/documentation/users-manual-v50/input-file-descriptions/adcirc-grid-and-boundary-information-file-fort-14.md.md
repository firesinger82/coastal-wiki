| 501–507 | 필수·자연 경계 조건의 적용 — 자유 미끄럼(free slip) 필수 경계 조건은 연속방정식(continuity equation)의 경계 유량 적분과 운동량방정식(momentum equation)의 법선 속도를 지정한다(501). 무미끄럼 필수 경계 조건은 경계를 따라 운동량방정식을 푸는 대신 법선 속도와 영 접선 속도를 설정한다(503). 자연 경계 조건은 경계 유량 적분만 지정한다(505). 자연 경계 조건은 운동량방정식의 법선·접선 속도를 제한하지 않는다(505–506). 개별 절점의 법선 흐름은 무한 해상도의 극한에서만 만족한다고 적는다(506). |
| 508–525 | General Notes for Normal Flow Boundary Conditions / 목록·접속 규칙 — 외부 경계를 영역 둘레에서 연속 순서로 먼저 나열하고 내부 경계를 뒤에 나열한다(510). 닫힌 외부 경계와 무법선 흐름 내부 경계는 첫 절점을 마지막에 반복한다(512·514). 닫히지 않은 경계의 시작 절점과 공유 절점 방향 결정 규칙을 설명한다(516–519). 외부 지정 흐름 경계와 외부 제방 경계의 직접 접속을 금지한다(521). 내부 제방과 외부 무법선 흐름 경계의 교점은 약한 의미(weak sense)로 다룬다(523–524). 적용 조건 원문을 함께 옮긴다. 원문: `All external (external no normal flow, external with specified normal flow and external barrier) boundaries should be listed in consecutive order around the outside of the entire domain before any internal (island with no normal flow or internal barrier) boundary segments are listed. Internal barrier boundaries that intersect an external boundary should be specified separately, even though this will result in some nodes being specified in both boundaries, (see below).` (510); `An external no normal flow or specified normal flow boundary that completely surrounds the domain (e.g., a lake) should be closed by repeating the first node as the last node.` (512); `All no normal flow internal boundaries (e.g., islands) should be closed by repeating the first node as the last node.` (514); `Unless the boundary segment is closed, always start listing the boundary nodes where two boundaries connect.` (516); `When an external specified normal flow or external barrier boundary connects to an external no normal flow boundary, the initial leg of the external specified normal flow boundary or external barrier boundary is used to determine the normal and tangential  ` (518); `direction at the node common to both boundaries.` (519); `External boundaries with specified (non-zero) normal flow boundary conditions and external barrier boundaries can not connect. They must be separated by an external no normal flow boundary or an elevation specified boundary.` (521); `An internal barrier boundary can intersect an external no normal flow boundary. (For example a levee may project out of an external no normal flow boundary in which case 2 nodes, the front and back node on the internal barrier boundary, would be common to the  ` (523); `external boundary.) However, the common external nodes must be treated in the weak sense. ADCIRC will automatically accommodate this as follows:` (524). |

| 545–550 | General Notes / 유량 적분·운동량방정식 처리 — 경계 유형별 경계 유량 적분과 법선·접선 운동량방정식 제거 및 속도 설정을 설명한다(545–549). 무미끄럼 조건의 수학적·물리적 정당화에는 측방 점성항과 경계층 해상도 조건을 붙인다(549). 유형 목록과 적용 조건을 원문 그대로 옮긴다. 원문: `For all normal flow boundaries (i.e. [IBTYPE(k)](../../parameter-definitions#IBTYPE) = 0,1,2,3, 4,10,11,12,13,20,21,22,23,24,30), the boundary flux integral in the continuity equation is evaluated with the appropriate (zero, specified or computed) flux. This is a natural boundary condition. For natural normal flow boundaries ([IBTYPE(k)](../../parameter-definitions#IBTYPE) = 20,21,22,23,24), this is the only lateral boundary condition that is used.` (545); `For essential normal flow boundaries with tangential slip ([IBTYPE(k)](../../parameter-definitions#IBTYPE) = 0,1,2,3,4,10,11,12,13), the normal direction momentum equation (obtained by re-orienting the x/y momentum equations into normal/tangential directions) is eliminated and the normal velocity is set by dividing the normal flux per unit width (zero, specified, or computed) by the total water column height.` (547); `For essential normal flow boundaries with no tangential slip ([IBTYPE(k)](../../parameter-definitions#IBTYPE) = 10,11, 12,13), both momentum equations are eliminated. The tangential velocity is set equal to zero and the normal velocity is set by dividing the normal flux per unit width (zero, specified, or computed) by the total water column height. ## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 453·484·490·498행: 절점 번호만 입력하는 조건 목록에는 `102`, `112`, `122`가 없다. 뒤 표는 이 세 유형을 나열한다.
- 453·545·476–499행: 입력 조건과 일반 설명은 `30`을 나열한다. 표 1에는 `30` 행이 없다.
- 486–489·547·549행: 표의 `10`–`13`은 `no slip`이다. 547행의 `essential normal flow boundaries with tangential slip` 목록도 `10,11,12,13`을 포함한다. 549행은 다시 이 유형을 `no tangential slip`으로 설명한다.
- 497–498·545행: 표는 `25`와 `122`를 자연 경계 조건으로 나열한다. 545행의 자연 경계 조건 목록 `20,21,22,23,24`에는 두 유형이 없다.
- 569·612행: 일반 경계 주의사항 참조는 `#NFBC_Note`를 가리킨다. 이 Markdown 파일에는 `NFBC_Note`라는 앵커 정의가 없다.
- 588·596행: 문장은 `less than or equal to 2/3`라고 적는다. 같은 문장의 괄호 안 부등식은 각각 `RBARWL2 < 0.667\*RBARWL1`, `RBARWL1 < 0.667\*RBARWL2`로 적혀 있어 등호가 없다.
- 616행: `This type differs from`이 두 번 이어진다. 첫 부분은 `IBTYPE(k)=5 or 25`, 뒤 부분은 `IBTYPE(k)=4 and 24`를 적는다.
- 630행: 관로 식은 `D^2`를 사용한다. 이 파일의 ADCIRC 본문에는 `D`의 정의가 없다.
- 459·630–662행: 입력 형식은 `PIPEHT`, `PIPECOEF`, `PIPEDIAM`을 적는다. 뒤 관로 식은 `PIPEHTR`, `PIPECOEFR`, `PIPEDIAMR`도 사용한다. 관로 식의 `ETA2`는 이 파일 본문에서 정의하지 않는다.
- 618·648·656행: 관로 설명은 `QN2(k,j)`를 사용한다. 경우 5·6의 식은 `QN2(I)`를 사용한다. 이 식에 쓰인 `I`의 정의는 본문에 없다.
- 648·656행: 648행의 분모에는 `1 +[/PIPECOEF(k,j)](../../parameter-definitions#PIPECOEF)`라는 표기가 있다. 656행의 식 시작은 `QN2(I)= RAMP\*\*0.25`이다. 두 별표를 수정하지 않고 옮겼다.
