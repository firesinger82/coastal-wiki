## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 416·453·471: `NSPO3DSD` 표시명의 링크는 `#I3DSD` 앵커를 가리킨다. 둘째 분기의 같은 표시명은 `#NSPO3DSD` 앵커를 가리킨다(435).
- 475: 둘째 `SIGMA(N)` 링크 주소의 앵커에는 `#SIGMA TARGET=`가 남아 있다.
- 439·457·475: 둘째·셋째 분기의 시각 행은 괄호 안에 `SIGMA(N)`을 두 번 적는다. 넷째 분기의 시각 행은 괄호 안에 `SIGMA(N)`을 세 번 적는다. 이 파일은 반복된 같은 이름의 필드를 구별하는 설명을 제시하지 않는다.
- 408·424·443·461·479: 배열 변수의 정의는 외부 링크로 연결되어 있다. 이 파일 본문에는 밀도·온도·염분 출력값의 단위가 없다.
