## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 166·202·301: CSS가 참조하는 `images/primary\_nav\_divider.gif`, `images/primary\_nav\_bg\_repeat\_on.gif`, `https://adcirc.org/wp-content/uploads/sites/2255/2013/03/grid\_bkgrd\_lt\_grey1.jpg`의 로컬 사본을 `models/ADCIRC/raw/manuals/`의 파일 목록에서 찾지 못했다. 각 참조는 그림 파일 없음이다. 일반 링크가 가리키는 `ADCIRC2018_Group_Photo2.jpg`(369), `2017ADCIRCUGMGroupPhoto.jpg`(371), `160506-A-Y1769-008-A-1.jpg`(375), `adcircBootCampers2016_small_caption.jpg`(376), `2011_ADCIRC_meeting.jpg`(388), `ADCIRC_Workshop2010_GroupPhoto2.png`(390)의 로컬 사본도 같은 파일 목록에서 찾지 못했다. 각 참조는 그림 파일 없음이다.
- 417·454·472: `NSPO3DSD`라는 링크 표시가 `../../parameter-definitions#I3DSD`를 가리킨다. 436행의 같은 변수 링크는 `../../parameter-definitions#NSPO3DSD`를 가리킨다. 링크 대상의 실제 정의는 이번 판독에서 확인하지 않았다.
- 476: 두 번째 `SIGMA(N)` 링크의 대상 문자열은 `../../parameter-definitions#SIGMA TARGET=`이다. 같은 행의 다른 SIGMA 링크에는 `TARGET=`가 없다.
- 409·435–436: 설명은 굵은 변수 행 하나가 출력 한 행을 나타낸다고 적는다. IDEN 조건 2 또는 -2의 헤더는 원문에서 435행과 436행으로 나뉘며 굵게 표시하는 마크업도 두 행에 걸쳐 있다.
- 413·417·431·436·450·454·468·472: 분기 조건은 `IDEN`을 사용한다. 각 분기의 헤더 마지막 변수는 `IRTYPE`이다. 이 파일 본문은 두 변수의 관계를 정의하지 않는다.
- 409·415–480: 문서는 변수 정의를 링크로 제공한다고 설명한다. 이 파일 본문에는 링크된 변수의 정의, 단위와 기본값이 제시되어 있지 않다. 링크 대상 문서는 이번 파일의 판독에 포함하지 않았다.
