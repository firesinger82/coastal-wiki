## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 232·237·402·404: 페이지 제목에 `fort.200, ??`가 남아 있다.
- 412·424·439·463: 입력 반복문의 크기는 `LONB\*LATB`로 적혀 있다(412·424). 격자 크기 설명은 `NWLON\*NWLAT`를 쓴다(439·463). 이 파일은 두 표기의 관계를 정의하지 않는다.
- 455·480: 풍응력 식에 `0.001293`이 들어 있다. 이 파일은 이 상수의 물리량과 단위를 설명하지 않는다.
- 465–466: 465행은 각 파일에 3시간 간격의 자료 8개가 들어 있으며 하루를 나타낸다고 적는다. 이어지는 문장은 `8 sets of met. data must be provided every` (465) 뒤에 `WTIMINC` (466)를 붙인다.
