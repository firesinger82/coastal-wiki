| 405–408 | Introduction / 지배 방정식·이산화 — ADCIRC는 회전하는 지구에서 움직이는 유체의 운동 방정식을 푼다고 설명한다(405–407). 정수압(hydrostatic pressure)과 Boussinesq 근사를 사용한다(407). 공간은 유한요소법(finite element method), 시간은 유한차분법(finite difference method)으로 이산화한다(407). 원문: `ADCIRC is a highly developed computer program for solving the equations of motion for a moving fluid on a rotating earth. These equations have been formulated using the traditional hydrostatic pressure and Boussinesq approximations and have been discretized in space using the finite element (FE) method and in time using the finite difference (FD) method.` (407). |
| 409–412 | Introduction / 차원·좌표 — 이차원 수심 적분(two-dimensional depth integrated, 2DDI) 모델 또는 삼차원(three-dimensional, 3D) 모델로 실행할 수 있다고 설명한다(409). 두 모델은 일반화 파랑 연속 방정식(Generalized Wave-Continuity Equation, GWCE) 형태의 수심 적분 연속 방정식에서 수위를 얻는다(409). 속도는 해당 차원의 운동량 방정식에서 얻고 모든 비선형 항을 유지한다고 설명한다(409). 직교(Cartesian) 또는 구면(spherical) 좌표계를 사용할 수 있다(411). 원문: `ADCIRC can be run either as a two-dimensional depth integrated (2DDI) model or as a three-dimensional (3D) model. In either case, elevation is obtained from the solution of the depth-integrated continuity equation in Generalized Wave-Continuity Equation (GWCE) form. Velocity is obtained from the solution of either the 2DDI or 3D momentum equations. All nonlinear terms have been retained in these equations.` (409); `ADCIRC can be run using either a Cartesian or a spherical coordinate system.` (411). |
| 413–416 | Introduction / 질량 행렬·해법 — 컴파일러 플래그(compiler flag)로 일관 질량 행렬(consistent mass matrix) 또는 집중 질량 행렬(lumped mass matrix)을 선택한다(413). 시간 가중 계수(time weighting coefficients)로 암시적(implicit) 또는 명시적(explicit) 시간 적분을 선택한다(413). 집중 질량 행렬과 완전 명시적 형식을 함께 지정하면 행렬 해법이 필요하지 않다(413). 그 밖의 GWCE 경우는 ITPACKV 2D의 Jacobi 전처리 반복 해법(Jacobi preconditioned iterative solver)을 사용한다고 설명한다(413). 2DDI 운동량 방정식에는 행렬 해법이 필요하지 않다(415). 3D에서는 수직 확산(vertical diffusion)을 암시적으로 처리하고 수직 질량 행렬을 집중하지 않으므로 각 수평 절점(horizontal node)에서 복소 삼중대각 행렬(complex, tri-diagonal matrix) 문제를 푼다고 설명한다(415). 원문: `The GWCE can be solved using either a consistent or a lumped mass matrix (via a compiler flag) and an implicit or explicit time stepping scheme (via variable time weighting coefficients). If a lumped, fully explicit formulation is specified, no matrix solver is necessary. In all other cases the GWCE is solved using the Jacobi preconditioned iterative solver from the ITPACKV 2D package.` (413); `The 2DDI momentum equations are lumped and therefore require no matrix solver. In 3D, vertical diffusion is treated implicitly and the vertical mass matrix is not lumped, thereby requiring the solution of a complex, tri-diagonal matrix problem over the vertical at every horizontal node.` (415). |
| 417–428 | Introduction / 경계조건(boundary conditions) — 지정 수위와 지정 법선 유량(normal flow)은 조석 조화 성분(harmonic tidal constituents) 또는 시계열(time series)로 줄 수 있다(417–420). 영 법선 유량, 속도의 미끄럼 또는 비미끄럼(slip or no slip) 조건이 있다(421–422). 외부 장벽의 영역 밖 월류(barrier overflow), 내부 장벽의 영역 부분 사이 월류가 있다(423–424). 표면 응력(surface stress)은 바람 또는 파랑 복사응력(wave radiation stress)을 포함한다(425). 대기압(atmospheric pressure)과 외향 파랑 방사 조건(outward radiation of waves)을 나열한다(426–427). 방사 조건의 이름은 원문 표기 Sommerfield를 유지한다(427). 원문: `* specified elevation (harmonic tidal constituents or time series)` (419); `* specified normal flow (harmonic tidal constituents or time series)` (420); `* zero normal flow` (421); `* slip or no slip conditions for velocity` (422); `* external barrier overflow out of the domain` (423); `* internal barrier overflow between sections of the domain` (424); `* surface stress (wind and/or wave radiation stress)` (425); `* atmospheric pressure` (426); `* outward radiation of waves (Sommerfield condition)` (427). |
| 429–436 | Introduction / 외력(forcing) — 수위, 법선 유량과 표면 응력 경계조건을 외력으로 나열한다(429–433). 조석 퍼텐셜(tidal potential)과 지구 하중·자기 인력 조석(earth load/self attraction tide)도 나열한다(434–435). 목록과 뒤 빈 줄을 포함한다(431–436). 원문: `* elevation boundary conditions` (431); `* normal flow boundary conditions` (432); `* surface stress boundary conditions` (433); `* tidal potential` (434); `* earth load/self attraction tide` (435). |
| 437–440 | Introduction / 조화 분석·실행 성능 — 최소제곱 분석(least squares analysis)은 실행 중 수위와 수심 평균 속도(depth averaged velocity)의 조화 성분을 계산한다(437). 문서는 이 기능이 후처리를 위한 긴 시계열 출력을 피한다고 설명한다(437). 루프 펼치기(unrolling loops)로 여러 컴퓨터 구조에서 성능을 최적화했다고 설명한다(439). MPI 라이브러리 호출을 통한 병렬 효율의 수치는 이 문서의 표현만 옮긴다(439). 원문은 이를 보통 90 per cent보다 높다고 적는다(439). 원문: `ADCIRC includes a least squares analysis routine that computes harmonic constituents for elevation and depth averaged velocity during the course of the run thereby avoiding the need to write out long time series for post processing.` (437); `ADCIRC has been optimized by unrolling loops for enhanced performance on multiple computer architectures. ADCIRC includes MPI library calls to allow it to operate at high efficiency (typically better than 90 per cent) on parallel computer architectures.` (439). |
| 441–455 | 사이트 뒷부분 / 유틸리티·쿠키·측정 — 앞 빈 줄과 유틸리티 표시 호출이 있다(441–443). 문서 링크 사전 가져오기(prefetch) 설정이 있다(445). UNC 쿠키 안내와 동의 버튼 설정이 있다(448–450). 마지막에는 jQuery 표시 처리와 New Relic 측정 정보가 있다(454–455). 사이의 빈 줄도 포함한다. |
