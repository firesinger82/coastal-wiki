The first dataset records the total accumulated time in seconds that a node was inundated beyond the threshold. Periods of inundation are counted toward the total time, even if they are not contiguous. The second dataset records the time of onset of inundation beyond the threshold in seconds since cold start. The time of onset data are useful in the context of real time model guidance for decision making.` (410)이다. 첫 데이터셋은 임계값을 초과한 누적 시간이다(410). 연속되지 않은 침수 기간도 총 시간에 산입한다(410). 두 번째 데이터셋은 초기 시작 이후의 초 단위 침수 발생 시점이다(410). `inunThresh`의 단위·기본값·범위는 이 파일에 제시되지 않는다(406). |
