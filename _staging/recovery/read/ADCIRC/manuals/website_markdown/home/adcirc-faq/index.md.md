A higher value is generally used in shallower water. See the fort.15 documentation on [adcirc.org](https://adcirc.org/home/documentation/users-manual-v51/input-file-descriptions/model-parameter-and-periodic-boundary-condition-file-fort-15/ "Model Parameter and Periodic Boundary Condition File (fort.15)"), and feel free to consult the ADCIRC mailing list for recommendations for your particular modeling scenario.` (577)이다. fort.15 문서와 메일링 리스트를 가리킨다(577). 웹 자료는 부분 목록이라고 명시한다(579–581). 공식 사이트, Notre Dame 연구실, Casey Dietrich 사이트를 제시한다(583–585). |

| 600–607 | Holland `B`와 밀도·기압 단위 — `B`가 속도 분포의 가파름을 나타내는 곡선 적합 매개변수(curve fit parameter)이며 열대저기압의 기본 속성이 아니라는 설명 원문은 `Once the Vmax and Pmin are established, the Holland B value—a curve fit parameter that indicates the steepness of the velocity profile and is not some sort of fundamental property of tropical cyclones as some seem to believe—can be computed according to the following formula:` (600)이다. 수식 원문은 `B = (Vmax)^2 \* rho\_air \* e / (Pn – Pmin)` (602)이다. `Vmax`·`rho\_air`·`e`·`Pn`·`Pmin`의 정의와 단위 원문은 `where Vmax is in m/s, rho\_air is set to 1.15 kg m^-3 in ADCIRC, e is Euler’s number, Pn is the “far field” atmospheric pressure, and Pmin is the central pressure (pressures in Pa, not mb).` (604)이다. 배경 기압이 1013mb로 설정되며 해역마다 실제 배경 기압이 다를 수 있다는 원문은 `The far field or background pressure is set to 1013mb in ADCIRC.
