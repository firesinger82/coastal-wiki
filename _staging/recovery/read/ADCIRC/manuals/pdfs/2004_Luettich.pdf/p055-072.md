| p.57 | 인쇄 쪽 번호 57. 절 제목은 “6.0 LATERAL BOUNDARY CONDITIONS”이다. 소제목은 “Elevation specified boundary condition –ADCIRC 2DDI and 3D”와 “Specified flux boundary condition –ADCIRC 2DDI”이다.<br>수위 지정 경계조건(elevation specified boundary condition)은 GWCE 식 (1.17)의 해당 경계 절점 행에서 모든 비대각 항을 0으로 만든다. 해당 대각 항은 다른 모든 대각 항의 제곱평균제곱근(root mean square)으로 설정하여 행렬 조건을 유지한다. 우변은 지정 수위와 이 제곱평균제곱근의 곱으로 설정한다. 해당 열의 비대각 항도 0으로 만든다. 제거할 각 열 항과 경계 수위의 곱은 해당 방정식 우변에서 뺀다.<br>단위 폭당 법선 유량(normal flux per unit width)은 육지 경계에서 0이거나 하천 경계에서 0이 아닐 수 있다. 이 유량은 자연 경계조건(natural boundary condition) 또는 필수 경계조건(essential boundary condition)으로 적용할 수 있다. 사용자는 접선 속도(tangential velocity)를 0으로 지정하거나 자유 미끄럼(free slip)을 가정하여 계산하도록 지정할 수 있다. 법선 유량은 GWCE 우변 경계 적분에 삽입한다. 입력 법선 유량의 부호는 영역 유입이 양수이고 유출이 음수이다. GWCE 유도에서는 외향 법선 방향을 양수로 가정하므로 GWCE에 사용하기 전에 법선 유량의 부호를 바꾸어야 한다. 자연 경계조건일 때 운동량 방정식은 수정하지 않는다. 필수 경계조건일 때 수심 평균 법선 속도(depth-average normal velocity) $U_N$은 단위 폭당 법선 유량을 국소 수심으로 나누고 $-1$을 곱한 값으로 강제한다. $U_N$의 양의 방향은 외향 법선이다.<br>$\displaystyle \begin{bmatrix}AUV_1&-AUV_2\\AUV_2&AUV_1\end{bmatrix}\begin{bmatrix}U\\V\end{bmatrix}=\begin{bmatrix}F_x\\F_y\end{bmatrix}\qquad(6.1)$.<br>$AUV_1,AUV_2$는 유한요소 조립(finite element assembly)에서 계산한 행렬 항이다. $F_x,F_y$는 우변 강제력 벡터(forcing vector)를 구성한다. 이 쪽은 유량과 속도의 단위를 별도로 적지 않는다.<br>원문 인용: `If the normal flux is applied as a natural boundary condition, no modifications are made to the momentum equations.` (p.57). |
| p.58 | 인쇄 쪽 번호 58. 6.0절의 유량 지정 경계조건 설명이 이어진다. 법선·접선 좌표계(normal - tangential coordinate system)에서 $U_N,U_T$는 속도 벡터와 단위 벡터 $\hat{N}=(N_x,N_y)$, $\hat{T}=(T_x,T_y)$의 내적으로 정의한다. 단위 벡터 정의는 APPENDIX를 참조한다.<br>$\displaystyle \begin{aligned}UT_x+VT_y&=U_T\\UN_x+VN_y&=U_N\end{aligned}\qquad(6.2)$.<br>법선 유량 지정 절점에서 식 (6.1)의 $y$ 운동량 방정식은 식 (6.2)의 법선 속도식으로 대체한다. $x$ 운동량 방정식은 원래 $x$ 방정식에 $T_x$를 곱한 항과 원래 $y$ 방정식에 $T_y$를 곱한 항을 더한 접선 운동량 방정식으로 대체한다. $T_x=N_y$, $T_y=-N_x$를 사용한다.<br>$\displaystyle \begin{bmatrix}AUV_1N_y-AUV_2N_x&-AUV_2N_y-AUV_1N_x\\N_x&N_y\end{bmatrix}\begin{bmatrix}U\\V\end{bmatrix}=\begin{bmatrix}F_xN_y-F_yN_x\\U_N\end{bmatrix}\qquad(6.3)$.<br>본문은 식 (6.3)의 좌변 행렬이 식 (6.1)의 “symmetry”를 갖지 않는다고 적는다. 법선 방정식에 $AUV_2$를 곱한 식과 접선 운동량 방정식을 더한 뒤 $AUV_1$로 나누어 식 (6.4)를 얻는다.<br>$\displaystyle \begin{bmatrix}N_y&-N_x\\N_x&N_y\end{bmatrix}\begin{bmatrix}U\\V\end{bmatrix}=\begin{bmatrix}\dfrac{F_xN_y-F_yN_x+AUV_2U_N}{AUV_1}\\U_N\end{bmatrix}\qquad(6.4)$.<br>접선 유량도 지정하는 경우에는 식 (6.4)의 첫 방정식 우변을 $U_T$로 대체한다. 접선 유량 0이 예로 제시된다.<br>다음 소제목은 “Zero normal velocity gradient boundary condition – ADCIRC 2DDI (version 42.05)”이다. 법선 방향 속도 기울기 0 경계조건(zero normal velocity gradient boundary condition)은 경계 절점 운동량 방정식을 해당 조건을 강제하는 방정식으로 대체한다. 계산한 속도로 경계 법선 유량을 정하고 다음 시간 단계의 GWCE 경계 유량 적분에 사용한다. 구현 방법은 두 가지이다. 첫 방법은 boundary condition type 40이다. 각 경계 절점에 대응하는 가상 절점(fictitious node)을 영역 내부의 내향 법선 위에 둔다. 가상 절점까지의 거리는 해당 경계 절점에서 가장 먼 이웃 절점까지의 거리와 같다.<br>원문 인용: `The no normal velocity gradient is enforced in ADCIRC using two different approaches.` (p.58). |
| p.59 | 인쇄 쪽 번호 59. 6.0절의 boundary condition type 40 설명이 이어진다. 각 시간 단계에서 법선 방향 속도 기울기 0 경계 절점을 제외한 모든 절점의 속도를 계산한다. 다음으로 각 가상 절점에 속도를 공간 보간(spatial interpolation)한다. 마지막으로 경계 절점 속도를 대응하는 가상 절점 속도로 설정한다. 거리 $d$는 가상 절점이 경계에 바로 붙은 요소층 밖에 놓이도록 선택한다. 따라서 인접한 법선 방향 속도 기울기 0 절점의 속도를 모르더라도 가상 절점의 속도를 보간할 수 있다.<br>그림은 경계 절점, 삼각형 요소, 외향 법선 $N$, 가상 절점, 가장 먼 이웃 절점까지의 거리 $d$와 내향 법선을 따른 같은 거리 $d$를 보여 준다. 수치 축과 비교 곡선은 없다. 그림의 경계 절점 속도는 가상 절점에서 보간한 속도로 설정된다.<br>그림 번호·캡션 원문: `Figure 6.1 Schematic of the configuration used to determine the velocity at a zero normal velocity gradient boundary node. The velocity at the boundary node is set equal to the interpolated velocity at a fictitious node that is a distance d away from the boundary node where d is the distance to the furthest neighbor from that boundary node.`<br>두 번째 방법은 boundary condition type 41이다. 이 방법은 경계 절점에서 다음 조건을 부과한다.<br>$\displaystyle \begin{aligned}\frac{\partial U}{\partial N}&=0\\\frac{\partial V}{\partial N}&=0\end{aligned}\qquad(6.5)$.<br>원문 인용: `Next, the velocity is interpolated in space to each fictitious node.` (p.59). |
| p.60 | 인쇄 쪽 번호 60. 6.0절의 boundary condition type 41 공간 이산화(spatial discretization)를 설명한다.<br>$\displaystyle \begin{aligned}\frac{\partial U}{\partial N}&=N_x\frac{\partial U}{\partial x}+N_y\frac{\partial U}{\partial y}=0\\\frac{\partial V}{\partial N}&=N_x\frac{\partial V}{\partial x}+N_y\frac{\partial V}{\partial y}=0\end{aligned}\qquad(6.6)$.<br>식 (6.6)에 선형 기저함수(linear basis functions)를 사용한 Galerkin 가중 잔차법(Galerkin weighted residual formulation)을 적용한다.<br>$\displaystyle \begin{aligned}&\left\langle N_x\frac{\partial U}{\partial x},\phi_j\right\rangle+\left\langle N_y\frac{\partial U}{\partial y},\phi_j\right\rangle\\&=\sum_{n=1}^{NE_j}\left[\int_{\Omega_n}N_x\frac{\partial U}{\partial x}\phi_j\,d\Omega+\int_{\Omega_n}N_y\frac{\partial U}{\partial y}\phi_j\,d\Omega\right]=\sum_{n=1}^{NE_j}\left[\left(N_x\frac{\partial U}{\partial x}+N_y\frac{\partial U}{\partial y}\right)\int_{\Omega_n}\phi_j\,d\Omega\right]\\&=\sum_{n=1}^{NE_j}\frac{A_n}{3}\left[N_x\sum_{i=1}^{3}U_i\frac{\partial\phi_i}{\partial x}+N_y\sum_{i=1}^{3}U_i\frac{\partial\phi_i}{\partial y}\right]=\sum_{n=1}^{NE_j}\frac{1}{6}\left[N_x\sum_{i=1}^{3}U_ib_i+N_y\sum_{i=1}^{3}U_ia_i\right]=0\\&\left\langle N_x\frac{\partial V}{\partial x},\phi_j\right\rangle+\left\langle N_y\frac{\partial V}{\partial y},\phi_j\right\rangle\\&=\sum_{n=1}^{NE_j}\left[\int_{\Omega_n}N_x\frac{\partial V}{\partial x}\phi_j\,d\Omega+\int_{\Omega_n}N_y\frac{\partial V}{\partial y}\phi_j\,d\Omega\right]=\sum_{n=1}^{NE_j}\left[\left(N_x\frac{\partial V}{\partial x}+N_y\frac{\partial V}{\partial y}\right)\int_{\Omega_n}\phi_j\,d\Omega\right]\\&=\sum_{n=1}^{NE_j}\frac{A_n}{3}\left[N_x\sum_{i=1}^{3}V_i\frac{\partial\phi_i}{\partial x}+N_y\sum_{i=1}^{3}V_i\frac{\partial\phi_i}{\partial y}\right]=\sum_{n=1}^{NE_j}\frac{1}{6}\left[N_x\sum_{i=1}^{3}V_ib_i+N_y\sum_{i=1}^{3}V_ia_i\right]=0\end{aligned}\qquad(6.7)$.<br>식 (6.7)에 상수 6을 곱하고 정리하여 ADCIRC에서 사용하는 다음 식을 얻는다.<br>$\displaystyle \begin{aligned}\sum_{n=1}^{NE_j}\left[\sum_{i=1}^{3}(N_xb_i+N_ya_i)U_i\right]&=0\\\sum_{n=1}^{NE_j}\left[\sum_{i=1}^{3}(N_xb_i+N_ya_i)V_i\right]&=0\end{aligned}\qquad(6.8)$.<br>식 (6.8)을 시간 수준(time level) $s+1$에서만 풀면 $U,V$ 성분에 대한 행렬 구성과 해법이 필요하다. 이를 피하기 위해 식 (6.8)을 시간 수준 $s+1$과 $s$로 나눈다. 각 경계 절점에 붙은 요소에서 절점 1은 경계 절점이다. 절점 2와 3은 요소의 나머지 절점이다. $\phi_i,\phi_j$는 이 유도에서 사용하는 선형 기저함수이다. $NE_j,A_n,a_i,b_i$의 별도 정의와 단위는 이 쪽 본문에 없다.<br>원문 인용: `To avoid this Eq.
