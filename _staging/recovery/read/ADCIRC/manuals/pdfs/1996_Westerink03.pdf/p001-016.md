| p.2 | 인쇄 쪽 번호 2. **2. Basic Methodology**, (a) “Essential No Normal Flow on External Boundaries with Free Tangential Slip Allowed”와 (b) “Essential No Normal Flow on External Boundaries with No Tangential Slip Enforced”. 본질적 경계조건(essential boundary condition)으로 기존의 법선 무유동(no normal flow) 경계조건을 확장한다.<br>(a)는 일반화 파동 연속방정식(Generalized Wave Continuity Equation, GWCE)의 해당 외부 경계 적분을 0으로 둔다. $x$-$y$ 운동량 방정식(momentum equation)을 $n$-$t$ (normal-tangential, 법선-접선) 방향으로 회전한다. 법선 운동량 방정식을 경계조건 $u_n^{*}=0$ (번호 없음)으로 대체한다. 접선 운동량 방정식은 수정하지 않아 자유 접선 미끄럼(free tangential slip)을 허용한다. 모델이 예측한 외부 경계 법선 유속과 유량은 정확히 0이다.<br>(b)도 해당 GWCE 경계 적분을 0으로 둔다. 법선 운동량 방정식을 $u_n^{*}=0$ (번호 없음)으로 대체한다. 접선 운동량 방정식을 $u_t^{*}=0$ (번호 없음)으로 대체하여 무미끄럼(no slip)을 강제한다. 모델이 예측한 법선 유속과 유량은 정확히 0이며 접선 유속도 없다. $u_n^{*}$와 $u_t^{*}$는 각각 지정하는 법선 및 접선 유속 성분이다. 이 쪽에는 이 기호의 단위가 인쇄되지 않았다. 무미끄럼 조건의 수학적 정당화에 관한 문장은 다음 쪽으로 이어진다.<br>`This procedure results in model predicted normal velocities and flows on no normal flow external boundaries exactly equaling zero.` (p.2) |

Basic Methodology**, (b)의 끝, (c) “Natural No Normal Flow on External Boundaries with Free Tangential Slip Allowed”, (d) “Essential No Normal Flow on Internal Boundaries with Free Tangential Slip Allowed”, (e) “Essential No Normal Flow on Internal Boundaries with No Tangential Slip Enforced”의 시작.<br>(b)의 무미끄럼 조건은 모의에 횡방향 점성항(lateral viscous term)을 사용한 경우에만 수학적으로 정당화된다. 횡방향 경계층(lateral boundary layer)을 충분한 격자 해상도로 분해한 경우에만 물리적으로 정당화된다.<br>(c)는 자연 경계조건(natural boundary condition)이다. 해당 GWCE 경계 적분을 0으로 둔다. 외부 경계 절점(node)의 운동량 방정식에는 법선 및/또는 접선 유속을 지정하지 않는다. 예측한 법선 유량은 근사적으로 0이지만 정확히 0은 아니다. 자유 접선 유속 성분을 허용한다. 원문은 잔류 법선 유량이 영역 내부 유량 오차와 일치하므로 우려할 대상이 아니라고 서술한다. 격자 크기가 매우 작아지는 극한에서는 외부 경계 법선 유량이 정확히 0이라고 서술한다.<br>(d)는 내부 경계의 GWCE 경계 적분을 0으로 둔다. 법선 운동량 방정식을 $u_n^{*}=0$ (번호 없음)으로 대체한다. 접선 운동량 방정식은 수정하지 않는다. 내부 경계의 예측 법선 유속과 유량은 정확히 0이다.<br>(e)는 내부 경계의 GWCE 경계 적분을 0으로 두며 다음 쪽으로 이어진다.<br>`We do note that the residual normal flow on the boundary is consistent with the interior domain flow errors and is therefore not of concern!` (p.3) |

Basic Methodology**, (g) “Essential Specified Normal Flow on External Boundaries with Free Tangential Slip Allowed”. 해당 GWCE 외부 경계 적분에 사용자 지정 법선 유량의 절점값을 사용한다. $Q_n^{*}$가 각 외부 경계 구간의 절점 사이에서 선형으로 변한다고 가정한다. 법선 운동량 방정식을 제거하고 다음 경계조건으로 대체한다.<br>**식 (1):** $u_n^{*}=Q_n^{*}/(\zeta+h)$.<br>$u_n^{*}$는 지정 법선 유량 외부 경계 절점의 경계 법선 방향 유속이다. $Q_n^{*}$는 같은 절점의 사용자 지정 법선 방향 유량 성분이다. $\zeta$는 지오이드(geoid)를 기준으로 한 자유수면 수위(free surface water elevation)이다. $h$는 지오이드를 기준으로 한 수심이다. 이 쪽의 기호 정의에는 단위가 없다. 접선 운동량 방정식은 수정하지 않아 자유 접선 미끄럼을 허용한다고 서술한다. 이 문장의 경계 절점은 원문에 “no normal flow external boundary nodes”로 인쇄되어 있다. 예측 법선 유속과 유량은 사용자 지정값과 정확히 일치한다고 서술한다.<br>`This procedure results in model predicted normal velocities and flows on specified normal flow external boundaries exactly matching user specified values.` (p.5) |

| p.7 | 인쇄 쪽 번호 7. **2. Basic Methodology**, (i)의 끝과 외부 장벽 월류식, (j) “Essential Normal External Barrier Flow Boundary with Free Tangential Slip Allowed”의 시작. (i)의 지정 법선 유량 외부 경계에서는 격자 크기가 매우 작아지는 극한에서 예측 법선 유량이 사용자 지정값과 일치한다고 서술한다. 외부 장벽은 월류 시 계산영역 밖으로 유량을 배출한다. 기본 가정은 장벽 월류 시 자유수면 사류 유출(free surface supercritical outflow)이 발생한다는 것이다.<br>**식 (2a):** $\text{For }\zeta\le h_b\ \Rightarrow\ Q_n^{**}=0$.<br>**식 (2b):** $\text{For }\zeta>h_b\ \Rightarrow\ Q_n^{**}=-\frac{2}{3}C_R\mu(\zeta-h_b)\left[\frac{2}{3}g(\zeta-h_b)\right]^{\frac{1}{2}}$.<br>$Q_n^{**}$는 외부 장벽 구간의 단위 폭당 법선 유출량(normal outflow per unit width)이다. $\zeta$는 지오이드 기준 자유수면 수위이다. $h_b$는 지오이드 위 장벽 높이이다. $C_R$는 ADCIRC의 모든 강제 함수(forcing function)에 쓰는 램프 계수(ramp coefficient)이다. $\mu$는 자유수면 유동 계수(coefficient of free surface flow)이다. $\mu$는 외부 장벽 유동 경계의 형상에 따라 변하며 원문의 typical value는 1.0이다. $g$는 중력가속도(acceleration due to gravity)이다. 이 쪽의 기호 정의에는 단위가 인쇄되지 않았다. 원문은 Leendertse의 “Aspects of SIMSYS2D - A System for Two-Dimensional Flow Computation”, RAND/R-3572-USGS, 1987을 근거로 든다. 원문은 이 식이 광정 위어(broad crested weir) 식이라고 설명한다. Henderson, “Open Channel Flow”, Section 6.6도 참조한다. 계산된 법선 유출을 법선 유량 경계조건 체계에 구현했다고 서술한다.<br>`ADCIRC version 30.02 also incorporates the ability for the user to specify external barrier type boundaries which, when overtopped, discharge flow out of the computational domain.` (p.7) |
