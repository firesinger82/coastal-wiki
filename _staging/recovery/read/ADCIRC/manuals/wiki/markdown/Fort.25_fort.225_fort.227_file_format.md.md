# Fort.25_fort.225_fort.227_file_format.md — 판독 구간 기록

구간은 1행부터 57행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | Fort.25/fort.225/fort.227 file format / 선두 입력 — 제목·판본·빈 줄을 포함한다(1–4). ASCII fort.25는 얼음 피복(ice coverage) 자료의 일반 매개변수 두 개만 지정한다고 명시하고 그 입력행을 제시한다(5–8). 원문: `The ASCII text fort.25 file is only used to specify two general parameters for the Ice coverage data. The file format is as follows:` (5); `[numIceFields](/index.php?title=NumIceFields&action=edit&redlink=1) ` (7); `[numBlankIceSnaps](/index.php?title=NumBlankIceSnaps&action=edit&redlink=1)` (8). |
| 10–22 | Notes / 항력 선택·필수 설정·얼음 파일 — Garratt와 얼음 피복률만 사용하는 IceCube 항력 계수 중 최대값을 택하되 항력 상한을 넘지 않아야 하며 얼음이 없으면 Garratt와 같다고 적는다(12). 기존 fort.15의 두 수정과 최소 두 자료 묶음을 요구한다(14). 파일 선택 조건·얼음 비율 범위·육지 또는 자료 없음의 처리값, OWI 형식과 헤더 정보를 제시한다(16–18). 기상과 얼음 자료의 격자 크기·시간 간격은 같을 필요가 없다고 명시한다(20–21). 원문: `When using ice fields, the wind drag coefficient is first computed by the usual Garratt formula based on wind speed, then a wind drag coefficient is computed by a new function called IceCube that is based solely on the percent of ice coverage, then the maximum of the Garratt and IceCube drag coefficients is taken but must still be less than or equal to the drag cap in ADCIRC. If there is no ice in a particular area, then the drag coefficient is the same as Garratt.` (12); `In order to use ice field data, two changes are required to an existing [fort.15 file](/Fort.15_file): the ten thousands place must be set to 12 (see the [NWS Simplified Table of Values](/index.php?title=NWS_Simplified_Table_of_Values&action=edit&redlink=1) for details), and the time increment of the ice field data ([CICE_TIMINC](/index.php?title=CICE_TIMINC&action=edit&redlink=1)) in seconds must be supplied on the [WTIMINC](/WTIMINC) line (see the Supplemental Meteorology/Wave/Ice Parameters table for details). Ice coverage datasets are linearly interpolated in time by ADCIRC, as a result, at least two datasets are required.` (14); `If [nnumIceFields](/index.php?title=NnumIceFields&action=edit&redlink=1) in the fort.25 file is set to 1, only the fort.225 file will be read; if numIceFields in the fort.25 file is set to 2 then both the fort.225 and fort.227 files will be read. The fort.225 (the basin scale, i.e., large scale coarse grid) and optional fort.227 (the region scale, i.e., smaller scale finer grid) files contain the actual ice percentage values (0.0 to 100.0%) and a value of -1.0 which means land or no data available. A value of -1.0% is treated as 0.0% ice in ADCIRC.` (16); `These files are formatted exactly like the fort.221 barometric pressure files for the OWI win/pre meteorological data format ([NWS](/NWS)=12). The data represent the percentage of area covered by ice within a grid cell. Grid dimensions and cell sizes are contained in the header lines of the fort.225 files.` (18); `If OWI-formatted meteorological forcing and ice coverage data are both used, the grid dimensions for ice coverage and meteorological data do not have to be the same; nor do the time increments` (20); `between data sets.` (21). |
| 23–32 | Method for Specifying the Coefficient of Drag / RaysIce — 얼음의 공기역학적 거칠기(aerodynamic roughness) 및 관측·경험식 배경을 설명한다(25–27). 기본값이 아닌 RaysIce 식, 얼음 농도(ice concentration)의 범위와 해당 식 선택값을 제시한다(28–29). 최대 계수·피복률·관측값·대칭성 및 다른 연구에서 사용한 계수와 적용 절차를 적는다(30–32). 원문: `The ADCIRC model ordinarily uses the wind drag coefficient formulation of Garratt (1977) in the calculation of surface wind stresses. It is a widely-used formulation and it has been found to work well for storm surge applications.` (25); `An additional physical process that has been examined in ice-covered regions such as coastal Alaska and the Great Lakes is the influence of sea ice as aerodynamic roughness elements. Macklin (1983) and Pease et. al. (1983) found that measurements of wind drag coefficients over first year sea ice typically yielded values that were significantly larger and varied less with wind speed than that predicted for open water.` (26); `More recent work (Birnbaum and Lupkes (2002) and Garbrecht et. al. (2002)) has formalized the effect of form drag on the specification of wind drag coefficients within marginal ice zones. From their work, Chapman et. al. (2005) utilized an empirical fit to the range of field data for the air-ice-water wind drag coefficient, CDF, and suggested:` (27); `CDF = [0.125 + 0.5 IC (1.0 – IC)] 10^-2 (RaysIce formulation, this is not the default)` (28); `in which IC is the ice concentration varying from 0.0 to 1.0 for open water and complete ice cover conditions, respectively. To specify this quadratic formulation for the wind drag, set the DragLawString parameter in the fort.15 file to “RaysIce”.` (29); `Inspection of the air-ice-water wind drag coefficient formula shows that a maximum value of 0.0025 occurs with 50% ice coverage. This value is very close to the Macklin (1983) measurement of 0.0028 for first year ice. Furthermore, it is seen that the value of the drag coefficient is symmetrical about 50% ice coverage suggesting that drag coefficient needed to represent 75% ice coverage is close to that of 25% ice coverage.` (30); `An alternative linear fit dependence on ice concentration has been applied by Danard et. al. (1989). These notions regarding variation of wind drag coefficient with ice cover have been supported by a number of Chukchi and Beaufort Sea storm surge simulations (Henry and Heaps, 1976; Kowalik, 1984; and Schafer, 1966) in which, wind drag coefficients greater than or equal to 0.0025 where utilized.` (31); `The method adopted for inclusion in ADCIRC considers the increased wind drag due to the presence of ice as developed by Chapman et. al. (2005). The method requires reading ice field concentration files into ADCIRC and calculating the wind drag coefficient values (variable over the model domain) using the form specified above. If ice cover is present, and the increased drag coefficient exceeds the value calculated using the standard Garratt (1997) formulation, the standard Garratt drag coefficient is replaced with the increased value associated with ice cover.` (32). |
| 33–36 | Method for Specifying the Coefficient of Drag / IceCube — 선택값이 없거나 두 지정 문자열일 때 쓰는 기본 삼차식(cubic function)을 설명하고 식을 제시한다(33–34). 얼음 농도별 계수값·기울기를 원문대로 적는다(35). 원문: `The IceCube formulation is used if the DragLawString is not specified in the fort.15, or is specified as “IceCube” or “default”. IceCube is a cubic function that represents a smoother transition between Garratt and the RaysIce formulation for low ice cover percentages and low wind speeds. This function is as follows:”` (33); `CDF = [0.075 + 0.75 IC – 0.9 IC^2 + 0.2 IC^3 ] 10^-2 (IceCube formulation, this is the default)` (34); `When [IC](/index.php?title=IC&action=edit&redlink=1) = 0 the drag coefficient is equal to the minimum value for Garratt (.000075), when [IC](/index.php?title=IC&action=edit&redlink=1) = 50 it has a value of 0.0025 and a zero gradient, and when [IC](/index.php?title=IC&action=edit&redlink=1) = 100 it has a value of 0.00125.` (35). |
| 37–57 | References — 얼음과 표면 항력·조석·폭풍 해일(storm surge)에 관한 참고문헌을 나열한다(39–57). 저자·연도·제목·보고서 또는 학술지·권·쪽과 빈 줄을 포함한다. 이 구간은 참고문헌 본문을 제공하지 않는다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 7–8·14·16·35: 여러 변수와 표 참조 URL에 `action=edit&redlink=1`이 들어 있다.
- 7·16: 첫 입력 변수 이름은 `numIceFields`이다(7). 파일 선택 설명의 첫 조건은 `nnumIceFields`로 적고 둘째 조건은 `numIceFields`로 적는다(16).
- 14: 옵션 변경 설명은 `the ten thousands place must be set to 12`라고 적는다. 어느 자리 또는 자리 묶음에 적용하는지에 대한 추가 설명은 이 파일에 없다.
- 29·35: 29행은 `IC`의 범위를 `0.0 to 1.0`으로 적는다. 35행은 같은 기호의 조건을 `0`, `50`, `100`으로 적는다.
- 34–35: 34행 식에 `IC = 0`을 대입하면 `0.075 × 10^-2 = 0.00075`이다. 35행은 IC가 0일 때 계수값을 `.000075`라고 적는다.
- 25·32·51: 표준 Garratt 식의 연도는 25행과 참고문헌 51행에서 `1977`이다. 적용 설명 32행은 `1997`로 적는다.
