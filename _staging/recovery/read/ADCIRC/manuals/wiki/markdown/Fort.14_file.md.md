# Fort.14_file.md — 판독 구간 기록

구간은 1행부터 11행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–6 | Fort.14 file / 역할 — 제목·판본 표기·빈 줄을 포함한다(1–4). 격자 좌표(grid coordinates), 요소 식별자(element identifiers), 경계조건(boundary conditions)을 담는 파일이라고 적는다(5). ADCIRC 실행에 이 파일이 필요하다고 명시한다(5). 원문: `The fort.14 file contains the grid coordinates, element identifiers and boundary conditions for the model run. This file is required to run the ADCIRC model.` (5). |
| 7–11 | File Format — 파일 형식·일반 경계 유형·유량 지정 경계(flux specified boundaries)의 상세 설명으로 가는 링크를 제시한다(7–11). 이 구간은 입력 변수·기본값·수식을 제시하지 않는다. |
