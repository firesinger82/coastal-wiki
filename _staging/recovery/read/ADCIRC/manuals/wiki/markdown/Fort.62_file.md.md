# Fort.62_file.md — 판독 구간 기록

구간은 1행부터 9행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–4 | Fort.62 file — 문서 제목(1)과 판본 표기 `_revid=615_` (3)를 포함한다. 빈 줄(2·4)을 포함한다. |
| 5–6 | 속도 관측점 출력 — fort.62는 fort.15에 지정된 모델 격자의 속도 기록 관측점(velocity recording station)에서 수심 평균 속도(depth-averaged velocity)를 출력한다(5). 원문: `The fort.62 file contains depth-avereaged velocity output at velocity recording stations in the model grid as specified in the [fort.15 file](/Fort.15_file).` (5). |
| 7–9 | File Format — 절 제목과 편집 링크(7)를 포함한다. 상세 형식은 fort.62 file format 문서를 참조한다(9). 원문: `See [fort.62 file format](/Fort.62_file_format) for details.` (9). |
