# Fort.64_file.md — 판독 구간 기록

구간은 1행부터 9행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–4 | Fort.64 file — 문서 제목(1)과 판본 표기 `_revid=621_` (3)를 포함한다. 빈 줄(2·4)을 포함한다. |
| 5–6 | 전체 격자 속도 출력 — fort.64는 fort.15에 지정된 모델 격자의 모든 절점(node)에서 수심 평균 속도(depth-averaged velocity) 시계열(time series)을 출력한다(5). 원문: `The fort.64 file contains depth-averaged velocity time series output at all nodes in the model grid as specified in the [fort.15 file](/Fort.15_file).` (5). |
| 7–9 | File Format — 절 제목과 편집 링크(7)를 포함한다. 상세 형식은 fort.64 file format 문서를 참조한다(9). 원문: `See [fort.64 file format](/Fort.64_file_format) for details.` (9). |
