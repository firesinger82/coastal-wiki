# Tools.md — 판독 구간 기록

구간은 1행부터 31행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–8 | Tools — 제목과 판본 표기를 포함한다(1–3). ADCIRC 도구를 조직하고 링크하는 페이지라고 설명한다(5). 모든 도구를 위한 단일 중앙 저장소는 아직 없다고 적는다(5). 시각화 도구는 `Visualization` 페이지로 연결하고 누락된 도구의 제보를 요청한다(5–7). |
| 9–20 | Multi-Purpose — ASGS는 National Hurricane Center의 권고 자료 수집을 포함한 ADCIRC 운영 계산의 자동화를 지원한다고 설명한다(11). Nate Dill의 Perl 유틸리티(utilities), Matlab의 `adcirc_util`, Python의 `adcircpy`, C++와 Python의 `ADCIRCModules`를 각각 연결한다(13–19). |
| 21–24 | Uncategorized — ADCIRC utilities 웹페이지에 기본 도구와 더 고급인 도구가 있다고 설명하고 해당 페이지를 연결한다(23). |
| 25–31 | File Construction — `OceanMesh2D`를 격자(mesh) 생성·편집 도구로 소개한다(27). `f13builder`는 절점 속성(nodal attributes)과 `fort.13 file`의 생성을 돕는다고 설명한다(29). SMS는 ADCIRC 입력 파일 생성과 출력 시각화를 위한 상용 소프트웨어라고 설명한다(31). |
