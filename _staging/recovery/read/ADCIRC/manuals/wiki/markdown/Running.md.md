# Running.md — 판독 구간 기록

구간은 1행부터 5행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–5 | Running — 제목과 판본 표기를 포함한다(1–3). 실행 전에 컴파일(compiling)과 필요한 입력 파일을 갖춰야 한다고 설명한다(5). 최소 입력 파일을 `fort.15 file`과 `fort.14 file`로 명시한다(5). 예제 실행, 시작 안내와 Casey Dietrich의 예제 링크를 제공한다(5). 원문: `Running the model requires that you have both [compiled](/Compiling) and have all necessary input files; the [fort.15 file](/Fort.15_file) and [fort.14 file](/Fort.14_file) are the minimum requirements. [Sample runs](/Examples_and_Test_Cases) can help if you don't already have input files handy. The basics of these steps are covered in [getting started](/Getting_started), and also in [examples from Casey Dietrich](https://ccht.ccee.ncsu.edu/swanadcirc/).` (5). |
