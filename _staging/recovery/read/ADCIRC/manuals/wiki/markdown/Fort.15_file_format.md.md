# Fort.15_file_format.md — 판독 구간 기록

구간은 1행부터 296행까지 빈틈없이 이어진다.

| 구간 | 내용 |

| 1–32 | Fort.15 file format / 머리말·목차 — 제목·판본·목차·빈 줄을 포함한다(1–32). 입력 자료를 이 페이지의 정확한 순서대로 넣어야 하며 빈 줄과 제목은 가독성을 위한 것이라고 명시한다(5). 원문: `The basic file structure of the [fort.15 file](/Fort.15_file) is shown below. Each line of input data is represented by a line containing the input variable name(s). Inputs in the [fort.15 file](/Fort.15_file) must be entered in the exact order shown on this page. Blank lines and headings are only to enhance readability. Loops indicate multiple lines of input. ` (5). |
| 33–42 | Main Controls / Metadata and Logging — 두 실행 설명 문자열의 길이 제한과 오류 무시·로그 상세 수준·로그 출력 위치 제어를 제시한다(37–41). 원문: `` `[RUNDES](/index.php?title=RUNDES&action=edit&redlink=1)` - alphanumeric run description 1, 32 characters or less `` (37); `` `[RUNID](/index.php?title=RUNID&action=edit&redlink=1)` - alphanumeric run description 2, 24 characters or less `` (38); `` `[NFOVER](/index.php?title=NFOVER&action=edit&redlink=1)` - non-fatal error override option `` (39); `` `[NABOUT](/index.php?title=NABOUT&action=edit&redlink=1)` - verbosity of run log output, `= -1` is debug mode, higher is less output, up to `3` for errors only `` (40); `` `[NSCREEN](/index.php?title=NSCREEN&action=edit&redlink=1)` - directs log messages to the screen (`> 0`), the adcirc.log file (`< 0`), or disables them (`= 0`) `` (41). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 37–253: 여러 입력 변수 참조 URL에 `action=edit&redlink=1`이 들어 있다. 이 파일은 해당 변수의 전체 정의를 본문에 제공하지 않는다.
- 74: 추가 최소 수심 제어행의 두 필드는 변수 이름 대신 `INTEGER` `INTEGER`로 적혀 있다.
- 114·125–126: `NFFR` 포함 조건은 경계 유형 `52`도 나열한다(114). 경계 절점 입력행의 조건은 `2, 12, 22`와 `32`만 나열한다(125–126). 이 구간에는 유형 `52`의 절점 입력행이 없다.
- 242–244: 두 입력행을 읽는다는 조건 뒤 첫 행에는 `TTBCTIMEINC, TTBCSTATIM`이 있으며 둘째 행에도 `TTBCTIMEINC`가 적혀 있다.
