# Fort.25_fort.225_fort.227_file.md — 판독 구간 기록

구간은 1행부터 10행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–6 | Fort.25/fort.225/fort.227 file / 역할 — 제목·판본·빈 줄을 포함한다(1–4). 얼음장(ice fields)을 바람 항력 계수(wind drag coefficient) 계산에 반영할 수 있다고 적는다(5). 얼음장이 해법에 주는 영향은 바람 속도와 얼음 피복률(percentage of ice coverage)에 따른 항력 계수 수정뿐이라고 명시한다(5). 원문: `The fort.25/fort.225/fort.227 file(s) give ADCIRC the ability to incorporate ice fields into the computation of wind drag coefficients. The only influence that these ice fields has on ADCIRC’s solution procedure is that they are used to modify the wind drag coefficients based on wind speed and percentage of ice coverage.` (5). |
| 7–10 | File Format — 별도 얼음 입력 파일 형식 문서와 유량 지정 경계(flux specified boundaries) 문서로 연결한다(7–10). 이 구간은 실제 입력행을 제시하지 않는다. |
