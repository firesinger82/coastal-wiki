# Fort.75_file.md — 판독 구간 기록

구간은 1행부터 9행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–4 | Fort.75 file — 문서 제목(1)과 판본 표기 `_revid=653_` (3)를 포함한다. 빈 줄(2·4)을 포함한다. |
| 5–6 | 시간 변화 수심 지형(time varying bathymetry) 출력 조건 — 이 기능을 활성화하면 fort.75 출력 파일을 생성한다(5). 출력은 fort.15에 지정된 수위 기록 관측점(water surface elevation recording station)의 NOUTE 등 출력 제어 설정을 따른다(5). 원문: `If the time varying bathymetry feature of ADCIRC has been activated, the fort.75 output file will be produced according to the output control specifications for water surface elevation recording stations (NOUTE, etc) as specified in the [fort.15 file](/Fort.15_file).` (5). |
| 7–9 | File Format — 절 제목과 편집 링크(7)를 포함한다. 상세 형식은 fort.75 file format 문서를 참조한다(9). 원문: `See [fort.75 file format](/Fort.75_file_format) for details.` (9). |
