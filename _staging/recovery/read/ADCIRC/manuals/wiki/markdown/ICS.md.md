| 1–16 | ICS — ICS는 fort.15의 좌표계(coordinate system)와 투영(projection)을 정하며 CORI 선택에도 영향을 준다(5). 제목·판본·목차·빈 줄을 포함한다(1–16). 원문: `ICS is a fundamental parameter in the [fort.15 file](/Fort.15_file) that defines the coordinate system and the desired projection. The value of ICS also has an important consequence for the choice of the Coriolis [CORI](/index.php?title=CORI&action=edit&redlink=1) parameter of the [fort.15 file](/Fort.15_file).` (5). |
| 17–36 | Available ICS Values / 1·2 — 표의 열 제목과 빈 줄을 포함한다(17–24). 값 1은 이미 Cartesian 좌표로 투영한 fort.14 점을 사용하며 이상화 문제에도 유용하다(25–29). 값 2는 지리 좌표를 CPP 등거리 원통 투영으로 바꾸지만 지구 곡률(curvature)은 고려하지 않는다(31–35). 원문: `1` (25); `Cartesian` (27); `Points in the fort.14 are already mapped onto an arbitrary Cartesian coordinate system, e.g., UTM. Also useful for idealized problems.` (29); `2` (31); `Geographic, CPP, no curvature` (33); `Points in the fort.14 are specified in geographic coordinates, which will be projected using the CPP (equidistant) cylindrical mapping by ADCIRC. The curvature of the Earth is not accounted for.` (35). |
| 37–86 | Available ICS Values / 20–24 — 각 옵션의 버전 표기는 원문 그대로 인용한다(39–81). 20은 등면적(Equal-area), 21은 CPP 등거리(equidistant), 22는 Mercator 등각(conformal), 23은 Miller, 24는 Gall-Stereographic 원통 투영이다(37–85). 원문은 이 옵션들이 지구 곡률을 올바르게 고려한다고 적는다(45·55·65·75·85). 원문: `20` (37); `ADCIRC version:` (39); `  =  55  ` (41); `Geographic, Equal-area` (43); `Points in the fort.14 are specified in geographic coordinates, which will be projected using the Equal-area cylindrical mapping by ADCIRC. | 87–94 | Implications — 버전 55부터 20–24를 사용할 수 있다고 적는다(89–93). 값 2는 회귀시험(regression testing)을 위해 유지한다고 적는다(93). 지리 영역에는 일반적으로 20–24를 사용해야 하며 Cartesian 영역에는 1을 계속 사용해야 한다고 적는다(93). Mercator의 각도 보존을 설명하며 시험에서는 20–24가 사실상 같은 답을 주었다고 적는다(93). 원문: `ADCIRC version:` (89); `  =  55  ` (91); `Beginning from Version 55, ICS values equal to 20-24 will be possible. These are intended to replace the old method of specifying ICS = 2, but this option is retained for regression testing. When ICS = 2, the curvature of the Earth is not correctly accounted for in the Spherical coordinate form of the governing equations which becomes more important as the geographic size of the computational domain size increases. In recent years global modeling using ADCIRC has been successful[&#91;1&#93;](#cite_note-1), e.g., [GLOCOFFS](https://wpringle.github.io/GLOCOFFS/) where it was found that the old method was deficient. The new options using values ICS = 20-24 now account for the curvature correctly, and should in general be always used on geographical domains (ICS = 1 should still be used for Cartesian coordinate domains). ICS = 22 is particularly attractive because it uses a conformal mapping (Mercator) that conserve the angles on the spherical Earth, but testing has generally found that all choices of ICS = 20-24 give effectively the same answers.` (93). |
| 95–105 | Negative ICS Value for Rotation / References — 20–24를 음수로 지정하면 지리 좌표를 회전할 수 있다(101). 주요 목적은 지구의 극을 육지로 옮겨 구면 지배방정식의 특이점(singularity)을 없애는 것이다(101). 출력은 원래 좌표계로 표시한다(101). 회전은 fort.rotm 입력 파일로 설정한다(101). 준비 중인 전지구 ADCIRC v55 논문을 참고문헌으로 적는다(103–105). 원문: `ADCIRC version:` (97); `  =  55  ` (99); `The values 20-24 can also be set to a negative value (i.e, -20, -21, ...) to implement an arbitrary rotation of the geographic coordinates by ADCIRC. This is primarily used to ensure that Earth's poles are rotated onto land to eliminate the singularity in the Spherical coordinate form of the governing equations. ADCIRC's outputs will be displayed on the original unrotated coordinate system. The rotation is set by the [fort.rotm](/Fort.rotm) input file (see the link for example formats).` (101). |
