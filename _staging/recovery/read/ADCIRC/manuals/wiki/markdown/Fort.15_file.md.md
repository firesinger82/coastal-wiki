| 1–20 | Fort.15 file / 역할·목차·File Format — 제목·판본·목차·빈 줄을 포함한다(1–17). 2DDI 및 3D 버전 실행에 필요한 대부분의 매개변수와 수위 또는 유량의 조화 경계조건(harmonic boundary conditions) 정보를 담는 필수 파일이라고 적는다(5). 별도 형식 문서로 연결한다(19). 원문: `This file contains the majority of the parameters required to run both the 2DDI and 3D versions of ADCIRC and the information to drive the model with harmonic boundary conditions (either elevation or flux). This file is required to run the ADCIRC model.` (5). |
| 21–39 | Tips and Tricks / Meteorological-Only Mode — 해양 상태 출력을 모두 끄고 파랑 결합(wave coupling)을 비활성화하면 기상 전용 모드로 실행한다고 적는다(25). 이 모드는 기상 강제력(meteorological forcing) 관련 루틴만 호출하며 수위와 유속을 계산하지 않는다고 명시한다(25). 시간 간격과 출력 간격 설정, 일반 2D 실행의 설정값 및 수동 스칼라 수송(passive scalar transport)의 추가 설정을 제시한다(25–38). 원문: ``By turning off all ocean state-related outputting and disabling wave coupling, ADCIRC will run in "met.-only" mode, a quick and convenient way to read in and write out meteorological data files.  In this mode, only routines necessary for meteorological forcing are called, i.e. no water levels nor velocities are computed.  Note that by changing `DT`, you can speed up this "simulation".  More specifically, since the only things being output are meteorological data, you can set `DT` equal to the time interval you wish met. data to be output, and then set the `[NSPOOLM](/index.php?title=NSPOOLM&action=edit&redlink=1)` and/or `[NSPOOLGW](/index.php?title=NSPOOLGW&action=edit&redlink=1)` (the local and global met. output intervals) to `1` (i.e. output every time step).  For typical 2D ADCIRC runs, this requires setting the following in the fort.15 file: `` (25); `` `[NOUTE](/index.php?title=NOUTE&action=edit&redlink=1) = 0`  `` (26); `` `[NOUTV](/index.php?title=NOUTV&action=edit&redlink=1) = 0`  `` (27); `` `[NOUTGE](/index.php?title=NOUTGE&action=edit&redlink=1) = 0`  `` (28); `` `[NOUTGV](/index.php?title=NOUTGV&action=edit&redlink=1) = 0`  `` (29); `` `[NHSTAR](/index.php?title=NHSTAR&action=edit&redlink=1) = 0`  `` (30); `` `[NHASE](/index.php?title=NHASE&action=edit&redlink=1) = 0`  `` (31); `` `[NHASV](/index.php?title=NHASV&action=edit&redlink=1) = 0`  `` (32); `` `[NHAGE](/index.php?title=NHAGE&action=edit&redlink=1) = 0`  `` (33); `` `[NHAGV](/index.php?title=NHAGV&action=edit&redlink=1) = 0`  `` (34); ``For passive scalar transport (`[IM](/IM) = 10`), also set: `` (36); `` `[NOUTC](/index.php?title=NOUTC&action=edit&redlink=1) = 0`  `` (37); `` `[NOUTGC](/index.php?title=NOUTGC&action=edit&redlink=1) = 0`  `` (38). |
| 40–47 | Meteorological-Only Mode / 3D 추가 설정 — 순압(barotropic) 또는 경압(baroclinic) 3D ADCIRC에서 추가로 설정할 여섯 값을 제시한다(40–46). 마지막 빈 줄을 포함한다(47). 원문: `while for barotropic or baroclinic 3D ADCIRC, also set: ` (40); `` `[I3DSD](/index.php?title=I3DSD&action=edit&redlink=1) = 0`  `` (41); `` `[I3DSV](/index.php?title=I3DSV&action=edit&redlink=1) = 0`  `` (42); `` `[I3DST](/index.php?title=I3DST&action=edit&redlink=1) = 0`  `` (43); `` `[I3DGD](/index.php?title=I3DGD&action=edit&redlink=1) = 0`  `` (44); `` `[I3DGV](/index.php?title=I3DGV&action=edit&redlink=1) = 0`  `` (45); `` `[I3DGT](/index.php?title=I3DGT&action=edit&redlink=1) = 0`  `` (46). |
| 48–54 | Ramping Meteorological Forcing at Hot-Start — 강제력을 점진적으로 적용하는 램핑(ramping)을 일반적으로 권하며 기본 램핑 시작 시점을 cold-start라고 설명한다(50). 15일 조석 전용 실행에서 얻은 hot-start 파일을 사용하는 예시를 제시한다(50–53). 예시의 기상 강제력 램핑 기간은 0.5일이며 시작 시점은 실행 15.0일이라고 적는다(54). 원문: ``It is generally best to [ramping](/Ramping) in forcing terms to the model to avoid shocking the system, but ramping parameters like `[DRAMP](/index.php?title=DRAMP&action=edit&redlink=1)` define the start of ramp time as being cold-start time.  Since it is common-place to initialize meteorological forcing at hotstart time, there is a special parameter to facilitate hotstart ramping of met. data.  Let's say you run a 15-day tide-only run and output a hotstart file.  Setting `` (50); `` `[NRAMP](/index.php?title=NRAMP&action=edit&redlink=1) = 8` `` (51); ``means you can supply `[DRAMPUnMete](/index.php?title=DRAMPUnMete&action=edit&redlink=1)`, which is the number of delays at which to start met. ramping, on the `DRAMP` line.  Here's an example:  `` (52); `` `5  0  0  0  0  0  0.5  0  15 &#160;! DRAMP, DRAMPExtFlux, FluxSettlingTime, DRAMPIntFlux, DRAMPElev, DRAMPTip, DRAMPMete, DRAMPWRad, DRAMPUnMete` `` (53); `What this says is that a 0.5-day ramp will be applied to the met. forcing, starting at run day 15.0 (the hotstart simulation's start time).` (54). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 25–46·50–53: 여러 변수 링크가 백틱 안에 있으며 URL에 `action=edit&redlink=1`이 들어 있다. 이 파일은 해당 변수의 전체 정의를 제공하지 않는다.
- 52·54: `DRAMPUnMete` 설명은 `the number of delays`라고 적는다(52). 예시 해설은 시작 시점을 `run day 15.0`으로 적는다(54).
- 53: 예시 줄의 입력값과 주석 사이에 HTML 문자 참조 `&#160;`이 남아 있다.
