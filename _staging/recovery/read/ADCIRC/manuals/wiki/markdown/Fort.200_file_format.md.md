# Fort.200_file_format.md — 판독 구간 기록

구간은 1행부터 114행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–22 | Fort.200 file format / 머리말·목차 — 제목·판본·목차·빈 줄을 포함한다(1–22). 입력 변수 한 행이 입력 자료 한 행을 나타내며 반복문과 if 절로 반복·조건부 입력을 표시한다고 적는다(5). 원문: `The basic file structure is shown below. Each line of input data is represented by a line containing the input variable name(s). Blank lines are only to enhance readability. Loops indicate multiple lines of input. Conditional input is indicated by an if clause. ` (5). |
| 23–43 | NWS = 10 or 110 or 10010 / File Structure — 해당 옵션의 격자 입력 반복문과 조건부 얼음 입력을 제시한다(23–31). 표면 압력(surface pressure), 두 바람 성분 및 얼음 농도(ice concentration)의 단위·범위와 ADCIRC 버전 조건을 적는다(34–42). 원문: `# NWS = 10 or 110 or 10010[[edit](/index.php?title=Fort.200_file_format&action=edit&section=1)]` (23); `for k=1, [LONB*LATB](/index.php?title=LONB*LATB&action=edit&redlink=1)` (27); `[PG(k)](/index.php?title=PG(k)&action=edit&redlink=1), [UG(k)](/index.php?title=UG(k)&action=edit&redlink=1), [VG(k)](/index.php?title=VG(k)&action=edit&redlink=1) , if NWS=10010: [IG(k)](/index.php?title=IG(k)&action=edit&redlink=1)` (29); `end k loop` (31); `Key:` (33); `[PG(k)](/index.php?title=PG(k)&action=edit&redlink=1): surface pressure (Pa)` (34); `[UG(k)](/index.php?title=UG(k)&action=edit&redlink=1): U10 wind speed (m/s)` (35); `[VG(k)](/index.php?title=VG(k)&action=edit&redlink=1): V10 wind speed (m/s)` (36); `ADCIRC version:` (38); ` &#8805;  55 ` (40); `[IG(k)](/index.php?title=IG(k)&action=edit&redlink=1): ice concentration (0-1 decimal fraction)` (42). |
| 44–55 | NWS = 10 or 110 or 10010 / Notes / 격자·시각·단위 — GFS 자료의 Gaussian 격자(Gaussian grid) 크기와 공간 보간(spatial interpolation), 자료 순서를 명시한다(46–48). 파일 이름의 시간 간격 규칙·정수 시간 조건과 cold-start/hot-start별 첫 파일·시각을 적는다(50–52). 입력 바람의 높이와 바람·압력의 단위를 명시한다(54). 원문: `NWS = 10, US National Climatic Data Center (NCDC) Global Forecast System (GFS) model` (46); `Meteorological data is input to a T1534, Gaussian grid (NWLON*NWLAT is hardwired to 3072*1536 = 4,718,592) and interpolated in space onto the ADCIRC mesh. Data are ordered in these files the same way they are generated by the degribbing program.` (48); `The met data are contained in a sequence of files with names as follows: fort.200, fort.200+N, fort.200+2*N, fort.200+3*N,…., where N is the time interval (in hours) between successive meteorological data (e.g., at 6 hr intervals this would be fort.200, fort.206, fort.212, etc.). N is determined as N = WTIMINC/3600 where WTIMINC is the meteorological data time interval (in seconds) and is specified in the Model Parameter and Periodic Boundary Condition File. WTIMINC must be evenly divisible by 3600.` (50); `If the model is cold started, it is assumed that the winds are at rest at the beginning of the model run and no data file (fort.200) is read corresponding to TIME=STATIM. Rather, the first required data file (fort.200+N) corresponds to TIME=STATIM+WTIMINC. If the model is hot started, an initial file (fort.200) is required corresponding to TIME=HOT START TIME. In either case, additional sets of meteorological data must be provided every WTIMINC, in appropriately named files. Meteorological data is interpolated in time to the ADCIRC time step.` (52); `Wind velocity (@ 10 m above the water surface) must be input in units of m/s. Surface atmospheric pressure must be input in units of Pascals = Newtons/square meter.` (54). |
| 56–69 | NWS = 10 or 110 or 10010 / 바람 응력·압력 변환 — 바람 속도에서 바람 응력(wind stress)을 구하는 관계식과 항력 계수(drag coefficient) 제한 조건을 제시한다(56–64). Pascal 단위 압력을 수주 높이로 바꾸는 관계식을 제시한다(66–68). 원문: `The following relations are used to compute wind stress from the input wind velocity.` (56); `WIND_SPEED = magnitude of WIND_VEL` (58); `DRAG_COEFF = 0.001*(0.75+0.067*WIND_SPEED)` (60); `If (DRAG_COEFF.gt.0.003) DRAG_COEFF=0.003` (62); `WIND_STRESS = DRAG_COEFF*0.001293*WIND_VEL*WIND_SPEED` (64); `The following relationship is used in ADCIRC to convert to pressure in meters of water from pressure in Pascal:` (66); `PRESSURE{m H2O}=PRESSURE{Pascal}/(GRAVITY*DENSITY of H2O)` (68). |
| 70–82 | NWS = 11 or 111 / File Structure — 날짜·시각 정수와 Eta-29 격자별 바람·압력 입력을 여덟 번 반복하는 구조를 제시한다(70–81). 원문: `# NWS = 11 or 111[[edit](/index.php?title=Fort.200_file_format&action=edit&section=4)]` (70); `for k=1, 8` (74); `IYEAR, IMONTH, IDAY, IHOUR` (76); `for j=1, [LONB*LATB](/index.php?title=LONB*LATB&action=edit&redlink=1)` (77); `[UE(j)](/index.php?title=UE(j)&action=edit&redlink=1), [VE(j)](/index.php?title=VE(j)&action=edit&redlink=1), [PE(j)](/index.php?title=PE(j)&action=edit&redlink=1)` (78); `end j loop` (79); `end k loop` (81). |
| 83–95 | NWS = 11 or 111 / Notes / 격자·시각·단위 — 비데카르트(non-cartesian) Eta-29 E 격자의 고정 크기와 ADCIRC 격자의 경도·위도 조건을 명시한다(85–87). 파일당 하루 자료의 수·간격·첫 시각·마지막 시각과 초기화별 파일 조건 및 시간 보간(temporal interpolation)을 적는다(89–90). 이진 파일(binary file)의 접근 방식·형식, 바람의 방향·높이·단위와 압력 단위를 제시한다(92–94). 원문: `NWS = 11, 111 – National Weather Service Eta-29 file.` (85); `Meteorological data is input to the standard Eta-29 “E” grid, (non-cartesian grid, NWLON*NWLAT is hardwired to 181*271 = 49,051), and interpolated in space onto the ADCIRC grid. The ADCIRC grid must be in lon, lat coordinates.` (87); `The met data are contained in a sequence of files with names: fort.200, fort.201, fort.202, fort.203,…., Each file contains 8 data sets spaced 3 hrs apart in time (WTIMINC is the met. data time interval = 3600*3 = 10800 sec) for a total of 1 day of data per file. The first and last data sets in each file are assumed to correspond to 03:00 hrs and 24:00 hrs, respectively, on the day of the file. If the model is cold started, it is assumed that the winds are at rest at the beginning of the model run and no data file (fort.200) is read corresponding to TIME=STATIM. Rather, the initial data set in the first required data file (fort.201) corresponds to TIME=STATIM+WTIMINC. If the model is hot started, an initial file (fort.200) is required in which the last data set corresponds to TIME=HOT START TIME. In either case, 8 sets of met. data must be provided every` (89); `WTIMINC in each file and appropriately named files must be provided for each day of the model run. Met data is interpolated in time to the ADCIRC time step.` (90); `The file type is binary: ACCESS=’sequential’, FORM=’unformatted’` (92); `Wind velocity (@ 10 m above the water surface) must be input in units of m/s oriented along the E grid coordinate directions. Surface atmospheric pressure must be input in units of millibars.` (94). |
| 96–111 | NWS = 11 or 111 / Notes / 바람 응력·압력 변환·날짜 — 바람 응력 관계식과 항력 계수 제한을 제시한다(96–104). millibars 단위 압력의 수주 높이 변환식을 적는다(106–108). 날짜·시각 정수 네 값은 읽지만 무시한다고 명시한다(110). 원문: `The following relations are used to compute wind stress from the input wind velocity.` (96); `WIND_SPEED = magnitude of WIND_VEL` (98); `DRAG_COEFF = 0.001*(0.75+0.067*WIND_SPEED)` (100); `If (DRAG_COEFF.gt.0.003) DRAG_COEFF=0.003` (102); `WIND_STRESS = DRAG_COEFF*0.001293*WIND_VEL*WIND_SPEED` (104); `The following relationship is used in ADCIRC to convert to pressure in meters of water from pressure in millibars.` (106); `PRESSURE{m H2O}=PRESSURE{millibars}/(100*GRAVITY*DENSITY of H2O)` (108); `The integer values IYEAR, IMONTH, IDAY, IHOUR are read in and ignored by ADCIRC.` (110). |
| 112–114 | General Note — 전체 모델 실행 기간의 기상 자료가 필요하며 부족하면 실행이 중단된다고 명시한다(114). 원문: `Meteorological data must be provided for the entire model run, otherwise the run will crash.` (114). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 27·29·34–36·42·77–78: 여러 입력 변수 참조 URL에 `action=edit&redlink=1`이 들어 있다.
- 27·48·77·87: 반복문은 격자 수를 `LONB*LATB`로 적으며 Notes는 고정 격자 크기를 `NWLON*NWLAT`로 적는다. 두 변수 쌍의 관계는 이 파일에 정의되어 있지 않다.
- 40: 버전 조건의 부등호는 HTML 문자 참조 `&#8805;`로 남아 있다.
- 89–90: 먼저 각 파일에 3시간 간격의 자료 여덟 묶음이 있어 하루를 담는다고 적는다(89). 같은 문단 끝은 각 파일에 `8 sets of met. data must be provided every WTIMINC`라고 적는다(89–90).
- 68·108: Pascal 변환식의 분모는 `GRAVITY*DENSITY of H2O`이다(68). millibars 변환식의 분모는 `100*GRAVITY*DENSITY of H2O`이다(108). 계수 `100`의 위치에 대한 추가 설명은 이 파일에 없다.
