| 216–229 | Notes — yi·xi를 lat·lon에서 분리해 2차원 좌표 배열(array)을 사용할 수 있다고 설명한다(218). 정규 격자(regular grids), 곡선 격자, 2차원 mesh-grid로 표현 가능한 불균일 격자를 지원한다(220–222). 위치·해상도는 변할 수 있지만 yi·xi 배열 크기는 일정해야 한다(224). 그룹별 시간 단계·시작·종료를 독립적으로 지정할 수 있다(226). 결측값, 패킹(packing)·압축(compression), IEEE NaN 부동소수점(float)을 지원한다고 적는다(228). 원문: `- Decoupling the yi/xi dimensions from lat/lon allows lat and lon to be 2-d arrays by depending on both dimensions` (218); `- Regular grids and Curvilinear grids` (220); `- Non-evenly spaced grids as long as they can be expressed in a 2-d "mesh-grid"` (222); `- Grids that change spatial resolution or position in time (but have consistent yi/xi array size)` (224); `- Each group/sub-grid can define the timesteps independently, including start and stop times` (226); `- Fill Value (and NetCDF packing/compression), and ieee nan floats supported` (228). |
| 230–247 | fort.15 Configuration — WTIMINC는 입력 자료 시간 간격과 별개인 격자에서 모델 격자로 보간하는 초 단위 간격이다(232). 폭풍 추종 격자에서는 입력 간격보다 세밀한 값이 유용할 수 있다고 적는다(232). &owiWindNetcdf 네임리스트(namelist)의 모든 입력을 문자열로 따옴표에 넣는다(234). 필수 콜드스타트(cold start) 시각 형식, 선택 풍속 배율·파일명 기본값·Powell 항력(drag) 그룹 번호와 네임리스트 예제를 원문 그대로 옮긴다(236–246). 원문: `WTIMINC: configurable grid-to-mesh interpolation timestep in seconds, separate from the input data timesteps. If the file contains storm-following grids, there may be some utility in setting this finer than the input timestep(s).` (232); `&owiWindNetcdf fort.15 namelist with all inputs quoted as strings` (234); `- NWS13ColdStartString: required cold start time of simulation formatted as 'YYYYMMDD.HHMMSS'` (236); `- NWS13WindMultiplier: optional wind speed multiplier (DWM from [NWS12](/NWS12))` (238); `- NWS13File: optional file name for netCDF file ( fort.22.nc default )` (240); `- NWS13GroupForPowell: optional group # to use for Powell drag` (242); ` &owiWindNetcdf NWS13File='fort.22.nc' NWS13ColdStartString='20000706.000000' /` (246). |
| 248–261 | Suggestions — 필요한 공간·시간 해상도와 그룹 복잡도만 사용하고 오버레이 사이 불연속(discontinuities)을 피하라고 적는다(250–256). 이동 격자 보간을 신뢰할 수 있는 경우의 시간 간격 권고를 적는다(254). 낮은 rank 격자는 같은 고해상도 장(field)의 성긴 표현이 가장 좋다고 적는다(258). 원문은 낮은 rank 격자가 전체 영역과 모의 기간을 아마 포함해야 한다고 적는다(260). 권고의 조건·수량·불확실성을 원문 그대로 옮긴다. 원문: `- Keep the spatial and temporal resolutions to only what is required` (250); `- Add sub-grids, more complex time dimensions, and complex lat/lon grid definitions only as necessary by sub-grid/group` (252); `- In most cases 1-hourly specified--if you have a moving-grid overlay and can rely on the built-in moving-aware interpolation` (254); `- Avoid discontinuities between overlays/grids` (256); `- Best case: the lowest rank grid should just be a less resolved version of exact same higher resolution fields that will be overlaid` (258); `- Lowest rank grid should probably cover the entire domain/mesh, and the entire model run time period` (260). |
| 262–269 | Interpolation Details — 풍속·기압의 시간·공간 에일리어싱(aliasing)을 줄이기 위한 여러 단계의 보간 절차를 소개한다(266–268). `Ch_maxmin_interp_timeseries.png` 캡션은 폭풍 최고 상태의 시간 에일리어싱이다(264). `Ch_movegrid_interp_spatial.png` 캡션은 최고 풍속의 공간 에일리어싱이다(265). 두 그림 파일 없음(264–265). 축·기호·최고값은 확인하지 못했다. |
| 270–273 | Step 1: Time/space on input grid(s) — 입력 격자에서 시간 보간과 필요한 공간 보간을 수행하여 WTIMINC의 중간 시각(intermediate timesteps)에 자료를 만든다(272). 원문: `Input fields are interpolated on the input grid (in time, and space if necessary) to the intermediate timesteps specified in the fort.15 parameter WTIMINC.` (272). |
| 274–279 | Step 2: Apply intermediate input grid to mesh — 중간 시각 격자 자료를 ADCIRC 격자에 공간 보간하고 입력 rank에 따라 여러 격자를 중첩한다(276). 최저 rank 오버레이는 미리 계산한 보간 가중치(weights)를 사용하므로 이동하는 폭풍 추종 격자일 수 없다(278). 나머지 오버레이의 가중치는 동적으로 갱신한다(278). 원문: `The gridded intermediate timesteps are interpolated in space on to the ADCIRC mesh, appropriately overlaying multiple input grids by rank as supplied. At this point the inputs are represented on the mesh at WTIMINC timesteps. ` (276); `NB: For the lowest ranked overlay, the grid-to-mesh interpolation weights are pre-computed, which means that this grid cannot be a storm-following moving grid. For all additional overlays, the weights are dynamically updated.` (278). |
| 280–286 | Step 3: Time interpolation to model timestep — 매 DTDP 계산 시각에 모델 격자의 중간 시각 입력을 절점별로 시간 보간한다(282). `/File:Nws13_interp1.png`와 `/File:Nws13_interp2.png` 참조를 포함한다(284·286). 두 그림 파일 없음. 원문에는 이 두 그림의 캡션이 없으며 그림의 단계·화살표·축·식은 확인하지 못했다. 원문: `At each model computational timestep (DTDP) the inputs at intermediate timesteps as represented on the mesh are interpolated in time to the appropriate model timestep node-by-node.` (282). |
