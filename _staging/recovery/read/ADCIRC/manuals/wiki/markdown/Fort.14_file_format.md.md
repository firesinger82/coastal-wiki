|---|---|
| 1–22 | Fort.14 file format / 격자와 요소 — 제목·판본·빈 줄과 입력 행 및 반복문 표기 설명을 포함한다(1–5). 격자 식별자·요소 수·절점 수를 제시한다(7–9). 절점별 좌표·깊이 항목과 요소별 연결 항목을 순서대로 나열한다(11–21). 원문: `The basic file structure is shown below. Each line of input data is represented by a line containing the input variable name(s). Blank lines are only to enhance readability. | 23–35 | 첫 번째 경계 반복 블록 — 경계 수·전체 절점 수를 적고 경계별 절점 수와 유형, 그 경계의 절점 번호를 반복하는 구조를 제시한다(23–34). 원문: `[NOPE](/index.php?title=NOPE&action=edit&redlink=1)` (23); `[NETA](/index.php?title=NETA&action=edit&redlink=1)` (25); `for k=1 to [NOPE](/index.php?title=NOPE&action=edit&redlink=1)` (27); `[NVDLL(k)](/index.php?title=NVDLL(k)&action=edit&redlink=1), [IBTYPEE(k)](/index.php?title=IBTYPEE(k)&action=edit&redlink=1)` (29); `for j=1 to [NVDLL(k)](/index.php?title=NVDLL(k)&action=edit&redlink=1)` (30); `[NBDV(k,j)](/index.php?title=NBDV(k,j)&action=edit&redlink=1)` (31); `end j loop` (32); `end k loop` (34). |
| 36–51 | 두 번째 경계 반복 블록 — 경계 수와 전체 절점 수, 경계별 절점 수·유형을 제시한다(36–43). 경계 유형에 따라 절점 번호만 쓰거나 연결 절점·장벽(barrier)·관(pipe) 관련 항목을 포함하도록 조건을 적는다(44–48). 두 반복문의 종료와 빈 줄을 포함한다(49–51). 원문: `[NBOU](/index.php?title=NBOU&action=edit&redlink=1)` (36); `[NVEL](/index.php?title=NVEL&action=edit&redlink=1)` (38); `for k=1 to [NBOU](/index.php?title=NBOU&action=edit&redlink=1)` (40); `[NVELL(k)](/index.php?title=NVELL(k)&action=edit&redlink=1), IBTYPE(k)` (42); `for j=1,NVELL(k)` (43); `[NBVV(k,j)](/index.php?title=NBVV(k,j)&action=edit&redlink=1) include this line only if [IBTYPE(k)](/index.php?title=IBTYPE(k)&action=edit&redlink=1) = 0, 1, 2, 10, 11, 12, 20, 21, 22, 30` (44); `[NBVV(k,j)](/index.php?title=NBVV(k,j)&action=edit&redlink=1), [IBCONN(k,j)](/index.php?title=IBCONN(k,j)&action=edit&redlink=1) include this line only if [IBTYPE(k)](/index.php?title=IBTYPE(k)&action=edit&redlink=1) = 94` (45); `[NBVV(k,j)](/index.php?title=NBVV(k,j)&action=edit&redlink=1), [BARLANHT(k,j)](/index.php?title=BARLANHT(k,j)&action=edit&redlink=1), [BARLANCFSP(k,j)](/index.php?title=BARLANCFSP(k,j)&action=edit&redlink=1) include this line only if IBTYPE(k) = 3, 13, 23` (46); `[NBVV(k,j)](/index.php?title=NBVV(k,j)&action=edit&redlink=1), [IBCONN(k,j)](/index.php?title=IBCONN(k,j)&action=edit&redlink=1), [BARINHT(k,j)](/index.php?title=BARINHT(k,j)&action=edit&redlink=1), [BARINCFSB(k,j)](/index.php?title=BARINCFSB(k,j)&action=edit&redlink=1), [BARINCFSP(k,j)](/index.php?title=BARINCFSP(k,j)&action=edit&redlink=1) include this line only if IBTYPE(k) = 4, 24` (47); ## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 7–48: 여러 입력 변수의 참조 URL에 `action=edit&redlink=1`이 들어 있다. 변수의 단위와 각 경계 유형의 뜻은 이 파일의 본문에 정의되어 있지 않다.
