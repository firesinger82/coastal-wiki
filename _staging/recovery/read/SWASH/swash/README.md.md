| 24–40 | 소개는 파랑·조석·부력(buoyancy)·바람이 구동하는 비정상(unsteady)·비정수압(non-hydrostatic)·자유수면(free surface)·회전 유동(rotational flow)과 수송(transport)을 모의하는 수치 도구로 SWASH를 설명한다(24–28). 설명 범위는 심해부터 해변·항만까지의 파랑 변형, 급변 유동, 연안해·하구·호수·하천의 밀도 유도 유동(density driven flow)이다(27–28). 배경 설명은 `SWASH website`로 연결한다(30). 현재 버전 표기는 `12.01`이다(31). 설치·설정 개요의 추가 자료는 `Implementation Manual`로 연결한다(33–36). 사용 조건은 `GNU General Public License`이며, 원저작물을 적절히 인용하면 복제·재사용·수정·배포할 수 있다고 문서가 적는다(38–39). 제목과 빈 줄을 포함한다(24–25·29·32·35·37·40). |
| 41–74 | 설치 전제는 `CMake`와 `Ninja (or GNU make)`이다(41–45). 문서는 `CMake 3.20+`를 권고하고 확인 명령 `cmake --version`을 제시한다(46). CMake 설치 대상은 `Windows, Linux and macOS`이다(47–49). Ninja 설명은 `GNU make`와 Windows의 `NMAKE`를 비교 대상으로 적는다(51–53). Perl 확인 명령은 `perl -v`이고 Windows 배포판은 `Strawberry Perl`이다(55–57). 요구 Perl 버전은 `5.0.0 or higher`이다(58). 컴파일러 요구는 `Fortran90`이다(60). 컴파일러 예시는 `gfortran`과 `Intel<sup>&reg;</sup> Fortran Compiler Classic`이다(61–62). Intel 컴파일러는 `oneAPI HPC Toolkit`에 포함된다(63). 문서는 두 컴파일러가 `OpenMP` 표준을 지원한다고 적는다(63). 64행은 플랫폼별 gfortran 설치 안내로 연결한다. 이식성 설명은 `ANSI standard Fortran90`을 근거로 든다(66). 빌드 스크립트의 지원 목록은 `GNU`, `Intel<sup>&reg;</sup>`, `Portland Group`, `Lahey`, `IBM XL Fortran`이다(67–73). 절 제목·번호 목록·빈 줄을 포함한다(41–44·50·54·59·65·68–74). Ninja 구성·빌드 명령은 `cmake .. -G Ninja` (100)과 `cmake --build .` (101)이다. 문서는 첫 명령이 소스의 주 설정 파일을 호출하고 두 번째 명령이 빌드 디렉터리에서 빌드한다고 설명한다(104). | 122–156 | 4단계 설치 명령은 `cmake --install .` (127) 또는 `make install` (133)이다(122–134). 기본 설치 경로 표기는 Unix 계열의 `$HOME/wavemodels/swash`와 Windows의 `%LocalAppData%\Programs\wavemodels\swash`이다(136). 문서는 이 경로가 관리자 권한 없는 설치를 허용한다고 설명한다(137). 사용자 경로 지정 예시는 `cmake --install . --prefix /somewhere/else/other/than/default/directory` (140)이다. 다른 지정 예시는 `cmake .. -DCMAKE_INSTALL_PREFIX=/somewhere/else/other/than/default/directory` (146)과 `make install` (147)이다. 설치 결과의 디렉터리는 실행 파일 `/bin`, 아카이브·라이브러리 `/lib`, 모듈 `/mod`, PDF `/doc`, 스크립트 `/tools`, 기타 파일 `/misc`이다(150–153). 문서는 설치 생략을 허용하지만 권고하지 않는다고 적는다(155). 설치를 생략하면 실행 파일과 라이브러리는 빌드 디렉터리의 하위 디렉터리에 있다고 문서가 적는다(155). 절 제목·코드 블록 표지·빈 줄을 포함한다(122–126·128–132·134–135·138–139·141–145·148–149·154·156). | 157–173 | 빌드 설정은 접두사 `-D`로 옵션을 전달한다(157–159). 일반 명령 문법은 `cmake .. -D<option>=<value>` (162)이다. `<value>`는 옵션에 따라 문자열 또는 불리언(boolean)이다(165). 옵션 표는 `CMAKE_INSTALL_PREFIX`의 형식을 `string`, 기본값을 `../wavemodels/swash`로 적는다(167–169). `CMAKE_Fortran_COMPILER`는 `string`이며 기본값은 `determined by CMake`이다(170). `MPI`는 `boolean`이며 기본값은 `OFF`이다(171). `CMAKE_VERBOSE_MAKEFILE`은 `boolean`이며 기본값은 `OFF`이다(172). 표 머리·구분선·코드 블록 표지·빈 줄을 포함한다(157–158·160–161·163–164·166–168·173). |
| 174–197 | MPI(Message Passing Interface) 병렬 빌드 예시는 `cmake .. -GNinja -DMPI=ON` (177)과 `cmake --build .` (178)이다(174–181). | 198–215 | 정리 절은 프로젝트 최상위에서 빌드 디렉터리와 `cmake --build .` 이후 생성 파일을 제거하는 명령을 제시한다(198–200). 명령은 `cmake -P clobber.cmake` (203)이다. 문서는 `-P`가 `*\<filename\>.cmake*` 스크립트를 실행한다고 설명한다(206). 시작 안내는 `SWASH's User Guide`의 `Chapters` 2·3을 먼저 읽고 `Chapter` 5도 읽도록 권고한다(208–214). 절 제목·코드 블록 표지·빈 줄을 포함한다(198–199·201–202·204–205·207–209·215). |
| 216–224 | 실행 모드는 두 가지이다(216–218). `serial`은 프로세서(processor) 하나를 쓰는 노트북용이며 작은 시험에 권고된다(220). `parallel, distributed (MPI)`는 여러 프로세서를 쓰는 노트북·데스크톱, 클러스터(cluster), `HPC` 등 분산 메모리(distributed memory) 시스템용이다(221). 적합한 실행 파일 획득 방법은 앞의 설치 절을 참조하라고 문서가 적는다(223). 절 제목·번호 목록·빈 줄을 포함한다(216–219·222·224). |
| 225–251 | 실행 절차는 명령 파일 `INPUT` 완성·수정, 모델 실행, `PRINT`의 경고·오류 확인, 필요 시 반복이다(225–235). 직렬 실행 명령은 `   ./swash.exe` (232)이다. 클러스터용 대체 명령은 `mpirun -np <n> swash.exe` (240)이다(237). 문서는 `<n>`을 `number of desired nodes`로 설명한다(243). `v 12.01`의 비구조 격자(unstructured mesh)는 병렬 모드에서 지원하지 않는다고 문서가 적는다(245). 자동 실행 스크립트는 `/bin/swashrun` 또는 Windows의 `\bin\swashrun.bat`이다(247). 사용 전제는 `PATH`에 `/bin` 디렉터리의 경로를 추가하는 것이다(247–248). 추가 설명은 `Implementation manual`로 연결한다(250). 절 제목·번호 목록·코드 블록 표지·빈 줄을 포함한다(225–228·230–231·233–236·238–239·241–242·244·246·249·251). |
