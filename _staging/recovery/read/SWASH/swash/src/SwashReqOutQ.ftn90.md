## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 139–140·191·375–376·410: BLOCK/TABLE은 nreoq를 증가시킨 뒤 max_outp_req 초과를 msgerr(2)로 보고한다. 각 경로의 outp_files(nreoq) 대입 전에는 이 초과 조건에 따른 return이나 goto가 없다.
- 154–159: Matlab·VTK 파일 판별은 .MAT/.mat·.VT/.vt 문자열의 index 검사이다. 확장자가 파일명 끝에 있는지 확인하는 별도 조건은 없다.
- 147–162·202·222: 블록 파일 형식 선택에서 dfac 초기값은 1 또는 −1이다. 출력량별 UNIT 호출의 STA 인수는 −1이며, tmp%r에는 그 호출 뒤 dfac 값을 저장한다.
- 279–283·522: 소문자 PVD 경로는 FILENM(ilpos+1:ilpos+3)에 pvd를 쓴다. 대문자 경로는 FILENM(ilpos+3:ilpos+3)에 PVD를 format a3으로 쓴다. 두 부분 문자열의 길이는 각각 3과 1이다.
- 304–311·315–328: 출력 디렉터리 MKPATH 실패는 outdir=.으로 처리한다. 병렬 하위 디렉터리 생성은 반복마다 같은 ierr에 결과를 받는다. 하위 디렉터리 오류 검사는 iproc 루프가 끝난 뒤에 한 번 수행한다.
- 220–225·240–245·447–451·469–473: 출력량 임시 목록은 출력량마다 노드를 할당한다. 배열 복사 뒤에는 tmp만 해제한다. 전체 임시 노드를 순회하며 해제하는 루프는 이 파일에 없다.
- 423–429·430–445: TABLE의 NOGRID 출력량 오류와 이차원 RUNUP 경고는 각각 독립 조건이다. 두 블록에는 해당 출력량을 건너뛰는 goto나 return이 없다. 이후 출력량 필터의 ivtype>0 분기는 목록에 번호를 추가한다.
- 249–252·478–481: OUTPUT 시간 키에서 nstatm=0이면 msgerr(3)를 호출한다. 이 검사 다음 문장은 두 경로 모두 nstatm=1이며 이어서 TBEG·DELT를 읽는다.
- 458–461·475·498–500: TABLE은 UNIT 키를 인식하면 unit를 무시한다고 보고한다. fac는 475행에서 길이 0으로 할당한다. nvar=0일 때 500행에서 같은 fac에 길이 0 할당을 다시 수행한다. 가져온 orqdat 형식 선언 내부는 읽지 않았다.
- 126–133·370·518–519: 출력점 집합 검색 실패와 BLOCK의 집합 유형 오류는 label 800으로 간다. label 800은 found를 참으로 설정한다.
