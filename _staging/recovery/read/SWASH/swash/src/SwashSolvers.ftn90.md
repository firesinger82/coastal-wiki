## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 1029·1466·1885·3392: pcg·pcg2·sip·bicgstab는 epsmac을 1d-18로 고정한다. 선언의 한 예는 `double precision, parameter :: epsmac = 1d-18 ! machine precision number` (1029). 단정밀도 루틴 pcg의 최소 정확도 식은 `ueps   = 1000.*real(epsmac)*rnrm0` (1216)이다.
- 1201–1230·1266·1339·1638–1667·1703·1776: pcg와 pcg2는 초기 잔차의 수렴 여부를 검사하는 분기 없이 반복문에 진입한다. 각 alpha 계산 `alpha = rho / a` (1266), `alpha = rho / a` (1703)은 반복 중 종료 검사 `if ( .not. rnorm > epslin ) exit` (1339), `if ( .not. rnorm > epslin ) exit` (1776)보다 앞에 있다.
- 1077·1230·1333·1357·1514·1667·1770·1794: pcg·pcg2의 rnorm 첫 대입은 각각 반복문 안의 `rnorm = sqrt(rho)` (1333), `rnorm = sqrt(rho)` (1770)이다. 반복문 뒤에는 `if ( rnorm > epslin .and. iamout > 0 .and. INODE == MASTER ) then` (1357), `if ( rnorm > epslin .and. iamout > 0 .and. INODE == MASTER ) then` (1794) 검사가 있다. 두 루틴은 maxit을 pnums(24)에서 가져온다. 이 파일의 두 루틴에는 maxit의 하한 검사 분기가 없다.
- 2092–2093·2209–2210·2223–2232: sip는 해 갱신 전에 잔차 제곱합을 누적한다. 해를 갱신한 뒤 이 제곱합을 SWREDUCE로 합산하고 제곱근을 구해 종료 검사와 로그에 사용한다. 같은 반복에서 갱신한 해로 잔차를 다시 계산하는 문장은 이 구간에 없다.
- 2802·2814–2818·2915·2928–2932: iludr 주석은 M행렬로 수정한다고 적는다. 실제 조건은 `if ( amat(nm,k,j) > 0. ) then` (2814), `if ( amat(nm,k,j) > 0. ) then` (2928)이며 참이면 원계수를 유지한다. 각 else는 해당 비대각을 0으로 두고 `prec(nm,k,1) = prec(nm,k,1) + amat(nm,k,j)` (2818), `prec(nm,k,1) = prec(nm,k,1) + amat(nm,k,j)` (2932)로 원계수를 대각에 더한다.
- 2865–2871·2883–2886·2988–2999·3013–3016·3196–3202·3214–3217·3272–3283·3297–3300: iludr와 iluds는 현재 대각의 역수를 저장하는 단계에서 대각 0을 1로 바꾼다. 이 단계보다 앞선 대각 계산식에는 이웃 diagb를 분모로 쓰는 항이 있다. 이웃 diagb의 설정은 외부 호출 흐름까지 확인하지 않았다.
- 3706·3783–3796·3975·4058–4071·4202: bicgstab는 반복 횟수를 늘린 뒤 `if ( .not. sigma /= 0. ) then` (3783), `if ( .not. sigma /= 0. ) then` (4058)에서 레이블 20·40으로 이동할 수 있다. unorm의 첫 대입은 각 분기 뒤의 3796·4071행이다. 공통 종료 처리는 `if ( j > 0 ) rnorm = min(rnorm,unorm)` (4202)이다.
