## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 3–21·2208–2315: 파일 목차는 RDHMS를 나열하지만 이 파일에는 RDHMS 루틴 정의가 없다. 이 파일이 정의하는 EQCSTR은 목차에 없다.
- 439–440·561–562·755–756·910–911·1116–1117: NSKP 설명 주석은 다른 자료형일 때 값을 유지한다고 적는다. 구현의 해당 경로는 INDBLE의 R=RSTA(643·676), ININTG의 IV=ISTA(827·836), INCSTR의 CSTA 복사(1012·1022–1030), INCTIM의 RV=RSTA(1214·1223)로 이동한다.
- 553·620·626·667: INDBLE의 R/RSTA는 배정밀도 선언이다. CHGVAL과 RQI 비교는 두 값을 REAL로 변환하여 EQREAL에 전달한다. EQREAL 내부는 이 판독 범위에 포함하지 않았다.
- 489·651·663·2208·2296: INDBLE의 두 내부 오류 메시지는 루틴명을 INREAL로 적는다. EQCSTR의 STRACE 호출은 이름 인수로 UPCASE를 전달한다.
- 1314·1347–1351·1456·1489–1493: ININTV와 INITVD의 지역 변수 RI 선언에는 초기값이 없다. 두 루틴은 RI에 값을 대입하는 문장 없이 각각 INREAL과 INDBLE의 인수로 전달한다. INREAL은 진입 후 R을 DBLE로 변환한다(474).
- 1352–1366·1494–1508: 두 시간 간격 루틴은 CHGVAL 참 분기 안에서만 시간 단위 키워드를 읽는다. CHGVAL 거짓 분기는 FAC=1로 설정한다. CHGVAL은 수치 판독 루틴에서 기준값과의 비교 결과로 설정한다(602·620·626).
- 1474·1493: INITVD의 구조 주석은 INREAL 호출을 적는다. 실행문은 INDBLE을 호출한다.
- 1632–1639·619·625·807: LEESEL의 반복 수 NREP는 SAVE 변수이다. NREP>1 경로는 NREP를 감소시키고 190번으로 이동하며 ELTYPE을 원래 자료형으로 복원하는 대입문이 없다. 수치 항목을 소비한 INDBLE과 ININTG 경로는 ELTYPE을 USED로 설정한다.
- 1643–1649·1661–1663·1678–1679: 새 항목 초기화는 ELTEXT·JKAR·ELINT·ELREAL을 설정하지만 LENCST를 설정하지 않는다. 줄 끝 EOR 경로와 빈 항목 EMPT 경로는 LENCST에 새 값을 대입하지 않고 190번으로 간다.
- 1809–1834: 따옴표 문자열 판독의 KARNR>LINELN 경로는 닫는 따옴표 확인이나 MSGERR 호출 없이 190번으로 간다.
- 1823–1826·1845–1852·1875–1880: 문자열·키워드·OTHR 판독은 JJ 또는 JKAR를 증가시키며 ELTEXT의 해당 위치에 직접 대입한다. 이 세 반복 경로에는 대입 인덱스와 ELTEXT 길이를 비교하는 조건이 없다.
- 2093–2096: PUTKAR는 JKAR>LEN(LTEXT)이면 MSGERR(2)를 호출한다. 다음 문장은 별도 분기 없이 LTEXT(JKAR:JKAR)에 대입하며 JKAR를 증가시킨다. MSGERR 내부의 반환·중단 동작은 확인하지 않았다.
- 321·1854·2416–2424: INKEYW의 긴 기본값과 LEESEL의 키워드 복사는 첫 8문자를 사용한다. KEYWIS의 비교 루프 상한은 LEN(STRING)이고 이 루프 앞에는 8로 제한하는 식이 없다.
- 1014–1015·1019: INCSTR의 두 오류 로그 WRITE 목록은 NAAM과 ELTEXT(1:LENCST)를 전달한다. 두 WRITE가 참조하는 41번 FORMAT은 문자 편집 지정자 A8 한 개를 포함한다.
