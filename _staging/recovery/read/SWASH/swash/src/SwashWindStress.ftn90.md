## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 130·135: wfac는 rhoa/(rhow*alpha*alpha)이다. 이 대입 앞에는 alpha 또는 rhow의 0 여부를 검사하는 조건이 없다.
- 166–187·301–367·545–547·625–627: 파속 보정 블록은 hum/hvm의 제곱근을 사용한다. 이 블록에는 젖은 표지나 양의 수심 조건이 없다. 응력 계수 계산의 `if ( nmu  == 1 ) nmu  = nm` (545·625)는 nmu를 nm로 바꾼다. `if ( ndm  == 1 ) ndm  = nm` (546·626)는 ndm을 nm로 바꾼다. `if ( ndmu == 1 ) ndmu = ndm` (547·627)는 ndmu를 그 시점의 ndm으로 바꾼다. 파속 보정 블록에는 같은 반사 처리가 없다. [10-15 전수 검증 정정]
- 76–79·506–509·885–888·928–931: 2차 다항식의 rr는 −1.49이고 uref는 31.5이다. 이 공식은 w10/uref를 그대로 사용하고 cd에 cdcap 상한만 적용한다. 해당 분기에는 w10 상한이나 cd의 0 하한을 적용하는 식이 없다.
- 391–401·549–563·587–601·960–970: relwnd는 항력계수 계산용 풍속 크기에서 흐름 속도를 뺀다. 최종 풍응력 대입은 rwx/rwy가 아니라 windu/windv에 alpha*cwndu/cwndv를 곱한다.
- 491–494·498–511: 1차원 다항식 분기는 mu와 nmu를 계산한다. 해당 분기의 이후 계산식에는 mu/nmu가 등장하지 않는다.
- 978–993: smax는 s0>smax일 때만 s0로 갱신한다. 이 블록에는 smax 초기화나 시간 창에 따른 감소가 없다. 마루 응력 적용 조건은 이 smax의 (1−wcrstp)배와 s0를 비교한다.
