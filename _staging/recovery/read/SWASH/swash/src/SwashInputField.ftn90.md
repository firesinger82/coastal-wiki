## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 73·112–188: igr1 선언에는 초기값이 없다. 알 수 없는 입력 종류의 else는 WRNKEY를 호출하며 igr1 대입과 return 문이 없다. 입력 종류 분기 다음 문장은 iflfac(igr1)을 인수로 사용한다. WRNKEY 내부 동작은 판독하지 않았다.
- 151–165: SAL·TEMP·SED 입력 분기는 각각 ltrans에 1을 더한 뒤 lsal/ltemp/lsed를 설정한다. 이 분기들에는 같은 성분의 기존 설정 여부를 검사하는 조건이 없다.
- 201–219·429–432: REPARM의 동적 입력 인수는 ifldyn(igr1)이다. 두 번째 성분 매개변수 복사 블록에는 ifldyn(igr2) 대입이 없다. 동적 입력 시각 설정 블록은 두 번째 성분 ifltim까지 복사한다.
- 113–115·128–135·221–224·240–244: BOT와 COOR 분기는 입력 배열 판독 전에 logcom(3) 또는 logcom(4)를 참으로 설정한다. 이후 격자 미지정 오류나 중단 조건의 return 앞에는 이 표지를 거짓으로 되돌리는 문장이 없다.
