## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 193·890–892·1402–1405·1889–1892: lriem은 선언에서 거짓으로 초기화된 지역 논리변수이다. 이 파일의 실행문은 LRIE 입력에서만 lriem을 참으로 바꾼다. 실행문에서 거짓으로 되돌리는 대입은 없다.
- 416–423: SwanFindPoint 결과 ix2<0이면 msgerr를 호출한다. 그 뒤 이 블록에는 명시적 return이 없으며 vert(ix2)의 VMARKER를 참조한다. msgerr 내부의 중단 동작은 이 파일에서 확인하지 않았다.
- 1017–1049·1478–1541·476–481·572–576·856–860·1971: 푸리에 성분과 경계점은 노드별로 할당·연결된다. 균일 FOUR 경로는 1037행 `if ( nfreq > 0 ) then` 안에서 성분 목록 복사 뒤 tmpf가 가리키는 마지막 노드를 해제한다(1049). 가변 FOUR 경로는 1529행 `if ( nfreq > 0 ) then` 안에서 현재 입력 구간의 마지막 성분 노드를 해제한다(1541). 가변 경로의 해제문은 1478행 `do` 안에 있으므로 입력 구간마다 실행될 수 있다. 루틴 끝에서는 `if (associated(tmp)) deallocate(tmp)` (1971)로 tmp가 가리키는 마지막 경계점 노드를 해제한다. 전체 연결 목록을 순회하는 해제 루프는 없다. [10-15 전수 검증 정정]
- 1035·1060·1461·1552: 균일 입력은 istok=2이고 nfreq>1이면 istok=3으로 변경한다. 가변 불규칙파 경로도 istok=2를 3으로 변경한다. 두 주파수 정렬 블록의 조건은 모두 istok=2 또는 ibound=1이다.

REG와 MONO는 같은 분기에 속한다(1425). FILE과 SERI는 같은 분기에 속한다(1431). 이 사슬에는 최종 `else`나 WRNKEY 호출이 없다. 이후 bcimp를 검사한다(1439). [10-15 전수 검증 정정]
- 1480·1483·1862–1863: rlen2 입력 뒤 거리 비교와 보간식이 이어진다. 보간 분모 rlen2-rlen1에 대한 0 검사나 LEN의 단조 증가 검사는 이 루틴에 없다.
