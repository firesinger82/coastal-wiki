- 192·217·224–230: sumqf는 `sumqf = 0.`으로 초기화한다(192). `if ( qf > 0. ) sumqf = sumqf + qf` (217)는 양의 유출 유량만 누적한다. 시간 수준 계산의 수심 조건은 `if ( hso(icell) > epsdry ) then`이다(224). `log(2.*cfl)`을 평가하기 전에 cfl>0을 확인하는 조건은 이 블록에 없다. [10-15 전수 검증 보완]
