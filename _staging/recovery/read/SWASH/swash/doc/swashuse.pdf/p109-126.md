| p.114 | 인쇄 쪽 번호 106. 제4장 `BLOck` 명령의 파일 출력과 배치 형식(layout)을 설명한다. 쪽 첫머리는 하나 이상의 공간 분포를 파일에 써야 한다는 이전 쪽 문장의 끝이다.<br>`'sname'`은 프레임 또는 그룹(group)의 이름이다. `FRAME` 또는 `GROUP` 명령을 참조한다. `HEADER`는 머리말 행(header lines)을 포함한 파일 출력을 지정한다. 머리말은 `PROJECT`의 실행 식별자(run identification), 시각, 프레임 또는 그룹 이름 `'sname'`, 변수, 단위를 표시한다. 머리말 행 수는 `8`이다. 파일 수치는 머리말에 표시한 단위를 사용한다. `NOHEADER`는 머리말 행 없는 파일 출력을 지정한다.<br>`'fname'`은 출력 데이터 파일 이름이다. `HEADER` 옵션의 기본 출력은 `PRINT` 파일이다. `NOHEADER`에서는 파일 이름이 필수이다.<br>기본 출력은 ASCII 문자 인코딩(character encoding)을 사용하는 사람이 읽을 수 있는 파일이다. 텍스트 편집기로 열고 편집하거나 Matlab 또는 Excel에서 볼 수 있다. 출력 확장자가 `.mat`이면 이진 MATLAB 파일(binary MATLAB file)을 생성한다. 이진 파일은 ASCII 파일보다 저장 공간이 적고 MATLAB에서 더 빨리 읽힌다. 출력 매개변수는 단정도(single precision)로 저장한다. 필요하면 Matlab 명령 `double`로 배정도(double precision)로 변환한다. 이진 MATLAB 파일은 특히 비구조 격자(unstructured grids) 계산에 유용하다. SWASH 소스 코드에 파랑 매개변수를 지도 형태로 그리는 MATLAB 스크립트가 포함되어 있다.<br>본문은 버전 `8.01`부터 Paraview에서 볼 수 있는 VTK 파일을 생성할 수 있다고 명시한다. Paraview는 Windows, Mac, Linux에서 사용할 수 있다. 기본 확장자는 `.vtk`이다. 실제 XML 기반 형식은 구조 격자(structured grids)의 `*.vts`와 비구조 격자 자료의 `*.vtu`로 달라진다. VTK XML 파일은 이진 형식이다. 파일은 일반 텍스트 메타데이터(metadata)를 포함하는 자기 기술형(self-descriptive)이다. 파일은 플랫폼 간 이동이 가능하다. 분산 메모리 기계(distributed memory machine)에서 SWASH를 병렬 실행한 뒤 각 프로세스의 VTK 파일을 수집할 필요가 없다. Paraview는 여러 하위 영역(subdomains)으로 구성된 전체 영역을 시각화할 수 있다.<br>`LAY-OUT`은 `[idla]`로 파일 출력 배치를 지정한다. `READINP`를 참조한다. 가능한 값은 `[idla]=1, 3, 4`이다. MATLAB 후처리(postprocessing)에는 옵션 `4`를 권장한다. 이진 MATLAB 파일을 생성할 때에는 옵션 `3`을 권장한다.<br>원문: `The number of header lines is 8.`(p.114) |
