# Cell_Map.md — 판독 구간 기록

구간은 1행부터 14행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — Confluence 페이지의 식별자, 제목, space, URL, 버전, 갱신 시각, 문서 계층과 frontmatter 경계 표식이다(1–9). |
| 10–14 | Cell Map — 메모리에 저장된 셀(cell) 배치를 표시한다(10). 그림 예시는 `Uniform Grid` 옵션이며 I·J 축에 라벨을 붙일 수 있다고 적는다. 적용 조건 원문: ` Deactivated cells can be viewed using this view by checking "Inactive Cell" box. The inactivated cells are displayed with gray color.` (11). Figure 1의 로컬 그림을 직접 열었다(13). 격자는 가로·세로 각각 10칸이다. 수평·수직 눈금은 각각 `1`부터 `10`이다. 오른쪽 위 두 셀은 회색이다. 옆 패널에는 `Cell Map`이 선택되어 있다. `Label Cells`와 `Inactive Cell`은 체크되어 있고 `Skip` 입력값은 `1`이다(13). 이 값은 그림의 예시값이다. 그림 캡션과 빈 줄을 포함한다(12–14). |
