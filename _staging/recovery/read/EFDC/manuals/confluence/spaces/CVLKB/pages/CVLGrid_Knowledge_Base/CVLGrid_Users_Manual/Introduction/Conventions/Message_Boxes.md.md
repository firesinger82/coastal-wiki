# Message_Boxes.md — 판독 구간 기록

구간은 1행부터 17행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | Message Boxes / 문서 메타데이터 — 페이지 ID `2818260`, 제목, space, 원문 URL, 버전 `1`, 갱신 시각, 문서 계층을 포함한다(1–9). |
| 10–16 | Message Boxes / 셀 정보 네 항목 — 현재 격자(grid)의 셀을 누르면 노란 정보 상자(message box)가 나타난다(10). 표시 항목은 네 개다(10). 셀 번호 원문: `- L – The cell number starting with # 2` (12). 셀 인덱스(cell indices) 원문: `- I,J – Cell indices` (13). 면적 단위 원문: `- Cell Area – in m2` (14). 꼭짓점 순서(corner order)의 허용 표기 원문: `- Corner Order – Clockwise or Counterclockwise` (15). 셀 번호는 `# 2`부터 시작하고 면적 단위는 원문 표기로 `m2`다(12·14). |
| 17–17 | Message Boxes / 한 셀만 표시와 이동 — 한 번에 셀 하나의 정보만 볼 수 있다(17). 상자 경계 안을 누른 채 끌어 다른 위치로 옮긴다(17). 수량 제한 원문: `Only one cell's information can be viewed at a time. The message box can me moved by clicking within its border and dragging it to another spot.` (17). |
