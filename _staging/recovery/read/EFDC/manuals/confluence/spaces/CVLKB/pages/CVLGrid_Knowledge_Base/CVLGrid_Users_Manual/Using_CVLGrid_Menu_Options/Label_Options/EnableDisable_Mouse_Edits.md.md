# EnableDisable_Mouse_Edits.md — 판독 구간 기록

구간은 1행부터 10행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목은 `Enable/Disable Mouse Edits`이다(3). 문서 ID는 `2818224`이다(2). 공간·원문 URL·버전·갱신 시각·탐색 경로를 기재한다(4–8). YAML 구분선은 1·9행이다. |
| 10–10 | Enable/Disable Mouse Edits — 레이블(label)에서 `LMC`를 사용한 뒤 다른 위치로 끌어 수동으로 이동할 수 있다(10). 도구가 활성화되면 레이블 옆에 검은 사각형이 나타나 이동할 수 있음을 표시한다(10). 원문: `This tool allows the user to move manually labels by LMC on the label and dragging it to another location. When enabled a black square appears next to the label indicating that the label can be moved.` (10). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행의 약어 `LMC`는 이 파일에서 풀어 쓰지 않는다.
