# Online_Activation_Process.md — 판독 구간 기록

구간은 1행부터 24행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | Online Activation Process / 문서 메타데이터 — 페이지 ID `2818265`, 제목, space, 원문 URL, 버전 `4`, 갱신 시각, 문서 계층을 포함한다(1–9). |
| 10–11 | Online Activation / 최초 사용과 인터넷 조건 — 설치 후 처음 사용하기 전에 활성화해야 한다(10). 영구 라이선스(Perpetual License)와 시험 라이선스(Trial License)는 오프라인 활성화를 쓰는 경우를 제외하고 인터넷 연결이 필수다(10). 인터넷 미연결 또는 방화벽(firewall) 존재 시 오류 메시지가 나올 수도 있다(10). 본문은 보안 프로그램·방화벽 설정을 조정하고 다시 시도한 뒤 실패하면 지원에 문의하라고 적는다(10). 적용 조건·의무·불확실성 원문: `After installation, the user must activate the software before first use. Sometimes problems occur for users at the activation stage. Please note that to activate Perpetual and Trial versions of CVLGrid, the user **must be connected to the internet unless using offline activation.** If the user is not connected to the internet, or if there is a firewall on the network or installation computer, an error message may be given. In this case, please adjust your internet virus checker or firewall settings and try activating again. If this fails please contact support.` (10). |
| 12–15 | Online Activation / 실행 경로 — 바탕 화면 아이콘이나 Start 메뉴로 CVLGrid를 시작한다(12). 실행 경로 원문: `"Start\All Programs\DSI\CVLGrid1.1\CVLGrid1.1".` (14). |
| 16–20 | Online Activation / 라이선스 입력 — 첫 실행 시 라이선스 이름(license name)과 라이선스 코드(license code)를 요구하며 코드에 따라 영구 또는 시험 버전을 자동 활성화한다고 적는다(16). 입력 항목·조건 원문: `2. If this is the first time you have run CVLGrid on your computer you will be see the CVLGrid be prompted for your license name and license code, as shown in [Figure 1](#OnlineActivationProcess-Figure1). CVLGrid will automatically activate the Perpetual or Trial version based on your license code.` (16). 직접 연 그림 1은 `Activation Wizard`에서 `Activate over the Internet.` 선택, `Hardware ID:`, 여섯 코드 입력 칸, `Activate CVLGrid` 버튼을 보여 준다(18–19). 그림에는 라이선스 이름 입력 칸이 보이지 않는다(18행 참조 그림). |
| 21–24 | Online Activation / 주 창 — 활성화 뒤 CVLGrid 주 창이 나타난다고 적는다(21). 직접 연 그림 2는 파란 곡선 격자(curvilinear grid)가 좁은 수로에서 오른쪽 넓은 영역으로 이어지고 아래쪽으로 가지가 연결된 주 창이다(23–24). 범례는 파란 선 `Grid`, 축척 막대는 `10.34 Kilometers`, 상태 표시줄은 `Grid Cells: 15532`, `NI,NJ: 483, 11`이다(23행 참조 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 16·21행: `#OnlineActivationProcess-Figure1`, `#OnlineActivationProcess-Figure2` 내부 참조가 있다. 이 파일에는 해당 ID를 정의하는 명시 앵커가 없다.
- 16·18행: 본문은 라이선스 이름과 코드를 요구한다고 적는다. 참조 그림 1에서는 라이선스 코드 입력 칸만 보이고 라이선스 이름 입력 칸은 보이지 않는다.
