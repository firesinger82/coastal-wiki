Each separate window corresponding to each layer appears in turn to allow the user to save layers in desired folder.  ` (10); ` For example, there can be three layers including grid, splines, and overlay layers, so if the user exports all layers there are three separate windows to set the name and location of the exported file. [Figure 1](#ExportAllLayer(s)-Figure1) shows exporting of a grid layer. [Figure 2](#ExportAllLayer(s)-Figure2) shows exporting of an overlay layer and [Figure 3](#ExportAllLayer(s)-Figure3) shows exporting of a spline layer.` (11). |
