# Layer_Control.md — 판독 구간 기록

구간은 1행부터 48행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — Confluence 페이지의 식별자, 제목, space, URL, 버전, 갱신 시각, 문서 계층과 frontmatter 경계 표식이다(1–9). |
| 10–14 | Layer Control — 레이어(layer) 도구는 격자(grid)·스플라인(spline)·오버레이(overlay)의 가져오기·내보내기·선택·조작 기능을 제공한다(10). 로컬 Figure 1을 직접 열었다(12). 그림은 레이어 이름·유형 목록과 `Show/Hide`, `Legend` 체크박스, 가져오기·내보내기·새 레이어·삭제·이름 변경·서식·결합·보기 버튼을 보여 준다(12–13). |
| 15–30 | Layers Tool / 기능 표 — 각 기능의 이름과 설명을 원문대로 옮긴다: `*Show/Hide*` — `Makes the layer visible or hidden. When the the box is checked the layer is visible` (19); `*Legend*` — `For the layer selected this option will show or hide that layer label on the legend. If box is checked then the legend is visible.` (20); `*Import*` — `Imports a polyline files or GRD file. Also loads CVL grid file.` (21); `*Export*` — `Opens a browser window to choose a location to save the selected layer. Options include the following extensions CVL, GRD, P2D, KML,  LDB, SHP, ECOMSED, SEAGRID, CH3D. This option allows the user to export a grid to a third party applications such as DELFT3D or other modeling tools.` (22); `*New*` — `Creates a new layer` (23); `*Delete*` — `Deletes the selected layer` (24); `*Rename*` — `Renames the selected layer` (25); `*Format*` — `Changes the color, symbol and line type of the lines on layer` (26); `*Combine*` — `Combines selected layers into one, this function only applied for splines and overlay layers.` (27); `*View*` — `View the selected layer` (28). `Show/Hide`와 `Legend`는 체크 상태에 따른 표시 조건을 설명한다(19–20). `Export`는 내보내기 확장자와 DELFT3D 등 외부 모델 도구 사용을 설명한다(22). `Combine`은 스플라인·오버레이 레이어에만 적용된다(27). 작업 공간으로 파일을 끌어 놓아 열 수도 있다고 적는다(30). 표 머리글·구분선과 빈 줄도 포함한다(15–30). |
| 31–43 | 레이어 항목의 RMC 메뉴 — 사용 가능한 메뉴 항목은 레이어 유형에 따라 달라진다(32). Figure 2·3·4의 로컬 그림을 각각 직접 열었다(34·37·40). 각 그림은 격자, 스플라인, 오버레이를 선택한 Layer Control 문맥 메뉴를 보여 준다. 그림의 공통 메뉴 이름은 `Rename`, `Format`, `Flag as Polygon(s)`, `Copy to Another Layer`, `Zoom to Selected`, `New Layer`, `Save`, `Deleted Selected`, `Convert to Splines`이다(34·37·40). 마지막 항목은 격자·스플라인 그림에서 비활성이고 오버레이 그림에서 활성이다. 적용 조건 원문: `It should be noted that the *Convert to splines* option is available only for overlay layers. The purpose is for the overlay layer to be converted to a spline layer.` (43). |
| 44–48 | 새 레이어 — Layer Control 빈 곳에서 RMC하여 새 레이어를 만든다고 적는다(45). Figure 5의 로컬 그림을 직접 열었다(47). 그림은 `New Layer` 하위 메뉴의 `Overlay Layer`, `Spline Layer`를 보여 준다. 캡션과 빈 줄을 포함한다(44–48). |
