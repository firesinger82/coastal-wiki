## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행의 `#ImportGridTypes-Figure1`과 `#ImportGridTypes-Figure7` 링크 대상에 해당하는 앵커 선언이 이 파일에 없다. 13·31행은 해당 캡션이다.
- 12·15·18·21·24·27·30행 그림은 `Number of Corners Inside Polygon(s) to Count Cell as "Inside":`에 `0`을 표시한다. 본문 10행은 이 `0`의 의미나 허용 범위를 설명하지 않는다.
