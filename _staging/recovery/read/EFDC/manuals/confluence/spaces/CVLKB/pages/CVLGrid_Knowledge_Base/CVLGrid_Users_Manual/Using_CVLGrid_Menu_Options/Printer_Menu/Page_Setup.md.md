# Page_Setup.md — 판독 구간 기록

구간은 1행부터 22행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터(metadata) — 페이지 ID(2), 제목(3), space(4), 원문 URL(5), 버전(6), 갱신 시각(7), 문서 계층 경로(8)를 기록한다. `---` 구분자를 포함한다(1·9). |
| 10–19 | Page Setup — 별도 창에서 인쇄 전 설정을 바꾼다(10). 창 위쪽의 프린터 이름은 `Show Printer's` 아이콘으로 바꾼다(10). 페이지 방향(Page Orientation)은 가로 또는 세로이며, 여백(Margins) 기본값은 1인치이다(12·14). 인쇄 가능 영역(Printable area)은 인쇄할 작업공간 부분을 정한다(16). 배경(Background)은 배경 또는 테두리의 인쇄 여부를 고른다(18). 오른쪽 흰 상자는 페이지와 여백을 미리 보여 준다(18). `Ok`는 설정을 저장하고 `Print` 선택 때 적용한다(19). `Cancel`은 설정 창을 닫는다(19). 설정 원문: `*Page Orientation* allows the user to decide whether the page will be printed in landscape or portrait mode.` (12); `*Margins* allows the user to set the size of the page margins. One inch is the default.` (14); `*Printable area* defines the portion of the workspace that will be printed.` (16); `*Background* selects whether or not the background or boarder will be printed. The white box on the right represents a preview of the page and margins.  ` (18); ` Selecting *Ok* will save the settings and apply them when the user selects *Print*. *Cancel* closes the print setup window.` (19). |
| 20–22 | Figure 1 — 빈 줄, 그림 참조 및 페이지·프린터 설정 창 캡션을 포함한다(20–22). 21행 그림의 로컬 사본을 열었다. 그림은 `Page & Printer Setup` 창을 보여 준다. 화면에는 `HP LaserJet Professional P1606dn`, `Letter, 8 1/2 x 11 in.`, 선택된 `Portrait`, `Landscape`, `Show Printers`, `Top: 1`, `Left: 1`, `Right: 1`, `Bottom: 1`, `All margins are expressed in inches.`, `Printable Area`의 `Height: 9`와 `Width: 6.5`, 선택된 `Frame`과 `Border`, 페이지 미리보기 및 `Cancel`·`OK` 버튼이 보인다. 화면의 선택값을 별도 기본값으로 해석하지 않았다. |
