# Toggle_Pan.md — 판독 구간 기록

구간은 1행부터 10행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터(metadata) — 페이지 ID(2), 제목(3), space(4), 원문 URL(5), 버전(6), 갱신 시각(7), 문서 계층 경로(8)를 기록한다. `---` 구분자를 포함한다(1·9). |
| 10–10 | Toggle Pan — 작업공간(workspace)을 클릭하고 끌어서 표시 위치를 이동한다(10). 도구막대(toolbar) 아이콘 또는 `SPACEBAR`로 활성화한다(10). 10행 그림의 로컬 사본을 열었다. 그림은 위·아래·왼쪽·오른쪽으로 향하는 네 화살표가 있는 이동 아이콘을 보여 준다. |
