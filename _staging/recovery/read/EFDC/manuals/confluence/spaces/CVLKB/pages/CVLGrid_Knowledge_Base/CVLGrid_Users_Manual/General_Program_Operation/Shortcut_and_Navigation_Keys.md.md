# Shortcut_and_Navigation_Keys.md — 판독 구간 기록

구간은 1행부터 30행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목 `Shortcut and Navigation Keys`, space `CVLKB`, 원문 URL, 버전과 갱신 시각을 담는다(2–8). |
| 10–25 | 탐색·바로가기 표 — F2로 전체 목록을 연다(10). `Scroll Wheel`은 활성 작업공간에서 위로 확대·아래로 축소한다(14). `RMC`는 사각형을 끌어 해당 영역을 확대한다(15). `Ctrl + E`는 전체 보기, `Ctrl + R`은 직전 CVLGrid 작업 반복이다(16–17). 셀 이동 입력 원문: `Go to a user specified cell by entering the L or I, J coordinates.` (18). `Alt + W`는 수평 축척 수 입력창을 연다(19). `Arrow Keys`는 작업공간을 이동하고, `- Key`는 축소, `+ Key`는 확대, `Esc`는 현재 선택 작업을 종료한다(20–23). `Space bar + LMC`는 작업공간을 이동한다(24). |
| 26–28 | Shortcut Keys 화면 — 그림 1을 열었다(26–27). GENERAL OPERATION에는 `F1 - Display user manual`, `F2 - Display a list of shortcut keys`, `F5 - Refresh view`, `Arrow Keys - Pan through the workspace and move to view different parts of the grid`, `- Key - Zoom out`, `+ Key - Zoom in`, `RMC - Right mouse clicking (RMC) and dragging to zoom in on the area encompassed by the rectangle`, `Scroll - Mouse scrolling up to zoom in and scrolling down to zoom out`, `Spacebar - End current selected operation`, `Alt + W - Zoom to a Fixed Scale`, `Ctrl + E - Zoom to extents`, `Ctrl + V - View a Specified Cell Using either L or IJ`, `Ctrl + R - Repeat last operation`, `Ctrl + Z - Undo last operation`, `Ctrl + Y - Redo last undo-operation`이 있다(모두 26, 그림 문구). EDIT POLYLINE에는 `1 - Move to First Point`, `C - Set Closed Polygon Flag (may add pt)`, `L - Move to Last Point`, `N - Move to Next Point`, `O - Set Open Polygon Flag`, `P - Move to Previous Point`, `V - View Points Order`, `DEL - Delete Current Point`, `Alt + C - Crop Data Points in Polygon`, `Alt + L - Clean Polylines (e.g. 0,0)`, `Ctrl + B - Break Polyline (select 2nd point)`, `Ctrl + C - Copy (and Transform) Selected Polylines`, `Ctrl + F - Set the Point Spacing`, `Ctrl + J - Join Selected Polylines`, `Ctrl + M - Mirror Polyline about X`, `Ctrl + N - Mirror Polyline about Y`, `Ctrl + O - Apply an Offset`, `Ctrl + P - Reverse Order of Points`, `Ctrl + S - Smooth the Polylines`, `Ctrl + T - Rotate Selected Polylines`이 있다(모두 26, 그림 문구). |
| 29–30 | CVLGrid Viewing Options 화면 — 그림 2를 열었다(29–30). 입력 이름·단위는 `Enter the horizontal scale (Kilometers):`, 표시값은 `5`이다(29). 본문은 이를 기본값으로 정의하지 않는다. |

- 23·24·26행: 표는 작업 종료 키를 Esc, 작업공간 이동을 Space bar + LMC로 적는다. 그림 1의 작업 종료 항목은 `Spacebar - End current selected operation`이다.
