# Horizontal_Units_Scale.md — 판독 구간 기록

구간은 1행부터 13행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — Confluence 페이지의 식별자, 제목, space, URL, 버전, 갱신 시각, 문서 계층과 frontmatter 경계 표식이다(1–9). |
| 10–13 | Horizontal Units Scale — 모델 영역 크기와 UTM 좌표(UTM coordinates)에 기반한 거리 축척 범례(scale legend)를 작업 공간에 추가할 수 있다(10). 단위와 변환 기준을 원문대로 옮긴다: `The *Horizontal Units Scale* frame provides the user the option of adding a scale legend to the workspace. This legend gives a visual representation of distance and is based on the size of the model domain and its UTM coordinates, shown in [Figure 1](#HorizontalUnitsScale-Figure1). The units of this legend can be changed to show meters, kilometers, feet, miles and nautical miles, however, the different units are simply converted from the base unit, meters.` (10). 선택 단위는 `meters, kilometers, feet, miles and nautical miles`이며 기준 단위는 `meters`이다. Figure 1의 로컬 그림을 직접 열었다(12). 흰색·검정의 거리 막대와 `157 Kilometers` 표기를 보여 준다. 이 수치는 그림 예시이다. 캡션과 빈 줄을 포함한다(11–13). |
