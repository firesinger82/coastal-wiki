When this option is selected a separate window appears, shown in [Figure 1](#LoadProject-Figure1) which allows the user to browse to the project file. The \*.cvp file may also be dragged and dropped onto the workspace to open the project. Note that the \*.cvp extension is a CVLGrid project format whereas \*.cvl extension is the grid format.` (10). |
