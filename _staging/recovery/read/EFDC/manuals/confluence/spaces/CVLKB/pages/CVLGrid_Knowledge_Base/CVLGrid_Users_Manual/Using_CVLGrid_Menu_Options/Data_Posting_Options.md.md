# Data_Posting_Options.md — 판독 구간 기록

구간은 1행부터 13행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — Confluence 페이지의 식별자, 제목, space, URL, 버전, 갱신 시각, 문서 계층과 frontmatter 경계 표식이다(1–9). |
| 10–13 | Data Posting Options — 포스팅(posting) 파일은 특정 구조물·지리적 대상과 위치를 연결하는 좌표 자료를 담는다(10). 여러 대상의 상대적 위치를 작업 공간에서 표시한다. 본문의 버튼 표기는 `*Date Posting Option*`이다(10). Figure 1의 로컬 그림을 직접 열었다(12). P 아이콘의 드롭다운(dropdown)은 `Load Posting File`, `Show`, `Options`, `Clear Posts`를 보여 준다. 캡션과 빈 줄을 포함한다(11–13). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 3·10·13: 제목과 그림 캡션은 `Data`를 사용한다. 10행의 버튼 이름은 `Date Posting Option`으로 적혀 있다.
- 10: 내부 링크 `#DataPostingOptions-Figure1`이 있다. 13행 캡션에는 해당 앵커 정의가 없다.
