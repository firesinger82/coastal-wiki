# Offline_Activation.md — 판독 구간 기록

구간은 1행부터 29행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | Offline Activation / 문서 메타데이터 — 페이지 ID `2818172`, 제목, space, 원문 URL, 버전 `5`, 갱신 시각, 문서 계층을 포함한다(1–9). |
| 10–13 | Offline License / 동글과 드라이버 — 인터넷 연결 없이 쓰는 오프라인 라이선스(Offline License)는 DSI가 제공하는 USB 동글(USB dongle)을 꽂아 실행에 필요한 라이선스 파일을 제공한다(10). 장기 임대와 영구 라이선스(Perpetual License)에 제공할 수 있다(10). 적용 종류 원문: `Users who wish to have a license of CVLGrid without requiring a connection to the internet can do so with an Offline License. DSI will provide the user with a USB dongle which can be plugged into their computer to provide the license file required for operation. Offline licenses can be provided for both long term rentals as well as Perpetual Licenses. The steps for activation using a dongle are described below.` (10). 구형 MS Windows에서는 `Flexnet USB dongle driver` 설치가 필요할 수도 있다(12). 드라이버는 이메일 또는 동글에서 제공되며 동글을 USB 포트에 꽂는다(12). 적용 조건·불확실성 원문: `1. To use dongle, the Flexnet USB dongle driver may need to be installed for older versions of MS Windows. This will have been provided by email or can be found on the USB dongle. Plug the dongle into the USB port.` (12). |
| 14–18 | Offline Activation / 활성화 옵션 — 바탕 화면 또는 Start에서 CVLGrid1.1을 열고 동글 활성화 옵션을 선택한다(14). 옵션 원문: `2. Open CVLGrid1.1 from shortcut on desktop or from the Start button then the Activation Wizard Form will appear as shown in [Offline Activation#Figure 1](#Figure1). The user should select the *Activation using a Dongle* option.` (14). 직접 연 그림 1은 `Activation Wizard`에서 `Activate using a Dongle`이 선택된 상태와 `License File:`, `Browse...`, `Activate CVLGrid`를 보여 준다(16–17). |
| 19–25 | Offline Activation / 라이선스 파일 선택과 실행 — `Browse`로 USB 동글의 라이선스 파일을 찾아 `Open`을 누른다(19). 입력 파일 패턴 원문: `3. Select the Browse button to browse to license file ( \*.lic) in on the USB dongle drive as shown in [Offline Activation#Figure 2](#Figure2) and select *Open*.` (19). 본문의 패턴은 Markdown 이스케이프를 포함한 `\*.lic`이다(19). 직접 연 그림 2는 `Removable Disk (D:)`의 `CVLGrid1.1` 폴더에서 `.lic` 파일을 선택하는 화면이며 필터는 `Lic Files (*.lic)`다(21–22). 파일 내용 형식 예시는 없다(19–22). 다음 단계는 `Activate CVLGrid` 버튼을 누르는 것이다(24). 본문은 이후 열리는 주 창 이름을 `EFDC+ Explorer Main form`으로 적는다(24). |
| 26–29 | Offline Activation / 사용 중 동글 제거 — 동글을 빼면 작업을 저장하고 CVLGrid를 닫거나 동글을 다시 꽂아 계속 사용하는 두 선택지가 있다(26). 적용 조건 원문: `5. If the user unplugs the USB dongle during use of CVLGrid, a warning form will appear as shown in [Offline Activation#Figure 3](#Figure3). The user has two options: to save the current work and close CVLGrid or keep using CVLGrid by reinserting the dongle into the USB port.` (26). 직접 연 그림 3의 경고는 저장 가능 시간을 5분으로 표시한다(28–29). 그림 경고 원문: `The license dongle has been removed. You have 5 minutes to save your work before CVLGrid closes. Reinsert the dongle if you want to keep using CVLGrid.` (28행 참조 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 14·19·26행: `#Figure1`, `#Figure2`, `#Figure3` 내부 참조가 있다. 이 파일에는 해당 ID를 정의하는 명시 앵커가 없다.
- 24행: 이 문서는 CVLGrid 활성화를 설명하지만 활성화 후 열리는 창 이름을 `EFDC+ Explorer Main form`으로 적는다.
