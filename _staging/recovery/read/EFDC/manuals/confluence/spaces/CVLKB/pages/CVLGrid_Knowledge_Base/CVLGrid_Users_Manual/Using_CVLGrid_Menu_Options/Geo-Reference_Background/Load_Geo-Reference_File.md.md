# Load_Geo-Reference_File.md — 판독 구간 기록

구간은 1행부터 16행까지 빈틈없이 이어진다.

그림의 설정값은 화면에 표시된 값으로 기록한다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목은 `Load Geo-Reference File`이다(3). 문서 ID는 `2818231`이다(2). 공간·원문 URL·버전·갱신 시각·탐색 경로를 기재한다(4–8). YAML 구분선은 1·9행이다. |
| 10–11 | Load Geo-Reference File — 드롭다운에서 이 옵션을 선택하면 파일 선택 창이 열린다(10). 사용자는 하드디스크에서 지리 참조(geo-reference) 파일을 찾아 작업영역(workspace)으로 불러올 수 있다(10). 파일 확장자는 `.GEO`이다(10). 원문: `From the dropdown menu, when *Load Geo-Reference File* is selected, a browsing window appears. The user is then able to navigate to the location of the geo-reference file on the hard drive and load it into the workspace. This browsing window is shown in [Figure 1](#LoadGeo-ReferenceFile-Figure1), and a loaded geo-referenced file with grid is shown in [Figure 2](#LoadGeo-ReferenceFile-Figure2). Note that the geo-reference files use the .GEO extension.` (10). |
| 12–14 | Figure 1 — `Load a GeoReference File` 창을 보여 준다(12행 그림). `File name:`의 표시값은 `West Lake.geo`이다. 파일 형식 선택에는 `GeoRef Files`가 표시된다(모두 12행 그림). 그림 링크·캡션·빈 줄을 포함한다(12–14). 직접 연 로컬 그림은 `models/EFDC/raw/manuals/confluence/spaces/CVLKB/attachments/2818231/worddav5e3f7fa7d59fcfa0208a37bad29f8fc0.png`이다(12행 그림). |
| 15–16 | Figure 2 — 호수·강·도시를 포함한 Google 위성영상을 CVLGrid 작업영역에 표시한 화면이다(15행 그림). `Show Grid`는 체크 선택 상태이다(15행 그림). `Legend` 상자에는 범례 항목이 보이지 않는다(15행 그림). 축척 막대 표기는 `.7836 Kilometers`이다(15행 그림). 격자선·좌표축·방향 화살표는 보이지 않는다(15행 그림). 그림 링크와 캡션을 포함한다(15–16). 직접 연 로컬 그림은 `models/EFDC/raw/manuals/confluence/spaces/CVLKB/attachments/2818231/worddavd2897d6e99eee0131bf837addabb3959.png`이다(15행 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행의 `#LoadGeo-ReferenceFile-Figure1`, `#LoadGeo-ReferenceFile-Figure2` 링크 대상에 해당하는 앵커 선언이 이 파일에 없다. 13·16행은 캡션이다.
- 10행은 Figure 2를 격자와 함께 불러온 지리 참조 파일의 예라고 설명한다. 15행 그림에는 위성영상이 보이지만 격자선은 보이지 않는다.
