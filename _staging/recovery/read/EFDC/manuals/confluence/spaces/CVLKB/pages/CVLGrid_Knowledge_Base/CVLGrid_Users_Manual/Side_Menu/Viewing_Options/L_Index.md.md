구간은 1행부터 13행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — Confluence 페이지의 식별자, 제목, space, URL, 버전, 갱신 시각, 문서 계층과 frontmatter 경계 표식이다(1–9). |
| 10–13 | L Index — 격자를 불러온 경우 셀의 인덱스(index) 번호를 볼 수 있다. 조건 원문: `With a grid is loaded, this option allows the user to see the index number of the grid cells as shown in [Figure 1](#LIndex-Figure1).` (10). Figure 1의 로컬 그림을 직접 열었다(12). 곡선형 격자(curvilinear grid)에 셀 번호 `2`부터 `151`까지가 보인다. 아래쪽 첫 행은 왼쪽의 `2`부터 오른쪽의 `16`까지 이어진다. 그 위 행은 `17`부터 `31`까지 이어진다. 범례(legend)는 `Grid2`이다. `i Skip`·`j Skip`의 예시값은 각각 `1`이다. 상태 표시줄에는 `Grid Cells: 150`, `NI,NJ: 15, 10`이 있다(12). 캡션과 빈 줄을 포함한다(11–13). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10: 내부 링크 `#LIndex-Figure1`이 있다. 13행 캡션에는 해당 앵커 정의가 없다.
- 12: 그림의 셀 번호에는 `151`이 표시된다. 같은 그림의 상태 표시줄은 `Grid Cells: 150`을 표시한다. 번호 1은 그림에서 확인되지 않는다.
