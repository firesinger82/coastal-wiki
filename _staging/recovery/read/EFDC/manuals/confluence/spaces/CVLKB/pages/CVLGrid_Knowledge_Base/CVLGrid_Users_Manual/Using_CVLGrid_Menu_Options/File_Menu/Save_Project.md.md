# Save_Project.md — 판독 구간 기록

구간은 1행부터 10행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목은 `Save Project`이다(3). 문서 ID는 `2818180`이다(2). 공간·원문 URL·버전·갱신 시각·탐색 경로를 기재한다(4–8). YAML 구분선은 1·9행이다. |
| 10–10 | Save Project — 전체 프로젝트를 하나의 `.CVP` 파일에 저장한다(10). 프로젝트는 다각형 형상 파일(polygon shape file), 스플라인(spline), 격자(grid)를 포함한다(10). Load Project의 Figure 1과 비슷한 파일 선택 창에서 저장 위치를 지정한다(10). 본문은 Load Project와 File Types 페이지를 참조한다(10). 원문: `*Save Project* allows the user to save the entire project to one .CVP file. This includes the polygon shape file, the splines, and the grid. When the user saves a project a browsing window similar to Figure 1 in [Load Project](/wiki/spaces/CVLKB/pages/2818181/Load+Project) allows the user to specify the desired save location. The project file is saved as a .CVP file, mentioned in [File Types](/wiki/spaces/CVLKB/pages/2818255/File+Types).` (10). |
