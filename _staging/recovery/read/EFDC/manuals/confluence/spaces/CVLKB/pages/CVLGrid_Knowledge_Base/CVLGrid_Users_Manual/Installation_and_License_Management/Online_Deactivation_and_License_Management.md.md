# Online_Deactivation_and_License_Management.md — 판독 구간 기록

구간은 1행부터 23행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | Online Deactivation and License Management / 문서 메타데이터 — 페이지 ID `2818173`, 제목, space, 원문 URL, 버전 `5`, 갱신 시각, 문서 계층을 포함한다(1–9). |
| 10–13 | Online Deactivation / 필요한 상황과 인터넷 조건 — 라이선스 사용권(seat)을 다른 컴퓨터로 옮기거나 하드웨어·운영체제를 크게 바꾸려면 비활성화가 필요하다(10). 비활성화는 사용권을 유지해 나중에 같은 컴퓨터나 다른 컴퓨터에서 재활성화하도록 한다(10). 적용 조건 원문: `Deactivation of CVLGrid is required when the user wishes to move their seat to a different computer, or plan to make some major changes to the hardware or operating system of their computer. Deactivation allows the seat to be retained and then reactivated on the same computer or a different computer later.` (10). 오프라인 라이선스를 쓰는 경우를 제외하고 인터넷 연결이 필요하다(12). 미연결·방화벽 때문에 오류가 나올 수도 있으며 본문은 보안 설정 조정과 재시도, 실패 시 지원 문의를 안내한다(12). 인터넷 조건·불확실성 원문: `As for the activation process, deactivation of CVLGrid requires **connection to the internet unless using the offline license.** If the user is not connected to the internet, or if there is a firewall on the network or installation computer, an error message may be given. In this case, please adjust your internet virus checker or firewall settings and try activating again. If this fails please contact support.` (12). |
| 14–20 | License Manager / 관리 창과 F3 — 주 창 오른쪽 위 DSI 메뉴의 `License Manager`에서 전체 사용권 수, 남은 활성화·비활성화 횟수, 라이선스 이름·코드를 제공한다고 적는다(14). 화면 해상도로 DSI 버튼이 숨으면 `F3`를 사용해 관리 창을 연다(16). 적용 조건 원문: `2. In some cases the user settings for screen resolution can cause the DSI button to be hidden. In this case use the F3 button to display *License Manager* shown in [Figure 1](#OnlineDeactivationandLicenseManagement-Figure1).` (16). 직접 연 그림 1은 `License Management` 탭의 `Total Number of Seats: 20`, `Seats Remaining: 12`, `License Code:`, `More`, 컴퓨터 식별 코드(Identification Code for Current Computer), `Deactivate` 버튼을 보여 준다(18–19). 20과 12는 이 화면의 예시 값이다(18행 참조 그림). |
| 21–22 | Deactivation / 사용권 반환 — 본문은 관리 창 하단 `Deactivation` 버튼, 다음 창 `Next`, 확인 `OK` 순서를 적는다(21). 현재 사용권이 비활성화되면 활성화 가능한 사용권 수가 하나 늘어난다(21). 절차·수량 원문: `3. At the bottom of the *License Manager Form* is the *Deactivation* button. Selecting this button will bring up the *Deactivation* form. Selecting *Next*, and selecting *OK* at the prompt will deactivate your current license seat, and the number of license seats available for activation will increase by one.` (21). |
| 23–23 | License Name / License Code 입력 — DSI는 보통 이메일로 코드를 제공한다고 적는다(23). 본문은 이메일에서 이름·코드를 복사하고 필요 시 먼저 텍스트 편집기(text editor)에 붙여 넣으라고 안내한다(23). 코드를 붙일 때는 왼쪽 첫 입력 칸을 눌러 전체 코드를 붙이면 CVLGrid가 블록으로 나눈다(23). 입력 항목·조건 원문: `DSI usually provides the license code via email. The best way to enter the License Name and License Code is to copy and paste these from the DSI email (sometimes you may need to copy and paste into a text editor first). When pasting the license code, click on the first code field from the left and then paste the entire code. CVLGrid will parse the code into the appropriate blocks.` (23). |
