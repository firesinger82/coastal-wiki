# Spline_Operations.md — 판독 구간 기록

구간은 1행부터 20행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | Spline Operations / 문서 메타데이터 — 페이지 ID `2818102`, 제목, space, 원문 URL, 버전 `4`, 갱신 시각, 문서 계층을 포함한다(1–9). |
| 10–16 | Spline Operations / 활성 레이어와 메뉴 — 스플라인(spline)을 읽거나 생성하면 폴리라인(polyline) 편집 기능을 사용할 수 있다(10). 먼저 `Layer Control`에서 원하는 `Spline` 레이어(layer)를 선택해야 한다(12). 활성 레이어 이름은 굵은 글씨로 표시된다(12). 선 위 커서는 손 모양이 되고 원문의 `LMC`, 이어 `RMC`로 메뉴를 연다(12). 적용 조건·의무 원문: `The user must first select the desired *Spline* layer in *Layer Control*. This makes the layer the active layer and it is displayed with bold font in the *Layer Control*. In the workspace a hand icon should now be displayed instead of an arrow when the user hovers over this spline. The user should select this polyline with LMC. When the user RMCs a function list is displayed as shown in [Figure 1](#SplineOperations-Figure1) and [Figure 2](#SplineOperations-Figure2).` (12). 직접 연 그림 1은 자홍색 선택 스플라인과 검은 사각 절점(node), 편집 메뉴를 보여 준다(14–15). 축척 막대는 `1 Meters`, 상태 표시줄은 `Poly: 1, Pt #: 5`다(14행 참조 그림). |
| 17–19 | Spline Operations / 메뉴 상세 — 직접 연 그림 2는 `Edit Properties`, `Zoom to Selected`, `Add RK/RM Labels to Polyline`, `Remove RK/RM Labels from Polyline`, `Edit RK/RM Options`, `Copy to Another Layer`를 보여 준다(17–18). `Mark Polyline as Closed`, `Mark Polygon as Open`, `Delete Nodes inside Selected Polylines`는 회색으로 표시된다(17행 참조 그림). |
| 20–20 | Spline Operations / 복사 대상 제한 — 활성 기능 대부분은 Overlay 작업과 비슷하지만 복사 대상에 제한이 있다고 적는다(20). 스플라인의 `Copy to Another Layer`는 선택한 스플라인을 스플라인 레이어로 복사하는 경우에만 적용한다(20). 목적지 범위·적용 조건 원문: `Generally, most of enabled functions of *Spline* *Operations* are similar to those for *Overlay Operation* except *Copy to Another Layer.* For spline, this function is only applied to copy the selected spline to a spline layer. The other functions have been introduced in [Overlay Operations](/wiki/spaces/CVLKB/pages/2818168/Overlay+Operations).` (20). 나머지 기능은 `Overlay Operations` 하위 페이지를 참조한다(20). |
