# None.md — 판독 구간 기록

구간은 1행부터 13행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — Confluence 페이지의 식별자, 제목, space, URL, 버전, 갱신 시각, 문서 계층과 frontmatter 경계 표식이다(1–9). |
| 10–13 | None — 적용 조건 원문: `When the option *None* is chosen then only the grid is displayed in the workspace. This is shown in [Figure 1](#None-Figure1).` (10). `None`을 선택하면 작업 공간에는 격자만 표시한다고 적는다. Figure 1의 로컬 그림을 직접 열었다(12). 파란 곡선형 격자(curvilinear grid) 선과 `Grid2` 범례(legend)를 보여 준다. 셀 인덱스(index) 숫자나 셀 색상 채움은 없다. 옆 패널에서 `None`이 선택되어 있다. 상태 표시줄에는 `Grid Cells: 150`, `NI,NJ: 15, 10`이 있다(12). 캡션과 빈 줄을 포함한다(11–13). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10: 내부 링크 `#None-Figure1`이 있다. 13행 캡션에는 해당 앵커 정의가 없다.
