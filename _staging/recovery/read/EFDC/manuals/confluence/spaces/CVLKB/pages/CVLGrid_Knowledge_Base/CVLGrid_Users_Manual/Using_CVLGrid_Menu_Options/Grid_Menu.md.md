| 36–36 | Table 1 / 노드·셀 삭제와 비활성화 — `Delete a Grid Node`는 손 모양 아이콘(hand icon)으로 선택한 셀의 노드를 즉시 삭제한다(36). 다각형(polygon) 내부 삭제는 `LMC`로 다각형을 만들고 `RMC`로 닫는다(36). 블록(block) 내부 삭제는 모서리를 나타내는 노드 2개를 선택한다(36). 두 번째 노드를 클릭하면 블록 영역의 모든 셀을 삭제한다(36). 블록 외부 삭제는 모서리 노드 4개를 선택한다(36). 네 번째 노드를 클릭하면 선택 블록 바깥의 모든 셀을 삭제한다(36). `Deactivate Line of Cells`는 `LMC`로 여러 셀을 가로지르는 선을 그린 뒤 `RMC`로 끝낸다(36). 선을 따라 있는 여러 셀은 비활성화된다(36). 모든 선택 조건과 수량을 원문 그대로 옮긴다(36). 원문: `This button allows the user to delete one or multiple cells within the generated grid. There are a number of options in the drop down menu as shown in [Figure 4](#GridMenu-Figure4).  *Delete a Grid Node* will immediately delete the node of a cell selected by the hand icon.  *Delete Nodes Inside a Polygon* allows the user to create a polygon with LMC. Closing the polygon with a RMC will delete multiple cells inside the polygon.  *Delete Nodes Inside a Block* is used by clicking two nodes to indicate the corners of the grid block that you want to delete. A block is selected which just contains the selected nodes. Clicking the second node will delete all cells of the block area.  *Delete Nodes Outside a Block* is used by clicking four nodes to indicate the corners of the grid block. A block is selected which just contains the selected nodes. Clicking the fourth node will delete all cells in the area outside the selected block.  *Deactivate Line of Cells*: Instead of deactivating cell by cell on the grid, select this function then draw a line by LMC in order to intersect multiple cells. RMC to end the line and multiple cells along that line will be deactivated.` (36). |
| 37–41 | Table 1 / 이동·전체 삭제·격자 선택·작업 이동 — 노드 이동은 원하는 노드에서 `LMC`를 사용하고 새 위치에서 다시 `LMC`를 사용한다(37). 그 노드에 연결된 선도 함께 움직인다(37). 전체 삭제는 아이콘을 누른 뒤 삭제할 격자를 선택한다(38). 선택한 격자에 별도로 연결된 격자도 삭제된다고 적는다(38). 연결되지 않은 격자가 여러 개이면 한 번에 하나만 편집할 수 있다(39). 선택 아이콘은 격자를 편집 대상으로 활성화한다(39). `Undo`는 이전 작업으로 돌아간다(40). 마지막 버튼은 다음 작업으로 이동한다(41). 각 표 행을 원문 그대로 옮긴다(37–41). 원문: `This button will move nodes on a grid. To move a node on the grid, LMC on the desired node then LMC on the position it should be moved to. Any line connected to that node will move also.` (37); `Delete the entire grid selected. Simply click this icon and then select the grid to delete. Note: any grid connected separately to the grid selected will also be deleted.` (38); `Select a grid so that it can be edited. If there are several grids in the workspace that are not connected the user will only be able to edit one at a time. This icon selects a grid and makes it active for editing.` (39); `Go back to a previous operation (Undo).` (40); `Go forward to next operation.` (41). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10·15·20·35·36행은 `#GridMenu-Figure1`, `#GridMenu-Figure2`, `#GridMenu-Figure3`, `#GridMenu-Figure4`, `#GridMenu-Table1`을 참조한다. 이 파일에는 해당 앵커 선언이 없다. 13·18·23·26·30행은 그림 또는 표 캡션이다.
- 32–41행 표의 첫 번째 열은 머리글과 본문 8개 행에서 모두 비어 있다. 버튼 이미지나 이름은 그 열에 없다.
- 20행은 노드 삭제 선택지의 그림으로 Figure 3과 Figure 4를 함께 참조한다. 23행 캡션과 22행 그림은 Figure 3을 셀 삽입 선택지로 표시한다.
- 35행 표의 여러 셀 삽입 이름은 `Insert a Multiple Cells`이다. 22행 그림의 이름은 `Insert Multiple Cells`이다.
- 36·37행의 약어 `LMC`와 `RMC`는 이 파일에서 풀어 쓰지 않는다.
