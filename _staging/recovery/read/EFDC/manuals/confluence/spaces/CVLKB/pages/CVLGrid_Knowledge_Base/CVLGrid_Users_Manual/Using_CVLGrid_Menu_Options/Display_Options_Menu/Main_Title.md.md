# Main_Title.md — 판독 구간 기록

구간은 1행부터 16행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — Confluence 페이지의 식별자, 제목, space, URL, 버전, 갱신 시각, 문서 계층과 frontmatter 경계 표식이다(1–9). |
| 10–14 | Main Title / 표시 옵션 — `Display Options`의 첫 프레임(frame)은 `Main Title`이다. 프로젝트 이름을 입력하면 작업 공간에 표시한다. `Format` 버튼은 글꼴·크기·색·위치·각도를 바꿀 수 있다. `Hide Title`은 작업 공간의 제목을 숨긴다고 적는다. 기능 설명 원문: `The first option when you open the *Display Options* menu is the *Main Title* frame (shown in [Figure 1](#MainTitle-Figure1)). Here the user can input the name of the project and it will be displayed in the workspace. The *Format* button next to this frame allows for formatting changes such as font, size, color, position, and angle (shown in [Figure 2](#MainTitle-Figure2)). The *Hide Title* text box will hide the title from the workspace.` (10). Figure 1의 로컬 그림을 직접 열었다(12). 표시 옵션 창에는 비어 있는 제목 입력칸과 `Format` 버튼, 체크되지 않은 `Hide Title` 체크박스가 있다. 나머지 프레임은 수평 단위 축척(horizontal units scale), 색(color), DTM 색상 램프(color ramp)이다(12). 캡션과 빈 줄을 포함한다(11–14). |
| 15–16 | Main title display formatting / Figure 2 — 로컬 그림을 직접 열었다(15). 창 제목은 `Text Display & Formatting Options`이다. 입력 텍스트는 `Title`이다. `Font` 표시값은 `12 pt`, `Arial`이다. `ForeColor` 버튼이 있다. `Angle`의 예시값은 `0`이다. `Use Background`는 체크되지 않았다. 배경 `Color` 버튼은 비활성으로 보인다. `Text/Label Alignment`의 선택지는 `Top Left`, `Top Center`, `Top Right`, `Center Left`, `Center Center`, `Center Right`, `Bottom Left`, `Bottom Center`, `Bottom Right`이다. `Top Center`가 선택되어 있다(15). 캡션을 포함한다(16). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10: 내부 링크 `#MainTitle-Figure1`, `#MainTitle-Figure2`가 있다. 13·16행의 캡션에는 대응하는 앵커 정의가 없다.
- 10·12: 본문은 `Hide Title`을 `text box`라고 적는다. 12행의 그림에서는 `Hide Title`이 체크박스로 보인다.
