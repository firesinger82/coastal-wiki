| 10–19 | Overlay Operations / 활성 레이어와 메뉴 — 중첩 자료(Overlay)를 읽거나 생성하면 폴리라인(polyline)을 편집할 수 있다(10). `Layer Control`에서 원하는 Overlay 레이어(layer)를 선택하면 굵은 글씨로 활성 상태를 표시한다(11). 선 위 커서는 손 모양이 되고 원문의 `LMC`, 이어 `RMC` 조작으로 메뉴를 연다(11). 적용 조건·조작 원문: `To access the operation the user should select the desired overlay layer in *Layer Control*. This makes this layer to be an active layer which may be seen from the bold font in the *Layer Control* space. In the workspace a hand icon should now be displayed instead of an arrow when the user hovers over this overlay line. The user should select this polyline with LMC. Now when the user RMCs a function list is displayed as shown in [Figure 1](#OverlayOperations-Figure1) and [Figure 2](#OverlayOperations-Figure2).` (11). 직접 연 그림 1은 녹색 스플라인(spline), 자홍색 선택 폴리라인, 검은 사각 절점(node), 굵은 `Overlay` 레이어 이름과 편집 메뉴를 보여 준다(13–14). 그림 2는 같은 메뉴를 확대하며 `Mark Polygon as Open`, `Delete Nodes inside Selected Polylines`가 회색으로 표시된다(16–18). |
| 20–27 | Overlay Operations / 기본 편집 옵션 — 표 안내, 빈 줄, 두 열의 빈 제목 행과 구분선을 포함한다(20–23). 속성 편집(Edit Properties), 선택선 전체 보기(Zoom to Selected), 폴리라인 닫기·열기를 설명한다(24–27). 옵션 이름·조건 표 행 원문: `\| *Edit Properties* \| Display the information from the current polygon/polylines selected and allow the user to edit their properties as shown in [Figure 5](#OverlayOperations-Figure5). \|` (24). `\| *Zoom to Selected* \| View the selected polyline entirely within the workspace. \|` (25). `\| *Mark Polyline as Closed* \| Make the polyline become a polygon. \|` (26). `\| *Mark Polyline as Open* \| Make the polygon become a polyline. \|` (27). |
| 28–35 | Overlay Operations / 거리 라벨·복사·격자 옵션 — 하천 킬로미터·마일(River Kilometer/River Mile, RK/RM) 라벨의 시작 거리와 간격을 설정하고 라벨 제거·설정 변경을 제공한다(28–30). 이름 변경, 다른 레이어로 복사, 선택선 내부 격자 절점 삭제, 원래 격자를 두 격자로 분할하는 옵션도 적는다(31–34). 옵션 이름·매개변수·조건 표 행 원문: `\| *Add RK/RM Labels to Polyline* \| Add labels of River Kilometer/River Mile (RK/RM) on polyline. Set distance to start labeling and distance between labels as shown in [Figure 3](#OverlayOperations-Figure3) \|` (28). `\| *Remove RK/RM Labels from Polyline* \| Clear the RK/RM labels from the polyline. \|` (29). `\| *Edit RK/RM Options* \| Settings for label and symbol distance as shown in [Figure 4](#OverlayOperations-Figure4) \|` (30). `\| *Rename* \| Define another name for the selected polygon/polyline. \|` (31). `\| *Copy to Another Layer* \| Copy the selected polygon/polyline to another available layer in *Layer Control*. \|` (32). `\| *Delete Nodes inside Selected Polylines* \| Delete grid nodes inside the selected polygon/polyline. \|` (33). `\| *Split Grid inside Selected Polylines* \| Split an original grid into two grids, a new grid inside selected polygon/polyline. \|` (34). |
| 36–39 | Polyline Distance Labels / 시작값과 간격 — 직접 연 그림 3은 `Polyline Distance Labels` 창이다(36–38). 입력 안내 원문은 `Enter the Labeling Starting RM and Delta ( 0.0, Meters):`이고 입력 칸의 예시는 `0, 0.5`다(36행 참조 그림). 확인·취소 버튼은 `OK`, `Cancel`이다(36행 참조 그림). 이 값이 기본값이라는 본문 설명은 없다. |
| 40–43 | Label & Symbol Distance Setting / 화면 설정값 — 직접 연 그림 4는 `Number of Polys Labeled: 1`, `Symbol`, `Font`, `Reset Labels`를 표시한다(40–42행 참조 그림). `Show Distance Labels`는 선택되고 `Reverse Order of Labels`는 미선택이다(40행 참조 그림). `Section Labeling Options`의 목록 칸은 비어 있다(40행 참조 그림). 수치 항목은 `Starting RK: 0`, `Delta (m): 1`이다(40행 참조 그림). `Units` 선택지는 `Kilometers`, `Meters`, `Miles`, `Feet`이며 `Meters`가 선택되어 있다(40행 참조 그림). 이들은 표시 예시이며 기본값·허용 수치 범위는 본문에 없다. |
| 44–46 | Polygon/Polyline Information / 속성·통계 — 직접 연 그림 5의 선택 번호는 `Polygon/Polyline: 1`, `ID:`는 빈 칸, `Layer:`는 `Overlay`, `Defined:`는 `1`, `Description:`은 빈 칸, `Closed`는 미선택이다(44–46행 참조 그림). `Stats`의 원문 이름·표시값은 `# Pts: 4`, `Length: 7.1`, `Area: NA`다(44행 참조 그림). 이 통계 화면에는 길이·면적의 단위가 표시되지 않는다(44행 참조 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 11·24·28·30행: `#OverlayOperations-Figure1`부터 `#OverlayOperations-Figure5`까지의 내부 참조가 있다. 이 파일에는 해당 ID를 정의하는 명시 앵커가 없다.
- 11행: `LMC`, `RMC`를 사용하지만 이 파일에는 두 약어의 풀이가 없다.
- 16·27행: 표의 옵션 이름은 `Mark Polyline as Open`이다. 참조 그림 2의 메뉴 이름은 `Mark Polygon as Open`이다.
- 36·40행 참조 그림: 시작값의 이름은 그림 3에서 `Starting RM`, 그림 4에서 `Starting RK`다.
