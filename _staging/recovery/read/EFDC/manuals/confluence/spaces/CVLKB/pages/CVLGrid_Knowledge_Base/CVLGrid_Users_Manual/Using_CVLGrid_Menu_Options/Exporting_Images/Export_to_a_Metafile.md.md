# Export_to_a_Metafile.md — 판독 구간 기록

그림의 설정값은 화면에 표시된 값으로 기록한다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목은 `Export to a Metafile`이다(3). 문서 ID는 `2818203`이다(2). 공간·원문 URL·버전·갱신 시각·탐색 경로를 기재한다(4–8). YAML 구분선은 1·9행이다. |
| 10–11 | Export to a Metafile — 주 도구모음(main toolbar)의 `Export Images`에서 `Export to Metafile`을 선택하면 이름과 저장 위치를 지정하는 창이 열린다(10). 출력 확장자는 `EMF`이다(10). DSI의 Picture Viewer 등을 포함한 여러 그래픽 도구에서 파일을 열 수 있다(10). 파일은 CVLGrid 작업영역(workspace)에 표시된 내용을 보여 준다(10). 원문: `To export a metafile the user can select *Export to Metafile* button from the *Export Images* button in the main toolbar. This option opens a window, shown in [Figure 1](#ExporttoaMetafile-Figure1), that allows the user to name the file and browse to a location on the hard drive. The file exported has an EMF extension that can be opened in various graphic utilities (e.g. DSI's Picture Viewer) and will display whatever is on the CVLGrid workspace.` (10). |
| 12–13 | Figure 1 — `Export Metafile` 창을 보여 준다(12행 그림). `Export File:` 입력칸은 비어 있다. `Show Border`는 체크 선택 상태이다. `Background`의 `Use`와 `Border`도 체크 선택 상태이다(모두 12행 그림). `Browse`, `Cancel`, `OK` 버튼이 있다(12행 그림). 그림 링크와 캡션을 포함한다(12–13). 직접 연 로컬 그림은 `models/EFDC/raw/manuals/confluence/spaces/CVLKB/attachments/2818203/worddavfd38f40ddd7831393a4e7c5d47190644.png`이다(12행 그림). |
