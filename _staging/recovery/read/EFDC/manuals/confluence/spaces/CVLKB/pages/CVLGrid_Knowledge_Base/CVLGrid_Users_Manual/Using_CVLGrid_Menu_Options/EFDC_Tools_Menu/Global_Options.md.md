# Global_Options.md — 판독 구간 기록

구간은 1행부터 13행까지 빈틈없이 이어진다.

그림의 설정값은 화면에 표시된 값으로 기록한다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목은 `Global Options`이다(3). 문서 ID는 `2818199`이다(2). 공간·원문 URL·버전·갱신 시각·탐색 경로를 기재한다(4–8). YAML 구분선은 1·9행이다. |
| 10–11 | Global Options — 이 옵션은 모델의 조도(roughness), 수면고(water surface elevation), 수층 수(number of water layers)를 설정한다(10). 원문: `This option allows the user set attributes of the model as roughness, water surface elevation, and number of water layers as shown in [Figure 1](#GlobalOptions-Figure1).` (10). |
| 12–13 | Figure 1 — `EFDC Model Options` 설정 창을 보여 준다(12행 그림). `Roughness` 아래 `Channel:`의 표시값은 `0.04`이다. `FloodPlain:`의 표시값은 `0.01`이다. `Water Surface:`의 표시값은 `0`이다. `# of Water Layers:`의 표시값은 `1`이다. 창에는 `Cancel`과 `OK` 버튼이 있다(모두 12행 그림). 그림 링크와 캡션을 포함한다(12–13). 직접 연 로컬 그림은 `models/EFDC/raw/manuals/confluence/spaces/CVLKB/attachments/2818199/worddavfa4f9e27da79c34e1af4563f195bf93c.png`이다(12행 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행의 `#GlobalOptions-Figure1` 링크 대상에 해당하는 앵커 선언이 이 파일에 없다. 13행은 Figure 1 캡션이다.
- 12행 그림의 조도·수면고 입력칸에는 단위가 표시되어 있지 않다. 본문 10행과 그림 12행에는 표시값을 기본값으로 정의하는 문구나 허용 범위가 없다.
