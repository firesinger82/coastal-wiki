# Load_Labels_File.md — 판독 구간 기록

구간은 1행부터 10행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목은 `Load Labels File`이다(3). 문서 ID는 `2818217`이다(2). 공간·원문 URL·버전·갱신 시각·탐색 경로를 기재한다(4–8). YAML 구분선은 1·9행이다. |
| 10–10 | Load Labels File — 파일 선택 창에서 원하는 레이블(label) 파일을 선택하면 작업영역(workspace)에 표시한다(10). 위치 표시 자료(posting file)를 먼저 불러온 경우 같은 좌표를 갖는 레이블은 해당 위치 표시(post) 바로 옆에 나타난다(10). 적용 조건을 원문 그대로 옮긴다(10). 원문: `This option displays a browser window from which the user is able to select the desired labels file. Once the file is selected it is displayed in the workspace. If a posting file was previously loaded, the labels with the same coordinates will show up right next to the posts.` (10). |
