구간은 1행부터 24행까지 빈틈없이 이어진다.

그림의 설정값은 화면에 표시된 값으로 기록한다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목은 `Edit Labels`이다(3). 문서 ID는 `2818226`이다(2). 공간·원문 URL·버전·갱신 시각·탐색 경로를 기재한다(4–8). YAML 구분선은 1·9행이다. |
| 10–15 | Edit Labels / Figure 1 — 작업영역(workspace)에 불러온 여러 레이블(label)을 수정할 수 있다(10). 창 왼쪽의 목록 아래 `Insert`, `Delete` 버튼으로 레이블을 추가하거나 삭제할 수 있다(11). 그림은 `CS08`을 선택한 `Edit Labels` 창이다(13행 그림). `Global View`의 `Labels`와 `Symbols`는 체크 선택 상태이다. `Selected Labels - Label Settings`의 `Alignment`, `Box Settings`, `Font Name`, `Font Size`, `Font Color`, `Angle`은 모두 체크 해제 상태이다. `Selected Labels - Symbols Settings`의 `Symbol`과 `Color`도 체크 해제 상태이다. `Sort by Label`은 체크 해제 상태이다. `Current Label Options`의 텍스트 표시값은 `CS08`이다. `X / Easting:`의 표시값은 `510745`이다. `Y / Northing:`의 표시값은 `2007010`이다. 3×3 배열의 선택 원 가운데 오른쪽 아래 원이 선택되어 있다. `Hide the Label & Symbol`과 `Hide the Label Text`는 모두 체크 해제 상태이다(모두 13행 그림). 그림 링크·캡션·빈 줄을 포함한다(12–15). 원문: `This option allows the user to make changes to multiple labels currently loaded in the workspace. When selected the window in [Figure 1](#EditLabels-Figure1) appears.  ` (10); ` In this window, the list of labels currently in the workspace is displayed in a sub-window on the left. At the bottom of this labels list the user can add or delete labels using the *Insert* and *Delete* buttons.` (11). 직접 연 로컬 그림은 `models/EFDC/raw/manuals/confluence/spaces/CVLKB/attachments/2818226/worddav6b310feacd4d216ff5b0bb46b5fa00b1.png`이다(13행 그림). |
| 16–19 | 하위 프레임(sub frame) 설명 / 표 머리글 — 다음 표가 Edit Labels 창의 하위 프레임을 설명한다고 안내한다(16). 빈 줄과 두 열의 표 머리글·구분선을 포함한다(17–19). |
| 20–24 | 하위 프레임 표 — `Global View`는 레이블과 기호(symbol)를 둘 다, 어느 한쪽만, 또는 아무것도 보이지 않게 선택할 수 있다(20). `Label Setting`은 왼쪽 목록에서 선택한 레이블에만 변경을 적용한다(21). `Symbol Settings`는 왼쪽 목록에서 선택한 레이블의 기호를 변경한다(22). `Sort by Label`은 목록을 알파벳순으로 정렬한다(23). `Current Label Options`는 현재 선택한 레이블의 정보를 보여 주고 그 레이블의 설정을 바꿀 수 있게 한다(24). 표의 각 이름과 설명을 원문 그대로 옮긴다(20–24). 원문: `*Global View*` (20); `The two check boxes select what is visible in the workspace. The user can make both labels and symbols visible or just one or the other, or none.` (20); `*Label Setting*` (21); `This sub frame applies changes only to the label selected from the list on the left.` (21); `*Symbol Settings*` (22); `This sub frame applies changes to the symbol of the label selected from the list on the left.` (22); `*Sort by Label*` (23); `Sorts the list alphabetically.` (23); `*Current Label Options*` (24); `Displays the information from the label currently selected in the list and allows the user to change the settings of that particular label.` (24). |
