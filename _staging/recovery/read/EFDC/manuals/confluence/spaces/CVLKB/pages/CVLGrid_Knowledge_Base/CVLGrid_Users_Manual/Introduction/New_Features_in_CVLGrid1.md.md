# New_Features_in_CVLGrid1.md — 판독 구간 기록

구간은 1행부터 21행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | New Features in CVLGrid1.1 / 문서 메타데이터 — 페이지 ID `2818251`, 제목, space, 원문 URL, 버전 `1`, 갱신 시각, 문서 계층을 포함한다(1–9). 파일명은 `New_Features_in_CVLGrid1.md`이며 제목은 CVLGrid1.1이다(3). |
| 10–16 | CVLGrid1.1 / 격자와 레이어 개선 — CVLGrid1.0에서 개선한 기능을 나열한다(10). 직교화(orthogonalization) 방법·사용자 제어 개선, Sorenson 방법과 사용자 정의 계수(user defined coefficients)를 적는다(12). 옵션 원문: `- Improved orthogonalization methodology and improved user controls. New orthogonalization options include use of Sorenson method and user defined coefficients.` (12). 레이어(layer) 제어를 단순화하고 디지털 지형 모형(digital terrain model)을 격자 개발에 활용한다(13–14). 텔레스코핑(Telescoping)은 사용자 정의 거리 가중 계수(distance weighting factor)로 셀 간격을 만든다(15). 매개변수 원문: `- Telescoping: ability to create a distributed space between grid cells based on a user defined distance weighting factor.` (15). 계수의 기본값·범위·단위는 이 파일에 없다. 격자 분할(split grid)은 두 영역을 만들고 새 레이어를 `Layer Control`에 자동 생성한다(16). |
| 17–21 | CVLGrid1.1 / 파일과 폴리라인 편집 — `ECOMSED`, `SEAGRID`, `CH3D` 격자를 읽고 쓴다(17). 선택한 폴리라인(polyline)의 `RMC` 편집에 `RM/RK` 라벨을 추가하는 기능을 적는다(18). 옵션·약어 원문: `- Edit selected polyline by RMC on the polyline: add RM/RK labels,` (18). 폴리라인 편집 단축키(hotkeys), 다른 레이어로 복사, 단순화한 사용자 인터페이스(user-interface)와 Side Menu를 나열한다(19–21). |
