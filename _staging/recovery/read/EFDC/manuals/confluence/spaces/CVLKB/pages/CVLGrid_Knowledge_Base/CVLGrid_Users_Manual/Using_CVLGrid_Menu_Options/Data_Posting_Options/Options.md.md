# Options.md — 판독 구간 기록

구간은 1행부터 19행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — Confluence 페이지의 식별자, 제목, space, URL, 버전, 갱신 시각, 문서 계층과 frontmatter 경계 표식이다(1–9). |
| 10–19 | Data Posting Options / 설정 표 — 작업 공간의 표시 내용을 바꾸는 폼(form)이다. 10행은 `Load Posting File` 문서의 Figure 3을 참조한다. 이 파일에는 직접적인 Markdown 그림 지시문이 없다. 설정 이름과 설명 원문: `*Default Symbol*` — `Allows the user to change the symbol that indicates each structure or feature.` (14); `*Properties*` — `Changes can be made to the type of symbol, color, and fill` (15); `*Clip Viewport*` — `Clips all the data that is outside the current view in the workspace` (16); `*XY Transform*` — `Allows the user to shift or rotate the coordinates of the data loaded` (17); `*Save Points*` — `Saves all the data points currently in the workspace` (18); `*Label Options*` — `Allows the user to change the text that labels each point. The text, font, color, and positioning can all be adjusted from this option` (19). 기본 기호와 기호·색·채움, 현재 화면 밖 자료 제거, 좌표 이동·회전, 현재 작업 공간의 모든 점 저장, 점 라벨의 텍스트·글꼴·색·위치를 다룬다(14–19). 표 머리글·구분선과 빈 줄을 포함한다(11–13). |
