If the I, J map has not been altered then the grid can be loaded straight back into EE without needing to change the boundary condition assignments. In other cases when a new grid has been generated the user will want to build a new EFDC model with the grid. Use the *Create New* button to create a new directory so as not to save over the original grid as shown in [Figure 2](#SaveEFDC-Figure2).` (10). 직접 연 로컬 그림은 `models/EFDC/raw/manuals/confluence/spaces/CVLKB/attachments/2818200/image2016-7-1_105513.png`이다(12행 그림). 직접 연 로컬 그림은 `models/EFDC/raw/manuals/confluence/spaces/CVLKB/attachments/2818200/worddavce8485a90f8392b77591494da9456728.png`이다(16행 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10·19행의 `#SaveEFDC-Figure1`, `#SaveEFDC-Figure2`, `#SaveEFDC-Figure3` 링크 대상에 해당하는 앵커 선언이 이 파일에 없다. 14·17·22행은 캡션이다.
- 14행 캡션은 `EDFC grid loaded`라고 적는다. 제목과 본문은 `EFDC`를 사용한다(3·10·19행).
- 10행의 약어 `EE`는 이 파일에서 풀어 쓰지 않는다.
