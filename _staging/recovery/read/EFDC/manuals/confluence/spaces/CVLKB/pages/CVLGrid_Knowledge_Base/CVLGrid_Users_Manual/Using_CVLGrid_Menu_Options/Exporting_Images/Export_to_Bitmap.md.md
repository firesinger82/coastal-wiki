# Export_to_Bitmap.md — 판독 구간 기록

구간은 1행부터 13행까지 빈틈없이 이어진다.

그림의 설정값은 화면에 표시된 값으로 기록한다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목은 `Export to Bitmap`이다(3). 문서 ID는 `2818201`이다(2). 공간·원문 URL·버전·갱신 시각·탐색 경로를 기재한다(4–8). YAML 구분선은 1·9행이다. |
| 10–11 | Export to Bitmap — `Export Images` 메뉴의 `Export to Bitmap` 옵션은 작업영역(workspace)의 모든 표시 내용을 비트맵(bitmap) 파일로 내보낸다(10). 저장 가능한 형식은 `JPG`, `BMP`, `PNG`, `GIF`, `TIF`이다(10). 원문: `The user can also export everything on the CVLGrid workspace to a bitmap file by selecting *Export to Bitmap* option from the menu of *Export Images* button as shown in [Figure 1](#ExporttoBitmap-Figure1). There are a variety images formats that can be saved including JPG, BMP, PNG, GIF and TIF.` (10). |
| 12–13 | Figure 1 — `Export Bitmap` 창을 보여 준다(12행 그림). `Filename:`은 빈 칸이다. `Bitmap Resolution(dpi):`의 표시값은 `96`이다. `Size X:`의 표시값은 `1034`이다. `Size Y:`의 표시값은 `626`이다. `Lock aspect ratio`는 체크 선택 상태이다. `Background`의 `Use`도 체크 선택 상태이다. `Image Types`에는 `JPG`, `BMP`, `PNG`, `GIF`, `TIF`가 있으며 `PNG`가 선택되어 있다(모두 12행 그림). `Browse`, `Cancel`, `OK` 버튼을 보여 준다(12행 그림). 그림 링크와 캡션을 포함한다(12–13). 직접 연 로컬 그림은 `models/EFDC/raw/manuals/confluence/spaces/CVLKB/attachments/2818201/worddavc8256026802a55cb90ae6dff1359ba67.png`이다(12행 그림). |
