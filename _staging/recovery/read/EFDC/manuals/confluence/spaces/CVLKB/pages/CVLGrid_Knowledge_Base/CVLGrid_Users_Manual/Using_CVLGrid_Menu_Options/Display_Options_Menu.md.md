# Display_Options_Menu.md — 판독 구간 기록

구간은 1행부터 14행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — Confluence 페이지의 식별자, 제목, space, URL, 버전, 갱신 시각, 문서 계층과 frontmatter 경계 표식이다(1–9). |
| 10–14 | Display Options Menu — 기본 도구 모음(main toolbar)의 아이콘을 클릭하여 `Display Options` 메뉴를 연다(10). 10행의 로컬 아이콘을 직접 열었다. 아이콘은 작은 검은 도형과 노란 표시를 보여 준다. Figure 1의 로컬 그림을 직접 열었다(12). `CVLGrid Display Options` 창은 `Main Title`, `Format`, `Hide Title`, `Horizontal Units Scale`, `Color`, `Show Legend`, `DTM Color Ramp` 설정을 보여 준다. `Horizontal Units Scale`에는 `Show`, 단위 `Kilometers`, `Use Lat/Long`이 있다. 색상 항목은 `Background`, `CVLGrid`, `Overlay`, `Spline`이다. 색상 견본은 각각 흰색·파랑·검정·초록이다. DTM 색상 램프(color ramp)의 예시는 `Ramp Label: Elevation (m)`, `Blue: 9E+15`, `Red: -9E+16`, `Cutoff: 0`, `Bottom: -1`이다. 표고 잘라내기 입력칸은 `Low End: 1E+32`, `High End: -1E+32`이다. `Diameter of DTM Point (in): 0.0075`가 표시된다. `Show Color Topo`, `Auto Ramp to Viewport`, `Show Legend`는 체크되어 있다. Lower Range와 Elevation Clipping Options의 `Use`는 체크되지 않았다(12). 메뉴 접근 절차, 빈 줄과 캡션을 포함한다(10–14). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10: 내부 링크 `#DisplayOptionsMenu-Figure1`이 있다. 14행 캡션에는 해당 앵커 정의가 없다.
- 12: `Elevation Clipping Options`의 표시값은 `Low End: 1E+32`, `High End: -1E+32`이다. 낮은 끝값이 높은 끝값보다 크다. 해당 프레임의 `Use`는 체크되지 않았다.
