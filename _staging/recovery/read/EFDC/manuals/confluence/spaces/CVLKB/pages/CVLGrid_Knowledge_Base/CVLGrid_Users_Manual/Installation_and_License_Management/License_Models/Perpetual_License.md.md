However, users will only be able to update their software to the latest version of CVLGrid within a certain time-frame agreed to in the sales arrangement. After that period of time, CVLGrid will still function normally but any bug fixes or new features which are added to CVLGrid after this date will not be accessible to the user. In order to access these updates the user will be required to have a valid maintenance contract with DSI. The *CVLGrid License Manager* will inform the user when this maintenance period is finished as shown in [Figure 1](#PerpetualLicense-Figure1). The user may then contact DSI to have their maintenance period extended if required.` (10). |
