# File_Types.md — 판독 구간 기록

구간은 1행부터 28행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | File Types / 문서 메타데이터 — 페이지 ID `2818255`, 제목, space, 원문 URL, 버전 `1`, 갱신 시각, 문서 계층을 포함한다(1–9). |
| 10–13 | File Types / 표 안내 — CVLGrid가 생성하거나 호환되는 파일을 소개한다(10). 빈 줄, 두 열의 빈 제목 행과 Markdown 표 구분선을 포함한다(11–13). |
| 14–20 | File Types / 다각형·스플라인·격자·프로젝트·그림 파일 — 다각형(polygon) 좌표 파일은 UTM(Universal Transverse Mercator)을 사용한다(14). 스플라인(spline) 좌표 파일, CVLGrid·Delft3D-RGFGRID 격자(grid), 프로젝트(project), 메타파일(metafile), 비트맵(bitmap)을 나열한다(15–20). 파일 이름·설명 표 행 원문: `\| *POLYFILE.P2D* \| Data file of polygon coordinates based on the UTM coordinate system. This file is usually used to display the border of a geographic region (see appendix for file format). \|` (14). `\| *SPLINE.SPL* \| This file contains the user-defined spline coordinates within the CVLGrid workspace (see appendix for file format). \|` (15). `\| *GRID.CVL* \| The grid file that is generated by CVLGrid. These files can be loaded and edited in CVLGrid or imported into EFDC Explorer. \|` (16). `\| *GRID.GRD* \| The grid file that is generated by Delft3D-RGFGRID. These files can be loaded and edited in CVLGrid or imported into EFDC Explorer. \|` (17). `\| *PROJECT.CVP* \| The project file created by CVLGrid. \|` (18). `\| *METAFILE.EMF* \| The metadata file that can be exported by CVLGrid \|` (19). `\| *BITMAP.PNG* \| Bitmap files (*JPG, BMP, GIF, TIF)* can be exported by CVLGrid \|` (20). |
| 21–25 | File Types / 공간 참조·위치·라벨·지도 형식 — 지리 참조(geo-referenced) 이미지, 위치 자료(posting files), 라벨 자료(labels files), KML, shapefile을 나열한다(21–25). Posting 형식과 Labels 형식의 목록을 따로 적는다(22–23). 표 행 원문: `\| *GEOREFERENCE* \| CVLGrid can upload geo-referenced files such as GIS or Google earth images that display the geographic region of the model domain. \|` (21). `\| *POSTING FILES* \| These files contain coordinate data that are linked to specific locations or features. They include P2D, PLT, DXF, DAT, and TXT files. \|` (22). `\| *LABELS FILES* \| These files contain the names of stations or features that are linked to specific coordinates. This allows the user to label the features added by the Posting file. They include P2D, DAT, TXT and GPX files. \|` (23). `\| *KML FILE (.kml)* \| KML is a file format used to display geographic data in an Earth browser such as Google Earth. \|` (24). `\| *SHAPEFILE (.shp)* \| The shapefile is spatial data format and are created directly by lists of the tools available in Environmental Systems Research Institute, Inc. (ESRI), software. \|` (25). |
| 26–28 | File Types / 경계·지형 자료 — 육지 경계(land boundary)는 서로 다른 경계 조각 둘의 X·Y 좌표를 두 블록으로 담으며 Delft3D-RGFGRID 입력이다(26). `.dat` DTM은 X·Y 좌표와 지형 고도(terrain elevation) Z 값을 세 블록으로 담는다고 적는다(27). `.tb2`는 Digital Terrain Model Tool이 생성하는 고도 자료다(28). 파일 형식·블록 수 원문: `\| *LAND BOUNDARY (.ldb)* \| The land boundary file contains two blocks with X and Y co-ordinates of two separate pieces of a land boundary. It is user input for Delft3D-RGFGRID. \|` (26). `\| *DTM FILE (.dat)* \| The file contains three blocks with X, Y co-ordinates and Z value for terrain elevation. \|` (27). `\| *DTM FILE (.tb2)* \| The file is created by the Digital Terrain Model Tool (DTM\_Tool), contains terrain elevation data. \|` (28). 실제 파일 내용의 예시 줄은 이 파일에 없다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 14–15행: 두 파일 형식 설명은 `see appendix for file format`이라고 적지만 부록 제목이나 링크가 없다.
- 20행: 이름 열은 `BITMAP.PNG`이고 설명의 괄호 안 형식 목록은 `JPG, BMP, GIF, TIF`다.
