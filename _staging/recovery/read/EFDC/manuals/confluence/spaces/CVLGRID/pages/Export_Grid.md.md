# Export_Grid.md — 판독 구간 기록

구간은 1행부터 34행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–10 | Export Grid / 도입 — 페이지 식별 정보와 판본을 포함한다(1–9). 생성한 격자를 도구모음 또는 RMC 메뉴로 내보낼 수 있다고 설명한다(10). |
| 11–18 | (1) Export grid from main toolbar button — 격자 레이어를 LMC로 선택한 뒤 도구모음의 내보내기를 사용한다(14–15). 형식과 지원 프로그램 표기는 원문대로 옮긴다. 원문: `1. LMC on the grid layer to select` (14); `2. Click on *Export to file* button on the main toolbar and the grid can be exported to three different file types: CVL Grid, RGF Grid and EFDC Grid as shown in [Figure 1](#ExportGrid-Figure1).` (15); `The CVLgrid file (\*.cvl) is the native file of the CVLGrid tool. GRF Grid file can be opened by Delft3D software, EFDC Grid can be opened by EFDC\_Explorer.` (17). |
| 19–34 | (2) Export grid from RMC option — 격자 레이어를 선택해 우클릭한 뒤 이름과 격자 유형을 골라 저장한다(21–22). 원문: `1. LMC on the grid layer to select` (21); `2. RMC on that grid layer, then select *Export to...* option as shown in [Figure 2](#ExportGrid-Figure2). The *Save As* form will be displayed. Enter a name for the grid and select grid type then click *Save* button as shown in [Figure 3](#ExportGrid-Figure3).` (22). 그림 1은 `Export CVL Grid`, `Export RGF Grid`, `Export EFDC Grid` 메뉴와 빨간 곡선형 격자(curvilinear grid)를 보여 준다(24). 그림 2는 같은 격자의 `Export To...` 메뉴를 보여 준다(28). 그림 3의 입력 예시는 `File name: Grid01`, `Save as type: CVLGrid (*.cvl)`이다(32). 이 화면의 예시를 기본값으로 보지는 않았다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 15·17·24행: 도구모음 설명과 그림 1은 `RGF Grid`로 적지만 지원 프로그램 설명은 `GRF Grid`로 적는다.
