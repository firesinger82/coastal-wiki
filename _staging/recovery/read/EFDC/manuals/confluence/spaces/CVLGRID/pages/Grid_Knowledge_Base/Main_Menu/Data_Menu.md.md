| 16–27 | Simple Interpolation of Grid Bathymetry / 횡단면(cross-section) 파일 — `XS.ldb` 예제의 이름·점 수·열 수·좌표·고도를 설명한다(18–22). 형식 원문: `- The first row is the name of the cross-section.` (20); `- The second row contains the number of data points (e.g 11), and the number of columns (e.g 3) for each data point. This includes coordinates (X, Y) and Z (elevation)` (21); `- Data points start from the third row to end.` (22). 그림 2를 열었다(24–26). 빨간 화살표는 이름과 자료점 수·열 수를 가리킨다. 그림의 파일 예제는 다음과 같다(모두 24행 그림 내부 행 번호): `XS01` (1); `11 3` (2); `570280.928 1125072.249 0` (3); `570214.048 1125008.509 -3` (4); `570122.193 1124923.641 -6` (5); `570047.242 1124847.396 -8` (6); `569959.764 1124771.240 -12` (7); `569885.045 1124695.224 -15` (8); `569814.451 1124631.947 -14` (9); `569744.011 1124564.547 -12` (10); `569669.391 1124501.424 -7` (11); `569611.442 1124450.986 -5` (12); `569545.457 1124383.835 0` (13); `XS02` (14); `9 3` (15); `571022.208 1124276.383 0` (16); `570925.072 1124190.936 -3` (17); `570825.178 1124101.372 -6` (18); `570733.007 1124033.207 -8` (19); `570637.088 1123939.691 -12` (20); `570549.720 1123850.595 -10` (21); `570462.239 1123778.549 -8` (22); `570391.527 1123719.296 -5` (23); `570292.222 1123613.714 0` (24); `XS03` (25); `9 3` (26); `571778.164 1123604.106 0` (27); `571660.741 1123494.530 -3` (28); `571543.549 1123389.383 -6` (29); `571430.744 1123292.830 -8` (30); `571314.144 1123171.403 -12` (31); `571210.311 1123058.622 -8` (32); `571123.129 1122979.378 -6` (33); `571040.221 1122904.419 -4` (34); `570941.048 1122800.526 0` (35). |
| 28–47 | 횡단면 가져오기·좌표계(coordinate system) — Import Cross-Sections에서 파일을 열고 적절한 투영(projection)을 선택한 뒤 OK를 누른다(28·38). 그림 3–6을 모두 열었다(30·34·40·44). 그림 3은 가져오기 메뉴, 그림 4는 XS.ldb 선택창을 보여 준다. 그림 5의 표시값은 `Category: UTM, Northern Hemisphere`, `Projection: UTM Zone 48 (102°E – 108°E)`이다(40). 그림 6은 하천을 따라 놓인 주황 곡선 격자와 여러 파란 횡단면을 보여 준다. 화면 격자 크기는 `Dimensions: 141 x 21`이다(44). |
| 48–57 | 횡단면 고도 색상 표시 — Alt+C에서 Specify Elevation을 열고 Z열을 기준으로 Min·Max를 넣는다(48). 예제 지시 원문은 `In this case, enter 0, -15`이다(48). 그림 7·8을 열었다(50·54). 그림 7은 `Enter Elevation Range (m):`, `(Enter 0, 0 to reset)`, 입력 `-15.000, 0.000`을 보여 준다(50). 그림 8은 횡단면을 고도별 여러 색으로 표시한다(54). |
| 58–88 | 격자 수심 보간 — 횡단면을 덮는 격자가 있을 때 Grid Bathymetry Interpolation을 사용한다(58–60). 설정 원문: `- *Grid Layer*: is the name of the selected grid layer for which we will interpolate the bathymetry.` (62); `- *Using Visible Data*: is the number of data points. In this case, there are 2234 points in the cross-section file.` (63); `- *Interpolation Options*: There are two options, including *Update Missing Only* (update elevation values for the missing grid nodes only, in case other nodes already have elevation values) and *Overwrite All Data* (create new elevation values for all grid nodes and overwrite the nodes that have existing elevation values).` (64); `- *Interpolation Method*: Inverse Distance Weighting (IDW) is used. The *IDW Options* frame allows changing of the interpolation properties.` (65). 역거리 가중법(Inverse Distance Weighting, IDW)의 설정을 바꿀 수 있다. Interpolate 후 OK를 누르고 Bottom Elevation을 표시한다(67–69). 위치에 관한 원문은 `The bottom elevation values for the grid are for grid nodes, not for the centroid of grid cells.`이다(75). 그림 9–11을 열었다(77·81·85). 그림 9는 보간 메뉴를 보여 준다. 그림 10의 표시값은 `Grid Layer: Grid 002`, `Using Visible Data: 74 data points in 1 data layers`, 선택 `Update Missing Only`, `Inverse Distance Weighting (IDW)`, `Number of Quad Points: 8`, `Number of Neighbours: 3`, `Power: 3`, `Maximum Distance (m): 100`, 미선택 `Using Data Zonalization`이다(81, 기본값 여부 본문 명시 없음). 그림 11의 파랑에서 빨강으로 변하는 범례는 `Bottom Elevation (m)`, `-14.81`, `-11.11`, `-7.40`, `-3.70`, `0.00`이다(85). |
| 89–110 | 다각형(polygon)을 이용한 대체 보간 — 격자를 덮는 다각형을 그린 다음 S 또는 Select Object로 선택 모드에 들어간다(89–91). 오버레이 레이어를 선택하고 다각형에 왼쪽 마우스 클릭(LMC) 후 RMC하여 Interpolate Grid Elevations를 실행한다(91). 완료 후 Bottom Elevation을 표시한다(93). 그림 12–15를 열었다(95·99·103·107). 그림 12는 파란 다각형이 전체 격자를 둘러싸며 위쪽 빨간 화살표가 선 추가 버튼을 가리킨다(95). 그림 13은 빨간 선택 다각형과 보간 메뉴를 보여 준다(99). 그림 14의 완료창은 `301 nodes in 1 grid(s)`, `0 scatter points in 0 layer(s)`, `17 data points in 17 cross-sections`라고 표시한다(103). 그림 15는 백색 배경에서 전체 곡선 격자의 고도 색상을 보여 주며, `Bottom Elevation (m)` 범례 값은 `-14.89`, `-11.17`, `-7.45`, `-3.72`, `0.00`이다(107). |
| 111–140 | Other Interpolation Methods / 양 끝 횡단면 주변 보간 — 횡단면이 적고 서로 멀리 떨어진 경우 IDW가 적절하지 않다고 적으며 직교 곡선 격자(orthogonal curvilinear grid)를 사용한다(113). 적용 조건 원문: `Note that the grid should have high resolution (grid cells).` (115). 두 횡단면을 덮는 격자를 만들고 양 끝의 해당 셀부터 보간한다(115–117). 각 횡단면 주변을 다각형으로 감싸서 선택하고 Interpolate Grid Elevations를 실행한다(127). 그림 16–20을 열었다(119·123·129·133·137). 그림 16은 서로 멀리 떨어진 횡단면 두 개, 그림 17은 이를 연결하는 `Dimensions: 141 x 21` 곡선 격자를 보여 준다(119·123). 그림 18의 빨간 화살표는 선 추가 버튼과 한쪽 끝 파란 다각형을 가리킨다(129). 그림 19는 빨간 선택 다각형의 RMC 메뉴를 보여 준다(133). 그림 20의 완료창은 `84 nodes in 1 grid(s)`, `0 scatter points in 0 layer(s)`, `2 data points in 2 cross-sections`라고 표시한다(137). |
| 141–160 | Other Interpolation Methods / I방향 전체 보간 — 두 끝에 기존 고도가 있는 셀을 바탕으로 격자 전체를 보간한다(141–143). 첫 절점을 선택하고 Shift를 누른 채 둘째 절점을 선택하여 블록을 정한다(143). 명령 원문은 `Interpolate Elevations in I Direction`이다(143). 그림 21–24를 열었다(145·149·153·157). 그림 21은 Bottom Elevation 표시 메뉴, 그림 22는 두 끝에만 고도가 채워진 격자를 보여 준다(145·149). 그림 23은 빨간 격자 블록과 `Interpolate Elevation in I-Direction` 메뉴를 보여 준다(153). 그림 24는 두 끝 사이의 고도가 채워진 곡선 격자를 보여 준다(157). 네 그림의 범례는 `Bottom Elevation (m)`, `-14.85`, `-11.15`, `-7.44`, `-3.74`, `-0.03`이다(145·149·153·157). |
| 161–172 | Extrapolation of Bathymetry — 양 끝의 고도 누락 셀을 채우려면 누락 셀과 기존 고도 셀을 함께 덮는 블록을 선택한다(163). 명령 원문은 `Extend Elevations in I Direction`이다(163). 그림 25·26을 열었다(165·169). 그림 25는 선택 모드와 빨간 블록의 `Extend Elevation in I-Direction` 메뉴를 보여 준다(165). 그림 26은 끝단까지 고도가 채워진 격자를 보여 준다(169). 두 그림의 범례는 `Bottom Elevation (m)`, `-14.85`, `-11.15`, `-7.44`, `-3.74`, `-0.03`이다(165·169). |
| 173–184 | Exporting to a Scatter Data File — 격자 레이어 RMC의 Create Scatter Data from Elevation으로 절점 고도를 추출하여 XYZ 산포 자료(scatter data) 레이어를 만든다(175). 본문 이름은 `XYZ from Grid`이며 Export Data Point에서 파일을 저장한다(175). 그림 27·28을 열었다(177·181). 그림 27은 생성 메뉴, 그림 28은 `XYZ from Grid 002` 레이어의 `Export Data Points...`와 저장창을 보여 준다. 저장창에는 `File name: Bottom_Elevation`, `Point Scatter (XYZ) Data (*.xyz, *.p2d, *.txt, *.dat)`가 보인다(181). 두 그림의 범례는 `Bottom Elevation (m)`, `-14.85`, `-11.15`, `-7.44`, `-3.74`, `-0.03`이다(177·181). |
| 185–199 | Download Online Bathymetry — Download Online Data에서 Data Set을 선택한다(187). 문서가 나열하는 자료는 GEBCO 2021·2014·08이다(189–191). 해상도·단위 원문: `providing elevation data, in meters, on a 15 arc-second interval grid.` (189); `a continuous terrain model for ocean and land with a spatial resolution of 30 arc-seconds` (191). 범위·조건 원문: `The *Data Extraction Limits* is auto-set to the whole model domain, but the user can manually select the specific area by checking to *Using Polygon File*and browser to the closed polygon that contains the area inside.` (193). Download로 지정 영역의 자료를 내려받고 적용한다(195). 그림 29를 열었다(197–199). 표시값은 `Data Set: GEBCO 2021`, `Data Field: elevation: Bottom Elevation`이다(197). Spatial Information의 Longitude는 `Min.: -179.998`, `Max.: 179.998`, `Interval: 0.004167`, `#: 86400`이며 Latitude는 `Min.: -89.998`, `Max.: 89.998`, `Interval: 0.004167`, `#: 43200`이다(197). Data Extraction Limits의 Longitude는 `Min.: -86.431679`, `Max.: -86.402306`, Latitude는 `Min.: 33.230610`, `Max.: 33.260571`이다(197). `Time Zone: 0`, 미선택 `Using Polygon File`, 미선택 `Save Log File`도 보인다(197). 이 값들은 그림 표시값이다. |
