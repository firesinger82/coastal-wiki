The density of points in the bottom elevation file will be based on the grid's resolution.`` (16). |
| 18–26 | Generate Grid's Elevation from Cross-section / 보간·내보내기 절차 — 횡단면과 격자 불러오기, 색 범위, 폴리라인으로 셀 선택, 횡단면 위치의 고도 보간(interpolation), 양 끝에서 I 방향 보간, XYZ 레이어 생성, 점 내보내기를 순서대로 설명한다(18–25). 적용 조건·색 범위 이름·좌표 기본 설정·열 순서·고도 단위·UTM 변환 조건을 원문 그대로 보존한다. 원문: ``1. Load the cross-sections file, and after that, generate a grid to cover the cross-section, as shown in [Figure 1](#GenerateGrid'sElevationfromCross-section-Figure1)[.](#GenerateGrid'sElevationfromCross-section-Figure1) To show the color ramp of the cross-section, press Alt+C, then set Min. and Max. values.`` (18); ``2. Draw a polyline to cover grid cells with cross-section by selecting *Add a new polyline* button from the toolbar, as shown in [Figure 2](#GenerateGrid'sElevationfromCross-section-Figure2).`` (19); ``3. Press the S key from the keyboard (selection mode), select the overlay layer in *Layer Control* panel, then click on the polyline, then it will be highlighted, as shown in [Figure 3](#GenerateGrid'sElevationfromCross-section-Figure3). Right-mouse click and select *Interpolate Grid Elevations* as shown in [Figure 3](#GenerateGrid'sElevationfromCross-section-Figure3).`` (20); ``4. Next, select the grid layer in the control panel, Right-mouse click on that layer, then select *Show Properties/Bottom Elevation*, as shown in [Figure 4](#GenerateGrid'sElevationfromCross-section-Figure4).`` (21); ``5. Apply step 3 for grid cells in other cross-sections. We will have cells in two heads of the grid, which have elevation as shown in [Figure 5](#GenerateGrid'sElevationfromCross-section-Figure5).`` (22); ``6. Select entire of the grid by selecting the grid block option, then select *Interpolation Elevation in I-Direction* as shown in [Figure 6](#GenerateGrid'sElevationfromCross-section-Figure6). [Figure 7](#GenerateGrid'sElevationfromCross-section-Figure7) shows the entire grid' elevation color ramp after interpolation.`` (23); ``7. Select the Grid layer and Right-mouse click, then choose *Create Scatter Data from Elevation* as shown in [Figure 8](#GenerateGrid'sElevationfromCross-section-Figure8). As a result, a new layer, "XYZ from Grid" will be created in the layer control. We can turn off the grid layer and see the data points as shown in [Figure 9](#GenerateGrid'sElevationfromCross-section-Figure9)`` (24); ``8. Now we can export the grid's elevation to a data point by selecting "XYZ from Grid" layer and right-mouse click to select *Export Data Points* as shown in [Figure 10](#GenerateGrid'sElevationfromCross-section-Figure10). As a default setting, Grid+ will export to a data file with three columns: the first column is longitude, the second column is latitude, and the last column is elevation value. Note that the unit of the elevation value is the same as the unit of the values in the cross-sections. In case we want to export to a data file in the UTM zone coordinates, we can use the feature *Convert* in Grid+ before exporting.`` (25). |
