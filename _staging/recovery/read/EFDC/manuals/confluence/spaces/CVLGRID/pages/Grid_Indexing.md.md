# Grid_Indexing.md — 판독 구간 기록

구간은 1행부터 32행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–14 | Grid Indexing / 도입·표시 — 페이지 식별 정보를 포함한다(1–9). 각 셀(cell) 또는 절점(node)의 I, J 인덱스(index) 방향을 개별 또는 동시에 바꾸는 기능을 소개한다(10). `Show Labels`와 `Cell IJ Indices` 표시 절차를 설명한다(12). 원문: `To display the I, J labels of the grid, select the grid layer in the *Layer Control* then RMC. Select *Show Labels* (e.g *Cell IJ Indices*) as shown in [Figure 1](#GridIndexing-Figure1).` (12). |
| 15–25 | Grid Indexing / 반전·회전 옵션 — 두 인덱스 동시 반전, I 반전, J 반전, 시계 회전, 반시계 회전을 다음 원문대로 적는다. J 반전 항목의 메뉴 이름도 수정하지 않았다. 원문: `*Transpose I-J Indices*: reverses both the I and J indices of the selected grid at same time.` (16); `*Flip I Indices*: reverses only the I indices of the selected grid.` (18); `*Flip I Indices*: reverses only the J indices of the selected grid.` (20); `*Rotate Indices Clockwise*: orders the indices in a clockwise direction.` (22); `*Rotate Indices Counter-Clockwise*: it is opposite of the *Rotate Indices Clockwise*.` (24). |
| 26–32 | Grid Indexing / 참조 그림 — 그림 1은 `Show Labels`의 `Cell I,J Indices` 선택과 셀 중앙의 인덱스 쌍을 표시한다(26). 그림의 아래 오른쪽은 `1,1`이며 위쪽의 I는 `10`, 왼쪽 아래의 J는 `12`까지 보인다(26). 좌하단에는 `Number of cells: 120`, `Dimensions: 11 × 13`이 보인다(26). 그림 2는 `Transpose I - J Indices`, `Flip I Indices`, `Flip J Indices`, `Rotate Indices Clockwise`, `Rotate Indices Counter-Clockwise` 메뉴를 보여 준다(30). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 18·20·30행: I 반전과 J 반전의 본문 메뉴 이름이 모두 `Flip I Indices`이다. 그림 2의 J 반전 이름은 `Flip J Indices`이다.
