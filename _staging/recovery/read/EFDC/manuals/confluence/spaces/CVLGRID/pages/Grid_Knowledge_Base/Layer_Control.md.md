# Layer_Control.md — 판독 구간 기록

구간은 1행부터 26행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–14 | Layer Control / 패널과 표시 전환 — 페이지 식별 정보·판본·수정 시각을 포함한다(1–9). 레이어 제어(Layer Control) 패널은 기존 레이어의 표시·삭제·속성 설정을 관리한다(10). 상단 화살표 또는 툴바 버튼으로 패널을 표시하거나 숨긴다(12). 패널 경계에서 좌클릭(LMC, Left Mouse Click)을 유지하며 움직여 크기를 바꾼다(12). 각 레이어 전구를 켜거나 꺼 표시를 바꾼다(14). 레이어를 선택하면 하단에 속성이 표시되고 격자 레이어는 노드 차원을 표시한다(14). 조작 조건과 버튼 표기는 그대로 옮긴다. 원문: ``To show/hide the *Layer Control*, the user can click on the arrow (<<) on the top bar of the panel or can click on the *Toggle Layer Control On/Off* button on the main toolbar. The frame size of the panel can be adjusted by moving the cursor to the edge of the panel then holding LMC and moving the cursor.`` (12); ``To turn on/off each layer by clicking on/off the light bulb on each layer. When selecting each layer (LMC on the layer), the attribute of the selected layer will be displayed at the bottom of the panel. For example, for grid layer, it will show the grid node dimensions.`` (14). |
| 15–26 | Layer Control / 우클릭 메뉴·그림 — 선택 레이어에서 우클릭(RMC, Right Mouse Click)하면 추가 옵션을 연다(16). 옵션은 레이어마다 다르며 전체 레이어 표시 전환은 공통 옵션이라고 적는다(18). 원문: ``The options available by RMC on each selected layer is different. However, there are some same options that are the same for all layers such as *Turn All Layer Off,* and *Turn All Layer On*.`` (18). 직접 연 그림(20): 위성 배경 위 하천 곡선 격자와 레이어 목록이다. 빨간 화살표가 패널의 `«` 버튼과 툴바 Toggle 아이콘을 가리킨다. 선택 영역의 `Curvilinear Grid` 및 `Dimensions: 41 × 3`이 보인다. 직접 연 그림(24): `Grid 001`의 RMC 메뉴로 Properties, Show Properties, Show Labels, Zoom to Layer, Grid Indexing, Export To, Remove, 레이어 생성 및 전체 표시 전환을 보여 준다. 그림 캡션과 빈 줄을 포함한다(21–26). |
