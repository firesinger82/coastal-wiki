# Extract_Grid_Nodes.md — 판독 구간 기록

구간은 1행부터 40행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–11 | Extract Grid Nodes / 도입 — 페이지 식별 정보를 포함한다(1–9). 기존 격자의 일부를 다른 격자 레이어로 추출하는 블록·폴리라인 방법을 소개한다(10). |
| 12–25 | Extract grid from selected grid block — 레이어와 선택 도구를 고른 뒤 두 절점을 Shift로 선택한다(14–15). 메뉴 선택으로 새 레이어를 만든다(16). 원문: ``2. From the main toolbar, select the *Select object* button and then select the first grid node. Hold the Shift key and select the second grid node. The grid block will be highlighted as shown [Figure 1](#ExtractGridNodes-Figure1).`` (15); ``3. Next, RMC to display options and then select *Extract Grid Block* option. A new grid layer will be created in the *Layer Control* as shown in [Figure 2](#ExtractGridNodes-Figure2).`` (16). 그림 1은 격자 경계의 파란 선택선과 `Extract Grid Block` 메뉴를 보여 준다(18). 그림 2는 새 `Grid 002` 레이어와 기존 빨간 격자에 겹친 파란 추출 격자를 보여 준다(22). |
| 26–40 | Extract grid with a polygon — 다각형을 새로 그리거나 불러와 격자와 겹치고, 다각형과 격자 레이어를 선택한 뒤 내부를 추출한다(28–32). 원문: ``1. Select the *Add a New Polyline* from the main toolbar to draw a new polygon (or import an existing polygon if available).`` (28); ``2. Start drawing a polygon that overlays a grid in the workspace (LMC to start and RMC to end drawing)`` (29); ``3. From the main toolbar, select the *Select object* button, then click on the polygon. It will be highlighted as shown [Figure 3](#ExtractGridNodes-Figure3).`` (30); ``4. Select the grid layer in the *Layer Control* by LMC on that grid layer`` (31); ``5. RMC on the workspace to show RMC options, then select *Extract Grid Inside the Selected Polygon* option. A new grid layer will be created in the *Layer Control* as [Figure 4](#ExtractGridNodes-Figure4).`` (32). 그림 3은 빨간 다각형과 `Extract Grid Inside the Selected Polygon` 메뉴를 보여 준다(34). 그림 4는 새 `Grid 003` 레이어와 다각형 내부에 남은 청록 격자, 파란 다각형 경계를 보여 준다(38). |
