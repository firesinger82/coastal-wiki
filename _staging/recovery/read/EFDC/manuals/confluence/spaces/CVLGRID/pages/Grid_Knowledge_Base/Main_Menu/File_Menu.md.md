# File_Menu.md — 판독 구간 기록

구간은 1행부터 36행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 제목 `File Menu`, space `CVLGRID`, 원문 URL, 버전과 갱신 시각을 담는다(2–8). |
| 10–15 | File Menu 개요 — 주 도구막대의 File 메뉴에서 프로젝트·입출력 기능을 연다(10). 그림 1을 열었다(12–14). New Project, Open Project, Save Project, Save Project As, Import, Export, Quit Application을 보여 준다. |
| 16–25 | File Menu 기능 표 — `New Project`는 Ctrl+N으로도 실행하며 작업공간의 모든 자료를 지운다(18). `Open Project`는 저장한 프로젝트를 열고 파일을 작업공간으로 끌어 놓을 수도 있다(19). 확장자 구분 원문: `The \*.gpp file may also be dragged and dropped onto the workspace to open the project. Note that the \*.gpp extension is a Grid+, whereas \*.gpc extension is the grid format.` (19). `Save Project`는 다각형 shapefile·스플라인(spline)·격자를 한 파일로 저장한다(20). 원문: `The *Save Project* option will save the entire project to one \*.gpp file.` (20). `Save As Project`는 다른 `.gpp` 파일에 저장한다(21). `Import`는 격자·EFDC 격자·지리 참조 지도·오버레이·스플라인을 가져온다(22). `Export`는 Grid+·RGF·EFDC 격자로 내보낸다고 적는다(23). `Quit Application`은 프로그램을 종료한다(24). |
| 26–36 | File Menu 화면 — 그림 2–4를 모두 열었다(26·30·34). 그림 2는 `Ohio.gpp`, `Grid+ Project (*.gpp)`를 선택한 열기 창을 보여 준다(26). 그림 3은 Import Grid, Import EFDC Grid, Import Georeferenced Image, Import Overlay, Import Splines, Import Labels, Import Cross-Sections, Import DEM, Import Scatter Data 메뉴를 보여 준다(30). 그림 4는 Export Grid, Save to EFDC Model, Export To Shapefile, Export To KML 메뉴를 보여 준다(34). |
