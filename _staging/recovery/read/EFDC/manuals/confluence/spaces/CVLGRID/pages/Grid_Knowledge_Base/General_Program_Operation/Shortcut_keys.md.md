# Shortcut_keys.md — 판독 구간 기록

구간은 1행부터 56행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–11 | Shortcut keys / 도입 — 페이지 식별 정보와 수정 시각을 포함한다(1–9). 격자 생성 조작을 위한 단축키를 소개한다(10). GUI에서 목록을 여는 키는 `F2`이다(10). |
| 12–22 | Table 1. Mouse Action Function — 마우스 동작 여섯 행과 설명을 그대로 옮긴다. Selection Mode 조건을 포함한다. 원문: `\| LMC \| Left Mouse Click to Select/Move/Add/Delete for grids, splines, or overlays \|` (16); `\| RMC \| Right Mouse Click to Show Context Menu \|` (17); `\| Shift+LMC \| Select a grid line or grid block in Selection Mode for grids \|` (18); `\| Shift+RMC \| Move then current view \|` (19); `\| Alt+RMC \| Zoom to a rectangle area \|` (20); `\| Mouse Wheel \| Scroll to zoom in/out \|` (21). |
| 23–42 | Table 2. Keystroke Function / 조회·이동·모드·격자 속성 — 단축키 이름과 각 동작을 행별로 그대로 옮긴다. 원문: `\| F2 \| Show the list of Shortcut Keys and Mouse Actions \|` (27); `\| Down \| Move the current view down \|` (28); `\| Up \| Move the current view up \|` (29); `\| Left \| Move the current view to the left \|` (30); `\| Right \| Move the current view to the right \|` (31); `\| D \| Delete Mode \|` (32); `\| I \| Insert Mode \|` (33); `\| S \| Select Mode \|` (34); `\| M \| Move/Replace Mode \|` (35); `\| N \| Turn Off Grid Properties \|` (36); `\| A \| Show Grid Cell Area \|` (37); `\| O \| Show Grid Orthogonal Deviation \|` (38); `\| R \| Show Grid Aspect Ratio \|` (39); `\| X \| Show Grid Cell DX \|` (40); `\| Y \| Show Grid Cell DY \|` (41); `\| Z \| Show Grid Bottom Elevation \|` (42). |
| 43–56 | Table 2. Keystroke Function / 측정·프로젝트·격자 편집·색·축척 — 조합키와 각 동작을 행별로 그대로 옮긴다. 원문: `\| Ctrl + M \| Measurement Mode \|` (43); `\| Ctrl + N \| New Project \|` (44); `\| Ctrl + O \| Open Project \|` (45); `\| Ctrl + S \| Save Project \|` (46); `\| Ctrl + Alt + S \| Save Project As \|` (47); `\| Ctrl + E \| Zoom to Full Extent \|` (48); `\| Ctrl + G \| Go to Position \|` (49); `\| Ctrl + R \| Refine Grid \|` (50); `\| Ctrl + D \| Coarsen Grid \|` (51); `\| Ctrl + Y \| Redo Action \|` (52); `\| Ctrl + Z \| Undo Action \|` (53); `\| Alt + C \| Set Range for Bottom Elevation Color Ramp \|` (54); `\| Alt + L \| Toggle Grid Lines On/Off \|` (55); `\| Alt + Z \| Set Horizontal Scale \|` (56). |
