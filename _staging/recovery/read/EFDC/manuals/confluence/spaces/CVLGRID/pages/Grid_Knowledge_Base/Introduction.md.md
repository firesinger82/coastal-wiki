# Introduction.md — 판독 구간 기록

구간은 1행부터 73행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–15 | Introduction / 도입 — 페이지 식별 정보·판본·수정 시각을 포함한다(1–9). CSS 규칙 뒤에 DSI가 개발한 격자 생성 도구(grid-building tool) Grid+가 CVLGrid를 대체한다고 적는다(10). 온라인 배경지도(online background map), 개선된 직교화(orthogonalization), 온라인 수심 자료(bathymetry data) 다운로드를 기능으로 소개한다(10). EEMS에 완전히 통합되어 EFDC+ Explorer GUI에서 실행할 수 있다고 적는다(12). |
| 16–26 | Introduction / 주요 특징 — 개선된 사용자 인터페이스(GUI), 객체 기반 선택(object-oriented selection), 위도·경도(Lat/Long) 좌표계, 온라인 배경지도, 스플라인(spline) 기반 격자 생성, 격자 직교화, 온라인 수심 자료 다운로드, EEMS 통합, 여러 격자 속성 표시, 단축키 사용을 열거한다(16–25). 관련 문서 링크와 빈 줄을 포함한다(19–26). |
| 27–38 | Summary of Capabilities / 지원 범위 — 사용성과 효과를 높일 다른 기능 및 개선 가능성을 인정한다(29). 새 기능과 개선은 자원을 사용할 수 있을 때 이루어질 것으로 예상한다고 적는다(29). EFDC+·EFDC 사용에 최적화되었다고 적는다(31). 기존 EFDC 격자 가져오기와 EFDC 형식 내보내기를 지원한다고 적는다(32). I,J 매핑(mapping)을 바꾸지 않고 EFDC 격자를 편집하여 경계조건(boundary condition)을 유지할 수 있다고 적는다(33). 다각형 자료, 폴리라인(polyline), 레이어(layer), 스플라인 편집 및 격자 생성을 열거한다(34–38). 원문: ``The following list provides a summary of the major features of Grid+. It is recognized that there are other capabilities and improvements that can be made to Grid+ to increase the ease of use and effectiveness of the software. It is anticipated that new features and improvements will be made as resources are available.`` (29); ``- Load and edit an EFDC grid without changing the I,J mapping, thereby allowing boundary conditions to be maintained`` (33). |
| 39–53 | Summary of Capabilities / 생성 후 격자 조작 — 격자가 생성된 후 전체 또는 국소 직교성(orthogonality) 개선과 세분화(refine)·성김화(coarsen)를 할 수 있다고 적는다(39–41). 노드(node) 재분배·이동, 한 셀 또는 여러 셀 추가, 삭제, 부분 격자 추출, 인덱스(index) 반전, 노드 고도 지정, 횡단면(cross-section)에서 노드 고도 생성, 고도 산재점(scatter data points) 내보내기, shapefile·Google Earth KML 내보내기, 여러 격자 연결을 열거한다(42–53). 파일 형식 표기는 그대로 옮긴다. 원문: ``  - Export grid node's elevation to scatter data points file (\*.xyz)`` (51); ``  - Export grid to different data types such as shapefile, Google Earth KML`` (52). |
| 54–68 | Summary of Capabilities / 표시·기타 기능 — 직교 편차(orthogonal deviation), 셀 종횡비(cell aspect ratio), 셀 면적, IJ 좌표, 셀 크기를 표시할 수 있다고 적는다(54–59). 셀 색 변경, 모서리 라벨, 셀의 N·S·E·W 표시, 거리 측정, 지리 참조 배경영상(geo-referenced background image), 범례·라벨·제목 변경, 메타파일(metafile) 내보내기, 지리·UTM 좌표계 변환을 열거한다(60–67). 표기는 원문대로 옮긴다. 원문: ``  - Cell aspect ration`` (56); ``  - Cell size (Dx, Dy)`` (59); ``- Convert grid coordinate systems (Geographic and UTM zone)`` (67). |
| 69–73 | Operating System and Hardware Compatibility — 시험하거나 정기적으로 EEMS 실행에 사용하는 운영체제 정보를 별도 문서 링크로 안내한다(71). 이 정보는 최신 EEMS 버전에 관한 정보라고 한정한다(73). 이 파일 자체에는 운영체제 이름이나 하드웨어 최소 사양이 없다. |
