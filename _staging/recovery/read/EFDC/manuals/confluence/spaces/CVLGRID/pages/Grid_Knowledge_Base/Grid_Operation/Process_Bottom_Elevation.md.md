# Process_Bottom_Elevation.md — 판독 구간 기록

구간은 1행부터 88행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–19 | Process Bottom Elevation / Delete Bottom Elevation — 페이지 식별 정보를 포함한다(1–9). 선택 영역 또는 격자선 절점의 저면 고도(bottom elevation)를 지운다(12). 레이블 표시, 같은 선 또는 다른 선 절점 선택, 삭제 후 NaN 표시를 설명한다(14–18). 원문: ``To view the bottom elevation of grid nodes, select the grid layer in the *Layer Control*, then RMC to display options, and select *Show Labels* / *Bottom Elevation* as shown in [Process Bottom Elevation#Process Bottom Elevation#Figure 1](#ProcessBottomElevation-Figure1). The bottom elevation values of nodes is then displayed. The following steps describe how to remove the bottom elevation of selected grid nodes.`` (14); ``2. Set the mouse in the selection mode, hold the Shift key and LMC on two grid nodes either on the same grid line segment or different gridline segments. The grid block will be highlighted.  Next, release Shift, then RMC to show options, and select the *Delete Bottom Elevation*, as shown in [Process Bottom Elevation#Process Bottom Elevation#Figure 2](#ProcessBottomElevation-Figure2). As a result, the bottom elevation of nodes will be removed.`` (17); ``3. To update the view of the bottom elevation of grid nodes after using the *Delete Bottom Elevation*, select show labels for bottom elevation as mentioned in [Process Bottom Elevation#Process Bottom Elevation#Figure 1](#ProcessBottomElevation-Figure1), the grid nodes whose bottom elevation has been removed will display as NaN labels as shown in [Process Bottom Elevation#Process Bottom Elevation#Figure 3](#ProcessBottomElevation-Figure3).`` (18). |
| 20–31 | Delete Bottom Elevation / 그림 — 그림 1은 `Show Labels`·`Bottom Elevation`과 `10.000` 레이블을 보여 준다(20). 그림 2는 파란 선택 블록과 `Delete Bottom Elevation` 메뉴를 보여 준다(24). 그림 3은 같은 선택 구역의 내부에 `NaN`이 있고 바깥에는 `10.000`이 남은 상태를 보여 준다(28). |
| 32–53 | Modify Bottom Elevation — 영향 영역을 선택한 뒤 Modify Selection 창에서 고도를 변경한다(34). 각 라디오 옵션(radio option)의 연산과 평균 정의, 이미 Apply를 누른 경우까지 취소한다는 설명을 그대로 보존한다. 원문: ``The *Modify Bottom Elevation* option is used to change the bottom elevation values of nodes in the defined area. The steps to define the selected gridline or grid bock are similar to the *Delete Bottom Elevation* option described above. After defining the impacted area, RMC to display options, and select the *Modify Bottom Elevation* as shown in [Process Bottom Elevation#Process Bottom Elevation#Figure 4](#ProcessBottomElevation-Figure4). The *Modify Selection* form will display as shown in [Process Bottom Elevation#Process Bottom Elevation#Figure 5](#ProcessBottomElevation-Figure5). The radial options of this form are described below.`` (34); ``*Assign a Constant Value*: Select this option, enter a constant value in the *Value* field then click the *Apply* button will assign that value to all nodes within the grid bock. The value displayed in the *Average* field is the initial averaged value calculated from the nodes within the grid bock.`` (36); ``*Add a Value To*: Select this option, enter a constant value in the *Value* field then click the *Apply* button will add a value to each existing value of nodes within the grid bock.`` (38); ``*Subtract a Value From:* This option is the opposite to the *Add a Value To* option.`` (40); ``*Multiply with a Value*: Select this option, enter a constant value in the *Value* field then clicking the *Apply* button will multiply the bottom elevation value of each node within the grid bock with a value.`` (42); ``*Divide by a Value*: This option is the opposite to the *Multiply with a Value* option.`` (44); ``*Delete Selected Values:* This option will remove the bottom elevation values from the selected nodes. It works like the *Delete Bottom Elevation* option that is described above.`` (46); ``*Apply*: Click this button to proceed with the radial option.`` (48); ``*Close*: Click this button to close the form.`` (50); ``*Cancel*: Click this button to cancel option selection, even clicking the Apply button previously.`` (52). |
| 54–61 | Modify Bottom Elevation / 그림 — 그림 4는 선택 블록의 `Modify Bottom Elevation` 메뉴를 보여 준다(54). 그림 5는 `Assign a Constant Value`가 선택된 Modify Selection 창을 보여 준다(58). 창에는 `Average: 10.000`, `Value: 5`가 보인다(58). 버튼은 `Apply`, `Close`, `Cancel`이며 이 값들이 기본값이라는 본문 설명은 없다(58). |
| 62–73 | Interpolate Bottom Elevation in I- or J-Direction — 서로 다른 기존 고도와 결측(missing value) NaN을 보간하여 채우는 기능을 설명한다(64). I,J 인덱스 사전 표시가 방향 구별을 돕는다고 적는다(64). 원문: ``Sometimes a grid will have nodes that have different values for bottom elevation, and are some nodes are without bottom elevation values (NaN represents missing values) as shown in [Process Bottom Elevation#Process Bottom Elevation#Figure 6](#ProcessBottomElevation-Figure6). This option is used to interpolate and fill the bottom elevation in the I direction of the selected nodes. Displaying the I,J indices in advance helps to define which one is I or J direction.`` (64). 그림 6은 왼쪽 `10.000`, 중간 `6.000`, 오른쪽 `2.000`과 그 사이의 `NaN`을 보여 준다(66). 그림 7은 왼쪽 결측 위치에 `7.976, 7.999, 8.022, 8.042`, 오른쪽 첫 결측 열에 `4.667, 4.672, 4.675, 4.673`, 다음 열에 `3.330, 3.341, 3.349, 3.348`을 보여 준다(70, 각 열 위에서 아래 순서). 두 그림의 범례는 `Bottom Elevation (m)`이며 눈금은 `2.00, 4.00, 6.00, 8.00, 10.00`이다(66·70). |
| 74–77 | Extent Bottom Elevation in I- or J-Direction — 첫 자료점 또는 마지막 자료점을 연장하여 결측을 채운다(76). 격자점 사이의 결측은 보간 기능을 사용하라는 조건을 원문대로 옮긴다. 원문: ``This option extents the first or last data points to fill the missing data. For filling missing data between grid points, please use the *Interpolation Elevation in I-Direction* or in J-Direction.`` (76). |
| 78–88 | Create XYZ Data from Block — 블록을 선택하고 XYZ 레이어를 만들어 절점 좌표와 고도를 점으로 표시하고 외부 파일로 내보낸다(80). 원문: ``After defining a grid block, then RMC display options as shown in [Process Bottom Elevation#Process Bottom Elevation#Figure 8](#ProcessBottomElevation-Figure8), select *Create XYZ Data from block* option to create an XYZ layer in the *Layer Control*. This contains the coordinates and elevation of nodes and displays as points, as shown in [Process Bottom Elevation#Process Bottom Elevation#Figure 9](#ProcessBottomElevation-Figure9). To export this layer to an external file, RMC on the layer then select *Export Data Points* option.`` (80). 그림 8은 `Create XYZ Data from Block` 메뉴와 절점 고도 레이블을 보여 준다(82). 레이블 예시는 오른쪽 외곽의 위에서 아래 순서 `6.400, 6.422, 6.442, 6.461, 6.478, 6.494`이다(82). 그림 9는 `XYZ from Grid 001` 레이어의 색 점들과 `Export Data Points...` 메뉴를 보여 준다(86). |
