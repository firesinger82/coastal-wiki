# Move_grid_nodes.md — 판독 구간 기록

구간은 1행부터 45행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–11 | Move grid nodes / 도입 — 페이지 식별 정보를 포함한다(1–9). 단일 절점(node) 또는 여러 절점 이동을 소개한다(10). |
| 12–23 | Move single grid node — 격자 레이어를 선택한 뒤 손 모양 이동 도구로 절점을 끌어 옮기고 S로 종료한다(14–16). 버튼 이름을 원문대로 보존한다. 원문: ``2. Select the *Mode node*button from the main toolbar, the cursor changes to a hand symbol ([Figure 1](#Movegridnodes-Figure1));`` (15); ``3. Click down on a node, drag it to a new position, and then release the mouse button. To escape this mode, press the S key.`` (16). 단독 마침표와 빈 줄도 포함한다(18–19). 그림은 항공사진 위 빨간 격자와 이동 도구를 가리키는 화살표를 보여 준다(20). |
| 24–38 | Fit to nearest spline — 해안선에서 떨어진 셀을 가장 가까운 스플라인(spline)에 맞추는 기능을 설명한다(26). 새 스플라인과 Shift로 선택한 가장자리 구간, 영향 범위의 세 번째 절점을 사용한다(28–29). 원문: ``1. Select *Add a new spline* to draw a spline;`` (28); ``2. LMC on the selected grid layer, hold the Shift then LMC on two edge grid nodes on the same grid line segment, the segment will be highlighted (its color is purple), LMC on the third grid node to define the impacted area. Next, RMC to show options and then select *Fit to Nearest Spline* option, as shown in [Figure 1](#Movegridnodes-Figure1). As a result, a set of nodes fit the spline as shown in [Figure 2.](#Movegridnodes-Figure2)`` (29). 31행 그림은 격자 가장자리의 자홍 선택선, 내부의 빨간 영향 범위선, 바깥 초록 스플라인과 `Fit to Nearest Spline` 메뉴를 보여 준다(31). 결과 그림은 이동한 가장자리가 초록 스플라인에 맞닿는 상태를 보여 준다(35). |
| 39–45 | Fit to nearest land boundary — 스플라인 대신 폴리라인(polyline)을 그리는 차이를 원문대로 보존한다. 원문: ``This option operates similar to the *Fit to Nearest Spline* option that is described above. The difference is instead of drawing a spline, do draw a polyline. [Figure 3](#Movegridnodes-Figure3) shows the *Fit to Nearest Land Boundary* option.`` (41). 그림 3은 파란 폴리라인, 격자 가장자리의 자홍 선택선, 내부의 빨간 영향 범위선과 `Fit to Nearest Land Boundary` 메뉴를 보여 준다(43). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 15행: 이동 도구의 버튼 이름을 `Mode node`로 적는다.
- 20·22·31·33행: 단일 절점 이동 그림과 스플라인 맞춤 그림의 캡션이 모두 `Figure 1`이다. 29행의 Figure 1 참조 이름도 22행의 참조와 같다.
