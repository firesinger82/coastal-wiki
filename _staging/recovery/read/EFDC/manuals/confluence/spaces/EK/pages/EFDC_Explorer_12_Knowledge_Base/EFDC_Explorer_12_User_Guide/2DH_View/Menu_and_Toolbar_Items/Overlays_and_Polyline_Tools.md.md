# Overlays_and_Polyline_Tools.md — 판독 구간 기록

구간은 1행부터 33행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–19 | 오버레이·폴리라인 도구(Overlays and Polyline Tools) — 오버레이는 모델 영역의 셀 선택에 자주 쓰는 다각형(polygon) 또는 폴리라인(polyline) 파일이며 Overlays 메뉴에서 그리기와 수정을 지원한다(10). 그림 1은 2DH View 주 메뉴의 Overlays 하위 메뉴이며 그림 2는 도구 모음의 동일 도구 메뉴이다(12–18). 두 그림을 직접 열었다. |
| 20–33 | 표 1 / 도구별 동작 — `Draw Polyline`은 각 점에서 LMC하고 RMC로 종료한다(24). `Delete Polyline`은 선 위 LMC로 삭제한다(25). `Insert Point`는 새 점 위치에서 LMC하여 삽입한다(26). `Delete Point`는 점 위 LMC로 제거한다(27). `Move Point`는 점을 LMC하고 끌어 이동한다(28). `Show River Miles`의 거리 표시 원문: `This allows the user to show River Kilometer/River Mile (RK/RM) on polyline. Set distance to start labeling and distance between labels.` (29). `Generate from Selection`은 현재 선택된 셀들로 폴리라인을 만든다(30). `Clear Polylines`는 현재 오버레이 레이어에 속한 모든 폴리라인을 지운다(31). `Open Polylines`는 파일에서 연다(32). `Save Polylines`는 신규 또는 편집된 폴리라인을 향후 Open Polylines로 사용할 수 있게 파일로 저장한다(33). 각 표 행의 Icon 열은 비어 있다(24–33). |
