| 10–19 | MHK 소개와 설정 진입 — 해양 수력 에너지(Marine Hydrokinetic, MHK) 모듈은 하천, 조석 수로, 해류 등의 터빈(turbines)과 파력 변환기(wave energy converters) 설치·운영 영향을 모의한다(10). 구현 근거로 Sandia National Laboratories의 SNL-EFDC와 James(2010)을 연결한다(10). Modules 아래 Marine Hydrokinetic Devices를 오른쪽 클릭하여 설정 폼을 연다(12). 그림 1은 모듈 트리와 장치 유형 수·셀 수 화면이다(14). `MHK Devises Settings` 제목과 빈 줄을 포함한다(18–19). |
| 20–36 | MHK Devices – General Tab — 흐름에서 추출하는 출력을 설정한다(22). 원문: `There are different methods for computing power extracted from flow, though currently only one method is enabled.` (22); `The method is to use the specified thrust coefficient that is multiplied by velocity cubed.` (22); `The available options are local cell velocity and upstream velocity.` (22). 흐름장(flow field)과의 상호작용 계수는 사용자가 지정해야 한다(24). 텍스트 출력 항목은 장치 상·하류 횡단면 에너지 플럭스(energy fluxes), 목 부분 조석 기준 모델의 평균 속도와 Z 프로파일(Z-profile), 기준 모델의 평균·표면 속도, 직선 수로 후류(wake structure) 보정 모델 출력이다(26–31). 그림 2는 General 설정 화면이다(33). 화면의 식 표기는 `v^3` (33행 그림)이다. 화면 계수 값은 기본값으로 단정하지 않고 다음과 같이 옮긴다: `Ratio of Mean Kinetic Energy Transferred Directly to Turbulence (-): 0.8995003` (33행 그림); `Factor of Energy Transfer between Large and Small Scale Turbulence (-): 0.009808416` (33행 그림); `k-ε Production-Dissipation Coefficient for MHK Turbine (-): 5.000193` (33행 그림); `Coefficient of Partial Flow Blockage (-): 2.3` (33행 그림). 사용자 지정 출력 곡선 항목은 `Use a User-defined Power Curve (Not Available)`로 표시된다(33). |
| 37–44 | Device Parameters Tab — 장치 유형 수, 현재 유형, 이름, 치수와 계수를 설정한다(39). 적용 조건 원문: `If the *Use Device Settings* checkbox is checked, the MHK will be displayed in the *3D View* base on their settings.` (39). 그림 3은 Device Parameters 화면이다(41). 표시된 항목·단위·값은 `Number of MHK Device Types: 1` (41행 그림); `Current Device Type: 1` (41행 그림); `Name of MHK Device Type: Device 1` (41행 그림); `Density of MHK Devices/Support Structures (#/Cell): 0.2` (41행 그림); `Width of MHK Turbine (m): 0.8` (41행 그림); `Distance from Top of MHK Turbine to Sediment Bed (m): 1.34` (41행 그림); `Distance from Bottom of MHK Turbine to Sediment Bed (m): 0.54` (41행 그림); `Width of MHK Support (m): 0.1` (41행 그림); `Distance from Top of MHK Support to Sediment Bed (m): 0.54` (41행 그림); `Distance from Bottom of MHK Support to Sediment Bed (m): 0` (41행 그림); `Drag Coefficient of MHK Turbine (-): 0.3295877` (41행 그림); `Drag Coefficient of MHK Support (-): 0.2` (41행 그림); `Velocity at which MHK Turbine Starts to Generate Electricity (m/s): 0` (41행 그림); `Velocity at which MHK Turbine will Generate no Additional Power (m/s): 3` (41행 그림). 이 구간은 해당 화면값을 기본값이나 허용 범위로 정의하지 않는다(39–43). |
| 45–72 | Device Locations — 위치를 I, J 인덱스(index) 또는 Easting, Northing으로 지정하고 Device Parameters에서 정의한 유형 번호를 입력한다(47). Assign은 셀 할당 폼을 연다(49). 원문 옵션은 `*Assign Values to All Grid Cells:*` (51); `*Cell Assignments Using Bounding Polygons in a File*` (53); `*Discrete Cells Assignments Using X, Y Pairs in a File*` (55); `*Discrete Cells Assignments Using I, J Pairs in a File*` (57)이다. 첫 옵션은 모든 셀에, 나머지는 각각 다각형 내부 셀, X·Y 좌표 셀, I·J 인덱스 셀에 유형을 할당한다(51–57). 파일 확장자 원문은 `\*.p2d` (59)이다. 덮어쓰기 조건 원문: `The *Overwrite Current Cell Values* checkbox can be used to overwrite the old assignment. If the checkbox is not checked, the next assignment will append to the old assignment.` (59). Apply 후 성공 메시지를 확인하고 위치 열을 갱신한다(59). 그림 4의 표 헤더는 `I Index; J Index; Easting (m); Northing (m); Device Type` (61행 그림)이다. 표의 6개 행은 `53 16 8.08 2.16 1` (61행 그림); `58 16 8.88 2.16 1` (61행 그림); `65 16 10.00 2.16 1` (61행 그림); `72 16 11.12 2.16 2` (61행 그림); `78 16 12.08 2.16 2` (61행 그림); `85 16 13.20 2.16 2` (61행 그림). 숫자 사이 간격은 열 구분을 공백으로 옮겼다(61). 그림 5는 I·J 파일 할당과 덮어쓰기 선택 화면이고 `Default MHK Device Type` 표시값은 `1`이다(65). 그림 6은 유형 1을 6개 셀에 성공적으로 적용했다는 메시지다(69). |
| 73–84 | Visualization Tab — COLLADA 3차원 객체 파일을 연결하고 Settings에서 크기·회전·색을 설정한다(75). 확장자 원문은 `\*.dae` (75)이다. 색 조건 원문: `Check on the box of *The Change Object Color* it allows changing the color for the object by selecting the color from the *Object Color* option, otherwise the color of the object will use the original color from the COLLADA files.` (75). 그림 7은 터빈과 지지대의 COLLADA 파일 연결 화면이다(77). 그림 8은 3D Object Settings의 좌표·크기·회전·색 설정 화면이다(81). 표시값은 `Position X: 0; Y: 0; Z: 0` (81행 그림); `Scale X: 1; Y: 1; Z: 1` (81행 그림); `Rotation X: 0; Y: 0; Z: 0` (81행 그림)이다. 이 좌표·회전 값의 단위는 그림에 표시하지 않는다(81). |
| 85–100 | MHK Devices in 2DH View — Add New Model Layer에서 Hydrodynamics와 MHK를 선택한다(87). | 101–121 | MHK Devices in 3D View — 3D View Option에서 Hydrodynamics와 MHK를 선택하여 레이어를 추가한다(103–107). 외부 레이어 가져오기로도 COLLADA 장치를 읽을 수 있다(109). 위치 미설정 시 보이지 않는 조건 원문: `The MHK object (e.g turbine) will be added to the Layer Control, however, we can not see the object due to its location is not set yet.` (109).
