# Project_Layout.md — 판독 구간 기록

구간은 1행부터 20행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 페이지 ID, 제목, space, 원문 URL, 버전, 갱신 시각, 문서 계층 경로와 frontmatter 구분선을 포함한다(1–9). |
| 10–15 | Save Project Layout — 불러온 모든 모델과 열린 모든 창의 배치를 프로젝트 배치(project layout) 파일로 저장한다(10–12). 원문: `It allows users to save all models loaded and all forms opened to a file (\*.eep).` (12); `As the default setting, the project layout setting file will be saved in the *#anlysis* folder.` (12). 그림 `6.png`는 Recent File, File 경로와 OK·Cancel이 있는 저장 창이다(14). 그림의 File 경로에는 `#analysis\Project.eep`가 보인다(14, 그림). 빈 줄과 그림 마크업을 포함한다(11·13–15). |
| 16–20 | Load Project Layout — 배치 설정 파일을 찾아 OK를 누르는 절차다(16–18). 그림 `7.png`는 배치 불러오기 창이며 Load Models·Load Title·Close Existing Models 체크 항목과 비활성 Close Existing Windows 항목을 보여 준다(20). 빈 줄과 그림 마크업을 포함한다(17·19–20). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 12·14(그림): 본문은 기본 폴더를 `#anlysis`로 적는다. 저장 창의 File 경로는 `#analysis\Project.eep`를 표시한다.
- 12·18: 링크 대상은 `#ProjectLayout-Figure1`과 `#ProjectLayout-Figure2`이다. 이 Markdown 파일에는 해당 앵커와 Figure 1·2 캡션이 없다.
