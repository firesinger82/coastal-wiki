## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행: CSS 선택자와 색상 선언이 본문 소개 문장 바로 앞에 남아 있다.
- 85행: 링크 표시 이름은 Figure 10이고 대상 URL의 앵커는 `#PropellerWash-Figure13`이다.
- 89행·103행: 그림 캡션 번호는 Figure 10 다음에 Figure 12로 넘어간다. Figure 11 캡션은 이 파일에 없다.
- 145행: 일반 정보 설명 첫 문장은 `MSSI Code`라고 적는다. 같은 행의 선박 구분 설명은 `MMSI Code`라고 적는다.
- 147행 그림: 여러 입력값에 `-999`가 표시된다. 이 문서는 이 값의 의미를 정의하지 않는다.
- 191행·200행 그림: 본문 분할 옵션 이름은 `Split using Time Duration (hours)`이다. 그림의 시간 분할 필드 이름은 `Split Using Time Between Points (hours)`이다.
- 314행 그림: 입력 예시에 `flow_est_zone2_mult`가 있다. 67–70행 설명과 같은 그림의 General 폼에는 이 이름의 정의가 없다.
- 318행·322행 그림: 선박 입력 파일과 항적 입력 파일의 예시는 아래쪽에서 잘려 있다. 파일의 나머지 입력행과 닫는 괄호는 이 그림들로 확인할 수 없다.
