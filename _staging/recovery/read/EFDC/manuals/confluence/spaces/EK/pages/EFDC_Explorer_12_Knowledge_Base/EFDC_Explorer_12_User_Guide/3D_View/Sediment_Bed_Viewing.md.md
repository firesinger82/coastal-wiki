## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행은 표시 옵션으로 `d50`을 열거한다. 이 파일은 `d50`의 뜻이나 단위를 정의하지 않는다.
- 10행의 그림 링크는 `#SedimentBedViewing-Figure1`을 가리킨다. 이 파일에는 해당 ID 선언이 없고 14행은 굵은 글씨 캡션이다.
- 8행의 문서 경로는 `EFDC+ Explorer 12 User Guide`를 포함한다. 12행 그림의 창 제목은 `3D View (20191104 EE10.1)`이다.
