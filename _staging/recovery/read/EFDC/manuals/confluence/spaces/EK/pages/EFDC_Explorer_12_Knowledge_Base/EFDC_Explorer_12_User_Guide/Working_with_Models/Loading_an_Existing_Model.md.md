| 1–9 | 앞부분 메타데이터(frontmatter). 문서 제목은 `title: "Loading an Existing Model"` (3)이다. 페이지 ID, space, URL, 버전, 갱신 시각과 문서 계층을 포함한다(1–9). |
| 10–22 | Step-by-step guide. 기존 모델은 `Model\Open Model` (12), 도구막대의 열기 아이콘 또는 `Ctrl + O` (16)로 연다(12–17). 그림 14는 폴더와 녹색 화살표가 있는 열기 아이콘이다. 그림 19는 Model 메뉴에서 Select Directory: Open Operation 창으로 향하는 화살표와 디렉터리 트리, 오른쪽 입력 파일 목록, 최근 프로젝트 목록 및 OK 버튼을 보여 준다. 마지막으로 연 디렉터리를 표시한다. 드롭다운은 최근 20개 프로젝트를 제공한다. 열기 작업의 필수 파일 조건을 그대로 옮긴다: `The directory displayed will be the last project directory opened.  The last 20 projects are available in the dropdown list located near the bottom of the form.  The panel on the right shows the files contained in the selected directory.  For Open operations, the EFDC.INP file must exist in the directory.` (21) |
| 23–28 | Other Options / Drag & Drop. EE가 이미 실행 중일 때 Windows Explorer에서 프로젝트 폴더나 그 안의 파일을 EE 창으로 끌어 새 프로젝트를 연다. 실행 상태와 허용 대상에 관한 원문: `If EE is already loaded, the user can load a new EFDC project using Windows Explorer.  The user can browse to the project folder (or parent folder) and then click on one of the following and then drag the item to the EE window.  EE accepts an EFDC project folder or any file inside the project folder.` (27) |
| 29–32 | Double Click. 설치 중 EE 확장자가 애플리케이션에 연결된다. EE 확장자 파일을 두 번 클릭하면 새 인스턴스(instance)가 시작되며 같은 폴더의 프로젝트를 연다. 조건과 경로 관계: `During EE installation, the file extension “EE” was associated with the EFDC+ Explorer application.  Therefore, the user can start a new instance of EFDC+ Explorer by double-clicking on any file with the EE extension.  EFDC+ Explorer will start and then load the EFDC project contained in the same folder as the EE file double-clicked on.` (31) |
| 33–35 | Recent Models. Model → Recent Models 메뉴는 최근 30개 모델을 최근 작업 순서로 제공한다. 원문: `You can quickly reopen a recent working model by accessing the main menu item Model then Recent Models. The menu lists the last 30 models ordered by working time with the more recent models on top of the others.` (35) |
