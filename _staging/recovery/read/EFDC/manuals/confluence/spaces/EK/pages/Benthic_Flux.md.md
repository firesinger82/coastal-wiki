| 10–19 | Benthic Flux / Benthic Nutrient Flux Method — 퇴적층 속성작용(diagenesis)·저서 플럭스(benthic flux)를 Benthic 탭에서 설정한다(10). 영양염 질량 플럭스를 상수 또는 시공간 변화 값으로 지정하면 속성작용 탭이 비활성화된다(15). Full Diagenesis Model을 선택하면 세 속성작용 탭을 사용할 수 있다(15). 옵션 적용 조건을 원문으로 옮기고 두 화면을 포함한다(12–18). 원문: `Clicking the button brings up the form shown in Figure 2. The top frame, *Benthic Nutrient Flux Method* is the option that controls EFDC's benthic flux approach. If the nutrient mass fluxes are to be specified either as constants or variable in time and space, then the diagenesis tabs are not used and consequently disabled. If the *Full Diagenesis Model (DiToro & Fitzpatrick, 1993)* option is selected then the three diagenesis tabs are visible to allow the user to specify the diagenesis parameters.` (15). 그림 직접 확인: `attachments/246775976/5-10-2019_11-32-12_AM.jpg` — Figure 1(12): Benthic 탭에서 `Computational Method: Specified Spatially Varying Fluxes`, `Number of Diagenesis Zones: 3`을 보여 주며 Modify Parameters를 강조한다. Rooted Macrophytes의 Use는 미선택이다. 그림 직접 확인: `attachments/246775976/5-10-2019_11-37-38_AM.jpg` — Figure 2(17): Constants & General 탭의 Benthic Nutrient Flux Method에서 `Spatially & Temporally Constant`, 선택값 `Specified Spatially/Temporally Varying Fluxes`, `Full Diagenesis Model`을 보여 준다. 복사한 설정은 `Phosphate: 0.01 (g/m²/day)`; `Ammonia-Nitrogen: 0.01 (g/m²/day)`; `NO₂-NO₃ Nitrogen: 0 (g/m²/day)`; `Silica: 0.01 (g/m²/day)`; `Chemical Oxygen Demand: 0 (g/m²/day)`; `Sediment Oxygen Demand: -3 (g/m²/day)`; `SOD Temperature Coefficient: 1.065`이다. 부호 규약은 `Sign Convention: (+) From Sediments to Water column, (-) From Water Column to Sediments`이다. | 20–24 | Diagenesis / 초기 매개변수 — Load Settings로 다른 프로젝트의 WQSD3D.INP를 읽어 현재 프로젝트를 초기화한다(20). 이후 값을 수정할 수 있으며 Chesapeake Bay ICM 적용값을 시작점으로 권고한다(20). 옵션 화면·캡션을 포함한다(22–23). 원문: `Figure 3 shows one of the diagenesis tabs for defining the diagenesis parameters. The best way to initialize all of the diagenesis parameters is to use the *Load Settings* button. This will read an existing WQSD3D.INP file from another project and initialize the settings for the current project with those from the loaded project. After the user initializes the parameters, they can modify the settings during the model development stages. The diagenesis values from the Chesapeake Bay ICM application (Cerco & Cole, 1995) provide a good starting point for diagenesis model parameterization.` (20). 그림 직접 확인: `attachments/246775976/Benthic_Fig3.PNG` — Figure 3(22): Diagensis - Options 탭과 Load Settings를 강조한 화면이다. | 25–29 | Sediment Diagenesis / Initial conditions — 반응성이 가장 큰 G1·G2·가장 작거나 불활성인 G3를 따로 또는 함께 지정한다(25). 상수·XYZ 산포 자료(scatter data)·연직 분포 자료(profile data)로 초기 농도를 지정하며 전체 모델 또는 선택 셀에 보간(interpolation)할 수 있다(25). 조건·분류·할당 방법을 원문으로 옮기고 설정 화면을 포함한다(27–28). 원문: `In addition to the diagenesis kinetic parameters, the sediment bed diagenesis initial concentrations also need to be specified. This can be accomplished by applying measured data for each parameter using the *Spatially Varying IC's* button. When pressed, the form shown in Figure 4 is displayed. Each parameter reaction class, i.e. G1 (most reactive), G2 and G3 (least reactive or inert) can be separately specified or specified at once by selecting options in *A Class Options* frame. The *Value to Set* frame allows the user to select the assignment method by using a *Constant* value, interpolating *From* *Scatter (XYZ) Data* or *From Profile Data.*The data can be interpolated for the entire model in a single operation or using only selected cells by selecting in *Grid Options* frame.` (25). 그림 직접 확인: `attachments/246775976/5-10-2019_11-42-26_AM.jpg` — Figure 4(27): Interpolate Classed Data 창에서 `All grid cells`, `For All Layers`, `Constant: 0`, `Replacement`, `A Specific Class: Cyanobacteria:G-Class 1`을 선택한다. 대안은 `Only grid cells inside polygons`, `A Specific Layer: 1`, `From Scatter (XYZ) Data`, `From Profile Data`, `Maximum value`, `Minimum value`, `For All Classes`이다. |
