# Modify_Model_Boundaries.md — 판독 구간 기록

구간은 1행부터 18행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–15 | 모델 경계 수정(Modify Model Boundaries) / 경계 그룹 추가 — CSS 색상 마크업 뒤에 Layer Control의 Boundaries 펜을 켜고 LMC 또는 Shift/Ctrl+LMC로 셀을 선택한 뒤 오른쪽 클릭하여 Add New Boundary Group을 실행하는 절차를 설명한다(10). 그룹 이름과 유형을 선택하며 상세 유형 설명은 Boundary Conditions 링크로 안내한다(10). 10행 펜 아이콘, 그림 1, 그림 2를 직접 열었다(12·14). 그림 1은 선택 셀의 Add New Boundary Group 메뉴이다. 그림 2는 `Boundary Group Name`, `Boundary Group Type` 입력 창이며 유형 목록은 `Flow Boundary`, `Hydraulic Structure/Rating Curves`, `South Open Boundary`, `East Open Boundary`, `West Open Boundary`, `North Open Boundary`, `Withdrawal/Return Structure`, `Jet/Plume Boundary`이다(14행 그림). |
| 16–18 | 기존 경계 그룹 — 기존 그룹이 있는 셀의 오른쪽 클릭은 개별 셀 또는 전체 그룹의 편집·삭제·시계열 보기를 추가로 제공한다(16). 그림 3을 직접 열었다(18). 메뉴에는 Edit Boundary Group·Edit Boundary Cell·Delete Boundary Cell·Delete Entire Boundary Group·View Boundary Group·View Boundary Group TSS·View Open Boundary Cell Flow·View Open Boundary Group Flow가 있다. |
