# Auto_generate_data_plot_statistics.md — 판독 구간 기록

구간은 1행부터 30행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | Auto generate data, plot statistics — 문서 식별자, 제목, space, URL, 판본, 갱신 시각과 문서 계층의 frontmatter(1–9). |
| 10–17 | 자동생성 기능 진입 — 자료 관측점(station)이 모델 출력 비교용으로 정의되었을 때 Model Analysis 하위 항목의 오른쪽 클릭(RMC)으로 자동생성 기능을 사용할 수 있다(10). 적용 조건 원문: `in case the data stations have been defined to compare to the model output, the *Auto Generate Data, Plot Statistics* is enabled by RMC on the sub-tab of the *Model Analysis*` (10) 선택하면 Auto Generate Options 양식이 열린다(14). 소제목·빈 줄·그림을 포함한다(11–17). `2020-06-03_9-51-49_AM.png`을 열었다(12). 그림은 Vertical Profiles (1)의 자동생성 메뉴와 비교표를 보여 준다. 표 열은 `Name`, `X (m)`, `Y (m)`, `Parameter`, `Layer`, `File name`, `Filter`, `Group`, `Used`이다. 예제 행은 `Buoy, 556057, 5275456, Temperature (°C), Layer 55`이고 `Filter: 0`, `Group: 0`, `Used: False`이다. |
| 18–30 | Generate Options — 자동 플롯, ASCII 추출, 기존 추출 재사용, 보고서와 보정(calibration) 유형을 설명한다(18–26). 옵션·기본 저장경로·조건 원문: `The EE will generate the comparison plot automatically if the *Automatically Generate Defined Plots* box is checked. The *Plot Location* indicates where the plots will be stored. The plots will be store in *#calib\_plots* folder as default settings. If the user wants to store the plots in other folder by clicking on the *Browse* button to change location.` (18); `*Automatically Export Model ASCII Extractions*: Selecting this option will generate ASCII file format of output model extraction with entire model simulation time from grid cell which has measured data station locates at. In case the *Pair Model and Data* option is checked, the EE only extracts for time that the measured data is available for those time points.` (20); `*Used Existing Model Extractions*: Extracting the data from the EFDC output can be time consuming if it is a large model run.  To avoid having to extract the results each time, this option can be used to reused the existing extracted data. The files extracted will be in the *#calib\_export* folder as the default setting of the *Data Location*. If the user wants to store the files in other folder by clicking on the *Browse* button to change location.` (22); `*Automatically Generate Reports*: This option links to the *Report Error Statistics* frame below. If this option is not checked, the *Report Error Statistics* options are enable. The error report is generated and stored in the *#calib\_stats* folder as default settings. The error report can be HTM format (\*.htm) if the option *HTM Report File* selected or ASCII format (\*.dat) if the option *ASCII Report File* selected. Further description about error statistics types are presented in [Calculating Error Statistics](/wiki/spaces/EK/pages/246547427/Calculating+Error+Statistics).` (24); `*Model Calibration Types*: There are several model calibration types, however not all types will be enable at the same time for auto generate options. It depends on which calibration types the user selected. For example, the Vertical Profiles is selected to use auto generate option by RMC on the *Vertical Profiles* sub-tab of the *Model Analysis* as shown in [Auto generate data, plot statistics#Figure 1](#Figure1) so it will be enable in the *Model Calibration Types* frame as shown in [Auto generate data, plot statistics#Figure 2](#Figure2).` (26). Auto Generate로 생성한다(28). 빈 줄과 마지막 그림을 포함한다(19,21,23,25,27,29–30). `2020-06-03_10-45-11_AM.png`을 열었다(30). 양식에서 `Automatically Generate Defined Plots`, `Automatically Export Model ASCII Extractions`, `Automatically Generate Reports`, `Vertical Profiles`가 체크되어 있다. `Pair Model and Data`, `Used Existing Model Extractions`, `Reload Data & Model Result`는 미체크 상태이다. 보고서 선택 항목은 `Average Error`, `Relative Error`, `Absolute Error`, `Std Dev Model`, `Std Dev Data`, `Nash-Sutcliffe`, `RMSE`, `Relative RMSE`, `Percent RMSE`, `Coeff of Efficiency`, `Index of Agreement`, `R Squared`이며 모두 체크되어 있다. `All`도 체크되어 있다. `HTM Report File`이 선택되고 `ASCII Report File`은 미선택이다. Plot Location 경로 끝은 `#calib_plots\`이고 Data Location 경로 끝은 `#calib_export\`이다. 표시 상태는 이 예제 화면의 상태이다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10·14·26: Figure 1·2 링크는 `#Figure1`, `#Figure2`를 가리킨다. 이 파일에는 해당 anchor 정의가 없다.
- 24·30의 그림: 본문은 Automatically Generate Reports가 체크되지 않을 때 Report Error Statistics 옵션이 활성화된다고 적는다. 그림에서는 Automatically Generate Reports가 체크되어 있고 해당 통계 선택 상자들이 활성 상태로 보인다.
