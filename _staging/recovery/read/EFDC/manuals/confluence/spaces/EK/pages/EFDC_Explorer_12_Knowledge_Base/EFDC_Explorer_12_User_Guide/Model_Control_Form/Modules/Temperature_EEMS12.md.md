# Temperature_EEMS12.md — 판독 구간 기록

구간은 1행부터 29행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터. Temperature (EEMS12)의 식별자·제목·space·URL·버전·갱신 시각·계층 경로가 있다 (2–8). |
| 10–15 | Activate the Temperature Module. 제목 앞에 색상 CSS가 있다 (10). EFDC+ Modules에서 Temperature를 활성화한다 (12). 14행 그림은 Temperature 선택을 강조한 화면이다. Use EFDC+ Model이 선택되며 전역 수송 방법은 `Upwind Difference; Anti-Diffusion Correction; Flux Limitation` (14행 그림)이다. |
| 16–19 | 모듈 우클릭 메뉴. Settings·Initial Conditions·Time Series를 제공한다 (16). 18행 그림은 메뉴와 온도 요약이다. 표시값은 `Surface Heat Exchange Submodel: No Atmospheric Linkage` (18행 그림); `Solar Radiation: Ignored; Surface Evaporative Losses: Ignored` (18행 그림); `Number of Atmospheric Series: 0; Number of Temperature Series: 0` (18행 그림); `Mean: 20.00 °C; Min: 20.00 °C; Max: 20.00 °C` (18행 그림)이다. |
| 20–29 | Temperature Parameters의 여섯 탭. 설정 절은 `Heat Exchange` (22); `Solar Radiation` (23); `Evaporation` (24); `Initial Conditions` (25); `Boundary Conditions` (26); `Ice` (27)이다. 29행 그림은 여섯 탭과 Heat Exchange를 보여 준다. `Surface Heat Exchange Option: No Atmospheric Linkage` (29행 그림); `Heat Transfer Coefficient: 0 (m/s)` (29행 그림); `Convective Heat Transfer Coefficient: 0 (dimensionless)` (29행 그림)이다. Allow Bed Temperatures to Vary with Time은 미선택이다 (29행 그림). |
