# Menu_and_Toolbar_Items.md — 판독 구간 기록

구간은 1행부터 30행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–15 | 2DH 메뉴 개요 — 메뉴 기능의 사용법을 하위 페이지에 설명한다고 적는다(10). 그림 1을 직접 열었으며 New 2DH View, Change View, Grid Cell Properties, Grid Cell Selection, Overlays, Vertical Profile, Harmonic Analysis, Layer Control, Timing Frames, Frame Control, 2DH View Settings, Save Layout, Load Layout 메뉴를 보여 준다(12–14). |
| 16–30 | 하위 페이지 링크 — New 2DH View, Change View, Grid Cell Properties, Grid Cell Selection, Overlays and Polyline Tools, Vertical Profile Plots, Harmonic Analysis, Other 2DH View Features의 제목과 링크만 나열한다(16–30). 이 구간에는 사용 절차나 수식·매개변수 정의가 없다. |
