Digital Elevation Model in 3D View — 10행은 CSS 색상 규칙 뒤에 수치표고모형(digital elevation model, DEM)의 생성·표시와 비행 시각화 용도를 설명한다. 예시는 중국의 Three Gorges Dam이며 내려받기 링크와 데모 판본 사용 안내가 있다(12). 입력 데이터의 필수 형식·열 순서 원문: ` The Three Gorges Dam in China is used as an example (this model can be downloaded from the [EEMS website](https://www.eemodelingsystem.com/user-center/modeling-resources/demonstration-models/2) and loaded in the Demo version of EEMS). In order to generate a DEM in 3D, it is first necessary to have correctly formatted digital elevation data. The data should be saved as ASCII file (\*.txt, \*.dat, \*xyz) in three columns. The first and second columns are Easting and Northing coordinates, the third column is the corresponding elevation.` (12). ASCII 파일의 첫 열은 Easting, 둘째 열은 Northing, 셋째 열은 대응 표고(elevation)이다(12). 빈 줄을 포함한다(11·13). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 16·20·24·30·38·42·46·92·96행의 그림 링크는 `#Figure1`부터 `#Figure13`까지의 ID를 참조한다. 이 파일에는 해당 ID 선언이 없다. 캡션은 Figure 6·11·12·13에만 붙어 있다(34·102·106·110).
- 38·42행: `RMC`의 뜻을 이 파일은 정의하지 않는다.
- 80·86·88행: `Sink with Current Model`, `Sink Factor:`, `Sink Offset:`에는 설명이 없다.
- 20행의 출력 형식 이름은 `Surfer ASCII Grid`이다. 22행 그림의 라디오 버튼 이름은 `Sufer ASCII Grid`이다.
- 40·44행 URL의 파일명은 `(1)`을 포함한다. 해당 폴더 목록의 로컬 파일명은 괄호가 빠진 `9-17-2020_9-42-07_AM1.png`, `image-20200921-0833351.png`이다. 두 파일을 찾아 열었다.
- 44행의 DEM Layer Properties 그림에서 DEM Info 표의 마지막 Z Range 행은 아래쪽이 일부 잘려 있다.
- 108행의 Scale Factor 입력란은 오른쪽 끝이 좁다. 표시된 숫자 뒤의 전체 자릿수는 이 그림에서 확인하지 못했다.
