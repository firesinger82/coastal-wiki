| 10–23 | Option 3의 적용 조건과 초기 물성 파일. 퇴적물 코어 자료가 SEDFlume 자료에 추가로 있을 때 사용하는 조건은 `Users may use the erosion rates option 3: *Equation (E = A\*Tau^n*) *and Bed Properties Using SEDB, BEDLAY, BEDBDN, and BEDDDN*, if sediment core datasets are available in addition to the SEDFlume datasets (Figure 1). Such sediment core samples are usually collected with much higher spatial density and much wider spatial coverage compared to SEDFlume samples. With the erosion rates option 3, the user can use sediment core datasets when configuring initial conditions for physical properties of sediment bed and, at the same time, use SEDFlume datasets when specifying erosion rate properties of sediment bed in the model.` (10)이다. 물성 초기화와 침식 특성에 서로 다른 자료를 사용한다 (10–12). 파일 역할은 `*sedb.inp*:        fraction of each sediment class` (14); `*bedlay.inp*:     layer thickness` (16); `*bedbdn.inp*:   wet density` (18); `*bedddn.inp*:   porosity` (20)이다. ## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 식의 전단응력 정의는 `N/m2`이다 (28). 코어 물성과 그림 표는 `dynes/cm2` 또는 `dynes/cm²`이다 (62, 68행 그림). 단위 변환 설명은 이 파일에 없다 (1–70).
- 본문 옵션명은 `Use Sediment Core with Grainsize`이다 (42). 화면은 `Use Sediment Cores with Grainsize`라고 쓴다 (44행 그림).
- 코어 파일 경로의 앞부분이 입력칸에서 보이지 않는다 (44행 그림).
