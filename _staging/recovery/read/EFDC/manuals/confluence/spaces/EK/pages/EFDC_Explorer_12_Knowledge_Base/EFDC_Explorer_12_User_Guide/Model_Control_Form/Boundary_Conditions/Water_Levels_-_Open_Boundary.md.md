| 21–24 | Open Boundary / 입사·출사파와 모서리 — 지정 고도(elevation specified)는 조화 성분(harmonic constituents)과 시계열을 조합한다(21). 방사 분리(radiation separation)는 입사파(incident wave)와 출사파(outgoing wave)를 분리하며 입사파는 요구 수면 고도의 두 배로 가정한다고 적는다(21). 기본으로 출사 특성(outgoing characteristic)을 정의하지 않아 내부 생성 파가 무반사로 경계를 나가게 한다고 적는다(21). 고도 지정 옵션은 만나는 각 개방 경계의 모서리 셀 하나를 비활성화하도록 권고한다(21). 방사 분리 옵션은 각 경계의 모서리 셀 둘을 비활성화해야 한다(21). 원문의 조건·수량·기본 동작을 그대로 옮긴다: ``*Elevation Specified* is the standard approach for water surface elevations, using a combination of harmonic constituents and time series. With the *Radiation Separation* boundary condition the incoming wave at an open boundary is separated from the outgoing wave and the incident wave is assumed to be twice the surface elevation required (Zhou, 2014). By default, the outgoing characteristic is left undefined, allowing waves generated interior to the model domain to pass outward across the boundary with no reflection. When using the *Elevation Specified* option the user should deactivate one cell in the corner of the grid where for each open boundaries when they meet. When using a *Radiation Separation* boundary then the user must have 2 cells deactivated in the corner for each boundary. This is shown in [Figure 2](#Figure2) where four cells are deactivated where the south and east boundaries meet. This is because an open boundary always sets a mask in the E-W direction for the S boundary, likewise, an open boundary sets a mask in the N-S direction for a W boundary.`` (21). 23행 `19.png`와 `EE10_140.png`의 로컬 사본을 모두 열었다. 첫 그림은 North 면과 Elevation Specified-Zero Tangential을 선택한 창이며 상수·시간 변화 농도 표의 자료 행은 비어 있다(23). 둘째 그림은 곡선 격자(curvilinear grid)의 남쪽 `S` 경계와 동쪽 `E` 경계가 만나는 모서리의 흰 비활성 셀 영역을 빨간 원으로 표시한다. 색상 막대는 `Bottom Elevation (m)`이며 양 끝 값은 `-19.004`, `5.312`이다. 표시 시각은 `2018-01-01 00:00`이다(23행 둘째 그림). |
| 25–28 | Open Boundary / 저면 변화와 Free Tangential — 경계의 급격한 수심 지형(bathymetry) 변화는 질량 수지 오차(mass balance errors)를 발생시킬 가능성이 있고 모델 불안정성을 일으킬 수 있다고 적는다(25). 경계 바깥 방향의 첫 두 셀을 같은 고도로 둘 것을 권고한다(25). Elevation Specified-Free Tangential은 보통의 경계 셀 둘 대신 경계 셀 하나만 사용하게 한다(27). 원문: ``Users should also be aware that if they have rapidly changing bathymetry at the open boundary, then it is possible to get mass balance errors. Rapidly changing bottom elevation at the open boundary can lead to EFDC becoming unstable. To easily resolve this issue, it is recommended that the first two cells going out in the direction of the open boundary i.e. in the southward direction for the southern open boundary, be at the same elevation.`` (25); ``In EE8.4 a BC option has been which allows the use of an elevation-specified flow but allows for a “free tangential”.  Normally an open BC requires two cells at the border. In some models where there are tight boundaries, this can be restrictive. The *Elevation Specified-Free Tangential* option allows EFDC to only use one cell at the border.`` (27). |
| 29–31 | Boundary Group Conditions frame — 개방 경계에서는 Constant Concentrations를 경계 배정에 항상 사용하고 시계열 농도에 더한다(31). 시계열 염분 `5 to 10 ppt`와 상수 염분 `10 ppt`의 예시는 시간 변화 염분 `15 to 20 ppt`를 적용한다(31). 덧셈과 범위의 원문: ``For open BC's, unlike flow BC's, the concentrations specified in the *Constant Concentrations* frame are always used for boundary assignments. The constant concentrations will be added to any time series concentrations defined. For example, if the user has a tidal time series of salinity that varies from 5 to 10 ppt and specifies a concentration for the salinity of 10 ppt in the *Constant Concentrations* frame, EFDC will apply time variable salinity concentrations ranging from 15 to 20 ppt.`` (31). 제목 마크업과 마지막 행을 포함한다(29–31). |
