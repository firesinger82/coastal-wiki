## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 일반 mklink 형식에 `General case: **Mklink /d "*****Working-Directory" "Shared-Directory"***  ` (58)라는 따옴표·별표 마크업이 표시되어 있다. 같은 행에서 굵게·기울임 표기 구분용 별표가 연속으로 나타난다(58).
- 그림 캡션 번호는 Figure 5 다음에 Figure 7로 이어진다. Figure 6 캡션은 이 문서에 없다(85, 97).
- Figure 8 캡션은 `**Figure 8.** **EFDC+ Run Options: MPI Cluster tab.**` (101)이다. 연결된 그림은 MPI Cluster 탭이 아니라 ipconfig를 실행한 Command Prompt 화면이다(99).
