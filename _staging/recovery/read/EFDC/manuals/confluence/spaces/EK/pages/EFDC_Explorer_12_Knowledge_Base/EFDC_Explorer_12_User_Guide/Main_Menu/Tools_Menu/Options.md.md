# Options.md — 판독 구간 기록

구간은 1행부터 14행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 페이지 ID, 제목, space, 원문 URL, 버전, 갱신 시각, 문서 계층 경로와 frontmatter 구분선을 포함한다(1–9). |
| 10–14 | Options — 단위 체계(unit system), 쓰기 작업의 기본 정밀도(default precision), 기본 텍스트 편집기(text editor)와 기타 설정을 변경한다(10). 변경 항목은 `The function allows the user to change the unit system (metric or imperial/US), write operation's default precision, and default text editor along with other miscellaneous settings.` (10)이다. `12.png`를 열었다(12). EFDC+ Explorer Settings의 General 탭이며 Formats·Text Editor 탭도 보인다(12, 그림). `Unit System`에서는 `Metric`이 선택되어 있고 `English/US`는 선택되지 않았다(12, 그림). `Language`의 표시값은 `English`이며 비활성 상태이다(12, 그림). Figure 1 캡션을 포함한다(14). |
