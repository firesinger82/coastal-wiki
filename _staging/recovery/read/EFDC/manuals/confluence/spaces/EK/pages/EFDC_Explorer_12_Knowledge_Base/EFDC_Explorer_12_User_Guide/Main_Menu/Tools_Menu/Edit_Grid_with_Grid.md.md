| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 페이지 ID, 제목, space, 원문 URL, 버전, 갱신 시각, 문서 계층 경로와 frontmatter 구분선을 포함한다(1–9). |
| 10–17 | Edit Grid with Grid+ / 통합 편집 — 현재 열린 모델의 격자(grid)를 Grid+에서 바꾼다(10). 독립 실행판과의 기능 차이 및 셀 수 제한 조건은 `Notice that the Grid+ version launched from EE has features that are limited compared to the stand-alone Grid+ version in EEMS.` (10); `It does not allow changing the number of grid cells.` (10); `It is used to improve grid orthogonalization or change grid nodes.` (10). Tools에서 Edit Grid with Grid+를 선택하여 실행한다(12). 그림 `image2024-8-21_10-7-30.png`는 해당 메뉴를 강조한다(14). Figure 1 캡션·빈 줄·그림 마크업을 포함한다(10–17). |
| 18–24 | Grid+ / 모델 갱신·복귀 — 레이어 제어에서 격자를 선택해 격자점(grid node) 이동·격자 직교화(orthogonalization)를 수행하고 File에서 갱신을 선택한다(18). 두 명령의 저장·유지·종료 조건은 `*Update EFDC Model*: Save the EFDC model with what we changed to the grid and keep Grid+.` (20); `*Update EFDC Model and Return*: Save the EFDC model with what we changed to the grid, but exit Grid+. A confirmative message will pop up to confirm that we want to exit Grid+, as shown in [Edit Grid with Grid+#Figure 4](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2576318465#EditGridwithGrid+-Figure4).` (22). 그림 `1.png`는 해안 지도 위의 흰색 격자, 왼쪽 `Grid 001` 레이어와 넓은 남쪽 해역·북쪽 및 북동쪽 수로의 격자를 보여 준다(24). 좌표 축과 유동 화살표는 없다(24, 그림). 그림 `2.png`는 File의 Update EFDC Model·Update EFDC Model and Return 메뉴다(24). 그림 `3.png`는 `Are you sure you want to exit Grid+?`와 Yes·No 버튼을 보여 준다(24). 빈 줄·세 그림 마크업을 포함한다(18–24). |
