# Shortcut_Keys.md — 판독 구간 기록

구간은 1행부터 73행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–33 | Shortcut Keys / 표 1 화면 변경 — Ctrl+F2 도움말의 표시 내용은 불러온 자료·모델 결과와 현재 보기에 따라 달라진다(10). 표의 행별 키 원문과 기능은 `Ctrl++` 확대(16), `Ctrl+-` 축소(17), `Ctrl+E` 모든 레이어 전체 범위 표시(18), `Ctrl+H` 서식지 분석(Habitat Analysis)(19), `Ctrl+V` 셀 또는 셀 그룹 이동(20)이다. 21행은 `**Ctrl+V** **Shift+Up**`와 `Go to a cell or group of cells`, `Pan up  Hold Shift key and press Up Arrow key to shift the view up.`를 세 열에 적으며 22행은 빈 표 셀이다. 이어서 `Shift+Down` 아래 이동(23), `Shift+Left` 왼쪽 이동(24), `Shift+Right` 오른쪽 이동(25), `Alt+E` 현재 그림의 비트맵(bitmap) 내보내기(26), `Shift+RMC` 이동(27), `Alt+RMC` 보기 영역 지정 확대(28), `Alt+Z` 지정 축척으로 View Port 설정(29), `Mouse Wheel` 휠 위·아래로 확대 계수 변경(30), `F5` 창 다시 그리기(31), `F4` 창 테두리·시간 제어·상태 표시줄 표시 전환(32)을 적는다. |
| 34–47 | 표 2 시간 변경 — 각 행 원문은 `Home` / `Go to the first time step` (38); `End` / `Go to the last time step` (39); `PgUp` / `Go backward one-time step` (40); `PgDn` / `Go forward one-time step` (41); `Shift+PgUp` / `Go backward 10-time steps` (42); `Shift+PgDn` / `Go forward 10-time steps` (43); `Ctrl+PgUp` / `Go backward 100-time steps` (44); `Ctrl+PgDn` / `Go forward 100-time steps` (45); `Ctrl+G` / `Go to a specific time` (46). |
| 48–57 | 표 3 셀 선택 — 각 행 원문은 `Ctrl+V` / `Go to a specific cell` (52); `Up` / `Move the selection up one cell` (53); `Down` / `Move the selection down one cell` (54); `Left` / `Move the selection left one cell` (55); `Right` / `Move the selection right one cell` (56). |
| 58–67 | 표 4 기타 — 각 행 원문은 `F7` / `Toggle Julian Dates` (62); `Alt+L` / `Load settings from file` (63); `Alt+K` / `Save settings to file` (64); `Ctrl+I` / `Toggle on/off Cell Information` (65); `Alt+T` / `Toggle the Automatic Use/Removal of Border Triangular Cells` (66). |
| 68–73 | Other Shortcut Keys — `Ctrl+F2`는 단축키 목록을 연다(72). `Ctrl+A`는 Model Control 창을 복원한다(73). 이 파일에는 참조 그림이나 수식·설정 매개변수 정의가 없다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 14–22: 표 1은 두 열로 시작하지만 21행은 세 열이며 첫 셀에 `Ctrl+V`와 `Shift+Up`이 함께 들어 있다. 22행은 빈 셀만 가진 행이다.
- 20·52: 표 1의 Ctrl+V 설명은 셀 또는 셀 그룹 이동이며 표 3의 설명은 특정 셀 이동이다.
