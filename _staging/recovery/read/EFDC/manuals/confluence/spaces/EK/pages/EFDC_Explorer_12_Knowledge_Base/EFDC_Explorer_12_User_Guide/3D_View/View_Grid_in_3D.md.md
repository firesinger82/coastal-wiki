# View_Grid_in_3D.md — 판독 구간 기록

구간은 1행부터 19행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–16 | 문서 메타데이터 — 페이지 ID·제목·space·URL·판본·갱신 시각·문서 경로와 frontmatter 구분자를 포함한다(1–9). View Grid in 3D / Properties 열기 — 10행은 CSS 색상 규칙 뒤에 Layer Control의 Model Grid 층에서 RMC를 수행하고 Properties를 선택하는 절차를 설명한다. View Grid in 3D 프레임의 목록에서 옵션을 고르고 OK를 누른다(12). 선택 절차 원문: `In the *View Grid in 3D* frame, the user can select an option from the drop-down list then click the *OK* button.` (12). Figure 1의 로컬 그림을 열었다(14–15). 그림은 Model Grid의 Properties 메뉴와 바닥 표고에 맞춘 3D 격자이다. 범례 `Bottom Elevation (m)`의 양 끝 값은 `-80.000`, `4.000`이고 `Vertical Exaggeration: 6`이 표시된다(14행 그림). 방향 표시는 Z가 위쪽, X가 오른쪽 아래, Y가 오른쪽이다. 별도 축 눈금은 없다. 빈 줄·그림 마크업·캡션을 포함한다(11·13–16). |
| 17–19 | Model Grid Properties — Figure 2의 로컬 그림을 열었다(17–19). 그림은 모델 격자 설정과 View Grid in 3D 목록을 보여 준다. 화면 예시값은 `Layer Name: Model Grid`, Grid Line Settings의 `Style: Solid`, `Width: 0.5`이다(17행 그림). `Layer Visible`, `Show in Legend`, `Show Grid`, `Use Corners`는 선택되고 `Show Outlines`, `Show East`, `Show South`는 선택되지 않았다. Grid Outline Settings는 회색이며 그 안의 `Style: Solid`, `Width: 0.5`도 보인다. 선의 `Color`는 회색이다. Options 목록은 `Not Shown`, `Grid at Water Surface`, `Grid at Bottom`, `Grid by Layer`, `Grid for Entire Column`, `Outline for Entire Domain`이고 `Grid at Bottom`이 선택되어 있다(17행 그림). 본문은 이 예시값의 기본값 여부나 Width의 단위를 명시하지 않는다. 빈 줄·그림 마크업·캡션을 포함한다(17–19). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행의 그림 링크는 `#ViewGridin3D-Figure1`·`#ViewGridin3D-Figure2`를 가리킨다. 이 파일에는 해당 ID 선언이 없고 15·19행은 굵은 글씨 캡션이다.
- 10행: `RMC`의 뜻을 이 파일은 정의하지 않는다.
- 10행의 층 이름은 `Model Grid`이다. 15행 캡션은 `View Model Gid`라고 적는다.
