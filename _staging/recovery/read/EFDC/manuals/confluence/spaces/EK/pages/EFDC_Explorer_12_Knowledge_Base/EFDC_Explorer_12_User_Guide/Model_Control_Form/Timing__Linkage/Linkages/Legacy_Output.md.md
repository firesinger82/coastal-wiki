# Legacy_Output.md — 판독 구간 기록

구간은 1행부터 12행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — Legacy Output의 페이지 ID, URL, 버전, 갱신 시각, 계층이다(1–9). |
| 10–12 | EFDC Generated Time Series — EE가 자체 시계열(time series)을 생성하므로 이 옵션의 사용을 권장하지 않지만 사용자는 사용할 수 있다고 적는다(10). 문장 앞 색상 CSS도 이 구간에 포함한다(10). 로컬 그림을 직접 열었다(12). Legacy Output 탭의 시계열 생성 화면이며 `Use`는 미선택이고 `Currently Defined Cells: 0`이다(12 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행: 색상 CSS가 본문 앞에 남아 있다.
