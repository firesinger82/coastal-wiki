Once the kinetic option has been chosen the user still needs to select which parameters will be varied/simulated within the selected kinetic option. ## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 24: 구역 수 입력란 이름 앞에 `429px`가 붙어 `429pxNumber of Kinetic Zones`로 적혀 있다.
- 28·34: 서로 다른 그림 캡션이 모두 `Figure 4` 번호를 사용한다.
- 30: 적용 조건에 `KC>1`을 사용하지만 이 문서는 `KC` 기호를 정의하지 않는다.
- 15: 그림의 `Total Active Metal` 행은 단위를 `(mg/L as C)`로 표시한다. 본문은 이 단위 표기의 의미를 설명하지 않는다.
