# Marker_Settings.md — 판독 구간 기록

구간은 1행부터 16행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–16 | 문서 메타데이터 — 페이지 ID·제목·space·URL·판본·갱신 시각·문서 경로와 frontmatter 구분자를 포함한다(1–9). Marker Settings — 축의 임의 값에 표시선 또는 기호(marker)를 설정할 수 있다(10). 상자에서 RMC를 수행한 뒤 표시를 추가하거나 삭제하고 방향·값·선 모양·색·기호 모양을 선택한다(12). 설정 절차 원문: `After RMC in the box, the user is able to add or delete markers as shown in Figure 1. Choose the X or Y values in the *Orientation* frame and then choose the value of the marker in *Value* box. Line style, color or shape of the symbol can also be customized.` (12). Figure 1의 로컬 그림을 열었다(14–16). 그림은 RMC의 Add/Delete 메뉴와 Marker Options 설정 화면을 보여 준다. 화면 예시값은 `Title: Marker_1`, `Alignment: Center`, `Value: 10`, `Position: 0`이다(14행 그림). `Orientation`에서는 `Y Value`가 선택되고 `Date/X Value`는 선택되지 않았다(14행 그림). `Show All`, `Visible`, `Show`는 선택되고 `Use Background`는 선택되지 않았다(14행 그림). `Line Style`, `Symbols`, `ForeColor` 버튼이 보인다(14행 그림). 빈 줄·그림 마크업·캡션을 포함한다(11·13–16). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 12행: `RMC`의 뜻을 이 파일은 정의하지 않는다. 14행 그림에는 `RMC`와 Add/Delete 메뉴가 표시된다.
