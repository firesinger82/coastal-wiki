# Change_Logs.md — 판독 구간 기록

구간은 1행부터 14행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | Change Logs — 문서 식별자, 제목, space, URL, 판본, 갱신 시각과 문서 계층의 frontmatter(1–9). |
| 10–14 | Change Logs — CSS 선언 뒤 각 실행(run)의 변경·메모를 기록하는 자유 양식 노트와 오른쪽 클릭(RMC) 편집을 설명한다(10). 모델 구축·보정(calibration) 과정의 전체 실행 이력을 남길 수 있으며 현재 실행의 기반이 된 이전 실행을 기록하도록 권고한다(10). 원문 예시와 저장파일: `"Run012 Based on Run011"` (12) `These data are stored in an ASCII text file in each run directory called "EFDC\_LOG.EE".` (12) 현재 실행의 변경사항을 뒤에 적으라고 설명한다(12). 빈 줄과 그림을 포함한다(11,13–14). `2019-04-25_2-42-36_PM.jpg`을 열었다(14). 그림은 Change Logs 보고서와 Run Log 편집기를 나란히 보여 준다. 예제 메모에는 `WL-09 Based on WL-08`, `wind data is replaced with the new one`, `wind: 20m/s`, `location of sewer:L=3592`, `Q inflow=1.5m3/s`, `Wind= Wind (WL-01) + 10`, `included: Temperature+Dye`가 표시되어 있다. 그림의 숫자는 자유 메모의 예시이며 모델 매개변수의 기본값·범위 설명은 아니다. |
