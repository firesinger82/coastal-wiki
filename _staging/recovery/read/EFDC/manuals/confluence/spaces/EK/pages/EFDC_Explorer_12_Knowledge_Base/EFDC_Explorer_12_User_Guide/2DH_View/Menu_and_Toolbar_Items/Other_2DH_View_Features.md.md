# Other_2DH_View_Features.md — 판독 구간 기록

구간은 1행부터 66행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–19 | 기타 2DH 기능 / Layer Control — 그림 1은 Layer Control, Timing Frames, Frame Control, 2DH View Settings, Save Layout, Load Layout 메뉴를 빨간 상자로 표시한다(12–14). 그림을 직접 열었다. Layer Control 창의 표시를 켜거나 끄는 기능을 설명한다(16–18). |
| 20–35 | 시간 프레임(Timing Frames) — 경계의 시간 프레임을 표시하며 `Available Boundary Groups`에서 선택하고 Add로 `Show Timing Frames`에 넣는다(22). 필드 원문은 `Time Begin, Time End`, `Time Scale`이다(22). Time Scale로 Y축을 조절한다(22). 단위 조건 원문: `The value of the scale field is dependent on what type of boundary forcing time series is selected.`; `For winds the scale is m/s, for flows and pressure the scale is days.` (24). `Show`로 표시를 켜거나 끈다(24). 오른쪽 클릭 메뉴는 Go to Time·Hide·Settings이다(26). 그림 2를 직접 열었다(28–30). 표의 첫 행은 ID `Sammamish River`, Group `Sammamish Ri...`, Time Begin `1826`, Time End `2826.959...`, Time Scale `40`, Show 체크, `Model Time` 체크 해제이다. 둘째 행은 ID·Group `BUOY`, Time Begin `1826`, Time End `2190.958...`, Time Scale `5`, Show 체크, `Model Time` 체크 해제이다(28행 그림). 표의 `ATM Parameter` 열은 비어 있으며 말줄임 표시 뒤 값은 읽을 수 없다. 그림 3을 직접 열었다(32–34). Sammamish River는 빨간 시간 곡선과 현재 시각을 나타내는 검은 수직선을 보여 준다. BUOY는 원 내부에서 왼쪽 위로 향하는 빨간 화살표이며 오른쪽 클릭 메뉴가 열린 상태이다. 시간 곡선과 원에는 수치 축 눈금이 없다. |
| 36–43 | 프레임 제어(Frame Control) — 축척 막대(scale bar), 북쪽 화살표(north arrow), 범례(legend), 시간 프레임의 표시를 `Show`로 제어한다(38). 그림 4를 직접 열었다(40–42). Scale Bar·North Arrow의 Show는 해제되어 있으며 Legend·Sammamish River·BUOY의 Show는 체크되어 있다. |
| 44–53 | 2DH View Settings / 글꼴·축척·회전 — 제목·시간·범례 텍스트의 글꼴을 설정한다(46). 축척 필드 원문은 `E/N Scale Modifiers`이다(48). 적용 제한 원문: `This should only be used for models that only have one active cell across the dimension needing scaling.` (48). 예시 원문은 `a straight river 100 km long (I component) and 100 meters wide (J component)`, `1:1 horizontal scale`, `a scaling factor of 5`이다(48). 회전 필드 원문은 `Model Rotation`이다(50). 북쪽 화살표도 회전에 맞춰 자동 갱신한다(50). 방향·부호 조건 원문: `Rotation is in the clockwise direction, however, the user may also enter a negative angle for counter-clockwise rotation.` (50). 범례 오른쪽 클릭으로 설정에 바로 접근한다(52). |
| 54–66 | 설정·회전 화면과 레이아웃 링크 — 그림 5를 직접 열었다(54–56). 설정 창의 예시 값은 `Easting Scales Modifier: 1`, `Northing Scales Modifier: 1`, `Rotation Angle (°): 0`이다(54행 그림). 그림 6을 직접 열었으며 범례의 시간과 텍스트를 각각 Time·Text 글꼴 설정 버튼으로 연결하는 빨간 화살표를 보여 준다(58–60). 그림 7을 직접 열었다(62–64). 회전된 모델 옆 나침반은 N이 오른쪽, E가 아래, S가 왼쪽, W가 위를 가리키며 축척 막대는 `9000 meters`이다(62행 그림). Save Layout·Load Layout의 설명은 View Layer Control 링크로 안내한다(66). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 22·24: 22행은 Time Scale로 Y축을 조절한다고 적으며 24행은 유량과 압력의 scale 단위를 `days`라고 적는다. 두 표기를 그대로 기록했다.
- 28행 그림 2: Group·Time End 일부 값이 말줄임 표시로 잘려 있으며 뒤의 전체 값은 그림에서 확인할 수 없다.
