# Propwash_Animation_new.md — 판독 구간 기록

구간은 1행부터 34행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–17 | 프로펠러 후류 애니메이션(Propwash Animation) / 선박 궤적 레이어 — 최신 EEMS의 선박 이동 궤적 애니메이션을 개선하여 이동 경로와 선박 뒤 제트(jet) 영향을 관찰하는 기능이라고 적는다(10). 2DH View의 prop wash 그룹에서 ship track 레이어를 추가한다(12). 그림 1을 직접 열었으며 `Primary Group: PropWash`, `Parameter: Ship Track`을 선택하고 Add를 누르는 2DH View Option 창을 보여 준다(14–16). |
| 18–23 | 선박 선택과 초점 설정 — ship track 활성 모드를 켜고 선박을 오른쪽 클릭하면 정보가 표시되고 궤적이 빨간 선으로 강조되며 `Set Focusing Objet` 옵션을 사용할 수 있다고 적는다(18). 그림 2를 직접 열었다(20–22). 왼쪽으로 뾰족한 선박 C-TRACTOR 13과 빨간 궤적, Ship Properties·Set Focusing Object·Unset Focusing Object 메뉴를 보여 준다. 노란 정보 상자의 원문 값은 `Ship Name: C-TRACTOR 13`, `MMSI: 367999999`, `IMO: 9299999`, `USCG:` 빈 값, `Call sign:` 빈 값, `Vessel type: Tug`, `Year built:` 빈 값, `Length: 50.00 m`, `Hull breadth: 18.00 m`, `Hull depth: -999.00 m`, `Min. draft: 4.00 m`, `Max. draft: 5.00 m`, `Gross tonnage: 190`, `Net tonnage: 88`, `Max. power: 4800`, `Num. of propellers: 2`, `Propeller diameter: 2.50 m`, `# Tracks: 1`이다(20행 그림). 이 값은 화면 예시 값이다. |
| 24–29 | 초점을 둔 애니메이션 — `Set Focusing Objet`를 선택하고 주 도구 모음 Animate를 누르면 현재 선박 궤적에 초점을 둔다고 설명한다(24). 그림 3을 직접 열었다(26–28). `2020-01-02 00:30` 화면에서 선박은 왼쪽을 향하고 선박 오른쪽 뒤로 색상 점들이 퍼진 제트 영역이 있다. 유속 범례는 `Velocity (C-TRACTOR 13) (m/s)`이며 `0.000`부터 `0.863`이다(26행 그림). 정지 화면을 확인했으며 실제 애니메이션 실행은 이 판독에 포함하지 않았다. |
| 30–34 | 초점 해제 — 애니메이션 후 오른쪽 클릭하여 `Unset Focusing Object`를 선택한다(30). 그림 4를 직접 열었으며 선박 오른쪽 클릭 메뉴의 Unset Focusing Object를 보여 준다(32–34). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 18·22·24·20행 그림 2: 본문과 캡션은 `Set Focusing Objet`라고 적고 실제 메뉴는 `Set Focusing Object`라고 적는다.
- 10: 기능 제공 판본은 `the latest version of EEMS`라고만 적혀 있으며 판본 번호는 없다.
- 20행 그림 2: 선박의 USCG·Call sign·Year built 값은 비어 있으며 Hull depth는 `-999.00 m`이다. 이 값의 의미는 본문에서 정의하지 않는다.
