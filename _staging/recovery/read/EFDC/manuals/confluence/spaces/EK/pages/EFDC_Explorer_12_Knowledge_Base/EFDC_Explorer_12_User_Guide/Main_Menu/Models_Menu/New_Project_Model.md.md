| 10–15 | New Project Model / 시작 — 메인 도구 모음 또는 Model의 New Model로 새 프로젝트를 생성한다(10). Cartesian Grid Generator는 네 격자 생성 옵션을 제공한다(12). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246613088/1.png`를 직접 열었으며 빈 메인 화면에서 New Model 도구 모음 아이콘을 빨간 사각형으로 표시한다(14). 원문: `This function is used to create a new project model. To create a new project model, the user can either click on *New Model*on the main toolbar or select *New Model* from the *Model* menu as shown in [New Project Model#Figure 1](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/246613088#NewProjectModel-Figure1).` (10); `Then the form *Cartesian* *Grid Generator* appears. There are four options to create a new grid from this form.` (12); `![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/246613088/1.png?version=1&modificationDate=1638503294078&cacheVersion=1&api=v2&width=680&height=458)` (14). |
| 16–27 | Generate Uniform Grid — 왼쪽 아래·오른쪽 위 좌표와 셀 크기를 입력하고 X·Y 셀 수를 계산한다(20). 회전 각도(rotation angle)를 입력할 수 있다(22). 기존 다각형 파일의 적용 조건과 바깥 셀을 제거하는 절차를 원문 그대로 옮긴다(24). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246613088/3.png`를 직접 열었다(26). 화면의 X·Y 값은 `Lower-Left (m): 584039.705, 2327048.908`, `Upper-Right (m): 587120.017, 2330544.211`, `Cell Size (m): 50.000, 50.000`, `Number of Cells: 62, 70`, `Rotation Angle (°): 0`, `UTM Zone: 48`이다(26, 그림). Bounding Polygons의 `Outline of West Lake`와 Add Files 메뉴를 보여 준다(26, 그림). 격자 그림은 파란 다각형 경계 내부를 초록 격자, 외부를 회색 격자로 표시하고 빨간 외곽 사각형에 P1 아래·P2 오른쪽·P3 위·P4 왼쪽을 붙인다(26, 그림). 좌표 눈금이나 화살표는 없다(26, 그림). 원문: `## Generate Uniform Grid` (16); `This option allows the user to generate a uniform grid as shown in [New Project Model#Figure 2](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/246613088#NewProjectModel-Figure2).` (18); `The user enters the lower-left and the upper-right coordinates, next, set cell size then click the Calculator of the *Number of Cells* to update the number of cells in the X and Y directions.` (20); `The *Rotation Angle* can be entered to rotate a uniform grid.` (22); `In case the user wants to generate a uniform grid from an existing polygon file, the user can RMC on the *Bounding Polygons* and select *Add Files* to browse the file. After opening the polygon file, the coordinates of the lower-left and the upper-right will be updated. Click the *Generate* button to generate grid, to remove cells that are outside of the polygon by clicking the *Remove Dry* button. Finally, click *OK* button.` (24); `![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/246613088/3.png?version=1&modificationDate=1638505191598&cacheVersion=1&api=v2&width=680&height=460)` (26). |
| 28–33 | Generate Radial Grid — 방사형 격자(radial grid) 생성을 안내한다(30). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246613088/4.png`를 직접 열었다(32). 화면 값은 `Focal Point (m): 0, 0`, `Start Angle (°): 30`, `End Angle (°): 150`, `Angular Step (°): 3`, `Radius Range (m): 4861.608, 20000`, `# Cells Along A: 40`, `# Cells Along R: 27`, `Aspect Ratio: 1`, `UTM Zone: 0`이다(32, 그림). 격자 그림은 중심점 오른쪽에 펼쳐진 고리 부채꼴이며 초록 격자와 빨간 외곽선, 내측 중앙 P1·상단 P2·외측 중앙 P3·하단 P4를 보여 준다(32, 그림). 좌표 눈금은 없다(32, 그림). 원문: `## Generate Radial Grid` (28); `This option allows generating radial grid as shown in [New Project Model#Figure 3](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/246613088#NewProjectModel-Figure3).` (30); `![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/246613088/4.png?version=1&modificationDate=1638505353538&cacheVersion=1&api=v2&width=680&height=460)` (32). |
| 34–39 | Generate Telescoping Grid — 절 제목은 telescoping 격자이지만 설명 문장은 radial grid라고 적는다(34–36). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246613088/5.png`를 직접 열었다(38). X·Y 값은 `Lower-Left (m): 0, 0`, `Upper-Right (m): 5000, 5000`, `Focal Point (m): 2500, 2500`, `Min. Cell Size (m): 87.300, 87.300`, `Max. Cell Size (m): 533.910, 533.910`, `Growth Factor: 1.100, 1.100`, `Number of Cells: 30, 30`, `Rotation Angle (°): 0`, `UTM Zone: 0`이다(38, 그림). 빨간 사각 외곽 안의 초록 직교 격자(orthogonal grid)는 중앙 초점(focal point) 부근에서 촘촘하고 가장자리로 갈수록 간격이 커진다(38, 그림). P1은 아래, P2는 오른쪽, P3는 위, P4는 왼쪽에 있다(38, 그림). 좌표 눈금은 없다(38, 그림). 원문: `## Generate Telescoping Grid` (34); `This option allows generating radial grid as shown in [New Project Model#Figure 4](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/246613088#NewProjectModel-Figure4).` (36); `![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/246613088/5.png?version=2&modificationDate=1638505467594&cacheVersion=1&api=v2&width=680&height=460)` (38). |
| 40–48 | Import Grid from Files — 지원 형식 예시와 Import Grid에서 형식·파일을 선택하는 절차를 설명한다(42–44). UTM Zone은 계산에는 쓰지 않지만 좌표 변환·GIS 출력·온라인 자료 다운로드에는 중요하며 올바른 값으로 갱신해야 할 수 있다고 적는다(46). 조건·부정·불확실성을 원문 그대로 옮긴다. 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246613088/2.png`를 직접 열었다(48). 빨간 화살표는 Import Grids 버튼에서 Import Grid 폼으로 향한다(48, 그림). Grid Type 목록은 `CVLGrid`, `RGFGrid`, `Grid95`, `DXDY/LXLY`, `ECOMSED`, `SEAGRID`, `CH3D`, `Corners(4)`이다(48, 그림). 화면은 Grid file·Browse, 미선택 Multiple Grid Files, 비활성 Auto Rotate Grid와 `UTM Zone: 0`을 보여 준다(48, 그림). 원문: `## Import Grid from Files` (40); `This option allows the user to import an existing grid file from multiple formats (for example CVLGrid, RGFGrid, GRID95) as shown in [New Project Model#Figure 5](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/246613088#NewProjectModel-Figure5).` (42); `After clicking the *Import Grid* button, the *Import Grid* form will appear to allow the user to select grid type from the drop-down list, then click the *Browse* button to browse to the grid file.` (44); `The user may need to update *UTM Zone* with a correct value before clicking *OK* button to generate a new model. The *UTM Zone* is not used for model computation but it is important to coordinate conversion, exporting to GIS formats as well as for downloading online data.` (46); `![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/246613088/2.png?version=1&modificationDate=1638503857822&cacheVersion=1&api=v2&width=680&height=460)` (48). |
