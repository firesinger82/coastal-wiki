# Generate_Image.md — 판독 구간 기록

구간은 1행부터 22행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–15 | 문서 메타데이터 — 페이지 ID·제목·space·URL·판본·갱신 시각·문서 경로와 frontmatter 구분자를 포함한다(1–9). Generate Image / Export Graphic to file — 이미지 내보내기와 파일 이름·폴더 선택을 설명한다(10·12). 비트맵(bitmap)의 해상도·크기·종횡비와 파일 형식을 설정할 수 있다(12). 설정·단위 원문: `Figure 2 shows the form of *Export Graphic to file,* the user should select a name for the image and select the folder to save the image by clicking the *Browse* button. In *Bitmap Settings,* the user can set *Bitmap Resolution (dpi), Size X* and *Size Y* or check the box to *Lock Aspect Ratio*. EFDC+ Explorer supports saving the images in several forms, by selecting the list of files in the *File Type* drop-list.` (12). 기본 저장 경로 원문: `Then click the *OK* button to finish, by default the image will be saved in the *#analysis*folder of the active model.` (14). 빈 줄을 포함한다(11·13·15). |
| 16–22 | Generate Image 화면 — Figure 1과 Figure 2의 로컬 그림을 모두 열었다(16·20). Figure 1은 2DV View 메뉴의 Generate Image 선택 화면이다(16–18). Figure 2는 Export Graphic to file 설정 화면이다(20–22). 화면 예시값은 `Bitmap Resolution (dpi): 96`, `Size X: 944`, `Size Y: 776`, `File Type: .png`이다(20행 그림). `Lock Aspect Ratio`는 선택되어 있고 `Save the Layout`은 선택되지 않았다(20행 그림). 본문은 예시값의 기본값 여부와 Size X·Size Y의 단위를 명시하지 않는다. 빈 줄·그림 마크업·캡션을 포함한다(16–22). |
