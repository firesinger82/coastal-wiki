# Sediment_Visualization.md — 판독 구간 기록

구간은 1행부터 34행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터. Sediment Visualization의 식별자·제목·space·URL·버전·갱신 시각·계층 경로가 있다 (2–8). |
| 10–15 | 수주(water column) 퇴적물의 2DH 시각화. 본문 앞에 색상 CSS가 있다 (10). 항목은 `Total Suspended Sediments, Cohesive Sediment, and Non-cohesive Sediment.` (10)이다. 12행 그림은 2DH View Option에서 `Base Model: Orginal Sediment Model; Primary Group: Water Column; Parameter: Total Suspended Sediments; Options: Depth Average` (12행 그림)를 선택한 화면이다. 목록에는 Salinity도 보인다 (12행 그림). |
| 16–21 | 퇴적층(sediment bed) 시각화. 항목은 `Bed Top Layer, Bed Thickness, Bed Density, Bed Porosity, Bed Mass, Bed Mass Fraction, Bed d50, Bed Delta, and Bed Topography.` (16)이다. 18행 그림은 `Base Model: Orginal Sediment Model; Primary Group: Sediment Bed; Parameter: Bed Top Layer` (18행 그림)와 같은 항목의 드롭다운을 보여 준다. |
| 22–27 | SEDZLJ 전용 보기. 항목은 `SEDZLJ Core ID, SEDZLJ Skin Friction, SEDZLJ D50 (Active Layer), SEDZLJ Erosion Rate, SEDZLJ Deposition Rate, Net Deposition/Erosion Rate, SEDZLJ Bedload Chemical Fate and Transport, SEDZLJ Bedload Flux, SEDZLJ Bedload Vector, and SEDZLJ Bedload Mass.` (22)이다. 24행 그림은 Base Model SEDZLJ Model, Primary Group Sediment Bed로 이 드롭다운을 보여 준다. Compare Model은 미선택이며 비활성 비교 모델 필드에는 Orginal Sediment Model이 보인다 (24행 그림). |
| 28–34 | 침식률·퇴적률·순교환율의 퇴적물 종류 선택. 적용 항목은 `*SEDZLJ Erosion Rate, SEDZLJ Deposition Rate,* and*SEDZLJ Net Deposition/Erosion Rate*` (28)이다. 30행 그림은 `Base Model: EE; Primary Group: Sediment Bed; Parameter: SEDZLJ Erosion Rate; Time Setting: 0.0003` (30행 그림)이다. Class 목록은 `(SED) Class 1` (30행 그림); `(SED) Class 2` (30행 그림); `(SED) Class 3` (30행 그림); `(SED) Class 4` (30행 그림); `(SED) Class 5` (30행 그림); `(SED) Class 6` (30행 그림); `(SED) Class 7` (30행 그림); `(SED) Class 8` (30행 그림); `(SED) Class 9` (30행 그림); `(SED) Class 10` (30행 그림); `(SED) Class 11` (30행 그림); `(SED) Class 12` (30행 그림); `(SED) Class 13` (30행 그림); `(SND) Class 14` (30행 그림); `(SND) Class 15` (30행 그림)이다. Total과 Fixed는 미선택이다. 시계열·수직 및 종단 프로필(Time Series, Vertical Profiles, Longitudinal Profiles) 방법은 Salinity Visualization 링크를 참조한다고 적는다 (34). |
