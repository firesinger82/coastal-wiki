Time Shift는 UTC 0 기준 조화상수(harmonic constants)의 위상 지연(phase lag)을 모델의 현지 시각에 맞추는 시간 이동이며 단위는 hours이다(102). 절 제목·번호 목록·빈 줄을 포함한다(78–103). |
