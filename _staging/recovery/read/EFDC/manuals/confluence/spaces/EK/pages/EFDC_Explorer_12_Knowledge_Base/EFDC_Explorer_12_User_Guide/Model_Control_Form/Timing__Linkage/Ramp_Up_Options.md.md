# Ramp_Up_Options.md — 판독 구간 기록

구간은 1행부터 12행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — Ramp Up Options의 페이지 ID, URL, 버전, 갱신 시각, 계층을 수록한다(1–9). |
| 10–12 | Ramp Up Options — 초기조건(initial conditions, ICs)에서 전체 물리과정으로 전환하는 시간과 부력(buoyancy)·비선형항(non-linear terms)의 단계적 적용을 설명한다(10). 범위·조건·설정 절차 원문: `Buoyancy can be adjusted with a buoyancy factor that must be between 0 and 1, with 0 being no buoyancy influence and 1 being full buoyancy influence. For some applications, the ramp up time from the ICs to natural physics require the phasing in of the buoyancy and the non-linear terms. This is accomplished using the *Modify* button and applying number of ramp up iterations for the various options.` (10) 로컬 그림을 직접 열었다(12). Timing Parameters to Ramp Up to Full Dynamics 대화창이며 화면 값은 `Number of reference periods to full Buoyancy Influence: 0`, `Number of reference periods for Linearized Solution: 0`, `Number of reference periods to phase in Non-Linear Solution: 0`이다(12 그림). |
