| 24–39 | Add New Graticule Layer — 경위선(graticule) 레이어의 위치와 선 간격을 설정한다(24–26). 좌표 단위 원문: `This can be used to show the location in geographic coordinates (degrees latitude and longitude).` (26) `Properties`로 `Graticule Settings`를 연다(26). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/278757474/2019-05-03_3-50-40_PM.jpg`을 열었다(28). 그림 3은 Graticule Lines의 Properties 메뉴이다(28행 그림). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/278757474/2019-05-03_3-48-40_PM.jpg`을 열었다(32). 그림 4는 Graticule Settings 창이다(32행 그림). 표시 예는 `System: WGS 84`, `UTM Zone: Zone 10`, `Interval Units: meter (m)`이다(32행 그림). `Use Geographic Coordinates`는 선택되지 않았다(32행 그림). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/278757474/2019-05-03_3-24-39_PM.jpg`을 열었다(36). 그림 5는 저면고 격자와 좌표선을 함께 표시한다(36행 그림). 가로 위치의 좌표 표시는 `549894`, `554894`, `559894`이다(36행 그림). 세로 위치의 좌표 표시는 위에서 아래로 `5294390`, `5289390`, `5284390`, `5279390`, `5274390`, `5269390`, `5264390`, `5259390`이다(36행 그림). 저면고 색상 범례는 `Bottom Elevation (m)`의 `-59.840`–`10.812`이다(36행 그림). 캡션과 빈 줄을 포함한다(30·34·38–39). |
| 40–51 | Add New XYZ Scatter Layer — XYZ 산점(scatter) 레이어와 새 데이터 점을 추가한다(40–42). 매개변수·단위·초기값 원문: `RMC on the *2DH View* window then select *Create New Data Point* which displays the *Data Point* form, in which X and Y are coordinates in meters of each point, Z is the third field which could be elevation or concentration etc.` (42) `The initial value of Z is zero and the user can edit this value by entering a new value.` (42) X·Y를 새로 입력하여 좌표를 갱신하고 Properties·Export·Remove 메뉴를 사용한다(42). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/278757474/2019-05-06_10-52-12_AM.jpg`을 열었다(44). 그림 6은 새 데이터 점 메뉴와 Data Point 창이다(44행 그림). 표시 예는 `X (m): 549735.10`, `Y (m): 5281875.16`, `Z (m): 8`이다(44행 그림). 빨간 화살표가 메뉴와 대화상자를 가리킨다(44행 그림). 저면고 색상 범례의 양 끝 값은 `-59.840`, `10.812`이고 단위는 `m`이다(44행 그림). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/278757474/2019-05-06_11-07-56_AM.jpg`을 열었다(48). 그림 7은 XYZ 레이어의 Properties 메뉴와 Scatter Data Properties 창이다(48행 그림). 캡션과 빈 줄을 포함한다(46·50–51). |
| 52–63 | Add New Label Layer — 라벨(label) 레이어를 추가하고 Create New Label로 Label Properties 창을 연다(52–54). 좌표·정보 원문: `in which X and Y are coordinates in meters, Z is a third field containing information of the point such as elevation` (54) 초기값·적용 목적 원문: `The initial value of Z is 9999999.88 to make sure that the label is not covered by other layers.` (54) 이름·기호·색·글꼴을 바꾸고 Properties·Import·Export·Remove 메뉴를 사용한다(54). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/278757474/2019-05-06_1-53-05_PM.jpg`을 열었다(56). 그림 8은 Create New Label 메뉴와 Station 1의 Label Properties 창이다(56행 그림). 표시 예는 `X (m): 543808.56`, `Y (m): 5285902.00`, `Z (m): 0.00`이다(56행 그림). `LMC here` 설명 상자가 왼쪽 위의 메뉴를 가리킨다(56행 그림). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/278757474/2019-05-06_4-52-03_PM.jpg`을 열었다(60). 그림 9는 Station 라벨 표식과 레이어 메뉴를 보여 준다(60행 그림). 색상 범례는 `Water Depth (m)`의 `0.072`–`65.933`과 `Bottom Elevation (m)`의 `-59.840`–`10.812`이다(60행 그림). 캡션과 빈 줄을 포함한다(58·62–63). |
