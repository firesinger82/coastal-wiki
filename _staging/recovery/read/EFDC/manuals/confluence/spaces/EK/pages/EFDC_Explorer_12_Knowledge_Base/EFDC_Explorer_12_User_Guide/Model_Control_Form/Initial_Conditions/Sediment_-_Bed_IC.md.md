| 34–39 | Use Polygon DSM — 제3자 도구의 디지털 퇴적물 모델(digital sediment model, DSM)을 읽어 EFDC 퇴적물 파일을 만든다(34–36). 입력 순서 원문: `The DSM format requires a polygon followed by the layer thickness, bulk density, porosity, and grain size distribution for each depth available (sediment depth intervals are based on data).` (36) 입경 경계의 정의 원문: `The "Max (μm)" sediment diameters, one for each sediment class, are needed to break the sediment grain size curves into ranges.` (36) `These diameters are not class diameters but represent the grain size breakpoints whose geometric mean of the upper and lower limits is the corresponding sediment class' diameter.` (36) Apply는 메모리에서 퇴적물 지도를 만들고 파일을 쓴다(38). 기존 지도 대체·저장 권고 원문: `The current sediment map (if any) will be replaced by the new one.` (38) `It is recommended that the project be saved into a new sub-directory prior to implementing this option in order to save different versions of the sediment bed configurations.` (38) 절 제목·빈 줄을 포함한다(34–39).
