| 10–13 | Model Nesting / 격자 그림 — 거친 격자(coarse grid)와 모델을 만든 뒤 세부 분석용 미세 격자(finer grid)를 그 안에 중첩(nesting)할 수 있다고 적는다(10). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/263159874/image2019-9-10_17-8-15.png`를 직접 열었다(12). 그림은 전체 수로의 붉은 `Coarse_grid`와 오른쪽 지류 일부에 겹친 더 촘촘한 파란 `Nested_grid`를 보여 준다(12). 축·좌표 값·교환 화살표는 표시되어 있지 않다(12, 그림). 원문: `EE10 has several functions designed to support the generation of nested models. These are accessed using the *Model Nesting* option in the *Models* menu. Once a user has created a coarse grid and model, a finer grid may be nested into the coarse grid for more detailed analysis. In [Figure 1](#Figure1)two grids are shown: a large coarse grid (red), and a more refined nested grid (blue).` (10); `![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/263159874/image2019-9-10_17-8-15.png?version=1&modificationDate=1568110097942&cacheVersion=1&api=v2&width=646&height=606)` (12). |
| 14–19 | 모델 로드와 메뉴 / Figure 2 — 큰 모델과 중첩 모델을 모두 로드하고 중첩 모델에는 경계 조건을 설정해야 하며 기준일(base date)은 큰 모델과 같아야 한다(14). 의무 조건을 원문 그대로 옮긴다(14). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/263159874/2019-09-10_5-14-45_PM.png`를 직접 열었으며 Model Nesting 메뉴가 선택된 화면을 보여 준다(16). 원문: `To use this function, firstly, open EE then loads the two models, large model, and nested model, the nested model must be set boundary conditions and have the same base date as the large model. Then click *Model* from the main menu, then select *Model Nesting* as shown in [Model Nesting#Figure 2](#Figure2).` (14); `![](https://eemodelingsystem.atlassian.net/wiki/download/attachments/263159874/2019-09-10%205-14-45%20PM.png?version=1&modificationDate=1568110525355&cacheVersion=1&api=v2)` (16); `The *Model Nesting* form appears as shown in [Model Nesting#Figure 3](#Figure3).` (18). |
| 20–35 | 큰 모델·세부 모델과 중첩 옵션 — 두 모델 선택 및 자동 갱신되는 시작·종료 시간을 설명한다(20–30). 시간이 다를 때 큰 모델의 시간 구간이 세부 모델의 시간 구간을 포함하도록 조정해야 한다(30). 큰 모델에서 가져올 네 체크 옵션을 설명한다(32–34). 필드 이름과 적용 조건을 원문 그대로 옮긴다. 원문: `In the *Large Model* frame:` (20); `*Select Model:* from the drop-down list, the user selects the large model (e.g Coarse\_Model)` (22); `*Time Begin* and *Time* End: two of these fields are updated automatically from the model.` (24); `In the *Detail Model* frame:` (26); `*Select Model:* from the drop-down list, the user selects the nested model (e.g Nested\_Model)` (28); `*Time Begin* and *Time* End: two of these fields are updated automatically from the model. however if it is different from the time of the large model, the user must adjust it so that the time of the large model covers the time of the detailed model.` (30); `In the *Nesting Options* frame:` (32); `There are four checkboxes, *Bottom Elevation, Boundary Conditions, Initial Conditions, Restart Files.* The check-boxes allow the user selects options from the large model that will be taken to the nested model.` (34). |
| 36–41 | 경계 위치의 주의 조건과 실행 / Figures 3–4 — 거친 모델의 경계 셀을 중첩 모델 경계로 선택하면 출력 추출 대신 거친 모델의 기존 경계 데이터 계열을 쓴다고 적는다(36). 문서는 경계 셀 회피·안쪽 이동·삭제의 대응을 제시한다(36). 해당 조건과 권고를 원문 그대로 옮긴다. OK 이후 완료 메시지를 설명한다(38). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/263159874/2019-09-10_5-09-40_PM.png`와 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/263159874/2019-07-26_2-32-05_PM.png`를 직접 열었다(40). 첫 그림은 `Coarse_Model`과 `Nested_Model` 선택, 두 모델에 같은 `Time Begin: 2015-06-01 00:00:00`, `Time End: 2015-09-30 00:00:00`을 보여 준다(40, 그림). Bottom Elevation·Boundary Conditions·Initial Conditions는 선택되어 있고 Restart Files는 비활성·미선택 상태이다(40, 그림). 두 번째 그림은 `Work completed in 0:00:00:08.3776788!` 메시지를 보여 준다(40, 그림). 원문: `It is recommended that the user pays special attention when selecting the boundary locations for the nested model at the cells in the coarse model which are those used as boundary conditions in the coarse model. This is because EE will use the existing boundary data series from the coarse model for those cells instead of extracting model output. The solution is to avoid the boundary cells in the coarse model, or move the boundary cells further inside, or delete them.` (36); `Finally, click *OK* button to start the process of nesting. A message informs the nesting process completed as shown in [Figure 4.](#Figure4)` (38); `![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/263159874/2019-09-10%205-09-40%20PM.png?version=1&modificationDate=1568110264238&cacheVersion=1&api=v2&width=414&height=470)![](https://eemodelingsystem.atlassian.net/wiki/download/attachments/263159874/2019-07-26%202-32-05%20PM.png?version=1&modificationDate=1564126407596&cacheVersion=1&api=v2)` (40). |
| 42–48 | 생성 결과·후속 설정·비교 그래프 / Figure 5 — 도구는 각 경계 셀의 시계열을 추출·생성하고 대응 경계 조건에 배정하며 중첩 모델 모듈의 초기 조건을 설정한다고 적는다(42). 사용자는 나머지 유체역학(hydrodynamics) 설정을 거친 모델과 같게 갱신해야 하며 필요하면 더 많은 모듈을 켤 수 있다(44). 의무·가능 조건을 원문 그대로 옮긴다. 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/263159874/2019-09-24_4-34-29_PM.png`를 직접 열었다(48). 그래프 제목은 `Coarse Model`이고 가로축은 `Time (days)`이다(48, 그림). 가로 눈금은 `553.98, 555.60, 557.21, 558.82, 560.44, 562.05, 563.66, 565.28, 566.89, 568.51, 570.12`이다(48, 그림). 세로축은 `Salinity (ppt)`이고 눈금은 `-0.80, 0.00, 0.80, 1.60, 2.40, 3.20, 4.00, 4.80, 5.60, 6.40, 7.20`이다(48, 그림). 범례는 붉은 `Coarse Model, Salinity (Depth Avg.)`와 파란 `Nested Model, Salinity (Depth Avg.)`이다(48, 그림). 두 선은 반복되는 봉우리를 보여 주며 일부 시각에서 서로 떨어져 있다(48, 그림). 원문: `The nesting tool will extract and build a time series for each boundary condition cell. It will also assign the time series to the corresponding boundary conditions and set the initial conditions for the modules in the nested model.` (42); `The user needs to update the rest of the *Hydrodynamics* for the Nested model, the same as the Coarse model and can then activate more modules if required.` (44); `An example of a comparison of time series output between the finer grid model and the coarse grid model is shown in [Model Nesting#Figure 5](#Figure5).` (46); `![](https://eemodelingsystem.atlassian.net/wiki/download/attachments/263159874/2019-09-24%204-34-29%20PM.png?version=1&modificationDate=1569317694902&cacheVersion=1&api=v2)` (48). |
