# Velocity_Rose.md — 판독 구간 기록

구간은 1행부터 40행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–17 | 유속 장미(Velocity Rose) / 진입 — CSS 색상 마크업 뒤에 EEMS11.2부터 셀의 사용자 지정 기간 유속 크기·방향 분포를 표시한다고 적는다(10). 2DH View에 유속 레이어를 추가하고 활성 모드를 켠 뒤 셀을 선택한다(12). 그림 1을 직접 열었으며 Velocity Magnitude (Depth Avg.) 레이어와 View Rose Plot 메뉴를 보여 준다(14–16). |
| 18–23 | 기간 설정 — 셀 오른쪽 클릭의 View Rose Plot에서 전체 모델 기간 안의 시각을 고르고 OK를 누른다(18). 시간 형식 원문은 `Julian date format`이다(18). 그림 2를 직접 열었다(20–22). 창 제목 범위는 `455 to 820`이며 표의 두 행은 `Start time: 455`, `End time: 600`이다. 값은 화면 예시 값이다. |
| 24–29 | 그림 3 / 유속 장미 — 셀 위치·기간은 그림 위에 나타나며 2DH View에 붙이거나 별도 창으로 띄울 수 있다(24). 그림 3을 직접 열었다(26–28). 셀 표기는 `L=443; I,J=19, 18`, 기간은 `From 2003-04-01 to 2003-08-23`이다. 16방위는 N·NNE·NE·ENE·E·ESE·SE·SSE·S·SSW·SW·WSW·W·WNW·NW·NNW이며 N은 위, E는 오른쪽이다. 파란 부채꼴은 주로 NE와 SW 방향에 있다. 중심은 `Calm 0.00%`이며 `3480 records used.`와 `Direction is coming from.`을 표시한다. 유속 범례 `Velocity (m/s)`의 파랑은 `0 - 2.49`, 빨강은 `≥ 2.49`이다(26행 그림). |
| 30–35 | Rose Plot Utility / 설정과 출력 — Settings에서 레이블·축척·방위 구간(sector)을 편집하며 Save·Load로 형식을 재사용한다(30). 비트맵과 Windows 메타파일(Windows metafile)로 내보낼 수 있다(30). 그림 4를 직접 열었다(32–34). 그림 3과 같은 셀·기간·방위·색상 구간·정온(calm) 비율·자료 수를 별도 창에 표시한다. 반지름 눈금은 퍼센트이며 바깥쪽 눈금은 `50%`이다. 안쪽 눈금 문자가 SW 부채꼴과 겹치는 부분이 있다(32행 그림). |
| 36–40 | 여러 유속 장미와 `Rose Frames` — 여러 셀 선택으로 여러 그림을 표시하고 `Rose Frames`로 위치·기간 상세 목록을 연다(36). 그림 5를 직접 열었다(38–40). List of Roses 표의 첫 행은 ID `L=443; I,J=19, 18`, `Time Begin` `455`, `Time End` `600`, `Show` 체크이며 둘째 행은 ID `L=2011; I,J=69, 49`, `Time Begin` `455`, `Time End` `500`, `Show` 체크이다. 둘째 유속 장미의 기간은 `From 2003-04-01 to 2003-05-15`, 중심은 `Calm 0.00%`, 자료 수는 `1080 records used.`이다. 방향은 `Direction is coming from.`이며 파랑 구간은 `0 - 1.15`, 빨강 구간은 `≥ 1.15`, 단위는 `Velocity (m/s)`이다. 부채꼴은 주로 ESE와 WNW에 있으며 반지름 눈금 일부가 겹쳐 있다(38행 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10·38행 그림 5: 본문은 EEMS11.2부터 제공한다고 적는다. 그림 5의 창 제목은 `EFDC_Explorer10.4.0`으로 표시되어 있다.
- 32·38행 그림: 반지름의 일부 퍼센트 눈금은 부채꼴·문자와 겹쳐 모든 값을 명확히 판독할 수 없다.
