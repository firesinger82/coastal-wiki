# Import_Structures.md — 판독 구간 기록

구간은 1행부터 22행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–17 | 문서 메타데이터 — 페이지 ID·제목·space·URL·판본·갱신 시각·문서 경로와 frontmatter 구분자를 포함한다(1–9). Import Structures / 구조물 형식 — 3D View의 시각화용 구조물(structure)을 외부 층으로 불러오는 기능을 설명한다(10·12). 10행은 COLLADA를 `COLLAborative Design Activity`라고 풀어 쓰고 `.DAE` 확장자와 XML 스키마(XML schema)를 설명하며 ISO/PAS 17506이라는 문서 이름을 적는다. 이 내용은 해당 문서의 설명으로 기록했다. 형식 원문: `EE10 allows users to import pre-defined structures for visualization using *3DView* tool. This allows users to get a better feel for the model domain by displaying significant engineering structures in the model domain. Any COLLADA file can now be imported to 3D View as an overlay file. COLLADA stands for "COLLAborative Design Activity" and is an interchange [file format](https://en.wikipedia.org/wiki/File_format) for interactive [3D](https://en.wikipedia.org/wiki/3-D_computer_graphics) applications. It has a “.DAE” extension (digital asset exchange) adds defines an [open standard](https://en.wikipedia.org/wiki/Open_standard) [XML schema](https://en.wikipedia.org/wiki/XML_schema) for exchanging [digital assets](https://en.wikipedia.org/wiki/Digital_asset) among various graphics. COLLADA has been adopted by ISO as a publicly available specification, ISO/PAS 17506.` (10). 형식 선택 절차 원문: `To add the 3D structure to 3DView, users can add external layers and select the format of 3D Overlay Object.` (12). Figure 1의 로컬 그림을 열었다(14–16). 그림은 Import External Layer 버튼을 가리키는 설명선과 Open External Layer 파일 선택 화면이다. 목록의 형식은 `3D Overlay Objects (*.dae;*.obj;*.stl;*.ply;*.3mf)`이고 `baichay_bridge.dae` 파일이 보인다(14행 그림). 배경 모델의 방향 표시는 X가 오른쪽, Y가 위쪽, Z가 왼쪽이다(14행 그림). 별도 축 눈금은 없다. 빈 줄·그림 마크업·캡션을 포함한다(11·13–17). |
| 18–22 | 3D Object Settings — 층의 Properties에서 X·Y·Z 좌표별 위치(position)·축척(scale)·회전(rotation)을 바꿀 수 있다(18). 설정 원문: `Once loaded in, users have extra flexibility to adjust the position of the 3D Object. When users active the layer and select properties, the 3D Object Settings form can be displayed. In this form, the position, scale as well as the angular rotation of the 3D Object are available to be adjusted along X, Y, Z coordinates ( as shown in [Import Structures#Figure 2](#Figure2)).` (18). Figure 2의 로컬 그림을 열었다(20–22). 그림은 모델 영역의 교량, 층의 Properties 메뉴, 아래쪽 설정 창을 보여 준다. 붉은 화살표는 Properties 메뉴 아래에서 3D Object Settings 창을 향해 아래로 내려간다(20행 그림). 화면 예시값은 `Name: baichay_bridge`; `Position`의 `X: 0`, `Y: 0`, `Z: 0`; `Scale`의 `X: 1`, `Y: 1`, `Z: 1`; `Rotation`의 `X: 0`, `Y: 0`, `Z: 0`이다(20행 그림). `Show in Legend`는 선택되고 `Change Object Color`는 선택되지 않았다. `Object Color` 선택란이 회색으로 보인다(20행 그림). 본문은 이 예시값의 기본값 여부와 위치·회전의 단위를 명시하지 않는다. 빈 줄·그림 마크업·캡션을 포함한다(19–22). |

- 18행의 그림 링크는 `#Figure2`를 가리킨다. 이 파일에는 해당 ID 선언이 없고 22행은 굵은 글씨 캡션이다.
