| 10–19 | 좌표계(coordinate system) 개요. EEMS 12 이전에 Cartesian과 UTM만 지원했다고 적는다. Cartesian 계산 격자의 X·Y 단위는 `meters` (10)이다. 여러 UTM 구역(zone)에 걸친 모델 격자에서 두 좌표계의 한계를 언급한다(10). EEMS 12의 지리 좌표계(Geographic Coordinate System) 도입, 기존 한계 해소 및 기초 투영(projection) 역할을 서술한다(12–18). 경도(longitude)와 위도(latitude)로 2차원 좌표를 정의하면 단일 투영의 시각화 정확도를 유지하며 모델·데이터의 공간 왜곡을 피한다고 적는다(18). |
| 20–23 | 새 모델의 투영 선택. New Model → Cartesian Grid Generator의 Model Projection / Set → Coordinate System의 목록으로 투영을 설정한다(20). 그림 22는 Set 버튼에서 좌표계 창으로 향하는 빨간 화살표를 보여 준다. 목록 항목은 `Geographic (Longitude/Latitude)` (22), `UTM, Northern Hemisphere` (22), `UTM, Southern Hemisphere` (22), `User Defined` (22), `No Projection` (22), `Favourites` (22)이다. |
| 24–29 | 격자 가져오기와 모델·격자 투영의 관계. 같은 좌표계를 쓰는 다중 격자의 선택 상자 및 파일 가져오기 절차와, 격자 파일의 투영이 다를 때 Model Projection을 격자 투영으로 갱신하는 조건을 그대로 옮긴다: `For example, we select the *Geographic (Longitude/Latitude)* option, then click the *OK* button, and the Coordinate System form will close. If we want to create a new model from multiple grids with the same coordinate system, we can check the checkbox "Use the same projection for all grids". After selecting Model Projection, we can import a grid from a file by clicking the *Import Grids* button. The *Import Grid* form will then pop up; from this form, we select grid type and then select the grid file by clicking the browse button. If we want to import multiple grids at once, we can check the checkbox "Multiple Grid Files.", as shown in [Setting the Coordinate System#Figure 2](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2515828737#SettingtheCoordinateSystem-Figure2).` (24) `Click the *OK* button, the *Import Grid* form closes, the Coordinate System form will display again to remind the user. Notice that the projection information shown in this form can be different from the projection in the Model Projection we set previously, as it is based on projection information from the grid file. [Setting the Coordinate System#Figure 3](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2515828737#SettingtheCoordinateSystem-Figure3) shows a case of grid and model projection having the same projection (e.g., geographic). While [Setting the Coordinate System#Figure 4](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2515828737#SettingtheCoordinateSystem-Figure4) shows a case of grid and model projection having different projections, and in this case, when clicking the OK button, the projection in the Model Projection will be updated as the projection in the grid file.` (26) 그림 28의 2.jpg는 Import Grids에서 Import Grid 창으로 향하는 화살표, `Grid Type: Grid+` (28)와 Multiple Grid Files 선택 상자를 보여 준다. 같은 행의 3.jpg는 WGS84 지리 좌표계가 모델·격자에 일치하는 화면이다. 공간 참조 정보(spatial reference information)의 `SPHEROID["WGS 84", 6378137, 298.257223563` (28), `UNIT["degree", 0.017453292519943295` (28), `AUTHORITY["EPSG", "4326"]` (28)가 보인다. 같은 행의 4.jpg는 모델의 WGS84 지리 좌표계와 가져온 격자의 `UTM, Northern Hemisphere` (28), `UTM Zone 17 (84°W – 78°W)` (28)를 대조한다. 매개변수 구문은 `PARAMETER["latitude_of_origin", 0]` (28), `PARAMETER["central_meridian", -81]` (28), `PARAMETER["scale_factor", 0.9996]` (28), `PARAMETER["false_easting", 500000]` (28), `PARAMETER["false_northing", 0]` (28), `UNIT["metre", 1, AUTHORITY["EPSG", "9001"]]` (28)이다. |
| 30–33 | 기존 모델의 좌표계 변경. | 34–40 | 다섯 참조 좌표계. Geographic의 WGS 1984 적용, Northern Hemisphere의 UTM 구역 범위 1–60, Southern Hemisphere의 별도 구역 선택 및 User Defined에서 활성화되는 Define·Import·Download를 원문으로 보존한다: `- *Geographic (Longitude/Latitude)*: Selecting this applies the World Geodetic System (WGS) 1984 to the project.` (36) `- *UTM, Northern Hemisphere*: Selecting this applies the Universal Transverse Mercator (UTM) - Northern Hemisphere projection. A drop-down menu will be enabled for specifying the UTM Zone (from 1 to 60).` (37) `- *UTM, Southern Hemisphere*: Selecting this applies the UTM - Southern Hemisphere projection. Similar to the *UTM, Northern Hemisphere*, users need to select a UTM Zone for this CS in the second drop-down menu.` (38) `- *User* Defined: Besides the predefined WGS 1984 geographic coordinate system and UTM projection, users can define their own UTM projection or import/download any projection for the current layer. Choosing this option enables the *Define*, *Import,* and *Download*` (39) |
| 41–48 | User Defined의 정의·가져오기·다운로드 및 내보내기. UTM·WGS 84 매개변수 설정, *.prj 파일 가져오기, EPSG Code로 다운로드하는 방법 및 Cartesian을 적용하는 No Projection 조건을 그대로 옮긴다: `  - *Define* button: Defines projection by configuring the map projection parameters ([Setting the Coordinate System#Figure 8](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2515828737#SettingtheCoordinateSystem-Figure8)). | 49–54 | UTM 투영 매개변수. 경도 구역 폭별 축척 계수(scale factor), 중앙 자오선(central meridian), 원점 위도(latitude of origin), 가산 동향값(false easting)과 가산 북향값(false northing)의 수치·단위·반구 조건은 `[Setting the Coordinate System#Figure 8](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2515828737#SettingtheCoordinateSystem-Figure8) shows a dialog that allows defining a UTM projection with some specific parameters. The scale factor of 0.9996 is applied for the zone width of 6° of longitude, and the scale factor of 0.9999 is applied for the zone width of 3°. The central meridian indicates the central meridian longitude of the zone. The latitude of the original is usually taken as zero, and the false easting is usually taken as 500 000 meters. The false northing is taken the zero value for the Northern Hemisphere and is taken the value of 10 000 000 meters for the Southern Hemisphere.` (49)이다. 그림 51의 9.jpg는 User Defined Map Projection 창이다. 표시 항목과 값은 `Projection: Univeral Transverse Mercator` (51), `Datum: WGS 84` (51), `Scale Factor: 0.9996` (51), `Central Meridian: -122.5` (51), `Latitude of Origin: 0` (51), `False Easting: 500000` (51), `False Northing: 0` (51)이다. 같은 행의 다른 그림은 `Import_Projection.prj` (51)와 `Projection files (*.prj)` (51)를 보여 주는 파일 열기 창이다. Figure 9 캡션을 포함한다(53). |
| 55–58 | EPSG 코드로 투영 정보 다운로드. 웹사이트 두 곳을 연결하고 UTM 구역 코드 형식과 구역 10의 입력 예시를 제공한다. 원문: `[Setting the Coordinate System#Figure 10](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2515828737#SettingtheCoordinateSystem-Figure10) shows a dialog that allows users to download projection information from the Internet using an EPSG code. EPSG codes for different coordinate systems can be found at <https://epsg.io> or <https://spatialreference.org>. The EPSG codes for the projection information for UTM zones have the form EPSG:326xx. For example, the EPSG code for UTM Zone 10 is EPSG:32610, so users can enter the value of 32610 into the search box to download its projection information.` (55) 그림 57의 EPSG Code 창에는 입력 값 `32610` (57)과 OK·Cancel 버튼이 보인다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 지리 좌표계 도입 문장에서 약어를 `Geographic Coordinate System (GSC)` (12)로 정의한 뒤 같은 행에서 `The GCS in EEMS 12 aims to:` (12)라고 적는다. GSC와 GCS의 철자가 다르다(12).
- 정밀도 설명의 참조는 `[Figure 8](#Figure11)` (59)이다. 표시되는 그림 번호와 링크의 앵커(anchor) 번호가 다르다(59).
