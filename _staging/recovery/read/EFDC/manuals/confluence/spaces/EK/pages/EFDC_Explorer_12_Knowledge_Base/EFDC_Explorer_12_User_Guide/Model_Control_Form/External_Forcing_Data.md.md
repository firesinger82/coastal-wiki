| 10–22 | 외부 강제력(external forcing) 시계열(time series) / 목록과 추가·가져오기 — 10행 앞부분은 색상 CSS다. 본문은 경계 강제력(boundary forcing) 시계열의 추가·편집·보기·비교 기능을 설명한다(10). External Forcing Data를 마우스 왼쪽 클릭(left mouse click, LMC)하면 메뉴 목록이 나타나며 생성한 시계열 수는 대괄호에 표시한다(10). 시계열은 나중에 Boundary Condition 탭에서 경계 그룹(boundary group)과 셀(cell)에 할당할 수 있다(12). LMC는 항목 보고서를 표시한다. 마우스 오른쪽 클릭(right mouse click, RMC)은 ``*Add New Data Series* and *Import Existing EFDC Formatted Series.`` (16) 옵션을 표시한다. 기존 자료가 있으면 ``*Edit Data Series*`` (16)로 편집하고 ``*View Data Series.*`` (16)로 그래프를 볼 수 있다. 입력 파일 예시는 ``( QSER.INP, ASER.INP, PSER.INP,....)`` (19)이다. 14행 `EE10_109.png`와 21행 `EE10_110.png`의 로컬 사본을 열었다. 첫 그림은 외부 강제력 메뉴와 경계 그룹·입력 자료 수 보고 화면이다(14). 둘째 그림은 추가·가져오기 메뉴 및 유량(flow) 시계열 보고 표다(21). 보고 표의 열은 `Series No.`, `Series Name`, `Num. of Records`, `From Day (Julian)`, `To Day (Julian)`이며 두 자료 행은 ``1, inflow, 368, 0, 367``; ``2, outflow, 368, 0, 367``이다(21행 그림). |
| 23–36 | Add New Data Series / 생성·이름 변경·복사 — 일반 Boundary Data Series 양식을 사용하는 조건은 ``Except for [*Harmonic Tides*](/wiki/spaces/EK/pages/240222570/Harmonic+Tides) and [*Hydraulic Structures*](/wiki/spaces/EK/pages/240320734/Hydraulic+Structures), all other sub-tabs use this general form.`` (25)이다. 선택한 하위 탭에 따라 추가 옵션이 있을 수 있다(25). 이름 변경의 적용 조건은 ``The name of a series can be edited in *Series Name*. Press "Enter" afterward to apply the edit.`` (29)이다. 시계열 추가·삭제·선택 표기는 ``*Add New* and *Delete.*`` (29); ``*Select Series*`` (29)이다. ``*View Series*`` (31) 버튼은 그래프를 표시한다. 여러 시계열·층(layer)을 함께 표시하는 선택지는 ``*View Options.*`` (31)이다. Shift와 Ctrl로 여러 셀을 선택하고 ``*Copy Data, Paste Data, Insert Row, Delete Row*`` (33)로 복사·붙여넣기·행 추가·삭제를 수행한다(33). 27행 `EE10_111.png`는 점이 없는 새 시계열 양식이다. 31행 `137.png`는 파란색·빨간색 곡선의 그래프 아이콘이다. 35행 `EE10_114.png`는 선택한 inflow 자료 표다. 세 로컬 그림을 모두 열었다(27·31·35). 보이는 열 머리글은 `Time (days)`, `Layer 1 (m³/s)`, `Layer 2 (m³/s)`, `Layer 3 (m³/s)`, `Layer 4 (m³/s)`, `Layer 5 (m³/s)`, `Total`이다(35행 그림). 자료 행을 `행 번호: Time, Layer 1, Layer 2, Layer 3, Layer 4, Layer 5, Total` 순서로 옮긴다: ``1: 0.000000, 0.1144, 0.1144, 0.1144, 0.1144, 0.1144, 0.5720``; ``2: 1.000000, 0.1144, 0.1144, 0.1144, 0.1144, 0.1144, 0.5720``; ``3: 2.000000, 0.1152, 0.1152, 0.1152, 0.1152, 0.1152, 0.5760``; ``4: 3.000000, 0.1088, 0.1088, 0.1088, 0.1088, 0.1088, 0.5440``; ``5: 4.000000, 0.1040, 0.1040, 0.1040, 0.1040, 0.1040, 0.5200``; ``6: 5.000000, 0.0984, 0.0984, 0.0984, 0.0984, 0.0984, 0.4920``; ``7: 6.000000, 0.0952, 0.0952, 0.0952, 0.0952, 0.0952, 0.4760``; ``8: 7.000000, 0.0912, 0.0912, 0.0912, 0.0912, 0.0912, 0.4560``; ``9: 8.000000, 0.0872, 0.0872, 0.0872, 0.0872, 0.0872, 0.4360``; ``10: 9.000000, 0.0832, 0.0832, 0.0832, 0.0832, 0.0832, 0.4160``; ``11: 10.000000, 0.0792, 0.0792, 0.0792, 0.0792, 0.0792, 0.3960``; ``12: 11.000000, 0.0768, 0.0768, 0.0768, 0.0768, 0.0768, 0.3840``; ``13: 12.000000, 0.0752, 0.0752, 0.0752, 0.0752, 0.0752, 0.3760`` (35행 그림). 그림에 표시된 `# of Points: 368` 중 화면에 완전히 보이는 13개 행을 옮겼다(35행 그림). |
| 37–55 | Import Series form / ASCII 가져오기 — 기존 ASCII 자료를 가져오면 현재 시계열 자료를 새 자료로 교체한다(39). 원문: ``An alternative option is to import an existing ASCII data file and replace the current series data with the new data with the *Import Series*`` (39). ASCII Data Import에서 ``*Browse*`` (43)로 파일을 고르고 ``*Header Rows to Skip,* and *Data Base Date.*`` (43)를 설정한다. 열 선택 조건은 ``The *Data Column to Import* should point to the column number that contains the Y data.`` (49); ``If there are more than two columns in the data file, it is advised to select *Multiple Columns* button and assign which type of data the columns is.`` (49)이다. 구분자를 고른 뒤 ``*Data Preview*`` (50)와 그래프로 가져온 자료를 확인하고 필요하면 조정한다(47–51). ``*OK*`` (52)로 실제 가져오기를 마친다. 39행 `227.png`는 자료 표로 향하는 초록색 화살표의 가져오기 아이콘이다. 41행 `EE10_118.png`는 가져오기 버튼을 빨간 테두리로 강조한 빈 유량 표다. 그 열 머리글은 `Time (days)`, `Layer 1 (m³/s)`, `Layer 2 (m³/s)`, `Layer 3 (m³/s)`, `Layer 4 (m³/s)`, `Layer 5 (m³/s)`, `Total`이며 `# of Points: 0`을 표시한다(41행 그림). 54행 `EE10_117.png`는 ASCII 가져오기 설정 화면이다. 세 로컬 그림을 모두 열었다(39·41·54). 설정 화면에서 `EE DAT or WQ Data`, `Julian Date`, 구분자 `Comma`, `Space`, `Tab`이 선택되어 있다. 보이는 설정값은 `Header Rows to Skip: 0`, `Data Base Date: 1/1/2012`, `Import from Data Column: 2`, `Conversion Factor: 1`이다. `Add Date`는 선택되어 있지 않으며 `Multiple Column` 버튼을 빨간 테두리로 표시한다(54행 그림). 화면 값은 예시로 옮겼다. |
