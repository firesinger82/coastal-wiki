# Generate_Animations.md — 판독 구간 기록

구간은 1행부터 20행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–15 | 문서 메타데이터 — 페이지 ID·제목·space·URL·판본·갱신 시각·문서 경로와 frontmatter 구분자를 포함한다(1–9). Generate Animations — 애니메이션(animation)을 동영상 파일로 내보내는 기능이다(10). Figure 1의 로컬 그림을 열었다(12–14). 그림은 2DV View 메뉴에서 Generate Animation 항목이 선택된 화면이다. 빈 줄과 그림 마크업·캡션을 포함한다(11–15). |
| 16–20 | Export Animation Settings — 기본 저장 폴더·파일 형식·파일 이름과 경로 선택·시작/종료 시각·건너뛸 시간 단계·내보내기 실행을 설명한다(16). 기본값·조건을 포함한 원문: `By default, the animation will be saved inthe *#animations* folder of the active model. We can select either AVI or MP4 file format for the animation. Next, put a filename for the animation and a folder to save the image by clicking the *Browse* button (Figure 2). Setting options for the animation file can be applied in this form, such as start/stop animation and the number of time steps to skip. Finally, click the *OK* button to start exporting.` (16). Figure 2의 로컬 그림을 열었다(18–20). 그림은 Generate Animation 설정 화면이다. 화면 예시값은 `Format: MP4`, `Start Animation (days): 300` 및 `2012-10-27 00:00:00`, `Stop Animation (days): 400` 및 `2013-02-04 00:00:00`, `Number of Time Steps to Skip: 1`, `Frame Rate: 2`이다(18행 그림). `AVI`도 형식 선택지로 보인다. 본문은 이 화면 예시값을 기본값으로 정의하지 않는다. 빈 줄·그림 마크업·캡션을 포함한다(17–20). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 16행: 애니메이션 파일 저장 절차를 설명하는 문장에 `a folder to save the image`라는 표현이 있다.
