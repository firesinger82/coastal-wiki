Animate Blanking / 인덱스 선택 — 10행은 CSS 색상 규칙 뒤에 선택한 I·J·K 인덱스(index)를 따라 일부 격자 셀(grid cell)을 숨기는 애니메이션(animation)을 설명한다. 12·14·16행의 로컬 그림을 각각 열었다. 세 그림은 I 인덱스·J 인덱스·K 층의 숨김(blanking) 애니메이션 버튼 아이콘이다. 설정 이름 원문은 `Animate Blanking along with I index` (12), `Animate Blanking along with J index` (14), `Animate Blanking along with K layer` (16)이다. 빈 줄·그림 마크업·아이콘 설명을 포함한다(11–17). |
| 18–22 | Animate Blanking / 필수 선택과 출력 — 애니메이션 대상 층과 숨김 대상 인덱스를 선택해야 한다(18). 적용 조건·출력 원문: `It is required to select the animation layers and the index that can be blanked as shown [Animate Blanking#Figure 1](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/276889601#AnimateBlanking-Figure1). EE10 also allows the user to generate animations and export this by selecting *Output AVI file*.` (18). ## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 8행의 문서 경로는 `EFDC+ Explorer 12 User Guide`를 포함한다. 18행의 본문은 `EE10`의 기능이라고 설명한다.
- 18행의 그림 링크는 `#AnimateBlanking-Figure1`을 가리킨다. 이 파일에는 해당 ID 선언이 없고 22행은 굵은 글씨 캡션이다.
- 18행은 `Output AVI file`을 선택해 내보낸다고 설명한다. 20행 그림에는 별도의 `Create AVI File` 체크박스와 `Output AVI File` 경로 입력란이 있다.
