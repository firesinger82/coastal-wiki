| 10–13 | Jet & Plume / 경계 유형 — 색상 CSS 뒤에 제트·플룸(jet/plume) 경계 창을 설명한다(10). Current Boundary Cell은 상류 셀과 하류 셀을 동시에 정의해야 한다(10). Jet/Plume Type은 우회(by-passing), 유량 시계열 또는 취수·환류(withdrawal/return) 시계열을 선택한다(10). 원문: ``One difference is that in *Current Boundary Cell for Jet/Plume,* the user must define an upstream cell and a downstream cell simultaneously.`` (10); ``These options include by-passing (ICAL=0), using a flow time series (QSER, ICAL=1), and using a withdrawal return time series (W/R, ICAL=2).`` (10); ``The *Flow Series* and *W/R Series* in *Flow Assignment for Cell* is enabled according to the Jet/Plume type selected.`` (10); ``From the release of EEMS11.2 WQ constituents may also be added to the plume.`` (10). 12행 `New_JetPlume.png`의 로컬 사본을 열었다. 그림은 그룹·셀, 확산기 포트(diffuser port), 유량 배정, 연행(entrainment) 기준과 농도 설정 창이다(12). 농도 표 머리글은 `Constituent`, `Conc`이다. 완전히 보이는 자료 행은 `Temperature (°C): 30`, `Dye_1 (mg/L): 100`, `RPOC (mg/L): .5`, `LPOC (mg/L): .5`, `DOC (mg/L): 4`, `RPOP (mg/L): .1`, `LPOP (mg/L): .1`, `DOP (mg/L): .05`이다(12행 그림). 이 값은 화면 예시이며 본문 기본값이 아니다. |
| 14–17 | Jet & Plume / 성장 정지 조건 — Diagnostics는 정지 조건 표시와 플룸 성장 상세 저장을 선택한다(14). 요소 수, 중심선(centreline)의 표면·저면 관통, 가장자리(edge)의 표면·저면 관통과 중성 부력(neutral buoyancy)을 설명한다(14). 원문: ``The *Diagnostics* drop-down menu allows the user to select from the display jet/plume stop conditions and save jet/plume growth details. The *Stop Plume Growth Option* allows the simulation to stop after a certain number of elements (ISTJP = 0), when the plume centreline penetrates the surface or bottom (ISTJP = 1), or when the plume edge penetrates the surface or bottom (ISJTP = 2), as shown in Figure 2. The neutrally buoyant condition, also shown in Figure 2, applies in all cases. `` (14). 16행 `2023-05-12-Jet_Plume.png`의 로컬 사본을 열었다. 그림의 여섯 패널은 `ISTJP = 1 (Rising)`, `ISTJP = 2 (Rising)`, `ISTJP = 1 (Falling)`, `ISTJP = 2 (Falling)`, `Neutrally Buoyant` 두 경우이다(16행 그림). 검은 점선은 범례의 `Centre Line`, 빨간 원은 `Boundary Stop`이다. 상승 패널의 1은 중심선이 수면에 닿는 곳, 2는 두 가장자리가 수면에 닿는 곳에 빨간 원을 둔다. 하강 패널은 같은 기준을 저면에 표시한다. 중성 부력 패널은 중심선이 수평으로 이어지는 영역의 시작을 빨간 원으로 표시한다. `Port` 화살표는 오른쪽의 방출구를 가리키며 `Diffuser`를 표시한다(16행 그림). 중성 부력 조건은 모든 경우에 적용한다고 본문이 적는다(14). |
| 18–23 | Diffuser Port Settings / 계산 제한과 갱신 — 방출 셀별 포트 수, 고도·직경, 진북(true north) 기준 방위각(azimuth)과 수직 고도각(altitude)을 지정한다(18). QSER 파일 유량은 포트 수를 곱하여 해당 셀의 전체 유량을 얻는다(18). 원문: ``In the *Diffuser Port Settings* frame, the user may specify the settings for each discharge cell, including the number of ports, the elevation, and the diameters of the port outlets, as well as the horizontal (azimuth, measured from true north) and vertical (altitude) angles.  It should be noted that the flow in the QSER file is multiplied times the number of ports for the total flow for that BC cell. So, for example, if a user has 10 ports, with each port having a time series of 0.15 cms assigned for the jet, then the total flow is 10 \* 0.15 cms = 1.5 cms.`` (18). 계산 종료용 Maximum Number of Elements는 초과 시 성장 계산을 항상 정지한다고 적는다(20). 너무 작게 지정하면 선택한 정지 성장 조건까지 도달하지 못한다고 적는다(20). 요소 계산의 반복 상한과 유체역학 시간 단계(hydrodynamic time steps) 기준 갱신 간격을 설명한다(22). 균일 유동(uniform flow)은 복잡하고 변화하는 환경보다 갱신 간격을 훨씬 크게 설정할 수 있다고 적는다(22). 원문: ``The *Maximum Number of Elements* option is mainly used for plume computation termination purposes.  This means that plume growth will always stop when the *Maximum Number of Elements* is exceeded, which is before reaching the neutral buoyancy level, or the plume reaches the surface (plume density less than ambient) or the bottom (plume density greater than ambient).  It is important not to set this value too small as it will cause the computations to cease before the plume reaches the stop growth option.`` (20); ``The *Maximum Number of Iterations* is the maximum number of loops to calculate within each step of the element computation. Since there are multiple loops in the jet/plume computation, the actual computation can be time-consuming. Therefore, *Number of Time Steps for Update* lets users define after how many hydrodynamic time steps EFDC+ should compute the jet/plume result again and update the results. If simulating a uniform flow condition, the number of time steps for each update can be set much greater than in a more complex and changing environment.`` (22). |
| 24–27 | Calculation Option / Froude Number — 계산 옵션의 선택값과 프루드 수(Froude Number) 조정 계수를 설명한다(24–26). 원문: ``In the *Calculation Option* menu, the user can select the *Use Max of Shear or  Forced* option or *Use Sum of Shear & Forced.*`` (24); ``An adjustment factor for the *Froude Number* may also be set.`` (26). 12행 화면에 보인 예시 값은 `Calculation Option: Use Max of Shear or Forced`, `Maximum Number of Iterations: 150`, `Convergence Criteria: 1E-05`, `Froude Number Adjustment Factor: 1`, `Maximum Number of Elements: 100000`, `Number of Time Steps for Update: 10`이다(12행 그림). 본문에는 이 항목들의 수치 기본값·범위가 없다(20–26). |
| 28–30 | Note to User — EFDC+를 국소 규모(local scale) 제트·플룸 해석기로 보아서는 안 된다고 적는다(30). 원문은 설계 규모를 `10~100m or even 1000m`라고 적는다(30). 현재 구현의 확산기 운동량(momentum) 계산은 셀 경계를 가로지르지 않는다(30). 계산한 주변수 연행 유량(ambient water entrainment flow rate)은 포트가 있는 셀의 수직층에만 분배한다(30). 적용 범위와 부정 조건의 원문: ``EFDC+ shouldn't be deemed as a local scale jet/plume solver. It is designed for scale from 10~100m or even 1000m where the local momentum effect at the beginning is not as important to the plume growth and the following advection/diffusion transport process. The momentum calculation for the diffuser implementation in EFDC+ does not cross the cell boundary in the current implementation. Furthermore, EFDC+ only distributes the computed ambient water entrainment flow rate along the vertical layers of the cell where the port is located.`` (30). 제목 마크업과 마지막 행을 포함한다(28–30). |
