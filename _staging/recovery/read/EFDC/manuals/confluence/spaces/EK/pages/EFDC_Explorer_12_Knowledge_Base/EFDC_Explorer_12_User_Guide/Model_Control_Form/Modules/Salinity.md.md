| 10–17 | Activate the Salinity Module — 제목 앞에 CSS 선택자·색상 선언이 남아 있다(10). EFDC+ Modules에서 염분(salinity) 모듈의 그래픽 사용자 인터페이스(Graphical User Interface, GUI)를 활성화한다(12). 그림 1은 Salinity 체크박스가 선택된 화면이다(14). 캡션과 빈 줄을 포함한다(13–17). |
| 18–31 | Settings — Salinity 오른쪽 클릭으로 설정과 초기조건(initial conditions)에 접근한다(20). 그림은 두 메뉴를 보여 준다(22). Salinity Parameters에서 초기조건과 시계열(time series)을 편집한다(24). 그림의 표시값은 `Constant/Average Salinity (ppt): 2.568` (26행 그림)와 `Salinity Time Series: 0` (26행 그림)이다. Edit는 Boundary Data Series를 열고 시계열은 나중에 경계 그룹·셀에 할당할 수 있다(28). 그림의 표 헤더는 `Time; Layer 1; Layer 2; Layer 3; Layer 4; Layer 5; Average` (30행 그림)이다. 표의 세 행은 `0 0.100000 0.10000 0.10000 0.10000 0.10000 0.10000` (30행 그림); `10 0.100000 0.10000 0.10000 0.10000 0.10000 0.10000` (30행 그림); `20 0.100000 0.10000 0.10000 0.10000 0.10000 0.10000` (30행 그림). 셀 사이 간격은 공백으로 옮겼다(30). Time의 단위는 이 표에 표시하지 않는다(30). |
| 32–40 | Initial Conditions — Assign으로 일정한 값 또는 공간적으로 다른 초기 염분을 설정한다(34). 자료가 없으면 Download로 공개 자료를 내려받을 수 있다(36). 적용 범위 원문은 `It is able to select to apply the downloaded data for the whole model time range or just fill some missing periods.` (36)이다. 그림 4는 Salinity Parameters와 Interpolate Layered Data 폼이다(38). 표시 항목은 `Use Spatially Varying Initial Conditions` (38행 그림); `Constant/Average Salinity (ppt): 22.114` (38행 그림); `Constant: 0` (38행 그림)이다. 전체 셀/다각형 내부 셀, 전체 층/특정 층, 상수/XYZ 산포 자료(scatter data)/프로파일 자료(profile data), 대체/최댓값/최솟값 보간(interpolation) 선택을 보여 준다(38). 화면값을 기본값으로 정의하지 않는다(26, 38). 캡션과 마지막 행을 포함한다(40). |
