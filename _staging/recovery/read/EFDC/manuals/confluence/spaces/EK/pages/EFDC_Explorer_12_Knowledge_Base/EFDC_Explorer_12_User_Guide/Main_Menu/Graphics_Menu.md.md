| 10–13 | Graphics 개요와 메뉴 그림 — 메인 도구 모음(main toolbar)의 Graphics에서 이미지 또는 애니메이션(animation)을 내보낼 수 있다(10). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246350347/EE10_198.png`를 직접 열었으며 Generate Image와 Generate Animation 메뉴를 보여 준다(12). 원문: `The *Graphics*item in the main toolbar of EE provides the user the ability to export either images or animations ([Figure 1](#Figure1)). | 14–28 | Generate Image — 출력 이름·폴더, 개별 또는 단일 이미지, 출력 창 선택, 여러 창의 배치와 전체 창 목록 표시를 설명한다(16–23). 기본 저장 폴더와 옵션 적용 조건을 각 원문 줄 그대로 옮긴다(18–23). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246350347/Image1.png`와 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246350347/Arange_window.png`를 직접 열었다(27). 첫 그림은 파일명과 두 출력 창 선택 및 Separated Images 선택을 보여 준다(27). 두 번째 그림은 두 창을 한 행 두 열에 배치하는 화면이며 `No. of Rows: 1`, `No. of Columns: 2`, `Column Width: 960`, `Row Height: 872`, `Show Form Border` 선택을 보여 준다(27, 그림). 미리보기 왼쪽은 하상 고도 색상 격자이고 오른쪽은 단면 격자이다(27, 그림). 작은 미리보기의 축 숫자는 식별하지 못했다(27, 그림). 원문: `## Generate Image` (14); `The *Generate Image* from is shown in [Figure 2](/wiki/spaces/EK/pages/2189197313/Graphics#Graphics-Figure2), and the options available are as follows:` (16); `- *Export Options* : the user should select a name for the image and select the folder to save the image by clicking the *Browse*button. By default, the image will be saved in the *#analysis* folder of the active model.` (18); `- *Separated Images:* if the option is selected, each window is exported as individual images` (19); `- *Single Image:* if the option is selected, the whole window is exported into a single image.` (20); `- *Select window to export*: all available windows with the necessary information for each are listed in the form, and the user can check the box to export the window of interest.` (21); `- If more than one window is selected in the *Select window to export* frame, the *Arrange Windows* button is also available. The *Arrange Windows* form is shown in [Figure 3](/wiki/spaces/EK/pages/2189197313/Graphics#Graphics-Figure3). The user is able to select *No.of Rows, No.of Columns, Column Width* and *Row Height.*` (22); `- By default, the *Select window to export*frame only displays the view and plot windows*.* To display other windows such as model control, work logs, check on the *List All Windows*checkbox.` (23); `Finally, click *OK* button to start exporting images. ` (25); `![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/246350347/Image1.png?version=1&modificationDate=1679296116555&cacheVersion=1&api=v2&width=636&height=309)![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/246350347/Arange%20window.png?version=1&modificationDate=1679296173668&cacheVersion=1&api=v2&width=764&height=591)` (27). |
| 29–41 | Generate Animation — 출력 이름·폴더·형식, 출력 창, AVI 시간 설정과 초기 프레임(initial frame) 옵션, 여러 창 배치와 전체 창 목록을 설명한다(31–37). 기본값과 모델 시간 범위 조건을 원문 그대로 옮긴다(33–37). 로컬 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246350347/Animation2.png`와 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/246350347/Animation3.png`를 직접 열었다(41). 첫 그림은 AVI 출력과 선택 창·시간·프레임 설정을 보여 준다(41). 화면 값은 `Start Animation (days): 41120.000000`, `2012-08-01 00:00:00`, `Stop Animation (days): 41620.000147`, `2013-12-14 00:00:12`, `Number of Time Steps to Skip: 1`, `Frame Rate: 2`, `Number of snapshots to display: 2`이다(41, 그림). Compressed AVI는 선택되어 있고 Grid·Symbols and Labels·Background image는 선택되어 있지 않다(41, 그림). 두 번째 그림의 배치는 `No. of Rows: 1`, `No. of Columns: 2`, `Column Width: 960`, `Row Height: 872`이다(41, 그림). 미리보기 왼쪽은 색상 격자이고 오른쪽은 붉은 곡선의 시계열 그래프이다(41, 그림). 작은 미리보기의 축 값은 식별하지 못했다(41, 그림). 원문: `## Generate Animation` (29); `The *Generate Animation* form is shown in [Figure 4](/wiki/spaces/EK/pages/2189197313/Graphics#Graphics-Figure4) with options as follows:` (31); `- *Export Options* : the user should select a name for the animation and select the folder to save the animation by clicking the *Browse*button. By default, the animation will be saved in the format of *\*.avi* file in the *#analysis* folder of the active model.` (33); `- *Select window to export*: all available windows with necessary information are listed in the form, and the user can check the box to export the window of interest.` (34); `- *AVI File Options:*the user can set up the file export options such as *Animation Timing*: the time for the AVI file needs to be inside the model timing. Add *Grid, Symbols* *and Labels* or *Background image* by checking the box in *Initial Frame Options*.` (35); `- If more than one window is selected in the *Select window to export* frame, the *Arrange Windows* button is alsoavailable. The *Arrange Windows* form is shown in [Figure 5](/wiki/spaces/EK/pages/2189197313/Graphics#Graphics-Figure5). The user is able to select *No.of Rows, No.of Columns, Column Width* and *Row Height.*` (36); `- By default, the *Select window to export*frame only displays the view and plot windows*.* To display other windows, such as model control, work logs, check on the *List All Windows*checkbox.` (37); `Finally, click *OK* button to start exporting images. ` (39); `![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/246350347/Animation2.png?version=2&modificationDate=1679296255228&cacheVersion=1&api=v2&width=636&height=494)![](https://eemodelingsystem.atlassian.net/wiki/download/thumbnails/246350347/Animation3.png?version=1&modificationDate=1679296305666&cacheVersion=1&api=v2&width=764&height=591)` (41). |
