| 20–28 | Model Control Form / 좌클릭 — 트리에서 모듈·초기조건·외력(external forcings)·경계조건·분석·보정(calibration)을 설정한다(20–22). Figure 2·3의 로컬 그림을 직접 열었다(24·28). 트리와 Horizontal Grid 보고서를 보여 주며 Figure 3은 Grid 항목을 강조한다(24·28 그림). 좌클릭(left mouse click, LMC)은 선택 항목의 정보를 표시한다(26). |
| 29–36 | 우클릭 — 우클릭(right mouse click, RMC)의 설정·초기조건·시계열(time series) 메뉴와 경우에 따라 폼을 직접 여는 동작을 설명한다(30·34). 적용 조건 원문: `In some cases, RMC on an item in the tree will immediately open a form rather than provide options. For example, modules may be turned on and off by RMC on the *Modules* header in the *Model Control*form as shown in [Figure 5](#Figure5).` (34) Figure 4·5의 로컬 그림을 직접 열었다(32·36). Figure 4는 Temperature의 Settings, Initial Conditions, Time Series 메뉴이다(32 그림). Figure 5는 Modules 우클릭으로 연 EFDC Modules 대화창이다(36 그림). |
| 37–40 | 2DH View / Layer Control — 평면도(plan view)의 접근, 기본 레이어(default layers), 전구의 표시 여부, Properties, Add a New Layer, 기본 그룹·변수 선택, Add와 선택·편집·라벨 아이콘을 설명한다(38). 기본 표시·옵션 원문: `One of the main navigation options in EE is the plan view, called *2DH View* (called *ViewPlan* in EE8.5) which is accessed from the main toolbar (*2DH* button) or the main menu (*2DH View* menu item). Navigation of the *2DH View* is primarily governed by the *Layer Control* form is shown in [Figure 6](#Figure6). By default, certain layers such as the model grid and the bottom elevation will be displayed. The light bulb icon indicates whether a layer is displayed (on) or not displayed (off) (1). RMC on a layer provides a number of options including *Properties* to set the display properties. To add a new layer, select the *Add a New Layer* button (2). The user may then select from the *2DH View Option* form from the drop-down list for the primary group, which includes options such as water level, boundary conditions, and water column (3). A sub-option for the parameter type should also be selected from the drop-down list. Select *Add* to add this to the *2DH View.*Directly adjacent to the light bulb are the arrow, pencil, and tag icons. These allow the user to select, edit, and modify labels for a layer.` (38) Figure 6 로컬 그림을 직접 열었다(40). 번호 1은 전구, 2는 새 레이어, 3은 `Primary Group: Water Column`과 `Parameter: Temperature`, 4는 Add 버튼이다(40 그림). 화면 옵션은 `Options: Depth Average`이다(40 그림). 바닥 표고 지도 범례는 `Bottom Elevation (m)`의 `-4.536`–`-1.500`이며 별도의 좌표축은 없다(40 그림). |
