# Windows_Menu.md — 판독 구간 기록

구간은 1행부터 38행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 페이지 ID, 제목, space, 원문 URL, 버전, 갱신 시각, 문서 계층 경로와 frontmatter 구분선을 포함한다(1–9). |
| 10–13 | Windows Menu — Windows 메뉴가 창의 배치와 조작을 제공한다(10). `EE10_192.png`를 열었다(12). Cascade·Tile Horizontal·Tile Vertical·Arrange Icons·Arrange Windows·Work Logs·Save Window·Restore Window와 현재 열린 창 목록이 표시된다(12, 그림). Model Control 항목 옆에 활성 창을 나타내는 체크 표시가 있다(12, 그림). |
| 14–17 | Cascade — `*Cascade*: Arrange the current windows on top of each other.` (14)이다. `EE10_193.png`를 열었다(16). Model Control·2DV View·2DH View 창이 조금씩 오른쪽 아래로 이동하며 겹쳐진 화면이다(16, 그림). 맨 앞 격자는 하천에서 넓은 하구로 이어지며 `Bottom Elevation (m)` 색 범례가 파랑 `-19.004`부터 빨강 `5.312`까지이다(16, 그림). |
| 18–21 | Tile Horizontal — 본문의 방향 설명은 `*Tile Horizontal*: Arrange the current windows next to one another horizontally` (18)이다. `EE10_194.png`를 열었다(20). 2DV View·2DH View·Model Control 창이 위·가운데·아래의 세 행으로 배치되어 있다(20, 그림). 2DV의 가로축은 `Distance (m)`이며 보이는 눈금은 `0`, `1500`, `3000`, `4500`, `6000`, `7500`, `9000`, `10500`, `12000`, `13500`, `15000`이다(20, 그림). 세로축은 `Elevation (m)`이며 왼쪽의 일부 숫자가 겹쳐 보인다(20, 그림). 단면의 염분(salinity) 색 범례는 `Salinity (ppt)`의 파랑 `0.000`부터 빨강 `35.000`까지이다(20, 그림). 아래의 평면 격자는 `Bottom Elevation (m)`의 `-19.004`부터 `5.312`까지를 표시한다(20, 그림). |
| 22–25 | Tile Vertical — 본문의 방향 설명은 `*Tile Vertical*: Arrange the current windows next to one another vertically` (22)이다. `EE10_195.png`를 열었다(24). 2DV View·2DH View·Model Control 창이 왼쪽·가운데·오른쪽의 세 열로 배치되어 있다(24, 그림). 2DV의 축은 `Distance (m)`와 `Elevation (m)`이다(24, 그림). 가로축의 보이는 눈금은 `0`부터 `15000`까지 1500 간격이며 세로축의 보이는 눈금은 `2.50`, `0.25`, `-2.00`, `-4.25`, `-6.50`, `-8.75`, `-11.00`, `-13.25`, `-15.50`, `-17.75`이다(24, 그림). 염분 범례는 `Salinity (ppt)`, `0.000`, `35.000`이다(24, 그림). 중앙 격자의 바닥 높이(bottom elevation) 범례에는 `-19.004`와 `5.312`가 보인다(24, 그림). |
| 26–31 | Arrange Icons·Arrange Windows — 최소화한 창을 작업 공간 아래에 배치한다(26). 행과 열로 창을 배치할 때의 지시는 `*Arrange Windows:* Open a form that lets the user freely arrange windows in columns, rows. The user drags window thumbnails from the left and releases them onto an empty space of choice.` (28)이다. `EE10_196.png`, `EE10_197.png`를 모두 열었다(30). 196.png는 왼쪽에 창 축소판을 놓고 오른쪽을 2행·2열의 빈 칸으로 나눈 설정 창이다(30, 그림). 표시값은 `No. of Rows: 2`, `No. of Columns: 2`, `Column Width: 960`, `Row Height: 433`이며 `Show Form Border`가 선택되어 있다(30, 그림). 197.png는 왼쪽 위 Work Logs, 오른쪽 위 2DH View, 왼쪽 아래 Model Control, 오른쪽 아래 2DV View로 배치한 결과이다(30, 그림). 2DH 범례는 `Bottom Elevation (m)`, `-19.004`, `5.312`이다(30, 그림). 2DV 범례는 `Salinity (ppt)`, `0.000`, `35.000`이다(30, 그림). 2DV 가로축 `Distance (m)`은 `0`부터 `15000`까지 1500 간격이며 세로축 `Elevation (m)`의 보이는 눈금은 `2.50`, `0.25`, `-2.00`, `-4.25`, `-6.50`, `-8.75`, `-11.00`, `-13.25`, `-15.50`, `-17.75`이다(30, 그림). |
| 32–33 | Work Logs — 작업 로그 창을 최대화하며 비활성 상태일 때 활성화한다(32). 적용 조건은 `*Work Logs*: Maximize the *Work Logs.*If the work logs are currently disabled, this option will enable it.` (32)이다. |
| 34–38 | Save Window·Restore Window·열린 창 목록 — 비활성 상태라는 문서의 설명은 `*Save Window*: This option is currently disabled.` (34) 및 `*Restore Window*: This option is currently disabled.` (36)이다. 현재 열린 창이 메뉴 끝에 표시되며 활성 창에는 체크 표시가 붙는다(38). 빈 줄도 포함한다(35·37). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행의 `#Figure1` 참조에 대응하는 앵커 정의와 Figure 1 캡션이 이 Markdown에 없다.
- 18행은 Tile Horizontal이 창을 서로 옆에 수평으로 배치한다고 설명한다. 20행 예시 그림은 창을 위·가운데·아래의 세 행으로 배치한다.
- 22행은 Tile Vertical이 창을 수직으로 배치한다고 설명한다. 24행 예시 그림은 창을 왼쪽·가운데·오른쪽의 세 열로 배치한다.
