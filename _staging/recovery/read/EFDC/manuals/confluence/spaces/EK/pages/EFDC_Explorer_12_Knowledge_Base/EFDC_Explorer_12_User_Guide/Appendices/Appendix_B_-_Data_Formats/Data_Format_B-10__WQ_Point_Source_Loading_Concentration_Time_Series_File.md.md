## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 15행은 `MWQPSR`, `TCPSER`, `TAPSER`, `RMULADJ`, `ADDADJ`를 열거한다. 이 파일은 각 이름의 의미를 설명하지 않는다.
- 15–18행: `NS`, `M`, `NWV`의 의미는 이 파일에 없다. NWV의 묶음 범위만 적혀 있다.
- 20–22행의 성분 약호들은 이 파일에서 풀어 쓰지 않는다. 13행은 TAM·FCB의 단위 예외만 제시한다.
- 20·25–39행의 Time에는 기준 시각이나 단위가 명시되어 있지 않다.
