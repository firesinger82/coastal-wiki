## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 관측 시계열 예시 표제는 `USGS_Speedy, Salinity, PPT`인데 같은 표의 설명은 `water temperature (Celsius)`를 든다(15행).
- DSM 그림의 자료 헤더에는 `density`와 예시값 `1643`이 있다(27행). 바로 앞의 행별 자료 설명에는 밀도 필드가 나열되지 않는다(24행).
- B-10 구조는 코어 좌표·깊이 수를 별도 행에 두고 `END`로 코어 정의를 끝내도록 적는다(38,58행). 두 번째 코어 예시의 `0.13 20.25`는 한 행에 붙어 있으며 예시 끝에 `END` 행이 없다(93–103행).
- 조화상수 예시의 관측소 수·조화성분 수 자리에는 `2`, `38`이 있으며 실제로 제시된 자료는 `Johor`의 성분 행 14개이다(193–210행).
- `BED.SDF` 입경 표 마지막 값은 `8520.0`이다(355행). 해당 침식률 배열 마지막 주석은 `8250 micron`이다(379행).
- `ENSIGHT.SDF` 변수 번호 8–9의 순서는 `CHG`, `CHD`이다(475–477행). 플래그 헤더의 순서는 `CHD`, `CHG`이다(525행).
- `CORE_FIELD.SDF` 절에는 코어 배치 숫자 배열의 축·인덱스 의미가 정의되어 있지 않다(535–599행).
- `RCHC` 정의의 조건에는 `REVC<0`가 적혀 있다(631행). 앞의 `REVC` 정의에도 같은 조건이 적혀 있다(629행).
- TVF ASCII 블록의 자료 수는 `NC × NL × NK`이다(746행). 이진 블록 설명에서는 `NC × LC × NK`라고 적혀 있지만 바로 뒤 표의 자료 바이트 수는 `4\*NK\*NL\*NC`이다(796,803행).
- 별도 ASCII `*FLD.INP` 예시의 헤더는 `ITYPE NT NC LC NK ITOPT IUPDATE IFLAG NODATA`이다(834행). 앞의 TVF 헤더에 있는 `TSCL TSHF VSCL VSHF YY MM DD` 필드는 이 예시 헤더에 없으며 시간 뒤의 셀 수 행도 없다(713,834–837행).
- FORTRAN 예시는 `implicit none`을 쓰지만 설정·출력에 쓰는 `TSCL`, `TSHF`, `VSCL`, `VSHF`의 선언을 제시하지 않는다. `# Write binary format`도 코드에 포함되어 있다(857행).
- Python 예시에는 `intVal = 0  % Reserved`가 들어 있다(869행).
- C#의 특정 셀 출력 분기는 유효값이 있는 셀만 세어 `cellCnt`를 쓴다. 그 다음 출력 반복문은 `j < NL`로 모든 셀의 인덱스와 값을 쓴다(875행).
