## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행: CSS 선택자와 색상 선언이 본문 앞에 남아 있다.
- 10행: 링크 표시 이름은 `Sediment Bed Initialization Tools`이고 URL 대상 페이지 이름은 `Sediment Bed Construction`이다.
- 20행·24행 그림: 본문은 Sediment Timestep을 수리동역학 시간 단계 수의 배수로 설명한다. 그림의 필드 단위는 `(s)`이다.
- 37행·46행 그림: 표의 여러 이름·값과 아래쪽 행이 잘려 있다. 잘린 숫자의 지수와 잘린 매개변수 이름의 나머지는 확인할 수 없다.
- 51행·59행 그림: Gamma 1–4의 입력 필드가 보인다. 이 문서는 Gamma별 정의나 계산식을 제시하지 않는다.
- 70행·72행 그림: 본문은 압밀률 단위를 seconds로 적는다. 예제의 Consolidation Constant는 `-1`이다. 이 문서는 이 음수의 의미를 정의하지 않는다.
