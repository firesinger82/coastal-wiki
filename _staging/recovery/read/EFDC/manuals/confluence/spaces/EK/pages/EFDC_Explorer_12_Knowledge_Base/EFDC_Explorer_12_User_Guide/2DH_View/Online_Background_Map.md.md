# Online_Background_Map.md — 판독 구간 기록

구간은 1행부터 16행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–16 | 온라인 배경 지도(Online Background Map) — Layer Control의 Online Background 전구를 켜거나 끈다(10). 적용 조건 원문: `To display the model grid for the correct online background map, the model grid needs to be set to the correct UTM Zone.` (12). Model Control의 Model Grid를 펼치고 Grid 또는 Layers를 오른쪽 클릭한 뒤 Model Grid 창의 `UTM Zone`에 구역 번호를 입력하고 OK를 누른다(14). 16행의 두 그림을 직접 열었다. 첫 그림은 온라인 영상과 모델 격자를 겹쳐 표시하고 Online Background 전구를 강조한다. 둘째 그림은 `UTM Zone: 16`인 Model Grid 창이다. 층 수 `# Layers: 10`의 `Thickness` 표는 층 `10: 0.100000`, `9: 0.100000`, `8: 0.100000`, `7: 0.100000`, `6: 0.100000`, `5: 0.100000`, `4: 0.100000`, `3: 0.100000`, `2: 0.100000`, `1: 0.100000`이며 `Layer Sum: 1.00000`이다. 그 밖의 표시 값은 `# Rows: 24`, `# Columns: 73`, `# Cells: 1380`, `Number of Cells (no SGZ): 13800`, `Number of Cells (with SGZ): 11120`, `Nominal Cell Height (m): 0.0480`, `Max. Surface Elevation (m): 0.0480`이다(16행 둘째 그림). 이는 화면 예시 값이며 본문은 UTM Zone의 기본값·범위를 명시하지 않는다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)
