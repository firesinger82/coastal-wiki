| 34–43 | 외해 경계조건(offshore boundary condition). 로컬 바람이 발생시키는 파랑에 더해 외부 너울(swell)을 고려할 수 있다고 설명한다 (34). EE가 열린 경계(open boundary)의 위치를 찾아 그룹별 조건을 편집하게 한다 (34). 세 조건의 이름과 적용 원문은 `- No Wave, i.e. no external wave actions are taken into account at the selected boundary group.` (36); `- Constant: constant wave parameters in time including waves wave height, wave period, wave direction, and directional spreading are provided for the selected boundary group.` (37); `- Time Varying: wave parameters for the selected boundary group are varying in time and are provided in files for at least two points lying on the boundary section. The distance indicates the location along the boundary of the data point with respect to the first grid cell (I1,J1) of the boundary group. The total length of the boundary is provided in the text box *Length (m)*. The data file format is the TPAR file described in SWAN User’s Manual. Wave parameters at every grid cell along the boundary group will be interpolated by SWAN based on the given data files.` (38)이다. No Wave는 선택 그룹의 외부 파랑 작용을 고려하지 않는다 (36). Constant는 파고(wave height), 주기(wave period), 파향(wave direction), 방향 퍼짐(directional spreading)을 시간 상수로 준다 (37). Time Varying은 경계 구간 위 최소 두 지점의 파일이 필요하며 거리는 첫 격자 셀 `(I1,J1)`에 대한 경계 방향 위치이다 (38). 전체 경계 길이는 `Length (m)`에 표시하며 파일 형식은 `TPAR`이다 (38). SWAN은 주어진 파일을 바탕으로 각 경계 셀의 파랑 매개변수를 보간(interpolate)한다 (38). `5-20-2019_1-50-11_PM.jpg`를 열었다 (40). 그림은 ocean 경계의 인덱스·길이를 표시하고 No Wave·Constant·Time Varying을 선택하는 SWAN Boundary Conditions 화면이다 (40). Figure 4 캡션과 빈 줄을 포함한다 (35–43). |
