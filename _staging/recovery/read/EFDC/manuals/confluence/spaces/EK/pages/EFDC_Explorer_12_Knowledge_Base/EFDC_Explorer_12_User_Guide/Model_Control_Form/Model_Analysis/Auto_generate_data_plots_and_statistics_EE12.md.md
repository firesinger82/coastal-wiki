# Auto_generate_data_plots_and_statistics_EE12.md — 판독 구간 기록

구간은 1행부터 64행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | Auto generate data, plots, and statistics (EE12) — 문서 식별자, 제목, space, URL, 판본, 갱신 시각과 문서 계층의 frontmatter(1–9). |
| 10–15 | 자동생성 기능 진입 — 비교 관측점이 정의되어 있으면 Calibration Time Series·High-Frequency Time Series·Vertical Profiles 등의 오른쪽 클릭(RMC)에서 자동생성 기능에 접근한다(10). Auto Generate Options 양식에는 Calibration·Saved Plots 탭이 있다(14). 빈 줄과 그림을 포함한다(11–15). `2020-06-03_9-51-49_AM.png`을 열었다(12). Vertical Profiles 자동생성 메뉴와 `Buoy`의 `X (m): 556057`, `Y (m): 5275456`, `Parameter: Temperature (°C)`, `Layer: 55`, `Filter: 0`, `Group: 0`, `Used: False` 비교표를 보여 준다. |
| 16–31 | Calibration tab / Calibration Options / Generate Options — 선택한 보정 유형에 따라 활성 옵션이 달라지고 예제에서는 Vertical Profile Plots가 사용 가능하다(16–22). 추출·재사용·플롯·자료 내보내기·그림 형식의 옵션, 기본 저장폴더와 적용 조건을 그대로 옮긴다: `- *Reload Data & Model Result*: extract model output after EFDC runs.` (26); `- *Use Existing Model Extractions*: Extracting the data from the EFDC output can be time-consuming if it is a large model run.  To avoid having to extract the results each time, this option can be used to reuse the existing extracted data.` (27); `- *Automatically Generate Defined Plots*: if the box is checked, the comparison plot will be generated automatically. The plots will be stored in the *#calib\_plots* folder as default settings. It can change the plot folder by clicking *Change Folder*.` (28); `- *Automatically Export Model Series*: the option is used to extract model output with the entire simulation time from the grid cell where the measured data station is located. The files extracted will be in the *#calib\_export* folder as the default setting. It can change the plot folder by clicking *Change Folder*. In case the *Pair Model and Data* option is checked, the EE only extracts when the measured data is available for those time points.` (29); `- *Export Image Type*: it is able to save the image as \*.emf, \*.png, \*.jpg, \*.bmp, \*.gif files.` (30). 소제목과 빈 줄을 포함한다(16–31). |
| 32–50 | Error Statistics Reporting / General button — 보고서 자동생성, 통계 선택, 보고서 형식·폴더와 Generate·OK·Cancel을 설명한다(32–43). 조건·형식·기본 폴더 원문: `- *Automatically Generate Reports*: this option links to the Report Error Statistics frame below. If this option is not checked, the *Report Error Statistics* options are enabled.` (34); `- *Set Error Statistics*: Clicking this button, the *Error Statistics* form will pop up as shown in [Figure 3.](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2152923137#Autogeneratedata,plots,andstatistics(EE12)-Figure3) From this form, we can select the type of error statistics we want to export to a report by checking the boxes and then clicking the *OK* button. The *Check All* and *Uncheck All* buttons allow having a quick selection.` (35); `- *HTM Report File or ASCII Report File*: this option will set the format of the error report` (36); `- *Change Folder*: the error report is generated and saved in the *#calib\_stats* folder as default settings. It can change the location of the error report by clicking *Change Folder*.` (37). Generate는 보정 플롯·통계를 생성하고 OK는 선택 저장 후 닫으며 Cancel은 선택을 건너뛰고 닫는다(41–43). 빈 줄, 45행의 선행 `e`, 그림과 캡션을 포함한다(44–50). `2022-09-09_9-27-48_AM.png`을 열었다(45). Calibration 탭에서 `Vertical Profile Plots`, `Use Existing Model Extractions`, `Automatically Generate Defined Plots`, `Automatically Export Model Series`, `Automatically Generate Reports`가 체크되어 있다. `Reload Data & Model Result`와 `Pair Model and Data`는 미체크이며 `Exported Image Type: .png`, `ASCII Report File` 선택을 표시한다. `2022-09-06_10-50-06_AM.png`을 열었다(49). Error Statistics 선택 항목은 `Starting Date/Time`; `Ending Date/Time`; `# Pairs`; `Data average`; `Model average`; `Data minimum`; `Model minimum`; `Data maximum`; `Model maximum`; `Standard Deviation Observed`; `Standard Deviation Predicted`; `Mean Error (ME) or Mean Bias Error (MBE)`; `Relative Mean Error (RME) or Percent Bias`; `Mean Absolute Error (MAE)`; `Maximum Absolute Error (MaxAE)`; `Root Mean Square Error (RMSE)`; `Relative Root Mean Square Error (RRMSE)`; `Scaled Root Mean Square Error (SRMSE)`; `Centered Root Mean Square Error (CRMSE)`; `Nash-Sutcliffe Coefficient of Efficiency (NSE)`; `RMSE-observations standard deviation ratio (RSR)`; `Kling-Gupta Efficiency (KGE)`; `Coefficient of Efficiency (COE)`; `Index of Agreement (IOA)`; `Coefficient of Determination (R²)`; `Correlation Coefficient (R)`; `Slope of Linear Regression (A)`; `Intercept of Linear Regression (B)`이다. 시작·종료 시각과 자료 쌍 수는 비활성 체크이다. Data average·Model average·RMSE·NSE가 체크되어 있으며 다른 통계는 미체크이다. Check All·Uncheck All·OK·Cancel 버튼이 있다. |
| 51–64 | Saved Plots tab — 저장 플롯(saved plots)의 2DH·3D·2DV·종단분포(longitudinal profile, LP) 자동 PNG 내보내기를 설명한다(51–58). 활성화·필드·기본 경로 원문: `The tab of *Saved Plots* is used to export the 2DH, 3D, 2DV automatically, and longitudinal profile (LP) plots to image files \*.png. (shown as [Figure 4)](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2152923137#Autogeneratedata,plots,andstatistics(EE12)-Figure4). Check on the *Automatically Generate Saved Plots* checkbox to enable this option.` (53); `- *Define/Edit*: when clicking this button the *Saved Plots* form will appear as shown in [Auto generate data, plots, and statistics (EE12)#Figure 5](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2152923137#Autogeneratedata,plots,andstatistics(EE12)-Figure5). Firstly, it is necessary to define the *Number of Saved Plots* in the box. The *Start* and *Stop* day will be updated automatically based on the model timing. The *Name* column is used to define the title of the exported image. *Path File* is the location of the plot data. *Time* is the date of the plots. Check *Use* box to generate the plot. When check-boxes options are defined, finally click on the *OK* button to save the settings and close the form.` (55); `- *Generate Plots*: the plots will be generated automatically and saved to the \*.png file in the *#calib\_plots* folder as default settings.` (56). Generate 후 저장 위치 메시지를 표시한다(58). 빈 줄·그림·캡션을 포함한다(52,54,57,59–64). `9-12-2022_4-20-51_PM.png`을 열었다(60). `Automatically Generate Saved Plots`가 체크되어 있고 2DH·3D·2DV·LP의 `Number of Plots`는 각각 `0`이다. 각 영역에 Define/Edit·Generate Plots 버튼이 있다. `Saveplots.png`을 열었다(64 첫 그림). Saved Plots: 2DV View에서 `Number of Saved Plots: 2`, `Start (days): 1274`, `2008-06-28 00:00:00`, `Stop (days): 1639`, `2009-06-28 00:00:00`을 표시한다. 표 열은 `No.`, `Name`, `Path File`, `Time`, `Use`이다. 두 행은 `1, Plot1, ... , 1284, 체크`; `2, Plot2, ... , 1284, 체크`이며 Path File은 긴 경로라 줄임표로 잘려 있다. `2022-09-13_11-44-21_AM.png`을 열었다(64 둘째 그림). Vertical Profiles의 플롯·통계 생성 완료 메시지에서 플롯은 `#calib_plots\`, 보고서는 `#calib_stats\`에 저장되었다고 표시한다. |
