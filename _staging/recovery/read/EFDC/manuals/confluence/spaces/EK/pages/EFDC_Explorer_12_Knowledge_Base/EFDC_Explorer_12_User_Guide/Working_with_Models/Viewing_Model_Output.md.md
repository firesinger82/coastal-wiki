# Viewing_Model_Output.md — 판독 구간 기록

구간은 1행부터 40행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–11 | 앞부분 메타데이터와 도입. `title: "Viewing Model Output"` (3) 및 페이지 ID, space, URL, 버전, 갱신 시각과 문서 계층을 포함한다(1–9). 긴 CSS 색상 지정 뒤에 모델 실행·출력 생성 후 결과 보기 방법을 소개하는 문장이 이어진다(10). 빈 줄도 포함한다(11). |
| 12–15 | 2DH View. 지정 시각의 매개변수 2차원 지도, 수심 평균(depth-averaged) 또는 각 수층(water column layer) 결과를 보여 준다. 시각 이동 방식은 `PgUp/PgDn` (12), `Ctrl-G` (12)와 스크롤 막대이다. 그림 14는 하천에서 바다로 펼쳐지는 곡선 격자와 바닥고(bottom elevation)를 색으로 표시한다. 범례는 `Bottom Elevation (m)` (14), 범위 `-19.004` (14)에서 `5.312` (14)이다. 낮은 값은 파랑, 높은 값은 빨강이다. 가로·세로 좌표축 눈금은 표시되어 있지 않다. 표시 시각은 `2018-01-01 00:00` (14)이며 상단 시각 이동 막대가 강조되어 있다. |
| 16–19 | 2DV View. 프로필·단면(profile/cross-section)을 제공하며 특정 시각 출력에는 먼저 슬라이더(slider) 옆 상자를 해제한 후 시각을 조정해야 한다. 원문: `- *2DV View:*provide access to the profile/cross-section post-processing utility of EFDC+ Explorer. To see the output generated by EFDC at a specific point in time, the user should first uncheck the box beside the slider and then use the slider (highlighted in [Figure 2](#Figure2)) to adjust the time.` (16) 그림 18은 `Col: I = 26, Time: 2009-03-06 00:00` (18)의 EFDC+ Testing, West Lake Toxics 수직 단면이다. 가로축은 `Distance (m)` (18), 눈금 `0, 450, 900, 1350, 1800, 2250, 2700, 3150, 3600, 4050, 4500` (18)이다. 세로축은 `Elevation (m)` (18), 보이는 눈금 `3.50, 3.75, 4.00, 4.25, 4.50, 4.75, 5.00, 5.25, 5.50, 5.75` (18)이다. 색 범례 `Coh-Sed, Class 1 (mg/L)` (18)는 `37.290` (18)에서 `39.320` (18)까지이다. 왼쪽 파랑에서 오른쪽 빨강으로 값이 커지며 격자 아래 경계가 지형을 따라 굽는다. 해제된 시각 선택 상자와 슬라이더가 빨간 테두리로 강조되어 있다. |
| 20–27 | Time series / Vertical Profile / Longitudinal Profile / Flux Tool. 지정 위치의 시계열(time series)을 제공한다(20). 수직·종단 프로필의 시각 선택 및 질량 부하(mass loading)를 추출하는 사용자 폴리라인(polyline)·경계조건은 `- *Vertical Profile*and *Longitudinal Profile:*operates similar to 2DV View; uncheck the box beside the slider and then use the slider o adjust time and see the plot generated by EE at different points in time.` (21) `- *Flux Tool:*used to obtain Time series plots of the mass loading of many constituents through a profile (user-defined polyline) or a boundary ( as shown in [Figure 3](#Figure3)). This tool can be found in *Main Menu*→ *Tools*and more information can be found on [Tools Menu](/wiki/spaces/EK/pages/245727433/Tools+Menu).` (22)이다. 그림 24는 Flux Extraction 창이다. `Constituent: Cohesive Sediments` (24), `Class: Cohesive Class 1` (24), `Time From: 64` (24), `To: 154` (24)가 보인다. Entire Series는 선택되어 있으며 Time Range와 Snapshot, Total은 선택되지 않았다. Transect 경로는 비어 있다. Figure 3 캡션을 포함한다(26). |
| 28–35 | Re-Scan Output. 모델을 다시 로드하지 않고 출력을 읽거나 2DH·2DV·3D 화면을 갱신한다. 실행 중 일시 정지에 관한 문구를 고치지 않고 전체 조건을 옮긴다: `- *Re-Scan Output*: After EFDC+ has completed running the model, the user can use *Re-Scan Output* feature ( shown in [Figure 4](#Figure4)) to immediately load the output without having to re-load the model. This option can also be used to refresh the model output to update the display in the 2DH, 2DV, or 3D Views. In previous releases of EE, the user would pause the EFDC+ model run before displaying the results. While EFDC+ can no longer be paused, it is also no longer necessary as the results can be displayed with the need to pause.` (30) 그림 32는 Model 메뉴의 Re-Scan Output을 빨간 사각형으로 강조한다. Figure 4 캡션을 포함한다(34). |
| 36–40 | Time Control Setting. 도구막대 버튼으로 캘린더(calendar), 시간 형식(time format)과 애니메이션(animation)을 설정한다(36). 그림 38은 해당 버튼과 Time Control Settings 창이다. `Gregorian Date` (38)와 `Time of Water Surface` (38)가 선택되어 있다. `Precision: 4` (38), `Format: yyyy-MM-dd HH:mm` (38), `Time Tolerance (minutes): 1` (38), `Snapshot Skip: 1` (38), `Frame Delay (sec): 0` (38)을 표시한다. Julian Date와 Time of selected layer는 선택되지 않았다. Figure 5 캡션을 포함한다(40). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- Re-Scan Output 설명의 마지막 문장은 `While EFDC+ can no longer be paused, it is also no longer necessary as the results can be displayed with the need to pause.` (30)이다. 일시 정지가 불가능하며 더는 필요 없다고 적는 동시에 `with the need to pause` (30)라고 적는다(30).
