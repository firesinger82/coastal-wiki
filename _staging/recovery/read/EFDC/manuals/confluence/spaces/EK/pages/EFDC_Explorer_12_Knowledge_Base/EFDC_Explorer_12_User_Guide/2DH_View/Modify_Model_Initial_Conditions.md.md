# Modify_Model_Initial_Conditions.md — 판독 구간 기록

구간은 1행부터 24행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–20 | 모델 초기 조건 수정(Modify Model Initial Conditions) / 선택 절차 — CSS 색상 마크업 뒤에 절차를 제시한다(10). Bottom Elevation 레이어의 펜을 누르고 Shift/Ctrl+LMC로 초기 조건을 바꿀 셀을 선택한 뒤 도구 모음의 Grid Cell Tool을 연다(12·16·18). 12행 펜 아이콘과 그림 1·2를 직접 열었다(14·20). 그림 1은 Bottom Elevation 레이어가 선택되고 펜이 활성화된 격자 화면이다. 그림 2는 Grid Cell Tool 도구 모음 버튼의 위치이다. |
| 21–24 | Properties에서 초기 조건 편집 — Edit Cell Properties를 선택하면 수심(water depth), 하상 표고(bottom elevation), 하상 거칠기(bottom roughness) 등의 변수와 값이 표시되어 수정할 수 있다(22). 그림 3을 직접 열었다(24). `Parameter`·`Value` 표에 보이는 행별 값은 `L - I - J: 1555 - 80 - 29`, `Bottom Elev...: -12.999`, `Delta X: 303.80`, `Delta Y: 216.73`, `Water Depth: 12.915`, `Roughness: 0.01000`, `Angle: 19.987`, `Cell Type: 5`, `Mask South` 체크 해제, `Mask West` 체크 해제이다. 표 아래 Apply·Cancel 버튼이 있다(24행 그림). 하상 표고·수심·거칠기 행이 빨간 테두리로 강조되어 있다. 값은 화면 예시 값이다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 12·14: 그림 1 캡션은 `RMC on cells with Boundaries layer selected.`라고 적는다. 12행 절차와 14행 그림은 Bottom Elevation 레이어를 사용한다.
- 24행 그림 3: 하상 표고의 표 이름은 `Bottom Elev...`로 잘려 있다.
