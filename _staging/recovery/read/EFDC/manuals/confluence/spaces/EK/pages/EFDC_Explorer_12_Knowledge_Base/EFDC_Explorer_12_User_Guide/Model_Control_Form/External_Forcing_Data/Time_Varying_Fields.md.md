| 10–29 | Time Variable Data Field — CSS 선언 뒤 셀별 시간·공간 외력을 지정하는 EE 10 옵션을 설명한다(10). 시간변화장(Time Varying Field, TVF) 형식은 외부 자료와 EFDC+를 연결하며 ASCII와 binary 형식을 Appendix B-26에 설명한다고 적는다(10). 원문은 전처리·후처리의 읽기·쓰기·보기 기능을 말하면서 현재 단계의 TVF 생성은 외부에서 해야 한다고 적는다: `Although the pre- and post-processing of EFDC+ Explorer can be able to read, write, and view TVF data but at this stage, the creation of TVF data should be done externally.` (10) 적용 사례 목록과 빈 줄을 포함한다(11–27). 목록은 지형, 저면 조도(bottom roughness), 식생(vegetation), 지하수·침투(groundwater/seepage), 바람, 기압(barometric pressure), 바람 차폐(wind shelter), 대기 차광(atmospheric shading), 강우·증발·강설·눈 두께·얼음 두께를 든다(14–26). 현재 구현 항목 원문: `Currently, the options are implemented in EFDC+ including topography, bottom roughness, groundwater seepage, rainfall, evaporation, wind and barometric pressure.` (28) |
| 30–37 | 기압장 생성 — 허리케인 기압 예제의 메뉴 진입과 대체 자료 적용을 설명한다(30). 조건 원문: `If the Data Option menu is set to *Not Used* for pressure, then the pressure field from the external forcing for atmospheric data series will be applied.` (30) `Generate`로 Field Data Interpolation 양식을 열고 자료 연결 뒤 다시 생성한다(34). 입력 연결표의 4열 원문: `4 columns are stations ID; X coordinates in UTM, Y coordinate in UTM; and the path of the data series respectively` (34) 개별 자료 파일 형식 원문: `It is advised to ensure that individual data series files are in the format: the number of records, series name, time and value (see Appendix B-26 for an example).` (34) 선형 보간(linear interpolation) 및 기존 자료 교체 여부를 선택할 수 있다(34). 빈 줄과 두 그림을 포함한다(31–37). 로컬 그림 `Timevaryingfields1.jpg`을 열었다(32). | 38–45 | 형식 변환과 공간 표시 — Tools의 Convert Time Varying Fields를 통한 ASCII→binary 변환을 설명한다(38). 생성한 장의 우선 적용 조건 원문: `Once the field is generated, EFDC will use this field in place of the other forcings defined by the user to simulate.` (42) 2DH View의 Forcing Fields로 외력장을 검토한다(42). 빈 줄과 그림을 포함한다(39–45). 로컬 그림 `Convert_Time.jpg`은 `ASCII to Binary`와 `Binary to ASCII`, `Binary Field Format`과 비활성 `NetCDF Format`, 파일명 입력란을 보여 준다(40). `2DHPressure.jpg`은 `2005-08-24 00:00` 기압장을 격자(grid)에 표시한다(44). 그림의 색 범례는 파랑 쪽 `1009.6`에서 빨강 쪽 `1009.7`까지이며 단위는 `Pressure (hPa)`이다. 보이는 격자에서 왼쪽은 빨강·주황, 오른쪽은 파랑·청록이다. | 46–55 | Time Varying Field Data Formats, File Names, and Units — ASCII는 수작업 생성·수정이 가능하지만 binary보다 디스크 공간이 크다고 설명한다(48). ASCII는 전체 파일을 메모리에 읽고 binary는 한 시간 단계만 읽으며, 로드 뒤 형식을 전환하면 모델 저장 시 대응 파일을 생성한다고 적는다(48). 파일명 규칙 원문: `The file name for the TVF data is fixed for different data type and has a general pattern of \*FLD.\*.` (50) `The file extension for the ASCII format is \*.INP, and the file extension for the binary format is \*.FLD.` (50) 절 제목, 빈 줄과 Table 1 제목을 포함한다(46–55). |
| 56–71 | Table 1 — 빈 표 머리와 열 제목을 포함한다(56–58). 파일명·EFDC 변수·단위·조건을 행별로 그대로 옮긴다. `1` / `TOPOFLD` / `TOPO` / `Bottom elevation in meters (e.g., dredging/dumping, land erosion/reclamation)` (59); `2` / `ROUGHFLD` / `ROUGH` / `Roughness height in meters (e.g., seasonal roughness)` (60); `3` / `VEGEFLD` / `VEGE` / `Vegetation (e.g., seasonal vegetation) (*not yet implemented*)` (61); `4` / `GWSPFLD` / `GWSP` / `Groundwater/seepage flow (inflow is positive, outflow is negative)  IDST = 0: Groundwater inflow in m³/s  IDST = 1: Groundwater seepage in m/s` (62); `5` / `WINDFLD` / `WIND` / `Wind speed in m/s (e.g., cyclone)` (63); `6` / `PRESFLD` / `PRESS` / `Barometric pressure in hPa (e.g., cyclone)` (64); `7` / `RAINFLD` / `RAIN` / `Rainfall (positive values in m/s)` (65); `8` / `EVAPFLD` / `EVAP` / `Evaporation (positive values in m/s)` (66); `9` / `SHELFLD` / `SHELT` / `Time varying wind shelter (*not yet implemented*)` (67); `10` / `SHADFLD` / `SHADE` / `Time varying sun shading (*not yet implemented*)` (68); `11` / `SNOWFLD` / `SNOW` / `Snow (snow depth, snowfall, …) in meters (*not yet implemented*)` (69); `12` / `ICEFLD` / `ICEFLD` / `Ice (thickness, temp., …) in meters (*not yet implemented*)` (70); `13` / `ZLJDLF` / `ZLJER` / `SEDZLJ erosion rate (factor A and power N) (*not yet implemented*)` (71). 기본값이나 별도 수치 범위 열은 없다. |
