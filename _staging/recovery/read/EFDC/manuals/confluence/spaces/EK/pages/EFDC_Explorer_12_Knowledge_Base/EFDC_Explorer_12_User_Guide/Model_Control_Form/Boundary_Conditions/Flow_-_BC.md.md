| 16–25 | Boundary Group Information / Current Boundary Cell — 그룹 정보 소절과 현재 셀 소절을 포함한다(16–25). 원문 항목: `- *Current Group:* the current group is displayed` (18); `- *Group Name:* enter the group name in the box` (19); `- *Flow Multiplier Switch:* the drop-down box provides a number of options, from normal inflow to various lateral inflow/outflow options` (20). 그룹의 셀 수, 위치와 초기 수위(initial WSEL), 수심(depth), 저면 고도(bottom)를 표시한다(24). 원문: `The number of cells in the boundary group is listed with detailed locations (*L*, *I*, and *J* ). *initial WSEL*, *Depth*, and *Bottom* values.  The *Add*, *Remove* and *Remove All* buttons are used to edit the boundary cells.` (24). 그룹명과 Flow Multiplier Switch의 기본값·수치 범위는 본문에 없다(18–24). |
| 26–33 | Flow Assignment — 현재 셀의 유량 시계열 지정과 편집, 같은 그룹의 모든 셀에 현재 시계열 지정, 셀 체적(cell volumes)에 기초한 분배 계수, 일정 유입량의 분배를 설명한다(28–32). 원문 항목: `- *Flow Time Series:* this is the drop-down list (as shown in [Figure 1](#Figure1)) link flow tables with the concentration table or time series.` (28); `- *Edit:* the button is used to edit the associated time series of the current boundary cell` (29); `- *All:* the button allows the user to quickly assign all the boundary cells in the current group to the *Flow Time Series*.  For example, pressing the *All* shown in [Figure 1](#Figure1) would set the flow series number for all cells in the group to the current “QSER\_2” table settings.` (30); `- *Time Series Flow Split Factor:*If the user has an input flow series for a river that requires distributing the river flow across several cells, the single time series of flow can be specified in the *Flow Time Series* and the *Distribute Factor* can be set to split the flow appropriately among the cells.  The *Distribute Factors* sets the *factor* based on cell volumes` (31); `- *Constant Flow*: A constant inflow can also be distributed in a similar manner to the *Time Series Flow Split Factor* by using the *Distribute Flows* button` (32). `QSER\_2` 예시를 포함한다(30). |
| 34–43 | Momentum Flux / 계산식 — 격자 내부 셀 간 계산과 달리 경계에서 들어오는 체적의 운동량은 기본 옵션에서 무시한다고 적는다(36). 유입 운동량을 선택한 셀 면에 추가하여 하천 흐름과 평행하거나 수직인 유입을 표현하도록 설명한다(36). 원문: `The default option is that the volume goes into the cell, but the momentum from the inflow of the flow boundaries is neglected.` (36); `The control parameter NQSMF in C24 indicates if the volumetric sources and sinks have an associated momentum flux.` (36); `If the *Momentum Options* is selected, the user can select *Flow Into Cell*  or *Flow Out of Cell* and enter *Momentum Width.* The moment option will add the momentum fluxes generated by current inflow/outflow at the boundary. The momentum flux QMF (m4/s2) at a boundary cell is calculated as:` (38); `QMF = QF\*QF/( HPK\*QWIDTH )` (40); `Where QF is the flow (m3/s), HPK (m) is the layer thickness, QWIDTH (m) is the width of the discharge for momentum. This width should be equivalent to that of the pipe or the outfall being used.` (42). `QMF` 단위는 `m4/s2`, `QF` 단위는 `m3/s`, `HPK`와 `QWIDTH` 단위는 `m`이다(38·42). 폭은 사용한 관(pipe) 또는 방류구(outfall)의 폭과 동등해야 한다(42). |
| 44–55 | Momentum Flux / 면과 방향 선택 — 운동량 옵션 목록을 제시한다(44–50). 원문 선택값: `- *Inflow Momentum Flux Ignored (default option)*` (46); `- *Momentum Flux on West U Face*` (47); `- *Momentum Flux on South V Face*` (48); `- *Momentum Flux on East U Face*` (49); `- *Momentum Flux on North V Face*` (50). 셀 위치와 유입·유출 특성에 따라 Flow into cell 또는 Flow out of cell을 선택해야 한다(52). 서쪽 끝 유입 셀의 예시는 West U Face와 Flow Into Cell 조합을 요구한다(52). East U Face와 Flow Out Of Cell 조합은 거의 같은 결과를 준다고 적는다(52). 원문: `Depending on the cell position and the characteristic of the flow boundary (inflow or outflow), the "Flow into cell" or "Flow out of cell" should be selected. For example, a boundary cell of an inflow is located on the west edge of the model domain, as shown in Figure 2. In this case, to add the momentum flux, you must choose the "Momentum Flux on West U Face" combined with "Flow Into Cell."  Alternatively, selecting the "Momentum Flux on East U Face" combined with "Flow Out Of Cell" will give an almost identical result.` (52). 54행 `2023_06_14_Momentum_flux_options.png`의 로컬 사본을 열었다. 그림은 모델 영역(Model domain)의 서쪽 갈색 영역 옆에 파란 경계 셀을 둔다. `West` 면의 `U` 화살표는 오른쪽으로 셀에 들어온다. `East` 면의 `U` 화살표는 오른쪽으로 셀에서 나간다. `South` 면의 `V` 화살표는 위로 셀에 들어온다. `North` 면의 `V` 화살표는 위로 셀에서 나간다(54행 그림). |
| 56–61 | Boundary Group Concentration Assignments — 시간 변화 농도는 시계열 유량에만 사용한다(58). 일정 농도는 일정 유량에만 사용한다(59). 일정 염분(salinity) `5 ppt`를 지정해도 일정 유량이 0이면 시계열 유량이 지정되어 있더라도 염분 입력은 0이라고 적는다(59). 같은 그룹의 모든 셀은 시계열 농도 설정과 일정 농도 설정을 각각 공유한다(61). 원문: `- *Time Varying Concentration:* the option is used with time series flows only. The user can select the time series for concentration by using the drop-down list in the *Data Series* list.` (58); `- *Constant Concentration*: the option is used with constant flow only. For example, if the user defines a constant salinity concentration of 5 ppt in the *Constant Concentration* frame but with zero constant flow, even if the boundary has flows assigned via a time series, the salinity input to the model will be zero.` (59); `**Note:**the concentration settings, for both time series and constant, are fixed for all cells for the same group.` (61). |
