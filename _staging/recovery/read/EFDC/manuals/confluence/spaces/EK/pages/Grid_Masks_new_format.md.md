| 10–29 | General Purpose — 격자 마스크(grid mask)는 셀 면에 놓는 얇은 댐이며 셀 사이 흐름을 완전히 또는 부분적으로 막는다(12). 완전 차단은 수주(water column)의 위에서 아래까지 물의 이동을 차단한다(14). 부분 차단은 고정 물체 또는 부유 물체로 설정할 수 있다(16). 치수 정의와 조건 원문: `- Anchor Elevation: if set to zero the object on the water will be considered as floating (e.g ships), otherwise it is a fixed object (e.g bridges, docks).` (24); `- Draft: the thickness of the floating or fixed object on the water.` (25); `- Clearance: is the thickness of space between the Draft and Bottom Sill when it is equal to 0, the object plays the role of a fully blocking mask, otherwise it is a partial blocking mask.` (26); `- Bottom Sill: the thickness of a solid structure on the surface of the riverbed.` (27); `- Bottom: means the riverbed.` (28). | 30–58 | 2DH View / Adding New Masks to Grid Cells — 마스크 레이어의 전구·포인터·펜을 켜고 단일 셀 또는 여러 셀에 마스크를 넣는 절차를 설명한다(34–57). 단일 셀 메뉴는 서쪽과 남쪽을 함께 완전 차단하거나 각 면을 완전 차단하는 선택과 `Edit Cell Blocking Mask`를 제공한다(36–41). 부유 설정의 기본 선택, 비활성 입력란, 고정 물체 전환 조건과 셀 추가·제거 절차 원문: `- *Edit Cell Blocking Mask:* after selecting this option the *Vertical Cell Face Blocking* form appears as shown in [Figure 4](#Figure4). The cell ID (L, I, J indices) will be added to the *List of Cells* frame. The cell indices and initial conditions are displayed on the *Current Cell* frame. By selecting this option, EE understands that the user wants to add a partially blocking mask (floating or fixed object) to the selected cell so the checkbox *Floating* is checked by default. In addition, the *Anchor Elevation* box is greyed out so it is non-editable. The user can now enter values for the *Draft* and *Bottom Sill.* When the *Floating* checkbox is unchecked then the *Anchor Elevation* box can be edited. If the value entered is non-zero the mask now is partially blocking as a fixed object.` (41); `The *Edit Cell Blocking Mask* option can also be used to edit the existing cells with assigned masks. These cells are in the *List of Cells* frame. LMC on a cell from this list then changes the properties of the mask on the right frame. To add a new cell with masks enter the I, J, L index in the Indices then press Enter key or click the left-arrow button as shown in [Figure 4](#Figure4). To remove a cell from the cell list, LMC on that cell then click the right-arrow button. Click the double right-arrow button to remove all cells at once as shown in [Figure 4](#Figure4).` (43). 여러 셀 선택 조건 원문: `**Add masks to multiple cells**: To add masks to multiple grid cells at the same time multiple cells must be selected first. This is done by holding the Ctrl key and LMC to select various single cells, or by holding the Shift key and LMC to select a range of adjacent cells. Other ways to select grid cells are described in [Grid Cell Selection](http://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/246612141/Grid+Cell+Selection). The next steps for adding masks to these cells are similar to that for adding a mask to single cell as presented above.` (57). Figure 2의 `8-26-2020_5-01-21_PM.png`는 그림 파일 없음(45). Figure 3의 `8-28-2020_4-45-51_PM.png`는 그림 파일 없음(49). Figure 4의 `8-28-2020_4-54-48_PM.png`는 그림 파일 없음(53). 세 그림의 캡션을 읽었다(47·51·55). |
