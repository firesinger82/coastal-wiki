# View_Layer_Control.md — 판독 구간 기록

구간은 1행부터 71행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–21 | View Layer Control / 창과 메뉴 — 2DH View 왼쪽에 현재 표시 가능한 레이어를 두며 창은 커서로 끌어 이동할 수 있다(10). 오른쪽 위 메뉴 아이콘으로 일반 옵션을 연다(12). 12행 메뉴 아이콘, 그림 1·2를 직접 열었다(14·18). 그림 1은 격자 옆 레이어 목록이다. 그림 2는 새 모델 레이어·외부 파일·전체 표시 전환·레이아웃 저장 및 불러오기·그림 및 애니메이션 생성·새 마스크·연결·눈금망(graticule)·XYZ 산점·레이블·오버레이 레이어 메뉴를 보여 준다. |
| 22–34 | 레이어 추가·파일·전체 표시 — Add New Layer는 활성 모델의 변수 레이어를 추가하며 상세는 링크로 안내한다(22). Open Layer from File의 형식 원문은 `\*.p2d, \*.shp, \*.kml, \*.kmz`이다(23). Turn All Layers On은 현재 모든 레이어를 표시하고 모든 전구가 켜진다(24). Turn All Layers Off는 모두 숨기고 전구가 꺼진다(25). 그림 3은 모든 전구가 켜진 상태이며 그림 4는 모두 꺼진 상태이다(27–33). 두 그림을 직접 열었다. |
| 35–48 | Save Layout — 시간 프레임·축척 막대·북쪽 화살표·범례·레이어 설정을 저장하여 나중에 다시 불러온다(35). Layer Control의 저장 아이콘 또는 2DH View 주 메뉴의 Save Layout을 사용한다(37–39). 파일·기본 경로 원문: `*2DHView.2DL*will be saved in the  *#analysis* folder by default` (39). 37행 저장 아이콘과 그림 5·6을 직접 열었다(41·45). 그림 5는 Save 2DH Layout 창과 저장 대상 파일, N이 위·E가 오른쪽인 북쪽 표시, `3000 meters` 축척, Clock·KingCo34a 시간 곡선을 보여 준다. 두 곡선에는 수치 축 눈금이 없고 현재 시각의 수직선이 있다(41행 그림). 그림 6은 주 메뉴의 Save Layout이다. |
| 49–58 | Load Layout — 불러오기 아이콘 또는 주 메뉴의 Load Layout으로 저장 파일 `2DHView.2DL`을 찾으며 기본 폴더는 `#analysis`이다(51–53). 적용 조건 원문: `If the saved layout also includes the layers, however the layer is not in the current view, the user should check the *Load Layer Settings* checkbox` (53). 51행 불러오기 아이콘과 그림 7을 직접 열었다(55–57). 그림 7은 Load 2DH Layout 창에서 Load Layer Settings가 체크된 화면이다. 배경의 북쪽 표시·축척·시간 곡선은 그림 5와 같은 구성이다. |
| 59–71 | 출력·순서·레이어 아이콘 — Generate Graphics와 Generate Animation은 Export Images and Animations 링크로 안내한다(59–60). 마스크 등의 새 레이어 옵션은 선택 즉시 목록에 추가한다(61). 레이어를 먼저 선택하고 Up/Down 화살표로 순서를 바꾼다(63). 오른쪽 클릭 메뉴는 레이어 유형에 따라 Properties·Zoom to Layer·Edit·Export·Remove 등을 제공한다(67). 63행 위·아래 화살표 그림과 그림 8을 직접 열었다(69–71). 그림 8의 기능 주석 원문은 `Light bulb - toggle layer display`, `Pointer - toggle display of cell information`, `Pen - toggle editing`, `Label - toggle display of labels`이다. 빨간 연결선이 주석을 각 아이콘에 연결한다(69행 그림). |
