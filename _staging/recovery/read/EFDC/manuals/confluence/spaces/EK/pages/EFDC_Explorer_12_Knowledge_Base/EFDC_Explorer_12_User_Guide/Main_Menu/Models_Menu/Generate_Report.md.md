구간은 1행부터 18행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 페이지 식별자, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(2–8). |
| 10–11 | Generate Report / 보고 범위 — 현재 모델의 일반 정보, 영역, 수평 격자(horizontal grid), 활성 모듈(active module), 시간 설정, 초기 조건, 외부 강제력(external forcing), 경계 조건(boundary condition), 모델 분석을 보고서로 제공한다(10). 다른 모델과 비교하는 데 쓸 수 있다고 적는다(10). |
