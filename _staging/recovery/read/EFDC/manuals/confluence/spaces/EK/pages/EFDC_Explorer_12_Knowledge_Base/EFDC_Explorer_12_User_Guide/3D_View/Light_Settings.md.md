# Light_Settings.md — 판독 구간 기록

구간은 1행부터 16행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–16 | 문서 메타데이터 — 페이지 ID·제목·space·URL·판본·갱신 시각·문서 경로와 frontmatter 구분자를 포함한다(1–9). Light Settings — 10행은 CSS 색상 규칙 뒤에 조명(light) 버튼으로 설정을 켜고 끄며 광원의 방향·세기를 정하는 기능을 설명한다. 10행의 로컬 그림을 열었다. 그림은 조명 버튼 아이콘이다. Light On을 선택하면 나침반의 붉은 점을 끌어 방향을 바꿀 수 있고 조명 속성도 바꿀 수 있다(12). 적용 조건·설정 원문: `When the box *Light On* is checked, the user can hold and move the red dot in the compass to change the light direction. The user may also adjust the properties of visible light such as ambient, diffuse, specular and global. ` (12). Figure 1의 로컬 그림을 열었다(14–16). 그림은 Light Options와 바닥 표고(bottom elevation)의 3D 화면이다. 나침반은 N이 위, S가 아래, W가 왼쪽, E가 오른쪽이며 붉은 점은 중심의 왼쪽 위에 있다(14행 그림). 화면 예시값은 `Azimuth (°): 285.12`, `Altitude (°): 54.61`, `Ambient (%): 0`, `Diffuse (%): 100`, `Specular (%): 100`, `Global (%): 17`이고 `Light On`이 선택되어 있다(14행 그림). 범례 `Bottom Elevation (m)`의 양 끝 값은 `-19.004`, `5.078`이다. 본문은 이 예시값을 기본값으로 정의하지 않는다. 빈 줄·그림 마크업·캡션을 포함한다(11·13–16). |
