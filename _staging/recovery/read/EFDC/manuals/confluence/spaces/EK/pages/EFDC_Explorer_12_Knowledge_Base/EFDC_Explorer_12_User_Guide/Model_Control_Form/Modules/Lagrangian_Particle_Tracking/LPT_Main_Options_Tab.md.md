| 10–15 | LPT Main Options / 계산 방법·시각 — `Compute Drifters`를 켜야 LPT를 사용할 수 있다(10). 전역 시작·종료 시각은 모든 그룹에 적용하는 율리우스 일(Julian days)로 설정한다(10). 입자 위치를 `EE\_Drifters` 파일에 쓰는 빈도의 단위는 분이며, 모든 그룹에 적용하고 보통 EE 출력 빈도와 독립적이다(10). 원문: `The *LPT Main Options* tab is shown in [LPT Main Options Tab#Figure 1](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/246645001#LPTMainOptionsTab-Figure1). Within the *LPT Computational Method & Timing* frame, switch on drifters with the *Compute Drifters* checkbox before LPT can be implemented. Here the user will set the global computational period starting and ending days for the particle tracking in Julian days for all groups. The frequency (in minutes) of writing the particle positions to the EE\_Drifters file is specified here.  This output frequency is for all groups and is independent of the normal EE output frequency.` (10). 직접 연 로컬 그림 `attachments/246645001/11-23-2020_1-53-05_PM.png` (12)은 LPT 주 옵션의 계산 시각, 수직 이동, 바람 영향, 임의 보행, 확산계수(diffusivity)와 벽면 미끄럼(wall slippage) 설정을 보여준다(12–14). 그림 표시값은 `# Drifters: 2000`, `Julian day to turn ON particle tracking: 275`, `Julian day to turn OFF particle tracking: 305`, `Output Freq (min): 2.5`, `Horizontal (m²/s): 0.5`, `Vertical (m²/s): 0.05`, `Slip Factor: 0`이다(12 그림). 그림은 `Particle Depths are FIXED at the Initial Seeding Depths`, `Horizontal Component Only`, `User Specified Constant Diffusivities`, `Depth is Specified`를 선택한 상태이다(12 그림). 바람 옵션은 `No Wind Drift Effect`이고 회색으로 표시된 입력은 `Coeff. A (s/m): 0.004865`, `Coeff. B (-): 0.0014434`이다(12 그림). |
| 16–21 | Vertical Movement Option / 수직 위치 조정 — 초기 종자 깊이를 고정하는 옵션을 선택하지 않으면 중립 부력(neutrally buoyant) 입자가 완전한 3차원으로 수직 이동한다(16). `Adjust Particle Depth`는 기본 옵션이다(16). 사용자는 이 옵션을 해제할 수 있다(16). 수직 조정량은 입자 깊이와 수심의 비율에 의존한다(16). 원문: `The *Vertical Movement Option* frame provides the user the option of fixing the temporal position of the particles at their initial seeding depths. If this is unchecked, the particles will drift vertically as *Fully 3D Lagrangian Neutrally Buoyant Particles*.  A sub-option is *Adjust Particle Depth.* This is the default option and adjusts particle depth with a change in water depth. In some cases, the user may wish to disallow this so that particles are not adjusted by the change in water depth, and so can turn off this adjustment by unchecking this box. If the *Adjust Particle Depth* is selected, the amount of adjustment in the vertical direction depends on the ratio of particle depth and water depth. The formula of the vertical adjustment is:` (16). 수식 원문: `dzp=  pdep/wdep\*dH` (18). 기호 정의 원문: `In which dzp is the adjustment of vertical particle depth, pdep is particle depth, wdep is water depth and dH the discrepancy of water depth of the current and previous timestep.` (20). `dzp`는 수직 입자 깊이의 조정량이다(20). `pdep`는 입자 깊이이다(20). `wdep`는 수심이다(20). `dH`는 현재 시간 단계와 이전 시간 단계의 수심 차이다(20). |
| 22–35 | Wind Drift Effects / 바람 영향·계수 — 바람 표류(wind drift)는 영향 없음, 두 바람 성분에 같은 항력계수(drag coefficient), 성분별 별도 항력계수의 세 선택지를 제공한다(22–28). 두 계수 옵션에서 사용자는 `A`와 `B`를 정의하여 입력해야 한다(26·28). 원문: `*No Wind Drift Effect*:  wind has no impact on the particles.` (24); `*Same Drag Coeff. for Both Wind Components*: the user should define coefficients A and B and then enter the values in the text boxes.` (26); `*Separated Drag Coeff. for Each Wind Component*:  the user should define coefficients A and B and then enter the values in the text boxes.` (28). Wind Drift Coefficient — 계수 `B`의 범위와 유류 이동 예측에서 쓰는 값의 원문은 `The wind drift coefficient, B, can range from 0.01 to 0.06; in many applications of oil movement forecast, the coefficient is fixed at 0.03.` (32). 문서는 계수의 추가 정보를 `Kim T-H (2014)` 참조 페이지로 연결한다(34). |
| 36–39 | Initial Particle Vertical Position Input Option / Random Walk — 사용자는 초기 수직 위치를 표고(elevation) 또는 깊이(depth)로 지정한다(36). 원문: `Within the *Initial Particle Vertical Position Input Option* the user may specify whether the vertical positions provided are elevations or depths.` (36). `Random Walk`를 켜면 수직만, 수평만, 두 방향을 함께 사용하는 선택지를 제공한다(38). 사용자는 EFDC 확산 계산의 `AH`, `AV` 또는 직접 입력한 일정 확산계수를 사용할 수 있다(38). 원문: `If the *Random Walk* checkbox is checked, the user has a number of options for the *Random Walk Dimensional Options*. The user may select the random walk-in only the vertical direction, in only the horizontal direction, or both vertical and horizontal directions at the same time. In addition, the user may specify the *Random Walk Size Options* by selecting to allow EFDC Diffusion calculations to be used for the AH and AV. Alternatively, there is the option for *Specified Constant Diffusivities* that should be inputted by the user.` (38).  |
| 40–40 | Wall Slippage — 문서는 대부분의 실제 사례에서 벽면 미끄럼 계수를 0.0으로 사용해야 한다고 적는다(40). 수로(flume)와 기타 시험 사례에서는 1.0 또는 완전 미끄럼(full slip)이 더 나을 수 있다고 적는다(40). 원문: `*Wall Slippage* frame allows the user to set the wall slip factor. For most real-world cases, the wall slip should be 0.0. However, for flume and other test cases, it may be better to use 1.0 or full slip.` (40).  |
