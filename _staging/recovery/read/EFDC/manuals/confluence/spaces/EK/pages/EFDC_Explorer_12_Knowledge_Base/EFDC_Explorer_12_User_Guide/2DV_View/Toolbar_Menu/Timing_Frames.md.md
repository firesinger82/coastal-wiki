# Timing_Frames.md — 판독 구간 기록

구간은 1행부터 14행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–14 | 문서 메타데이터 — 페이지 ID·제목·space·URL·판본·갱신 시각·문서 경로와 frontmatter 구분자를 포함한다(1–9). Timing Frames — 2DV View에 경계(boundary)의 시간 프레임(timing frame)을 표시한다(10). Available Boundary Groups에서 경계를 선택하고 Add를 누르면 오른쪽 Show Timing Frames에 추가한다(10). 시작·종료 시각과 Y축에 맞는 Time Scale 조정을 설명한다(10). 설정·적용 원문: `The *Timing Frames*allows the user to display timing frames of boundaries on the *2DV View.*When this function is selected, a *Timing Frames*form appears, as shown in [Figure 1](#Figure1). The form allows users to define new frames by selecting from the *Available Boundary Groups*box. Clicking the *Add*button causes the selected boundary to be added to *Show Timing Frames*in the right panel. In this frame, the user can define the beginning and ending time of the timing frame with *Time Begin, Time End.*The *Time Scale*may be adjusted up or down to set the Y-axis to the most suitable value to see essential events.` (10). Figure 1의 로컬 그림을 열었다(12–14). 그림은 경계 그룹 트리와 시간 프레임 설정 표가 있는 화면이다. 표의 예시 행은 `ID: Flow01`, `Group: Flow01`, `Time Begin: 136.75`, `Time End: 164.75`, `Time Scale: 5`이다(12행 그림). `ATM Parameter` 셀은 비어 있고 `Show`, `Model Time`은 선택되어 있다(12행 그림). 표에는 시간·축척 값의 단위가 표시되지 않는다. 빈 줄·그림 마크업·캡션을 포함한다(11–14). |
