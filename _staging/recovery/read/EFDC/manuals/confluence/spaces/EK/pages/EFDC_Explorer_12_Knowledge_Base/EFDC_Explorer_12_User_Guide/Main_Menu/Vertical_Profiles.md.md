구간은 1행부터 16행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 페이지 ID, 제목, space, 원문 URL, 버전, 갱신 시각, 문서 계층 경로와 frontmatter 구분선을 포함한다(1–9). |
| 10–13 | Vertical Profiles — 수직 프로파일(vertical profile)을 주 도구 모음에서 생성하는 방법을 소개한다(10). 창 선택 상태에 관한 조건은 `If no vertical profile window is currently selected, the only option is *New Vertical Profile*([Figure 1](#Figure1)).` (10)이다. 색상 CSS와 Vertical Profile Plots 문서 링크를 포함한다(10). `2019-10-02_10-53-57_AM.png`를 열었다(12). Vertical Profile 메뉴가 열려 있으며 `New Vertical Profile`, `Timing Frames`, `Load Layout` 항목이 보이는 화면이다(12, 그림). |
| 14–16 | 수직 프로파일 창이 현재 창인 경우 — 추가 메뉴 표시 조건과 다른 기능과의 관계는 `When a vertical profile plot window is opened as the current window, clicking on the *Vertical Profile* from the main menu will show additional items as shown in [Figure 2](#Figure2). The function of these items is identical to the main toolbar items and described in [*2DV View*](/wiki/spaces/EK/pages/223019036/2DV+View)*.*` (14)이다. `2019-10-02_10-57-26_AM.png`를 열었다(16). Vertical Profile 메뉴에 Data Settings·Chart Settings·Marker Settings·Comments·Timing Frames·Change Fonts·확대와 보기 변경·자료 가져오기와 내보내기·그림과 애니메이션 생성·배치 저장과 불러오기 항목이 추가된 화면이다(16, 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행은 수직 프로파일 창이 선택되지 않았을 때 유일한 옵션을 `New Vertical Profile`이라고 설명한다. 12행의 해당 예시 그림에는 `Timing Frames`와 `Load Layout`도 표시되어 있다.
- 10·14행의 `#Figure1`, `#Figure2` 참조에 대응하는 앵커 정의와 Figure 번호 캡션이 이 Markdown에 없다.
