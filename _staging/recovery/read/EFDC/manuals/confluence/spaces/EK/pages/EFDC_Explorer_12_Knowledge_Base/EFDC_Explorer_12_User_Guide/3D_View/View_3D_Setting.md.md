# View_3D_Setting.md — 판독 구간 기록

구간은 1행부터 23행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–18 | 문서 메타데이터 — 페이지 ID·제목·space·URL·판본·갱신 시각·문서 경로와 frontmatter 구분자를 포함한다(1–9). View 3D Setting / 제목·축척·축 — Figure 1의 로컬 그림을 열었다(10–11). 그림은 범례에서 설정 창으로 내려가는 붉은 RMC 화살표와 3D View Settings를 보여 준다. 화면 예시값은 `Main Title: EFDC_DSI Testing`, `Sub Title: Lake Washington`, `Easting Scale Modifier: 1`, `Northing Scale Modifier: 1`, `Vertical Scale Modifier: 5`, `Length (px): 25`이다(10행 그림). 주제목의 `Visible`과 3D Axes의 `Show`는 선택되고 부제목의 Visible은 선택되지 않았다. 시간·텍스트 글꼴 버튼은 `Time`, `Text`이다. 범례 `Bottom Elevation (m)`의 양 끝 값은 `-59.840`, `10.812`이고 `Water Surface Elevation (m)`의 양 끝 값은 `6.645`, `6.662`이다. 범례는 `Vertical Exaggeration: 5`도 표시한다(10행 그림). 제목 표시·글꼴 설정 원문: `[View 3D Setting#Figure 1](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2171764737#View3DSetting-Figure1) shows the 3D View settings. From this form, the user can set the *Main Title* and *Sub Title* are visible or invisible by checking on the box; the font of time and text for the layers in the 3D legend can be changed by clicking on the *Time* and *Text* buttons.` (13). 수직 과장(vertical exaggeration)과 편집 제한 원문: `To change the vertical exaggeration by entering a value in the *Vertical Scale Modifier.* The values for the fields of *Easting and Northing Scale Modifier* are not editable.` (15). 축 표시 조건 원문: `To show on/off the 3D axes by checking on the *Show* box of the *3D Axes* frame.` (17). 빈 줄·그림 마크업·캡션을 포함한다(10–18). |
| 19–23 | View 3D Setting / 층 색상 — 층에서 RMC를 수행해 속성을 편집하고 여러 색상표(color ramp)·범위 경계값·자동 색상·회색 또는 고정색·셀 사이 색 혼합을 사용할 수 있다(19). 설정 설명 원문: `RMC to the layer, the user can edit the payer properties. They can display multiple color ramps simultaneously. The user may define the color ramp cut-offs within each option or whether to auto-color based on the parameters min and max. The user may also display a gray color ramp or use a fixed color. The gradient fill option blends the color from one cell to another providing a more realistic appearance. ( as shown in [View 3D Setting#Figure 2](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2171764737#View3DSetting-Figure2))` (19). 표시 옵션의 적용 조건 원문: `The options displayed depend on which sub-models have been activated in EE.` (21). 23행의 로컬 그림을 열었다. 그림은 Surface Layer Properties 설정 화면이다. 화면 예시값은 `Layer Name: Salinity`, `Min. Value: 0`, `Max. Value: 34.99999`, `Color Ramp: Default`, `Legend Format: F3`, `Cell Overlap: 1`이다(23행 그림). `Layer Visible`, `Show Unit`, `Show in Legend`, `Automatic Range`, `Filled with Color Ramp`는 선택되고 `Auto-Scale with View`, `Reverse`, `Smooth Field`, `Show Contours`는 선택되지 않았다. `Under Range Color`는 파란색, `Over Range`는 붉은색, `Dry Cell Color`는 체크무늬 선택 표시이다(23행 그림). `Opacity`는 수치 없는 슬라이더이다. 본문은 화면 예시값을 기본값으로 정의하지 않는다. 빈 줄·그림 마크업을 포함한다(20·22–23). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 13·19행의 그림 링크는 `#View3DSetting-Figure1`·`#View3DSetting-Figure2`를 가리킨다. 이 파일에는 해당 ID 선언이 없고 두 번째 그림에는 캡션도 없다(23).
- 19행: `RMC`의 뜻을 이 파일은 정의하지 않는다.
- 19행은 속성 편집 대상을 `payer properties`라고 적는다. 이어지는 문장들은 층의 색상 설정을 설명한다.
