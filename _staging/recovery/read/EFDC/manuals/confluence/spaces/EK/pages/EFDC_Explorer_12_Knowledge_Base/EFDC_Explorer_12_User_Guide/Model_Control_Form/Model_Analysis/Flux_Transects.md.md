## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10·18 첫 그림: 본문은 기능 위치를 `Vertical Profile` 하위 탭으로 적는다. 그림에서 선택된 항목은 `Flux Transects (4)`이다.
- 18의 세 그림: 비교표 예제의 Parameter 값은 `16`이다. Station Information의 선택 매개변수는 `Flow`이다. 코드 목록의 `16` 설명은 `Direction`이다.
