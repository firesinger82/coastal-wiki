| 구간 | 내용 |
|---|---|
| 1–11 | 문서 메타데이터 — 페이지 ID·제목·space·URL·판본·갱신 시각·문서 경로와 frontmatter 구분자를 포함한다(1–9). Blanking and Clipping / 적용 대상 — 10행은 CSS 색상 규칙 뒤에 메뉴 아이콘이나 층의 오른쪽 마우스 메뉴로 숨김(blanking)·값 잘라내기(clipping)를 실행하는 방법을 설명한다. 적용 조건 원문: `This function is only implemented for layers of Water Column and Model Grid.` (10). 오른쪽 마우스 메뉴 이름은 `Clipping/Blanking`이다(10). 10행의 로컬 그림을 열었다. 그림은 이 기능의 가위 모양 버튼 아이콘이다. 빈 줄을 포함한다(11). |
| 12–15 | Grid Cell Blanking — 선택한 I·J·K 인덱스 범위의 셀만 표시하는 예시를 설명한다(14). 범위·적용 원문: `Users may view certain cells along with the selected I, J, or K index by using the blanking option. For example, the model in this case ([Figure 1](#BlankingandClipping-Figure1))  is only being viewed between 3 and 80 on the I column index, between 3 and 46 on the J row index, and from 1 to 5 on the K layer index.` (14). 빈 줄과 절 제목을 포함한다(12–15). |
| 16–22 | Value Clipping — 특정 값 범위의 셀을 표시한다(18). 염분(salinity) 예시 범위·단위 원문: `The function allows users to display the cells in a certain value range. For instance, [Figure 1](#BlankingandClipping-Figure1) presents cells in the salinity layer which have a value range from 0 to 30 ppt.` (18). Figure 1의 로컬 그림을 열었다(20–22). 그림은 Clipping/Blanking Options와 염분 격자를 보여 준다. 화면 예시값은 `Column Index (I) From: 3`, `To: 80`; `Row Index (J) From: 3`, `To: 46`; `Layer Index (K) From: 1`, `To: 5`; `Value Range From: 0`, `To: 30`이다(20행 그림). `Use Blanking`, `Clipping by Value`가 선택되어 있다. 격자는 회색 전체 격자 중 염분 색상이 있는 셀을 보여 준다. 범례 `Salinity (ppt)`의 양 끝은 `0.000`, `35.000`이다(20행 그림). 이 범례의 상한과 셀 표시 범위의 상한은 서로 다른 화면 요소이다. 별도 축 눈금은 없다. 빈 줄·절 제목·그림 마크업·캡션을 포함한다(16–22). |
