# Mass_Flux_Tool.md — 판독 구간 기록

구간은 1행부터 20행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 메타데이터 — 페이지 ID, 제목, space, 원문 URL, 버전, 갱신 시각, 문서 계층 경로와 frontmatter 구분선을 포함한다(1–9). |
| 10–15 | Mass Flux Tool — 단면(profile)을 통과하는 질량 플럭스를 계산한다(10). 대상과 용도는 `*Mass Flux Tool*: This tool is used to calculate the mass flux through a profile for parameters such as flow, sediments, and toxics and is most useful when wanting to compute pollutant loading.` (10)이다. `2.png`를 열었다(12). Tools 메뉴의 Mass Flux Tool 항목을 강조한 화면이며 Figure 1 캡션을 포함한다(12–15). |
| 16–20 | Flux Extraction — 먼저 플럭스 선(flux line)을 보유하거나 2차원 수평 보기(2DH)의 다중선(polyline) 도구로 생성해야 한다(16). 선·성분·계산 기간의 선택 지시는 `In order to use this tool, the user must first have a flux line or create a flux line with the polyline tool in *2DH*then select it with the *Browse* button. The user should then select the constituents from the top-down list and the time range over which the flux will be calculated (as shown in [Figure 2](#Figure2)).` (16)이다. `3.png`를 열었다(18). `Transect` 경로의 끝은 `ProfileRC.p2d`이며 `Constituent`의 표시값은 `Salinity`이다(18, 그림). `Class`는 비활성 상태이다(18, 그림). 방향 옵션은 `Dominant Flow`, `I Direction`, `J Direction`, `Total Flow`이며 `Total Flow`가 선택되어 있다(18, 그림). 기간 옵션 `Entire Series`가 선택되어 있고 `Time Range`는 선택되지 않았다(18, 그림). 비활성 시간 입력란은 `Time From: 0`, `To: 10`이다(18, 그림). Browse·Report·Plots·Cancel 버튼과 Figure 2 캡션을 포함한다(18–20). |
