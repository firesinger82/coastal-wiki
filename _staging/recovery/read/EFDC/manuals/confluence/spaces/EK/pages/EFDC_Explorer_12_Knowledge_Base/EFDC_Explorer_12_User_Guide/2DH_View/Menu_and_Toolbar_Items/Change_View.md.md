# Change_View.md — 판독 구간 기록

구간은 1행부터 31행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 메타데이터 — 문서 ID, 제목, space, URL, 버전, 갱신 시각과 문서 계층을 기록한다(1–9). |
| 10–16 | Change View / 사각형 확대(Zoom To Rectangle) — 메뉴와 메인 화면의 Change View에는 네 옵션이 있다(10). 관심 영역에서 오른쪽 클릭 후 끌어 사각형을 만든다(12). 도구 모음 아이콘 또는 `ALT + RMC`로도 활성화한다(14–16). 14행 그림을 직접 열었으며 빨간 사각형과 돋보기 아이콘을 보여 준다. |
| 17–26 | 이동(Pan/Shift)·이전 화면(Previous View) — 마우스 커서 방향으로 모델 격자 영역을 이동하며 도구 모음 아이콘 또는 `SHIFT + LMC`를 사용한다(17–21). Previous View는 이전 2DH 화면으로 돌아가며 도구 모음 아이콘으로도 실행한다(22–26). 19행 그림은 이동 화살표와 손 모양 아이콘이며 24행 그림은 되돌아가는 화살표와 돋보기 아이콘이다. 두 그림을 직접 열었다. |
| 27–31 | 전체 범위 표시(View Full Extents) — 2DH View의 모든 항목이 보이도록 자동 축소한다(27). 도구 모음 아이콘 또는 `CTRL+ E`로 활성화한다(27). 27행 그림은 바깥으로 향하는 네 화살표 아이콘이다. 그림 1은 Change View의 네 하위 메뉴를 보여 준다(29–31). 두 그림을 직접 열었다. |
