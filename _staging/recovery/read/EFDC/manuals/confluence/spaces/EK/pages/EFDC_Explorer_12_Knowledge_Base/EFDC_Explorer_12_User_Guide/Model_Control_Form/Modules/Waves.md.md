| 10–17 | 파랑(wave) 모듈 활성화. Activate the Wave Module 제목 앞에 CSS 텍스트가 남아 있다 (10). EFDC+ Modules에서 파랑 모듈의 그래픽 사용자 인터페이스(Graphical User Interface, GUI)를 활성화할 수 있다 (12). `Wave1.png`를 열었다 (14). 그림은 EFDC+ Modules의 Waves 체크 상자가 선택된 화면이다 (14). Figure 1 캡션과 빈 줄을 포함한다 (11–17). |

Figure 2 캡션과 빈 줄을 포함한다 (19, 22, 24–25). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 10행 제목 앞에 CSS 색상 규칙이 본문 텍스트로 남아 있다.
- 12·18행의 `#Waves-Figure1`, `#Waves-Figure2` 참조에 해당하는 명시적 앵커 정의가 이 파일에 없다. 16·25행에는 캡션이 있다.
