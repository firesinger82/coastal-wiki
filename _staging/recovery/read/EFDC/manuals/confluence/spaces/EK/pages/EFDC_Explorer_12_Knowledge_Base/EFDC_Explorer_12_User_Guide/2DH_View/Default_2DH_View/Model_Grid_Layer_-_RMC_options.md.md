| 10–15 | Model Grid Layer / RMC 메뉴 — 시작 문장은 `Mode Grid` 레이어를 선택하라고 적는다(10). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/2090696766/10-28-2021_1-35-21_PM.png`을 열었다(12). 그림 1은 Model Grid 레이어의 속성·편집·고도와 체적 조회·좌표 변환·격자 내보내기 메뉴이다(12행 그림). 배경 저면고 범례는 `Bottom Elevation (m)`의 `-4.536`–`-1.500`이다(12행 그림). 캡션과 빈 줄을 포함한다(14–15). |
| 16–37 | Properties / Model Grid Properties — 레이어 이름·범례와 격자 표시, 외곽선(outline) 표시를 설명한다(18–26). Layer Visible 설명은 boundaries 레이어를 대상으로 적는다(22). `Show East`, `Show South`, `Use Corners`는 이름만 적는다(28–32). 설정·조건 원문: `The *Layer Name* shows the name of the layer which is shown in the Layer Control and in the legend if the check-box *Show in Legend* is checked. The user can rename the layer name here.` (20); `*Layer Visible* check-box allows showing on or off the boundaries layer.` (22); `*Show Grid:* Show on/off the grid in the *2DH View*.` (24); `*Show Outlines:* Show on/off the outline of the model grid in the *2DH View*.` (26); `*Show East:*` (28); `*Show South:*` (30); `*Use Corners:*` (32); `*Grid Line Settings:* Settings for styles and colors of grid line and grid outline.` (34). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/2090696766/11-1-2021_5-06-43_PM.png`을 열었다(36). 그림 2는 Model Grid Properties 창이다(36행 그림). Show Grid·Show Outlines·Use Corners가 선택되어 있고 Show East·Show South는 선택되지 않았다(36행 그림). 격자선과 격자 외곽선의 스타일·색·폭을 별도로 설정한다(36행 그림). 절 제목과 빈 줄을 포함한다(16–37). |
| 38–47 | Zoom to Layer / Edit — Model Grid의 전체 범위를 표시한다(40). `Primary Group`, `Parameter`를 변경하여 현재 모델 격자 레이어를 다른 레이어로 변경한다(44). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/2090696766/11-1-2021_5-16-47_PM.png`을 열었다(46). 그림 3은 `Primary Group: Model Grid`, `Parameter: Model Grid`를 선택한 옵션 창이다(46행 그림). 절 제목과 빈 줄을 포함한다(38–47). |
| 48–53 | View Elevation-Volume — 고도(elevation)와 체적(volume), 고도와 면적(area)의 관계를 두 곡선으로 표시한다(50). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/2090696766/11-1-2021_5-19-45_PM.png`을 열었다(52). 그림 4의 빨간 곡선은 `Elevation - Volume`, 파란 곡선은 `Elevation - Area`이다(52행 그림). 세로축은 `Elevation (m)`이며 눈금은 위에서 아래로 `-1.50`, `-1.75`, `-2.00`, `-2.25`, `-2.50`, `-2.75`, `-3.00`, `-3.25`, `-3.50`, `-3.75`, `-4.00`, `-4.25`, `-4.50`, `-4.75`이다(52행 그림). 아래 가로축은 `Volume (10⁶m³)`이고 눈금은 `0.0000`, `212.0162`, `424.0325`, `636.0487`, `848.0649`, `1060.0812`, `1272.0974`, `1484.1136`, `1696.1299`, `1908.1461`, `2120.1624`이다(52행 그림). 위 가로축은 `Area (km²)`이며 보이는 눈금은 `0.8399`, `178.8900`, `356.9400`, `534.9901`, `713.0401`, `891.0902`, `1069.1402`, `1247.1903`, `1425.2403`, `1603.2904`이다(52행 그림). 두 곡선은 왼쪽 아래에서 오른쪽 위로 이어지고 파란 곡선의 상단에는 수평 구간이 있다(52행 그림). 절 제목과 빈 줄을 포함한다(48–53). |
| 54–61 | Export Elevation-Volume / 설명 없는 항목 — 고도·면적·체적 시계열 내보내기의 형식과 기본 폴더 원문: `This option will export the time series of Elevation-Area-Volume to a file (\*.dat). The file will be located in the *#analysis* folder as default.` (56) `Auto-rotate Cell Corners`, `Convert Grid Coordinates`는 절 제목만 있다(58·60). 사이의 빈 줄을 포함한다(54–61). |
| 62–69 | Export to CVLGrid / Export to RGFGrid — 격자 형식과 해당 파일을 열 수 있는 소프트웨어를 적는다(64·68). 형식 원문: `This option will export the model grid to a file (\*.cvl). | 70–81 | Export Grid Cells / Export Grid Lines — 형식과 파일명을 선택하여 격자 셀 또는 격자선을 내보낸다(72·78). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/2090696766/11-3-2021_10-08-01_AM.png`을 열었다(74). 그림 6은 `Grid_cells` 저장 창이다(74행 그림). 로컬 그림 `models/EFDC/raw/manuals/confluence/spaces/EK/attachments/2090696766/11-3-2021_10-16-08_AM.png`을 열었다(80). 그림 7은 `gridline.p2d` 저장 창이다(80행 그림). 두 창의 파일 형식 선택지는 `P2D Files (*.p2d)`; `Land Boundary (*.ldb)`; `KML files (*.kml;*.kmz)`; `Shapefile (*.shp)`; `Mapinfo (*.mif)`; `Point Scatter (XYZ) Data (*.xyz, *.p2d, *.txt, *.dat)`; `Data Files (*.dat)`; `Text Files (*.txt)`이다(74·80행 그림). 폴더는 `#analysis`이다(74·80행 그림). 절 제목과 빈 줄을 포함한다(70–81). |
