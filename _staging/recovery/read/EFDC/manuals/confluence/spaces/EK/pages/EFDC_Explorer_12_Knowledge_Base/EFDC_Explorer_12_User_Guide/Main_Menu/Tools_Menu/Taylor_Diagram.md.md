| 16–19 | Taylor Statistics와 도표 생성 — 기준 시계열(base series) 선택, Calculate·OK의 순서 및 예시 성능 해석은 `To use this option, click the *Tools* menu then select  *Taylor Diagram* as shown in [Taylor Diagram#Figure 2](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2099511297#TaylorDiagram-Figure2), then the *Taylor Statistics* form will be displayed as shown in [Taylor Diagram#Figure 3](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2099511297#TaylorDiagram-Figure3). Finally, click the *OK* button to display the plot shown in [Taylor Diagram#Figure 4](https://eemodelingsystem.atlassian.net/wiki/spaces/EK/pages/2099511297#TaylorDiagram-Figure4). This diagram uses three red points to represent the two models and the observed data. From this, we can see that the red point representing the simulated results of Model 2 is closer to the observed data than Model 1. Therefore Model 2 demonstrates better performance.` (16)이다.
