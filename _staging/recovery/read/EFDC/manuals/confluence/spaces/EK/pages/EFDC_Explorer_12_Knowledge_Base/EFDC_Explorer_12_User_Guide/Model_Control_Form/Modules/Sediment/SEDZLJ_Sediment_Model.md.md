| 10–15 | SEDZLJ 개요. 문서는 Sandia에서 개발한 알고리즘이라고 소개하며 Thanh et al. (2008)과 Jones and Lick (2001)을 언급한다 (10–12). 점착성 여부와 무관하게 대표 입경으로 여러 퇴적물 종류를 다루며, 수주(water column)·퇴적층·침식 및 퇴적 교환에 적용한다고 설명한다 (12). SEDFlume은 층 깊이와 가해진 전단응력에 따른 두께 변화를 측정한다 (12). 14행 도식의 실선 Dynamics 화살표는 EFDC+ Hydrodynamic Model에서 SEDZLJ Sediment Transport Module로 향한다. 점선 Morphological Feedback 화살표는 역방향이다. 하단은 사용자 정의 Sediment Class #1·#2·#3·…와 Water Column·Sediment Bed를 선으로 연결한다. |
| 16–29 | 입력 파일과 모듈 활성화. 표준 입력 자료의 역할은 `bed.sdf                 General SEDZLJ setup, sediment properties, erosion properties for active and deposition bed layers` (18); `erate.sdf               Erosion properties for parent-bed layers, which were acquired from SEDFlume core tests` (20); `core\_field.sdf      Linkage of SEDFlume erosion properties to model grid cells` (22)이다. 다른 기관의 일부 형식을 불러와 변환할 수 있다고 적는다 (24). `Users can activate the SEDZLJ sediment transport module by checking the box *Sediment Transport* in the *EFDC+ Modules* tab and selecting *SEDZLJ* in the drop-list.` (26)이다. 28행 화면은 Sediment Transport의 SEDZLJ 선택과 탐색 트리의 활성화 항목을 보여 준다. 표시된 전역 수송 옵션은 `Upwind Difference; Anti-Diffusion Correction; Flux Limitation` (28행 그림)이다. |
| 30–35 | Major Settings. 퇴적층 수와 입도 종류 수를 바꾸면 기존 초기·경계 조건을 잃을 수 있다고 경고한다 (32). 34행 화면의 상단 표시값은 `# Sediment Bed Layers: 7; # Sediment Classes: 6` (34행 그림)이다. 아래 General 영역도 함께 표시된다. 해당 설정과 식은 36–57 구간에서 56행 그림을 기준으로 옮긴다. |
| 36–57 | General Tab. 지형 변화와 수리 피드백, 경사 영향, 수직 농도 역확산(anti-diffusion) 옵션이 있다 (38). 시작일은 침식·퇴적 없이 수리장을 안정화시키는 준비 기간(spin-up)을 설정한다 (40). `Date/Time to Start Sediment Transport (days)` (40)이다. 퇴적 제한의 범위·의미·영점 조건은 `*Deposition Limit of Water Column Sediments* can be determined between zero and one, and this parameter represents the minimum fraction of sediment in the bottom water column layer allowed to deposit in a single time step. Setting this value to zero would cause 100% of the amount to be deposited in one-time step, however, this is also dependent on the settling rate specified.` (42)이다. `Maximum Deposition Layer Thickness (m)` (44); `Minimum Water Depth for Shear Stress Updates (m)` (46); `Sediment Timestep (s)` (48)를 설명한다. 외부 ASCII 또는 이진 침식률 행렬을 사용할 수 있다 (52). Hard Bottom Option은 `bedmap.inp`에서 `zero`이면 수주 입자의 이류(advection)는 계속하되 침식·퇴적 교환을 비활성화하고, `one`이면 교환을 활성화한다 (54). 원문의 적용 조건은 `*Hard Bottom Option* allows the user to specify in which cell erosion or deposition processes are activated or not.  For example, no interaction between sediment bed and water column can occur at deactivated cells where zero value is assigned (bedmap.inp), so suspended sediment load is advected during the simulation but the particles in suspension are not allowed to settle down on riverbed in such deactivated areas. On the other hand, erosion or deposition processes are fully simulated at activated cells where a value of one is assigned (bedmap.inp).` (54)이다. 56행 그림의 표시값은 `Date/Time to Start Sediment Transport (days): 1` (56행 그림); `Deposition Limit of Water Column Sediments (0-1): 1` (56행 그림); `Maximum Deposition Layer Thickness (m): 1` (56행 그림); `Minimum Water Depth for Shear Stress Updates (m): 0.1` (56행 그림); `Sediment Timestep (s): 1` (56행 그림); `Options: Not Used` (56행 그림)이다. 세 계산 옵션·Use Hotstart File·Write Diagnostics·BEDMAP.INP 적용은 미선택이다. Lookup Table and Bed Properties by Core ID가 선택되었다. 나머지 옵션의 표시 식 `E=A*Tau^n` (56행 그림)은 LaTeX로 `E=A*\mathrm{Tau}^{n}`이다. 세 번째 옵션은 `SEDB, BEDLAY, BEDBDN and BEDDDN` (56행 그림)을 사용한다. |
| 58–67 | Sediment Properties Tab. 입경·침식 및 부유 임계 전단응력·침강 속도를 지정한다 (60). `dynes/cm2` (60) 단위를 사용한다. Sediment Info의 Van Rijn 계산값은 안내용이며 입력 파일에 자동 사용하지 않는다 (62). Initialize Defaults를 누르면 표로 가져온 값을 모델에 사용한다 (64). 66행 그림의 열은 `Class / Size (μm) / Critical Shear Stress for Erosion (dynes/cm²) / Critical Shear Stress for Suspension (dynes/cm²) / Settling Velocity (cm/s)` (66행 그림)이다. 각 행은 `1 / 40 / 1.54 / 1.54 / 0.14388` (66행 그림); `2 / 125 / 1.54 / 2.22 / 1.177861` (66행 그림); `3 / 275 / 1.80 / 5.19 / 3.962058` (66행 그림); `4 / 800 / 4.03 / 16.64 / 10.1979` (66행 그림); `5 / 2400 / 16.61 / 75.21 / 21.68077` (66행 그림); `6 / 6000 / 53.42 / 188.02 / 34.28032` (66행 그림)이다. |
| 68–77 | Sediment Bed Tab. 활성층(active layer)·퇴적층(deposition layer)의 특성과 소류사(bedload) 옵션을 지정한다 (70–74). `Number of Shear Stress Categories to Calculate Erosion Rates` (70)는 `only for` (70) Erosion Rates Option 1에 적용된다. 76행 그림은 `Active Layer Thickness Multiplier: 15` (76행 그림); `Number of Shear Stress Categories to Calculate Erosion Rates: 8` (76행 그림); `Number of Sediment Size Categories: 8` (76행 그림); `Bank Erosion: Disabled; # of Bank/Channel Pairs: 0; # of Time Series: 0` (76행 그림); `Bedload Grainsize Cutoff (μm): 64` (76행 그림)이다. Compute Bedload for Coarser Classes와 Allow Bedload to Exit Domain at BCs가 선택되었다. 침식 특성 표의 열은 `Size (μm) / Critical Shear Stress for Erosion (dynes/cm²)` (76행 그림)이고, 행은 `0.1 / 1.535724` (76행 그림); `40 / 1.535724` (76행 그림); `125 / 1.535724` (76행 그림); `275 / 1.800894` (76행 그림); `800 / 4.026866` (76행 그림); `2400 / 16.61321` (76행 그림); `6000 / 53.41545` (76행 그림); `10000 / 89.02575` (76행 그림)이다. |
| 78–83 | Erosion Rates Tab. D50에 따른 활성·퇴적층 침식 특성 표를 사용하며 General의 옵션에 따라 형식이 달라진다 (80). 82행 그림은 `# Sediment Bed Layers: 5; # Sediment Classes: 3` (82행 그림)이다. 침식률 표의 열은 `Size (μm) / Erosion Multiplier (A) / Erosion Exponent (n) / Maximum Erosion Rate (cm/s)` (82행 그림)이다. 각 행은 `0.001 / 1 / 0.331 / 0.1` (82행 그림); `4 / 0.03562 / 1.403 / 0.1` (82행 그림); `63 / 0.00186 / 2.231 / 0.1` (82행 그림); `125 / 0.00186 / 2.231 / 0.1` (82행 그림); `500 / 0.00139 / 2.337 / 0.1` (82행 그림); `1000 / 0.00048 / 2.671 / 0.1` (82행 그림); `2000 / 6E-05 / 3 / 0.1` (82행 그림); `4000 / 1E-05 / 3 / 0.1` (82행 그림)이다. |
| 84–95 | Core Definitions Tab. 모재층(parent-bed layer)의 공간별 물성과 침식률을 위한 코어를 정의한다 (86–92). 94행 그림의 설정은 `Number of SEDFlume Cores: 3; Riverine; 1 / # 3` (94행 그림); `Water Density (g/cm³): 1; Sediment Density (g/cm³): 2.65` (94행 그림); `Easting (meters): 270677; Northing (meters): 1675088` (94행 그림)이다. 층 물성 표의 보이는 열은 `Layer / Critical Shear Stress (dynes/cm²) / Dry Density (g/cm³) / Thickness (cm) / D1=40 (μm) / D2=125 (μm) / D3=275 (μm)` (94행 그림)이다. 완전히 보이는 값은 `Active 1 / 0.1 / 0.801 / 0 / 10 / 50` (94행 그림); `Deposited 2 / 0.1 / 0.801 / 0 / 10 / 50` (94행 그림); `3 / 3 / 0.801 / 15 / 10 / 50` (94행 그림); `4 / 3.5 / 0.801 / 15 / 10 / 50` (94행 그림)이다. D3 이후 값은 보이지 않는다. SEDFlume Measured Erosion Rates의 완전히 보이는 전단응력 열은 `0.01 / 2 / 4 / 8 / 16` (94행 그림)이다. 대응 침식률 행은 `Layer 1 / 2.6387E-10 / 5.8128E-05 / 0.00029065 / 0.0014533 / 0.007267` (94행 그림); `Layer 2 / 2.6387E-10 / 5.8128E-05 / 0.00029065 / 0.0014533 / 0.007267` (94행 그림); `Layer 3 / 2.6387E-10 / 5.8128E-05 / 0.00029065 / 0.0014533 / 0.007267` (94행 그림); `Layer 4 / 3.4339E-15 / 1.1204E-06 / 1.456E-05 / 0.0001892 / 0.0024587` (94행 그림)이다. 오른쪽의 추가 전단응력 열 제목과 침식률은 화면 경계에서 잘렸다. |
| 96–109 | Core Assignments Tab. 최근접 코어 또는 ID가 있는 다각형으로 격자에 코어 정의를 배정한다 (98–104). P2D는 코어 ID의 한 줄 헤더 뒤에 다각형의 X/Y 좌표를 둔다 (104). 출력은 `DSI Standard format (I, J, and Core Number) or Sandia Lab Standard format` (106)이다. 108행 그림은 Allow Core Definitions on a Cell by Cell Basis와 Assign Core Numbers using Polygons with ID's를 선택했다. `Default Core Number: 3` (108행 그림)이다. 다각형 밖 격자에는 기본 코어를 배정한다는 문구가 있으며, DSI Standard·Sandia Lab Standard 선택지는 둘 다 미선택이다. 파일 경로는 오른쪽이 잘려 전체를 판독할 수 없다 (108행 그림). |
| 110–117 | Wave Options Tab. `No Wave Action, Wind Wave (SEDZLJ),` (112)와 `STWAVE.` (112)를 제공한다. 현재 경계층에만 영향을 주며 EFDC 파랑 하위 모델과의 연계는 아직 제공되지 않는다고 적는다 (112). 원문의 파일 요구와 선택 조건은 `If the standard SEDZLJ wind wave option is selected, then the EE wind wave option is not used.  In this case, the user must ensure they have all the correct files such as FETCH.INP.  Refer to the SEDZLJ user guide for details on this format. Conversely, if the STWAVE option is selected then correctly formatted STWAVE files are required.` (114)이다. 116행 그림의 Wave Action Option은 `No Wave Action` (116행 그림)이며 bed shears only를 명시한다. |
| 118–124 | Miscellaneous Tab. 표피마찰(skin friction)과 시험용 일정 전단응력을 설정한다 (120). 종류별 최대 입경은 D50 계산에만 사용하며 실제 수송 계산은 대표 입경을 사용한다 (122). 124행 그림은 Compute Skin Friction from D50를 선택했다. `User Specified Grainsize to Compute Skin Friction (μm): 65` (124행 그림); `Constant Bed Shear Stress (Testing Only) (dynes/cm²): 0` (124행 그림)은 비활성 필드이며 Use Constant Bed Shear Stress는 미선택이다. 최대 입경 표는 `Class / Max (μm)` (124행 그림)이다. 각 행은 `1 / 70.71066` (124행 그림); `2 / 185.405` (124행 그림); `3 / 440.9366` (124행 그림); `4 / 1414` (124행 그림); `5 / 3999.396` (124행 그림); `6 / 7998.795` (124행 그림)이다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 본문은 퇴적 제한을 단일 시간 단계에 퇴적할 수 있는 최소 분율이라고 설명한다 (42). 같은 행은 0이면 100%가 퇴적될 수 있다고 설명하며 침강 속도에도 의존한다고 덧붙인다.
- 코어 표의 D3 이후 값과 침식률 표의 오른쪽 추가 열은 화면 경계에서 잘렸다 (94행 그림).
- 본문 버튼 이름은 `Initialize Defaults`이다 (64). 해당 그림의 버튼 이름은 `Initialize Values`이다 (66행 그림).
