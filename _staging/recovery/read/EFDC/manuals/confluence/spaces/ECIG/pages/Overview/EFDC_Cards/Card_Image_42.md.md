# Card_Image_42.md — 판독 구간 기록

구간은 1행부터 100행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–15 | C42 — 원문 frontmatter의 페이지 정보와 분류 경로를 읽었다(1–9). 비점착성 퇴적물(non-cohesive sediment) 매개변수 집합 2와 자료 행을 NSND번 반복하라는 지시를 제시한다(10). NSND>0이면 ISTRAN(7)=0일 때도 자료가 필요하다고 적는다(12). 빈 줄과 주석 표식도 포함한다(11–15). 원문: ` C42 NON-COHESIVE SEDIMENT PARAMETER SET 2 REPEAT DATA LINE NSND TIMES ` (10); ` \* DATA REQUIRED IF NSND>0, EVEN IF ISTRAN(7) = 0 ` (12). |
| 16–45 | 평형 농도와 소류 함수 — 하상 위 기준 평형 농도(above bed reference equilibrium concentration)의 함수와 인수를 제시한다(16–22). Garcia and Parker, Smith and McLean, Van Rijn, 임계 응력을 제외하거나 포함하는 SEDFLUME 옵션을 제시한다(24–32). 소류(bed load) PHI 함수는 일정값·Van Rijn·수정 Enguland-Hansen·Wu, Wang, and Jia를 구분하며 4·5는 미사용이라고 적는다(34–44). 원문: ` \* ISNDEQ: >1 CALCULATE ABOVE BED REFERENCE NON-COHESIVE SEDIMENT ` (16); ` \*                     EQUILIBRIUM CONCENTRATION USING EFDC FUNCTION ` (18); ` \*                     CSNDEQC(SNDDIA,SSG,WS,TAUR,TAUB,SIGPHI,SNDDMX,IOTP) ` (20); ` \*                     WHICH IMPLEMENT FORMULATIONS OF ` (22); ` \*                  1 GARCIA AND PARKER ` (24); ` \*                  2 SMITH AND MCLEAN ` (26); ` \*                  3 VAN RIJN ` (28); ` \*                  4 SEDFLUME WITHOUT CRITICAL STRESS ` (30); ` \*                  5 SEDFLUME WITH CRITICAL STRESS ` (32); ` \* ISBDLD: 0 BED LOAD PHI FUNCTION IS CONSTANT, SBDLDP ` (34); ` \*               1 VAN RIJN PHI FUNCTION ` (36); ` \*               2 MODIFIED ENGULAND-HANSEN ` (38); ` \*               3 WU, WANG, AND JIA ` (40); ` \*               4 (NOT USED) ` (42); ` \*               5 (NOT USED) ` (44). |
| 46–55 | 임계 응력(critical stress) — TAUR의 단위를 제시하며 음수일 때 TAUR와 TAUN을 Van Rijn 공식으로 내부 계산한다고 적는다(46–50). 비점착성 퇴적물 수송에서 TAUN이 TAUR와 같다고 적는다(52). 임계 Shields 응력(critical Shields stress)은 무차원이다(54). 원문: ` \* TAUR: CRITICAL STRESS IN (m/s)\*\*2 ` (46); ` \*            NOTE: IF TAUR < 0, THEN TAUR AND TAUN ARE INTERNALLY ` (48); ` \*            COMPUTED USING VAN RIJN'S FORMULAS ` (50); ` \* TAUN: EQUAL TO TAUR FOR NON-COHESIVE SED TRANS ` (52); ` \* TCSHIELDS: CRITICAL SHIELDS STRESS (DIMENSIONLESS) ` (54). |
| 56–75 | 수송 활성화 응력과 Rouse 수(Rouse number) — 부유 수송(suspended load)과 소류 각각의 입경별·D50·비균일 하상(nonuniform bed) 임계 응력 옵션을 구분한다(56–70). 임계 Shields 응력을 명시적으로 포함하지 않는 공식에 대한 적용 조건을 그대로 옮긴다(60–62·68–70). Rouse 수 계산에는 전체 응력 또는 입자 응력(grain stress)을 사용하는 옵션이 있다(72–74). 원문: ` \* ISLTAUC: 1 TO IMPLEMENT SUSP LOAD ONLY WHEN STRESS EXCEEDS TAUC FOR EACH GRAINSIZE ` (56); ` \*                 2 TO IMPLEMENT SUSP LOAD ONLY WHEN STRESS EXCEEDS TAUCD50 ` (58); ` \*                 3 TO USE TAUC FOR NONUNIFORM BEDS, THESE APPLY ONLY TO RESUSPENSION ` (60); ` \* FORMULAS NOT EXPLICITLY CONTAINING CRITICAL SHIELDS STRESS SUCH AS G-P ` (62); ` \* IBLTAUC: 1 TO IMPLEMENT BEDLOAD ONLY WHEN STRESS EXCEEDS TAUC FOR EACH GRAINSIZE ` (64); ` \*                 2 TO IMPLEMENT BEDLOAD ONLY WHEN STRESS EXCEEDS TAUCD50 ` (66); ` \*                 3 TO USE TAUC FOR NONUNIFORM BEDS, THESE APPLY ONLY TO BED LOAD ` (68); ` \* FORMULAS NOT EXPLICITLY CONTAINING CRITICAL SHIELDS STRESS SUCH AS E-H ` (70); ` \* IROUSE: 0 USE TOTAL STRESS FOR CALCULATING ROUSE NUMBER ` (72); ` \*               1 USE GRAIN STRESS FOR ROUSE NUMBER ` (74). |
| 76–93 | 소류·부유 수송 분율 제어 — 두 분율을 1로 설정하거나 이진 관계(binary relationship) 및 선형 관계(linear relationship)를 선택하는 다섯 옵션을 제시한다(76–84). USTAR/WSET 비에는 전체 또는 입자 전단 속도(shear velocity)를 사용하며, 이진 전환 기준값을 RSNDM으로 지정한다(86–90). 원문: ` \* ISNDM1: 0 SET BOTH BEDLOAD AND SUSPENDED LOAD FRACTIONS TO 1.0 ` (76); ` \*               1 SET BEDLOAD FRACTION TO 1. USE BINARY RELATIONSHIP FOR SUSPENDED ` (78); ` \*               2 SET BEDLOAD FRACTION TO 1, USE LINEAR RELATIONSHIP FOR SUSPENDED ` (80); ` \*               3 USE BINARY RELATIONSHIP FOR BEDLOAD AND SUSPENDED LOAD ` (82); ` \*               4 USE LINEAR RELATIONSHIP FOR BEDLOAD AND SUSPENDED LOAD ` (84); ` \* ISNDM2: 0 USE TOTAL SHEAR VELOCITY IN USTAR/WSET RATIO ` (86); ` \*               1 USE GRAIN SHEAR VELOCITY IN USTAR/WSET RATIO ` (88); ` \* RSNDM: VALUE OF USTAR/WSET FOR BINARY SWITCH BETWEEN BEDLOAD AND SUSPENDED LOAD ` (90). |
| 94–100 | C42 입력 예시 — Markdown의 빈 표 머리글과 구분선(94–95), 열 이름(96), 네 자료 행의 옵션·응력·Shields 응력 및 나머지 입력 값(97–100)을 제시한다. 각 자료 행을 그대로 옮긴다. 원문: ` \| C42 \| ISNDEQ \| ISBDLD \| TAUR \| TAUN \| TCSHIELDS \| ISLTAUC \| IBLTAUC \| IROUSE \| ISNDM1 \| ISNDM2 \| RSNDM \| ` (96); ` \|  \| 3 \| 2 \| 1.54E-04 \| 1.54E-04 \| 0.0703 \| 1 \| 1 \| 0 \| 0 \| 0 \| 0 \| ` (97); ` \|  \| 3 \| 2 \| 2.05E-04 \| 2.05E-04 \| 0.0317 \| 1 \| 1 \| 0 \| 0 \| 0 \| 0 \| ` (98); ` \|  \| 3 \| 2 \| 4.03E-04 \| 4.03E-04 \| 0.0311 \| 1 \| 1 \| 0 \| 0 \| 0 \| 0 \| ` (99); ` \|  \| 3 \| 2 \| 1.31E-03 \| 1.31E-03 \| 0.0406 \| 1 \| 1 \| 0 \| 0 \| 0 \| 0 \| ` (100). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 16·24행: `ISNDEQ` 설명의 계산 조건은 `>1`이라고 적는다(16). 같은 공식 목록에는 옵션 `1 GARCIA AND PARKER`도 적는다(24).
- 20·56–70·86–90행: 함수 인수의 `WS`, `TAUB`, `SIGPHI`, `SNDDMX`, `IOTP`, 적용 조건의 `TAUC`, `TAUCD50`, 비의 기호 `USTAR`, `WSET`은 이 파일에 명시적인 기호 정의가 없다.
