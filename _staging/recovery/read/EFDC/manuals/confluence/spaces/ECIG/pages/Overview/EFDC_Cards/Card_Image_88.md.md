# Card_Image_88.md — 판독 구간 기록

구간은 1행부터 22행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 문서 머리말 — 페이지 제목은 Card Image 88이다(3). 페이지 ID, space, URL, 버전, 갱신 시각과 문서 경로를 기록한다(2–8). |
| 10–22 | C88 High frequency output for specific locations and times — 특정 위치·시각의 고빈도 출력(high frequency output) 사용 옵션을 설명한다(10–18). 1은 고빈도 출력 날짜를 사용한다(14). 0은 특정 출력 옵션을 사용하지 않는다(16). 카드 헤더와 예시값 0을 제시한다(20–22). 예시값을 기본값으로 정의하지 않는다. 원문: `\* HFREOUT: 1 use high frequency dates for output` (14); `\*                   0 specific output option is not used` (16); `C88 HFREOUT` (20); `                   0` (22). |
