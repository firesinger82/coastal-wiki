# Deactivating.md — 판독 구간 기록

구간은 1행부터 18행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–11 | 메타데이터와 비활성화 전제 — 다른 컴퓨터에서 라이선스를 사용하려면 현재 라이선스를 먼저 비활성화해야 한다고 적는다(1–10). 의무 원문: `When the user wants to use the license in other computer, the user have to deactivate the current license first. The following steps describe how to deactivate the EEMS license.` (10). |
| 12–17 | 비활성화 단계 — Help의 License Management, Perpetual License의 Deactivate, Yes, Next, Yes, 성공 메시지의 OK 순서를 제시한다(12–16). 이 구간에는 단계 사이 빈 줄도 포함한다. |
| 18–18 | 그림 1–6 — 같은 행에 있는 로컬 그림 여섯 개를 모두 열었다(18). 첫 그림은 Help의 License Management, 둘째 그림은 Perpetual License와 Deactivate 및 `Seats Total: 50`, `Seats Remaining: 0`, 셋째 그림은 비활성화 Yes/No, 넷째 그림은 Next가 있는 Deactivation Confirmation, 다섯째 그림은 컴퓨터 이전·재설치 목적 확인, 여섯째 그림은 비활성화 성공과 프로그램 종료 메시지다. 넷째 그림의 연결 조건 원문은 `Please note that a live internet connection is required to deactivate.`이다(18행 그림). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 12–16행: Figure 1–6 링크의 fragment ID를 선언한 로컬 앵커가 본문에 없다. 여섯 그림은 18행에 모두 존재한다.
