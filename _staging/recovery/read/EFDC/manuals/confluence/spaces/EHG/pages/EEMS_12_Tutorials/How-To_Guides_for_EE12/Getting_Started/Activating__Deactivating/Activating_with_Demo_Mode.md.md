# Activating_with_Demo_Mode.md — 판독 구간 기록

구간은 1행부터 70행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–19 | 메타데이터·데모 활성화·인증 — Demo 버튼으로 데모를 활성화하고 Google·LinkedIn·EEMS 계정 중 로그인 방식을 고른다(1–14). Windows 7·IE11에서 작동하지 않을 수 있으며 인증 화면이 표시되지 않으면 Windows 10 및/또는 이후 IE 버전이 필요할 수 있다고 적는다(10). 미등록 EEMS 계정은 Sign up 후 이메일로 계정을 활성화해야 한다(14). 브라우저에서 EEMS 사이트 로그인 상태가 필요할 수 있다고 적는다(18). 조건·의무·불확실성 원문: `Activate the EEMS Demo mode by clicking on *Demo* button on the form, as shown in [Activating with Demo Mode#Figure 1](https://eemodelingsystem.atlassian.net/wiki/spaces/EHG/pages/247693389#ActivatingwithDemoMode-Figure1). Note that EE Demo Model may not work with Windows 7 and IE11. If the authentication form is shown in [Activating with Demo Mode#Figure 2](https://eemodelingsystem.atlassian.net/wiki/spaces/EHG/pages/247693389#ActivatingwithDemoMode-Figure2) fails to display, then you may need to upgrade to Windows 10 and/or a later version of IE. From the authentication form, there are several different options to log in.` (10); `- Sign in with EEMS account: Any user with an account on the EEMS website may activate EEMS by using this option ([Activating with Demo Mode#Figure 4](https://eemodelingsystem.atlassian.net/wiki/spaces/EHG/pages/247693389#ActivatingwithDemoMode-Figure4)). If you are not registered on the EEMS website, click *Sign up* tab to register ([Activating with Demo Mode#Figure 5](https://eemodelingsystem.atlassian.net/wiki/spaces/EHG/pages/247693389#ActivatingwithDemoMode-Figure5)). After initial registration, the user must check their email to activate the account. To understand the limitations of the Demo version, click on *Demo Information.*` (14); `You may need to be logged into the EEMS website in your browser to activate the demo mode.` (18). |
| 20–39 | 그림 1–5 / 인증 화면 — 로컬 그림 다섯 개를 열었다(20·24·28·32·36). 그림 1은 Activation Wizard의 Demo 버튼, 그림 2는 Google·LinkedIn·계정 로그인 방식, 그림 3은 LinkedIn 이메일/전화·비밀번호 입력, 그림 4는 EEMS 계정 로그인, 그림 5는 Sign Up과 이름·성·기관 입력 화면이다. 그림에는 수식·모델 격자가 없다. |
| 40–65 | 데모 화면·제한 확인·업그레이드 — Help의 License Management에서 데모 제한을 확인하고 Upgrade의 Yes/No를 선택한다(40–48). 로컬 그림 6–10을 열었다(42·50·54·58·62). 그림 6은 `EFDC_Explorer10.3.3 - DEMO MODE` 주 화면, 그림 7은 License Management 메뉴, 그림 8은 Information 탭, 그림 9는 Demo Mode License 탭, 그림 10은 데모 라이선스 제거 확인 창이다. 그림 9의 제한 원문: `Using EE you may load and run models provided by DSI from our website but you are not entitled to add new features to them.`; `For your own models, you are limited to less than 300 horizontal cells and use of the dye, salinity, and particle tracking (10 drifters) modules.`; `You can run your model with EFDC+.`; `If you load a model larger than 300 cells you may view your model without editing. However, you cannot save edits, run the model or view output.`; `Using CVLGrid you may load and edit any grids. However, saving and exporting is disabled.` (58행 그림). 업그레이드 안내는 `Note that an active internet connection is required.`라고 적는다(58행 그림). |
| 66–70 | EEMS Compatibility Setting — 데모를 관리자 모드로 시작할 때 오류를 방지하기 위해 관리자 실행 상자를 해제하는 것을 권고한다(66). 권고 원문: `It is recommended to uncheck the “Run this program as an administrator” box as shown in the [Activating with Demo Mode#Figure 11](https://eemodelingsystem.atlassian.net/wiki/spaces/EHG/pages/247693389#ActivatingwithDemoMode-Figure11) to prevent an error happen when launching EEMS in the administrator mode with Demo Mode.` (66). 로컬 그림 11을 열었다(68). EEMS11.2 Properties의 Compatibility 탭에서 `Run this program as an administrator` 상자가 해제된 상태를 강조한다. |
