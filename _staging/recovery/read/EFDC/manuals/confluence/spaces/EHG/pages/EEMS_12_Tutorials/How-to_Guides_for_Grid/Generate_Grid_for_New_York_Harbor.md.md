| 96–103 | Step 6: Create branch grids — 지류도 본류와 같은 단계로 생성한다(98). 오류 없이 병합하려면 교차 스플라인과 노드가 충분한 정밀도로 겹쳐야 한다(98–102). 원문: `The branch grids can be built using the similar steps as for main channel grids. | 104–129 | Step 7: Generate grids with islands / 방법 선택과 국소 세분 — 섬까지 덮은 격자를 만든 뒤 섬의 셀을 삭제하는 방법과 본류·지류만 따로 만드는 방법의 장단점을 설명한다(106). 이 사례는 두 번째 방법을 사용한다(108). 시작부터 끝까지 셀 수를 유지하고 복잡한 지류를 먼저 만들도록 권고한다(110–112). 지류 끝의 국소 셀을 세분(refinement)하는 절차를 보여 준다(118–128). 원문: `1.
