| 28–68 | Step 1: Determine Magnetic Declination — 편각으로 진북(true north)을 식별하려는 목적을 설명한다(30). 임시 지점표시의 좌표를 계산기에 옮기고 남·북 및 서·동 선택에 주의하도록 안내한다(31–37). 결과를 Heading에 넣어 영상을 서쪽에서 동쪽으로 회전한 뒤 임시 지점표시를 삭제한다(38–39). 부호·각도 조건을 원문으로 옮긴다(30·38). 관련 설정·계산 결과·나침반 그림을 포함한다(41–67). 원문: `- The purpose of determining the Magnetic Declination is to identify the True North for the site. Note that a positive declination is east, while a negative declination is west.` (30); `- Go back the Google Earth, enter the Magnetic Declination 6.26oW (W mean that the Declination here is negative) on the heading of the placemark. (see [Figure 7](#Geo-referenceMapGenerationinCVLGrid-Figure7)) then left mouse click the *OK* button. We will see that the background image on Google Earth will rotate from the west to the east with an angle 6.26o.` (38). 그림 직접 확인: `attachments/246645222/image2016-7-12_12257.png` — Figure 1(41): Google Earth의 Lake Okeechobee 배경 지도 위에서 Tools의 Options 메뉴를 연 화면. 그림 직접 확인: `attachments/246645222/image2016-7-12_13648.png` — Figure 2(45): Google Earth Options의 Show Lat/Long에서 `Degrees, Minutes, Seconds`를 선택하고 Apply·OK를 누르는 화면. 그림 직접 확인: `attachments/246645222/image2016-7-12_1375.png` — Figure 3(49): 호수 위 임시 지점표시(placemark)와 Latitude·Longitude 입력란을 빨간 테두리로 표시한 화면. 그림 직접 확인: `attachments/246645222/image2016-7-12_13723.png` — Figure 4(53): NOAA 로고가 있는 Magnetic Field Calculators의 Declination 페이지를 보여 준다. 그림 직접 확인: `attachments/246645222/image2016-7-12_13742.png` — Figure 5(57): 계산기에 위도·경도를 입력하고 N·W 방향을 선택한 화면. 그림 직접 확인: `attachments/246645222/image2016-7-12_13758.png` — Figure 6(61): 편각(magnetic declination) 결과와 나침반 도식을 표시한다. `Model Used: WMM2015`, `Latitude: 26° 58' 51.18" N`, `Longitude: 80° 45' 40.22" W`, 날짜 `2015-03-09`, `6.26° W ± 0.32°`, `changing by 0.10° W per year`이다. MN은 붉은 북쪽 바늘 위에 적혀 있으며 붉은 바늘 축은 파란 기준 축보다 왼쪽으로 기울어져 있다. 그림 직접 확인: `attachments/246645222/image2016-7-12_13817.png` — Figure 7(65): 임시 placemark의 View 탭 Heading에 `-6.26`을 입력한 화면. |
| 69–90 | Step 2: Determine Upper Left (UL) and Lower Right (LR) Coordinates — Google Earth에서 UTM을 선택하고 UL·LR 지점표시를 추가한다(71–72). 좌표 표의 Easting·Northing 값과 단위를 행 전체로 옮긴다(76–77). 두 모서리의 설정 화면을 포함한다(79–89). 원문: `\| **UL** \| **LR** \|` (76); `\| Easting  467419.45 m E  Northing  3009561.68 m N \| Easting  563219.52 m E  Northing  2951517.39 m N \|` (77). 그림 직접 확인: `attachments/246645222/image2016-7-12_132227.png` — Figure 8(79): Show Lat/Long의 `Universal Transverse Mercator`를 선택한 화면. 그림 직접 확인: `attachments/246645222/image2016-7-12_132322.png` — Figure 9(83): 지도 왼쪽 위 UL placemark의 UTM Zone·Easting·Northing을 지정하는 화면. 그림 직접 확인: `attachments/246645222/image2016-7-12_132545.png` — Figure 10(87): 지도 오른쪽 아래 LR placemark의 UTM Zone·Easting·Northing을 지정하는 화면. |
| 91–103 | Step 3: Save image for UL-LR Area — 영상 저장 메뉴와 Premium 해상도 선택을 보여 준다(93–102). 해상도 선택은 선택 사항이며 전문 버전(professional version)에서 다른 해상도로 저장할 수 있고 이 문서는 가장 높은 해상도를 권고한다고 적는다(97–98). 원문: `- Choose Premium resolution` (97); `  - Image resolution selection is an optional. | 104–117 | Using CVLGrid / 영상 불러오기 — 지구 아이콘의 Setup을 선택한다(106). Google Earth에서 만든 JPEG 영상을 CVLGrid의 bitmap 파일로 불러온다고 설명한다(112). 관련 도구와 메뉴 그림을 포함한다(108–116). 원문: `- Load the bitmap file (browse to image of Lake Okeechobee, which was generated by Google Earth). The bitmap file is the image file which is called in CVLGrid. The image generated by Google Earth is a JPEG image (\*.jpg), so the bitmap file is to be loaded is the JPEG image.` (112). 그림 직접 확인: `attachments/246645222/7-27-2017_3-59-11_PM.jpg` — Figure 13(108): CVLGrid1.1의 지구 아이콘 메뉴에서 Setup을 강조한 화면. 그림 직접 확인: `attachments/246645222/image2016-7-12_135335.png` — Figure 14(114): Bitmap Georeferencing의 File 메뉴에서 Load Bitmap File을 선택하는 화면. |
| 118–131 | Using CVLGrid / 기준점 좌표 — UL은 Point 1, LR은 Point 2로 선택한다(118·125). Easting을 X, Northing을 Y에 입력한다(119·126). 원문 좌표 대응을 그대로 옮기며 두 기준점 화면을 포함한다(121–130). 원문: `- Right mouse click on UL then choose *Point 1*` (118); `- Type the Easting coordinate into X and Northing coordinate into Y` (119); `- Right mouse click on LR then choose *Point 2*` (125); `- Type the Easting coordinate into X and Northing coordinate into Y` (126). 그림 직접 확인: `attachments/246645222/image2016-7-12_135425.png` — Figure 15(121): UL 마커를 Point 1로 선택한 화면이다. `Pixel X: 330`, `Pixel Y: 176`, `X: 467419.400`, `Y: 3009561.68`을 표시한다. 그림 직접 확인: `attachments/246645222/image2016-7-12_135813.png` — Figure 16(128): LR 마커를 Point 2로 선택한 화면이다. `Pixel X: 4304`, `Pixel Y: 2589`, `X: 563219.500`, `Y: 2951517.39`를 표시한다. |
| 132–147 | Using CVLGrid / 갱신·저장·불러오기 — 두 기준점 좌표 입력 뒤 Update를 누르고 File/Save Geo-reference File로 저장한다(132–133). 생성한 Okeechobee Lake.geo를 나중에 불러올 수 있다고 적는다(143). 저장과 배경 영상 불러오기 그림 및 마지막 캡션을 포함한다(135–147). 원문: `- After typing coordinates of UL and LR then click *Update* button` (132); `- *File/Save Geo-reference File* (enter the name and folder location for the geo-reference file) then click *Save* button.` (133); `- The geo-reference file named *Okeechobee Lake.geo* is now generated and can be loaded at any time.` (143). 그림 직접 확인: `attachments/246645222/image2016-7-12_13595.png` — Figure 17(135): File의 Save Georeference File 메뉴를 선택한 화면. 그림 직접 확인: `attachments/246645222/image2016-7-12_135941.png` — Figure 18(139): 저장창의 `File name: Okeechobee Lake.geo`, `Save as type: GeoRef Files`를 지정한 화면. 그림 직접 확인: `attachments/246645222/image2016-7-12_14135.png` — Figure 19(145): CVLGrid에서 지리참조(geo-reference) 호수 영상을 배경으로 불러온 화면. |
