## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- Figure 2의 ITYPE = 0 입력 형식은 닫는 괄호가 더 많은 표기 그대로 표시되어 있다 (28).
- Figure 2 형식은 NK를 층수로 설명하지만 ITYPE 식은 KC를 사용한다. 본문은 LA, LC, KC를 정의하지 않는다 (28).
- Figure 2의 데이터 행은 오른쪽 끝에서 잘려 있다. Figure 1의 DATA FILE FORMAT 설명은 Line #7 도중 아래 끝에 도달한다 (18,28).
