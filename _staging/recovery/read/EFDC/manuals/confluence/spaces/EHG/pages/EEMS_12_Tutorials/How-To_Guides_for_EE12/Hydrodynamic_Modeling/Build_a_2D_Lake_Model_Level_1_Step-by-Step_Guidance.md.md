## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- CSS 색상 지시문이 Introduction 제목에 남아 있다(10).
- 제목과 소개는 2D 모델이지만 수직층 설정 단계는 5개 층을 요구한다(3, 12, 222). 모델 격자 그림도 `# Layers: 5`를 표시하고 바로 뒤 주 화면은 `Water Layers: 1`을 표시한다(226, 234).
- 소개는 예제에서 Dye 모듈을 사용한다고 적는다(14). 이 파일의 절차에는 Dye 모듈을 켜거나 염료 계열을 지정하는 단계가 없다(20–262).
- 초기 조건 도입은 바닥 거칠기 할당도 안내한다고 적는다(62). 해당 절의 하위 절은 수심지형과 수위 할당이고 바닥 거칠기 할당 단계는 없다(66–97).
