# Loading_a_Model.md — 판독 구간 기록

구간은 1행부터 32행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–13 | 메타데이터와 Step-by-step guide — Model의 Open Model 또는 `Ctrl+O`로 기존 프로젝트를 연다(1–12). |
| 14–23 | 그림 1–3 / 모델 불러오기 — 로컬 그림 세 개를 열었다(14·18·22). 그림 1은 Model의 Open Model과 `Ctrl+O`, 그림 2는 도구모음 Open Model, 그림 3은 디렉터리 트리·파일 목록·프로젝트 경로·최근 경로 목록을 가진 Select Directory: Open Operation이다. 그림 3의 Legacy EFDC Projects - Load Options는 `Scale: 1`, `Reset BC Groups During Load`, `Force Distinct BC During Load`, `Load Water Quality Mass Loading BC's Without Associating Flow BC's to the WQ BC's`를 표시하며 세 상자는 해제됐다(22행 그림). 도구모음 대안과 디렉터리 창 설명도 포함한다(16–20). |
| 24–25 | 최근 프로젝트와 필수 입력 파일 — 마지막 프로젝트 경로를 표시하고 최근 30개 프로젝트를 하단 목록에서 선택할 수 있으며 오른쪽에 선택 디렉터리 파일을 표시한다(24). Open 작업에는 해당 디렉터리에 EFDC.INP가 있어야 한다(24). 수량·의무 원문: `In [Loading a Model#Figure 3](https://eemodelingsystem.atlassian.net/wiki/spaces/EHG/pages/229343334#LoadingaModel-Figure3), the directory displayed will be the last project directory opened.  The last 30 projects are available in the drop-down list located near the bottom of the form.  The panel on the right shows the files contained in the selected directory.  For Open operations, the EFDC.INP file must exist in the directory.` (24). |
| 26–32 | Drag & Drop — Windows Explorer에서 프로젝트 또는 부모 폴더를 찾아 허용 항목을 EE 화면으로 끌어 넣을 수 있다(26–28). 허용 입력 항목 원문: `- EFDC project folder` (30); `- EFDC.EE file` (31); `- \*.INP files` (32). |
