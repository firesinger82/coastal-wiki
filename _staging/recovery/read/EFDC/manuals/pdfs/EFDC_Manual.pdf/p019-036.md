| p.19 | 인쇄 쪽 번호는 15이다. 절은 `1.3 Input Files`와 `1.3.1 Primary Run Control`이다. 이 쪽은 격자 가져오기 결과와 주요 모듈 및 실행 제어 입력 파일을 설명한다.<br>그림 캡션은 `Figure 14. Import from multiple grid files – result display.`이다.
