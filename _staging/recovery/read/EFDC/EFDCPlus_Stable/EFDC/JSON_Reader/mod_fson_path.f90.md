## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 34–83·92–476·608–664: 모듈과 공통 경로·스칼라·배열 조회 루틴에는 implicit none 문장이 없다. 콜백 인터페이스와 형식별 배열 루틴에는 implicit none을 적는다.
- 121–140: 점 또는 여는 대괄호에서 child_i<i가 거짓이면 cycle한다. array=true 설정은 cycle 뒤에 있다.
- 143–153·156–162: 닫는 대괄호 처리 뒤에는 p 연결 여부 검사가 없다. 루프가 끝날 때 array 플래그를 검사하는 문장도 없다.
- 175–193: 경로의 정수 판독은 숫자 이외의 첫 문자에서 현재 integral을 반환한다. 부호·비숫자·넘침을 오류로 보고하는 분기가 없다.
- 223–224·263–264·349–350: 정수 변환은 p.value_real을 사용한다. 배정밀도 조회는 p.value_double을 사용한다.
- 213–234·254–274·296–317·339–360·383–396·417–429: 스칼라 조회 실패 경로는 value에 대입하지 않고 반환한다. 일부 기본값과 STOPP 호출은 주석이다.
- 202·213–214·244·254–255·284·296–297·327·339–340·371·383–384·406·417–418: path는 선택 인수이다. 연결 실패 출력문은 present(path) 조건 밖에서 path를 참조한다.
- 389–397: logical 조회는 integer와 logical만 처리한다. integer의 참 조건은 value_long_integer>0이다.
- 464–467·497·522·547·572·597·634–648·685·710·735·760·785: 형식별 배열 할당은 요소 콜백 안에 있다. 공통 순회가 콜백을 호출하지 않는 빈 배열 경로에는 별도의 배열 할당문이 없다.
- 637–653·685–686: 2차원 조회는 첫 내부 배열의 크기를 기준으로 사용한다. 앞선 요소의 콜백을 실행한 뒤 나중 내부 배열의 크기 또는 형식 불일치를 만날 수 있는 순서이다. 크기 불일치는 실행 STOPP이고 내부 형식 불일치의 STOPP는 주석이다.
