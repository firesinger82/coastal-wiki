## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 60–65·142–148: 두 JSON 그룹 루프의 상한은 fson_value_count(zoogroups)이다. ZOOPL 배열 접근 앞에 NZOOPL과의 개수 비교는 이 루틴에 없다.
- 112–113: FSPPZ와 FSAPZ는 같은 JSON 키 predation.fraction_of_silica.SU에서 읽는다. 사망 분배율 입력은 SU와 SA를 서로 다른 키로 읽는다(129–130).
- 54·138·276: json_data는 두 입력 파일의 파싱 결과를 받는다. ZOOPL_CONTROL에는 JSON 객체 해제 호출이 없다.
- 233–257: 온도표 하한은 -10이고 상한 설정값은 60이다. 온도표 간격은 범위를 NWQTD로 나누고 M=1..NWQTD만 채운다. WTEMPZ 증가는 각 온도점 계산 뒤에 있다.
- 325·321–330: 온도 인덱스 식은 층 K 인덱스가 없는 TWQ(L)를 참조한다. 이 루틴의 K 루프 안에는 TWQ를 새로 설정하는 문장이 없다.
- 351: 조류 농도 접근 인덱스는 19+NAL로 적혀 있다. 동물플랑크톤 농도 접근은 NWQVZ+NZO를 사용한다(342·406).
- 350–353·381–392·417: BAZ는 이동성 조류의 LMASKDRY 참 분기에서 설정한다. 건조 셀 else에는 BAZ 초기화가 없다. 조류 영향식은 이 셀 조건 밖에서 BAZ를 참조한다.
- 368·378·401·417: 먹이 관련 분모에는 1.E-18을 더한다. DOCRIT와 1.0-WQACZ를 분모로 쓰는 식 앞에는 별도의 0 검사 조건이 없다.
