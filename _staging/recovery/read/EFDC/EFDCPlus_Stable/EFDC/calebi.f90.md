## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 35–62·282–287·372–377: save 배열 DZCC의 DZC 전치 복사는 최초 할당 조건 안에 있다. 차단 보정은 DZCC(:,L)을 다시 0으로 만들고 정규화한 값으로 덮어쓴다. 이 루틴 끝에는 DZCC를 원래 DZC로 되돌리는 문장이 없다.
- 39·54–61·136–155: KSZFLAT은 최초 할당 때 false로 초기화된다. true 판정은 같은 초기 할당 블록의 IGRIDV=1 조건에서만 수행된다.
- 281–287·371–377: 두 방향 차단 보정은 SUMT로 DZCC를 나눈다. 각 나눗셈 앞에는 SUMT=0을 검사하는 조건이 없다.
- 336–358·419–441: 서쪽 이웃의 동쪽 면 적분은 정규화한 DZCC(K,L)과 KBBU(LP)..KC를 사용한다. 남쪽 이웃의 북쪽 면 적분은 SGZV(L,K)와 KBBV(LP)..KTBV(LP)를 사용한다.
- 415–445: 주석은 LS의 북쪽 면 적분이라고 적는다. 계산은 B(LS,K)·ZZN(K,LS)를 사용한다. 결과 대입의 인덱스는 BI1N(L)·BI2N(L)·BEN(L)이다.
- 524–535: 보간 범위 밖 조건은 엄격한 < 및 > 비교이다. NMAX=1이고 XVAL=XDAT(1)이면 else에 들어가며 `do N = 1,NMAX-1`은 반복하지 않는다. 이 경로에는 YVAL 대입이 없다.
