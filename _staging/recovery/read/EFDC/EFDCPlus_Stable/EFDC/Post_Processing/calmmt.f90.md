## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 93·206·236 및 772·835: TOXBLPF·TOXLPF·TXPFLPF 누적 조건은 ISTRAN(5)>0이다. INITIALIZE_RESIDUALS에서 이 배열들의 초기화 조건은 ISTRAN(7)>0이다.
- 137–138·156–157·184–191: WIRT·WTLPF 누적은 DT를 사용한다. UIRT·VIRT 누적은 DELT를 사용한다. UTLPF·VTLPF 누적식에는 시간 간격 인자가 없다.
- 290–299: ISICM>=1일 때 MMTCNT에 DELT를 두 번 더한다. 같은 조건에서 FLTWT를 두 배로 바꾼다.
- 29–40·275–283·451–466·730–897: VPX·VPY·VPZ는 CALMMT의 save 지역 배열이다. 전체 0 대입은 최초 할당 블록에 있고, INITIALIZE_RESIDUALS에는 이 배열들의 초기화 문장이 없다.
- 610·623·649·672: SEDBTLPF·SNDBTLPF의 출력 전 0 초기화 범위는 K=2..KB이다. 이후 합산 범위는 K=1..KB이다.
- 633–641: TVAR1S에는 TOXLPF(L,K,1)을 복사한다. NT 루프는 TVAR1S를 변경하지 않고 같은 배열로 RSALPLTH를 NTOX회 호출한다.
- 661–664·684–687: 퇴적물 총합 SEDTLPF는 NSC 루프에서 같은 배열로 반복 출력한다. 모래 총합 SNDTLPF도 NSN 루프에서 같은 배열로 반복 출력한다.
- 295·718: 실행 조건은 TIMEDAY>=WASPTIME(NTIME)이다. 해당 endif의 주석은 MMTCNT>=RESSTEP로 적는다.
