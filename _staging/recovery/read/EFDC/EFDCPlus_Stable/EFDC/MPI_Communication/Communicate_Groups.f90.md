## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 25–58·188: Communicate_Initialize는 Comm_Cells와 nComm_Cells를 매 호출 allocate한다(55–56). 이 루틴에는 allocated 검사와 num_Processors==1 조기 반환문이 없다.
- 65–66·80–81·97–98·112–113·129–130·144–145·161–162·176–177: 경계 목록의 폭은 두 셀로 고정되어 있다. 서/동 목록은 J=3..JC-2를 사용한다. 남/북 목록은 I=1..IC를 사용한다.
- 201·464·862·1118·1337·1626·1991·2325·2565: 각 통신 루틴에 선언된 J는 실행문에서 사용되지 않는다. Communicate_CON1의 NCLASS/IBL/IC1/IC2/NS/NT(1626)와 Communicate_BEDLOAD의 K(2325)도 실행문에서 사용되지 않는다. CON1의 J는 주석 처리된 지형 변화 루프에만 나타난다(1698 등).
- 221–239·479–500·882–901·1138–1156·1359–1378·1655–1674·2013–2032·2346–2365·2585–2604: save 버퍼의 할당과 전체 0 초기화는 각각 하나의 송신 버퍼 미할당 조건 안에 있다. 이 파일에는 해당 버퍼 크기를 변경하는 재할당문이나 deallocate문이 없다.
- 1354–1357·1390–1400·1414·1447–1457·1471·1504–1514·1528·1561–1571·1585: Communicate_UVW3의 저장 크기식은 kcm 기준 변수 4개와 kcm+1 기준 변수 2개를 더한다. 실제 송신문은 U/V/W 세 변수만 넣는다. 수신 길이는 셀별 `(KC-KSZ(L)+1)*3`을 누적한다.
- 1648–1653·1696–1707·1739–1750·1770–1781·1813–1824·1844–1855·1887–1898·1918–1929·1961–1972: Communicate_CON1의 지형 변화 관련 조건·BELV 송수신·저장 크기 추가는 모두 주석 처리되어 있다. 서쪽 송신 주석은 `!        PSENDS(II) = BELV(L)` (1703)를 적으며, 실행 수주 송신문은 PSENDW를 사용한다(1690·1710).
- 2008–2011·2044–2060·2074·2113–2129·2143·2182–2198·2212·2251–2267·2281: Communicate_CON2의 저장 크기식은 두 변수에 kcm, 한 변수에 kcm+1을 사용한다. FUHUD/FVHUD/FWUU 세 변수의 실제 층 루프는 모두 KSZ(L)..KC이다. 수신 길이는 `3*(KC-KSZ(L)+1)*NACTIVEWC`를 셀별로 누적한다.
- 2314–2346·2377·2406: Communicate_BEDLOAD는 인수 I1/I2로 `nSize = I2 - I1 + 1` (2342)을 계산한다. 이 루틴에는 I1<=I2나 퇴적물 배열 등급 범위를 검사하는 조건이 없다. 버퍼는 PSENDW 미할당일 때의 nSize로만 할당한다(2343–2365).
- 2582–2583·2616–2644·2658·2751·2844·2937: Communicate_QQ의 저장 크기식은 `kcm*3 + 4`를 사용한다. 실제 포장은 QQ/QQL/DML의 K=0 값 세 개, KSZ(L)..KC 층값, TBX/TBY/UV/VU 값 네 개를 넣는다(2616–2644). 수신 길이 증가식은 `II = II + 7 + (KC-KSZ(L)+1)*3` (2658·2751·2844·2937)이다.
