## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 9·12–13: 실제 루틴 이름은 BEDLOAD이다. 머리말 설명은 SUBROUTINE CALSND가 비점착성 침강·퇴적·재부유를 계산한다고 적는다.
- 83·127–162·175–199·212–232: 일반 식 경로에는 LMASKDRY 조건이 있다. van Rijn·Engelund–Hansen·Wu/Wang/Jia 셀 중심 계산 경로에는 해당 조건이 없다.
- 130–144: van Rijn 경로는 ISEDEFF=2에서 CSHIELDS를 먼저 TMPVAL로 곱한다. 이후 CSHIELDSC 대입식도 TMPVAL*CSHIELDS를 사용하며 직전 입경 보정 CSHIELDSC를 사용하지 않는다.
- 175–184: Engelund–Hansen의 CSHIELDS 초기값은 LP 루프 밖에서 정한다. IBLTAUC=0/1일 때 LP 루프 안의 ISEDEFF=2 보정은 현재 CSHIELDS에 배율을 곱하며 셀마다 원래 임계값을 복구하는 문장은 없다.
- 239–250: 주석은 후류 소류사를 포함한다고 적는다. 실제 양수 PROP_BLD 분기는 QSBDLDP에 더하지 않고 덮어쓴다.
- 366–367: 평균 면 수송의 x 식은 두 셀의 UCELLCTR를 사용한다. y 식은 현재 셀 VCELLCTR와 남쪽 셀 UCELLCTR를 사용한다.
- 425–446: 주석은 SEDSTART>TBEGIN일 때 점진 증가를 제공한다고 적는다. 실행 조건에는 TBEGIN 비교가 없으며 기간은 1.0으로 고정된다. FLUXFAC<=0일 때 수송률을 지우는 else는 이 블록에 없다.
- 27–30: ASNDFBL·SNDBTMP·SNDFBLM·XOUT·YOUT는 선언 이후 이 파일에서 사용되지 않는다.
