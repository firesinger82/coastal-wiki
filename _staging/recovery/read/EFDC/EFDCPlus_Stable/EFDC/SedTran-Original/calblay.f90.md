## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 53–55·61·321·507: HBEDMAX1 대입은 ISNDAL==2 조건 안에 있다. 부모층 경로는 ISNDAL<=1의 else이며 그 경로에서 HBEDMAX1을 사용한다.
- 506–512: K=KBT(L)=1인 분기에서 VDRBED(L,KBT(L)-2)·VDRBED(L,KBT(L)-1)를 읽는다. 두 번째 인덱스 계산 결과는 각각 -1·0이다. 이 블록에는 해당 인덱스 범위를 검사하는 조건이 없다.
- 511–512·514–555: TMPTOP1·TMPTOP2를 계산한다. 해당 K=1 두께 분할 경로의 후속 식에서는 두 값을 사용하지 않는다.
- 164–178·193–207: 재배치 경로는 하부 1층에 2층 질량을 더한다. VFRBED는 2층 이상에서 위층 복사·기존 최상층 0 대입만 하며 합쳐진 1층 분율을 다시 계산하는 식은 이 블록에 없다.
- 62–64·325–327·696: ISNDAL<=1 경로의 !$OMP 지시문은 붙여 쓴 활성 형식이다. 부모층 경로의 !  $OMP 지시문은 !와 $OMP 사이에 공백을 둔 일반 주석 형식이다.
- 518·682–691: BDENBED 복사에 not updated anywhere else 주석이 있다. 같은 루틴 뒤쪽은 최상층 BDENBED를 다시 계산한다.
- 9–704: 현시각 SEDB·SNDB·TOXB와 물성을 추가·이동·삭제한다. 이 루틴에는 SEDB1·SNDB1·TOXB1·HBED1·VDRBED1·PORBED1 대입이 없다.
- 21·29·9–704: 변경 이력은 Hard Bottom Bypass 추가를 적는다. 이 파일에는 LBED 조건이 없으며 k1은 선언 이후 사용되지 않는다.
