## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 36–39: SNDHYDCN은 SAVE allocatable로 선언하고 AllocateDSI로 할당·초기화한다. 이후 이 파일의 실행식은 SNDHYDCN을 참조하지 않는다.
- 61–77: 일정 공극률 경로에서 최상층 LP 루프를 닫은 뒤 K 루프 상한으로 KBT(L)-1을 사용한다. K 루프 내부에서는 LP를 다시 순회하며 L을 바꾼다.
- 50–82·242: 일정 공극률 경로는 VDRBED를 VOIDCON1로 바꾸지만 PORBED에 대입하지 않는다. 이후 습윤 밀도 식은 PORBED를 사용한다.
- 147–159: 음수 SEDVRDT 경로의 주석은 초기 간극비 VDRBED0 유지라고 적는다. VDRBED0 복구·두께 갱신 식은 주석 처리되어 있고 실행문은 VDRBED1·HBED1에 현재 값을 복사한다.
- 95–106·113–123·148–162: 양수 SEDVRDT 경로만 지수 압밀을 적용한다. 0 경로의 VDRBED 식은 이전 값을 유지하는 형태이고 음수 경로의 TMPEXP=1.0은 해당 경로에서 사용되지 않는다.
