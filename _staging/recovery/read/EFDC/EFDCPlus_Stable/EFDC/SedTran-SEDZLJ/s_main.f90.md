## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 32·37: LASTTIME은 -9999. 초기값과 최초 TIMEDAY 대입만 가진다. 이 파일의 나머지 실행문은 LASTTIME을 참조하지 않는다.
- 64·350: 실제 수송 블록 조건은 NSEDFLUME>0이다. 종료 주석은 NSEDFLUME>0 .and. N>=ISEDTIME이라고 적는다. 이 블록 입구에는 N>=ISEDTIME 실행 조건이 없다.
- 74–89: 바닥/수층 플럭스 SEDF(L,0,NS)의 0 대입은 K=1..KS 루프 안 K=KS 조건에 있다. KS=0이면 이 루프는 실행되지 않는다.
- 211–225: 하류 SMASS>0 경로는 LDTMP의 PERSED·TSED를 갱신한다. 해당 else는 LUTMP의 TSED·PERSED를 0으로 설정한다. 이어지는 EFDC 변수 갱신은 LDTMP를 사용한다.
- 279: KSZ(L)층 주 대각 식의 침강속도 인덱스는 WSETA(L,1,NS)이다. 이 식은 WSETA의 해당 인덱스에 KSZ(L)를 쓰지 않는다.
- 240·341: 실행 NS 루프의 상한은 NSEDS2이다. 종료 주석의 상한 표기는 NSEDS이다.
- 304–311: 전진 소거 식은 TVAR3S를 분모로 사용한다. 이 블록에는 해당 분모가 0인지 검사하는 조건이 없다.
