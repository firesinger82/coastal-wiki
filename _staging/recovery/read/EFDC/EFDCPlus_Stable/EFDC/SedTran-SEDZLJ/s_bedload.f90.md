## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 47–52: 격자 변환배열은 LCM 크기로 할당한다. 값 대입 슬라이스는 2:LA이다. 이 블록에는 나머지 인덱스 대입이 없다.
- 54·70·94·116·143·162·184·222·279: PSUS 전체 기본값 1.0 대입은 최초 할당 분기 안에 있다. 이후 작은 입도는 각 계산 루프에서 CYCLE한다.
- 97·126·147·150: DWS·TCRE·WATERDENS와 LOG 식의 분모를 사용한다. 해당 식 앞에 이 값들의 0 또는 로그 입력 범위 검사는 없다.
- 120–130: 중간 영역의 PSUS 식은 max(...,0.0)만 적용한다. 그 식에는 상한 1.0 제한이 없다. USW>=4.0인 외부 else는 별도로 1.0을 설정한다.
- 56·58·111–125: ISKIP는 PARALLEL 밖에서 1로 설정된다. PARALLEL DEFAULT(SHARED) 안의 ND 루프는 ISKIP(NS)=0을 대입한다. 해당 대입 옆에는 atomic 또는 critical 지시문이 없다.
- 192–201: 우세 방향 조건은 UBL>VBL이다. ABS 비교는 없다. 각 경사 보정 경로의 후속 식은 앞 식에서 갱신된 UBL 또는 VBL을 사용한다.
- 279–288: CBL 갱신 뒤 이 루틴에는 CBL의 비음수 제한이나 가용 질량 검사 조건이 없다.
