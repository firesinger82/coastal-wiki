## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 118–123·443–447·838·1008: dt0는 DELT이다. 동적 시간 간격 분기의 dtwasp는 10으로 고정한다. HydroLink 시간 간격에는 dtwasp를 전달하지만 분산 상한 계산에는 dt0를 사용한다.
- 446·449: 동적 시간 간격의 NMMT 식에는 NWASPOUT-1이 분모로 들어간다. AUX 식에는 NMMT가 분모로 들어간다. 이 두 식 앞에는 해당 분모의 0 여부 검사문이 없다.
- 51·75·586–596: nf는 save 정수로 선언하지만 실행문에서 대입하거나 참조하지 않는다. 고정 크기 parameter와 NCHN>NF 검사는 주석이다. 유로 배열은 최초 crnu 미할당 조건에서 NCHN 크기로 할당한다.
- 184–234: 폴더 생성과 ABmax.txt 경로는 슬래시를 사용한다. WASP8SEG_EFDCIJK.DAT 경로는 역슬래시를 사용한다(225·234).
- 282–296: 바닥 구획 번호는 LAUX(I,J,1)에 저장한다. 같은 블록의 깊이·부피 계산은 DZC(L,KC)를 사용한다(288–292).
- 298–323·485·516–546: 저서층 번호와 부피 계산 블록에는 해당 구획을 출력하거나 HydroLink에 등록하는 문장이 없다. HydroLink 구획 수와 이름 등록 루프는 수층만 포함한다.
- 455–463: 초·분의 상위 단위 변환 조건은 각각 tsec>60과 IStartminute>60이다. 두 조건은 60과 같은 경우를 포함하지 않는다.
- 73·82–84·503·509–511·542–544: segname.inp에서 읽은 SSN을 segname 구성에 사용하지 않는다. SN2와 segname의 선언 길이는 모두 23이고 segname 대입은 SN2 뒤에 char(0)을 붙인다. hlsetsegname 뒤에는 ierror 검사가 없다.
- 568·718–739·876–892: NCHN 계산은 KC와 KC-1을 사용한다. 568행에는 SGZ 격자 관련 DELME 주석이 있다. 수직 연결 등록에는 KSZ 조건이 없고 초기 구획 자료에는 KSZ 조건이 있다.
- 47·76·255·274·295·519·699–707: LAUX 선언에는 초기값이 없다. 이 파일의 LAUX 대입은 대응 셀의 수층 번호를 채운다. 구조물 연결은 상류·하류 좌표의 LAUX를 먼저 읽고 두 값이 모두 0인지 검사한다.
- 688–690: 유입점 연결은 LUTM=0을 전달한다. 바로 앞 주석은 LUTM·LDTM의 범위를 1부터 구획 수까지라고 적는다. 외부 WASP 문서와 HydroLink 처리는 확인하지 않았다.
- 812·818·824: hlsetfpconsttype의 두 번째 인수는 세 호출 모두 1이다. 세 번째 인수는 순서대로 0·1·2이다.
