## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 55–59·74–78·166–174: 제어 유형 선언 주석은 0–3만 설명한다. COMPUTE_HSFLOW는 ITYPE=4를 블록 시계열 제어로 처리하며 IHYD=0을 설정한다. 뒤의 USINV 식은 IHYD로 HS_USELEV를 참조한다(237).
- 138–145: 세 save 배열의 할당 여부 검사는 NDIRCULV 하나만 검사한다. 방향 카운터 초기값은 100으로 고정되어 있다.
- 154: COMPUTE_HSFLOW는 매 호출 HSOPTION을 1로 설정한다. 이 파일의 계산 분기에는 HSOPTION 참조가 없다.
- 159–163·544·550·640–641: 구조물 유형 9는 HOPEN·WOPEN·SOPEN 기본 설정에서 제외된다. 갑문 분기는 세 값을 합산한다. 시계열 제어 밖에서 세 값을 모두 설정하는 갑문 전용 초기화 문장은 이 루틴에 없다.
- 178–200·237·262·366·483·718–744: 펌프 규칙 분기는 LD=LC를 설정하고 GOTO 1000으로 이동한다. 이 이동은 USINV·HUD와 DIA를 계산하는 뒤 블록을 건너뛴다. KC>1의 상류 층 배분은 USINV·DIA를 사용한다. 이 지역 변수들의 선언에는 초기값이 없다(130).
- 203–226: 문 제어 매개변수 검사는 1·2·4 순서의 if/elseif다. 여러 비트가 동시에 해당해도 이 블록은 첫 해당 분기만 실행한다.
- 239–246·280–309: 영역 밖 하류는 ZHD=-9999로 설정한다. 암거의 하류 수심·경사 처리에는 LD=LC 분기가 있다. 만관 흐름 분기는 LD=LC 여부를 다시 검사하지 않고 S=(ZHU-ZHD)/HS_LENGTH(IHYD)로 덮어쓴다.
- 248–254·716–720: 방향 전환 지연 분기는 직전 암거 유량을 절반으로 바꾸고 GOTO 1000으로 이동한다. 이 이동은 HSCTL(NCTL).CUR.FLOW=QHS 대입을 건너뛴다.
- 275·277·288·319·324·326·959: 암거 식에는 9.81·19.62·0.6667·1.3333이 직접 들어간다. CROSS_SECTION은 HS_MANN<=0이면 KCON=0을 반환한다(958–962). 암거 식은 KCON·HS_LENGTH·HS_MANN을 분모로 사용하며 COMPUTE_HSFLOW에는 이 값들의 양수 검사 분기가 없다.
- 330–355·590: 암거 증감률 제한은 0.95·1.05를 사용한다. 시작 유량 보정은 0.015·0.0125를 사용한다. QMAX 제한은 0.01·0.1을 사용한다. 갑문 취수·회귀 유량 증가량은 QNWR*0.1이다. 이 값들은 코드 상수다.
- 395–408: 전이 수심 구간에서 RATIO는 HDD 기준으로 계산한다. HUD>=1.25*HB 분기는 RATIO*Q2+(1.-RATIO)*Q1을 사용한다. HUD가 HB와 1.25*HB 사이인 분기는 RATIO*Q1+(1.-RATIO)*Q2를 사용한다.
- 456·515: 유형 7 보의 사다리꼴 직사각형 성분은 HS_WIDTH(IHYD)를 사용한다. 유형 8 오리피스를 보로 처리하는 같은 성분은 WOPEN을 사용한다.
- 494: 자유 오리피스 분기는 HUD를 ZHU-USINV+0.5*HB로 다시 설정한다. 행 주석은 중심선(centerline) 기준이라고 적는다.
- 563·578·605–615: 갑문 참조 탐색은 M2를 다음 구조물로 옮긴 뒤 M1의 ISTATE를 검사한다. 하류 참조 ZHDR를 HYD_STR(NCTL)에 저장하지만 배수 종료 조건은 지역 ZHD를 사용한다.
- 643–700: 갑문 마스크는 개방량 합이 증가하면 FOPEN=1, 감소하면 FOPEN=0이다. 네 인접 셀 조건 외의 경우를 처리하는 else는 없다.
- 707–709: 지원하지 않는 구조물 분기는 NQCTYP=10이다. STOPP 문자열의 번호는 9다.
- 130·445·481·504·711–713: CDD는 초기값 없이 선언한다. 실행 대입은 유형 7·8 분기에 있다. 유형 11 분기는 CDD를 대입하지 않고 유량식에서 사용한다.

- 811·839·844–852·900–904: 반원 분기는 보정 뒤 DIA=RA로 바꾼다. 반타원 분기는 RB=HS_HEIGHT(IHYD), DIA=HS_HEIGHT(IHYD)로 설정하고 보정 뒤 DIA를 바꾸지 않는다.
