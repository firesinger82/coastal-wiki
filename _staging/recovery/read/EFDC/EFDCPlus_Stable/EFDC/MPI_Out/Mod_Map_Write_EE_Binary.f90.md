## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 51·57: 드라이버에서 가져온 Variables_Propwash와 선언한 K/L/NS는 이 드라이버의 실행문에 등장하지 않는다.
- 170–178: QSUME를 선택하는 else는 KC>1이 아닌 경우이다. 해당 주석은 “KC < 1”이라고 적혀 있다(176).
- 225–239·276–304·329–335: LWC_temp_gl와 WVDISSIPA_temp_gl에는 할당 직후 전체 0 초기화가 없다. 두 배열은 해당 루프에서 1..LA만 채운다. LEC/LNC/LSC와 파고·주기·방향 배열에는 전체 0 초기화가 있다.
- 225–232·482–486: Map_Write_WCOUT은 임시 배열 8개를 할당한다. 명시적 deallocate 목록은 5개이다. LWC_temp_gl·LSC_temp_gl·WVDISSIPA_temp_gl은 이 목록에 없다. 이 사실은 루틴 종료 시 자동 해제 여부를 판단하지 않는다.
- 739–820·829–832: Map_Write_SDOUT은 SMPON부터 WQBFSAD까지 등록한다. 온도 보정식은 TEM_Global·KSZ_Global을 참조하지만 이 루틴에는 두 배열 등록 호출이 없다.
- 979–988: 주석은 “3D arrays of real(4)”라고 적는다. 실행 조건과 전달 배열 이름은 300+rkd 및 RK8을 사용한다.
- 992–1022: 배열을 비운다는 주석 아래 포인터 변수명은 모두 주석이다. 이 블록의 실행문은 Dim_Array_Written_Out(:)=0이다.
