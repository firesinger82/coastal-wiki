## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 469–484·495–506: save와 write_schema_file은 출력 파일을 open한다. 두 루틴에는 close 문장이 없다.
- 589–609: get_real은 지역 real(rk), target 변수 target을 선언한다(591). 이 함수의 실행문은 해당 지역 변수를 참조하지 않는다.
- 1117·1126–1136: type_settings_create의 node는 optional이다. present(node) 분기 밖의 create 참 분기는 node%value%parent와 node%set_value를 참조한다.
- 1224·1235–1240: list_set_data는 last_item을 self%first로 시작한다. 기존 항목이 있을 때 마지막 항목을 찾는 루프는 이 블록에 없다.
- 1212·1229·1232: strindex는 길이 8이다. 목록 항목 경로는 strindex를 trim하지 않고 '['와 ']' 사이에 연결한다.
- 1301–1306·1339–1400: settings_write_yaml의 write_header 호출은 주석 처리되어 있다. 내부 write_header에는 자기 재귀 호출이 있지만 바깥 실행문에서 호출하는 문장은 없다.
- 1546–1549: format_real의 고정 소수점 시도 조건은 value<1.e7_rk이다. 조건은 절대값을 사용하지 않는다. 정수성 검사는 kind를 지정하지 않은 int(test)를 사용한다.
- 25–26·1613–1616: 정수 기본 범위는 -huge(1)..huge(1)로 선언한다. format_integer의 출력 버퍼는 길이 8로 고정한다.
- 1706–1710: list_write_schema는 인수 선언만 있고 XML 출력 실행문이 없다.
