## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 11·30: 머리말 날짜는 12/19/2024이다. 변경 기록의 QUICKEST 구현 날짜는 2025-12이다.
- 44·56·72·77–90: DDELTA·DDELTD2·ITRANFLOC는 선언과 대입 후 실행 계산의 입력으로 사용되지 않는다. WCSUM은 선언 후 사용되지 않는다.
- 173·192·221·239: 수평 QUICKEST 계산 여부는 SUB 또는 SVB의 0.5 초과 조건으로 정한다. 이 판별은 SUB3D·SVB3D를 사용하지 않는다.
- 266–280·287–301: 수직 경계 주석은 현재 농도를 반복해 풍상법으로 퇴화한다고 적는다. 두 경계 분기는 CONC_U에 중심 농도를 반복한 뒤 내부 경계와 같은 QUICKEST_FACE 함수를 호출한다. 이 파일은 그 함수 내부를 정의하지 않는다.
- 165·214·276–298: 수평 쿠랑 수는 ABS(U2)·ABS(V2)와 면 격자 길이 역수를 사용한다. 수직 쿠랑 수는 인접 DZC 평균*HP+1.E-30을 분모로 사용한다. 이 파일에는 계산한 쿠랑 수를 특정 범위로 제한하는 문장이 없다.
- 257–258·280·301·315–317·327–329: FWUU 계산은 K=1..KS에 한정된다. CD 갱신은 FWUU의 K−1과 K를 참조한다. 이 파일에는 FWUU의 0·KC 경계를 초기화하는 문장이 없다.
- 103·348–349·490: 개방 경계 저장·적용의 실제 조건은 IW<=NACTIVEWC이다. 348행 주석은 IW=0 난류 이류(turbulence advection)를 우회한다고 적는다. 490행 종료 주석은 IW>0 블록이라고 적는다.
- 120–151: 수송 생략 검사는 부호 그대로 합산한 BCSUM<=0에서 현재 농도의 최댓값을 검색한다. 이 합산에는 ABS를 쓰지 않는다.
- 180·198·227·245·279·300·321: 면 농도는 여섯 위치에서 QUICKEST_FACE 호출로 구한다. 제한자가 내장되어 ISFCT·ISADAC를 쓰지 않는다는 설명은 321행 주석이다. MOD_QUICKEST의 함수 내부는 이번 대상 파일에 포함하지 않았다.
