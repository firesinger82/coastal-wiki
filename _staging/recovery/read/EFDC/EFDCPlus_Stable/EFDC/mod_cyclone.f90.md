## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 61·77·87: ICYCLONE 선언 기본값은 0이다. ReadCyclones 안의 ICYCLONE 초기화와 cyclone_model 판독 호출은 주석이다. 이 파일의 실행문에는 ICYCLONE 대입이 없다.
- 90·100·138: ReadCyclones는 cyclone_tracks와 points를 할당한다. 이 루틴에는 기존 할당을 해제하는 문장과 JSON 자료를 해제하는 호출이 없다.
- 92–96·134–135: start_time은 -1.e30에서 시작하며 더 큰 점 시간으로 갱신한다. end_time은 +1.e30에서 시작하며 더 작은 점 시간으로 갱신한다. 두 값은 fson_get 입력 뒤에도 각 점에서 갱신한다.
- 140–175·200–217: InterpCycloneTrack은 점들의 Time으로만 포함 구간을 찾는다. start_time·end_time은 이 함수와 CycloneFields에서 검사하지 않는다. num_points가 1이면 인접 점 루프가 실행되지 않는다.
- 122·155: 이동 속도 계산의 시간차 조건은 ABS(delTT)>=1.0e-9다. 보간의 시간차 조건은 ABS(deltaT)>1.0e-9다. delTT는 초로 환산하며 deltaT는 일 단위다.
- 195–197: TC_KF<=0 검사에서 대입 대상은 TC_KM이다. TC_KF는 이 보정문에서 바뀌지 않는다.
- 43·308·433: thetaMax 선언 기본값은 65다. Hubbert 장 계산은 thetaMax를 70으로 대입한다. McConochie 점 계산은 thetaMax를 사용하지만 해당 장 계산 루틴에는 thetaMax 대입이 없다(369–395).
- 237·275–283·347–355·413–421·536–539: delP를 1 이상으로 제한하는 문장은 Holland 장 루틴에만 있다. 나머지 세 점 계산 루틴도 delP를 기압식에 사용한다.
- 293–297: Holland 점 계산은 gamma 식에서 pt.Vmax로 나눈다. 이 루틴에는 pt.Vmax=0을 검사하는 조건이 없다. pt.Vmax 선언 기본값은 0이다(24).
- 240·311·378·469: 자동 coeffB의 상·하한 제한은 Holland 식에만 있다. 다른 자동 coeffB 식에는 min·max가 없다.
- 379–380·485: McConochie 장 계산은 입력 Rmw가 양수이면 유지한다. Willoughby 장 계산은 pt.Rmw를 복사하지 않고 풍속·위도로 Rmw를 계산한다.
- 542–543·551–553·629·635: Willoughby 전이 풍속의 ww에는 WeightingDeriv(xi)가 들어간다. WeightingFunc(xi)는 별도 함수로 정의되어 있다.
- 424–428·570–574: McConochie와 Willoughby의 r<Rmw 유입각 식은 서로 다르다. 전자는 `beta = 10. * r / Rmw` (426), 후자는 `beta = 10. + (1. + r / Rmw)` (572)다.
- 291·363·451·566: Holland는 TC_CSWP를 곱한다. Hubbert와 McConochie는 TC_CSWP로 나눈다. Willoughby 점 루틴에는 TC_CSWP 사용이 없다.
- 200–218·618–622: 트랙은 순서대로 기존 풍속과 혼합한다. PATMT(L)는 혼합 계수를 적용하지 않고 Pa로 덮어쓴다. 이 파일에는 여러 트랙의 순서를 별도로 정렬하는 문장이 없다.
- 242·313·382·503: 네 장 루틴의 OpenMP PRIVATE 목록은 ND·LF·LL·L·X·Y다. 점 루틴 출력 인수인 r·Pa·Wx·Wy는 이 목록에 없다. 병렬 실행 결과는 이번 판독에서 확인하지 않았다.
- 641–655: 반복 최대 횟수는 100이며 허용오차는 10e-4다. df=0 검사, x 범위 제한, 수렴 실패 반환 상태는 SolveNewtonRaphson에 없다.
- 225–226·304–305·373·527–528: Holland 장 루틴의 fc·omega·factor·DEL, Hubbert 장 루틴의 fc·omega·DEL·Vm, McConochie 장 루틴의 DEL, Willoughby 점 루틴의 gwd는 선언 이후 실행식에 등장하지 않는다.
