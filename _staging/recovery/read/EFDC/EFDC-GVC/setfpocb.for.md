## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 87·209–315: ITYPE=0과 ITYPE=1은 독립 IF 블록이다. 다른 ITYPE 값을 처리하는 ELSE나 오류 출력은 없다.
- 95·122·157·185: 전체층 초기화는 K<=KBT(L)인 층에만 값을 대입한다. 더 큰 K를 초기화하는 문장은 이 루틴에 없다.
- 158·273: 전체층 클래스 3·4 조건은 VFRBED(L,K,3)+VFRBED(L,K,4)>0이다. 표층 갱신 조건은 VFRBED(L,K,3)>0이다.
- 150·266·164–170·279–285: 미세 비점착성 블록의 제목은 CLASS 2다. 실행 대입의 클래스 인덱스는 3과 4다.
- 186–199·297–310: 예측 전체 분율은 클래스 1..4만 합산한다. PFPOCB 비율 보정 뒤 각 클래스에 1.0 상한을 다시 적용한다. 최종 전체 분율을 다시 맞추는 식은 없다.
