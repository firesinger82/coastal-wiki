## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 64·273–288·303–318: 초기 교차 속도 루프는 `LN=LNC(L)` (64)을 대입한다. 파랑 포함 초기 난류 계산은 V1(LN,1)과 V(LN,1)을 사용한다(281·311). 이 두 ND·L 루프에는 LN을 현재 L로 다시 대입하는 문장이 없다.
- 523–532: CALEXP1 선택 블록과 ISCDMA=3·4의 CALEXP3 호출은 주석 처리되어 있다. 활성 명시 운동량 호출 조건은 ISCDMA<=2, =5, =6, =9이다.
- 631–682: CALPUV 선택 블록 대부분은 CJH·CX·C 주석이다. 649–650행 CALPUV9·CALPUV9C 호출은 활성 코드이며 주석 처리된 ISCDMA·IRVEC 조건 안에 포함되지 않는다.
- 705·710–711: 진단 WRITE의 실수 인수에는 ABMIN이 두 번 들어간다. 출력 머리글에는 AVMA·AVMI·ABMA·ABMI가 적혀 있다.
- 715–716: 최대 반복 횟수 갱신은 `ITRMAX=MAX(ITRMAX,ITER)` (715)이다. 다음 대입은 `IRRMIN=MIN(ITRMIN,ITER)` (716)이다. 최소 반복 횟수 대입의 좌변과 우변 누적 변수 이름이 다르다.
- 788–803: KC>1 참 분기와 else 분기 모두 CALUVW(ISTL,IS2TL)를 호출한다. else는 해당 호출 전에 단층 U·V를 외부 모드로 계산하고 `W(L,1)=0.` (799)을 대입한다.
- 1018–1025·1124–1126: ISICM>=1도 ITMP=1을 설정한다. 이 수질·패류 계산 블록의 활성 계산 호출은 ISTRAN(8)의 WQ3D와 ISTRAN(4)의 CALSFT(2)이다. CALWQC 호출은 주석이다.
- 1073–1078: WWQ 계산 루프의 첫 수직 인덱스는 K=1이다. 식은 WWQ(L,K-1)을 참조한다. 이 파일에는 WWQ(L,0)을 대입하는 문장이 없다. 포함 파일과 호출 루틴의 초기화는 판독하지 않았다.
- 69–70·1185–1189: 초기 교차 속도 계산은 H1C와 HMC를 모두 대입한다. 시간 루프 안의 교차 속도 계산은 H1C·UV·VU를 대입하며 HMC 대입은 없다.
- 371–372·1431–1436: 시간 루프의 TIMESEC·TIMEDAY는 ISDYNSTP 조건 없이 DT*FLOAT(N)으로 계산한다. 출력용 TIME에는 ISDYNSTP 분기가 따로 있다.
- 1438–1448·1470–1479: TMSR의 NBTMSR..NSTMSR 조건은 주석 처리되어 있다. HYDOUT의 같은 N 범위 조건은 활성 코드이다.
- 1442·1458·1508: TMSR·DUMP 호출 분기는 ICALLTP=1을 대입한다. `ICALLTP=0` (1508) 대입은 0차원 수지 출력의 주석 블록 뒤에서 실행된다. 이 파일에는 ICALLTP 값을 조건이나 식으로 읽는 실행문이 없다.
- 1608–1610·1632–1650·1663–1736: 조화 분석·그래픽 출력의 다음 호출 카운터는 NTSPTC/24 또는 NTSPTC/출력 횟수를 더한다. 이 블록에는 분모 0 검사나 증가량 0 검사가 없다. 변수의 형식과 입력 제한은 포함 파일·다른 루틴을 판독하지 않아 확인하지 않았다.
- 1786–1792: ISCRAY=0 분기는 THDMT 기존 값에 경과 시간을 더한다. else 분기는 THDMT에 경과 시간만 대입한다.
- 1880–1894: CFLMAX.OUT 삭제·재생성·출력은 ISCFL 조건 없이 수행된다. 출력 FORMAT은 각 행에 12F7.2를 지정한다.
