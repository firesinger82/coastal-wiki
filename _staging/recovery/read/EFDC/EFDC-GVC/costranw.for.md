## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 20–23: 6행의 루틴 이름은 COSTRANW지만 목적 주석에는 COSTRAN이라고 적혀 있다.
- 273–277·332: KC=1 분기는 CONCYZ 대신 CONCZ(L,1)에 CONCY(L,1)을 대입한다. 결합 농도 CONCXYZ 식은 CONCYZ(L,K)를 참조한다. KC=1 경로에서 CONCYZ에 값을 대입하는 별도 문장은 이 파일에 없다.
- 355–356·413–414·468–513: 수평 플럭스 루프는 각 셀에서 CSTARN/CSTARP를 0 초기화한다. 수직 플럭스 루프에는 해당 초기화가 없다. 수직 루프의 CSTARP는 W2>0일 때만, CSTARN은 W2<0일 때만 대입된다.
- 468–513: 수직 플럭스 계산은 CONCXYZ 배열을 참조한다. 이 파일에서 CONCZXY 배열은 336–337행에 계산된 뒤 실행식에 다시 등장하지 않는다.
- 493–495·498: W2<0 분기는 CSTARU와 CSTARUU를 모두 CONCXYZ(L,K+1)에서 복사한다. K<KS 조건의 CSTARUU 대입도 같은 인덱스 K+1을 사용한다. 바로 뒤 TOP 식은 CSTARU−CSTARUU이다.
- 607·622–625·646–649: ISCDCA가 0이 아닌 경로의 주석은 FQC 공급항을 포함하지 않는다고 적는다. 두 실행 CH 식은 RDZIC*FQC(L,K)를 포함한다.
- 42–70: DELTD2·S3TL·S2TL·DELTA4는 이 파일에서 대입된 뒤 실행식에 다시 등장하지 않는다. DELTA는 설정·DELTA4 계산에 사용되지만 이류 플럭스 식의 시간 간격은 DELT이다.
- 29–36·98–104: CONTMX/CONTMN, FQCPAD/QSUMPAD/QSUMNAD를 선언한다. 이 파일에는 CONTMX/CONTMN을 사용하는 실행문이 없다. CALFQC에 전달한 공급·배출 작업 배열은 이 파일에서 후속 계산식에 등장하지 않는다. CONT/CMAX/CMIN은 0 대입만 있다.
- 76–83·468–515·538–541: 입구의 0 초기화 목록에는 FWU가 없다. 수직 플럭스 대입 루프는 1..KS이며 CH 갱신은 수직면 인덱스 0과 KC도 참조한다. 포함 파일·호출 루틴의 초기화는 확인하지 않았다.
