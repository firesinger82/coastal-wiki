## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 6·19: 루틴 선언은 CALTRAN1D이다. 수송 설명 주석은 루틴 이름을 CALTRAN으로 적는다.
- 71–82: 시작 초기화 목록은 FUHV(L,K)=0.을 두 번 대입한다(74·76). 이 목록에는 FVHV 대입이 없다. FVHV 실행 대입은 이후 플럭스 부호 분리에서 나온다(944).
- 84–89·427·516: AREANEW·AREAOLD 대입은 LCT=6 또는 LCT=7 조건에만 있다. 다른 LCT 값의 ELSE 대입은 이 블록에 없다. CON 갱신은 AREANEW를 분모로 쓰며 해당 갱신 블록에는 0 분모 검사 조건이 없다. 외부 초기화는 확인하지 않았다.
- 57–69: 시간 수준 선택의 두 경로 모두 ISUD=1로 설정한다. ISLTMT 조건도 ISUD=1을 대입한다. 이 파일의 실행문에는 ISUD=0 대입이 없다.
- 54–63·771–772: DELTD2·S3TL·S2TL은 값을 받는다. 이후 실행식은 이 세 변수를 참조하지 않는다. DELTD2를 쓰는 대체 수평 역확산 식은 주석이다.
- 93–100·108–109: CALFQC를 호출하기 전에 K=1..KC·L=1..LC의 CON을 CON1에 무조건 복사한다.
- 6·26–27·108–109: CALFQC 호출은 IS2TL을 인수로 넘긴다. CALTRAN1D의 인수 목록에는 IS2TL이 없다. 이 파일 본문에는 IS2TL의 별도 선언·값 대입이 없다. 포함 파일의 선언·초기화는 확인하지 않았다.
- 189–202·204–217: 300 경로의 실행 플럭스 계산은 수평 FUHU·FVHU만 대입한다. 같은 경로의 이전 수직 FWU 계산은 C1D 주석이다.
- 365–370·391–394·460–465·486–489: ISTL=2의 두 CH 실행식은 수평 플럭스만 포함한다. 다른 시간 수준의 두 CH 실행식은 수직 FWU 차이도 포함한다.
- 445·460–462·486–489: 주석은 ISCDCA가 0이 아닌 경우 FQC를 포함하지 않는다고 적는다. 해당 ELSE의 두 CH 실행식에는 FQC가 들어 있다.
- 71–82·734–739·761–766: 시작 초기화 루프에는 WWW 대입이 없다. WWW 실행 갱신은 K=1..KS에서 수행한다. 수평 역확산 교차항은 K=1의 WWW(...,K-1)도 읽는다. 이 파일 본문에는 WWW(...,0)·WWW(...,KC)를 따로 초기화하는 대입이 없다. 외부 초기화와 실제 KS·KC 관계는 확인하지 않았다.
- 30·108–109: FQCPAD·QSUMPAD·QSUMNAD는 배열 선언과 CALFQC 호출 인수로만 실행문에 등장한다. 이 파일의 이후 계산식은 이 세 배열을 참조하지 않는다.
- 889–900: CONTMX·CONTMN 대입은 L=2..LA 범위이다. 이 파일 본문에는 두 배열의 L=1..LC 전체 0 초기화가 없다. 첫·마지막 층 극값 계산은 KC=1 별도 분기 없이 인덱스 2와 KS를 읽는다. 실제 배열 범위와 입력 층 수는 확인하지 않았다.
- 427·516·965–970·1132–1136: 표준 농도 갱신은 CH/AREANEW를 사용한다. FCT 유입·유출량 계산은 HPI를 사용한다. 마지막 역확산 갱신은 CON*HP·CH*HPI를 사용한다.
- 48·924–927·1081–1084: BSMALL=1.0E-6과 이웃 최소 농도 보정의 1.E+6은 고정값이다. DU·DV 베타 계수에는 MIN(...,1.) 상한이 있다. 이 베타 계수 블록에는 MAX(...,0.) 하한 대입이 없다.
- 717–718·1168: ISADAC=0 또는 ISCDCA=1이면 FCT 진단 절에 도달하기 전에 RETURN한다. FCT 진단 출력 조건은 ISFCT=2이다.
