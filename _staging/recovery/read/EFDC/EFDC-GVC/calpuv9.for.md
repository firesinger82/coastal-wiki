## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 36–67·139·582·710·747: 진단 파일 삭제 조건은 ISDSOLV=1이다(36·47·58). 진단 추가 출력 조건은 ISDSOLV≥1이다(139·582·710·747).
- 83·93–105·129–136: CALEBI 호출과 FPGXE·FPGYE 갱신은 BSC>1.E−6 조건을 사용한다(83·93). 명시적 수송 식은 FPGXE·FPGYE를 해당 BSC 조건 밖에서 참조한다(132·136). BSC 조건의 else에는 두 배열을 재설정하는 실행문이 없다.
- 218–225·235–244: 다층 저항의 TMPX·TMPY 기본값은 1.0이다(218–219·235–236). 비영 UHE·VHE 조건이 성립하면 바닥 속도와 면 수심의 곱을 UHE·VHE로 나눈다(220–221·237–238). 이 계산 블록에는 계산한 TMPX·TMPY의 부호나 크기를 제한하는 대입이 없다.
- 201–208·239–244·254–257: 실행 식생 저항 항은 DELT*FXVEGE·DELT*FYVEGE이다(203·207·241·244). 식생 항에 RITB를 곱하는 대체 연속행은 주석이다(204·208). ORIGINAL 블록에는 RITB를 곱한 식과 곱하지 않은 식이 모두 주석으로 남아 있다(254–257).
- 610–630·688–705: 최소 대각 계수의 역수는 조건 없이 계산한다(630). IRVEC=99 경로는 CC 및 이웃 CC 곱의 제곱근으로 나눈다(688–693·705). 해당 블록에는 역수와 제곱근 앞의 양수·0 분모 검사 조건이 없다.
- 669–700: 정규화 계수 CCS·CCW·CCE·CCN·CCC와 CCCI 대입은 IRVEC=9 또는 IRVEC=99 분기 안에 있다. CALL CONGRAD는 두 분기 밖에서 실행한다(700). 이 구간에는 그 밖의 IRVEC 값에 대한 정규화 계수 대입 분기가 없다. CONGRAD 내부는 이 판독에 포함하지 않았다.
- 269–279·804–850·911–1008: 면 스위치 복원 루프에는 ISCDRY 조건이 없다(269–279). 새 수심 계산과 최종 갱신 뒤에는 음수 HP·HU·HV의 진단 및 조건부 종료가 있다(911–1008). 이 파일에는 ISCDRY에 대입하는 실행문이 없다.
- 838–843: 단순 인접 수심 평균식은 주석이다(838–839). 실행 HU·HV 식은 각 셀의 DXP*DYP*HP 합의 절반을 속도 면의 DXU*DYU 또는 DXV*DYV로 나눈다(840–843).
- 847–849·915·932·950: 셀·면 수심의 역수는 음수 HP·HU·HV 검사보다 앞에서 계산한다. 역수 계산 루프에는 0 분모 검사 조건이 없다.
- 776·989–990: FORMAT 1002의 시작은 3I4이다(776). 해당 FORMAT을 사용하는 WRITE의 첫 세 자료 항은 IL(L), JL(L), SUB(L)이다(989). SUB의 선언 형식은 포함 파일 판독 대상 밖이므로 이 기록에서 확인하지 않았다.
- 997–1002·1010–1011: CFL 진단 WRITE는 K=1..KC의 값을 출력한다(998–1001). FORMAT 1991·1992의 실수 필드 수는 각각 12로 고정되어 있다(1010–1011).
- 1059–1060·1073–1100·1106–1109: 발산 최댓값은 0, 최솟값은 1000000으로 초기화한다. LMAX·LMIN 대입은 최대·최소 갱신 조건 안에 있다. 이 진단 블록은 해당 조건 실행 여부를 확인하는 별도 분기 없이 두 셀 번호를 참조한다.
- 457–462·582–608·1072·1092·1134: RIFTR·EVAPSW 초기화는 ISGWIE≥1 분기 안에 있다(457–462). FP 진단 출력, 발산식, 0차원 체적 수지식은 별도 ISGWIE 조건 없이 두 배열을 참조한다. 포함 파일과 외부 초기 상태는 이 판독에 포함하지 않았다.
- 1132–1139: L=2..LA 루프는 1136행에서 끝난다. VETZERD 갱신식은 루프 밖에서 EVAPSW(L)을 참조한다(1139). 루프 종료와 해당 참조 사이에는 L 재대입이 없다.
