## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 8–9·6: 설명 주석의 루틴 이름은 CALEXP이고 실행 루틴 선언은 CALIMP2T다.
- 561–563·598–609: y 이류 설명은 운반장을 N과 N+1 사이에서 평균한다고 적는다. 실행 수평·수직 운반량 식은 동일한 UHDY·VHDX·W 값을 각각 두 번 더한다.
- 403·569·436–437·608–609: W2 설명 주석은 DXYP*W/H라고 적는다. 표준 형태의 실행 W2 식에는 HP 또는 H로 나누는 항이 없다. W의 외부 정의는 이 파일 판독에 포함하지 않았다.
- 694–712·713–753: 연속 방정식 반 단계 진행·중간 속도 초기화 머리말 아래에는 실행문이 없다. 코리올리·곡률 반복 시작 주석 뒤에는 CAC·FCAX·FCAY 계산과 TVAR1W/S 갱신을 수행하는 K·L 루프가 있다. 이 파일에는 반복 횟수·수렴 조건을 검사하는 실행 분기가 없다.
- 789–806: 수평 운동량 확산을 FX·FY에 적용하는 ISHDMF 조건과 플럭스 차분 대입은 모두 주석 처리되어 있다.
- 838–850·899–930: 두 ISTL=3 조건 블록과 ELSE·ENDIF는 주석 처리되어 있다. 911–928행의 DU·DV 계산과 수면 응력 제거는 해당 조건 없이 실행한다.
- 921–928: 마지막 DU·DV 대입은 층 인덱스 KS를 직접 사용한다. 이 블록 앞에는 KS>0 조건이 없다. 앞의 내부 전단 루프 범위는 K=1..KS다(911).
