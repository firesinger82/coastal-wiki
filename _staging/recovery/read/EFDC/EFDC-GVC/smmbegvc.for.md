## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 55–61: 동적 시간 ELSE 분기는 TIMTIM에 값을 대입한다. 오류 로그 WRITE는 TIMTMP를 전달한다. 이 오류 블록의 동적 시간 분기에는 TIMTMP 대입이 없다.
- 136–137: 비활성 산소 하한은 0.1이다. 실행 산소 하한은 3.0이다.
- 106–126: 유기물 상태 갱신은 M=1..NSMG를 사용한다. 속성작용 플럭스는 그룹 1과 2만 합산한다.
- 118–119·150–151·177–178·305–306: 분할 시작 LF의 간격은 LDMWQ다. 종료 LL의 길이 계산에는 LDM을 사용한다.
- 233–255: ZBRENT 오류 상태 1·2는 로그만 기록한다. 이 분기 뒤 결과 복사와 WQBFO2 계산을 계속하는 실행문이 있다.
- 276–299·303–351: PO4와 규소 플럭스 갱신에는 SCB 또는 IWQSI 조건이 있다. 뒤의 플럭스 누적은 모든 L=2..LA에 대해 실행하며 갱신 조건의 ELSE에서 플럭스를 0으로 두는 문장은 없다.
- 346–362: 플럭스 누적식은 해당 플럭스 값을 직접 더한다. DTWQ를 곱하는 문장은 이 누적 블록에 없다. TIMEBF는 현재 시간 척도 값을 더한다.
- 251–252·218–229: SM1H2S·SM2H2S 결과 복사는 염분 조건 밖에 있다. 이 파일의 낮은 염분 ELSE는 CH4 계수만 설정한다.
