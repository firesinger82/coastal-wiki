## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 54–67: FUHV(L,K)=0.은 57행과 59행에 반복된다. 이 초기화 루프에는 FVHV 대입이 없다. FWQQ/FWQQL은 0 초기화한다(64–65).
- 33–45: DELTD2·DELTI·S3TL·S2TL·BSMALL은 설정 이후 이 파일의 실행 조건이나 계산식에서 참조되지 않는다. 포함 파일에 따른 저장 위치와 다른 루틴의 참조는 이 판독 범위 밖이다.
- 6·80·141·274·406: ISTL은 인수로 받는다. 이 파일에서 ISTL을 검사하는 조건은 모두 주석 처리되어 있다.
- 49–50·128–131·207–214: QQ2/QQL2는 실행문에서 QQ/QQL의 두 배로 계산한다. 해당 배열을 사용하는 후속 플럭스 식은 이 파일에서 주석 처리되어 있다.
- 82–108·144–182: IDRYTBP 불성립 경로의 플럭스 계산은 LMASKDRY 참인 셀만 갱신한다. 수평 FVHV는 초기화 루프에서 0 설정하지 않는다(54–67). LMASKDRY 불성립 셀의 값을 설정하는 ELSE는 플럭스 블록에 없다.
- 294–295·303–309·334–335·345–351: ISWAVE≤1 경로는 UUU/VVV를 0 이상으로 제한한 뒤 생성 항을 더한다. ISWAVE≥2 경로에는 해당 MAX 제한 루프가 없다(397–470).
- 272–356·397–435: ISWAVE≤1 경로는 IDRYTBP·LMASKDRY 조건을 사용한다. ISWAVE≥2 생성·수송 경로에는 해당 두 조건이 없다. ISWAVE≤1 수송 초기 항은 QQ/QQL을 사용하고 ISWAVE≥2 초기 항은 QQ1/QQL1을 사용한다(282·286·320·324·427·430).
- 474–513: KC≤2 계산은 AQ(L,2)·QQ(L,0)·QQ(L,KC)를 사용하고 K=1을 갱신한다. 이 블록에는 KC=1을 별도로 처리하는 조건이 없다.
- 487–488·507–508·550–551·569–570·597–598·618–619: 역수 계산 앞에 대각 계수나 전진 소거 분모의 크기를 검사하는 실행 조건은 없다.
- 29·521–532·798–803: 진단 배열 선언과 진단 출력은 CDIAG 주석이다. 진단 FORMAT은 실행문으로 남아 있으며 실행 WRITE 문은 없다.
