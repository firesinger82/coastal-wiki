## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 10–12·1151·1346·1419: 머리말은 구값+신값 저장에서 상태 15·19·21을 예외로 적지만, 세 상태 실행 대입 모두 WQVO에 WQV를 더한다.
- 54–56·1481–1483·1501–1503·1513–1515: 영역 시작은 LDMWQ 간격이고 끝은 LF+LDM-1이다. 두 길이의 일치 여부는 이 파일에서 검사하지 않는다.
- 113–118: 오류 로그 시각 TIMTMP를 먼저 계산한 뒤 ISDYNSTP의 두 분기에서 다시 대입한다.
- 212–215: Secchi 수심 계산 안내 아래 실행문은 WQKETOT에 WQKESS를 저장한다. WQSDCOEF/WQKESS 식은 주석이다.
- 253·257–261: 대형조류 광 제한은 현재 층 바닥까지 감쇠된 WQI0BOT를 층 적분 입력으로 다시 사용한다.
- 413–419·468–474: IWQSRP=2 인산염 상층 공급은 SEDT(L,K)를 사용하고 규산 상층 공급은 SEDT(L,K+1)를 사용한다.
- 149–150·390·455–456: 암모늄·산소의 비음수 작업값을 계산하지만 질산화식은 WQVO(L,K,19)·WQVO(L,K,14)를 직접 사용한다.
- 536–540: 풍속 11 m/s 제한 안내와 제한 IF 대입은 주석이다. 실행 바람 식은 WINDST(L)를 제한 없이 WINDREA로 복사한 값을 사용한다.
- 567–581: 주석 처리된 IWQKA=2 식은 HP(L)**1.5 분모와 면 속도 MAX를 사용한다. 실행 식은 HP(L)**0.5 분모와 면 속도 평균을 사용한다.
- 552–608·612: WQVREA는 IWQKA 0..4의 독립 IF에서 설정된다. 그 외 값에 대한 ELSE나 이 표층 분기 입구의 WQVREA 초기화는 없다.
- 646–648: 대형조류 신값 계산과 WQMCMIN 제한 대입에서 SMAC를 각각 곱한다.
- 940–941·840–841·878–879·914–915: PO4T 대형조류 포식 항은 WQFPIP를 사용한다. RPOP·LPOP·DOP 대형조류 포식 항은 각각 WQFPRPM·WQFPLPM·WQFPDPM을 사용한다.
