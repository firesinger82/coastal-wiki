## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 50–339: 파일명 대입 분기는 NCALL3D=1..24에만 있다. NCALL3D>24의 파일명 설정이나 기본 분기는 이 파일에 없다.
- 355–572: 각 변수의 극값 탐색 루프는 K=1..KC·L=2..LA이다. 극값 탐색에 I3DMIN/I3DMAX·J3DMIN/J3DMAX로 셀을 제한하는 조건은 없다.
- 538–544: JS3DSND=0 분기는 SND3DMA를 설정하면서 최솟값 변수로 SED3DMI를 대입한다. SND 극값 복사 조건은 JS3DSED=1이다.
- 551–567: ATOXMAX/ATOXMIN을 초기화한다. TOX 루프의 극값 갱신 대입 대상은 ASEDMAX/ASEDMIN이다. 이후 진단과 TOX 출력 범위에는 ATOXMAX/ATOXMIN을 사용한다.
- 846–863: TOX 자료를 단위 59에 쓰는 정수/실수 선택 조건은 JS3DSND이다.
- 1184–1218: TOX 재배열 블록은 단위 59를 열고 닫는다. 정수 배열의 WRITE는 단위 54이며, 실수 배열의 WRITE는 단위 59이다(1203·1214).
- 599–614: KPB/KPS를 찾는 각 탐색은 조건을 만족한 경우에만 해당 값을 대입한다. 이 셀 루프 앞에는 KPB(L)/KPS(L)를 초기화하는 문장이 없다.
- 625–636: 보간식의 분모는 인접 ZZ 값의 차이다. 하단 보간은 ZZ(2)를 직접 참조한다. 이 블록에는 KC>1이나 분모의 0 여부를 검사하는 조건이 없다.
- 673·708·727·746·765·784·812·831·850: SCALE3D는 각 출력 최댓값과 최솟값의 차로 254를 나눈다. 이 나눗셈 앞에 차가 0인지 검사하는 조건은 없다.
- 688–690·716–718·735–737·754–756·773–775·792–794·820–822·839–841·858–860: IAP 변환은 255 초과 값만 제한한다. 실수 출력용 AP에는 각 변수의 출력 최댓값을 곱한다.
- 899–929 및 같은 구조의 935–1217: 실수 자료 읽기는 JS3D 값이 정확히 3인 경우이다. 실수 재배열 분기의 조건은 JS3D 값이 3. 이상인 경우이다.
- 1221–1420: ISCLO=0 또는 NWGG=0 조건의 ELSE는 모든 변수 파일을 IAKL로 읽고 정수 형식으로 쓴다. 이 ELSE에는 JS3D=3용 실수 읽기/쓰기 분기가 없다.
