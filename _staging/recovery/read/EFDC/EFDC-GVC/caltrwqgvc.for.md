## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 6·19–22: 선언된 루틴 이름은 CALTRWQGVC이다. 기능 설명 주석의 루틴 이름은 CALTRAN이다.
- 38·40–67: BSMALL은 1.0E-6으로 고정되어 있다. DELTD2·S3TL·S2TL·ISUD는 이 파일에서 설정되지만 실행 계산식에서 참조되지 않는다. INCLUDE 파일 내부의 사용 여부는 확인하지 않았다.
- 121·176: ISPLIT에 따른 이동과 CALDIFF 호출은 주석 처리되어 있다. 실행 CALL은 102–103행 CALFQC이다.
- 188–217·737–740·827–835·985–999: 최초 수평 플럭스 계수 적용·CH·CON 갱신에는 LGVCP 조건이 없다. FCT 최댓값·최솟값, DU/DV, 최종 CH/CON 갱신에는 LGVCP 조건이 있다.
- 227·352·693–716·839–867: 농도 경계 계산에는 M=4용 목록과 M=8용 수질 목록이 따로 있다. 반확산 플럭스와 DU/DV의 경계 0 설정은 NCBS/NCBW/NCBE/NCBN 목록을 사용한다.
- 241·269·297·326·366·395·424·454: 경계 유출 농도의 상한을 지정하는 IF 문은 모두 주석 처리되어 있다.
- 596–602: ISFCT(MVAR)>=2에서는 수평 플럭스를 0.5배로 설정한다. 내부 ISFCT(MVAR)=3에서는 원래 UTERM/VTERM을 다시 대입한다. 600행 주석은 이 분기에서 2로 나누지 않는 이유를 묻는다.
- 669–687·139·218: CONT는 최초 농도 복사와 갱신 뒤 0 재설정에 사용된다. 공급원 차단 분기에서 CONT를 0 또는 1로 바꾸지만 이후 실행식에는 CONT 참조가 없다.
- 786–789: 최솟값 식의 농도 항은 SUB3D/SVB3D를 사용한다. 같은 식의 1.E+6 보정 항은 SUB/SVB를 사용한다.
- 939–942: 베타 계수는 DU/DV가 양수일 때만 비율로 바꾼다. 이후 MIN(...,1.)을 적용하며 별도 MAX(...,0.) 대입은 없다.
- 722·968–978: ISFCT(MVAR)=0의 GOTO 600은 SWB3D를 곱하는 968–972행 루프도 건너뛴다.
- 737–740·1007–1021: 최댓값·최솟값의 농도 비교에는 LGVCP 조건이 있다. 마지막 진단 루프에는 LGVCP 조건이 없다.
