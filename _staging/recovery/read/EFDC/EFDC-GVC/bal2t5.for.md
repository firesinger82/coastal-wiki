## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 198–199·490: UMOBMO·VMOBMO는 각각 UMOBEG·VMOBEG에서 DYEOUT을 뺀다. 같은 출력 블록은 UMOOUT·VMOOUT을 별도 항목으로 출력한다.
- 284–292·310–345: RDERDE·RVERDE·RVERDO의 -9999. 대입이 반복된다. RUERDE2T·RUERDO에는 -9999.를 대입하지만 이 파일의 이후 계산·출력은 해당 두 이름을 참조하지 않는다.
- 353·384–415·542·581·618: RDERDE2T는 DYEERR2T/DYEEND2T로 계산한다. SED·SND·TOX의 대응 상대오차는 시작값과 마지막값의 평균을 분모로 쓴다. 질량 출력 설명은 _R_E_를 2.*ERR/(END+BEG)로 표시한다.
- 194·420: WVOLBMO2T는 WVOLOUT을 뺀 값이다. RWVERDO2T는 WVOLERR2T를 VOLOUT으로 나누며 조건도 VOLOUT.NE.0.이다.
- 179–185: 전체·바닥 부피에는 HBED를 더한다. WVOLEND2T에 PORBED*HBED를 더하는 식은 주석 처리되어 있다.
- 533–534·572–573·609–610·794: FORMAT 8888은 F10.2와 10개 E14.6 필드를 고정한다. 세 질량 상대오차 파일의 WRITE 항목 수는 NSED·NSND·NTOX 반복 범위에 따른다.
- 547–548·734–736: 염료 출력의 실제 변수명은 RDERDE2T·RDERDO2T이다. FORMAT 949의 열 제목은 RDYEERE2T·RDYEERO2T이다.
