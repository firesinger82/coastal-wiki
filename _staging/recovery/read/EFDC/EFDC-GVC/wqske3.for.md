## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 60–62·1690–1692·1710–1712·1722–1724: 수평 블록 시작 LF는 LDMWQ 간격을 사용한다. 끝 LL은 `LL=LF+LDM-1` (62 등)로 계산한다. 두 크기의 관계는 포함 파일 판독 범위 밖이다.
- 118–140: 과거 온도 색인식과 STOP는 주석이다. 실행식은 `IWQT(L) = NINT( 4.*TWQ(L)+121.)` (119)이며 범위 밖이면 로그 후 MAX·MIN으로 1..NWQTD에 제한한다(121–138).
- 228–231: 주석은 Secchi 수심 출력을 설명한다. WQSDCOEF/WQKESS 식은 주석이며 실행문은 `WQKETOT(L,K) = WQKESS` (231)이다.
- 50–58·234–236·361–368: IWQSUN=2에서 표층 일사는 WQIH0(L), 일사 평균은 WQIH1(L)·WQIH2(L)·WQIH3(L)를 사용한다. 같은 IWQSUN=2의 야간 성장 중지 조건은 `IF(WQI0 .LE. 0.001)THEN` (362)이다.
- 457–462·533–538: IWQSRP=2의 비표층 PO4 유입계수는 `WQTTS = WQKPO4P*SEDT(L,K)` (461)를 사용한다. 같은 방식의 규소 유입계수는 `WQTTS = WQKSAP*SEDT(L,K+1)` (537)를 사용한다.
- 609–611: 주석은 풍속 11 m/s 상한을 요구한다. 실행문은 `WINDREA = WINDST(L)` (610)이며 이 파일에는 이 식 앞에서 풍속을 11로 제한하는 문장이 없다.
- 623–677: WQVREA 대입은 IWQKA(IZ)=0·1·2·3·4의 독립 IF 안에 있다. 이 L 루프에는 다섯 조건 밖의 기본 대입이나 다른 값에 대한 else가 없다.
- 595–690: WQKRDOS는 표층 분기에서 계산한다(678). 비표층 else는 WQP19만 0으로 설정한다(679–681). 이어 ISICE=1 분기는 K=KC 조건 없이 WQP19와 WQKRDOS에 각각 (1−RICECOVL)을 곱한다(685–690).
- 723–726: 대형조류 신 값 계산에서 SMAC를 곱한다(724). 이어 `WQV(L,K,IDNOTRVA) = MAX(WQV(L,K,IDNOTRVA),WQMCMIN)*SMAC(L)` (725)에서도 SMAC를 곱한다.
- 10–12·1311·1542·1621: 머리말은 WQVO 구·신 값 합산에서 NWQV=15·19·21을 제외한다고 적는다. 실행문은 세 색인에서도 WQVO에 WQV를 더한다.
- 1442–1449: XDOPSL·XDOALL 외부 부하 누적은 표층 습성 침적을 WQRR에 더하기 전에 수행한다(1443–1444). 해당 침적 분기에는 두 진단 배열에 침적을 더하는 문장이 없다(1446–1449).
- 1461–1464: 저층 산소 공급은 `TEMFAC=STEMFAC**(TEM(L,1)-20.)` (1461)와 `WQRR(L) = WQRR(L) + TEMFAC*WQBFO2(L)*DZWQ(L)` (1462)를 사용한다. 바로 아래 XDOSOD·XDOALL 누적식에는 TEMFAC가 없다(1463–1464).
- 579–580·1534·1563–1566: WQO18 식에는 음의 부호와 DTWQO2가 들어 있다. 산소 갱신은 `*     + WQP19(L)*WQVO(L,K,19) ) + WQO18(L)*WQVO(L,K,18)` (1534)로 COD 항을 더한다. COD 진단은 `XDOCOD(L,K)=XDOCOD(L,K) - WQO18(L)*WQVO(L,K,18)` (1563)로 같은 계수를 뺀다.
- 1611–1621: FCB 외부 부하와 구 값 식은 색인 NWQV를 사용한다(1611·1618). 습성 침적과 신 값·WQVO 합산은 색인 21을 사용한다(1615·1619–1621). NWQV와 21의 관계는 이 파일에서 설정하지 않는다.
- 1688–1707: 퇴적물 연결의 `+             +WQWSM*DZWQ(L)*WQV(L,1,IDNOTRVA)` (1698)는 IWQBEN=1·ND/L 루프 안에 있다. 해당 항을 IDNOTRVA>0으로 감싸는 조건은 이 블록에 없다.
- 1702·1705·1715–1718·1726–1729: 초기 WQDFLP·WQDFSI에 SCB를 곱한다. 흡착 성분 추가식은 기존 플럭스를 포함한 전체 괄호에 SCB를 다시 곱한다.
- 72·1631–1632·1787–1789: IMWQZT(L)는 반응 계산의 현재 K에서 설정한다(72). 광 분석 K=1..KC 루프는 `RLIGHT1=WQKEB(IMWQZT(L))+WQKETSS*SEDT(L,K)` (1789)를 사용한다. 해당 분석 블록에는 현재 K로 IMWQZT를 다시 설정하는 문장이 없다.
- 1742–1744·1753·1783–1785·1805: 일변동·광 분석 출력은 각 카운터가 NSTPTMP와 같을 때만 실행된다. NSTPTMP는 각 평균 일수 매개변수와 NTSPTC의 곱을 2로 나눈 식이며 이 블록에는 NSTPTMP>0 검사가 없다. 일변동 블록의 RMULTMP 대입값(1744)은 그 일변동 블록 안에서 사용되지 않는다.
