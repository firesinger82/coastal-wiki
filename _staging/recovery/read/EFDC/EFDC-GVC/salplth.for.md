## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 30·45–48·98–108·153–163: DBSB는 클래스 번호를 초기화한다. 해당 배열을 출력하는 문장은 모두 주석 처리되어 있다.
- 40–44·50–83·289–310: 염분·온도·염료 헤더는 LEVELS=2와 DBS=0/99를 출력한다. KC=1 데이터 분기는 농도 1개만 출력한다.
- 41·86–95·313–323·368–385: 점착성 퇴적물·독성 농도 헤더는 LEVELSS=3이다. KC>1 점착성 퇴적물 데이터는 농도/질량/플럭스 4개를 출력한다. 독성 농도 데이터는 KC=1과 KC>1에서 모두 4개를 출력한다.
- 110–151·352–362·463–473·578–589: 추가 모래 출력 파일은 SNDCONH01/02/03.OUT로 고정한다. 03 파일에 출력하는 클래스 인덱스는 3 대신 NSND이다.
- 368–381·479–492·596–611: 독성 농도와 입자상 분율은 독성종 인덱스 1만 참조한다.
- 35·204–243·301–310·410–420·521–531: ICON>=8 농도 출력 분기가 있다. 이 파일의 LUN 선택·파일 OPEN 분기는 ICON=1..7만 포함한다.
- 384·495·614·627–629: 각 좌표 형식의 독성 출력 분기에서 LUNF를 닫는다. 공통 종료 블록에서 ICON=5이면 LUNF를 다시 닫는다.
