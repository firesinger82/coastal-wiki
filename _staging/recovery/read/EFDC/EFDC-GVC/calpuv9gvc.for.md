## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 6·21–23: 루틴 선언 이름은 CALPUV9GVC이다. 목적 주석은 CALPUV9라는 이름을 적는다.
- 10·996: 머리말의 최종 수정일은 2001-11-01이다. 면 수심 계산 앞에는 GVC 수정일 08/04/04라는 별도 주석이 있다.
- 254–265·275–287: 다층 비식생 TMPY는 V(L,KBV)를 쓴다. 다층 식생 TMPY는 V(L,1)을 쓰지만 같은 식생 분기의 속력 제곱합에는 V(L,KBV)를 쓴다.
- 93–109·112–132: GVCSCL*·BI1·BI2·BE 기반 압력 경사 구현은 주석이다. 실행 압력 경사 구현은 KGVCU·KGVCV와 BI1GVC·BI2GVC·BEGVC를 사용한다.
- 639–643: RAVAIL과 RIFTRL의 MIN을 RIFTR로 환산한다. 해당 블록에는 RAVAIL 또는 RIFTRL을 0 이상으로 제한하는 문장이 없다.
- 770–790·845–855: CC 최솟값 역수와 CC 곱 제곱근을 계산한다. 이 계산 블록에는 CC가 0 또는 음수인지 검사하는 조건이 없다.
- 1002–1014: HU·HV 계산은 GVCSCLU·GVCSCLV를 분모에 사용한다. 이어서 HP·HU·HV의 역수를 계산한다. 이 블록에는 해당 스케일 또는 수심 0 여부를 검사하는 조건이 없다.
- 21–23·1192–1221·1302: 목적 주석과 FORMAT들은 젖음·마름을 언급한다. 이 파일의 실행문에는 ISCDRY 대입이나 마름 보정 재진입 GOTO가 없다. ISDRY는 마지막 체적 수지 분기에 사용한다.
- 936·907–933·1159–1163: 1002 FORMAT은 선언되어 있다. 이 파일의 실행 WRITE 문장은 해당 FORMAT을 참조하지 않는다.
- 1231–1232·1245–1251·1265–1271·1278–1281: LMAX·LMIN의 이 루틴 내 대입은 DIVEX 최댓값·최솟값 갱신 분기에만 있다. 해당 분기가 실행되지 않아도 뒤 좌표 변환은 LMAX·LMIN을 참조한다.
- 1304–1311: VETZERD의 EVAPSW(L) 참조는 L 루프 종료 뒤에 있다. VOLADD의 누적과 달리 해당 EVAPSW 항에는 별도 합산이 없다.
