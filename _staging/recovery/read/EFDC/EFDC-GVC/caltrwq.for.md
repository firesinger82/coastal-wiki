## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 6·19–22: 선언된 루틴 이름은 CALTRWQ이다. 기능 설명 주석의 루틴 이름은 CALTRAN이다.
- 38·40–67: BSMALL은 1.0E-6으로 고정되어 있다. DELTD2·S3TL·S2TL·ISUD는 이 파일에서 설정되지만 실행 계산식에서 참조되지 않는다. INCLUDE 파일 내부의 사용 여부는 확인하지 않았다.
- 69–80·811–814: 초기화 루프에서 FUHV의 0 대입이 두 번 있다. 같은 초기화 루프에는 FVHV의 0 대입이 없다. FVHV 계산 대입은 813행에 있다.
- 118·173: ISPLIT에 따른 이동과 CALDIFF 호출은 주석 처리되어 있다. 이 파일의 실행 CALL은 99–100행 CALFQC이다.
- 214·339·663–686·843–871: 농도 경계 계산에는 M=4용 목록과 M=8용 수질 목록이 따로 있다. 반확산 플럭스와 DU/DV의 경계 0 설정은 NCBS/NCBW/NCBE/NCBN 목록을 사용한다.
- 228·256·284·313·353·382·411·441: 경계 유출 농도의 상한을 지정하는 IF 문은 모두 주석 처리되어 있다.
- 713–716: 양 끝 층의 최댓값·최솟값 계산은 층 2와 KS를 직접 참조한다. 이 계산을 감싸는 KC 조건은 이 파일에 없다.
- 740–743: 수평 최솟값 계산은 차단된 이웃에 1.E+6 항을 더한다.
- 942–945: 베타 계수 계산은 DU/DV가 양수일 때만 비율로 바꾼다. 이후 MIN(...,1.)을 적용하며 별도 MAX(...,0.) 대입은 없다.
- 998–1009: 진단 조건은 ISFCT(M)=99이다. 출력 조건은 CCMAX>0과 CCMIN>0이며 별도 허용오차 상수는 사용하지 않는다.
