## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 32–47·82–84: DELTI의 분모는 DELT이고 시계열 가중치의 분모는 TDIFF이다. NDAYA 계산은 NTSPTC를 사용한다. 이 파일에는 DELT·TDIFF·NTSPTC의 0 여부를 검사하는 조건이 없다.
- 72–80: 시각 탐색은 M1을 늘려 GOTO 100으로 반복한다. 이 탐색에는 시계열 마지막 표본 번호와 M2를 비교하는 문장이 없다.
- 170–177: 회전 작업 배열 두 개는 각각 해당 관측 성분이 유효할 때만 설정한다. 각 유효 성분의 회전식은 두 작업 배열을 모두 참조한다.
