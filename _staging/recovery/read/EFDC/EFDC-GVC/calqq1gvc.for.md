## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 40·712: BSMALL은 실행문에서 1.E-12로 설정된다. 이 파일에서 BSMALL을 참조하는 조건은 주석 처리된 712행에만 있다.
- 65: FVHV의 0 초기화에는 `DSI bug fix`라는 주석이 있다. 같은 초기화 루프에서 네 수평 플럭스 배열을 모두 0 설정한다(62–65).
- 304–411·415–484: ISWAVE≤1 계산은 LGVCP를 검사하고 GVCSCLP를 곱한다. ISWAVE≥2 생성·수송 블록에는 LGVCP 검사가 없고 해당 UUU/VVV 식에는 GVCSCLP 인자가 없다.
- 314·367·444·475·637·661: ISWAVE≤1의 VVV 초기 항은 H1P 또는 H2P를 두 번 곱한다. ISWAVE≥2의 VVV 초기 항은 H1P 또는 H2P를 한 번 곱한다. 이후 QQL 복원은 두 ISTOPT 분기 모두 HPI를 두 번 곱한다.
- 324–329·377–382: 수송 직후 UUU/VVV를 0 이상으로 제한하는 루프는 두 시간 분기 모두 주석 처리되어 있다. QQ와 QQL 하한 적용은 이후 실행문에 있다(615·638·662).
- 488–528·607: KC≤2 별도 해법과 KC>2 바깥 조건은 주석 처리되어 있다. 532–605행 해법은 해당 KC 조건 없이 실행된다.
- 573–585·589–590: QQ 분모 검사가 실패하면 CLQTMP를 0으로 바꾼다. 다음 QQL 분모 검사는 바뀐 CLQTMP를 사용한다. QQL 분모 검사도 실패하면 CLQTMP를 0으로 바꾸며 두 우변 갱신은 검사 뒤의 같은 CLQTMP를 사용한다.
- 549–550·573–581: K=1의 EQ/EQL 역수에는 1.E-8 분모 검사가 없다. K=2..KS의 두 역수에는 해당 검사가 있다.
- 632–668: QQL과 DML 갱신은 ISTOPT(0)=1 및 ISTOPT(0)=2라는 두 독립 IF 안에 있다. 다른 ISTOPT 값에 대응하는 ELSE는 이 블록에 없다.
- 28·513–524·626·794–799: 진단 배열 선언과 진단 출력 블록은 주석 처리되어 있다. FORMAT 881·110·111·600·601 선언은 실행문으로 남아 있으며 이 파일의 실행 WRITE 문은 없다.
