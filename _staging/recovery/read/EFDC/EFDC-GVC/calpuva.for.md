## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 89·99–109: CALEBI 호출과 부력 압력 경사 계산 루프에는 BSC 조건이 없다.
- 130–160: ISTL=2 분기와 ELSE 분기의 FUHDYE·FVHDXE 식은 같은 코드이다.
- 510–514: RAVAIL과 RIFTRL의 MIN을 RIFTR로 환산한다. 해당 블록에는 RAVAIL 또는 RIFTRL을 0 이상으로 제한하는 문장이 없다.
- 672·711–719: CCMNMI는 계산하지만 이 파일의 실행식에서는 이후 참조하지 않는다. CCMNMI를 사용하는 최솟값 대각 스케일 대입은 주석이다.
- 724–738: 정상형 설정은 방향 계수와 FPTMP를 제곱근으로 나눈다. CONGRAD 호출 뒤에는 P를 SQRT(CC)로 나눈다. 호출 전에 P를 SQRT(CC)로 곱하는 문장은 이 파일에 없다.
- 790–822: FILT3TL 유량 필터는 ISTL=2의 ELSE 안에 있다. 해당 ELSE에는 ISTL=3을 별도로 검사하는 조건이 없다.
- 834–838·844–848: ISTL=3의 HPPTMP 유량 항 시간 계수에는 0.5가 있다. 같은 분기의 침투·증발 차감 시간 계수에는 0.5가 없다. ELSE의 유량 항과 침투·증발 차감 시간 계수에도 0.5가 없다.
- 834–836·1079–1082: ISTL=3 수심 갱신은 H1P를 기준으로 한다. ISTL=3 발산 식은 HP와 H2P의 차이를 쓰며 유량은 UHDY1E·VHDX1E를 사용한다.
- 869–873·934–989: 수심 역수 계산은 음의 수심 진단 앞에 있다. 역수 계산 블록에는 수심 0 여부를 검사하는 조건이 없다.
