## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 111–124: 출력 설명은 DTWQ를 DT와 IWQDT의 곱으로 표기한다. 실행식은 ITIMSOL=0에서 2, ITIMSOL=1에서 1을 사용한다. IWQDT 재설정 메시지 분기에는 IWQDT 대입문이 없다.
- 173–198: IWQKA(1)의 0..4와 IWQVLIM의 0..2 선택은 독립 IF로 로그를 출력한다. 이 블록에는 그 밖의 값을 중단하는 분기가 없다.
- 366–374: KHNG 입력은 WQKHNG에 읽는다. '(KHNG, KHPG)' 출력은 WQKHND와 WQKHPG를 사용한다(373).
- 411–414: 입력 READ에는 SIceAdj가 있다. 대응 WRITE에는 SIceAdj가 없다.
- 579–580: ISSKIP=0일 때 같은 FORMAT 999 READ를 연속 두 번 실행한다.
- 807·810–813: 온도 참조표 주석은 −15..40°C를 적는다. 실행식은 WTEMP=0.25*REAL(M)-30.25이며 M=1..NWQTD이다.
- 879–880: WQTDGP 상한 분기는 WTEMP>WQTMD2를 검사한다. 해당 계산식은 WQTMP2를 사용한다.
- 1224–1225·1248–1249: 영역 시작 인덱스 LF는 LDMWQ를 사용한다. 끝 인덱스 LL은 LDM을 사용한다.
- 1199–1211·1233–1255: 상수 초기조건에서 WQTAMP(1,1) 대입은 IWQSRP=1 분기에만 있다. 해당 분기 밖에서는 WQTAMP(1,1)를 XWQTAMP로 복사하고 다른 셀에 복사한다.
- 1270–1325: MACALGMP.INP 판독은 IWQICI와 별개로 IDNOTRVA>0일 때 실행된다. 해당 블록은 지도 셀 바닥층 WQV와 WQVO를 상수 대형조류 초기값으로 설정한다.
- 1418–1421: READ는 STEMFAC를 입력한다. 대응 WRITE는 STEMFAC를 포함하지 않는다.
- 1514–1520: 부하 변환은 1..18·19·20·NWQV를 고정 인덱스 그룹으로 처리한다. FORMAT 969/970은 21개 정수를 지정한다(1718–1719).
- 1553–1559·1571: WQWDSL(1,1,NW)는 CONV1 또는 유량*CONV2로 환산한다. 실제 셀 L=2..LA의 표면층 WQWDSL은 모든 NW에 대해 XDSL(NW)*DXYP(L)를 사용한다.
- 426–434·1668–1671: IWQSUN=2에서는 셀별 일사 과거값을 초기화한다. SUNFN 검사의 참 분기는 IWQSUN=1만 포함하며 IWQSUN=2는 NONE 검사 분기로 들어간다.
- 813·1773–1777: 첫 온도 표의 WTEMP 간격은 0.25이고 두 번째 표의 간격은 0.1이다. 두 번째 표는 WQKCOD와 WQTDKR를 같은 M 인덱스에 다시 대입한다.
- 1752–1761: KINETICS.INP에서 IZ를 읽어 배열 인덱스로 사용한다. 이 블록에는 IZ 범위·중복 검사가 없다.
- 1808–1822·1864–1880: 지도 파일은 입력 행 수와 IJCT를 검사한다. 해당 블록에는 K/IWQZX/IZMUD/IZSAND 범위·중복 셀·XMUD의 0..100 범위를 검사하는 조건이 없다.
