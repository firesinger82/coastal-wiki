## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 199–201·222–225·247–251: means_init의 지역 integer 분기에서도 크기를 t%i2/i3/i4 대신 t%r2/r3/r4에서 읽는다. 같은 루틴의 전역 integer 분기(106–107·135–137·166–169)는 integer 배열에서 읽는다.
- 414–415: rank 4 임시 oldmean4d/tvar4d의 첫 세 차원은 t%r3의 크기, 네 번째 차원만 t%r4의 크기로 할당한다.
- 299·307·338–347·441–477: sine/cosine 배열과 initialisedtvarsin은 makeaverage의 save 변수이고, clearaverage에는 이 변수들을 초기화하는 문장이 없다.
- 337–363·364–388: thetamean 평균은 atan2로 계산하지만 뒤의 별도 분산 분기는 zswet만 구분하므로 thetamean은 일반 분산 else로 들어간다.
- 97–105·125–134·155–165: MPI에서 global rank 3/4 원본 배열은 0으로 대입한다. rank 2의 원본 0 대입은 주석 처리되어 있다.
- 348–350: sine/cosine가 모두 numeps보다 작을 때 cosine 설정식은 numeps*sign(tvar2d_cos,1.d0)이다. sign 함수의 두 번째 인자는 상수 1.d0이다.
- 546–564: means_collect는 rank 2에서만 제곱항을 추가 수집하고 rank 3/4에서는 mean/variance/max/min만 수집한다. 교차항 수집 호출은 없다.
- 272·501–503·530: sl 미사용 경고를 피하려는 주석과 함께 sl%nx=-1 조건 return 및 항상 false인 print 블록을 둔다.
