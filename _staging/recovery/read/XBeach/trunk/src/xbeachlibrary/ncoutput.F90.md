## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 214–217·251: ncoutput_init에서 dofortran/donetcdf를 계산하지만 두 플래그를 사용하는 분기는 없고 nf90_create를 호출한다. getkey의 반환 rc(356)도 이 파일에서 검사하지 않는다.
- 233–234·239·418–425·517–523: globalvarids는 -1로 초기화하지만 pointsvarids는 할당 후 일괄 초기화가 없다. 초기화의 유형 default 분기는 오류를 출력한 뒤 select 밖의 변수 속성 기록으로 진행한다.
- 500·503·507·510: rank 3 관측점 dimids(3)은 pointtimedimid인데 bedlayersdimid와 비교한다. rank 4의 추가 공간 차원은 dimids(2/3)에 배치하지만 bed_layers 검사 대상은 dimids(3/4)다.
- 552·662–671: drifter 변수의 coordinates는 pointx pointy로 설정하지만 그 좌표 변수의 정의·기록은 outputp 조건(446·662) 아래 있다. drifter 조건(531)은 outputp와 독립이다.
- 666·669: 초기화에서 같은 pointtypes 배열을 같은 pointtypesvarid에 두 번 기록한다.
- 1060–1068·1075–1083·1090–1098: MPI 관측점 처리에서 소유 프로세스가 먼저 임시 r2/r3/r4에 값을 만들고 전송·해제한다. pointoutputs의 각 배열을 할당·수신하는 문장은 뒤의 elseif(xomaster) 분기에 있다. 두 조건이 동시에 참인 경우의 수신 저장은 이 블록에 별도로 보이지 않는다.
- 1091·1095·1100: rank 4 관측점의 MPI 경로는 세 번째 크기를 size(t%r4,3)으로 쓰지만 직렬 경로는 size(t%r3,3)으로 쓴다. rank 2/3의 gridrotate 호출(1062·1077)은 par/sl을 전달하지만 rank 4 호출(1092·1101)은 전달하지 않는다.
- 1216·1231: 전역 실수 rank 1에서 임시 r1은 할당·해제만 하고 그 사이 값 계산이나 출력에 사용하지 않는다.
- 1083·1098·1354·1359·1368–1376: rank 3/4 관측점 NetCDF 출력은 pointoutputs의 첫 추가 차원 값만 전달한다. Fortran 호환 출력은 pointoutputs 대신 로컬 allocatable r3/r4를 참조한다. 앞 MPI 수집에서는 해당 임시 배열을 해제하고, 직렬 수집에서는 pointoutputs 배열을 할당한다. 실행 결과는 이 판독에서 확인하지 않았다.
- 1316·1388–1400: dofortran_compat가 거짓이어도 points(0,0)을 할당하지만 명시적인 points 해제는 dofortran_compat가 참인 블록 안에만 있다. 이는 명시 해제문의 위치에 관한 사실이며 루틴 종료 때의 자동 해제 여부를 부정하는 판단은 아니다.
- 1403–1405: runup 파일 write의 unit 인덱스는 ii+par%npoints, 바로 뒤 flush의 unit 인덱스는 i+par%npoints다.
- 1139·1305·1415·967–970·1390–1394·1559·1612: NetCDF 전역·관측점·평균 시간은 morfacopt 검사 없이 par%t*max(par%morfac,1.d0), runup/Fortran 일반점 및 dims.dat 시간 확대는 morfacopt==1 조건 아래, drifter 시간은 par%t다.
- 1675–1678·269: dimensionid는 s%ntdisch와 문자열 '2'를 같은 inoutdimid에 매핑하며 inout 차원 정의 길이는 2다.
- 2052·2054·2127·2147·2167: hotstartfiles_write의 xomaster 조건은 zs/zb/uu/vv 블록에서 중첩 반복된다. 세 lowlevel hotstart writer는 open의 iostat를 ierr에 받지만 해당 루틴 안에서 이를 검사하지 않는다. 파일명 번호 폭 I6.6, 실수 E15.8·정수 I4 형식도 코드에 고정되어 있다.
