## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 82–85·188–191: vector/block-vector 분배는 root=0만 허용하며 오류 시 전달받은 comm 대신 MPI_COMM_WORLD에 Abort를 호출한다.
- 122–133·228–239: 두 vector 루틴은 root에서 i=1..sz 전체에 전송 타입을 만들며 root 자신의 수신도 설정한다. matrix_distr의 주석은 root 자신에게 전송하지 않는다고 설명한다(263·275–276); 실제 include 내부는 확인하지 않았다.
