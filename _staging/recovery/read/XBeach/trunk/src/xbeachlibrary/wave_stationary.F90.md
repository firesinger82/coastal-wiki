## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 123: Snell 식의 asin 인자에 max/min으로 −1..1 제한하는 실행식이 없다.
- 66–72: scheme_local_yadvec는 최초 xadvec 할당 조건에서만 결정된다. 이후 호출에서는 기존 저장 값을 사용한다(179–180·255–256).
- 225–229: Df는 현재 i열에서 계산하지만 fwcutoff 조건과 0 대입은 전체 배열 `where (s%hh>par%fwcutoff)` 및 `s%Df = 0.d0`이다.
- 185–195·260–277: ee와 rr 이류 갱신 후 소산 한계에 따라 dtw를 줄이고 MPI 최소값을 다시 모은다. 이후 ee/rr 소산(282–288)은 줄인 dtw를 사용한다.
- 431·436·439: 파랑·롤러 질량 플럭스 분모는 `max(s%hh,.001d0)`이며, s%ust에는 s%ustr 대신 s%usd를 더한다. 이 파일에서는 s%usd의 계산·대입이나 breakerdelay 호출이 없다(11의 import만 존재).
- 74–92·225·333–336·367–377·428: uorb는 매 호출 0 초기화 후 x열 반복의 소산 전 H로 계산된다. 반복 후 H 갱신이나 마지막 x열 복사에 uorb 재계산·복사가 없으며 끝에서 urms=uorb/sqrt(2.d0)를 사용한다.
- 215–222: break select에는 Roelvink1/2, Baldock, Janssen만 있고 Daly case와 case default는 없다.
