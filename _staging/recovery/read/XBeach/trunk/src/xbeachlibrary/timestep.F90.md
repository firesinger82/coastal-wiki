## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 105–116·148–157·377·394: timepars의 ith/outputh에는 선언 초기값이 없고 timestep_init도 해당 두 항목을 초기화하지 않는다. outputtimes_update의 hotstart 판정·증가에 이 항목을 사용한다.
- 134–141: timestep_init의 tocomp 상수는 선언 이후 이 루틴 본문에서 참조되지 않는다.
- 552–553·581–583: bed celerity와 1D Dc 제한은 par%dt를 줄일 수 있지만 바로 뒤에 별도 ilim/jlim/limtype/dtold 갱신문이 없다. 다른 유속·점성 제한에는 갱신 조건이 있다.
- 588–592: s%ny>0 조건의 then/else가 동일한 par%dt=par%dt*par%CFL*0.5d0이다.
- 566–574: mdx는 격자 길이의 제곱이며, par%dy>0이면 mdy=par%dy를 그대로 사용하고 else이면 mdy=mdx를 사용한다.
- 633–647: 방향 전파 dt 제한의 MPI 경로는 ntheta>1 조건, non-MPI 경로는 stationary 이외의 wavemodel case 조건을 사용한다.
- 435·493–529·588–646·673–682: limtype은 local dt 감소 시 기록되며, 이후 CFL·파향·시각 정렬·MPI 최소화·선택 dt 제한에는 모두 별도 limtype 갱신문이 있는 것은 아니다.
- 706·710: timestep의 save dtref 선언에는 초기값이 없다. compute_dt의 초기 시각 hotstart=0/1 분기에서 dtref=0으로 설정한다(466·476).
