# curvilinear grid properties 1–19쪽 — 판독 기록

이 PDF는 PowerPoint(.pptx)를 LibreOffice로 변환한 이미지형 문서이며, 모든 쪽에 인쇄된 쪽 번호가 없다. 그림 번호·캡션도 없다. 아래 "원문 문구"는 각 쪽에 보이는 제목 또는 문장이다.

| 쪽 | 내용 |
|---|---|
| p.1 | 제목 없음, 인쇄 쪽 번호 없음. 곡선 격자 도식. 실선 곡선 2계열(격자선)과 점선 곡선 2계열(보조 격자선)이 교차하며, 한 셀 근처에 네 기호가 표시됨: `z+`(더하기 기호, 수위 z 점), `u—`(가로 막대 기호, u 점), `v\|`(세로 사선 막대 기호, v 점), `co`(원 기호, c 점). 즉 z·u·v·c 점의 엇갈린(staggered) 배치를 보여 주는 도식. 원문 문구: `z`, `u`, `v`, `c` (기호 옆 글자). 수식·표 없음. |
| p.2 | 제목 `dsu(i,j)`. p.1과 같은 격자 도식. z 점 `+` 아래에 `i,j` 표기. 붉은 굵은 선이 z(i,j) 점에서 시작해 u 점을 지나 오른쪽 이웃 z 점 방향 격자선(점선 계열 선) 위를 따라 가는 구간을 표시. dsu = u 점을 중심으로 z(i,j)와 z(i+1,j) 사이의 격자선을 따른 길이(도식 판독). 원문 문구: `dsu(i,j)`. |
| p.3 | 제목 `dsz(i,j)`. 같은 도식. 붉은 선이 z(i,j) 점을 중심으로 좌우 u 점 두 개 사이의 격자선(실선 격자선 사이의 점선 곡선 위) 구간. dsz = z 점 중심, 양쪽 u 점 사이의 s 방향 길이(도식 판독). 원문 문구: `dsz(i,j)`. |
| p.4 | 제목 `dsv(i,j)`. 같은 도식. 붉은 선이 v 점(`\|`)을 중심으로 좌측 실선 격자선 교점에서 c 점(`o`) 위쪽 부근까지 이어지는 상단 실선 위 구간. dsv = v 점 중심 s 방향 길이(도식 판독). 원문 문구: `dsv(i,j)`. |
| p.5 | 제목 `dsc(i,j)`. 같은 도식. 붉은 선이 c 점(`o`)을 중심으로 좌우 v 점 사이의 상단 실선 위 구간. dsc = c 점 중심 s 방향 길이(도식 판독). 원문 문구: `dsc(i,j)`. |
| p.6 | 제목 `dnu(i,j)`. 같은 도식. 붉은 선이 u 점(`—`)을 지나는 세로 방향 격자선(실선 계열)에서 c 점 높이의 교점부터 아래쪽 교점까지 구간. dnu = u 점 중심 n 방향 길이(도식 판독). 원문 문구: `dnu(i,j)`. |
| p.7 | 제목 `dnz(i,j)`. 같은 도식. 붉은 선이 z 점 `+`를 지나는 세로 방향 점선 격자선 위에서 v 점 높이 위쪽 끝부터 아래 교점까지 구간. dnz = z 점 중심 n 방향 길이(도식 판독). 원문 문구: `dnz(i,j)`. |
| p.8 | 제목 `dnv(i,j)`. 같은 도식. 붉은 선이 z(i,j) 점에서 위쪽으로 점선 격자선을 따라 v 점을 지나 다음 위쪽 가로 점선 교점까지 구간. dnv = v 점 기준 n 방향 길이로, z(i,j)와 z(i,j+1) 사이 거리(도식 판독; p.17 식 `dnv_{i,j}`가 z(i,j+1)−z(i,j) 차이에 쓰임과 일치). 원문 문구: `dnv(i,j)`. |
| p.9 | 제목 `dnc(i,j)`. 같은 도식. 붉은 선이 c 점(`o`)을 중심으로 위쪽 약간 위부터 u 점 위치까지 세로 실선 위 구간. dnc = c 점 중심 n 방향 길이(도식 판독). 원문 문구: `dnc(i,j)`. |
| p.10 | 제목 `dsdnu(i,j)`. 같은 도식. 붉은 색칠 사변형이 u 점(`—`)을 중심으로 한 셀(위쪽 실선, 아래쪽 실선, 좌우는 점선 곡선 경계)을 채움. dsdnu = u 점 셀 면적(도식 판독). 원문 문구: `dsdnu(i,j)`. |
| p.11 | 제목 `Momentum balance in u direction`. 글머리 문장 `Only consider advection of velocity component in the local grid direction`. 식 2줄(식 번호 없음).<br>식 1: $\frac{d(Vu)}{dt} - \sum Q_{in}u_{in} + \sum Q_{out}u + Vg\frac{\partial \eta}{\partial s} + A\frac{\tau_{b,s}}{\rho} = 0 \Rightarrow$<br>식 2: $u\frac{dV}{dt} + V\frac{du}{dt} - \sum Q_{in}u_{in} + \sum Q_{out}u + Vg\frac{\partial \eta}{\partial s} + A\frac{\tau_{b,s}}{\rho} = 0$<br>기호 정의는 이 쪽에 없음(V, Q_in, Q_out, u_in, A, τ_{b,s}, ρ). |
| p.12 | 제목 `Continuity equation`. 식 2줄과 글머리 `Multiply continuity equation with u`(식 사이).<br>식 1: $\frac{dV}{dt} - \sum Q_{in} + \sum Q_{out} = 0$<br>글머리: `Multiply continuity equation with u`<br>식 2: $u\frac{dV}{dt} - \sum Q_{in}u + \sum Q_{out}u = 0$<br>식 번호 없음. 기호 정의 없음. |
| p.13 | 제목 없음. 글머리 `Subtract continuity eq. times u from momentum equation and divide by V`(V는 이탤릭). 식 3줄(식 번호 없음).<br>식 1: $V\frac{du}{dt} + \sum Q_{in}(u - u_{in}) + Vg\frac{\partial \eta}{\partial s} + A\frac{\tau_{b,s}}{\rho} = 0$<br>식 2: $\frac{du}{dt} + \frac{\sum Q_{in}(u - u_{in})}{V} + g\frac{\partial \eta}{\partial s} + \frac{A\tau_{b,s}}{\rho V} = 0$<br>식 3: $\frac{du}{dt} + \frac{\sum Q_{in}(u - u_{in})}{A h_{um}} + g\frac{\partial \eta}{\partial s} + \frac{\tau_{b,s}}{\rho h_{um}} = 0$<br>h_um은 이 쪽에서 정의되지 않음(식 3에서 V를 A h_um으로 치환한 것으로 보임). 식 2의 마지막 항은 분자 `Aτ_{b,s}`의 글자가 겹쳐 보임. |
| p.14 | 제목 `Procedure`. 글머리: `Go around the cell centered at u-point` / `Compute q across cell boundary by averaging qx resp. qy` / `If q is inward` (하위 항목) `Compute Q_in by multiplying with dnz resp dsc` / `Compute u_in as` / `Add Q_in (u_in –u) to advection`(쪽 아래에서 잘림). `Compute u_in as` 위치에 식 2줄이 겹쳐 인쇄됨(윗줄은 앞 하위 항목 문장과 겹침):<br>줄 1: $u_{in} = u\cos\Delta\alpha + v_u\sin\Delta\alpha$ (판독: 문장과 겹쳐 일부 불명확, `v_u` 아래첨자 u로 읽힘)<br>줄 2: $u_{in} = u_v\cos\Delta\alpha + v\sin\Delta\alpha$<br>식 번호 없음. Δα 정의 없음. `u_v`, `v_u` 정의 없음. 이 쪽은 텍스트와 식이 겹쳐 있고 하단 글머리가 잘림. |
| p.15 | 제목 `dsdnz(i,j)`. 같은 도식. 붉은 색칠 사변형이 z 점 `+`를 중심으로 한 셀. dsdnz = z 점 셀 면적(도식 판독). 원문 문구: `dsdnz(i,j)`. |
| p.16 | 제목 `dsdnv(i,j)`. 같은 도식. 붉은 색칠 사변형이 v 점(`\|`)을 중심으로 한 셀. dsdnv = v 점 셀 면적(도식 판독). 원문 문구: `dsdnv(i,j)`. |
| p.17 | 제목 `Water level slopes in u, v points`. 식 2줄(식 번호 없음).<br>식 1: $\frac{\partial \eta}{\partial s}(i,j) = \frac{\eta_{i+1,j} - \eta_{i,j}}{dsu_{i,j}}$<br>식 2: $\frac{\partial \eta}{\partial n}(i,j) = \frac{\eta_{i,j+1} - \eta_{i,j}}{dnv_{i,j}}$<br>η는 수위. 단위 표기 없음. |
| p.18 | 제목 `Continuity`. 식 1개(식 번호 없음, 두 줄에 걸쳐 인쇄):<br>$\frac{\eta^{n+1}_{i,j} - \eta^{n}_{i,j}}{\Delta t} = -\frac{\left(u^{n+1}_{i,j}h^{n}_{i,j}dnu_{i,j} - u^{n+1}_{i-1,j}h^{n}_{i-1,j}dnu_{i-1,j}\right) - \left(v^{n+1}_{i,j}h_{i,j}dsv_{i,j} - v^{n+1}_{i,j-1}h^{n}_{i,j-1}dsv_{i,j-1}\right)}{dsdnz_{i,j}}$<br>v 항의 `h_{i,j}`는 위 첨자 n 없이 인쇄됨(원문 그대로). 좌변 오른쪽 `=` 뒤 분수 앞에 `-` 부호가 다음 줄 앞에 인쇄됨. |
| p.19 | 제목 `Wave propagation`. 식 6줄(식 번호 없음).<br>$Cgxu_{i,j} = \frac{1}{2}(Cgx_{i,j} + Cgx_{i+1,j})$<br>$Eu_{i,j} = E_{i,j} + \frac{1}{2}dsu_{i,j}\frac{E_{i,j} - E_{i-1,j}}{dsu_{i-1,j}} =$<br>$= \left(\left(dsu_{i-1,j} + \frac{1}{2}dsu_{i,j}\right)E_{i,j} - \frac{1}{2}dsu_{i,j}E_{i-1,j}\right)/dsu_{i-1,j}\quad , Cgxu_{i,j} > 0$<br>$Eu_{i,j} = E_{i+1,j} - \frac{1}{2}dsu_{i,j}\frac{E_{i+2,j} - E_{i+1,j}}{dsu_{i+1,j}} =$<br>$= \left(\left(dsu_{i+1,j} + \frac{1}{2}dsu_{i,j}\right)E_{i+1,j} - \frac{1}{2}dsu_{i,j}E_{i+2,j}\right)/dsu_{i+1,j}\quad , Cgxu_{i,j} < 0$<br>$Fluxx_{i,j} = Cgxu_{i,j}Eu_{i,j}dnu_{i,j}$<br>조건: 두 번째~세 번째 줄은 `Cgxu_{i,j} > 0`, 네 번째~다섯 번째 줄은 `Cgxu_{i,j} < 0`. 기호 정의(Cgx, Cgxu, E, Eu, Fluxx)는 쪽에 없음. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 문서 전체: 인쇄된 쪽 번호·식 번호·그림 번호가 없다(전 쪽).
- p.1–10, 15–16: 기하량(dsu, dsz, dsv, dsc, dnu, dnz, dnv, dnc, dsdnu, dsdnz, dsdnv)은 제목과 붉은 강조 선·면만 있고 정의식·설명 문장이 없다. 위 "도식 판독" 서술은 그림에서 읽은 것이며 원문에 문장으로 정의되지 않았다. p.1 도식의 점 `c`는 격자 모서리(corner) 점으로 읽히나 원문에 설명 없음. 판독자가 격자선의 어느 쪽 교점까지 선이 닿는지는 그림 해상도상 근사 판독.
- p.4–5, 8–9: 붉은 선이 가리키는 정확한 끝점이 도식상 모호함(dsv, dsc, dnv, dnc).
- p.11–13: 기호 V, A, Q_in, Q_out, u_in, τ_{b,s}, ρ가 정의되지 않았다. p.13 식 3의 h_um은 정의되지 않았다. p.11 식 1과 2의 앞 두 합 `-ΣQ_in u_in + ΣQ_out u`의 부호 배치는 인쇄 그대로이며 p.12 연속식과 같은 형태.
- p.11 식 1 끝의 `⇒` 뒤에 식 2가 이어짐.
- p.13 식 2의 `Aτ_{b,s}` 글자가 겹쳐 있음(식 2 마지막 항 분자).
- p.14: 식 2줄이 글머리 문장과 겹쳐 인쇄되어 윗줄 판독이 불확실(특히 `v_u`). 쪽 하단의 `Add Q_in (u_in –u) to advection` 줄이 잘려 끝 단어 뒤가 보이지 않을 수 있음(`advection` 뒤 더 이어지는지 불명). Δα, u_v, v_u 미정의. 윗줄 `u_in = u cosΔα + v_u sinΔα`와 아랫줄 `u_in = u_v cosΔα + v sinΔα`는 서로 다른 점(u 점 셀 vs v 점 셀)에 대한 식일 수 있으나 원문에 조건 표기 없음.
- p.13 식 3의 합 `Σ Q_in (u − u_in)`과 p.14 `Add Q_in (u_in –u) to advection`은 (u − u_in)와 (u_in − u)로 부호 순서가 다르게 인쇄됨.
- p.18: v 항의 `h_{i,j}`에 위 첨자 n이 없고, 나머지 h에는 `n`이 있음(인쇄 그대로). 좌변은 `−`가 분수 앞 별도 줄에 있음.
- p.17: 수위 기울기 식의 분모 dsu_{i,j}, dnv_{i,j}는 p.2, p.8 제목 기하량과 같은 이름.
- p.19: 두 번째 줄(`Eu_{i,j} = E_{i,j} + ...`)과 네 번째 줄(`Eu_{i,j} = E_{i+1,j} - ...`)의 분모는 `dsu_{i-1,j}`, `dsu_{i+1,j}`로 인쇄됨. 전개 후 식과 일관됨.
- p.19: 한 쪽이 Cgxu>0(상류 i측), 한 쪽이 Cgxu<0(상류 i+1측)로 구분됨. Cgxu = 0일 때의 처리는 쪽에 없음.
