## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 31·34·40: 생성 명령은 `xbi`에 저장하지만 설명은 `xbo`가 전체 모델 구조체를 담는다고 적고, 저장 명령은 다시 `xbi`를 사용한다.
- 218: 원격 실행 예제 첫 줄 끝에서 세 점 다음에 백틱 두 개가 붙어 있다. 원문: ``` xbr = xb_run_remote( ...`` ``` (218).
- 255–256·275–276·280: 구조체 변환 설명과 앞 예제의 이름은 `xs_peel`, 차원 변환 줄은 `xb_peel`이다.
- 267–282: 앞 코드에서 선택한 출력은 구조체로 설명되지만 마지막 plot은 `xbp(end,1,:)`를 직접 인덱싱한다. 이 코드 구간에는 xbp를 수치 배열로 다시 대입하는 줄이 없다.
