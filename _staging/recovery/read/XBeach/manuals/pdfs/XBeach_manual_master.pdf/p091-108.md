| p.92 | 인쇄 88 of 141. 4.13.1.3 Fixed point output: `npoints` 키워드 뒤에 출력 지점마다 한 줄로 x, y 세계좌표를 준다; XBeach는 출력 위치를 가장 가까운 계산점에 연결한다. 출력 변수 수·선택은 `npointvar` 키워드(모든 지점 및 runup gauge 공통) 뒤에 변수명을 한 줄씩. 예 params.txt: `npoints = 2` / `0. 800.` / `2000. 1600.` / `npointvar = 4` / H / zs / zb / D (첫 지점 x=0.0 외해경계·y=800.0, 둘째 지점 x=2000.0·y=1600.0 측면경계). 4.13.1.4 Runup gauge output: x방향 transect를 스캔하여 이동하는 물가선(waterline)에서의 시계열. `nrugauge` 키워드 뒤에 gauge당 한 줄로 초기 위치 좌표; 가장 가까운 계산점이 아니라 가장 가까운 계산 cross-shore transect에 연결. 마지막 젖은 점 판정의 최소 수심은 키워드 `rugdepth`. runup gauge는 점 출력과 변수 선택을 공유하되, `npointvar`에 없으면 xw, yw, zs를 자동 추가한다. 변수 순서는 `pointvars.idx` 출력 파일 확인. 본문: `Fixed point output significantly reduces the amount of data written to file in each time step` (p.92) |
