## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 61: loadable 접근 설명에 `(say $>10$ of small processes`가 나오며 해당 여는 괄호를 닫는 문자가 이 문장에 없다.
- 99·106–113: 재구조화 목록은 init·run·finalize 코드를 `an init subroutine`에 넣는다고 적지만, 뒤 소절은 init·run·finalize 시작 각각 앞에 함수명을 만드는 것으로 설명한다.
- 119–120·156: main 예시에는 `using iso_c_bindings`·`using libxbeach_module`이 적혀 있고, C 호환 설명은 `iso_c_binding`이라고 적는다.
- 88·91·94·109·111–113·133·165–166: 외부 listings 대상은 `../xbeach.F90`, `../libxbeach.F90`, `../Makefile.am`이다. 해당 파일의 내용을 이 문서 자체가 제공하지 않으므로 참조가 실제로 해소되는지는 이 판독에서 확인하지 않았다.
- 132: 저자가 반환 배열 접근의 최선 여부를 확신하지 않는다고 적고 배열 해제 또는 저장 필요성을 언급하지만, 이 문장에는 구체적인 소유권·수명 규칙이 없다.
