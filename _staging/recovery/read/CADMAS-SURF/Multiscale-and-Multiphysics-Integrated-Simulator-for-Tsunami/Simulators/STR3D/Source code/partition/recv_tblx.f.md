## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 143–193: DMT·EPSG·SIGG·IST·SIGY 재할당에서 기존 1:NELM 구간만 복사한다. NELM+1:NELM+NELMC 구간을 채우는 대입문은 이 블록에 없다.
- 308·314–321: IRANK를 재할당하지만 이 구간에는 IRANK 초기화·수신·대입문이 없다.
- 209–294: INDC·IELC·IEDG·IELQ·IFCQ·IEDQ·IVRQ의 기존 배열을 직접 참조·해제한다. 이 구간에는 ASSOCIATED 검사문이 없다.
