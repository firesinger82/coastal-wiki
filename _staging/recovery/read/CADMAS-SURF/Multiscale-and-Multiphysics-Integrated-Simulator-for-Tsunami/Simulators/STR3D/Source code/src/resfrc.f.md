## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 106–108: RRES 계산은 FNRM(1)을 분모로 사용한다. 이 계산 앞에는 FNRM(1)==0 검사가 없다.
- 7–10·69–84: RESMAX·NODMAX·JMAX는 초기화하고 갱신한다. 이 파일에는 이 배열을 출력하거나 반환 인수로 전달하는 문장이 없다.
- 100–108: RNRM은 세 성분을 계산한다. 루트 rank의 ICONV 판정은 RNRM(1)과 FNRM(1)만 사용한다.
