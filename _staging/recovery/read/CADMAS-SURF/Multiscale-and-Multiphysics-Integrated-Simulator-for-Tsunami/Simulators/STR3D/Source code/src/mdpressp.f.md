## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 38–42·68–93·101–103: IFD만 전체 초기화한다. PFD·RFD는 일부 분기에서만 대입하지만 두 배열 전체 NPM개 값을 전송한다.
- 44·48·71·85: 탐색 점의 위치는 PPM(:,I)에서 받는다. 초기 압력식은 GRID(3,I)를 사용한다.
- 68–83: `AREAIN(RL,1.D-2)`가 참이면 IFD(I)=2로 설정한다. 이 조건이 거짓이고 `AREAIN(RL,1.D-1)`이 참이면 `MINVAL(RL) > RL_MIN`일 때만 IFD(I)=1로 설정한다. [11-04 전수 검증 정정]
- 12·17–18·71–72·85–86: G는 9.8D0로 고정한다. 초기 압력식의 첫 수위 항에는 1.D3를 곱하고 두 번째 수위 항에는 곱하지 않는다.
