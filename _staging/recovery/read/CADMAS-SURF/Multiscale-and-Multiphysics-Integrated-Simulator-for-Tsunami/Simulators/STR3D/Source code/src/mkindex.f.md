## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 17·177–181·202–206·256–261·320–324: MSG의 DATA 초기값은 0이다. 각 출력 분기는 MSG==0일 때만 실행하고 MSG를 1로 바꾼다.
- 199–200·203–204: LSYM·LNUMI·LNUMO를 인수로 받는 ASEINDX 호출은 주석이다. 그 뒤 PRNASE 호출에는 이 변수들을 전달한다. 이 파일에는 이 세 변수의 별도 대입문이 없다.

- 153–326: ISOLV 선택에는 CASE DEFAULT가 없다.
- 277·311·313–318: DMUMPS 호출 뒤 INFOG(17)로 메모리를 계산한다. 이 파일에는 MUMPS 오류 상태를 검사하는 별도 조건이 없다.
