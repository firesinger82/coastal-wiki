## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 12–34: NELM/NELMC/NELMX는 NE1/NE2/NE3 계산에 쓰이지만 NE1과 NE2는 이 파일의 후속 문장에서 참조하지 않는다.
- 91–92·132–133·218–224·239–240·255–261: UGP/FTI/RFCI/FRCI/WRK1/INDOF/INDMPC는 이전 값을 보존하지 않고 재할당한다. 해당 재할당 직후의 전체 초기화 문장은 없다.
- 148–202: FCK/FCM/FCMD는 셋째 층을 추가하고 FCD는 넷째 층을 추가한다. 이 구간에는 추가 층을 초기화하는 대입문이 없다.
