## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 30–37·84–91·120–138: NNP 분기는 4·6·8만 처리한다. 이 SELECT CASE들에는 CASE DEFAULT가 없다.
- 221–248: NINDC와 INDC는 전체 접촉면의 고유 노드를 기준으로 만든다. IFIL은 그룹 루프 밖에서 0으로 초기화되므로 여러 그룹에 속한 노드는 최초 그룹에서만 등록된다.
