## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 30–388: CASE는 111부터 133까지의 아홉 조합과 211부터 233까지의 아홉 조합이며, CASE DEFAULT는 없다.
- 26·31–386: 모든 배열은 가정 크기(assumed-size) 일차원 배열로 선언하며, 저장 형식별 첨자를 계산해 접근한다. 이 루틴에는 NI·NJ·NK 사이의 크기 관계나 실제 배열 길이를 검사하는 문장이 없다.
- 33–200: ITYPA=1인 분기는 I=1..NI와 J=I..NJ만 계산한다. 출력 압축 저장의 대칭성을 검사하는 문장은 없다.
