## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 15–29: IDYN=1·0 이외의 값에 대한 ELSE 대입은 없다.
- 17–21: 차분식의 분모는 DT1·DT2·DT1+DT2이다. 이 루틴에는 이 값들의 0 검사문이 없다.
- 141·175: 표면 압력의 파일 출력 조건은 NPFC>0이다. 전송 조건은 ICPL>0이다.
- 36–40·49–139: 벡터 크기는 앞의 세 성분으로 계산한다. UG·RFCO의 성분 출력 보폭은 6이다.
