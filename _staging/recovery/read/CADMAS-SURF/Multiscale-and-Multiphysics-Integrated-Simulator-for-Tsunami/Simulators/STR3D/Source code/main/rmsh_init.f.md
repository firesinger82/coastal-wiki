## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 109–127: L은 CASE(4)에서만 IFB(2,J,I)로 대입하지만 IRMSH(6,I)=L은 SELECT CASE 밖에서 실행한다.
- 123: RZ 계산 앞에 Z(2)=Z(1)을 검사하는 조건은 없다.
- 100–129: J=1:2가 끝난 뒤 저장하는 N·NP·RL은 마지막 J 반복에서 얻은 값이다.
