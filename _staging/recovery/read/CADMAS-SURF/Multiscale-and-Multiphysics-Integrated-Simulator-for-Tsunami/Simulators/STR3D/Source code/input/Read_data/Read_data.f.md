## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 13–19·31–52: N_SUB를 사용하는 NSUB 대입은 주석이다. 활성 코드는 NSUB=1을 사용하며 ISUB(13,NSUB)를 할당한다. I_SUB 증가와 RD_SUBCASE 호출은 SOL 분기 안에 있다.
- 33–49: ISOL 판독, ISOL별 KK(1) 대입, SUBCASE 이름 비교 분기는 모두 주석 처리되어 있다.
- 109·107–108: GRID의 두 번째 크기는 NNOD+N_SHEL이다. INDG·IGCD의 크기는 NNOD이다.
- 715–718·811–815: TABLEM1과 TABLED1·TABLED2 분기는 배열을 달리 전달하면서 같은 RD_TABLEM1을 호출한다.
- 600–854: 카드 이름 분기 체인에는 최종 ELSE가 없다. 일치하지 않은 행의 오류 출력은 이 체인에 없다.
- 854–858: 카드 판독 루프가 끝난 뒤 각 I_* 기록 위치와 N_* 개수를 비교하는 문장은 없다.
