## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 13·105: 접촉 외부 반복 한도 MAXITER2는 20이다.
- 64–65·182–183: 두 CASE(2)의 ASESLV 호출은 주석 처리되어 있다.
- 67–68·185–186: 압력 풀이 PARSLV에는 IPARM 뒤 KK(21),ITER,ITO를 전달한다. 구조 풀이 PARSLV에는 IPARM 뒤 ITER,ITO를 전달한다.
- 234–238: 외부 루프에는 ICONV2=1일 때 EXIT가 있다. MAXITER2까지 수렴하지 않았을 때 별도 오류를 호출하는 문장은 이 구간에 없다.
