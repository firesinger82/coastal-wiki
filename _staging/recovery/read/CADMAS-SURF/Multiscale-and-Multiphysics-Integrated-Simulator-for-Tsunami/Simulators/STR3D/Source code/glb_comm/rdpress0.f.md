## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 14–20: .prs가 존재하면 ICPL=1을 대입한다. 파일이 없을 때 ICPL을 0으로 바꾸는 문장은 없다.
- 56–66: 시간 수 계수 루프의 첫 READ만 END=10을 가진다. 이어지는 NNOD개 절점 READ에는 END= 처리가 없다.
- 119–127·149–158: 표면 선택 조건은 해당 표면 절점 중 적어도 하나가 프로세스 내부 절점이라는 조건이다. 모든 절점이 내부 절점이어야 한다는 검사는 이 루프에 없다.
