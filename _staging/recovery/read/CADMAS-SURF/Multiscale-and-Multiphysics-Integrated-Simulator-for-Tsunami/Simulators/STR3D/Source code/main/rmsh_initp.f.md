## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 118–136: L은 CASE(4)에서만 대입하지만 IRMSH(6,I)=L은 SELECT CASE 밖에서 실행한다.
- 132: RZ 계산 앞에 Z(2)=Z(1)을 검사하는 조건은 없다.
- 95: 오류 메시지는 현재 루틴 이름 RMSH_INITP가 아니라 'STOP IN SUB. RMSH_INIT!'다.
- 110–138: J=1:2가 끝난 뒤 저장하는 N·K·RL은 마지막 J 반복에서 얻은 값이다.
