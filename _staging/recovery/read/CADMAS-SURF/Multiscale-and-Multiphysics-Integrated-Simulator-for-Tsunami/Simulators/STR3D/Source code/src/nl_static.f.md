## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 13·72–84: 외부 반복 상한은 20으로 고정하고 내부 반복 상한은 KK(6)+1로 정한다.
- 129–132·218–220: 내부 반복 상한 도달에는 ERRSTP 호출이 있다. 외부 반복에는 ICONV2==1일 때의 EXIT만 있으며, 외부 반복 상한 도달 뒤 별도 오류 호출은 없다.
- 161–163: CASE(2)의 ASESLV 호출은 주석 처리되어 있다. SELECT CASE에는 CASE DEFAULT가 없다(154–169).
