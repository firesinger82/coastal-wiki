## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 13·49–122: ICHK는 DATA로 0을 받는다. 이 파일에는 ICHK를 바꾸는 실행문이 없으며 49행 이후는 ICHK가 0이면 실행하지 않는다.
- 17–21: ICONV2 비교에는 ISLV(1,I)와 ISLVO(1,I)만 사용한다. 주절점 번호와 프로세스 번호는 이 비교에 없다.
- 34–37·75–79·96–100: 이전 상태 통계의 IOLD는 +1 뒤 5 이상이면 2를 뺀다. 현재 상태 통계의 INEW는 MOD(상태,10)+1이다. 상세 변환 CASE의 이전 상태 집합은 2·4 및 3·5이며 현재 상태 집합은 2·12 및 3·13이다.
