# cad-str-instr 37–54쪽 — 판독 기록

이 기록은 지정된 300 dpi 쪽 이미지를 직접 보고 작성한 한국어 판독 기록이다. 작은 첨자와 수식 기호는 원본 해상도 또는 확대 이미지로 확인했다. 원문 인용의 철자는 지정된 opendataloader 추출본과 대조했다. 표의 쪽 번호는 PDF 쪽 번호다. 인쇄 쪽 번호는 각 행에 따로 적었다. 입력 형식 표는 비어 있지 않은 열의 번호와 내용을 기록했다. `Type`의 `I`, `R`, `A`는 원문 표기를 유지했다. 별도로 적지 않은 기본값·범위·권장값·단위는 해당 쪽에 명시되지 않았다. 수식의 $\square$는 이미지에 보이는 빈 사각형을 옮긴 것이다. 이 사각형이 대신하는 기호는 `[원문 인쇄 판독 불가]`로 기록했다.
