## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 25–26·102–105: IEOF!=0이고 END를 찾지 못하면 오류이다.
- 89–90·131: XBUF 대입은 LEVEL=1이며 NL=LG2+1인 분기에서만 보인다. LEVEL=1의 VF_CGRID 호출에는 항상 XBUF를 전달한다. 수신 루틴 내부는 이 파일에서 확인하지 않았다.
- 28–30·80–84: 주석은 LEVEL>=2에서 건너뛴다고 적지만 좌표 문자열의 실수 변환과 좌표 간격 검사는 LEVEL 조건 밖에서 수행한다.
