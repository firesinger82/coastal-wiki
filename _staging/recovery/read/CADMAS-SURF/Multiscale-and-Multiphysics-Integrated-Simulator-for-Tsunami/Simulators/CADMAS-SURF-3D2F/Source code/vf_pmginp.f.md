## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 27–40·72–103: 파일 열기 오류 시 MGRANK=0의 GOTO 6000은 환경 데이터 전달과 두 검사 블록을 건너뛴다. 이 분기와 다른 순위의 상태 동기화는 대상 파일 밖에서 확인하지 않았다.
- 61·84–92: 음수 부모 번호 거부문과 부모 관계 순환 검사 본체는 주석 처리되어 있다. 음수 N에 대한 NB_SC=-N 대입은 실행문이다.
- 32–40·139–145: 파일 열기 오류는 기본 설정 분기로 이동한다. 9010 CAN NOT OPEN 오류 블록으로 향하는 실행 GOTO는 이 파일에 없다.
