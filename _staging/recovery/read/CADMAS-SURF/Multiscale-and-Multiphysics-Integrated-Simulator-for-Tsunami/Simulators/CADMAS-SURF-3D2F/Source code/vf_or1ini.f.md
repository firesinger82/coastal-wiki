## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 30: ICPL>0 또는 ISTM=1이면 상세 파일 초기화를 생략한다.
- 33: IRSTYP=0이어도 ETIME이 1.0D30과 다르면 출력 파일 초기화 경로를 진행한다.
- 80–82: LG·LD 플래그는 각각 IPRNT>1·IDROP>=1에서 켠다.
