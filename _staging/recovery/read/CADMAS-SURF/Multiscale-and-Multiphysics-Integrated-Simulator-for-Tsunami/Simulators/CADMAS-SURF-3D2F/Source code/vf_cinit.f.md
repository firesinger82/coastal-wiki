## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 227–228·239–240·251–252: x·y면 초기유속 조건은 해당 면 인덱스가 0이고 양측 NF가 같음이다. z면 조건은 INDZ가 0이고 양측 NF의 곱이 0임이다. [11-04 전수 검증 정정]
- 97·133: INDBE 인수 설명 주석의 첫 차원은 MAXBK1이고 실제 DIMENSION은 MAXBE1이다.
- 417–419: DROPTX 초깃값은 -1.0D10이다. DROPTY·DROPTZ는 0.0D0이다.
- 151·172–174: FF는 전체를 0으로 초기화한다. FX/FY/FZ에는 전체 0 초기화 호출이 없고, 인덱스가 0인 면에만 값 대입이 있다.
