## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 21–48·313: IPART 분기는 0과 1만 처리한다. 다른 값의 ELSE 분기는 없다.
- 321–329: POS·POS1·POS2와 DVEL·DVEL1·DVEL2를 할당한다. 이 파일의 해당 블록은 POS와 DVEL에만 값을 대입한다.
- 335–337: IPGRID와 조건부 IRGRID를 할당한다. 이 파일에는 두 배열 원소의 값 초기화가 없다.
- 27–32·55–57·83–85·109–113·154–155·218–223·281–286·321–337: ALLOCATE 문에 STAT 인수와 할당 실패 검사문이 없다.
