## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 46·82–83·214–215: LNDH의 세 번째 첨자는 0:2이다. LTYP>0 조건으로 LTYP를 해당 첨자에 쓰며 이 블록에는 LTYP<=2 검사가 없다.
- 305–339: GGV·GGX·GGY·GGZ 갱신에는 음수의 0 보정이 있다. 해당 갱신 블록에는 1을 상한으로 적용하는 문장이 없다.
- 404–416: MODE=0의 KST 탐색은 조건을 만족한 K에서만 KST에 대입한다. 탐색 전에 KST 기본값을 대입하는 문장은 이 파일에 없다.
