## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 38: DTO를 분모에 쓰기 전에 이 파일에는 DTO=0 검사가 없다.
- 30–35·127–152: DRECV·ISEND·DSEND는 MYRANK=0 분기에서만 할당한다. 다른 랭크 분기에서도 해당 배열을 scatter·gather 인수로 전달한다. 호출된 루틴 내부는 이 파일에서 확인하지 않았다.
- 1–3·90–118: UU·VV·FX·FY·GGX·GGY를 받지만 이 이름을 쓰는 유량 계산문은 주석 처리되어 있다. 실행 중인 누적은 FLFU·FLFV를 사용한다.
