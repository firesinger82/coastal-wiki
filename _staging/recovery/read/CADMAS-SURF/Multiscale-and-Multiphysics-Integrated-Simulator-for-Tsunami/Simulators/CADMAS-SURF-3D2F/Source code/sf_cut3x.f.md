## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 17–29: 주석 처리된 검사는 DABS(V)<=EPSV와 V<-EPSV를 사용한다. 실행 검사는 -EPSV*1.D3<=V<=EPSV와 V<-EPSV*1.D3를 사용한다.
- 9–13·100–104·526–530: PX는 좌표 보정 전 값을 보존한다. 두 경계 면적 분기는 보정 후 P0가 아니라 PX의 평균 RXM으로 추가 조건을 검사한다.
- 35–63: IMODE는 1·2만 처리하며 그 밖의 값에는 별도 오류 분기가 없다.
