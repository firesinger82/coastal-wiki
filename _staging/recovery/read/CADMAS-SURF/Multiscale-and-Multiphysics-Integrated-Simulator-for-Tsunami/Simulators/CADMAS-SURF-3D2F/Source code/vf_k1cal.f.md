## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 150–151: 주석의 이전 적분 조건에는 IPRNT만 있다. 실행 조건은 ICPL·ISTM도 검사한다.
- 169–173: AE가 최소값 미만이면 AK도 AKMINK로 설정한다. AE 조건이 거짓인 경우에만 AK 최소값을 별도로 검사한다.
- 181–183: VF_BSSS 호출 두 개는 주석이다. VF_BWKE는 실행한다.
