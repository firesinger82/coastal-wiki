## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 51–54·71–72: WK01–WK03·WKBC 주석은 I*4로 적는다. IMPLICIT·DIMENSION 선언에 따른 형은 DOUBLE PRECISION이다.
- 119–128: MODE를 0으로 고정한다. NFWK를 계산하지만 이 분기 출력 대상은 NF이다.
- 117–118·129–137: MODE=1 설명은 모든 NF를 0으로 출력한다고 적는다. ELSE 실행식은 MIN(NF,0)이다.
- 231–237: 도화 출력 와도의 경계값 세 성분을 모두 0으로 기록한다.
