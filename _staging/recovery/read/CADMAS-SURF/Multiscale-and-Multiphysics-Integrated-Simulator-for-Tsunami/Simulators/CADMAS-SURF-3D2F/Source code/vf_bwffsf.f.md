## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 58–63·71–72: 배정밀도 TN과 단정밀도 R4TN을 둘 다 계산한다. VF_CWMTB1에 전달하는 WVT는 DBLE(R4TN)이다.
- 66–68: 증폭률 분기는 A>=ZERO이고 내부에서 TNOW/T/A를 계산한다. ZERO의 값은 이 파일 내부에 정의되어 있지 않다.
