## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 74–75·373: JSW를 할당하고 초기화한다. 파일 끝까지 JSW를 명시적으로 해제하는 문장은 없다. nfwrk는 373행에서 명시적으로 해제한다.
- 144–145·164–165: 부모 중복 검사는 실행문이다. 부모 미발견 오류 호출은 CDEBUG 주석이다.
- 238–240·261–266: VF_PMGSTS로 격자 대응을 얻는다. 부모·자식 영역 끝점의 경계 표시는 실수 좌표의 .EQ. 비교로 설정한다.

- 344–346·353–369: mgcnum/=0 오류 호출 뒤에도 MGCNUM을 순회하여 자식 영역을 NF=-1로 만드는 코드가 있다. 오류 루틴의 반환 여부는 이 파일 밖에서 확인하지 않았다.
