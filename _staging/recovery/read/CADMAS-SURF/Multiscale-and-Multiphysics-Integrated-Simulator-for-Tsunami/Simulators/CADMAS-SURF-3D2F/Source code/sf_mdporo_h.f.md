## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 42–53: KST는 조건을 만족하는 셀에서만 대입한다. 조건을 만족하는 셀이 없을 때 기본값 대입은 이 파일에 없다.
- 95–125: GGF 성분을 GGFW에 복사하여 VF_P3SRD1에 전달한 뒤 반환된 GGFW를 해당 성분에 복사한다(95–98). ICHG는 인접 I-1·J-1·K-1에서도 읽지만 이 면 갱신 앞에는 ICHG 통신 호출이 없다. 해석: VF_P3SRD1 호출은 자료 교환을 수행한다. [11-04 전수 검증 정정]
- 42–146·148–158: 갱신 분기는 MODE=0과 MODE=2만 처리한다. 마지막 통신의 ELSE는 MODE가 0이 아닌 모든 값을 처리한다.
