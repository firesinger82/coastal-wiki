## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 169–171: GT를 0으로 고정하고 GST=GS+GT와 RF=-GT/MAX(GST,ZERO)를 계산한다.
- 174–176: AK에는 AKMINK 하한을 적용한다. AE0는 AE를 그대로 가져온다.
