## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 39–42·83–84·99–101: FLTU/FLTV/FLTW/QT 주석은 VOF 함수 F의 플럭스·생성소멸이라고 적는다. 실행문은 TT 온도 계산의 작업 배열로 전달한다.
- 90–91·vf_sdiff.f:1–2: VF_T1CAL의 VF_SDIFF 호출은 인수가 17개이다. 대상 루틴의 선언은 FF와 CC를 별도로 받는 인수 18개이다.
- 76·93–94: QT는 0으로 초기화한다. 생성소멸 계산 VF_TGENE 호출은 주석이다.
