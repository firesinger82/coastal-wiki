## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 226–231: 서로 다른 그룹 탐색 뒤 m=0으로 재설정하므로 뒤의 m==1 디렉터리 분리 분기는 이 실행 흐름에서 선택되지 않는다.
- 232·244·246: getcwd·chdir 실제 호출은 주석 처리되었으며 인터페이스 선언은 남아 있다.
- 98–99·290–292: mpi_init 실패는 901로 이동하지만 해당 메시지는 mpi_comm_size 오류라고 표기한다.

- 52–59·63–69·118–219: 모델 간 실제 통신자 중 comm_mlicdsmg2fc만 이 루틴에서 직접 생성한다. 나머지 대응 변수는 선언되어 있으며 이 루틴은 comm_work_*를 생성한다.
