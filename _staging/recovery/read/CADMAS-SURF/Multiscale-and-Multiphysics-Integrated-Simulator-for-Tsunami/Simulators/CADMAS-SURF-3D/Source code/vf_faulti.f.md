## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 32·36·84: 여는 파일은 fault_cad.txt이나 진행 로그에는 fault.txt라고 적는다.
- 25·87: LP는 이 파일에서 명시적으로 선언하거나 값을 대입하지 않고 WRITE의 장치 번호로 사용한다.
- 39·62·125: 읽기 오류의 행 번호 출력은 두 읽기 루프의 N이 아니라 NFLT+1을 사용한다.
- 57–60·85–89: B·L의 극값은 ±1.D9로 초기화한다. NFLT=0을 별도로 처리하는 분기는 이 계산 앞에 없다. [11-04 전수 검증 정정]
