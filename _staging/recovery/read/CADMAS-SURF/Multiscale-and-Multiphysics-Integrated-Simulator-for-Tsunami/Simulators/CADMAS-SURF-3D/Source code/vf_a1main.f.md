## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 412–491·579–617: 연속된 여러 ALLOCATE 문은 같은 IERR에 STAT를 기록한다. 오류 검사는 묶음 마지막에 한 번 있다.
- 402–408·412–430·565–571·579–614: 첫 입력 호출은 주요 배열 할당보다 앞이고 두 번째 입력 호출은 경계 배열·부모 대응 배열 할당보다 앞이다. 해당 입력 루틴 내부 처리는 이 파일만으로 확인하지 않았다.
- 470–475·665–669: 임시 좌표 배열 할당·해제의 LB_CADMAS 조건은 주석 처리되어 있다.
- 575·578·691–696: STBUF 할당 뒤 IERR를 0으로 재설정한다. DELH·DELH_IN 할당 직후에는 별도 IERR 검사가 없다.
- 680–688: PVCP0.GE.ZERO일 때 공기압 배열을 할당하고 초기화한다. 조건에는 PVCP0=0도 포함된다.
- 947·951–1007: 종료 플래그를 계산한 뒤 결과 파일들을 출력하고 MPI_ALLREDUCE 종료 판정을 수행한다.
- 1003–1004·1018–1019: 종료 플래그는 comm_mlicdsmg2fc의 MPI_MAX, 시간 간격은 같은 통신자의 MPI_MIN으로 결합한다.
- 1044–1072·1075–1116: LOOPS 하위 반복은 유속·압력 계산을 감싼다. 온도·농도·난류·VOF 함수 계산은 그 반복 밖에 있다.
- 859·870–909: DB_INI 호출과 진단 후 중단 블록은 주석 처리되어 있다.
