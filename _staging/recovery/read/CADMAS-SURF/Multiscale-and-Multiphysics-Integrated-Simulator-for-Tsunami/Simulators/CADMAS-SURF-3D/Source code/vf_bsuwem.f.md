## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 52–67: N=5·6과 N=3·4 이외는 마지막 ELSE에서 y·z 이웃을 증가시킨다. 이 ELSE에는 N=1·2의 명시 검사가 없다.

- 81·84·87·90·93·96: 복사 기준 반대편 셀 조건은 NF.NE.8이며 유체 NF=0만으로 제한하지 않는다.
