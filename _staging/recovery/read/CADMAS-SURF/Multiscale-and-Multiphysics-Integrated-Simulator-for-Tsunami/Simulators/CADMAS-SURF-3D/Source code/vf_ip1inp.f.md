## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 37–42: 헤더의 IPRNB에는 MAXPRB 초과 검사만 있다. 0 또는 음수를 거부하는 검사 조건은 이 파일에 없다.
- 93–95: GGVNOW에는 PLOWER 하한을 적용한다. 이 루틴에는 공극률이 1을 넘는지 검사하는 조건이 없다.
- 81·74–75: 새 PRTNOW를 읽은 뒤 이전 시각보다 큰지 검사하는 조건은 없다. 종료 판정은 PRTNOW와 T0, 블록 수를 사용한다.
