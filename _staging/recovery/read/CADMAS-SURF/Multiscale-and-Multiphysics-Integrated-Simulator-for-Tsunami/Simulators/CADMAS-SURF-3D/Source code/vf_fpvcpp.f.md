## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 35·157–159: PPPVC 인수 설명은 OUT이나 기존 PPPVC를 판정하고 압력 합에 사용한다.

- 157·204: 영역 밖 압력 표지는 1.0D30과의 정확한 비교·대입으로 처리한다.
