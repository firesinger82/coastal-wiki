## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 78–83·93: 배정도 TN을 계산하지만 이후 WVT에는 단정도 R4TN을 DBLE로 변환한 값을 사용한다.
- 86–88: A.GE.ZERO 조건에서 A=TDMY/T/A를 계산한다. ZERO의 정의는 이 파일에 없다.
- 127·134–142: VWS 계산의 VAL+D 분모 검사 없이 좌표 및 유속 배율에 사용한다.
- 102–145: IJP=0이면 SRCUV 대입을 수행하지 않는다.
