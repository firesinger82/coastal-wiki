## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 372–377: 이 출력 루틴은 IGRARA의 각 값이 1 이하이면 시작 좌표는 2, 끝 좌표는 각 전역 격자 상한으로 직접 변경한다.
