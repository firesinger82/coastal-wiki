## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 48: G0 계산은 DBLE(LOOPS)를 곱한다. 이 루틴 안에서 LOOPS 값을 제한하는 문장은 없다.
- 52: CC 갱신은 GGV(I,J,K)로 나눈다. 해당 분기의 조건은 NF(I,J,K)=0이며 별도의 GGV=0 검사는 없다.
