## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 34·47: 수직 피난 판정은 agent_z<shelter_height로 비교하지만 피난 완료 후 z 대입은 height+shelter_height다.
- 83–88: 상태 0 분기의 사망 판정과 통계 갱신은 모두 주석 처리되어 있다.
- 89–94: 상태 5를 상태 0으로 바꾸는 실행 분기가 존재한다.
- 35·56·65: 현재 수심 외에 누적 최대 수심 max_depth를 사망 조건에 사용한다.
