## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 32: 첫 번째로 time<=agent_start(n)을 만족하는 에이전트에서 move_agent 전체를 return한다.
- 111–126: 비도로 셀 진입 방지는 주석 처리되어 있고 영역 밖 검사만 실행된다.
- 99–104·128–132: 지역 변수 u·v를 계산하지만 이 파일에는 agent_u·agent_v에 대한 대입이 없다.
- 50–52: 수직 피난의 z 증가는 shelter_height를 상한으로 제한하지 않는다.
