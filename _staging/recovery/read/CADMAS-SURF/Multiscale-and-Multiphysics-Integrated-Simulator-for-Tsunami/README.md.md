# README.md — 판독 구간 기록

| 1–3 | 시스템 소개. 구조해석과 유동해석을 결합하여 쓰나미 발생부터 처오름(runup)과 구조 변형까지 계산하는 목적을 적는다. 정수압(hydrostatic pressure) STOC-ML, 단상 Navier–Stokes와 VOF 기법, 기액 이상 VOF 기법, 유한요소법(Finite Element Method, FEM) STR3D의 연결을 설명한다. 원문: `# Multiscale Multiphysics Integrated Simulator for Tsunami` (1); `We develop a numerical fluid simulator coupled with a structural analysis. The purpose of this system is to efficiently calculate all stages of a tsunami from source to runup, including structural deformation. ` (2); `Specifically, a semi three-dimensional model ([**STOC-ML**](https://www.pari.go.jp/unit/tsunamitakashio/open-software/t-stoc/download/index.html)；Developed by [Port and Airport Research Institute](https://www.pari.go.jp/en/)) assuming hydrostatic pressure is used from the source to the propagation of tsunami waves, and this is connected to the single-phase Navier-Stokes equation ([**CADMAS-SURF/3D**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Simulators/CADMAS-SURF-3D)), which calculates the sea surface using the VOF method, and then, in order to consider the effect of the gas phase, the single-phase VOF method is connected to the gas-liquid two-phase VOF method ([**CADMAS-2F**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Simulators/CADMAS-SURF-3D2F)) and finally to the structural and ground calculations ([**STR3D**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Simulators/STR3D)), which are calculated using FEM.` (3). [11-04 전수 검증 정정] |
| 4–12 | 시뮬레이터 목록. CADMAS-SURF/3D는 3차원 비압축성 단상, CADMAS-SURF/3D2F는 기액 이상, STR3D는 구조·지반 FEM, AGENT는 피난 시뮬레이터로 소개한다. 항만공항기술연구소의 STOC-ML 정수압 모델과 STOC-IC 비정수압 모델 링크를 적는다. 9행은 빈 줄이다. 원문: `# Simulators` (4); `1. [**CADMAS-SURF/3D**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Simulators/CADMAS-SURF-3D) (Single-phase model for three-dimensional incompressible fluid)` (5); `2. [**CADMAS-SURF/3D2F**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Simulators/CADMAS-SURF-3D2F) (Gas-liquid two-phase model for three-dimensional incompressible fluid)` (6); `3. [**STR3D**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Simulators/STR3D) (FEM-based structural and soil calculation model)` (7); `4. [**AGENT**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Simulators/AGENT) (Evacuation simulator)` (8); `The following simulators are published by [Port and Airport Research Institute](https://www.pari.go.jp/en/)` (10); `1. [**STOC-ML**](https://www.pari.go.jp/unit/tsunamitakashio/open-software/t-stoc/download/index.html) (Hydrostatic model for calculating fluid motion due to tsunami)` (11); `2. [**STOC-IC**](https://www.pari.go.jp/unit/tsunamitakashio/open-software/t-stoc/download/index.html) (Non-hydrostatic model for calculating fluid motion due to tsunami)` (12). |
| 13–17 | 전후처리 도구 목록. CADMAS-MESH-MULTI는 STOC 입력 준비, CADMAS-MESH는 CADMAS 입력 준비, CADMAS-VR과 ViewKai는 결과 가시화 도구로 소개한다. 원문: `# Pre and post-processor` (13); `1. [**CADMAS-MESH-MULTI**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Pre%20and%20post-processors/CADMAS-MESH-MULTI) (STOC-ML and STOC-IC input data preparation support tool)` (14); `2. [**CADMAS-MESH**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Pre%20and%20post-processors/CADMAS-MESH) (CADMAS-SURF/3D and CADMAS-2F input data preparation support tool)` (15); `3. [**CADMAS-VR**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Pre%20and%20post-processors/CADMAS-VR) (STOC-IC, STOC-ML, CADMAS-SURF/3D and CADMAS-2F calculation results visualisation tool)` (16); `4. [**ViewKai**](https://github.com/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/tree/main/Pre%20and%20post-processors/ViewKai) (CADMAS-SURF/3D and CADMAS-2F calculation results visualisation tool)` (17). |
