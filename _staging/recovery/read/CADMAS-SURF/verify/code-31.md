## 확인 방법과 확인 범위

각 구간의 원문을 `nl -ba <원문> | sed -n 'A,Bp'`로 열어 읽었다.
한 번에 연 원문 구간은 200행 이하이다.
한국어 요약을 원문의 조건·수량·단위·부호·순서·일본어 설명과 대조했다.
각 구간의 행 번호가 붙은 백틱 인용을 해당 원문 행과 기계적으로 비교했다.
비공백 원문 행의 인용 누락은 0행이다.
백틱 인용 내용과 행 번호의 불일치는 0건이다.
원문 인용이 유지된 상태에서 한국어 설명의 오류와 근거 없는 기능 단정을 수정했다.
기록의 구간 경계와 frontmatter는 변경 전 값과 일치한다.
원문 파일의 SHA-256은 작업 시작 때의 값과 일치한다.

대상은 README·Makefile·입력 형식 설명·객체 목록이다.
대상에는 Fortran 실행 분기·DO 블록·GOTO·INCLUDE·COMMON·PARAMETER·DATA·MPI 호출문이 없다.
대상 Makefile에는 `-D` 정의가 없다.
표본 오류의 랭크 조건은 이번 대상에 해당하지 않는다.
구간 근거 없는 해석 유형은 Makefile의 기능 분류와 입력 설명의 NF 서술에서 확인했다.
원문의 오기와 표기 불일치는 인용에 그대로 보존했다.
모델과 빌드 명령은 실행하지 않았다.
원문·노트·git은 변경하지 않았다.
