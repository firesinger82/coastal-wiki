# CADMAS-SURF code-11 전수 대조

대상은 사용자 지정 기록 50개다. 대상 구간은 102개다. 원문은 각 기록의 frontmatter `file:`에 적힌 파일이다. 원문 행 수 합계는 3,352행이다.

구간별로 `nl -ba <원문> | sed -n 'A,Bp'` 출력과 기록의 인용 및 의미를 대조한다. 빈 행과 주석도 원문 행 수에 포함한다. 원문과 모델 실행 결과는 수정·생성하지 않는다.

기록 경로의 공통 접두사는 `_staging/recovery/read/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/CADMAS-SURF-3D2F/Source code/`다. 아래 파일명은 이 접두사를 생략한다. 원문 행 열은 해당 기록의 `file:`을 기준으로 한다.

정정과 보완은 각각 해당 유형이 발생한 구간 행 수로 센다. 같은 구간에 두 유형이 있으면 각각 센다. 후속 사실 행의 정정은 연결된 구간의 정정에 포함한다. 이상 없음은 완료한 구간 중 두 유형이 모두 없는 구간 행 수다.
