2026-11-04 사용자 지정 기록을 각 frontmatter의 원문과 대조했다.
원문은 기록의 구간별로 `nl -ba <원문> | sed -n 'A,Bp'`로 열었다.
표의 원문 행 수는 빈 행과 주석 행을 포함한다.
정정·보완 수는 해당 표식을 붙인 구간 행 수이다.
한 구간에 두 표식이 있으면 정정과 보완에 각각 한 번 센다.
표 밖의 후속 검토 항목은 목록에 남기되 마지막 집계에는 넣지 않는다.

남은 기록에 이미 있던 표식은 원문으로 확인한 뒤 미등록 내역으로 목록에 추가했다.
