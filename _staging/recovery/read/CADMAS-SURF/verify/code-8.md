# CADMAS-SURF code-8 전수 대조

원문은 각 기록 frontmatter의 file 경로이다.
기록 경로의 공통 접두사는 `_staging/recovery/read/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/CADMAS-SURF-3D/Source code/`이다.
원문을 각 구간별로 `nl -ba <원문> | sed -n 'A,Bp'`로 열어 대조했다.
원문 행 수에는 빈 행과 주석을 포함한다.
정정·보완·이상 없음의 집계 단위는 기록의 구간 행이다.
한 구간에 정정과 보완이 함께 있으면 정정으로 집계한다.
원문·노트·git은 수정하지 않았다.
모델은 실행하지 않았다.
전체 대조 범위는 기록 21개·구간 행 118개·원문 4,747행이다.
이 합계는 아래 기록별 대조 표의 합이다.
행 번호가 붙은 인용문 4,174행은 원문 문자열과 일치했다.
인용하지 않은 원문은 빈 행 397개와 내용 없는 주석 구분 행 176개이다.
내용 없는 주석 구분 행은 단독 `C`·`c` 또는 `!` 반복이다.
실행문·선언문·내용 있는 주석의 인용 누락은 없었다.
이 수치는 대상 기록의 인용문과 frontmatter가 가리키는 원문을 문자 단위로 대조한 결과이다.
각 원문의 SHA-256과 행 수는 기존 frontmatter 값과 일치했다.
구간 경계와 frontmatter는 수정하지 않았다.
