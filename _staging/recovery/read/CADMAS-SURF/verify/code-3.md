# CADMAS-SURF code-3 전수 대조

대상 기록의 frontmatter에 지정된 원문을 구간별로 `nl -ba <원문> | sed -n 'A,Bp'`로 열어 대조했다. 한 호출의 원문 구간은 200행 이하다. 코드 인용 문자열과 행 번호는 기계 대조를 함께 사용했다. 한국어 요약과 일본어 주석 뜻은 원문을 읽고 대조했다. 원문·모델 실행·git 변경은 하지 않았다.

기록 경로의 공통 접두사는 `_staging/recovery/read/CADMAS-SURF/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/CADMAS-SURF-3D/Source code/`이다. 원문 행 수에는 빈 행이 포함된다. 정정과 보완은 아래 변경 목록의 항목 수다. 이상 없음은 수정하지 않은 구간 행 수다. 동일 구간에 두 종류의 변경이 있으면 각각 센다. 대상 31개 기록의 구간 행 175개를 모두 대조했다. 이 구간이 포함하는 원문은 총 5,183행이다.

최종 기계 확인에서 원문 인용 5,387개의 문자열과 행 번호가 일치했다. 각 원문의 SHA-256은 해당 기록 frontmatter 값과 일치했다. 구간 경계와 frontmatter는 수정하지 않았다. 원문의 비어 있지 않은 행은 모두 해당 구간의 인용에 포함된다. 변경 목록의 정정·보완 수는 기록의 표식 수와 일치한다.
