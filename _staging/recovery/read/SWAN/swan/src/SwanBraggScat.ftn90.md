## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 186–187·217–218·290–294·344·424–428·478: 작업 배열 한 변은 int(pbrag(1))이다. 파수 간격과 분산(variance) 정규화의 분모는 실수 pbrag(1)을 사용한다. 주변점 범위의 반폭은 정수 (nreg-1)/2이다.
- 206–207·252–298·386–432: dpmean과 fb는 전체 0으로 초기화한다. ingrd가 거짓인 계산점에는 이후 평균 수심·스펙트럼 대입을 하지 않는다. 유효 수심점 수가 0인 경우만 dpmean을 excfld(1)로 바꾼다(316–321·450–455).
- 161–168·326–327·350–351·460–461·484–485·516–520·529–555: FIT2와 FFT 호출은 같은 ierr를 사용한다. FIT2 오류는 CYCLE하고 FFT 오류는 EXIT한다. 최종 ierr/=0 메시지는 Fourier 변환 오류로 적혀 있다.
- 243–244·351·376–377·381–510: 정형 격자 FFT 오류의 EXIT는 내부 iyc 루프 안에 있다. 그 뒤에는 바깥 ixc 루프와 비정형 ic 루프가 이어진다.
- 165–166·346·480: c와 r는 kind=8로 선언한다. 두 변환 실행문은 cmplx(r)이며 kind 인수를 쓰지 않는다.
- 550–555: FIT2는 행렬식 d가 정확히 0d0이 아닌지 검사한다. 해당 조건에는 작은 절댓값을 따로 검사하는 기준이 없다.
- 690–706·867–872: SWFBXY는 fb 절댓값의 최대값 검사와 d>DEPMIN 검사를 수행한다. SWFB는 fb 절댓값의 최대값을 검사하지만 수심 DEPMIN 검사는 없다. [10-13 전수 검증 정정]
- 679·713·723·872·886·896: 파수차 보간의 절단값은 1/pbrag(2)이며 kd<5와 파수차 제곱>절단값 제곱 조건을 사용한다. 해당 루틴들 안에는 pbrag(2)=0 검사문이 없다.
- 728–755·901–928: 파수 공간 경계 밖 보간 좌표도 끝 구간의 가중치 0 또는 1로 처리한다. 해당 분기는 바닥 스펙트럼을 0으로 설정하지 않는다.
- 1008–1011·1077–1079·1161–1164·1230–1232·1438–1441·1466–1468: SWBRAGG1·SWBRAGG2·FILBRG는 IMATRA·REDC0를 INTENT(OUT)으로 선언한다. 실행문은 두 배열의 기존 값을 읽어 산란항을 누적한다. 각 루틴 안에는 누적 전 전체 초기화문이 없다.
- 1049–1053·1202–1206·1346–1350: 산란계수 계산 조건은 kd<5이다. 계산식은 sinh(2*kd)와 cg를 분모에 쓰며 해당 블록에 0 분모 검사문이 없다.
