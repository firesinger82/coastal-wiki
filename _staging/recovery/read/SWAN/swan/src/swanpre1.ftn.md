## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 1020–1036·1057–1081: 주파수·스펙트럼 의존 투과 계수 부재 분기에서도 마지막에 `DEALLOCATE(TMPFT)`를 실행한다. TMPFT 할당은 각각 `TRCF.NE.-1.` 분기 안에 있다. 이 블록의 해제 대상은 연결 리스트 전체가 아니라 TMPFT 한 포인터다.
- 1067–1079: TRCF2D 선언 크기는 (MDC,MSC)이다. 입력 목록은 J를 1..MSC로 먼저 증가시키고 이후 I를 증가시키며 TRCF2D(I,J)에 복사한다.
- 915–929: COMPUTE 입력 수가 300을 넘으면 MSGERR(2)를 호출한다. 그 바로 뒤에는 RETURN 없이 RCOMPT(NCOMPT,1–5)에 값을 저장한다. MSGERR 내부 동작은 이 파일에서 확인하지 않았다.
- 1217–1225: 자유고 형상 계수 검사에서 GAMT<0.1과 GAMR<0.1 보정은 하나의 ELSEIF 사슬이다. 두 값이 모두 0 이상 0.1 미만이면 GAMT 보정 분기만 실행된다.
- 1256–1286: 모서리 목록 TMP 할당은 LIN 분기의 유효 XP 입력 뒤에 있다. `DEALLOCATE(TMP)`는 LIN 분기 밖이며 NUMCOR<=1 검사보다 앞에 있다. 연결 리스트 전체를 순회하며 해제하는 문장은 이 블록에 없다.
- 1684–1708: MXS와 MYS로 DX=XCLEN/MXS 및 2차원 DY=YCLEN/MYS를 계산한다. 해당 대입 앞에 이 블록 내부의 0 분모 검사는 없다. ININTG의 'RQI' 처리 내부는 판독하지 않았다.
- 1793–1794·1814–1815: 스펙트럼·계산 좌표 배열은 미할당 조건에서만 할당된다. CGRID 입력 크기가 바뀌었을 때 이미 할당된 배열의 크기를 비교하거나 재할당하는 문장은 이 CGRID 분기에 없다.
- 1874–1887: BOU는 전역 격자 크기로 바꾼 뒤 SWBOUN을 호출한다. STPNOW()가 참이면 지역 크기 복원문에 도달하기 전에 RETURN한다.
