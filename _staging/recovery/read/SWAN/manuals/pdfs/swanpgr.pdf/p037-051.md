Chapter 12, **Names for SWAN program units**. 최상위 서브루틴(subroutine)은 사용자가 익숙하므로 어떤 이름이든 사용할 수 있다. 이름은 기억하기 쉬워야 한다. 하위 서브루틴은 사용자의 프로그램과 이름 충돌을 피하도록 특정 문자 조합을 선택하는 것이 권장된다. 모든 SWAN 루틴을 `sw`로 시작하는 방식을 제안한다. 모듈(module)도 모호하지 않은 이름이 필요하다. `swmod` 뒤에 3자리 기호를 붙일 수 있다는 예시를 제시한다. 적용한 서브루틴 이름과 모듈을 담은 ASCII 파일은 짧은 기능 설명을 포함하여 최신 상태로 유지해야 한다. 본문 인용: `The names therefore need to be mnemonic.` (p.37) |
