| p.13 | 인쇄 쪽 번호 7. Chapter 2 Use of patch files. 공식 버전 배포 사이에 버그 수정이나 새 기능이 홈페이지에 게시될 수 있다. 보통 패치는 기존 소스 코드 위에 설치할 수 있다. 홈페이지의 patchfile 링크는 패치를 나타낸다. 패치 이름은 현재 버전 번호에 문자 코드를 더한다. 첫째는 ’A’인 `41.51.A`이고 둘째는 ’B’이며 셋째는 ’C’이다. 적용한 패치를 나타내도록 출력 파일의 버전 번호는 `41.51ABC`로 갱신된다. 적용 절차는 1. 파일을 오른쪽 클릭하여 save link as로 다운로드, 2. SWAN 소스 코드 디렉터리에 배치, 3. `patch -p0 < patchfile` 실행이다. 패치를 하나 또는 여러 개 적용한 뒤에는 소스 코드를 다시 컴파일해야 한다. 웹 브라우저 화면에서 잘라 붙이지 말고 패치 파일을 다운로드하는 것이 중요하다고 설명한다. 일부 패치는 탭(tab)을 포함할 수 있다. 대부분의 브라우저는 파일을 표시할 때 탭을 보존하지 않는다. 그 텍스트를 복사하여 붙이면 탭을 찾지 못해 패치가 실패한다. 문제가 있으면 패치 파일 자체를 살펴볼 수 있다.<br>Linux/UNIX: 다운로드한 패치는 캐리지 리턴(carriage return, CR)을 포함하는 MS-DOS ASCII 파일이다. UNIX 형식 변환에는 `dos2unix`를 사용한다. 대안 명령은 이미지에 `cat 41.51.[A-C] \| tr -d ’\r’ \| patch`로 인쇄되어 있다. 원문은 이 명령으로 `41.51.A`부터 `41.51.C`까지 한 번에 적용한 뒤 변환이 수행된다고 설명한다.<br>Windows: `patch`는 UNIX 명령이다. Windows 운영체제에 적합한 patch 프로그램을 SWAN 홈페이지에서 받도록 안내한다.<br>`After applying a patch or patches, you need to recompile the SWAN source code.` (p.13). |

| p.15 | 인쇄 쪽 번호 9. Chapter 3 Installation. §3.1 Introduction. SWAN은 노트북부터 슈퍼컴퓨터까지 여러 아키텍처(architectures)에 설치할 수 있다. 원문은 표준 ANSI Fortran 90을 사용하여 소스 코드의 이식성(portability)을 보장한다고 설명한다. MPI 방식은 메모리 분산 노드(memory-distributed nodes)를 가진 Linux 클러스터에서 선택적으로 실행할 수 있다. GNU make를 사용하거나 처음부터 직접 빌드하는 방법은 §3.2에서 설명한다. 버전 41.41부터 CMake를 사용한 설치도 지원한다. CMake 설치는 §3.3에서 설명한다.<br>`SWAN can be installed on various architectures, including laptops and supercomputers.` (p.15). |
