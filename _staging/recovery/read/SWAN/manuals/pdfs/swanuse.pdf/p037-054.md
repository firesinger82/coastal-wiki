| p.38 | 인쇄 쪽 번호 30. 쪽 첫머리의 기본 옵션은 `STATIONARY TWODIMENSIONAL`이다. `COORDINATES`는 직교 좌표(Cartesian coordinates)와 구면 좌표(spherical coordinates)를 선택한다. 명령 상자의 기본 선택은 `CARTesian`이다. `SPHErical`에서는 `CCM`이 기본 투영법이고 `QC`를 선택할 수 있다. `REPeating` 옵션도 표시한다. 중첩 실행(nested run)은 성긴 격자(coarse grid)의 SWAN 실행과 같은 좌표계를 사용해야 한다.<br>`CARTESIAN`에서는 모든 위치와 거리를 m로 쓴다. 사용자가 각 명령에서 정한 x축과 y축을 기준으로 좌표를 준다. `SPHERICAL`에서는 위치 좌표와 지리적 격자 크기를 degree로 쓴다. \(x=0\)은 그리니치 자오선이다. \(x>0\)은 자오선 동쪽이다. \(y>0\)은 북반구이다. 이 세 관계에는 식 번호가 없다. x는 경도(longitude)이고 y는 위도(latitude)이다. 입력 격자와 출력 격자의 x축은 동쪽을 향해야 한다. 격자 간격은 degree로 쓴다. 나머지 거리는 meter로 쓴다.<br>`CCM`은 central conformal Mercator를 뜻한다. 표시 영역의 수평 축척과 수직 축척은 각각 cm/degree 기준으로 일정하다. 중심의 축척은 종래 Mercator 투영과 같지만 그 중심에서만 같다. 투영 중심의 영역은 정확히 등각(conformal)이다. `QC`는 quasi-cartesian 투영이다. 수평 축척과 수직 축척은 cm/degree 기준으로 서로 같다.<br>`REPEATING`은 학술적 사례에만 사용한다. 계산 x방향의 한쪽 끝에서 나간 파랑 에너지(wave energy)가 반대쪽으로 들어온다. 파랑장은 영역의 x방향 길이로 반복되는 것과 같다. `SETUP`에 의한 수위 상승(set-up) 계산과 함께 사용할 수 없다. 규칙 격자(regular grid)에만 사용할 수 있다.<br>구면 좌표는 수평 크기가 10 또는 20 km인 비교적 작은 영역에도 사용할 수 있다. 구면 좌표로 구성된 해양 모형에 중첩하여 경계 조건을 얻을 때 유용할 수 있다. 구면 좌표의 규칙 격자는 항상 E-W, N-S로 향해야 한다. 원문 조건은 `[alpc]=0, [alpinp]=0, [alpfr]=0`이다. 각각 `CGRID`, `INPUT GRID`, `FRAME`을 참조한다.<br>본문 인용: `A nested SWAN run must use the same coordinate system as the coarse grid SWAN run.`(p.38) [10-13 전수 검증 정정] |
