## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 151: argv[argc - 1] 접근 앞에 argc 또는 argv를 검사하는 문장은 이 run 안에 없다.
- 184·162·798: 초기 dt는 C(0.001)이다. run은 solver_params.initial_tstep을 직접 참조하지 않으며 반복 말미에 get_dt_CFL 반환값으로 dt를 덮어쓴다.
- 194: num_blocks_all은 선언 시 계산 이후 이 파일에서 참조되지 않는다.
- 217·270–289·941: avg_cuda_time은 0.0f로 초기화된다. 누적 예제는 블록 주석 안에 있고 실행 코드의 추가 갱신 없이 마지막에 출력된다.
- 624·802·936·443–444·794–795: 시간은 clock() 차이를 CLOCKS_PER_SEC로 나눈다. 예시 위치의 peek()/sync() 확인 호출은 주석 처리되어 있다.
- 798·815–825·845–858·866–877: dt를 get_dt_CFL 반환값으로 갱신한 뒤 출력 루틴들에 dt를 전달한다.
- 218·422·912·940: steps는 0에서 시작하고 while 내부 912행의 후위 증가에서 바뀐다. 평균 시간 간격 출력의 steps 분모에는 0 검사 조건이 없다.
- 62–85 및 classes/SimulationParams.h:151–195: 본문 주석은 시험 번호를 1–22로 설명한다. 이번에 함께 판독한 SimulationParams의 case 19–23 주석은 세 원뿔·세 원뿔 댐 붕괴·두 종류 지형·방사형 댐 붕괴로 나뉘며, 실행 본문 머리말의 19–22 목록과 번호 설명이 같지 않다.
