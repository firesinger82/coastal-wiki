## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 165–172: getCmdLineArgumentValue는 접두어만 일치하고 값이 없어도 bFound=true를 반환하며 이 경우 *value 대입은 없다.
- 191–200·223–232·255–258: 정수·실수·문자열 인수 판독은 접두어 일치 뒤 continue한다. 같은 접두어 인수가 뒤에 있으면 다시 출력값을 갱신한다.
- 255–256: getCmdLineArgumentString은 접두어 뒤 구분자와 길이를 검사하지 않고 length+1 위치를 반환한다.
- 309–311: Windows 실행 이름은 rfind(".exe")가 npos가 아니면 마지막 네 문자를 제거한다. 검색 위치가 문자열 끝인지 비교하는 조건은 없다.
- 347–357: fp가 NULL이 아니면 첫 분기에서 fclose 후 즉시 반환한다. 뒤의 if (fp) 분기에 도달하는 경로에서 fp는 NULL이다.
