## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 40·68–69·89·116–117: 두 NetCDF 격자 초기화 함수는 units 인수를 받지만 단위 속성에는 HEIGHT_UNITS_VALUE를 기록한다.
- 245–252: depth와 elevation 변수 정의가 모두 netcdf_state->varid_depth에 출력 ID를 저장한다.
- 287–288: maxVx·maxVy 초기화 호출의 units 인수는 TIME_HOURS_UNITS_VALUE이다.
- 169·191–243: LATLONGMODE 분기는 lat 차원을 grid_cols로 dimid_x에, lon 차원을 grid_rows로 dimid_y에 저장한다. lat·lon 변수 정의는 dimids를 재설정하지 않는다. dimids[0]의 앞 대입은 dimid_time이다. x_edge·y_edge 차원 정의는 LATLONGMODE의 else에만 있다.
- 325–355: recid는 nc_inq_varid로 받은 뒤 nc_inq_dimlen에도 전달한다. xid·yid는 nc_inq_dimid로 받은 뒤 좌표 변수 판독 함수에도 전달한다.
- 344·373–381 및 lisflood.h:492: time_idx는 size_t 멤버인데 -1을 대입한다. 마지막 시각의 dt 계산에는 time_idx-1을 사용하며 이 함수에는 tlen이 2 이상인지 검사하는 조건이 없다.
- 463–468·486: ASCII 판독의 fscanf 반환값은 이 함수에서 검사하지 않는다. 결측값 비교는 value와 no_data_value를 모두 int로 변환한다(487).
- 494–504·585–595: 파일명형 ASCII·binary 판독 함수는 파일을 열지만 fclose를 호출하지 않는다. 자동 판별형 read_file에는 fclose가 있다(637).
- 516–522·547·563: binary 판독은 정수 둘·실수 넷 헤더를 먼저 읽고 파일 위치를 바이트 8로 옮긴 뒤 격자 자료를 읽는다. binary 쓰기는 정수 둘 뒤에 실수 넷과 격자 자료를 차례로 쓴다(696–706).
