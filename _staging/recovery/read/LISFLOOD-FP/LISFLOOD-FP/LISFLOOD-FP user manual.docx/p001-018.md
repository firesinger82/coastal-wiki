| p.4 | 인쇄 쪽 번호 4. 제목은 Executive summary이다. 모델 판은 ~~5.9.5~~<u>8.0.0</u>으로 표시된다. 이어 읽은 문자열은 `5.9.58.0.0`이다. 본문은 래스터(raster) 홍수 범람(flood inundation) 모델의 하천·해안 범람 계산을 설명한다. 출력은 각 시간 단계의 격자별 수심(depth), 수면 표고(water surface elevation), 유속(velocity) 등의 래스터 지도다. 하천 홍수에서는 하도 구간 출구와 지정 위치의 수위(stage)·유량(discharge) 수문곡선(hydrograph)도 출력한다고 적는다. 1차원 St. Venant 방정식의 운동파(kinematic) 또는 확산파(diffusive) 근사로 하도 홍수파를 계산한다고 적는다. 만제 수심(bankfull depth)을 넘으면 인접 범람원(floodplain)으로 물이 이동한다고 적는다. 범람원에서는 래스터 격자의 저류 셀(storage cell) 개념으로 2차원 확산을 계산한다고 적는다. 셀 사이 유동 계산에는 물리적 복잡도가 다른 세 가지 선택지가 있다고 적는다. 가장 복잡한 경우에는 완전한 천수 방정식(shallow water equation)을 사용한다고 적는다. 원문은 `Channels can also be represented as features within the 2D grid structure using a subgrid version of the model.` (p.4)이다. 하위 격자(subgrid) 버전은 셀 안의 하도와 인접 범람원 유동을 함께 계산한다고 적는다. 이 설명은 이류(advection)가 없는 1차원 St. Vernant 근사를 명시한다. 마지막 문장은 항공 레이저 고도 측량과 항공 합성개구레이더 간섭법(Synthetic Aperture Radar interferometry)을 이용한 지형 자료를 언급한다. |
