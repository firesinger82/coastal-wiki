## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 141·177–229: SetChannelStartHfromQ의 HoutFREE는 함수 입구에서 한 번 OFF로 초기화한다. FREE와 RATE8 분기는 값을 바꾸며 HFIX2와 HVAR3 분기는 이 값을 다시 OFF로 대입하지 않는다.
- 248–258: 초기 수심의 do-while은 dh=C(0.00001)와 eps=C(1.5)*dh를 사용한다. iter를 늘리지만 반복 조건은 fabs(err_d)>eps뿐이며 iter 상한 검사는 없다.
- 199·681: 초기 RATE8 보간 인수는 Q_Val[nodes-1]이다. ChannelQ_Diff의 RATE8 보간 인수는 x[2*nodes-3]이다.
- 335·372–374·578·648–649·696: Qtmp와 Qbc 선언에는 초기값이 없다. 첫 셀의 QFIX4 또는 QVAR5인 경우에만 해당 값을 대입한 뒤 다음 계산에서 사용한다.
- 343·468·594·750: 두 하천 병렬 루프의 주수로 분기는 공유 Solverptr->Hds에 값을 저장한다.
