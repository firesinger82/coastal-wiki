| p.4 | 인쇄 쪽 번호 **4**. 절 번호 없는 **Executive summary**이다. 본문은 이 설명서가 **version 5.9.5**의 셰어웨어(shareware) 구현을 다룬다고 명시한다. 모델은 하천 또는 연안의 홍수 확산을 모의한다. 출력은 각 시간 간격(time step)의 각 격자에 대한 수심(water depth)·수면 표고(water surface elevation)·유속(velocity) 등의 래스터(raster) 지도이다. 하천 홍수에서는 하도 구간 출구와 지정 위치의 수위(stage) 및 유량(discharge) 수문곡선(hydrograph)도 출력한다. 하도(channel)에서는 1차원 St. Venant 방정식의 운동파(kinematic) 또는 확산파(diffusive) 근사를 푼다. 만제 수심(bankfull depth)을 넘으면 인접 범람원(floodplain)의 저류 셀(storage cell)로 물이 이동한다. 본문은 래스터 셀 사이 유동 계산에 물리적 복잡도가 다른 **three options**가 있다고 명시한다. 가장 단순한 경우에는 중력과 지형의 함수로 홍수 확산을 다룬다. 가장 복잡한 경우에는 전체 천수방정식(full shallow water equation)을 사용한다. 하도는 2차원 격자 내부의 서브그리드(subgrid) 형상으로도 표현할 수 있다. 이 경우 이류(advection)를 제외한 1차원 St. Vernant 방정식 근사로 셀 내부 하도와 인접 범람원의 결합 유동을 계산한다. 모델은 항공 레이저 고도계와 합성개구레이더 간섭계(Synthetic Aperture Radar interferometry) 등의 지형 원격탐사 자료를 활용하도록 설계되었다. 원문: `This document is the user manual for the shareware implementation of the LISFLOOD-FP raster flood inundation model version 5.9.5.`(p.4). |

Villanueva and Wright (2006)의 TRENT 모델에 기반한 Godunov 접근과 Roe 근사 리만 해법(approximate Riemann solver)을 사용한다. 명시적 이산화(discretisation)는 래스터 격자에서 공간 1차이다. 충격 포착(shock capturing) 방법을 사용한다. Buscot 시험에서는 사용하지 않는다. 적용은 `1D Diffusive and kinematic`이다. **`ch_dynamic`**: `startq`는 확산파 모드에서 확산 정상상태 해를 자동으로 사용한다. 이 키워드는 완전 동적 정상상태(full dynamic steady state) 초기조건을 활성화한다. 주로 향후 호환성과 매우 복잡한 하천 시스템을 위해 포함했다고 설명한다. `startq`와 함께만 사용할 수 있다. 기본 상태는 off이다. Buscot 시험에서는 사용하지 않는다. 적용은 `1D Diffusive`이다.<br>**`binarystartfile filename`**: `startfile`과 같지만 입력 자료가 이진(binary) 형식이다. 본문은 `startfile (above)`라고 적는다. 기본 상태는 off이다. 활성화하려면 키워드를 반드시 지정해야 한다. Buscot 시험에서는 사용하지 않는다. 적용은 `All 2D models and subgrid`이다. **`startelev filename`**: `startfile`과 유사하지만 수심 대신 수면 표고로 초기화한다. 기본 상태는 off이다. 활성화하려면 키워드를 반드시 지정해야 한다. Buscot 시험에서는 사용하지 않는다. 적용은 `All 2D models and subgrid`이다. **`startfile filename`**: 초기조건을 주는 이전 결과의 ARC ascii 래스터 파일. 수심 파일이어야 한다. 기본 상태는 off이다. Buscot 시험에서는 주석 처리되어 사용하지 않는다. 적용은 `All 2D models except Roe`이다.<br>다음 캡션은 `Table 10 Additional, less commonly used settings and parameters`이다. 이 쪽에는 Table 10의 열 머리만 있다. Table 10의 매개변수 행은 이 쪽에 없다. |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- p.1의 표지에는 `Code release 6.1.1`이 있다. p.2의 문서 정보 표에는 `Code release 6.0.4`가 있다. p.2–18의 머리말은 코드 릴리스를 **5.9.6**으로 표기한다. p.4의 본문은 `version 5.9.5`라고 적는다.
- p.4의 본문은 래스터 셀 사이 유동 계산에 `three options`가 있다고 적는다. p.10의 Table 1에는 Routing, Flow-limited, Adaptive, Acceleration, Roe의 다섯 해법 행이 있다.
- p.10의 식 (2) 첫 항은 `∂A/∂x`로 인쇄되어 있다. 확대 이미지에서도 분모는 `∂x`이다. 기록에는 인쇄된 분모를 그대로 옮겼다.
- p.11의 adaptive 설명은 안정 시간 간격의 비례 인자를 `(1/∆x)²`로 적는다. p.15의 Table 4는 격자 크기가 줄 때 adaptive 시간 간격이 제곱으로 줄어든다고 적는다.
- p.11의 acceleration 설명은 안정 시간 간격의 비례 인자를 `1/∆t`로 적는다. 같은 쪽은 `∆t`의 별도 기호 정의를 제시하지 않는다. p.15의 Table 4는 격자 크기가 줄 때 acceleration 시간 간격이 선형으로 줄어든다고 적는다.
- p.13의 본문은 배포 파일을 `14 files`라고 적는다. 같은 쪽 Table 3에는 파일명 행이 13개 있다. Windows 실행 파일 행은 32비트와 64비트 시스템용을 함께 언급한다.
- p.15의 본문은 `seventeen file types`라고 적는다. p.6–7의 입력 형식 목차에는 `3.2.1`부터 `3.2.24`까지 항목이 있다.
- p.18의 `startq` 설명은 `ch_dyanmic`를 참조한다. 같은 표의 실제 항목명은 `ch_dynamic`이다. 확대 이미지에서도 두 철자는 다르다.
- p.18의 `binarystartfile` 설명은 `startfile (above)`라고 적는다. 같은 표의 `startfile` 행은 `binarystartfile` 행보다 아래에 있다.
- p.18의 `startfile` 적용 열은 `All 2D models except Roe`이다. 같은 쪽의 `binarystartfile`·`startelev` 적용 열은 `All 2D models and subgrid`이다. 두 행에는 Roe 제외 문구가 없다.
- 지정 범위에서 인쇄된 식 번호는 p.10의 (1)과 (2)이다. 번호 없는 수식 표기는 p.10의 두 기울기와 p.11의 한 기울기·두 시간 간격 비례식이다.
- p.10의 수식 첨자는 확대하여 확인했다. p.14의 마찰계수 첨자는 확대하여 $N_c$와 $N_{fp}$로 확인했다. 이미지로도 판독할 수 없는 항목은 없었다. 열지 못한 쪽 이미지는 없었다.
