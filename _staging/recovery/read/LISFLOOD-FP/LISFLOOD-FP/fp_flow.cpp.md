## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 121·127–128: CalcFPQx의 주석은 서쪽 이웃이라고 적는다. 실제 p1 계산은 i+1을 사용한다.
- 142·157·160·227·257·273·276·343: 두 방향 모두 경사 계산에는 dx, 유량 폭과 적응 시간 간격(adaptive timestep)에는 dy, 유속 환산에는 dx를 사용한다.
- 25–26·47–51·95–99: acceleration과 Roe의 시간 간격 갱신은 독립 if 문이다. 유량 선택은 같은 셀에서 acceleration을 Roe보다 먼저 검사한다.
- 158–175·199–216·274–291·316–333: 각 유량 함수는 adaptive_ts가 ON이 아니면 Qlim을 계산한다. 이 내부 분기에는 qlim 플래그 검사가 없다.
