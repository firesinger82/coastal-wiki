# Celeris code-1 전수 대조 (11-04)

대상 5개 기록의 대조를 완료했다.
원문은 각 기록의 `file:` 경로를 사용했다.
원문 4960행을 `nl -ba`와 `sed -n`으로 200행 이하 구간으로 열어 대조했다.
구간 표의 123행과 기록 끝의 부가 사실 26행을 확인했다.
백틱 인용은 문자열과 원문 행 번호를 대조했다.
입력 항목의 id·value·option 인용은 원문에서 역으로 찾아 누락 여부를 확인했다.
원문 SHA-256은 각 frontmatter 값과 일치했다.
구간 경계와 frontmatter를 유지했다.
원문·노트·git은 수정하지 않았다.
모델은 실행하지 않았다.
