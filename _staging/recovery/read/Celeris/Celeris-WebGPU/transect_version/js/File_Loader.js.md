## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 39–41·121–123·181–183: 행 배열에 접근하기 전에 입력 행 수를 검사하는 문장은 각 판독 루프에 없다. 열 수 검사와 NaN 검사는 있다.
- 59–78: 앞쪽 평탄화는 인덱스 0–2에 내부 인덱스 4를 복사한다. 뒤쪽 평탄화는 마지막 네 인덱스에 `WIDTH - 5` 또는 `HEIGHT - 5`를 복사한다.
- 230–235: 일반 파 데이터 로더는 선언한 파 개수와 데이터 행 개수의 일치 검사를 수행하지 않는다. `loadTransectWaveData`는 각 행의 파 개수를 검사한다(185–188).
- 319: Google Maps API 키 문자열이 하드코딩되어 있다. 해당 행의 주석에는 배포 전 제거하고 입력값으로 만들라는 문구가 있다.
- 345–357: `fetchMapImage`는 응답 상태 검사와 이미지 오류 처리 콜백 없이 응답 Blob 및 onload를 사용한다.
- 265–270·363–383: `CreateGoogleMapImage`는 `device`·`context` 인수를 본문에서 사용하지 않고 이미지를 반환한다. `createTextureFromImage`는 정의되어 있지만 이 파일에 호출문이 없다.
- 452: `globalYCenter` 계산 결과는 이후 식에서 사용하지 않는다.
