## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 9: 유니폼 visibility는 VERTEX와 FRAGMENT이다. 같은 행 주석은 fragment stage에만 공개한다고 적는다.
- 40–46: 4번 주석은 샘플러라고 적는다. 실제 선언은 비필터 float 텍스처이다.
- 157–162: 17번 샘플러 주석은 linear와 nearest-neighbor를 함께 적는다. 실제 type은 `filtering`이다.
- 267–273: 로고를 그리는 분기는 `ShowLogos == 0`일 때 실행한다.
- 297–320·322: 라벨 사전에는 ID 19·20 항목이 없다. 선택값에 대한 별도 기본 라벨 분기는 이 루틴에 없다.
- 330·338–344·363–375: 눈금선은 다섯 개를 그린다. 숫자 라벨은 최솟값·간격 1배·간격 3배·최댓값의 네 개를 그린다.
- 266–380: 인수 `ctx`와 `offscreenCanvas`를 받아 그리지만 이 루틴에 전체 캔버스를 지우는 호출은 없다.
