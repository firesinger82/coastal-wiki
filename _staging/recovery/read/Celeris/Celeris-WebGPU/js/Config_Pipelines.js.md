## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 6–18·22–282: 계산 파이프라인 생성 함수만 allComputePipelines 인수를 받아 add한다. 다섯 렌더 파이프라인 생성 함수에는 이 집합 인수와 add 호출이 없다.
- 22·53–57·61·103–107·111·141–145·156·196–200·211·276–280: 깊이 형식 기본값은 모두 depth24plus다. 각 깊이 객체는 depthFormat && {...} 형태다.
- 55–56·105–106·143–144·198–199·278–279: 일반·격자 렌더는 깊이 쓰기 true와 less, skybox는 false와 less-equal, model·duck은 true와 less-equal을 지정한다.
- 1–283: 이 파일은 셰이더 코드와 바인드 그룹 레이아웃을 인수로 받는다. createBindGroup·dispatchWorkgroups·텍스처/버퍼 생성·균일 버퍼 쓰기·시간 단계 패스 호출은 이 파일에 없다.
