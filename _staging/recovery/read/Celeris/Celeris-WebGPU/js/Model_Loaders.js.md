## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 77·119: 바이너리는 gltf.buffers[0]만 읽는다. 기하는 gltf.meshes[0].primitives[0]만 읽는다.
- 187–223: accessor 배열은 byteOffset과 count * comps로 연속 뷰를 만든다. 이 루틴에는 byteStride·sparse를 처리하는 분기가 없다.
- 84–116·156–160: textures 배열은 gltf.images 순서로 생성한다. 기본색 index로 textures를 직접 조회하며 이 파일에는 gltf.textures의 source를 조회하는 문장이 없다.
