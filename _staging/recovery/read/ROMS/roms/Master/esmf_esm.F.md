## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 4·67–71: 모듈 구현은 !defined CMEPS 조건 안에 있다. 같은 구현 내부에는 # ifdef CMEPS로 cmeps_roms_mod를 선택하는 USE 분기가 있다.
- 256–330·334–338: 활성 모델의 SELECT CASE에는 OCN·조건부 ATM/ICE/WAV/DAT만 있고 CASE DEFAULT가 없다. 이후 DebugLevel>0 분기는 SELECT CASE의 model을 사용한다.
- 395·409: 재시작과 일반 시작 시계 생성의 refTime=ClockInfo(Idriver)%ReferenceTime 인수는 모두 주석 처리되어 있다.
- 575–584: 두 결합 시간 간격은 실수 Time_Step의 .ne. 비교로 검사한다. 이 조건에는 허용 오차를 적용하는 식이 없다.
- 598: 디버그 출력 뒤 FLUSH 대상은 고정된 Fortran 단위 6이다.
