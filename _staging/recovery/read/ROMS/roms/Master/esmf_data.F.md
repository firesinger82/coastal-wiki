## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 569–588·971–978: 세 ESMF_TimeGet 호출에는 rc=rc 인수가 없다. 호출 직후 ESMF_LogFoundError 검사는 기존 rc를 검사한다.
- 486–522·527·530–531: CONCURRENT 분기는 ROMS 병렬 관련 배열과 OCN_COMM_WORLD를 DATA 통신자 값으로 설정한다. 별도 log.data 파일을 여는 문장은 주석 처리되어 있다.
- 1080–1087·1121–1148: 달력 SELECT CASE에는 gregorian과 year_360_day/360_day만 있고 CASE DEFAULT가 없다. DATA 시작 시각을 설정하는 IF에는 ELSE가 없다.
- 1238–1477: DATA_SetGridArrays의 ExportCount는 인수 선언 이후 실행문에서 참조하지 않는다. grid를 컴포넌트에 설정하는 ESMF_GridCompSet 호출은 주석 처리되어 있다(1456–1458).
- 1645–1684: TIME_INTERP_NOT_WORKING 분기는 ESMF_AttributeLink에 ExportState를 전달한다(1677). DATA_SetStates의 인수 목록에는 ExportState가 없고 이 루틴의 지역 변수에도 ExportState 선언이 없다(1479–1514). 이 분기의 전처리·빌드는 확인하지 않았다.
- 1785–1786·1941–1978: DATA_ModelAdvance의 주석은 DATA_run으로 진행한다고 적는다. 실행문은 DATA_ncread와 DATA_Export를 호출하며 DATA_run 호출은 없다.
- 1547–1556·1616–1622·2326–2349: DATA_SetStates는 모든 생성 필드의 arraySpec를 rank=2·ESMF_STAGGERLOC_CENTER로 설정한다. DATA_Export에는 Nvdim=3인 필드의 ptr3d를 얻는 분기도 있다. 해당 분기의 실제 입력과 실행은 확인하지 않았다.
- 2291·2465–2472: DATA_Export는 field_index 반환값 id를 ImportField(id)에 사용한다. 이 사용 앞에는 id>0 조건 검사가 없다.
- 2325–2422: MyFmin/MyFmax는 각 localDE에서 해당 DE의 첫 값으로 다시 초기화한다. ESMF_VMAllReduce 호출은 DE_LOOP 뒤에 있다(2426–2444).
- 2840–2848: 가중치 주석에는 nearest millisecond integer toward zero라고 적혀 있다. 실행식은 fac1과 fac2에 ANINT를 사용한다.
- 2991–2992·3267: DATA_ncread의 lvar는 MIN(43,LEN_TRIM(longname))으로 대입하지만 이후 참조하지 않는다. ZL은 깊이 수준 판독에 쓰며 별도 정수 i도 날짜 저장에 쓴다.
- 3119–3291·3298–3305: Trec<=Nrec 조건은 시간 좌표·필드 판독을 감싼다. Tdelta·Tmono·Tintrp·Vtime 갱신은 이 조건 밖의 판독 요청 분기에서 실행한다.
- 3433–3436·3450–3458: 각 다중 파일을 조사할 때 Lcheck와 Tscale은 같은 지역 변수에 받는다. 파일 선택 루프는 마지막 조사에서 남은 Lcheck와 Tscale을 사용한다.
- 3723–3730: 시간 변수 탐색의 units 검사는 lowercase를 사용한다(3677–3679). Tscale 선택의 day/hour/second 검사는 원래 var_Achar 문자열을 그대로 사용한다.
- 3920–3929: 다음 파일 번호는 기존 Fcount+1이다. 범위 검사 조건은 (1.gt.Fcount).and.(Fcount.gt.IFS(ifile)%Nfiles)로 두 비교를 AND로 결합한다.
- 3867·3951: DATA_inquiry는 Fcount=0 오류 메시지에서 지역 문자열 label을 출력한다. 선언 이후 이 출력 전 label에 값을 대입하는 문장이 없다.
- 4019·4041–4043·4080–4087: DATA_inquiry는 내보내기 Nvdim을 2로 고정한다. HYCOM 특별 처리는 전역 문자열에 HYCOM이 있고 수평 크기가 4500×3298일 때 마지막 행을 버린다. 해당 자료의 깊이 차원이 여러 수준이면 Zlevel=1을 선택한다.
- 3861·3895–3909·4231–4262·4287: 지역 Tscale은 units CASE 안에서만 대입한다. 시간 변수 속성에 units가 없을 때의 별도 기본 Tscale 대입은 이 루틴 앞부분에 없으며 TimeValue 배율 계산에 Tscale을 사용한다.
- 3791–4576: DATA_inquiry의 nctname은 인수 선언 이후 실행문에서 참조하지 않는다. LowerBound는 거짓/참 대입만 있고 조건에서 참조하지 않는다(3897·4305).

- 4522–4523: 순환 시간의 한 분기에서 Tmono 계산은 인수 Tcurrent와 mod_scalars의 tdays(ng)를 함께 사용한다.
