## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 49–56: STATIC와 EXEC 기본 on 설정은 SHARED와 STATIC가 모두 비어 있는 중첩 조건 안에 있다. STATIC가 이미 설정된 경우 이 기본값 블록은 EXEC를 설정하지 않는다.
- 199–207: 주석은 libraries를 ROMS/Utility 라이브러리로 초기화한다고 적는다. 207행의 실제 대입은 빈 값이다.
- 251·257–258·376–377: COMPILERS는 사용자 지정 가능한 기본 경로이다. 컴파일러 규칙 포함에는 COMPILERS를 쓰지만 내부 매크로 전처리 입력 경로는 Compilers/make_macros.h로 직접 적는다.
- 253·260–265·572·617: MAKE_MACROS는 HOME 아래 make_macros.mk 한 경로이다. GET_MACROS는 BUILD_DIR/make_macros.*를 검색하지만 참 분기에서 포함하는 파일명은 make_macros.mk로 고정한다.
- 278–282·288–289·302–303: 소스·오브젝트·전처리 출력 경로 변환은 notdir로 원래 디렉터리를 제거한다. 서로 다른 디렉터리에서 같은 파일명을 가진 입력의 처리 결과는 이 파일만으로 확인하지 않았다.
- 449–458 및 479–486: modules 공통 목록에는 ROMS/Nonlinear/WEC와 ROMS/Modules가 있다. includes 공통 목록에는 이 두 경로가 없다.
- 550: MYLIB는 libroms.a로 대입한다. 이 파일의 다른 행에는 MYLIB 참조가 없다.
- 593·598·603: tarfile·zipfile·gzipfile 명령은 각각 roms-4_2.tar·roms-4_2.zip·roms-4_2.gzip 문자열을 직접 적는다. gzipfile의 실행문은 gzip -v roms-4_2.gzip *이다.
