## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 303·276·315: Hcount 판독의 PIO case 조건은 `# if defined PIO_LIB && defined DISTRIBUT` (303)이다. 인접한 Htime·CosW_sum 판독 조건은 `# if defined PIO_LIB && defined DISTRIBUTE` (276·315)이다. 전처리 이름의 마지막 E 유무가 다르다.
- 87·388·448·507·569·630·692: pioVar는 지역 포인터로 선언한다(87). PIO 입력 블록은 pioVar%vd에 연결 대입을 수행한다. 이 파일에는 pioVar 자체를 대상으로 하는 연결 대입이나 ALLOCATE 문이 없다.
- 150–179·190–243: 조석 입력은 time(ng)를 8640000.0_r8로 설정한다(151·191). 시간 복원은 각 입력 묶음의 끝에 있다(178–179·242–243). 중간 FoundError 반환 경로에는 시간 복원문이 없다(164·176·204·216·228·240).
- 269–283·297–309·370–411·430–470·489–529·550–592·611–653·673–715: HAR%IOtype의 SELECT CASE는 io_nf90와 전처리 조건부 io_pio만 갖는다. CASE DEFAULT는 없다.
- 71: varid는 지역 정수로 선언하지만 이 파일에서 그 뒤에 참조하거나 대입하는 문장이 없다.
- 63–64·130–811: update는 길이 3으로 선언한다. 입력 호출은 update(1)만 사용하며 update(2)·update(3) 참조는 없다.
