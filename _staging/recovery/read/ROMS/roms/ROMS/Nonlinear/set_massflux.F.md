## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 318–345·353–380: reset_massflux_tile은 DC(:,0)에 층별 두께·메트릭을 누적한 뒤 역수를 계산한다(340,375). 두 역수 대입 앞에 DC(:,0)==0 검사나 하한 대입은 이 블록에 없다.
- 143–159·329–331·364–366: set_massflux_tile은 nrhs 시각 속도를 사용한다. reset_massflux_tile은 기존 플럭스와 nnew 시각 속도 플럭스를 0.5_r8로 평균한다. WEC 기여도 reset 경로에서는 0.5_r8*u_stokes*DC 또는 0.5_r8*v_stokes*DC로 더한다.
