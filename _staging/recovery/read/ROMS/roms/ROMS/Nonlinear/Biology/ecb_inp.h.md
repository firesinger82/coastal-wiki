## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 242·265: SELECT CASE 안에 `CASE ('Vadvection')`가 두 번 있다. 265행 항목은 ADJOINT·TANGENT·TL_IOMS 중 하나가 정의될 때 포함되며 ad_Vadvection을 load_tadv에 전달한다(272–275).
- 266: ad_Vadvection을 읽는 분기의 조건 줄은 `IF (itracer.lt.(NBT) THEN`이다. 다른 세 이류 분기의 조건 줄은 `IF (itracer.lt.NBT) THEN`이다(232·243·255).
- 323–364·365–380·381–394·395–400: Hout의 세 추적자 ID 블록과 Qout(idsurT)는 ID=0 검사·exit_flag=5·RETURN을 둔다. Qout(idTvar)·Qout(idzslT)·Qout(idTsur)는 해당 대입 앞에 같은 ID=0 검사를 두지 않는다.
- 90–91·100–101: K_PO4와 R_P2N 입력 CASE에는 PO4 전처리 조건이 없다.
- 69–685: load_l/load_i/load_r/load_tadv/load_lbc의 반환값은 Npts에 대입한다. 이 입력 SELECT CASE에는 Npts 값에 대한 조건 검사가 없다.
- 1069–1074: X 확산 보고 루프는 itrc=idbio(i)를 설정한다. Dout 조건은 idDtrc(i,iTxdif)를 사용하고 변수 설명은 idTvar(itrc)를 사용한다.
- 699–1122·1131–1150: 보고는 Master·Lwrite·Lbiology 조건 안에 있다. 뒤의 nl_tnu4 제곱근 변환과 Tnudg 역수 변환은 그 조건 밖에서 모든 격자·생물 추적자에 수행한다.
