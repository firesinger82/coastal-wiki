## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 313·324–347: 무조건 CASE ('Vadvection')와 ADJOINT/TANGENT/TL_IOMS 안 CASE ('Vadvection')의 문자열이 같다. 조건부 CASE는 ad_Vadvection으로 load_tadv를 호출한다(343–346).
- 440–441·448–449·470–471·456–462: Qout 입력에서 idTvar·idzslT·idTsur에는 해당 CASE 내 식별자 0 검사가 없다. idsurT에는 0 검사와 exit_flag=5/RETURN이 있다.
- 645–647·672–674: AlphaPL과 KSiL 출력 설명은 모두 Small phytoplankton으로 시작한다.
- 153–166·754–772: Holling 계수 입력 CASE는 일곱 개이다. 해당 보고 분기에는 KZS2ZL WRITE가 없고 여섯 계수만 출력한다.
- 173–174·780–785: ZS2ZLstar 입력 CASE가 있다. 보고 else는 PL2ZLstar 변수와 문자열을 두 번 출력하며, 두 번째 설명은 소형 동물플랑크톤 섭식이다.
- 796–801: PusaiPL/PusaiZS 출력 이름 문자열은 PusauPL/PusauZS이다. 단위 설명은 mmole_N/m3이다. 앞선 PusaiS/PusaiL 출력 단위는 m3/mmole_N이다(675–680).
- 1129–1131: X 확산 진단 출력 조건은 idDtrc(i,iTxdif)이다. 직전 itrc=idbio(i)를 설정하며 다른 확산 진단 조건은 itrc를 사용한다(1124·1138·1146·1155).
- 32·66–609: load 계열 반환값을 Npts에 저장한다. 이 파일에는 Npts 값을 검사하는 IF가 없다.
- 64–613: 키 선택에는 CASE DEFAULT가 없다. 이 파일의 생물 매개변수 입력 CASE에는 값의 상한·하한 검사나 기본값 설정이 없다. load 계열 내부 처리는 판독하지 않았다.
