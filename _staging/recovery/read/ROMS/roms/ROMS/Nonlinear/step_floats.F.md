## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 283–286·516–519: i2의 하한은 1이고 j2의 하한은 0이다. i1·j1의 하한은 0이다.
- 317–342·553–575: 수직 층 검색은 곱이 0 이상인 각 층에서 izgrd를 대입한다. 대입 후 EXIT 문은 없으며 cff6을 갱신하고 다음 층을 계속 검사한다. 대입식에는 cff6-cff5 분모가 있고 이 분모의 0 검사는 해당 블록에 없다.
- 390–406·792–808: 생물 옵션의 i1oHz는 보간한 Hz의 역수로 바뀐다. 역수 대입 조건은 my_thread.and.bounded이며 해당 블록에는 보간 Hz가 0인지 검사하는 조건이 없다.
- 631–634·685–688·705–710: 상태 판정은 상한 Lm/Mm+0.5 이상에서 bounded를 거짓으로 둔다. 새 방출 위치 검사는 같은 상한을 초과할 때 거짓으로 둔다.
