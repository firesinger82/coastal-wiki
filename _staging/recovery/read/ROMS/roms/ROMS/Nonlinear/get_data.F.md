## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 63·108–1632: update는 길이 3으로 선언되지만 이 파일의 입력 호출은 모두 update(1)만 전달한다. update(2)와 update(3)을 참조하는 실행문은 이 파일에 없다.
- 335–346: WAVES_BOT_PERIOD 입력은 Pwave_botG(:,:,1)로 마지막 차원의 첫 슬라이스를 지정한다. 다른 파랑 속성 입력은 DwaveG·HwaveG 등의 전체 배열을 전달한다(247–331·352–388).
- 150–157·164–188·414–424·450–460·589–617: Lprocess는 인용한 선행 플럭스 조건에서 Nrun.eq.1일 때만 참이다. 바람 입력은 Lprocess를 검사한다. cloudG·srflxG_avg·sstG·dqdtG 입력에는 Lprocess 검사가 없다.
- 90–97·115–1632·1638–1645: PROFILE의 wclock_on은 첫 입력 호출 전에 있다. 입력 호출 뒤 오류 분기는 즉시 RETURN을 수행한다. wclock_off는 루틴 끝에 있으며 각 오류 RETURN 앞에는 별도의 wclock_off 호출이 없다.
