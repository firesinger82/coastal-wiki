## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 69·146–162·888·964–983: t2dgrd/u2dgrd/v2dgrd는 optional 인수이다. 이를 참조하는 격자 선택 블록 앞에 PRESENT 검사는 없다. 정점 pgrd도 optional 선언이며 def_var에 직접 전달한다(599·653–657·678–682).
- 110–117·241–251·931–938·1071–1081: Vinfo 초기화는 각 정의 흐름의 루프 밖에서 수행한다. 내부 필드 루프에서 Vinfo(11:12)는 특정 CASE에서만 재설정한다. CASE DEFAULT 및 그 속성을 공백으로 되돌리는 문장은 이 선택문에 없다.
- 175·195·475·997·1020·1345: 동향/북향 속도 변수 정의는 각각의 VarOut로 선택한다. 두 속도를 쓰는 조건은 두 VarOut의 논리곱이다.
- 422–431·546–555·1280–1289·1425–1434: iceField 포인터 선택은 비선형 HIS/QCK/RST 및 AVERAGES의 AVG 분기만 가진다. 그 외 파일/모델에 대한 ELSE 연결이나 이 루틴 입구의 NULLIFY 문장은 없다.
- 491–492·1361–1362: 동향/북향 회전 출력은 Si의 IUOUT 해빙 속도를 참조한다. 이 회전 블록에는 AVG 여부로 ICE_SAVG를 고르는 분기가 없다.
- 825·850: 정점 상태 추출과 내부 필드 추출 모두 `extract_sta2d`에 r2dvar를 전달한다. 상태 루프는 isUice/isVice/isUevp/isVevp를 격자별로 나누는 SELECT CASE를 갖지 않는다(820–839).
- 945–962·1048–1068: PIO 정의에서 재시작 파일은 vtype=PIO_FRST를 선택한다. 같은 흐름의 pioVar dkind 대입은 PIO_FOUT이다.
- 964–983·1125–1132: PIO 새 변수 정의는 Uevp/Vevp도 u/v 격자로 지정한다. 기존 파일 조회의 상태 SELECT CASE는 isUice/isVice만 u/v 격자로 지정하고 나머지는 r2dvar로 지정한다.
- 1142·1147: 기존 PIO 파일 조회에서 idUiER의 dkind는 PIO_FOUT이고 idViNR의 dkind는 vtype이다.
- 1233·1259–1263: ice_wrt_pio는 gfactor를 설정하고 gtype을 선언한다. 이 루틴의 쓰기 호출은 ioDesc를 전달하며 gfactor/gtype을 이후 계산식이나 호출 인수에서 사용하지 않는다.
- 41·51·585–872·874–1467: `ice_def_station_pio`, `ice_wrt_station_pio`를 PUBLIC으로 선언한다. 이 파일의 정점 루틴 본문은 nf90 두 루틴이며, 해당 PIO 정점 이름의 SUBROUTINE 본문은 없다.
- 866–868: 정점 nf90 쓰기 오류 FORMAT 10을 정의한다. 해당 루틴에는 이 FORMAT을 사용하는 WRITE 문장이 없다.
