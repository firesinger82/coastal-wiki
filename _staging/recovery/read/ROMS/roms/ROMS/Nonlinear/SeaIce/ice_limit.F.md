## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 106–107·121–125: Tice 제한값 -70·0과 생물 상태 판정값 Aice=0.5·Hice=0.02·Ilog=-1/+1은 코드 상수이다.
- 109–116: 얼음 면적 또는 두께가 0 이하일 때 Aice·Hice·Hmel·Hsno·Iage를 0으로 둔다. 이 분기에 Tice·Enth·Hage를 0으로 만드는 문장은 없다.
- 105: Hmel은 0 하한만 적용한다. 이 파일에는 Hmel 상한을 적용하거나 max_hmelt를 참조하는 문장이 없다.
- 179·188·197·262–281: Iphy·INO3 경계 호출은 model을 전달하고 INH4 경계 호출은 iNLM을 전달한다. 병렬 교환 호출은 모두 iNLM을 전달한다.
- 237–256·262–281: 주기 교환 목록은 Iage와 조건부 Ilog를 포함한다. mp_exchange2d의 병렬 교환 목록에는 Iage·Ilog가 없다.
