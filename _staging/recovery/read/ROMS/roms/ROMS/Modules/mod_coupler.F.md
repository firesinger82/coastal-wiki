## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 126–132: TimeInterval은 대칭 행렬이라는 주석이 있다. 그 주석의 예시는 TimeInterval(Iocean,Iatmos)를 자기 자신과 같다고 적으며 반대 인덱스의 원소를 적지 않는다.
- 30·46·198·271·316–325: Export/Import의 T_STRING code 길이는 10이다. Fields%code와 지역 code 길이는 40이다. 필드 ID 검색은 이 문자열들의 ADJUSTL/TRIM 결과를 비교한다.
- 35–50·271–278: T_FIELD에는 GridID/MaskID/ExpMin/ExpMax/ImpMin/ImpMax가 선언되어 있다. allocate_coupler의 Fields 대입 블록에는 이 여섯 성분의 대입이 없다. 다른 파일에서의 대입은 판독하지 않았다.
- 188·193: load와 ng는 지역 변수로 선언되지만 이 파일의 실행문에서 사용되지 않는다.
- 281–282·423–424: 입력 READ 오류 라벨 30의 WRITE는 문자열 TRIM(ADJUSTL(Vinfo(1))) 하나를 FORMAT 80에 전달한다. FORMAT 80은 프로세서 수를 나타내는 i3.3 정수 출력 두 개를 선언한다.
- 143·267–269·417–419: 필드 수 초과 조건은 MaxNumberFields를 검사한다. 대응하는 FORMAT 60의 안내문은 차원 상수를 MV라고 부르며 mod_ncparam.F 수정과 재컴파일을 안내한다.
- 299–305·322–329·335–346: ImportID는 최초 할당 때 0으로 초기화하고 일치하는 code가 있으면 FieldID를 복사한다. 이 루틴에는 미일치 ImportID를 검사하는 후속 조건이 없다. ExportID에는 id>0 검사와 불성립 시 STOP이 있다.
- 366–378: inode는 -1에서 시작하여 각 프로세서 배정마다 1 증가한다. 총 배정 수 비교는 inode+1을 사용한다. 불일치 보고의 FORMAT 80 호출은 inode를 전달한다.
- 385–391·401–407: 보고용 string의 선택 조건은 Iocean/Iwaves/Iatmos와 같은 model 번호 세 가지이다. 두 선택 블록에는 ELSE가 없고 각 WRITE 직전의 기본 string 대입도 없다.
