## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 165–185: mg 루프의 SELECT는 SSF(ng)%IOtype을 사용한다. 두 파일 조회 호출은 SSF(mg)%name을 사용한다.
- 153–199·215–243: ANA_PSOURCE 미정의 분기에서 Nsrc(mg)·Msrc(mg) 값 대입은 공급원 스위치 조건과 foundit 조건 안에 있다. 할당 직후 배열 전체 초기화 문장은 없으며, 이후 SOURCES(ng) 구성원 할당은 Nsrc(ng)를 사용한다.
- 202–206: 해석적 공급원 분기의 Msrc(ng)는 200으로 고정한다.
- 332·352–353: 루틴 이름은 deallocate_sources이다. MyFile 문자열의 루틴 부분은 deallocate_mixing이다.
- 133·171–185: ifile은 선언 뒤 참조되지 않는다. nvatt·nvdim·Vid·my_pioVar는 조회 출력 인수로 전달되지만 이 루틴의 후속 식에서는 참조되지 않는다.
- 477·498–523: Dsrc_min/Dsrc_max는 입력 호출의 출력 인수이며 후속 조건에서는 참조되지 않는다. 면 개수 조건은 실수 Dsrc의 INT 결과를 0·1·2와 비교한다. 다른 값 자체를 오류로 설정하는 조건은 이 루틴에 없다.
- 535–543: 두 오류 조건은 각각 LwSrc 거짓·LuvSrc 참, LuvSrc 거짓·LwSrc 참을 요구한다. 두 스위치가 모두 참인 경우에 대한 별도 오류 조건은 이 블록에 없다.
