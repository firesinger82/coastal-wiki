## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 161–164: SPLIT_4DVAR에서 Ldone을 선언한다. 이 파일에는 Ldone의 값 대입이나 참조가 없다.
- 594–655·1495–1511: 분할 실행에서 NLmodVal·ObsScale·ObsVal·ObsErr 판독에 ng=1을 사용한다(595·612·633·1497). 인접 주석은 중첩 격자 처리에 관한 질문을 남긴다(592·1495).
- 1010–1015·1257–1261: 초기화 단계 congrad 호출(1013) 바로 뒤에는 FoundError 반환 조건이 없다. 내부 계산의 congrad 호출(1259) 바로 뒤에는 FoundError 반환 조건이 있다(1260).
- 875–876·1166–1170·1648–1652: increment는 FrequentImpulse를 먼저 거짓으로 설정한다(876). FrcRec>3 조건 블록은 FrequentImpulse를 참으로 설정하며 ELSE 분기는 없다(1167–1169·1649–1651).
- 468·2055·2164·2226: increment의 driver 기본값은 'r4dvar'이다. posterior_error의 driver 기본값은 'w4dvar'이고 두 convolve 호출에 이 값을 전달한다.
- 1965–1973·1979–1984·2011–2019: multiscale_eigen·multiscale_eigen_write·normalization·multiscale_eigen_read 호출 바로 뒤에는 FoundError 반환 조건이 없다. 정규화 판독의 get_state 호출 바로 뒤에는 해당 조건이 있다(1991–1992·1995–1996·2001–2002·2007–2008).
- 2038–2040·2087·2132·2144·2185: posterior_error 주석은 단일 외부 반복에서만 작동한다고 적는다. 대각 성분·대각합·EOF 계산 루프의 외부 번호 범위는 모두 1..Nouter이다.
- 2203–2204·2206–2222: 주석은 inner=0 시작 벡터로 현재 레코드 1을 사용할 수 있다고 적는다. 실행 코드는 my_inner=0의 ELSE에서 random_ic를 호출한다(2216–2217).
- 1775–1782·2285–2287: analysis는 IOtype에 따라 HIS%ncid 또는 HIS%pioFile%fh를 -1로 설정한다. posterior_error 끝은 IOtype 분기 없이 HIS%ncid만 -1로 설정한다.

- 1717–1726: DATALESS_LOOPS의 NLM NLPenalty 로그도 RPM DataPenalty(i).ne.0.0_r8 조건 안에 있다. 이 로그 블록에는 NLPenalty 자체의 0 여부 조건이 없다.
