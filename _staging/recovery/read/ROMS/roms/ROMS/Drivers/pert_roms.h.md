## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 43–44·302–303: user(7:8)의 설명 주석은 J-index라고 적는다. 실행문은 이 두 입력을 KperTL과 KperAD에 대입한다.
- 295–307·384–387·499–502: user 입력을 INT로 변환한 뒤 변수와 좌표를 사용한다. 두 BOUNDED 식은 I/J의 프로세스 소유 범위만 검사한다. 이 파일의 해당 판독·선택 블록에는 user 배열 길이, 변수 번호 또는 K 인덱스의 허용 범위를 검사하는 조건이 없다.
