## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 347–348·379–391: Lini=1·Lbck=2이다. 초기장 저장 주석은 Lbck 기록을 적지만, 해당 블록은 INI(ng)%Rindex=1로 설정하고 wrt_ini의 마지막 인수도 1을 전달한다. wrt_ini 내부 처리는 이 파일에서 확인하지 않았다.
- 823–828·833–837·843–846·1409–1414: 첫 번째 내부 루프의 TLM 이력 인덱스 설정 843–846행은 ng 반복문 밖에 있다. 앞의 두 ng 반복문은 각각 828·836행에서 끝난다. 두 번째 내부 루프의 같은 설정은 ng=1..Ngrids 반복문 안에 있다.
- 317·889–892·1620–1624: 첫 번째 내부 루프 뒤 파일 종료는 nf90_close를 직접 호출하고 status에 반환값을 넣는다. 이 파일에는 status 검사문이 없다. 두 번째 외부 루프의 TLM 종료는 close_file 호출 뒤 FoundError를 검사한다.
- 1185–1210: 접선형 관측 판독 SELECT 뒤에는 FoundError 검사문이 없다. 판독 루프 뒤에는 Nrun=1·TLmodVal=0 대입이 이어진다. NetCDF 판독 루틴 내부 처리는 이 파일에서 확인하지 않았다.
- 321·298–1653: 지역 배열 Nrec는 선언 이후 참조가 없다. 구조체의 %Nrec는 여러 기록 초기화에서 사용한다.
- 1675·1684–1686: 재시작 주석은 record 3 저장을 설명한다. 해당 코드의 RST(ng)%Rindex 대입값은 2이다. wrt_rst 내부 처리는 이 파일에서 확인하지 않았다.
