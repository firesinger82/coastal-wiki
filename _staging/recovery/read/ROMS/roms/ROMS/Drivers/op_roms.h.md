## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 359–361·397–399: CHECKPOINTING의 지역 변수 LwrtGST는 선언과 .TRUE. 대입 이후 참조되지 않는다.
- 406–428·507–508: Nconv(ng)는 ng 인덱스가 없는 iaup2(4)에서 복사한다(428). NconvRitz(ng)는 iparam(5,ng)에서 복사한다(508). iaup2를 갱신하는 라이브러리 내부는 확인하지 않았다.
- 439–440: 체크포인트 조건은 MOD(iter,nGST)를 계산한다. 이 파일 안에는 nGST>0 검사문이 없다. nGST의 외부 입력 규칙은 확인하지 않았다.
- 458–488: 행렬·벡터 계산 선택은 배열 전체의 ANY(ABS(ido).eq.1)를 사용한다(458). 이 분기의 기록 초기화와 상태 포인터 연결은 모든 ng를 순회한다(459–485). propagator_op는 state·ad_state 배열 전체를 받는다(487).
- 490–500·546–556·835–900: info 오류 분기는 메시지를 출력하고 RETURN한다(498·554). 해당 분기와 IRAM_error에는 exit_flag 대입문이 없다.
- 523–524·533–534: 병렬 pdseupd 호출의 bmat 뒤 크기 인수는 Nsize(ng)이다(524). 직렬 dseupd 호출의 같은 위치에는 배열 Nsize가 적혀 있다(534). 라이브러리 인터페이스와 빌드는 확인하지 않았다.
- 565–607: 고유벡터 번호 i는 1..MAXVAL(NconvRitz)를 순회한다(565). 그 안의 ng 루프는 모든 격자의 Rvector(Is:Ie,i)와 RvalueR(i,ng)를 사용한다(585–607). 이 블록에는 i<=NconvRitz(ng) 검사문이 없다.
- 847–849·855–899: string은 intent(out) 인수이다. 오류 코드 선택에는 마지막 ELSE가 없고 초기값 대입도 없다. 나열하지 않은 info 값에는 string 대입문이 없다.
