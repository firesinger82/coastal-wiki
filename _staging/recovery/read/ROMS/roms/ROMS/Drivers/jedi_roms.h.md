## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 95·99·217·220: 루틴 이름은 ROMS_initializeP1이고 실행 Phase는 1이다. 99행 설명은 phase 2라고 적는다.
- 39–41·68–71: ad_post_initial의 USE는 TANGENT 조건 안에 있다. 같은 조건은 tl_post_initial·tl_bath의 USE도 감싼다. 이 파일에는 ad_post_initial 호출문이 없다.
- 110·222 및 351·382·433: P1과 run의 kernel 인수는 optional이다. 두 루틴은 kernel을 SELECT CASE에 사용하며 해당 사용 앞에 PRESENT(kernel) 검사가 없다.
- 222–233·273–284·320–331·382–429·433–444: 다섯 kernel 선택 블록에는 CASE DEFAULT가 없다.
- 360·385–386·402–403·419–420: ROMS_run은 NEXTtime·ENDtime을 계산한다. 이 루틴은 이후 두 값을 다른 계산이나 호출에 사용하지 않는다.
