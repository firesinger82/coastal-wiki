## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 124–125: MPI rank·size 조회는 같은 MyError 변수로 반환값을 받는다. 이 두 호출 뒤에는 MyError를 검사하는 실행문이 없다.
- 135–136·160–161·197–201: first를 거짓으로 바꾼 뒤 입력과 배열 초기화를 수행한다. 두 단계의 오류 반환 경로에는 first를 참으로 복원하는 대입이 없다.
- 247·251·628–629·636–640·658–671: 초기화 주석은 tangent linear model을 적지만 실제 호출은 ad_initial이다. 고유벡터·잔차 쓰기 주석은 nonlinear history file을 적지만 실제 호출과 구조는 ad_wrt_his·ADM이다.
- 364·401: CHECKPOINTING의 LwrtGST는 선언하고 참으로 대입하지만 ROMS_run의 이후 조건이나 호출에서 참조하지 않는다.
- 522–542: pdseupd의 표준 고유값 문제 크기 인수는 Nsize(ng)이다(527). 직렬 dseupd의 해당 위치는 `&                     sigmaR, bmat, Nsize, which, NEV, Ritz_tol,   &` (537)로 Nsize를 격자 인덱스 없이 전달한다.
- 511·584·620·649: Ritz 출력 반복은 MAXVAL(NconvRitz)까지 모든 격자를 순회한다. 격자별 Rvector와 RvalueR의 i 접근 앞에는 i≤NconvRitz(ng) 조건이 없다.
- 493–503·549–559: ARPACK의 비영 info 경로는 오류 메시지를 출력한 후 반환한다. 해당 경로에는 exit_flag를 비영으로 설정하는 대입이 없다.
- 442–443: 체크포인트 조건은 MOD(iter,nGST)를 사용한다. 이 파일의 해당 실행 경로에는 nGST의 0값 검사 조건이 없다.
- 849–851·857–899: IRAM_error의 string은 intent(out)이다. 열거한 info 값 이외를 처리하는 else나 공통 문자열 초기화는 없다.
