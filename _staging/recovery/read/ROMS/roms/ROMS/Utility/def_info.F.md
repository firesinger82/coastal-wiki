## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 16–50: DimIDs 설명 주석은 21번 다음에 23번을 적으며 22번 설명은 없다.
- 129–133·191–199 및 3757–3761·3821–3829: 생태군 차원 지역 변수의 선언 조건은 BIOLOGY/ECOSIM이고, 해당 차원 값을 복사하는 조건은 ECOSIM/SOLVE3D이다. cppdefs.h 내부의 조건 관계는 이 판독에 포함하지 않았다.
- 276·289–349 및 3909·3922–3982: 파일 종류 IF/ELSE IF 연쇄 직전에 type은 'CF-1.4, SGRID-0.3'으로 설정되어 있다. 해당 연쇄에는 어느 ID도 맞지 않을 때 별도 type을 대입하는 ELSE가 없다.
- 943–946·4576–4579: 두 루틴의 ADM_TADV 속성을 쓰는 tadv_putatt 호출에서 오류 로그는 'NLM_TADV'를 출력한다.
- 1169–1174·4802–4807: 두 루틴의 bio_file 전역 속성은 길이 512의 문자열을 '-'로 채운 뒤 기록한다.
- 2530–2541·6152–6163: 표준 NetCDF의 HdecayMX는 def_var에 차원 수 2와 (/statedim, scaledim/)을 전달한다. 표준 NetCDF의 HdecayMY는 차원 수 1과 같은 두 항목 차원 ID 배열을 전달한다. PIO의 HdecayMX·HdecayMY는 모두 차원 수 2와 해당 배열을 전달한다.
- 3889–3897: PIO format의 SELECT CASE는 pio_method 1·2와 3·4만 처리한다. CASE DEFAULT나 이 SELECT 바로 앞 type 초기화는 없다.
- 618–629·4251–4262: 표준 NetCDF의 nrm_file 전처리 조건에는 CORRELATION이 있다. PIO의 nrm_file 전처리 조건에는 CORRELATION이 없다.
- 5603 및 5586·5593·5614: PIO의 wec_alpha def_var는 자료형 인수로 NF_TYPE을 쓴다. 인접한 sz_alpha·CrgBan_cw는 PIO_TYPE을, Znudg는 PIO_TOUT을 쓴다. 해당 상수의 정의나 값 일치는 이 파일에서 확인하지 않았다.
- 7213–7220·7202–7211·7222–7231 및 3593–3602: PIO의 idmskV 정의 블록은 Vinfo(1,2,9,10,21)을 대입한다. 해당 블록에는 Vinfo(22)와 Aval(5) 대입이 없다. 인접 idmskU·idmskP와 표준 NetCDF의 idmskV 블록에는 두 대입이 있다. def_var 내부의 Vinfo·Aval 처리 방식은 이 판독에 포함하지 않았다.
- 3765–3767: PIO 루틴은 PARALLEL_IO가 없고 DISTRIBUTE가 있을 때 ibuffer(2)를 선언한다. 이 대상 파일의 PIO 루틴 본문에는 이후 ibuffer 대입·참조가 없다. 조건부 포함 헤더 내부는 판독하지 않았다.
