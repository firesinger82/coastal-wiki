## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 135·154: ad_vbar_sol은 ASSUMED_SHAPE 분기에서 intent(inout)이고 해당 else에서 intent(in)이다. 수반 수집 실행부에는 ad_vbar_sol에 대입하는 문장이 없다(340–344).
- 180–199: 시간 인덱스 식은 nADJ(ng)로 정수 나눗셈한다. 보간 가중치 식은 fac1+fac2의 역수를 사용한다. 이 계산 블록에는 해당 분모를 검사하는 조건문이 없다.
- 275–293·305–345·357–395: WEAK_NOINTERP 분기는 강제력 슬롯을 수반 값으로 덮어쓴다. 각 해당 else는 기존 강제력 슬롯에 fac1·fac2 가중 수반 값을 더한다.
- 503·507·518–578: frc_clear_tile은 it1·it2·kout·nout과 fac·fac1·fac2·time1·time2를 선언한다. 해당 루틴의 실행식에는 이 변수들의 참조가 없다.
