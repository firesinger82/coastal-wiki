## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 105–106·161–172: MyRval의 할당 크기와 load_r 판독 길이는 Nmodels다. i>j 쌍마다 ic를 증가시키는 루프의 MyRval 접근 개수는 루프 범위에서 계산하면 Nmodels*(Nmodels-1)/2다. 이 CASE에는 ic<=SIZE(MyRval) 검사가 없다.
- 133–145: OrderLabel CASE는 i=Nval인 슬롯만 대입한다. ocean/waves/atmos 판별은 INDEX의 부분 문자열 검사이며 #if와 무관한 IF/ELSE IF 순서로 첫 일치 모델만 설정한다.
- 203–241·257–295: Export/Import의 모든 code 크기는 해당 부모 배열이 처음 할당될 때의 Nexport/Nimport로 정한다. 부모 배열이 이미 할당된 경로에는 개별 code 크기를 다시 할당하는 문장이 없다.
- 37·60·87·3–307: Lwrite는 지역 선언과 두 입력 경로의 Master 대입 이후 사용되지 않는다.
- 40·3–307: 지역 정수 ng는 선언 이후 사용되지 않는다.
- 101–296: 입력 키 SELECT CASE에는 CASE DEFAULT가 없다.
