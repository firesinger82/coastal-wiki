## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 106: wrt_tides_nf90의 varid는 선언 이후 사용되지 않는다. 각 출력 호출은 HAR%Vid를 직접 넘긴다.
- 124·363–366·405·680–683: NetCDF의 시작 로그는 정수 ng를 FORMAT 20에 넘긴다. FORMAT 20은 변수명·파일명 문자 인수를 받는 오류 형식이다. 해당 루틴의 기록 로그 FORMAT 10은 참조하지 않는다. PIO의 시작 로그는 FORMAT 10을 지정한다.
- 386–395·491–494·520–523·549–552·580–583·610–613·641–644: wrt_tides_pio는 ioDesc에 포인터 연결을 수행한다. 이 루틴의 지역 선언에는 ioDesc 선언이 없다. USE로 가져오는 모듈의 선언 내부는 이 파일 판독에 포함하지 않았다.
- 330–339·641–656: NetCDF 추적자 출력은 gtype=r3dvar와 GRID%vmask를 함께 전달한다. PIO 추적자 출력도 r3dhar 기술자와 GRID%vmask를 함께 전달한다.
- 610–625: PIO 3차원 V 출력의 ioDesc 선택 조건은 pioVar(idFsuH)%dkind를 검사한다. 이어지는 출력 호출은 idv3dH·pioVar(idv3dH)를 전달한다.
- 638–648: PIO 추적자 루프의 자료형 선택 조건은 pioVar(idTrcH)%dkind를 사용하며 idTrcH에 itrc 인덱스를 붙이지 않는다. 같은 루프의 출력 호출은 idTrcH(itrc)·pioVar(idTrcH(itrc))를 사용한다.
