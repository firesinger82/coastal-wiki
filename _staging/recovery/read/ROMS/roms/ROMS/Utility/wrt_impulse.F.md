## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 83–91·262–269·830–837: 입출력 경로를 고르는 SELECT CASE의 대상은 LZE(ng)%IOtype이다. 자유수면 출력 호출의 파일 객체는 NetCDF 경로의 TLF(ng)%ncid와 PIO 경로의 TLF(ng)%pioFile이다. 두 객체의 설정 관계는 이 파일에 보이지 않는다.
- 123–124·669–671: wrt_impulse_nf90의 varid·ibuffer(2)와 wrt_impulse_pio의 INPncid·ibuffer(2)는 이 파일에 보이는 본문에서 선언 이후 사용되지 않는다. 136·688행에서 포함하는 set_bounds.h 내부는 판독하지 않았다.
- 217–221·771–775: 시간 변수 부재 분기는 exit_flag=2를 설정한 뒤 RETURN 없이 다음 자유수면 처리 블록으로 이어진다. 자유수면 변수 부재 분기에는 exit_flag=2 뒤 RETURN이 있다(279–284·847–852).
- 175–179·242–249·270–278·283·609 및 727–731·805–812·838–846·851·1250: 입력 파일 열기 이후 자유수면 읽기·쓰기 오류 또는 변수 부재 경로는 RETURN한다. 해당 RETURN 앞에는 이 파일에 보이는 입력 파일 닫기 호출이 없다. 정상 흐름의 입력 파일 닫기 호출은 609·1250행에 있다. 호출 루틴 내부의 파일 처리는 판독하지 않았다.
- 622·1263: netcdf_sync와 pio_netcdf_sync 호출은 파일명 인수로 INPncname을 전달한다. 같은 호출의 파일 식별자·객체 인수는 TLF(ng)%ncid·TLF(ng)%pioFile이다. 동기화 호출 내부의 인수 사용은 판독하지 않았다.
- 782·861·938·1017·1094·1173: PIO 입력 기술자 선택은 각 OCEAN 수반 배열의 KIND가 숫자 8과 같은지 검사한다. 참 분기는 PIO_double과 ioDesc_dp 계열을 선택한다. ELSE는 PIO_real과 ioDesc_sp 계열을 선택한다. 출력 기술자는 출력 변수의 dkind를 PIO_double과 비교해 선택한다(824·903·980·1059·1136·1215).
- 227·261·292·326·355·389 및 420–454·482–516·546–580: NetCDF 2차원 경로는 읽기 전과 쓰기 전에 MyType=gtype을 각각 대입한다. NetCDF 3차원 경로는 읽기 전에 MyType=gtype을 대입하며 읽기와 쓰기 사이에는 같은 재대입이 없다. nf_fread2d·nf_fread3d 내부에서 MyType을 변경하는지는 판독하지 않았다.
