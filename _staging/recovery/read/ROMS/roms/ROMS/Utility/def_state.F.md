## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 20·58·175·850: 입력 설명 주석의 스위치 이름은 ldef이다. 실제 인수와 생성·조회 분기는 Lcreate를 사용한다.
- 80·89: 입출력 방식 선택은 S(ng)%IOtype을 사용한다. CASE DEFAULT의 로그는 AVG(ng)%IOtype을 출력한다.
- 120–121·1115–1116: nrec·nvd·varid는 각 루틴에서 선언되지만 이 파일의 이후 실행문에는 등장하지 않는다. w3dgrd는 선언·차원 대입(134·462–468·1129·1457–1463) 이후 def_var 인수로 사용되지 않는다.
- 258–264·1253–1259: N와 s_rho 차원 정의는 모두 DimIDs(9)를 출력 위치로 사용한다. s_rho 정의가 N 정의 다음에 실행된다.
- 383–388·423–428·450–455·1378–1383·1418–1423·1445–1450: t3dfrc·u3dfrc·v3dfrc의 차원 대입은 WRITE_WATER && MASKING의 else 안에 있다. 이 벡터를 받는 플럭스·응력 def_var 블록(751–817·1798–1875)에는 그 else 조건이 없다. 포함 파일의 옵션 조합 제한은 이 판독 범위에서 확인하지 않았다.
- 532·569·606·644·681·728·1535·1580·1625·1671·1716·1771: 경계 변수 생성은 ANY(Lobc(...)) 조건을 사용한다. 기존 파일의 경계 변수 누락 검사(985–1002·1032–1042·1054–1060·2076–2093·2123–2133·2145–2151)는 Lobc 조건을 사용하지 않는다.
- 1038–1042·2129–2133: idSbry(isVvel) 누락 분기는 로그 뒤 RETURN한다. 바로 앞 idSbry(isUvel) 누락 분기(1032–1037·2123–2128)에 있는 exit_flag=3 대입은 이 두 v경계 분기에 없다.
- 1523·1950: PIO 자유수면 변수의 신규 정의는 dkind=PIO_FOUT을 사용한다. 같은 변수의 기존 파일 조회는 dkind=PIO_TOUT을 저장한다.
