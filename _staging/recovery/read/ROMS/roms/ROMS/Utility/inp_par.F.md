- 282–304: 추출 차원 초기화 대상은 xtr_Lm과 xtr_Mm이다. xi_rho 뒤 오류 조건은 xtr_Lm=0이며 eta_rho 뒤 오류 조건은 xtr_Jm=0이다. xtr_Jm 대입은 eta_rho 이름이 일치한 분기 안에 있다(289–292).
- 295–306: 추출 차원 오류 출력 두 곳은 FORMAT 20을 지정한다(296·301). 같은 블록에는 차원 질의 오류 문구의 FORMAT 45가 별도로 선언되어 있다(305–306).
- 543–552: read_VegPar 호출 바로 뒤에는 FoundError 검사가 없다. 인접 read_StaPar 호출 바로 뒤에는 FoundError 검사가 있다(539–540).
- 235–237·249–251·657–665·681–705: 이 파일의 LprocessOBC/LprocessTides/Lsponge/Lclimatology/Lnudging 설정 블록은 조건이 참일 때 TRUE를 대입한다. 조건이 거짓일 때 FALSE를 대입하는 대응 ELSE는 이 블록들에 없다.
- 612–615·855–858·887–892: 기후장 메타데이터의 varid>MV 경로는 정수 MV·varid를 WRITE(stdout,130)에 넘긴다(856). FORMAT 130은 횡방향 경계 조건 제목이며 첫 편집 기술자는 a이다(612). 너징 메타데이터의 같은 초과 검사는 두 정수를 받는 FORMAT 140을 쓴다(888–891).
- 934–935: ran_seed에 넘기는 sequence는 매 호출 759로 대입한다.
