## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 165–167: 입력 깊이가 z_w(i,j,0)보다 작으면 zfloat를 `z_w(i,j,0)+5.0_r8`로 바꾼다. 5.0_r8은 이 식에 직접 적힌 상수이다. Fz0는 160행의 Save original value 주석이 붙은 대입 뒤에도 이 보정값으로 다시 대입된다.
- 143–145·161·169–177·193–194: 주석은 초기 깊이를 찾지 못하면 표면 모델 층을 사용한다고 적는다. 코드는 Kflt(l)를 먼저 입력 zfloat로 설정하고, 표면 층 번호 N(ng)는 Tinfo(izgrd,l)에 설정한다. 층 검색 조건이 한 번도 참이 되지 않으면 Kflt(l)에 N(ng)를 대입하는 문장은 없다. 후속 루프는 Tinfo(izgrd,l)를 Kflt(l)로 대입한다.
- 163–175: 수직 좌표 계산은 수평 소수 좌표의 INT 결과 i/j를 사용한다. 이 계산 블록의 z_w와 Hz 참조에는 한 셀의 i/j만 들어간다. 이 블록에 수평 보간식은 없다.
- 2–3·243–246: FLOATS 또는 STATIONS 조건의 루틴은 ng/model 인수를 받는다. 두 전처리 조건이 모두 정의되지 않은 경로의 루틴 선언에는 인수가 없다.
