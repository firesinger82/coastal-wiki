## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 41–44·49–53·107–186·279–358: MINRES 경로에 info와 ipiv를 선언한다. 이 파일에는 이 두 변수를 사용하는 실행문이 없다.
- 76–80·252–256: RPCG의 zfact는 cg_QG 또는 cg_beta로 나눈다. 해당 대입 앞에는 분모의 0 검사문이 없다.
- 90–101·213–225·266–273·385–397: 관측 오차 사용 조건은 ObsErr!=0이다. RPCG 불성립 경로는 SQRT(ObsErr)를 사용하며, 이 블록의 조건은 ObsErr>0이 아니다.
- 145–161·317–333: zgk 제곱근과 zLTt 대각값으로 나누는 식이 있다. 이 계산 블록에는 해당 분모의 0 검사문이 없다.
- 191–201·363–373: MINRES 불성립 풀이에서 zbet는 cg_delta와 cg_beta로 갱신되며 zu와 zgam의 분모가 된다. 이 블록에 zbet의 0 검사문은 없다.
- 57–69·211–225 및 235–245·383–397: IMPACT_INNER 경로는 ad_ObsVal(iobs,mloop)를 사용한다. 해당 조건 불성립 경로는 ad_ObsVal(iobs)를 사용한다.
