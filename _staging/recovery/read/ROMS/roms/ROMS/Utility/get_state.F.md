## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 11–12·115·134–148: 파일 머리말은 상태/초기조건을 읽는다고 적는다. wrapper 구분 주석은 Write out history fields라고 적는다. 실제 호출 대상은 get_state_nf90와 get_state_pio이다.
- 225–279·739–793: 모델 식별자 조건 연쇄에는 최종 ELSE가 없다. string·IDmod 선언과 이 연쇄 사이에는 두 변수를 초기화하는 별도 대입문이 없다.
- 369–378·883–892: LastRec의 최대 시간 검색은 Tmax=-1.0_r8에서 시작한다. IniRec 갱신 조건은 TimeVar(i).gt.Tmax이다. 모든 TimeVar가 -1 이하인 경우에는 이 루프가 IniRec를 대입하지 않는다.
- 380–391·894–905: 명시 레코드의 범위 오류 조건은 IniRec가 0이 아니고 mySize보다 큰 경우이다. 0이 아닌 IniRec는 InpRec에 복사한다. 이 블록에는 IniRec<1을 검사하는 조건이 없다.
- 397–409·911–923: 시간 배율은 0으로 초기화하며 units 문자열의 day/second 포함 여부만 검사한다. 문자열을 소문자로 바꾸는 호출은 이 블록에 없다. 양수 배율일 때만 INPtime에 곱한다.
- 421·425·435–436·935·939·949–950: GENERIC_DSTART의 INItime 일수 변환은 86400.0_dp를 직접 사용한다. 인접한 시간 변환 식은 day2sec 또는 sec2day를 사용한다.
- 411–413·450–459·925–927·964–973: 시간 설정 주석은 전역 시간과 인덱스를 msg=1 초기조건 처리에서만 덮어쓴다고 적는다. 수반 분기의 msg.ne.1 조건은 time·tdays를 덮어쓴다. 수반 ntstart·ntend·ntfirst 대입은 해당 msg 조건 밖에 있다.
