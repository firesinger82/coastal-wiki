## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 199·206·225: multifile_info_s1d의 목적 주석은 1D 구조를 적는다. 인수 설명은 S를 2D 구조로 적는다. 실제 S 선언은 S(Ngrids)이다.
- 232·258–344: multifile_info_s1d의 지역 정수 i는 선언 이후 참조되지 않는다.
- 261–266·272–344·430–435·441–514: 각 파일의 time_min/time_max는 구조에 따로 저장한다. Tscale과 Lcheck는 파일별 구조에 저장하지 않고 마지막 check_file 호출이 반환한 값을 이후 선택·종료시간 검사에 사용한다.
- 275–285·444–454: 수반모델(adjoint model)의 초기 파일 선택은 time<=Tmax만 검사한다. 다른 모델의 선택은 time>=Tmin만 검사한다. 해당 선택 루프에는 반대쪽 경계 검사와 파일 사이 시간 공백 검사가 없다.
