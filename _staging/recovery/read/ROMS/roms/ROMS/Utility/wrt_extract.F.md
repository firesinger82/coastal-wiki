## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 388–417·2391–2425: U점 깊이 출력 블록은 RHO점 깊이를 i방향으로 평균하여 EXTRACT%z_v에 대입한다(394–396·2396–2398). 두 쓰기 함수의 idpthU 배열 인수도 z_v이다(407·2415). V점 깊이 블록은 같은 이름 z_v에 j방향 평균을 대입한다(427–428·2434–2436).
- 643–653·2701–2713·2876–2888: 표준 NetCDF의 idUfx2 출력은 ExtractFlag(ng)*DU_avg2를 담은 Ur2d를 넘긴다(643·651). PIO의 idUfx2 블록도 같은 곱을 Ur2d에 계산하지만(2702), 함수에는 COUPLING%DU_avg2를 직접 넘긴다(2711). PIO의 idVfx2는 배율을 적용한 Vr2d를 넘긴다(2877·2886).
- 207·1755–1766·2192·4006–4017: scale의 지역 선언에는 초기값이 없다(207·2192). 표면 활성 추적자 루프의 scale 설정 분기는 itrc.eq.itemp와 itrc.eq.isalt만 있다(1757–1765·4008–4016). 두 분기 모두 불성립할 때 scale을 설정하는 ELSE는 이 블록에 없다. NAT의 외부 정의는 이 파일에 없다.
- 241–268·2219–2246: 두 출력 루틴은 시간 쓰기 호출 전에 Rindex와 Nrec(Fcount)를 증가시킨다(241·243·2219·2221). 시간 쓰기 오류 뒤에는 FoundError 조건으로 RETURN한다(268·2246). 이 파일에는 증가한 두 카운터를 되돌리는 대입문이 없다.
