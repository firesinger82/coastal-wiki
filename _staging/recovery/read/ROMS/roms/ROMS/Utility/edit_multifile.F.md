## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 35 및 1–443: edit_multifile의 지역 정수 Iunder는 선언 이후 사용되지 않는다.
- 17–18·163–169·187–191·203–207: 머리말 주석은 base 파일명을 수정하지 않는다고 적는다. RBL4DVAR_FCT_SENSITIVITY의 FWD2HIS 다중 파일 분기는 HIS(ng)%base와 FWD(ng)%base를 수정한다(190–191). 단일 파일 분기는 HIS(ng)%base를 수정한다(207).
- 55–341: task 선택문에는 CASE DEFAULT가 없다.
- 36·62–70·89–97·116–124·320–328: HIS2FWD·HIS2BLK·QCK2BLK·TLM2FWD는 ntimes(ng)/ndef*(ng) 식의 결과를 정수 Nfiles에 넣는다. 각 CASE는 지정 조건에서만 Nfiles를 1 늘린다. 해당 CASE에는 Nfiles가 1 이상인지 검사하는 분기가 없다. edit_file_struct 호출 뒤 각 대상의 files(1)을 참조한다.
- 390–438: Nfiles가 기존 값과 다를 때만 네 배열을 해제하고 재할당한다. name·files 공백화와 파일 핸들·식별자·레코드 수·시간 필드 초기화는 이 조건 밖에서 실행한다.
- 318–324: TLM2FWD는 TLM 구조를 닫는 close_file 호출에 iNLM을 전달한다(321).
- 404–412: files(j)의 공백화 루프 길이는 LEN(S(ng)%name)이다. 이 루프는 각 files(j)의 길이를 별도로 계산하지 않는다.
- 440 및 347–443: edit_file_struct는 레이블 10의 FORMAT을 정의한다. 이 루틴에는 해당 FORMAT을 사용하는 WRITE 문장이 없다.
