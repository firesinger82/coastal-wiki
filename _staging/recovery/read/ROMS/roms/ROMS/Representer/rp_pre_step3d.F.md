## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 4·923–929·942–948·959–969·1014–1028: 이 파일은 NEUMANN을 직접 정의한다. NEUMANN 대체 분기의 식도 파일 안에 남아 있다.
- 176–177·265–267·341–343·1391–1400: 인수 목록과 ASSUMED_SHAPE 분기는 tl_ghats를 사용한다. 명시적 형상 분기의 선언 이름은 ghats이다. 비국소 실행식은 ghats와 tl_ghats를 모두 참조한다.
- 78–80·153–155·215–217·299–301·1416–1425: rmask_wet의 전달·선언 조건은 SOLAR_SOURCE·WET_DRY이다. 실행 중 태양 복사 플럭스에 rmask_wet을 곱하는 조건은 WET_DRY_NOT_YET이다.
- 917·1065·1133·1161–1162·1192–1193 및 1266–1270: 수직 플럭스 분기는 tl_Vadvection을 검사한다. 인공 연속 방정식의 Gamma 선택은 Vadvection을 검사한다.
- 789–803·805–819: LtracerSrc가 거짓인 원점 분기에서는 tl_FX·tl_FE만 0으로 둔다. 같은 분기의 기본 FX·FE 0 대입은 주석이다.
- 1161–1190: MPDATA·HSIMT 수직 이류 분기의 기본 FC 바닥·표면 0 대입은 주석이며 tl_FC의 0 대입은 실행 코드이다. 다른 수직 이류 분기의 기본 FC 경계 0 대입은 실행 코드이다(1061–1062·1127–1130·1155–1158·1223–1257).
- 1343–1345: 역수 변화 보정의 상수는 `2.0_8*cff` (1345)이다. 다른 대응 보정식은 2.0_r8*cff를 사용한다(1485·1661).
- 1353–1355·1361–1372·1492–1494·1499–1507·1668–1670·1675–1683: 주석은 혼합 계수가 변하면 2*FC를 차감해야 한다고 적는다. 해당 실행식의 TL_IOMS 보정항은 FC 한 항을 차감한다.
- 875·884: 평균 나이 루프는 itrc=1..NPT를 간격 2로 순회하며 inert(itrc+1)을 참조한다. 해당 블록에는 NPT의 짝수 여부를 검사하는 조건문이 없다.
