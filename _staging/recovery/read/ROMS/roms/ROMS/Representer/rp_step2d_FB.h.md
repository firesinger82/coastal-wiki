## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 1·548–550·634–682·746–753: 파일은 첫 행에서 `#define DEBUG`를 설정한다. DEBUG 조건은 IniVal=0.0_r8과 지역 배열 초기화를 포함한다. DEBUG 조건의 `IF (Master) THEN` (748)은 시간 인덱스를 장치 번호 20에 출력한다(749).
- 59–60·891·915·2824: 모듈은 rp_obc_flux_tile·rp_set_DUV_bc_tile을 가져온다(59–60). 첫 체적 보존 블록은 tl_obc_flux_tile·tl_set_DUV_bc_tile이라는 이름을 호출한다(891·915). 뒤의 체적 보존 블록은 rp_obc_flux_tile을 호출한다(2824). 가져온 모듈의 내부 정의는 이 파일 판독에 포함하지 않았다.
- 386–394·505–513·590–593·676–681: DIAGNOSTICS_UV의 진단 인수·작업 배열 선언은 주석이다. DEBUG 안의 DIAGNOSTICS_UV 블록은 Uwrk/Vwrk·DiaU2rhs/DiaV2rhs에 IniVal을 대입하는 실행문이다(677–680).
