## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 154·161·395·531·1024·1535·730·1223·1732·1968: Nsink=2, MinVal=1.0e-6_r8, CONST_PAR의 표면 PAR=158.075_r8, WENO 가중치 하한=1.0E-14_r8을 고정한다. 침강 대상은 iPhyt·iSdet이고 속도는 wPhy(ng)·wDet(ng)이다(229–242).
- 72–78·98–103·120–149: rmask는 MASKING 조건의 입력 인수이고 z_r·tl_z_r는 무조건 입력 인수이다. 타일 루틴의 실행 계산식에는 이 세 인수의 참조가 없다. 광 감쇠의 층 두께는 z_w 차이를 사용한다(555–556·865–870).
- 118·178–180·312–327·333–372: BioTrc·BioTrc1·tl_BioTrc의 두 번째 차원은 2이고 itime 루프는 1..2이다. nstp·nnew도 이 차원의 인덱스로 직접 사용한다. 이 타일 루틴에는 nstp·nnew가 1..2인지 검사하는 조건이 없다.
- 306–327: 주석은 forward 기본 상태 nnew를 농도 단위로 읽어서 기본 BioTrc에는 t를 직접 넣는다고 적는다. 접선형 nnew는 tl_t*Hz_inv와 t*Hz*tl_Hz_inv를 더하는 식을 사용한다. 입력 단위의 실제 외부 생성 과정은 이 파일 판독에 포함하지 않았다.
- 339–371 및 501–509·994–1002·1505–1513: 각 성분에 MinVal 하한을 적용한다. 최대 풀에서 부족분 cff1을 차감하는 조건은 최대 풀 값이 cff1보다 엄격히 클 때이다. 이 차감 조건에는 ELSE가 없다.
- 378–381·516–517·1009–1010·1520–1521: 최초 Bio_old·tl_Bio_old는 보정된 nstp를 사용한다. 기본 상태 I·II는 Bio_old와 Bio를 보정된 nnew로 다시 설정한다. 기본 상태 III는 두 배열을 보정된 nstp로 다시 설정한다. tl_Bio_old의 재대입은 세 기본 상태 블록에 없다.
- 555–565·865–887·1048–1058·1559–1569: 셀 평균 PAR와 접선형 PAR는 Att를 분모에 사용한다. 해당 낮 분기의 조건은 PARsur>0이며 Att=0을 별도로 처리하는 분기는 이 광 감쇠 블록들에 없다.
- 395–407·853–857: 표면 tl_PARsur는 CONST_PAR 및 TL_IOMS 조건에 따라 계산한다. 이후 TL_IOMS 참 분기의 광 감쇠 시작값 tl_PAR에는 tl_PARsur 대신 기본 PARsur를 복사한다. TL_IOMS가 정의되지 않은 분기는 tl_PARsur를 복사한다.
