## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 36–39·58–63: 퇴적층 모듈을 가져오는 조건은 `# if defined SEDIMENT && defined SED_MORPH`이다. 퇴적층 인수를 전달하는 조건은 `# if defined SEDIMENT_NOT_YET && defined SED_MORPH_NOT_YET`이다.
- 84–88: `_NOT_YET` 조합의 서브루틴 인수 목록에서 `&                          omn,` (86)는 다음 인수 행(87) 앞에 있으나 행 끝의 `&`가 없다.
- 225–226·382–384: 바닥 W의 기본 식은 이전 퇴적층 두께에서 새 두께를 뺀 값에 음의 계수를 곱한다. 수반식은 `ad_bed_thick(i,j,nnew)`와 `ad_bed_thick(i,j,nstp)`에 같은 양의 `adfac`을 더한다.
- 270·297: 전체 수주 두께를 분모로 사용하는 두 대입이 있다. 이 대입 앞에는 두께의 0 여부를 검사하는 조건문이 없다.
- 250–267·315–348: 기본 상태의 점원 W 재누적과 그 수반 처리 모두 `DO is=1,Nsrc(ng)` 방향으로 점원을 순회한다. 이 파일에는 같은 셀에 놓인 복수 점원의 좌표 중복을 검사하는 조건문이 없다.
