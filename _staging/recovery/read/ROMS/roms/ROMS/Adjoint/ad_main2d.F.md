## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 103·280: next_indx1은 선언 후 `next_indx1=3-indx1(ng)`로 계산한다. 이 파일에는 이후 next_indx1을 참조하는 문장이 없다.
- 270–274: ng 루프에서 iif와 nfast를 각각 1로 설정한 뒤 iif<nfast+1 조건으로 수정자 ad_step2d를 호출한다.
- 62–64·338–340: ad_set_tides의 USE 문장은 주석이다. 같은 SSH_TIDES_NOT_YET 또는 UV_TIDES_NOT_YET 전처리 조건의 호출 문장은 주석이 아니다.
- 67–69·231–258: FLOATS_NOT_YET의 USE 문장은 주석이며 ONLY 이름은 tl_step_floats이다. 해당 전처리 조건의 실행 블록은 ad_step_floats를 호출한다.
- 77–79·362–377: ocn2atm_coupling의 USE 쪽 지시문은 `# ifdef AIR_OCEAN_NOT_YET && defined MCT_LIB`이다. 호출 쪽 지시문은 `# if defined ATM_COUPLING_NOT_YET && defined MCT_LIB`이다.
- 404–419·427–428: FORCING_SV의 iic(ng) 조건은 앞 ng 루프가 종료된 뒤에 있다. 해당 조건의 참 분기에서 다음 ng 루프를 시작한다.
- 221·430·436: WEAK_CONSTRAINT의 ad_forcing 호출은 인수 4개를 전달한다. FORCING_SV의 두 ad_forcing 호출은 각각 인수 5개를 전달한다. ad_forcing의 정의는 이 파일 판독 범위에 포함하지 않았다.
