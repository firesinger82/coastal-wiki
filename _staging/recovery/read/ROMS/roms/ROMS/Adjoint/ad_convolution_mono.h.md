## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 16·549·580·613·648·683·987·1014·1043·1075·1107·1367·1402·1439·1482·1525: 머리말은 diffusion tangent-linear operators라고 적는다(16). 일부 개방경계 블록 주석도 Tangent linear라고 적는다. 해당 실행 블록은 ad_ 이름의 배열과 ad_conv_ 또는 ad_mp_exchange 루틴을 사용한다.
- 330–331·480–489: ASSUMED_SHAPE의 else는 VnormU·VnormV를 각각 `(LBi:UBi,LBj:UBj,NSA,N(ng))` 차원 순서로 선언한다(330–331). 정규화 실행식은 `VnormU(i,j,k,rec)` (483), `VnormV(i,j,k,rec)` (489)를 참조한다. k는 1..N(ng)이며 rec는 1 또는 2이다(480·384–388).
- 306·352–358: ASSUMED_SHAPE의 else에서도 ad_ubar·ad_vbar·ad_zeta의 마지막 차원은 콜론이다(352–354). 같은 분기의 ad_t·ad_u·ad_v는 마지막 시간 차원의 명시적 크기 3 또는 2를 사용한다(356–358).
- 269–271·294–296·322–324·348–351·754–780·1196·1604: HnormSTF·ad_tflux의 인수 및 선언은 ADJUST_STFLUX와 SOLVE3D가 모두 정의된 조건을 사용한다. 첫 정규화 블록의 시작은 `#ifdef ADJUST_STFLUX`이다(754). 이후 합성곱 블록과 면적 정규화 블록의 시작은 `# if defined ADJUST_STFLUX && defined SOLVE3D` (1196), `#if defined ADJUST_STFLUX && defined SOLVE3D` (1604)이다.
