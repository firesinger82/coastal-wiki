## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 30–31: 입력 설명은 하한 MIN(I,J)과 하한 MAX(I,J)에 모두 LBij라는 이름을 적는다. 실제 입력 선언은 LBij·UBij이다(96·1015·1942).
- 53–58·187–188·1105–1106·2031–2032: 루틴 목록은 세 루틴을 Tangent linear라고 적는다. 실행 루틴 이름은 ad_conv_r3d_bry_tile·ad_conv_u3d_bry_tile·ad_conv_v3d_bry_tile이다(69·988·1915). 본문 주석은 2D state variable at RHO-points라고 적으며 U점·V점 루틴에도 같은 표기가 있다.
- 157–166·175–182·1075–1084·1093–1100·2001–2010·2019–2026: ad_DC·ad_FS 선언은 `#  if defined IMPLICIT_VCONV || defined SPLINES_VCONV` 분기를 사용한다(157·1075·2001). 두 배열의 0 초기화는 `#  ifdef IMPLICIT_VCONV` 분기를 사용한다(177·1095·2021). 이 파일의 두 조건에는 SPLINES_VCONV 검사 포함 여부가 다르다.
- 406·437·1331·1362·2257·2288: 스플라인 후진 대입 수반에서 CF를 통해 다음 층 ad_DC에 누적하는 루프는 RHO점·V점에서는 `DO k=1,N(ng)-1`이다(406·437·2257·2288). U점의 해당 루프는 `DO k=N(ng)-1,1,-1`이다(1331·1362).
- 1134–1140·1161–1167·1259–1262·1271–1274·2060–2066·2087–2093·2185–2188·2197–2200: U점·V점 비스플라인 FC 계수는 인접 두 수평점의 Kv 합을 사용한다. 스플라인 FC·CF 계수는 Hz에 인접 두 점 합을 사용하면서 Kv에는 단일 `(i,j,k-1)`·`(i,j,k+1)` 점을 사용한다.
- 1217–1224·1266–1276·1878–1884: U점 루틴의 입력 ad_A를 Nold로 옮기는 남북 분기는 `DO i=Istr,Iend`를 사용한다(1219). 남북 스플라인 계수 계산은 `DO i=IstrU,Iend`를 사용한다(1269). 초기 조건 수반의 남북 분기는 `DO i=IstrU-1,Iend+1`을 사용한다(1880). Istr·IstrU를 설정하는 포함 파일 내부는 이번 판독 대상이 아니다.
- 2560·2548·1636·708: V점 일반 음해법 우변 수반의 남북 분기는 `ad_DC(i,k)=0.0`을 사용한다(2560). 같은 루틴의 동서 분기와 U점·RHO점 남북 우변 수반의 0 대입은 0.0_r8을 사용한다(2548·1636·708).
