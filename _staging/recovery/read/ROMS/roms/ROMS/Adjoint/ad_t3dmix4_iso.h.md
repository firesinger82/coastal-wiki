- 90·129·175–177·213–215: DIAGNOSTICS_TS의 DiaTwrk 호출 인수와 루틴 인수 목록은 `!!` 주석이다. ASSUMED_SHAPE 갈래의 DiaTwrk intent(inout) 선언(176)은 주석이 아니다. 명시 형상 갈래의 같은 선언(213–214)은 주석이다.
- 227–230: eps·small·slope_max·strat_min은 parameter 상수다. 원문 값은 `real(r8), parameter :: eps = 0.5_r8` (227); `real(r8), parameter :: small = 1.0E-14_r8` (228); `real(r8), parameter :: slope_max = 0.0001_r8` (229); `real(r8), parameter :: strat_min = 0.1_r8` (230).
