## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 155–160: 서쪽 기본 단면적 식은 h(Istr-1,j)와 h(Istr,j)를 쓴다. 접선형 식은 tl_h(Istr-1,j)를 두 번 쓰며 tl_h(Istr,j)를 쓰지 않는다.
- 20–22·27·526: 모듈의 기본 접근은 PRIVATE이다. PUBLIC 목록에는 tl_obc_flux_tile과 tl_set_DUV_bc_tile만 있고, tl_obc_flux와 tl_conserve_mass_tile은 이 목록에 없다.
- 300–301: tl_ubar_xs 계산식의 두 항은 bc_area로 나눈다. 이 대입 앞의 실행 조건은 체적 보존 경계 존재와 tile_count=NSUB이며 bc_area의 0 여부를 검사하는 조건은 이 루틴에 없다.
- 132–133·146–150·165–172·275–301: my_area/my_flux와 tl_my_area/tl_my_flux를 모두 선언한다. my_area/my_flux의 초기화·누적 문장은 !^ 주석이며 실행 누적은 접선형 변수에만 있다. 보정 속도 계산은 mod_scalars에서 가져온 기본 bc_area/ubar_xs를 참조한다.
