## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 1·551–553·637–685·749–756: 파일 첫 행은 `#define DEBUG` (1)이다. DEBUG 블록은 IniVal을 0.0_r8로 선언한다(552). DEBUG 블록은 기본장 작업 배열들을 초기화한다(643–684). Master 분기는 논리 장치 번호 20에 시간 인덱스를 기록한다(751–754).

- 46–49·144–146·240–242: mod_sedbed 사용 조건은 SEDIMENT_NOT_YET·SED_MORPH_NOT_YET·SOLVE3D를 모두 요구한다(46–47). wrapper에서 SEDBED(ng)%tl_bed_thick을 넘기는 조건과 tile 루틴에서 이를 받는 조건은 두 퇴적층 매크로만 요구한다(144·240).
