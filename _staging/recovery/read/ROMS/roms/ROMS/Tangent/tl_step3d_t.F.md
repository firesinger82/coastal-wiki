## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 310–311: Lhsimt는 수평 배열의 ANY와 수직 배열의 ANY를 각각 계산해 AND한다. 이 대입식은 두 배열에서 같은 추적자 인덱스가 HSIMT인지 비교하지 않는다.
- 409–426·760–785: 수평 MPDATA·HSIMT 플럭스 분기의 실행문은 각각 CONTINUE이다. 수평 시간 적분 조건은 MPDATA만 검사한다. 해당 ELSE는 tl_FX·tl_FE의 차이를 새 추적자에서 뺀다. 플럭스 선택에 기본 ELSE는 없다(378–649).
- 1022–1035·1116–1146: 수직 MPDATA·HSIMT 플럭스 분기의 실행문은 각각 CONTINUE이다. 수직 시간 적분 조건은 MPDATA만 검사한다. 해당 ELSE는 tl_FC의 차이를 새 추적자에서 뺀다. 수직 플럭스 선택에 기본 ELSE는 없다(804–1108).
- 907–923·978–987·1010–1019·1066–1080: SPLINES는 상·하단 기본·접선 선형 플럭스를 0으로 설정한다. AKIMA4·CENTERED2·CENTERED4 또는 SPLIT_U3에는 SED_MORPH의 바닥 플럭스 분기가 있다.
- 1172–1175: SPLINES_VDIFF에서 cff는 dt*pm*pn 대입 뒤 oHz를 곱한 값이다. 다음 tl_cff 대입의 우변은 이 cff와 tl_oHz의 곱이다.
- 1046·1081–1104: CENTERED4 또는 SPLIT_U3의 내부 루프는 k=2:N(ng)-2이다. 경계 플럭스 식은 수직 인덱스 3과 N(ng)-2를 직접 참조한다. 이 분기 내부에는 N(ng)의 하한 검사가 없다.
- 1476–1477: 평균 연령 루프는 itrc=1,NPT,2이고 iage=inert(itrc+1)를 직접 참조한다. 이 블록 내부에는 NPT가 짝수인지 검사하는 문장이 없다.
- 1567–1581: 시간 변화율 진단은 전체가 주석이다. 같은 DiaTwrk(i,j,k,itrc,iTrate)에 대한 1574–1575행 대입 뒤 1576–1577행 대입이 이어진다.
- 1611–1639: 부표용 dAktdz는 기본 Akt와 Hz로 계산하며 확산 추적자 인덱스는 1로 고정한다. 이 블록에는 tl_Akt·tl_Hz를 사용한 경사 섭동 대입이 없다. 분산 메모리 교환의 모델 인수는 iNLM이다.
- 75·124·165: nrhs는 상위 루틴에서 전달되어 타일 루틴의 입력 정수로 선언된다. 이 파일 원문의 타일 실행부에는 nrhs 참조가 없다. 이류 식은 추적자 시간 슬롯 3을 직접 사용한다(388–405·812–826).
