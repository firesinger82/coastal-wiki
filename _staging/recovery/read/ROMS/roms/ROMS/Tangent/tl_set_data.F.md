## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 708: 호출 원문은 `CALL ana_psource (ng, tile iTLM)`이다. tile과 iTLM 사이에 쉼표가 없다.
- 94·130–134 등: update 선언의 초기값은 `.FALSE.`이다. 이후 update는 보간 호출의 인수로 반복 전달되며 이 파일의 별도 실행 대입문은 없다.
- 551–552: 대기압 보간 경로의 SetBC는 `.TRUE.`로 설정된다. `.FALSE.` 대입은 주석 처리되어 있다.
- 264–266·505–507·583–585: 바람·응력·파향 회전 조건은 각각 idUair·idUsms·idWdir의 입력 정보를 검사한다. 바람과 응력의 해당 조건에는 idVair·idVsms 입력 정보 검사가 없다.
- 802–858: WET_DRY 경계 수위의 하한은 Dcrit(ng)−GRID(ng)%h이다. acquire 선택은 tl_LBC에 있으며 대입 대상은 BOUNDARY%zeta_west/east/south/north이다.
- 1358·1400·1413·1425·1437: 전방 혼합 변수의 추가 입력 경로는 MY25_MIXING_NOT_YET·GLS_MIXING_NOT_YET·LMD_MIXING_NOT_YET·LMD_BKPP_NOT_YET·LMD_NONLOCAL_NOT_YET 매크로를 사용한다.
- 1444–1445: 비국소 수송의 입력 배열 이름은 MIXING(ng)%ghatsG이고 결과 배열 이름은 MIXING(ng)%ghat이다.
