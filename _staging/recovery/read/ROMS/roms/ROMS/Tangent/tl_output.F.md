## 판독 중 확인된 코드 사실 (판단 아님, 후속 검토 대상)

- 29–31·42–44·297–299: TL_AVERAGES 조건에서 def_avg_mod와 wrt_avg_mod의 USE ONLY 이름이 모두 def_avg이다. 평균 자료 쓰기 호출 이름은 wrt_avg이며 이 USE ONLY 목록에 wrt_avg가 없다.
- 185–196·294–295: 이력 쓰기 조건은 MOD(iic(ng)-1,nTLM(ng))를 사용한다. 평균 쓰기 조건은 MOD(iic(ng)-1,nAVG(ng))를 사용한다. 이 파일에는 해당 두 간격의 양수 여부를 검사하는 독립 조건이 없다.
- 3·359–362: TANGENT 분기의 tl_output은 ng 인수를 받는다. TANGENT가 없는 #else의 tl_output은 인수 없이 정의된다.
