|---|---|
| 1–10 | Model Coupling Toolkit (MCT) — 제목, 목차 템플릿(template), 편집 주석, 배치 마크업과 빈 줄을 포함한다(1–8). MCT 통신과 Warner 등의 2008년 결합 문헌을 소개한다(9). 이후 다른 coupler 인터페이스(interface)를 허용하도록 코드가 더 범용으로 바뀌었다고 적는다(9). |
| 11–14 | 동시 실행과 양방향 결합 — 각 모델은 자체 격자·입력·시간 간격·다른 모델에서 받지 않는 강제력(forcing)·출력 형식·출력 간격이 필요하다고 적는다(11). 하나의 실행파일로 컴파일하고 사용자 지정 동기화 간격(synchronization intervals)에 정보를 교환한다(11). 원문은 current release가 SWAN 양방향 결합을 포함한다고 적는다(13). 조건과 의무를 그대로 옮긴다. 원문: `The coupling provides a mechanism for data transfer between models while they are running concurrently (at the same time). The model coupling requires that each model still needs its own grid, input parameters file, its own time step, forcing files (information not acquired from the other model), and each model writes its own output in its own format (just as if it was not coupled) on its own time interval. However the models are compiled into one executable and exchange information at user defined synchronization intervals.` (11); `The current release of ROMS includes 2-way coupling to the wave model SWAN. For coupling to SWAN, the transferred fields are:` (13). |
| 15–32 | SWAN 교환장 — WAVE에서 받는 Dwave·Hwave·Lwave·Pwave_bot·Pwave_top·Wave_break·Wave_dissip와 WAVE에 보내는 ubar·vbar·zeta·h를 나열한다(15–30). ubar·vbar는 수심 적분(depth integrated) ξ·η 방향 속도라고 원문에 적혀 있다(27–28). 모든 장 이름·설명 주석을 그대로 옮긴다. 원문: `  Fields acquired from the WAVE Model:                                !` (15); `                                                                      !` (16); `     * Dwave      Wave direction.                                     !` (17); `     * Hwave      Wave height.                                        !` (18); `     * Lwave      Wave length.                                        !` (19); `     * Pwave_bot  Wave bottom period.                                 !` (20); `     * Pwave_top  Wave surface period.                                !` (21); `     * Wave_break Percent of breakig waves.                           !` (22); `     * Wave_dissip Wave energy dissipation.                           !` (23); `                                                                      !` (24); `  Fields sent to the WAVE Model:                                      !` (25); `                                                                      !` (26); `     * ubar       Depth integrated xi-direction velocity.             !` (27); `     * vbar       Depth integrated eta-direction velocity.            !` (28); `     * zeta       Water surface elevation.                            !` (29); `     * h          Bottom elevation.                                   !` (30). |
| 33–52 | WRF 교환장 — 원문은 WRF 결합이 시험 중이며 향후 공개된다고 적는다(33). OCEAN으로 보내는 PSFC·RELH·T2·U10·V10·CLDFRA·RAIN·SWDOWN·GLW·USTRESS·VSTRESS와 OCEAN에서 받는 SST를 나열한다(35–51). 각 단위·범위·높이와 설명 주석을 원문 그대로 옮긴다. 원문: `For coupling to the Atmospheric Model WRF, (currently being tested, to be released in the future), the transferred fields are:` (33); `  Fields sent to the OCEAN Model:                                     !` (35); `                                                                      !` (36); `     * PSFC       Surface atmospheric pressure  (mb)                  !` (37); `     * RELH       Surface air relative humidity (-)                   !` (38); `     * T2         Surface 2m air temperature    (degC)                !` (39); `     * U10        U-Wind speed at 10 m          (m/s)                 !` (40); `     * V10        V-Wind speed at 10 m          (m/s)                 !` (41); `     * CLDFRA     Cloud fraction                (percent/100, so 0-1) !` (42); `     * RAIN       Precipitation                 (kg/m2/s)             !` (43); `     * SWDOWN     Short wave radiation          (Celsius m/s)         !` (44); `     * GLW        Long wave raditaion           (Celsius m/s)         !` (45); `     * USTRESS    Surface u-stress              (m2/s2)               !` (46); `     * VSTRESS    Surface v-stress              (m2/s2)               !` (47); `  Fields acquired from the OCEAN Model:                               !` (49); `                                                                      !` (50); `     * SST        Sea surface temperature       (degC)                !` (51). |
| 53–56 | 빌드와 입력 조건 — MPI 컴파일과 링크할 MCT의 사전 컴파일 의무를 설명한다(53–54). Tidal Inlet·Tidal Headland 배포 사례를 언급한다(54). 올바른 교환장을 위해 coupling*.in을 수정해야 하고 swan.in의 안내도 읽도록 적는다(56). 원문 의무와 명칭을 그대로 옮긴다. 원문: `The coupling must be compiled with MPI.` (53); `Users need to first compile the Model Coupling Toolkit, as this library is linked to during the compilation. Examples of coupled applications distributed with the source code include the Tidal Inlet Test Case and the Tidal Headland Test case.` (54); `Users need to modify the coupling*.in file to ensure that the correct fields are being transferred. Users should also read the information for the swan.in file.` (56). |
