| 1–15 | Introduction — 제목, 목차 템플릿(template), 편집 주석과 배치 마크업을 포함한다(1–7). ROMS NetCDF의 전처리(pre-processing)·후처리(post-processing) 스크립트를 소개하고 MEXNC·SNCTOOLS를 언급한다(10). Matlab 2012a부터 native NetCDF 인터페이스(interface)를 선호한다는 설명, 버전별 지원, 구버전 스위치와 갱신 권고를 원문대로 옮긴다(12). 저자의 프로그래밍·플롯 경험담은 원문 저자의 진술로만 기록한다(14). 원문: `{{note}} '''However''', starting with Matlab version '''2012a''', released on Feb 9, 2012, the '''native''' interface to NetCDF is the preferred method for processing NetCDF data in the scripts distributed in the ROMS repository '''matlab''' and described here. The '''native''' interface was introduced in Matlab version '''2008b''' for '''NetCDF-3''' type files.  The '''NetCDF-4''' support started in version '''2010b'''.  The support for '''HDF5''' files was completed in version '''2011a'''.  The '''OpenDAP''' support began in version '''2012a'''.  If your Matlab version is older than '''2008b''', we highly recommend that you update to the newest version.   However, in the basic generic scripts we have switches for older versions to activate either the '''MEXNC''' interface for standard NetCDF files and the '''SNCTOOLS''' interface to process NetCDF files on an '''OpenDAP''' server.` (12). |
| 16–35 | Repositories — ROMS matlab 저장소의 Subversion checkout 명령과 MyDir 목적지(directory) 의미를 제시한다(18–22). 로컬 사용자명이 ROMS 사용자명과 다르면 --username 옵션이 필요하다고 적는다(22–24). MEXNC·SNCTOOLS의 checkout도 제공한다(26–32). 두 인터페이스가 필요 없어지는 Matlab 버전과 OpenDAP 접근 조건을 원문대로 옮긴다(34). 원문: `    <span class="red">svn checkout <nowiki>https://www.myroms.org/svn/src/matlab</nowiki></span> '''MyDir'''` (20); `where '''MyDir''' is the destination directory on your local computer. It will be created if not found. If your '''username''' on your local computer is not the same as your ROMS username you will need to pass the '''--username''' option to '''svn''':` (22); `    <span class="red">svn checkout --username joe_roms <nowiki>https://www.myroms.org/svn/src/matlab</nowiki></span> '''MyDir'''` (24); `Although not necessary nowadays, the '''MEXNC''' interface can be downloaded from:` (26); `    <span class="red">svn checkout <nowiki> https://mexcdf.svn.sourceforge.net/svnroot/mexcdf/mexnc/trunk</nowiki></span> '''MyDir'''` (28); `and the '''SNCTOOLS''' interface can be downloaded from:` (30); `    <span class="red">svn checkout <nowiki> https://mexcdf.svn.sourceforge.net/svnroot/mexcdf/snctools/trunk</nowiki></span> '''MyDir'''` (32); `But recall that both the '''MEXNC''' and '''SNCTOOLS''' interfaces are obsolete if you have Matlab Version '''2008b''' or newer and Matlab Version '''2012a''' for accessing NetCDF files on an '''OpenDAP''' server. See description in the [[Matlab_Scripts#Introduction\|above]].` (34). |
