# Plotting_Package_Installation.wiki — 판독 구간 기록

구간은 1행부터 68행까지 빈틈없이 이어진다.

| 구간 | 내용 |
|---|---|
| 1–9 | 소개 — Fortran 프로그램으로 ROMS 출력을 벡터 그림(vector graphics)으로 표시하는 패키지와 래스터(raster)·애니메이션(animation) 스크립트를 소개한다(1–2). 목차·정리 태그·빈 줄을 포함한다(3–9). 원문: `The ROMS/TOMS Plotting package is a collection of Fortran programs for visualizing ROMS model output. It can be used to create publication quality, vector graphics. The '''[[Raster Scripts\|ncgm2www]]''' script is provided to facilitate raster images and animations.` (2). |
| 10–16 | Required Software — NCAR Graphics/NCL·NetCDF·GNU Make·Fortran 77과, 래스터 또는 애니메이션을 계획할 때의 ImageMagick 요구사항을 열거한다(10–15). 원문: `* [http://ngwww.ucar.edu/ NCAR Graphics] (now part of [http://www.ncl.ucar.edu/ NCL])` (11); `* [http://www.unidata.ucar.edu/software/netcdf/ NetCDF]` (12); `* [http://www.gnu.org/software/make/ GNU Make]` (13); `* Fortran 77 Compiler` (14); `* [http://www.imagemagick.org ImageMagick] (If you plan to make raster images or animations)` (15). |
| 17–25 | Download — SVN 배포와 checkout 명령을 제시한다(17–20). 로컬 사용자명과 ROMS 사용자명이 다르면 `--username`이 필요할 수 있다고 적는다(22–24). 원문: `    <span class="red">svn checkout <nowiki>https://www.myroms.org/svn/src/plot</nowiki> MyDir</span>` (20); `If your user name on your local machine is not the same as your ROMS user name you may need to add the <span class="red">--username</span> option.` (22); `    <span class="red">svn checkout --username joeroms <nowiki>https://www.myroms.org/svn/src/plot</nowiki> MyDir</span>` (24). |
| 26–33 | Build / makefile — NCAR 설치 위치의 환경 변수와 소스 디렉터리 이동을 안내한다(26–29). makefile의 사용자 매크로(macro) 점검을 요구한다(31–32). 원문: `Be sure that your <span class="blue">'''NCARG_ROOT'''</span> environment variable is set to the directory where [http://ngwww.ucar.edu/ NCAR Graphics] (or [http://www.ncl.ucar.edu/ NCL]) is installed. Once you have the source code downloaded, move into the src directory:` (27); `   <span class="red">cd Mydir/src</span>` (29). |
| 34–41 | makefile / 디버그·64비트 — 두 매크로의 빈 기본값과 활성화 효과를 제시한다(34–40). 디버그 실행 파일명에는 G를 붙인다(36). NCAR가 64비트로 설치되었다면 64비트 플래그를 쓰라고 적는다(40). 원문: `   <span class="blue">PLT_DEBUG ?=</span>` (34); `If set, this option will set the proper debugging compiler flag. This option is mostly used by developers and will add a 'G' to the resulting executable names (ccntG, cntG, csecG, and secG) so they will not replace the standard executables.` (36); `   <span class="blue">PLT_LARGE ?=</span>` (38); `If set, this option will activate 64-bit compilation. Use this flag if you downloaded or compiled NCAR Graphics in 64-bit mode.` (40). |
| 42–47 | makefile / 컴파일러 — 컴파일러 기본값과 `<OS>-<compiler>.mk` 선택을 설명한다(42–44). NCL 바이너리와 같은 컴파일러 또는 소스 빌드와 같은 컴파일러·플래그를 써야 한다(46). 원문: `   <span class="blue">FORT ?= g77</span>` (42); `This macro must be set to the name of your compiler. This macro tells make what compiler file to include. To see what options are available look in the Compilers directory. The files are named '''<OS>-<compiler>.mk''' so the '''Linux-g77.mk''' file is for compiling on Linux using the g77 Fortran compiler (make will automatically detect your operating system). If your OS/compiler combination is not there you can create your own. The <OS> portion of the filename is derived from the result of the <span class="red">uname -s</span> command and the <compiler> portion will be whatever you set <span class="blue">FORT</span> to. <!--Therefore, if <span class="red">uname -s</span> returned ''''OSJoe'''' and you are using the ''''joefortran'''' compiler, the filename would be '''OSJoe-joefortran.mk''' and you would need to set <span class="blue">FORT</span> to ''''joefortran''''.-->` (44); `If you downloaded a binary distribution of [http://www.ncl.ucar.edu/ NCL] you will need to use the same compiler that was used to make that [http://www.ncl.ucar.edu/ NCL] build. For Example, if you installed the 64-bit binary for x86_64 chips for Linux compiled with gcc 3.x you would want to use the gcc 3.x g77 compiler. If you built [http://www.ncl.ucar.edu/ NCL] from source you should use the same compiler and flags to build the ROMS Plotting Package.` (46). |
| 48–55 | makefile / NCAR 버전·설치 위치 — NCAR 호출 매크로의 기본값과 문서가 지칭하는 NCL 5.0.0 설정을 설명한다(48–50). 실행 파일 설치 경로의 기본값을 제시한다(52–54). 원문: `   <span class="blue">NCAR_VERSION ?= NCARG441</span>` (48); `You should only have to modify this option if you have a very old version of NCAR Graphics installed. For the Current 5.0.0 release of NCL leave this macro variable set to ''''NCARG441''''. This option changes the way calls to the NCARG libraries are made.` (50); `   <span class="blue">PLT_BINDIR ?= $(HOME)/bin</span>` (52); `Set this option to the path where you want the plotting executables (ccnt, cnt, csec, and sec) to be installed.` (54). |
| 56–62 | Machine Dependent Include File — 링커(linker)·NetCDF 경로·NCL 호환성과 두 번째 밑줄(second underscore) 문제를 설명한다(56–57). 컴파일 플래그를 시험해야 할 수 있으며 ROMS용 NetCDF는 단일 밑줄일 가능성이 높다고 적는다(59–61). 원문: `Next you should check the paths and options of the machine dependent include file you chose with the FORT macro variable in the makefile. In particular you should check that <span class="blue">LD</span> points to the correct <span class="red">ncargf90</span> and that <span class="blue">NETCDF_INCDIR</span> and <span class="blue">NETCDF_LIBDIR</span> are set correctly. It is important that your NetCDF libraries are compatible with your NCL install. The most common compatibility issue is the infamous '''second underscore problem'''. A simple google search will tell you more than you wish to know on this subject as will a search in the ROMS forum. The binary distributions of NCL 5.0.0 appear to have been built with the -fno-second-underscore compiler option set where applicable.` (57); `The last thing to check is <span class="blue">FFLAGS</span>. You may have to experiment with these to get the ROMS Plotting Package to compile. For example, if you installed the 64-bit binary for x86_64 chips for Linux compiled with gcc 3.x you would would want to add <span class="blue">-fno-second_underscore</span> to <span class="blue">FFLAGS</span> in the Linux-g77.mk file.` (59); `'''NOTE:''' If you are running ROMS it is likely that your NetCDF library is already built with single underscores at the end of symbol names.` (61). |
| 63–68 | Compiling — 소스 디렉터리의 `make`, 실행 파일 네 개, 등고선만의 흑백 버전과 회색 색상표 사용을 설명한다(63–64). 다음 문서 링크와 닫기 태그를 포함한다(66–68). 원문: `Make sure you are in the src directory and issue the <span class="red">make</span> command. If the process is successful you will have <span class="red">ccnt</span>, <span class="red">cnt</span>, <span class="red">csec</span>, and <span class="red">sec</span> executables in your <span class="blue">PLT_BINDIR</span> directory. Both <span class="red">cnt</span> and <span class="red">sec</span> are the contour only black and white versions of <span class="red">ccnt</span> and <span class="red">csec</span> respectively. If you need a grayscale plot use <span class="red">ccnt</span>'''/'''<span class="red">csec</span> with one of the provided "grey" palettes.` (64). |

## 판독 중 확인된 사실 (판단 아님, 후속 검토 대상)

- 57·59행: 두 번째 밑줄 옵션을 각각 `-fno-second-underscore`와 `-fno-second_underscore`로 적는다.
