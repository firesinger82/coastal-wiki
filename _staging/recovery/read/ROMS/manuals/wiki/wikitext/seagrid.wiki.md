| 1–18 | SEAGRID 소개·도구 — 그래픽 사용자 인터페이스(Graphical User Interface, GUI) 기반 MATLAB 프로그램으로 네 모서리의 곡선형 직교 격자(curvilinear orthogonal grids)와 ROMS NetCDF 격자를 만든다고 적는다(3). 배포·소스 링크와 해안선·수심 전처리용 join_cst.m·read_srtm30plus.m 도구를 설명한다(5–17). 원문: `<div class="title">SEAGRID</div>` (1); `SeaGrid is a GUI-based Matlab program for creating curvilinear orthogonal grids with 4 corners. SeaGrid allows for flexible, interactive grid design, and includes tools to create ROMS NetCDF grid files.` (3); `Information and a tutorial may be found at:` (5); ` https://github.com/sea-mat/seagrid` (7); `The above page has links to a zip file for use on Windows, but the full source code distribution (so you can build the mex-files for Linux, Mac, etc) is also [https://github.com/rsignell-usgs/seagrid available on Github].` (9); `The SeaGrid tutorial does not cover preparation of coastline and bathymetry.  For this, some useful additional m-files for working with SeaGrid are:` (11); `* [https://github.com/rsignell-usgs/RPSstuff/blob/master/RPSstuff/join_cst.m join_cst.m]: Turn coastline segments (e.g. from the [http://www.ngdc.noaa.gov/mgg/coast/ Coastline Extractor]) into coastline polygons that will then mask land when used in SEAGRID.` (13); `* [https://github.com/rsignell-usgs/RPSstuff/blob/master/RPSstuff/read_srtm30plus.m read_srtm30plus.m]: Read SRTM30+ worldwide 30sec (~1km) topography. ` (15); `These tools are part of the [https://github.com/rsignell-usgs/RPSstuff RPSstuff Matlab toolbox on Github].` (17). |
| 19–30 | 해안선 준비 / 추출·표시 — Coastline Extractor의 MATLAB 형식으로 coast.txt를 저장하는 절차를 적는다(21). 두 열은 경도(longitude)·위도(latitude)이며 서·남쪽 음수와 NaN 구간 구분을 설명한다(23). plot·fillseg 예제를 원문대로 옮긴다(26–27). 원문: `Here is one procedure for preparing coastline and bathymetry for Seagrid using these tools:` (19); `* Go to the [http://www.ngdc.noaa.gov/mgg/coast/ Coastline Extractor] and extract the coastline for your region, making sure you check the "Matlab format" box instead of the default format.  Note that the highest worldwide shoreline is the default World Vector Shoreline, but for the US Waters, there is a higher resolution "NOAA Medium Resolution Shoreline" available.   For example here, let's assume that you save the file on your computer as "coast.txt". ` (21); `* Load the coastline into Matlab using "load coast.txt".  You now have a variable called "coast" in Matlab with two columns.  The first column is longitude in decimal degrees, west negative. The second column is latitude in decimal degrees, south negative.  Each coastline segment is separated by a pair of NaN values.` (23); `* Assuming you've obtained the m-files from the SVN above, you can now type ` (25); ` >> plot(coast(:,1),coast(:,2));    % plot the coast as line segments` (26); ` >> fillseg(coast);                 % attempt to fill all line segments separated by NaNs.   ` (27); `This will probably look bad since in most coastline datasets, coastlines that look continuous are actually composed of many line segments.` (29). |
| 31–47 | 해안선 준비 / 결합·폐합·저장 — join_cst의 허용 오차(tolerance)와 선분(line segments) 길이 정렬, 다각형(polygon) 폐합(closing) 조정 절차를 설명한다(31–40). lon·lat 이름을 반드시 써야 한다는 요구와 .mat 저장 예제·모든 대입을 원문대로 옮긴다(42–46). 원문: `You can join together line segments whose ends are closer than a certain tolerance using the "join_cst.m" command:` (31); ` >> coast_new=join_cst(coast,.0001);   % join coastline segments closer than 0.0001 degrees ` (33); `This will also sort the coastline segments so that the longest segment is first.  Often this segment is the main coastline, while the rest of the segments are islands.    To see what has happened, clear the figure and try "fillseg" again:` (35); ` >> clf;` (37); ` >> fillseg(coast_new);` (38); `this should look better, but typically you have to add a point to the first coastline segment so that the polygon closes the way you want.  Usually just changing the latitude or longitude of the first data pair (2nd line of the coast_new file) to be the appropriate limit of your coastline region will work.` (40); `* Once "fillseg(coast_new)" shows filled polygons in the region you want masked, then save the longitude and latitude values as "lon" and "lat" to a .mat file (you *must* use the names "lon" and "lat"):` (42); ` >> lon=coast_new(:,1);` (44); ` >> lat=coast_new(:,2);` (45); ` >> save seagrid_coast.mat lon lat` (46). |
| 48–64 | 수심 준비 / 해상도·벡터·저장 — 축 범위에서 수심을 읽는 60초 해상도(resolution) 예제를 옮긴다(48–54). 최대 30초와 낮은 해상도 사용 가능성을 설명한다(55). meshgrid로 좌표를 만들고 세 벡터로 변환하며 양의 수심과 필수 xbathy·ybathy·zbathy 이름·저장 형식을 원문대로 옮긴다(57–63). 원문: `* For bathymetry, try using "read_srtm30plus.m".  If you've still got your coastline plot up, type` (48); ` >> ax=axis;  % grab the lon/lat range` (50); ` >> lon_range=ax(1:2);` (51); ` >> lat_range=ax(3:4);` (52); ` >> [xbathy,ybathy,zbathy]=read_srtm30plus(lon_range,lat_range,60);` (53); `This reads in worldwide bathymetry at 60 second (1 minute) resolution.  The highest resolution available is 30 second, but you might want to use a lower resolution when you make your grid so that Seagrid doesn't take too long, and then when once you've got your ROMS grid, create higher resolution bathymetry.   ` (55); `* Seagrid expects bathymetry as three vectors describing bathymetry sounding triplets, with depth positive.  Since we've got a grid, we need to construct the lon and lat points using "meshgrid", and then save remembering that Seagrid expects the names "xbathy", "ybathy", "zbathy" and that depths are positive (not negative):` (57); ` >> [xbathy,ybathy]=meshgrid(xbathy,ybathy);  ` (59); ` >> xbathy =  xbathy(:);   %columnize` (60); ` >> ybathy =  ybathy(:);   %columnize` (61); ` >> zbathy = -zbathy(:);   %columnize, and make depth positive` (62); ` >> save bathy_seagrid.mat xbathy ybathy zbathy` (63). |
| 65–67 | SeaGrid 실행·저장 주의 — 수심 로딩 뒤 화면이 보라색일 때 수심 값 표시를 끄거나 점 수를 줄일 수 있다고 적는다(65). MATLAB 판본이 바뀌며 GUI 문제가 생겼으므로 자주 저장하라고 적는다(67). 이 프로그램을 실행하지 않았다. 원문: `* Now start up Seagrid and load the coastline and bathymetry data.  If your whole screen turns purple when you load the bathymetry, you'll probably want to toggle off the display of the depth values, or reduce the number of depth points.` (65); `* Remember to save often when using SeaGrid, as the GUI has become buggy over then many releases of Matlab since it was designed.` (67). |
