| 18–28 | External Library Paths / 적용 조건 — 대부분의 응용에 NetCDF 위치가 필요하다고 적는다(22). USE_NETCDF4·병렬 입출력(parallel I/O) 조건과 NF_CONFIG·MPI-I/O를 설명한다(22–24). 직렬(serial)·공유 메모리(shared-memory) 응용에는 직렬 라이브러리가 필요하며 MPI 구성과 혼합 병렬화(hybrid parallelism)를 사용할 수 없다고 적는다(26). 원문: `==External Library Paths==` (18); `For information about required and optional external libraries visit the [[External Libraries]] page.` (20); `For most applications, only the location of the '''NetCDF''' library ('''NETCDF_LIBDIR''') and include directory ('''NETCDF_INCDIR''') are needed. Notice that when the [[#USE_NETCDF4\|USE_NETCDF4]] macro is activated, we need the serial or parallel version of the '''NetCDF-4/HDF5''' library. The configuration script '''NF_CONFIG''' (available since NetCDF 4.2) is used to set up all the required libraries according to the installed options ('''OPeNDAP''', '''NetCDF4/HDF5''' file format). The parallel library uses the '''MPI-I/O''' layer (available in most modern MPI implementation) requiring compiling with the selected '''MPI''' library.` (22); `In ROMS distributed-memory applications, you may use either the serial or parallel version of the '''NetCDF-4/HDF5''' library. The parallel version is required when parallel I/O is activated (ROMS cpp option [[Options#PARALLEL_IO\|PARALLEL_IO]] and [[Options#HDF5\|HDF5]]). For more I/O options see the [[IO\|ROMS I/O page]].` (24); `However, in serial or shared-memory ROMS applications, we need to use the serial version of the '''NetCDF-4/HDF5''' to avoid conflicts with the compiler. We cannot activate '''MPI''' constructs in serial or shared-memory ROMS code. Hybrid parallelism is not possible.` (26). |
