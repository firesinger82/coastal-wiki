During the analysis cycle, a background solution (represented by the blue line) is corrected using observations that are available during the analysis window. The analysis state estimate at the end of the analysis window is then used as the initial condition for a forecast. The red curve represents the forecast generated during the forecast cycle from the 4D-Var analysis. The skill of the forecast on any day can then be assessed by comparing it to a new analysis that verifies on the same forecast day, or by comparing the forecast with new observations that have not yet been assimilated into the model.` (14); `To quantify the impact of the observations on the forecast skill it is necessary to run a second forecast which is initialized from the background solution at the end of the analysis cycle.
