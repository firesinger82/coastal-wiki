# user.wiki — 판독 구간 기록

구간은 1행부터 7행까지 빈틈없이 이어진다. 한국어 문장은 판독 설명이며, 원문 인용은 행 번호와 함께 구분한다.

| 구간 | 내용 |
|---|---|
| 1–7 | user 페이지 / 전재 지시문 — 제목과 구분선을 포함한다(1–4). Variables의 user section과 roms.in의 user section을 전재(transclusion)하는 `{{#lst:...}}` 지시문이 각각 있다(2·7). 6행은 roms.in에서 다음 내용을 가져온다고 소개한다. 원문 파일에 실제 전재 본문은 없다. 원문: `<div class="title">user</div>` (1); `{{#lst:Variables\|user}}` (2); `----` (4); `From [[roms.in]] we have the following:` (6); `{{#lst:roms.in\|user}}` (7). |
