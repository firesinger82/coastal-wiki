| 11–18 | Introduction — ESMF/NUOPC 결합 인프라(infrastructure), 대기·해양 결합, ROMS만 4D-Var를 하는 약결합 자료동화(weakly coupled data assimilation), 관측 확인(observations verification)의 전방 해(forward solution)를 시험한다고 적는다(12). 2011년 허리케인 경로 그림을 참조한다(14–15). The simulations are started on 2011-08-27 06:00:00 GMT. The '''WRF''' and '''ROMS''' grids are incongruent, as shown below, so the '''DATA''' model provides the SST values to '''WRF''' at locations not covered by the '''ROMS''' grid. In this case, SST is exported from '''ROMS''' and '''DATA''' components to '''WRF''', which imports the regridded values and then melds both SST fields. The '''DATA''' component is usually a NetCDF file containing SST data snapshots from satellite, climatology, or a global model forecast/hindcast like '''HyCOM'''.` (17). 그림 참조(파일 이름·원문 캡션): `[[Image:2011_Atlantic_hurricane_tracks.png\|center\|800px]]` (14); 그림 파일 없음; `[[Image:Hurricane_Irene_track.png\|center\|800px]]` (15); 그림 파일 없음. |

| 32–37 | ROMS Driver — 두 운영 방식 중 이 시험은 driver mode를 사용하여 ROMS가 주 프로그램(main program)이 된다고 설명한다(33). | 38–49 | Run Sequence — ROMS에서 ATM으로의 명시적(explicit) 교환과 ATM에서 ROMS로의 반암시적(semi-implicit) 교환을 설명한다(39). 시간 평균장(time-averaged fields)이 ROMS 우변(right-hand-side)을 n+1/2 ATM 장으로 강제한다고 적는다(39). WRF·ROMS 시간 간격, 결합 간격(coupling interval), RAMS 평균 진단 패키지 활성화를 원문대로 옮긴다(39). @* wildcard와 DATA·WRF·ROMS 실행 순서 표를 그대로 옮긴다(42–48). 그림 파일 없음. 원문: `The '''ESMF''' RunSequence configuration file sets how the '''ESM''' components are connected and coupled. All the components interact with the same or different coupling time step. Usually, the connector from '''ROMS''' to '''ATM''' is explicit, whereas the connector from '''ATM''' to '''ROMS''' is semi-implicit. Often, the timestep of the atmosphere kernel is smaller than that for the ocean. Therefore, it is advantageous for the '''ATM''' model to export time-averaged fields over the coupling interval, which is the same as the '''ROMS''' timestep. It is semi-implicit because '''ROMS''' right-hand-side terms are forced with ''n+1/2'' '''ATM''' fields because of the time-averaging. In this application, the '''WRF''' and '''ROMS''' timesteps are 20 and 60 seconds, respectively, for stable solutions due to the strong hurricane winds. The coupling step is 60 seconds (same as '''ROMS''').
