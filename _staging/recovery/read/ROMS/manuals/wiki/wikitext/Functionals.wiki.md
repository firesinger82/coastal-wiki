Each of these include files contains the analytic expressions for its respective functionality. For instance, a simple box grid can be represented analytically internal to the model more easily than preparing a grid file with some outside program. Those expressions will be found inside [[Functionals#ana_grid.h \| ana_grid.h]]. The version of [[Functionals#ana_grid.h \| ana_grid.h]] found in the '''ROMS/Functionals''' directory contains everything for the example problems distributed with ROMS (unless it requires an external grid file). If you choose to build analytic grids for your own applications, it is recommended that you use that in '''User/Functionals''' instead, or provide a version in some third location pointed to by [[makefile#MY_ANALYTICAL_DIR \| MY_ANALYTICAL_DIR]].` (3). |
