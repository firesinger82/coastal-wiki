# LISFLOOD-FP 대조 보고서 판 이력 판정 AD1

## 1 요약

대상은 세 보고서의 `## 5 차이 결론`에 있는 A·B·D 행이다. 아래 행 수는 해당 절의 고유 행 ID를 센 값이다. 노트 수정 행도 각각 한 행으로 센다.

| 보고서 | A 원행 | B 원행 | D 원행 | 합계 |
|---|---:|---:|---:|---:|
| [LT1 이론](lisflood-theory-vs-code.md#5-차이-결론) | 15 | 28 | 0 | 43 |
| [LI1 매개변수](lisflood-par-vs-code.md#5-차이-결론) | 12 | 31 | 2 | 45 |
| [LI2 파일·출력](lisflood-files-output-vs-code.md#5-차이-결론) | 14 | 28 | 1 | 43 |
| 합계 | 41 | 87 | 3 | 131 |

| 원 결론 | 확정 결론 | 행 수 |
|---|---|---:|
| A | A 판 차이 | 37 |
| A | C 문서 누락 | 2 |
| A | F 표기 차이 | 2 |
| B | A 판 차이 | 14 |
| B | B 문서 오기 | 73 |
| D | A 판 차이 | 0 |
| D | D 문서에만 있음 | 3 |

확정 분류의 합계는 A 51행, B 73행, C 2행, D 3행, F 2행이다. 이 수치는 2–4절의 판정 표에서 집계했다. 마지막 줄의 “A 확정”은 원래 A였던 41행 중 A를 유지한 37행을 뜻한다. “그 밖 재분류”는 A에서 C 또는 F로 바꾼 4행을 뜻한다.

판정과 노트용 결론 문장은 AI 해석이다. 백틱 안에는 근거 원문을 적었다. 코드 인용은 들여쓰기를 제외한 원문을 유지했다. 문서 수식은 기호를 전사했다. 이번 지시의 규칙에 따라 차이를 직접 설명하는 변경 이력이 있으면 8.0 이전 변경도 A로 판정했다. 단순한 기능 도입이나 일반적인 버그 수정 기록만으로 수치·부호·인수의 변경을 추정하지 않았다.

문서 인용의 PDF는 `LISFLOOD-FP user manual.pdf`를 뜻한다. DOCX는 `LISFLOOD-FP user manual.docx`를 뜻한다. 교량 DOCX는 `LISFLOOD-FP user manual +bridge.docx`를 뜻한다. 판독 기록의 루트는 `_staging/recovery/read/LISFLOOD-FP/LISFLOOD-FP/`이다.

문서 판의 공통 근거는 PDF p.1의 `Code release 6.1.1`과 `25th November 2013`이다. PDF p.2 머리글은 `Code release 5.9.6`이다. PDF p.5 판 이력의 맨 위 행은 `5.9`, `Aug 05 2013`, `Support for LatLong added (Chris Sampson)`이다. 교량 DOCX p.1은 `Code release 4.3.6`과 `25th April 2008`을 적는다. 교량 DOCX p.5는 `4.3`, `Sep 04 2009`, `Dynamic & diffusive steady state 1D solution added & tested by Tim Fewtrell`을 적는다.

DOCX p.1은 `6.1.1` 삭제와 `8.0.0` 삽입을 변경 추적으로 남긴다. DOCX p.5의 기존 `5.9` 행 위에는 `8.0`, `Jul 20 2020`의 추가 행도 있다. 이 행의 원문은 `New first-order finite volume (FV1) and second-order discontinuous Galerkin (DG2) solvers for multi-core CPUs and Nvidia GPUs; support for spatially-varying rainfall (James Shaw)`이다. 판독 기록 `LISFLOOD-FP user manual.docx/p001-018.md`의 p.1·p.5 행과 원본 DOCX의 `word/document.xml`을 대조했다. 표지의 삽입 문구를 기존 PDF 본문의 기능 판으로 일괄 적용하지 않았다.

판 이력 검색은 네 배포본의 `VersionHistory.h`와 세 문서의 판 이력 표를 대상으로 했다. 배포 구조에는 `cmake|lisflood-win|lisflood-lin|archive|libnuma|install|executable`을 사용했다. 기본값과 입력에는 `case.sens|strcasecmp|strcmpi|resroot|res_prefix|momentumthresh|SGCbetahmin|SGCr|SGCp|parameter|resettimeinit|drycheck|chainage`를 사용했다. 식과 기하에는 `friction|weir|bridge|continuity|time.step|routing|gamma|regression|width|geometry`를 사용했다. 파일과 통계에는 `porosity|porfile|binary|checkpoint|Rain-|SGC velocity|max depth|velocity|max velocity|days|inundation|output`을 사용했다. 각 행의 이유는 검색 결과에 있는 변경 내용이 해당 차이를 설명하는지 판정한 결과이다.
