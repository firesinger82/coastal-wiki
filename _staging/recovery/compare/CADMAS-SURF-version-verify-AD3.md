# CADMAS-SURF STR 대조 보고서 A·B·D 판정

## 1 요약

대상은 두 보고서의 `## 5 차이 결론`에 있는 고유 행 ID 115개다. `cadmas-str-docs-theory-vs-code.md`에서 A 34행, B 45행, D 1행을 셌다. `cadmas-str-datatable-vs-code.md`에서 B 33행, D 2행을 셌다. 아래 표의 원문 인용과 AI 판정은 별도 열로 구분한다.

확정 분류는 B 112행과 D 3행이다. 아래 판정 표에서 집계했다.

| 원 결론 → 확정 결론 | KT1 | KT2 | 합계 |
|---|---:|---:|---:|
| A → A | 0 | 0 | 0 |
| A → B | 34 | 0 | 34 |
| A → C·F | 0 | 0 | 0 |
| B → A | 0 | 0 | 0 |
| B → B | 45 | 33 | 78 |
| D → A | 0 | 0 | 0 |
| D → D | 1 | 2 | 3 |
| 합계 | 80 | 35 | 115 |

B 유지에는 원 보고서의 이미지 전사 오류를 바로잡은 KT2-205·218·219·527이 포함된다. 이 네 행의 오류 대상은 매뉴얼이 아니라 대조 보고서다. 영어판 원본 이미지의 NIGRV·NISTP·NNSTP와 식 (2)의 교차 첨자는 일본어판 및 코드와 일치한다.

코드 경로 기준은 `models/CADMAS-SURF/raw/source_code/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/`다. `STR/`는 `STR3D/Source code/`다. `2F/`는 `CADMAS-SURF-3D2F/Source code/`다. `3D/`는 `CADMAS-SURF-3D/Source code/`다. 표의 보고서명 `KT1`은 `cadmas-str-docs-theory-vs-code.md`다. `KT2`는 `cadmas-str-datatable-vs-code.md`다.

문서명 `설명서`와 `instr`는 STR `Program Instructions`다. `연성 설명서`와 `instr-cadmas`는 STR `Program Instructions (CADMAS)`다. `매뉴얼`과 `manual`은 STR `Manual`이다. 각 문서는 위 코드 경로 기준의 `STR3D/Manual/`에 있다. `영`과 `일`은 각각 영어판과 일본어판이다. 쪽 번호는 별도 표시가 없으면 PDF 쪽이다. 일본어판은 `_staging/recovery/extract/CADMAS-SURF/pdf-jp/`의 대응 텍스트로 위치를 찾았다. 식·숫자·표는 지정된 `cadpages/`와 `cadjp/ad3-*.png` 쪽 이미지로 판독했다.

판 근거 V1의 재판독: `3D/vf_a1main.f:33`은 `C----------------------------------------------------------2012.03 start`다. 34줄은 `      INCLUDE 'VF_ASEABT.h'`다. 35줄은 `C----------------------------------------------------------2012.03 end`다. `2F/vf_a1main.f:33`은 `C----------------------------------------------------------2016.09 start`다. 34줄의 INCLUDE 문은 같다. 35줄은 `C----------------------------------------------------------2016.09 end`다. 두 파일의 `diff -u`도 같은 INCLUDE 문 앞뒤의 날짜 교체를 보인다. 이 구간은 STR의 BCTPARA 판독문이나 연성 배열 선언을 감싸지 않는다. 해당 구간을 그 항목들의 변경 날짜로 적용할 수 없다.

문서 판 표지 재판독: 영어 설명서 표지는 `CADMAS-STR Program Description`이다. 일본어 설명서 표지는 `CADMAS-STR プログラム説明書`다. 일본어 연성 설명서 표제는 `CADMAS - STR 連成解析部 プログラム説明書`다. 이 세 STR 문서의 영어판·일본어판 본문에는 발행 연도나 개정 날짜가 없다. 영어 설명서의 인쇄 49쪽은 PDF 52쪽이다. 일본어 설명서의 인쇄 49쪽은 PDF 51쪽이다. 일본어 설명서는 인쇄 101–104쪽에 `６．出力データ`를 포함한다. 영어 설명서는 인쇄 100쪽에서 부록을 시작한다. PDF 생성일은 본문의 동작 변경 날짜를 입증하지 않는다.

검색 기준: 주석 줄을 제외하지 않고 전체 `Simulators/`를 검색했다. `rg -n -i 'IELM\s*\(\s*23\s*,'`와 `rg -n -i 'IPFACE0?\s*\(\s*11\s*,'`는 각각 0줄을 반환했다. 두 검색의 종료값은 각각 1이다. 3D 사본에는 `SF_STRUCT.h`, `sf_array.f90`, `sf_rd_obst.f`, `sf_pface0.f`, `sf_gpres.f`, `sf_str1.f`, `sf_str2.f`가 없다. 표에서 재인용하는 STR·2F 대상 구현에는 해당 동작을 감싼 날짜 표지가 없다. 일본어판이 코드와 일치하고 영어판만 다른 경우에는 요청된 기준에 따라 B 번역 오기로 분류한다.

STR 문서의 PDF 메타데이터 원문은 다음과 같다. `pdfinfo`로 읽었다.

행별 근거에 코드 원문을 인용한 고유 파일은 72개다. 이 파일들에 `rg -n '20[01][0-9][./][01][0-9]'`를 각각 실행한 결과는 모두 0줄이다. 각 종료값은 1이다. V1의 날짜 표지와 이 파일들의 동작을 연결할 근거가 없으므로 V1을 행별 변경 날짜로 사용하지 않았다.
