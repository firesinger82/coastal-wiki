## 5 차이 결론

분류별 개수: A 21, B 37, C 29, D 0, E 2, F 0, H 25, X 0. 차이 결론은 114행이다. §2–4의 일치 84행은 이 표에서 반복하지 않는다.

판 근거는 저장소 커밋 하나로 나누지 않는다. 매뉴얼 표지는 p.1의 `CADMAS-SURF 3D-2F`다. 대상 범위의 배너는 p.145·153의 `Ver.1.0`이다. 3D2F는 `VF_A0PRM.h:1`의 `IVR001=0, IVR002=2`와 `vf_a1main.f:33`의 `C----------------------------------------------------------2016.09 start`를 갖는다. 형제 3D는 `vf_a1main.f:33`에 `C----------------------------------------------------------2012.03 start`를 갖는다. 두 날짜는 수정 구간의 날짜 표지다. 두 날짜를 매뉴얼 발행일로 사용하지 않는다. 이 PDF p.111–160의 인쇄 쪽573–622는 합본 연속 쪽이다. 표지에 없는 발행 연도나 1.0과 0.2의 연대 순서를 추정하지 않는다.

A는 이 판 표지와 실제 사본 차이 또는 명시된 MG/2FC·C2F 변경 구간이 함께 있는 경우에 적용한다. B는 동일 문서 내부 불일치·한 글자 키워드 오기·형·단위 오류에 적용한다. C는 대상 설명의 구현 누락이다. H는 GUI·권고·실행 사례·참고문헌이다. E는 아래 반대 근거 검토를 통과한 정적 결함 후보다. 이번 작업은 코드를 수정하거나 실행하지 않았다.
