이 보고서는 AI가 작성한 정적 대조 기록이다. 따옴표와 백틱 안은 원문이다. `해석:` 뒤는 원문에서 도출한 판단이다. 10-13 검증은 결론 행과 연결된 본문 행의 인용·분류·조건을 대조한 기록이다.

## 3 코드에만 있는 처리

10-13 검증의 검색 대상은 swanuse·swantech·swanimp·swanpgr의 쪽별 판독 기록 전체와 저장된 웹 문서 전체이다. `rg -i`로 키워드·별칭·동작 설명을 검색했다. 일치하는 일반 단어와 실제 명령 문법을 구분했다. 다른 매뉴얼이나 부록에 설명이 있으면 누락 범위를 해당 절 또는 노트로 한정했다.

`REARTH`, `NOUPDATE`·`NOUPDAT`, `INTEST`·`INTE`, `COTEST`·`COTE`, `OUTEST`·`OUTE`, `ASTD`, `IGHS`, `IGTM`, `IGDIR`는 관련 명령 설명을 찾지 못했다. `INCLUDE`의 웹 변경 기록은 `website/modifications/modifications.htm:1100`의 `to INCLUDE files.`이다. 이는 Fortran 공통블록을 INCLUDE 파일로 옮겼다는 설명이다. 명령 파일의 INCLUDE 문법 설명이 아니다. `POOL`의 검색 결과도 내부 배열의 과거 변경 기록이다. `IX1`·`IX2`·`IY1`·`IY2`는 GROUP 명령에서만 나온다. ## 5 차이 결론

집계 단위는 행 ID이다. 같은 현상을 다른 문서 위치나 노트에서 다시 다룬 경우에도 별도 ID가 있으면 별도 행으로 센다. 따라서 E 행 수는 확정 버그 수가 아니다. 2절의 일치 행과 3절의 T1-255는 아래 표에서 제외한다.
