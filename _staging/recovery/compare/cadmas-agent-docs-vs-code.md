# AGENT 영어 문서와 공개 코드 대조

## 1 요약

분류별 개수: A 1, B 37, C 38, D 3, E 15, F 3, H 18, X 0. 일치 241행. 전체 356행. 개수는 §2·§3·§4의 행 ID를 기준으로 셌다.

주요 문서 오기는 진입 가능 셀 값, 피난소 비용 읽기·쓰기 플래그, 확률 척도, 배열 차원, 튜토리얼의 미등록 키워드이다. §3의 코드 결함 후보는 14행이다. E 15행 중 KA1-503은 KA1-422와 같은 반환 문제를 노트 수정안에서 다시 다룬다. §3 후보 행 기준으로 강함은 12행이다. 중간은 실수 통계 예약값과 비도로 차단의 2행이다.

이 보고서는 AI가 작성한 원문 대조 기록이다. 매뉴얼 원문과 코드 원문은 표 안의 인용으로 구분한다. 모델을 빌드하거나 실행하지 않았다. 다른 파일을 수정하지 않았다.

대상은 `CADMAS-AGENT_Manual_English.pdf` PDF p.1–30과 `AGENT_Tutorial_English.pdf` PDF p.1–21이다. `AGENT manual p.N`과 `AGENT tutorial p.N`은 PDF 쪽이다. 매뉴얼 p.2–3의 인쇄 쪽은 i–ii이다. 매뉴얼 p.4–30의 인쇄 쪽은 PDF 쪽에서 1을 뺀 값이다. 튜토리얼에는 별도 인쇄 쪽 번호가 없다.

코드 파일의 생략 경로는 `models/CADMAS-SURF/raw/source_code/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/AGENT/Source code/`이다. `3D`와 `3D2F` 접두어는 같은 `Simulators/` 아래 각 `Source code/`를 뜻한다. 노트 경로는 저장소 상대 경로이다. 판독 기록은 위치를 찾는 데만 사용했다. 코드 판정은 `nl -ba`로 연 원문에 근거한다. 식·표·그림 판정은 지정된 `cadpages/cad-agent-manual-NNN.png`와 `cadpages/cad-agent-tutorial-NNN.png`를 직접 연 결과에 근거한다.

코드 판 표지는 `main.f90:13`의 `write(*,*)"agent_ver3.5 start"`이다. 매뉴얼 표지 p.1에는 판 번호와 날짜가 없다. 튜토리얼 p.8은 `ver3.5_omp`를 별도 언급한다. 공개 코드와 문서의 시간 순서를 이 표지만으로 확정하지 않는다. 문서 내부 모순은 B로 판정한다. 명시적 변경 주석이 없는 구현 차이는 날짜를 추정하여 A로 돌리지 않는다.

§2의 일치 행은 차이 분류를 붙이지 않는다. 일치가 아닌 행은 §5에서 A·B·C·D·E·F·H·X 중 하나로 닫는다. H는 표지·목차·GUI·실행 환경 예시처럼 코드 대조 대상이 아닌 항목이다. 문서가 같은 항목을 반복할 때 표의 문서 위치에 반복 위치를 함께 적는다. 예시 입력값은 코드 기본값을 뜻하지 않는다.

문서·코드 열은 확인한 원문이다. 이유 열은 그 원문을 대조한 `해석:`이다. 노트 수정안은 적용 전 제안이다.
