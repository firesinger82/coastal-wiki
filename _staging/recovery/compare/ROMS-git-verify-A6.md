# ROMS A 행 git 이력 확정 A6

## 1 요약

대상은 사용자 지정 목록의 100행이다. 아래 판정 표의 행 ID를 집계하면 biology 2행, coupling-nesting-parallel 29행, da-4dvar 31행, da-representer 7행, inputs 31행이다.

아래 판정 표의 확정 결론은 A 확정 98행과 B 문서 오기 2행이다. C·D·F·H는 각각 0행이다. B로 바꾼 행은 RCN-096과 RCN-1854이다.

변경 커밋도 정정했다. RCN-001의 WRF 호출 최초 추가는 4a631f7d이다. DA1-200의 include 통합은 5a16bf27이다. DA1-612와 DA1-615의 BGQC 예제값 변경은 5c27056f이다. 각 근거는 해당 판정 행에 인용했다.

코드 기준은 `57aecf589a408b1e5490d2db7f9bd0196062a44e`이다. `git rev-list --count HEAD`의 결과는 1005이다. 커밋 날짜는 `git log --date=short --format='%h %ad %s'`의 저자 날짜이다. 코드 인용 경로는 `models/ROMS/raw/source_code/roms/`를 기준으로 한다. `wiki-20260503:` 인용 경로는 `models/ROMS/raw/manuals/wiki/wikitext/`를 기준으로 한다. 위키 사본의 수집일은 쪽의 작성일을 뜻하지 않는다. `local:`은 작업 시점의 위키 노트 원문이다. 공개 태그는 문서와 맞는 코드 상태의 증거로 사용한다. 태그를 위키 쪽의 작성 판으로 단정하지 않는다.
