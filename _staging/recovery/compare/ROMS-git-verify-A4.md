# ROMS 대조 보고서 A 행 git 이력 확정 A4

## 1 요약

대상은 [roms-build-options-history-vs-code.md](roms-build-options-history-vs-code.md#5-차이-결론)의 지정된 A 행 131개이다. 대상 수는 이 보고서 2절의 고유 행 ID로 집계한다.

| 확정 결론 | 행 수 |
|---|---:|
| A 확정 | 113 |
| B 문서 오기 | 4 |
| C 문서 누락 | 14 |
| D 해당 구현 없음 | 0 |
| F 동등한 표현 | 0 |
| H 이력 기록 | 0 |
| 합계 | 131 |

위 개수는 2절의 확정 결론 열을 집계한 값이다. B는 RBH-1462·RBH-1523·RBH-1525·RBH-1588이다. C의 13행은 설명이 `:Option to`로 끝나는 행이다. C의 나머지 1행은 SOUTHERN_WALL의 직접 소비 루틴을 누락한 RBH-1464이다. 지정된 131행의 문서 출처는 모두 Options.wiki이다. 지정된 행에는 ChangeLog 변경 기록이 없다.

이 보고서는 AI가 작성한 판정 기록이다. 백틱 안의 문구는 원문 인용이다. 코드 경로의 기준은 `models/ROMS/raw/source_code/roms/`이다. 현재 코드는 `57aecf58 2026-09-18 Reporting Computer Memory Availability and Usage (#81)`이다. 문서의 `revid-6053:Options.wiki`는 `models/ROMS/raw/manuals/wiki/wikitext/Options.wiki`를 가리킨다. `models/ROMS/raw/manuals/wiki/manifest.json`은 Options의 `revid`를 `6053`으로 기록한다. 같은 매니페스트의 수집 시각은 `2026-05-03T14:20:20Z`이다.

과거 판은 행의 서술과 일치하는 코드가 있는 공개 태그 또는 커밋으로 특정한다. 커밋 날짜는 저자 날짜이다. `git log -S/-G`로 찾은 변경을 `git show`의 변경 전후 원문으로 대조했다. 각 행의 현재 줄은 위 HEAD의 원문이다.

대상 행 ID의 누락과 중복은 각각 0개이다. `REV:path:N` 형식의 원문 인용 1165개를 해당 문서 또는 `git show REV:path`의 N번째 줄과 다시 대조했다. 이 수량은 2절의 인용 위치를 중복 포함하여 센 값이다.
