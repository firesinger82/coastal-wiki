## 1 요약

분류별 개수: A 0, B 35, C 66, D 1, E 4, F 2, H 8, X 0. 판정 행은 192개다. 일치는 76개다. 일치가 아닌 행은 116개다. 집계 기준은 §5의 행 ID다.

코드 결함 후보는 FREEBOARD의 0 계수 보정, STOPC의 주기 상대 오차, RADSTR의 누산 순서, WLEN의 평균식이다. 각 후보의 반대 근거와 근거 강도는 해당 대조 행에 기록한다. E 판정은 인용한 호출 경로와 식의 정적 검토에 근거한다.

이 문서는 AI가 작성한 원문 대조 보고서다. 인용문과 해석을 구분한다. 대상은 `swanuse.pdf`의 §4.5.4, §4.5.5, §4.7, Appendix A다. PDF 쪽은 파일의 첫 쪽을 1로 센다. 해당 본문에서 인쇄 쪽은 PDF 쪽보다 8 작다.

코드 경로의 기준은 `models/SWAN/raw/source_code/swan/src/`다. 표의 `swanpre1.ftn:2817` 같은 표기는 이 디렉터리를 기준으로 한다. `switch.pl`, `bin/swanrun`, `misc/swan.edt`는 상위 `swan/` 디렉터리를 기준으로 한다. 문서 경로의 기준은 `models/SWAN/raw/manuals/pdfs/`다. 표의 `U65/57`은 `swanuse.pdf` PDF 65쪽, 인쇄 57쪽을 뜻한다. 인용문 안의 줄바꿈은 공백으로 옮긴다. 인용문 밖의 …는 중간 생략을 뜻한다. 코드 인용은 원문에서 행 끝의 개발 이력 숫자와 들여쓰기만 생략한다.

코드는 `swanmain.ftn:965`의 `VERNUM = 41.51`을 사용한다. 읽기 전용 `git log`에서 HEAD는 `43e9bbb`다. HEAD의 제목은 `Merge branch 'master' into 'main'`이다. `updated src (patch B)`의 커밋은 `0dabfa4`다. 두 커밋의 날짜는 2026-07-13이다. 문서는 표지에 `SWAN Cycle III version 41.51`을 표시한다. 같은 버전 번호만으로 모든 기본값이 같다고 가정하지 않는다.

`src/CMakeLists.txt:5`는 `set( SWITCHES -unix )`를 지정한다. 같은 파일 9–32행은 MPI, JAC, METIS, FFRO, NETCDF 옵션을 추가한다. `switch.pl:85`의 `if ($jac=~/TRUE/) {$newline=~s/^!JAC//;}`는 JAC 행을 활성화한다. 86행의 `else {$newline=~s/^!WFR//;}`는 JAC를 선택하지 않은 빌드에서 WFR 행을 활성화한다. 89행은 MPI 행을 활성화한다. 101–103행은 METIS, NCF, NNCF 행을 선택한다. 따라서 이 접두사가 붙은 행을 일률적으로 주석으로 판정하지 않는다. 기본 빌드에서 `!COH`, `!ADC`, `!NRL` 같은 비선택 접두사는 실행문으로 취급하지 않는다.

입력 생략의 공통 근거는 `ocpcre.ftn:434`의 `!              ='REQ' : variable is required`, 435행의 `!              ='UNC' : if no variable, then variable will not be changed`, 436행의 `!              ='STA' : if no variable, then variable will get value of RSTA`다. `ocpcre.ftn:476`의 `CALL INDBLE (NAAM, RDBL, KONT, DRSTA)`가 실수 읽기를 수행한다. 따라서 `UNC,0.`의 0을 기본값으로 옮기지 않는다. 표의 기본값은 별도 표시가 없으면 새 실행에서의 값이다. 재입력에서 `UNC`는 앞서 저장한 값을 유지한다.

## 3 코드에만 있는 처리

### 3.1 검색 범위와 본문 밖의 입력

네 PDF의 쪽별 판독 기록 전체와 로컬 웹 문서를 `rg -i`로 검색했다. 판정을 좌우하는 식·수치는 해당 PDF 쪽 이미지와 대조했다. 웹 검색 범위는 `models/SWAN/raw/manuals/website/` 전체다. 명령 문법의 존재를 판정할 때 일반 명사 `ice`, `growth`, `filter`와 논문의 저자 이름을 명령으로 세지 않는다.

`swanuse` Appendix C는 `misc/swan.edt`의 문법표를 싣는다. U137–141/129–133에 YAN, BABANIN, SSWELL ROGERS, 추가 WCAP·BREAKING·TRIAD·NUMERIC 선택이 있다. 이 항목들은 §4 본문에 없더라도 “어떤 문서에도 없다”에 해당하지 않는다. §3.3에서 따로 대조한다. ### 4.5 유지할 서술과 보고서 연결

## 5 차이 결론

분류별 개수: A 0, B 35, C 66, D 1, E 4, F 2, H 8, X 0. 일치가 아닌 행은 116개다. 일치 76개를 합하면 PN-001–192의 192개 판정 행이다. §4에서 기존 행을 다시 연결한 항목은 중복 집계하지 않았다.

A는 판 차이다. B는 문서·노트 오기다. C는 문서 누락이다. D는 문서·노트에만 있는 명령이다. E는 코드 결함 후보다. F는 식의 표기 또는 느슨한 용어 표현의 차이다. H는 코드 대조 대상이 아닌 권고·성능·적용 주장이다. X는 외부 원문이 있어야 결론을 나눌 수 있는 경우다. 이번 표에는 A와 X로 남길 항목이 없다. 과거 커밋의 존재만으로 같은 41.51 문서의 오기를 판 차이로 옮기지 않았다.

분류 변경 목록은 다음과 같다.

- PN-051: B → F. 두 매뉴얼의 `bilinear fit`은 xy 교차항을 명시하지 않는 명칭이다.
