# CADMAS-SURF A·B·D 행 판정

## 1 요약

대상은 지정한 세 보고서의 차이 결론 표에 있는 A·B·D 75행이다. AGENT 대조 보고서는 A 1행·B 37행·D 3행이다. 튜토리얼·빌드 대조 보고서는 A 1행·B 21행·D 1행이다. 흐름 보고서는 B 10행·D 1행이다. 이 개수는 아래 표의 보고서와 행 ID 조합으로 센다.

재분류별 개수는 A 유지 2행·B 유지 67행·B에서 A로 변경 1행·D 유지 4행·D에서 B로 변경 1행이다. D에서 A로 변경한 행은 0행이다. 확정 분류의 합계는 A 3행·B 68행·D 4행이다. 이 개수는 아래 75행의 원 결론과 확정 결론 열에서 셌다. 원래 A인 행의 A 확정은 2행이다. B에서 A로 바뀐 행은 KA1-219이다. 그 밖 재분류 1행은 RF-019의 D에서 B로 변경이다.

이 문서는 원문을 인용한 AI 판정 기록이다. 인용부호와 코드 표시는 원문이다. 이유와 노트 결론은 판정자의 문장이다.

보고서 약칭 AG는 `cadmas-agent-docs-vs-code.md` §5이다. 보고서 약칭 KU는 `cadmas-tutorials-build-vs-code.md` §5이다. 보고서 약칭 RF는 `../flow/CADMAS-SURF-callflow.md` §8이다. AG·KU 보고서는 이 파일과 같은 디렉터리에 있다.

노트 경로의 기준은 `models/CADMAS-SURF/`이다.

코드 경로의 공통 루트는 `models/CADMAS-SURF/raw/source_code/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/`이다. 코드 약칭 `3D/`는 `CADMAS-SURF-3D/Source code/`이다. `2F/`는 `CADMAS-SURF-3D2F/Source code/`이다. `AG/`는 `AGENT/Source code/`이다. `STR/`는 `STR3D/Source code/`이다. ReadMe의 경로는 각 시뮬레이터 폴더를 기준으로 적는다.

영어판 텍스트는 `_staging/recovery/extract/CADMAS-SURF/pdf/`에 있다. 일본어판 텍스트는 같은 상위 경로의 `pdf-jp/`에 있다. `AG 매뉴얼`은 `cad-agent-manual.txt`와 `CADMAS-AGENT_Manual_Japanese.txt`이다. `AG 튜토리얼`은 `cad-agent-tutorial.txt`와 `AGENT_Tutorial_Japanese.txt`이다. `3D 매뉴얼`은 `cad-3d-manual.txt`와 `CADMAS-SURF3D_Manual_Japanese.txt`이다. `2F 매뉴얼`은 `cad-2f-manual.txt`와 `CADMAS-2F_Manual_Japanese.txt`이다. `3D 튜토리얼`은 `cad-3d-tutorial.txt`와 `CADMAS-SURF3D_Tutorial_Japanese.txt`이다. `2F 튜토리얼`은 `cad-2f-tutorial.txt`와 `CADMAS-2F_Tutorial_Japanese.txt`이다. 쪽수는 PDF 쪽수이다. 영어판과 일본어판의 쪽수가 다른 곳은 각각 적는다.

문서 시점의 직접 표지는 AG 일본어 튜토리얼 p.3의 `Inputデータ ※マニュアルver3.5参照`와 p.10·17의 `Inputデータ ※マニュアルver3.3参照`이다. AG 코드의 직접 표지는 `main.f90:13`의 `write(*,*)"agent_ver3.5 start"`와 `remesh.f90:110`의 `!!! modify ver3.4`이다. 파일 생성일은 코드 동작의 개정일로 사용하지 않는다. 날짜 주석은 해당 블록에만 적용한다. 사본 diff는 `diff -u 3D/<파일> 2F/<파일>` 방향이다.
