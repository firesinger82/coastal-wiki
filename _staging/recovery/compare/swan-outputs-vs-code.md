# SWAN 출력 명령·물리량·파일 형식과 코드 대조

## 1 요약

문서·코드 대조 140행과 현재 노트 대조 22행을 판정했다.
집계 대상은 2·3절의 O-001–O-140와 4절의 N-001–N-022이다.
5절은 이 중 일치가 아닌 101행의 결론을 다시 제시한다.
5절의 재제시는 개수에 중복 산입하지 않았다.

주요 차이는 출력 명령의 생략 인수 기본값, 출력 물리량의 적분 정의, 파일의 머리말·밀도 기록 규칙이다.
코드 결함 후보는 NGRID EASYMESH, WLEN, 제한 주파수 TRANSP, RADSTR, PTDIR, ABS L, NetCDF REL L, DISICE, 단위 표시 목록, TEST S2D 건조점 기록의 10개이다.
E 판정의 근거 강도는 모두 강함이다.
E는 정적 대조의 결론이다.

이 보고서는 SWAN 사용자 매뉴얼 41.51의 4.6절, 출력 물리량 정의, Appendix C와 Appendix D를 대조한다.
코드 기준은 `models/SWAN/raw/source_code/swan`의 HEAD `43e9bbb`이다.
`43e9bbb`는 2026-07-13 병합 커밋이다.
patch B의 실제 변경 커밋은 `0dabfa4`이다.
`src/swanmain.ftn:965`는 `VERNUM = 41.51`이다.
`src/swanmain.ftn:967`은 `CALL BUGFIX ('A')`이다.
`src/swanmain.ftn:968`은 `CALL BUGFIX ('B')`이다.

이 보고서의 코드 경로는 위 코드 기준 디렉터리에 상대적이다.
PDF 쪽은 파일 첫 쪽을 1로 센다.
사용자 매뉴얼 본문의 PDF 쪽은 인쇄 쪽보다 8 크다.
코드 인용의 줄 번호는 전처리 전 원문에 해당한다.
판독 기록은 위치 색인으로만 사용한다.
판정은 원문 코드와 매뉴얼 본문에 근거한다.
기존 노트는 수정하지 않았다.

빌드 조건: `src/CMakeLists.txt:5`는 `set( SWITCHES -unix )`이다.
같은 파일 9–31행은 선택에 따라 `-mpi`, `-jac`, `-metis`, `-fixfront`, `-netcdf`를 추가한다.
`switch.pl:85`는 `if ($jac=~/TRUE/) {$newline=~s/^!JAC//;}`이다.
`switch.pl:86`은 `else              {$newline=~s/^!WFR//;}`이다.
`switch.pl:89`는 `if ($mpi=~/TRUE/) {$newline=~s/^!MPI//;}`이다.
`switch.pl:102`는 `if ($ncf=~/TRUE/) {$newline=~s/^!NCF//;}`이다.

따라서 보고서는 선택한 스위치가 활성화하는 행을 실행 코드로 취급한다.

### 3.1 출력 선택자로 설명하지 않은 물리량

검색 대상은 네 매뉴얼의 Marker 본문과 `models/SWAN/raw/manuals/website/` 전체이다.
검색어는 `rg -n -i '\b(ufri|ufric|zlen|tauw|cdrag|ursell|biph|astd|difpar|oute|outest|mdgrid|noaux|noswll|fs1d|sfd|npart)\b'`이다.
CDRAG는 GEN1·GEN2의 입력 인수로 검색된다.
URSELL은 LIMITER·TRIAD의 설명으로 검색된다.
이 두 단어의 존재는 출력 선택자의 명세가 아니다.
나머지 검색어는 출력 명령 설명에서 검색되지 않았다.
출력 목록 원문은 swanuse PDF 110–114 / 인쇄 102–106과 PDF 141–143 / 인쇄 133–135에서 확인했다.
네 원문 PDF도 `pdftotext -layout`의 전체 텍스트로 별도 검색했다.
UFRI/UFRIC·ZLEN·TAUW·BIPH·ASTD·DIFPAR·OUTE·OUTEST·MDGRID·NOAUX·NOSWLL·FS1D·SFD·NPART·PPER·DTM·FWID는 네 원문 PDF 모두에서 단어 검색 결과가 0건이다.
CDRAG·URSELL·XC·YC의 원문 PDF 검색 결과는 물리 설명·입력 인수·좌표 표기이며 출력 선택자 명세가 아니다.
