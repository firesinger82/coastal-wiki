# SWAN E 행 git 이력·반대 증거 판정

## 1 요약

이 기록은 지정된 대조 보고서의 제5절과 흐름 보고서의 제8절에서 결론이 E인 39행을 대상으로 한다. 행 수는 제2절의 보고서명과 행 ID 조합으로 센다. 같은 원인을 다룬 행도 원 보고서별로 기록한다. 판정은 소스코드의 정적 분석이다.

코드 기준은 `43e9bbb 2026-07-13 Merge branch 'master' into 'main'`이다. 실제 patch B 변경은 `0dabfa4 2026-07-13 updated src (patch B)`이다. 문서 시점 대조 기준은 `7ee8981 2024-09-02 initial release (v 41.51)`이다. 공개 직후 수정은 `2444143 2024-09-10 updated src (v 41.51)`이다. `git rev-list --count 43e9bbb`의 결과는 98이다.

도입 커밋은 해당 줄의 `git blame --line-porcelain -L N,N 43e9bbb -- src/파일`로 확인했다. `b2ae30e 2022-08-10 initial release`는 이 저장소의 최초 코드 반입이다. 이 커밋의 날짜는 원 개발 날짜를 뜻하지 않는다. 인용 끝의 `40.93`, `41.71` 등은 원문에 있는 개발 표지이다. 개발 표지를 공개 판의 도입 날짜로 환산하지 않는다.

각 행의 이력 검색은 `git log --format='%h %ad %s' --date=short -G '검색식' 43e9bbb -- src/파일`로 수행했다. 문서 시점의 동일 줄은 `git show 7ee8981:src/파일`로 대조했다. 반대 증거는 HEAD의 주석, 다른 계산 경로, 입력 검사, 호출 조건과 전처리 표지에서 찾았다. E의 강도는 모순의 직접성과 SWAN에서의 사용 경로를 함께 반영한다. 강함은 도달 가능한 경로의 직접 모순이다. 중간은 별도 설계 의도를 완전히 배제하기 어려운 모순이다. 약함은 SWAN이 사용하지 않는 보조 반환값에 남은 모순이다.

웹 검색 대상은 [P: problems_and_fixes.htm](https://swanmodel.sourceforge.io/problems_and_fixes/problems_and_fixes.htm), [A: patches/41.51.A](https://swanmodel.sourceforge.io/problems_and_fixes/patches/41.51.A), [M: modifications.htm](https://swanmodel.sourceforge.io/modifications/modifications.htm)이다. P의 현재 안내는 `no patches will be published on this site`이다. 과거 41.51.A의 상세 검색에는 `models/SWAN/raw/manuals/website/`의 보관 원문을 사용했다. 표의 P·A·M 줄번호는 이 디렉터리 아래의 해당 HTML·패치 파일 줄번호이다. P 보관본은 A의 배포일을 13-03-2026으로 적는다. A 원문의 첫 두 수정 설명은 `correct initialization of some arrays`와 `some ASCII output files treated as dummies in case of netCDF`이다. git의 대응 커밋은 `c6d3136 2026-03-13 updated src (patch A)`이다. 표의 웹 검색 결과는 P·A·M 전체에서 해당 증상과 관련 용어를 검색한 결과이다. 포괄적인 수정 제목은 동일 결함의 수정 증거로 취급하지 않는다.

제2절의 확정 결론을 집계하면 E 유지(강함)는 31행이다. E 유지(중간)는 7행이다. E 유지(약함)는 1행이다. 재분류한 행은 0행이다. SS-516은 SWAN이 DIAG를 사용하지 않는 반대 증거에 따라 약함으로 낮췄다. 입력 설정 보고서의 T1-011은 스칼라 수위의 호출 경로에 따라 강함으로 높였다. PN-127은 빈 순서에 따른 정적 반례에 따라 강함으로 높였다. O-110은 ABS L의 실제 RTYPE과 계산 분기를 연결하여 강함으로 높였다.

원 보고서와 제2절의 보고서명·행 ID를 대조한 결과는 39행 일치이다. 코드 원문 인용 472개를 해당 커밋의 해당 줄과 대조했다. 인용문 불일치는 0개이다. 이 수치는 제2절의 소스코드 인용 쌍을 센 값이다.
