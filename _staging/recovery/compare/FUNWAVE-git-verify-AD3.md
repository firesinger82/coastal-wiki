# FUNWAVE 대조 보고서 A·B·D 행의 git 이력 판정

## 1 요약

대상은 [funwave-aux-docs-build-vs-code.md](funwave-aux-docs-build-vs-code.md)의 「5 차이 결론」이다.
대상 표에서 A 78행, B 56행, D 6행을 집계했다.
대상 행 수는 140행이다.
FG1은 집계에 포함하지 않는다.

| 원 결론 | 확정 A | 확정 B | 확정 D | 확정 F | 행 수 |
|---|---:|---:|---:|---:|---:|
| A | 42 | 3 | 0 | 33 | 78 |
| B | 2 | 54 | 0 | 0 | 56 |
| D | 0 | 0 | 6 | 0 | 6 |
| 합계 | 44 | 57 | 6 | 33 | 140 |

재분류는 B→A 2행, A→B 3행, A→F 33행이다.
D→A는 0행이다.
그 밖 재분류는 A→B와 A→F를 합한 36행이다.
B→A인 FN1-131·FN1-257은 최초 커밋 이전 판의 문서 차이로 판정했다.
각 표의 행 수와 재분류 수는 아래 140개 행 ID에서 집계했다.

TVD 현재 기준은 `b4c322e 2025-01-24 make more efficient by defining 2D array dir`이다.
`git rev-list --count HEAD`의 결과는 554이다.
전체 ref를 포함한 `git rev-list --count --all`의 결과는 572이다.
변경·삭제·이름 검색은 전체 ref에 적용했다.
최초 커밋은 `cab9425 2016-03-02 first add to repository`이다.
GPU 공개 기준은 `7f892ba 2019-11-26 3 cases for test`이다.

문서 추가·변경 날짜의 직전 코드는 `git rev-list -1 --before=YYYY-MM-DDT00:00:00+0000 HEAD`로 정했다.
정적 분석 문서와 2.1 문서의 2016-11-03 직전 코드는 `2e72b18 2016-11-01 Merge pull request #5 from malej/master`이다.
Intro-TN의 2016-11-10 직전 코드는 `7948152 2016-11-04 Merge pull request #8 from malej/master`이다.
3.0 TeX의 2016-11-18 직전 코드는 `739a08d 2016-11-14 change theta_input to theta_input/180*pi`이다.
3.0 PDF의 2017-02-26 직전 코드는 `cc511df 2017-02-19 add resistance and output`이다.
3.0 PDF의 2018-02-24 직전 코드는 `cab6d74 2018-02-07 standard io and sediment module`이다.
3.0 문서의 원문 판본 표시는 p.1의 `Release Dec 2016`이다.
2016년 원문에 대응하는 동작과 2018년 PDF 변경 시점의 동작은 해당 행에서 구분한다.

2016-11-03 이전 커밋에는 `src/` 디렉터리가 없다.
`b9c035d 2016-11-03 new structure for entire repo, added doc folder, added Dan Topa's report, added and cleaned up examples`가 `src/` 사본을 추가했다.
`8d5a857 2016-11-03 updated .gitignore and moved/removed source from main directory and put it in /src dir`가 루트 소스를 삭제했다.
따라서 이전 커밋의 인용은 실제 경로인 `REV:X.F:N`으로 적었다.
이후 인용은 `REV:src/X.F:N`으로 적었다.
현재 TVD 인용의 `FUNWAVE-TVD/`는 `models/FUNWAVE/raw/source_code/FUNWAVE-TVD/`를 뜻한다.
현재 GPU 인용의 `FUNWAVE-GPU/`는 미커밋 수정이 있는 `models/FUNWAVE/raw/source_code/FUNWAVE-GPU/`를 뜻한다.
