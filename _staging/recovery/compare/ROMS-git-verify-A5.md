대상은 `roms-build-options-history-vs-code.md`의 「차이 결론」에서 사용자가 지정한 130행이다. 아래 판정 표의 고유 행 ID 130개를 집계했다.

B는 RBH-1719·1724·1839·2139·3493이다. D는 RBH-1738·1938·1952이다. F는 RBH-3502다. 지정한 행에는 ChangeLog 변경 기록 행이 없다.

표의 코드 인용 1,269개를 `git show` 원문과 대조했다. 문서 인용 144개를 로컬 원문과 대조했다. 인용 불일치는 0개다. 대상 행 ID의 누락과 중복은 각각 0개다.

코드 저장소는 `models/ROMS/raw/source_code/roms`이다. 현재 코드는 `57aecf58`이다. 커밋 날짜는 `git log --date=short`의 저자 날짜다. 위키 인용 경로의 기준은 `models/ROMS/raw/manuals/wiki/wikitext/`이다. 위키는 2026-05-03 수집 사본이다. 이 수집일을 각 쪽의 작성일로 사용하지 않았다.

각 옵션과 경로에 `git log -S` 또는 `git log -G`를 적용했다. 일치하는 공개 태그의 `git show REV:path`와 변경 커밋의 같은 파일을 대조했다. 부재 판정은 `git log --all -G`로 태그 쪽 이력도 검색했다. 경계조건 묶음은 `WEST_*`·`WESTERN_WALL`의 CPP 분기와 현재 LBC 분기를 속성별로 대조했다. 표의 원문은 해당 판의 줄 번호를 사용한다. 표 안의 `\|`는 Markdown 열 구분자를 이스케이프한 원문이다.
