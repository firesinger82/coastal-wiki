# ROMS D 행 Git 재검증 D1

## 1 요약

대상은 사용자가 지정한 11개 보고서의 D 행 133개이다. 대상 행 수는 각 보고서의 「차이 결론」 절에서 행 ID를 대조하여 셌다. 기존 D 판정에는 실제 삭제 이력이 있는 항목이 포함되어 있다. `TALK_PROGNOSTIC`과 `ESMF_COUPLING`은 A로 정정한다. CMEPS의 `bulk_fluxes import`도 과거 코드와 입력 파일에 존재했다. 현재 구현의 다른 이름과 문서의 잘못된 이름은 B 또는 F로 구분한다. 구현이나 해당 입력 계약이 없는 항목은 D를 유지한다.

현재 코드의 기준은 `57aecf589a408b1e5490d2db7f9bd0196062a44e 2026-09-18 Reporting Computer Memory Availability and Usage (#81)`이다. `git rev-list --count HEAD`의 결과는 1005개 커밋이다. 현재 코드의 인용 경로는 `models/ROMS/raw/source_code/roms`를 기준으로 한다. 위키 인용의 `wiki-revid-N`은 `models/ROMS/raw/manuals/wiki/manifest.json`에 기록된 쪽별 revid이다. 위키 사본의 수집일은 2026-05-03이다. 수집일을 위키 서술의 작성일이나 코드 판으로 사용하지 않는다.

각 검색은 저장소 루트에서 `rg -n -i --hidden --no-ignore -g '!**/.git/**' -- '검색어' .`로 수행했다. `.git` 객체 디렉터리를 제외한 현재 트리 전체를 검색했다. 표의 검색어는 실제 정규식이다. `ad_`, `tl_`, `rp_` 접두어와 밑줄·공백 변형을 함께 검색했다. 각 검색 결과의 수는 일치한 줄 수이다. `User`, `Compilers`, `ESM`, `Data`의 수는 전체 줄 수에 포함된다. 같은 줄이 여러 검색어와 일치하면 검색어별로 각각 센다. 넓은 검색의 동명 변수와 다른 사례의 식은 해당 기능의 구현과 구분한다.

이력 검색은 경로를 제한하지 않은 `git log HEAD -i --pickaxe-regex -S '검색어' --format='%H %ad %s' --date=short -p --unified=0`을 사용했다. 표의 이력 칸에 별도 검색어가 없으면 해당 행의 첫 검색어를 사용했다. 공통 항목의 검색 결과는 관련 행마다 기록했다. 날짜는 커밋의 저자 날짜이다. 삭제 전 인용의 `HASH^`는 해당 커밋의 부모 판이다. 도입·삭제 판정은 검색된 패치와 `git show REV:path`의 원문을 대조했다. 단순 경로 이동과 바이너리 자료의 문자열 일치는 기능 삭제로 세지 않는다.

A는 과거 코드 또는 입력 계약의 삭제가 확인된 판 차이이다. B는 현재 구현과 맞지 않는 문서의 이름·위치·식이다. F는 현재 다른 이름의 분기에 같은 식이 있는 경우이다. D 유지는 문서가 주장한 기능 또는 입력 계약의 구현을 찾지 못한 경우이다. 과거 메타데이터의 존재는 그 필드의 송수신 계산이 구현되었다는 뜻으로 확대하지 않는다.
