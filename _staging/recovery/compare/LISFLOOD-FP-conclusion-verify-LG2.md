# LISFLOOD-FP LG2 차이 결론 원문 재대조

## 1 요약

대상은 `lisflood-cpu-gpu-acc-adaptive.md`의 §5에 있는 LG2 84행이다.
최종 결론별 개수는 다음과 같다.

| 최종 결론 | 행 수 |
|---|---:|
| A 판 차이 | 0 |
| B 문서 오기 | 0 |
| C 문서 누락 | 55 |
| D 문서에만 있음 | 0 |
| E 코드 결함 후보 | 23 |
| F 표기 차이 | 5 |
| H 코드 대조 대상 아님 | 1 |
| 일치 | 0 |
| 합계 | 84 |

E 강함은 19행이다.
E 중간은 4행이다.
E 약함은 0행이다.
보고서 결론을 유지한 행은 56행이다.
보고서 결론에서 바뀐 행은 28행이다.
인용을 고친 행은 7행이다.
인용 정정 행은 LG2-032·035·054·070·087·094·097이다.
개수의 근거는 아래 행별 표이다.

`바뀜`은 보고서와 최종 판정의 분류 또는 E 강도가 달라진 경우이다.
결론 문장의 조건 보완과 잘못된 인용 설명의 정정은 별도로 집계한다.
판 판정 열은 `LISFLOOD-FP-version-verify-E2.md`의 해당 행을 표시한다.
AD1·AD2·E1·E3와 표본 검증에는 LG2 행이 없다.
판정은 원문 정적 대조의 결과이다.
모델 실행과 수치 검증은 하지 않았다.

현재 코드 인용의 기준 경로는 `models/LISFLOOD-FP/raw/source_code/LISFLOOD-FP/`이다.
`U/`는 `cuda/acc/`이다.
`N/`는 `cuda/acc_nugrid/`이다.
`M/`는 `cuda/adaptive/`이다.
`배포문서/`는 `models/LISFLOOD-FP/raw/source_code/LISFLOOD-FP-8.3-package/`이다.
문서 쪽은 사용자가 지정한 쪽 이미지의 번호이다.

이 보고서의 C는 현재 사용자 지시의 문서 누락이다.
모델의 물리·수치·입출력·실행 흐름을 H로 제외하지 않는다.
원 보고서의 코드 간 차이만으로 문서 오기나 판 차이를 만들지 않는다.
세 매뉴얼 추출본에 `rg -i 'acc_nugrid|mwdg2|hwfv1|Haar|compaction'`을 적용한 결과는 0행이다.
이 검색은 문서 설명의 위치를 찾는 색인 확인이다.
원본 `README.md:63–65`는 FV1·DG2의 CUDA 빌드를 설명한다.
각 C 행은 표에 적은 ACC·N·M의 세부 구현 또는 해법 간 지원 차이의 설명 누락으로 한정한다.
