# Celeris CP2 차이 결론 원문 재대조

## 1 요약

대상은 보고서 「## 5 차이 결론」의 CP2-001–999 중 실제로 수록된 150행이다. H 행을 포함했다. 중복과 누락은 없다.

| 최종 결론 | 행 수 |
|---|---:|
| A 판 차이 | 48 |
| B 문서 오기 | 12 |
| C 문서 누락 | 31 |
| D 문서에만 있음 | 0 |
| E 코드 결함 후보 | 2 |
| F 표기 차이 | 7 |
| H 코드 대조 대상 아님 | 49 |
| 일치 | 1 |

E는 강함 1행과 중간 1행이다. 보고서 분류를 유지한 행은 138행이다. 보고서 분류를 바꾼 행은 12행이다. 인용·참조 위치·빠진 조건을 고친 행은 14행이다. 이 수치는 아래 행별 표에서 집계했다.

인용 교정 행은 CP2-019, CP2-023, CP2-026, CP2-046, CP2-055, CP2-074, CP2-094, CP2-132, CP2-133, CP2-134, CP2-146, CP2-148, CP2-149, CP2-150이다.

이전 구현의 구체적인 파일·자료 구조 차이는 사용자 A 기준을 적용했다. 현재의 표시 전용 추가 처리와 표시 결함 후보는 사용자 H 기준을 적용했다. 모델 실행과 수치 실험은 하지 않았다.

현재 코드 기준은 ebca435(2026-07-20)이다. git diff ebca435 --의 출력은 없다. 코드 경로의 기준 디렉터리는 models/Celeris/raw/source_code/Celeris-WebGPU/이다. P20은 해당 디렉터리 docs의 Tavakkol 2020 논문이다. P17은 Tavakkol 2017 논문이다. 문서 쪽은 PDF 쪽 번호이다. P20의 파일명은 docs/Tavakkol_2020_Celeris_Base_interactive_Computer_Physics_Communications.pdf이다. P17의 파일명은 docs/Tavakkol_2017_Celeris_GPU_accelerated_Computer_Physics_Communications.pdf이다. P20의 1–14쪽 이미지와 P17의 1·3·6쪽 이미지를 직접 열었다. 판독 기록은 판정 근거로 사용하지 않았다.

바뀜은 보고서의 분류 또는 E 강도 변경을 뜻한다. 문장 보완만으로는 바뀜을 예로 세지 않는다. 인용 교정은 이유 칸의 「인용 교정:」으로 표시한다. A의 이전 구현 문구 추가는 인용 교정 개수에서 제외한다.

VR·360도 재검색의 루트는 위 코드 디렉터리이다. rg는 보고서 5.2와 같은 자산·외부 라이브러리·사례·자동화 폴더와 skybox·duck·model 전용 셰이더를 제외했다. git log는 --all과 같은 경로 제외를 적용했다. 검색 실패는 0건으로 세지 않았다.
