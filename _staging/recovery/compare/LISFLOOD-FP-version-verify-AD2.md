이 문서는 원문 인용을 근거로 작성한 AI 판정 기록이다. 배포일과 MD5 일치는 사용자 제공 사실을 기준으로 삼았다. 배포일은 8.0이 2020-10-09이다. 8.1은 2022-09-23이다. 8.2는 2024-07-29이다. 8.3은 2026-10-13이다. 코드 변경 이력의 날짜는 배포일과 구분했다.

인용 경로의 기준은 다음과 같다. `v8.0:`은 `_staging/recovery/extract/LISFLOOD-FP/external/v8.0/LISFLOOD-FP-trunk/`이다. `v8.1:`은 같은 external 아래 `v8.1/LISFLOOD-FP-trunk/`이다. `v8.2:`는 같은 external 아래 `v8.2/LISFLOOD-FP/`이다. `v8.3:`은 같은 external 아래 `v8.3/LISFLOOD-FP-8.3/source/`이다. `배포:`는 8.3의 배포 루트이다. 접두어가 없는 코드 경로는 `models/LISFLOOD-FP/raw/source_code/LISFLOOD-FP/`이다. `노트:`는 `models/LISFLOOD-FP/`이다. Word·PDF·bridge는 각각 사용자 지정 user manual.docx·user manual.pdf·user manual +bridge.docx이다. 문서 쪽은 판독 기록의 변환본 쪽 번호이다.

문서 시점은 사용자 지시대로 모두 8.0 이전으로 판정했다. PDF 표지 p.1의 원문은 `Code release 6.1.1`과 `25th November 2013`이다. Word p.1은 `6.1.1` 삭제와 `8.0.0` 삽입을 함께 보존한다. Word p.5의 기존 이력은 `5.9`·`Aug 05 2013`·`Support for LatLong added (Chris Sampson)`이다. 같은 쪽의 변경 추적 삽입에는 `8.0`·`Jul 20 2020`과 `New first-order finite volume (FV1) and second-order discontinuous Galerkin (DG2) solvers for multi-core CPUs and Nvidia GPUs; support for spatially-varying rainfall (James Shaw)`가 있다. 이 삽입을 문서 전체의 코드 기준판으로 사용하지 않았다. bridge p.1의 원문은 `Code release 4.3.6`과 `25th April 2008`이다. bridge p.5에는 `4.3`·`Sep 04 2009`와 `Dynamic & diffusive steady state 1D solution added & tested by Tim Fewtrell`이 있다.

배포본 간 코드 변화는 배포본을 직접 비교했다. 8.0 이전 변화는 VersionHistory.h와 문서의 판 이력에서 해당 동작을 명시한 기록으로 판정했다. 일반적인 모듈화·버그 수정 기록만으로 특정 수치·조건·배열 크기의 변경을 추정하지 않았다. 문서 안의 구판 설명도 해당 변경 기록이 있으면 요청된 규칙에 따라 A로 분류했다. 해당 변경 기록이 없으면 원래 차이의 성격에 따라 분류했다. VersionHistory.h의 8.0 이전 이력은 네 배포본에서 같은 변경 내용을 보존한다. 8.1과 8.2의 VersionHistory.h는 같다.
