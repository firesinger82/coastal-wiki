# LISFLOOD-FP LT1 차이 결론 원문 재대조

## 1 요약

대상은 `lisflood-theory-vs-code.md` §5 차이 결론의 고유 LT1 행 223개이다. §5.3의 223행을 기준으로 중복 재인용을 제외했다. 참고문헌 99행을 포함했다.

| 최종 결론 | 행 수 |
|---|---:|
| A 판 차이 | 20 |
| B 문서 오기 | 22 |
| C 문서 누락 | 22 |
| D 문서에만 있음 | 0 |
| E 코드 결함 후보 | 3 |
| F 표기 차이 | 6 |
| H 코드 대조 대상 아님 | 148 |
| 일치 | 2 |
| 합계 | 223 |

E의 강함은 2행이다. E의 중간은 1행이다. E의 약함은 0행이다. 보고서 결론에서 분류가 바뀐 행은 12행이다. 분류를 유지한 행은 211행이다. 인용을 고친 행은 15행이다. 모든 수량은 §2의 행별 표를 집계했다.

`바뀜`은 보고서 §5.3의 분류 또는 E 강도가 바뀐 경우이다. 인용 보정은 원문 글자·조건·식·수량·쪽 또는 줄을 고친 경우이다. 이유 칸의 `인용 보정:`으로 해당 행을 표시한다. 결론 문장의 설명 보충만으로 인용 보정에 세지 않는다.

`현재:`와 접두어 없는 코드 파일은 `models/LISFLOOD-FP/raw/source_code/LISFLOOD-FP/` 아래 파일이다. `v8.0:`·`v8.1:`·`v8.2:`는 사용자 지정의 `_staging/recovery/extract/LISFLOOD-FP/external/` 아래 각 배포본이다. `v8.3:`은 같은 위치의 `v8.3/LISFLOOD-FP-8.3/`에 있는 README와 패치를 뜻한다. `패키지:`는 `models/LISFLOOD-FP/raw/source_code/LISFLOOD-FP-8.3-package/`이다. `PDF`는 `LISFLOOD-FP user manual.pdf`의 인쇄 쪽이다. 쪽 판정은 사용자가 지정한 `lf-manual-pdf-NNN.png`를 직접 열어 확인했다. `AD1`·`AD2`·`E1`·`E2`·`E3`는 같은 compare 디렉터리의 판 판정 파일이다.
