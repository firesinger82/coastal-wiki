# SWAN 대조 보고서 D 행의 전체 소스·git 이력 확인

## 1 요약

확정 결론은 D 43행과 F 2행이다. 이 수치는 2절의 확정 결론 열을 센 결과다. F로 바꾼 행은 QC-050과 QC-058이다. 조사 범위에서 삭제 전 구현과 삭제 커밋을 함께 확인한 A 행은 0행이다.

대상은 지정된 대조 보고서 7개의 `## 5 차이 결론`과 `SWAN-callflow.md`의 `## 8 차이 결론`에서 원 결론이 D인 45행이다. 행 수는 해당 절의 결론 열을 세었다. 보고서별 원 D 행 수는 numerics 1행, sources 0행, obstacles·setup·QC·BC 35행, inputs·setup 2행, inputs·physics·numerics 1행, outputs 1행, implementation·history 4행, callflow 1행이다.

검색 루트는 `models/SWAN/raw/source_code`다. 검색은 `rg -n -i -uuu -g '!.git' PATTERN models/SWAN/raw/source_code`로 수행했다. 이 명령은 숨김 파일과 전처리 표시 행을 포함한다. `.git`은 소스가 아닌 저장소 메타데이터이므로 검색 대상에서 제외했다. 표의 일치 수는 텍스트 행 수다. PDF 바이너리 일치는 별도로 표시한다. 경로 목록은 같은 루트에서 `rg --files -uuu -g '!.git'`로 얻은 100파일이다.

git 저장소는 `models/SWAN/raw/source_code/swan`이다. 전체 HEAD 이력은 `git rev-list --count HEAD`에서 98커밋이다. 판정 범위는 `2980d1a^..43e9bbb`에 `--since=2023-02-27T00:00:00Z`를 적용한 50커밋이다. 이 수는 `git rev-list --count`에서 얻었다. 비병합 이력은 같은 명령에 `--no-merges`를 적용한 25커밋이다. 나머지 25개 병합의 tree는 각각 부모 하나의 tree와 같다. 이 동일성은 `git rev-list --parents --merges`와 각 커밋의 `git show -s --format=%T`로 확인했다. 표의 이력 검색은 `git log --no-merges --since=2023-02-27T00:00:00Z --format='%h %ad %s' --date=short -G PATTERN 2980d1a^..43e9bbb -- .` 또는 같은 범위의 `-S STRING`이다. `-G`는 변경된 행을 검색한다. `-S`는 문자열 출현 횟수가 바뀐 커밋을 검색한다. 두 검색의 0건은 최초 판에 이미 있는 구현의 부재를 뜻하지 않으므로 공개 판의 `git show REV:PATH` 원문도 함께 대조했다.

41.45 공개 이력의 원문은 `2980d1a 2023-02-27 initial release (v 41.45)`, `e430c02 2023-02-27 initial release (v 41.45)`, `50dedab 2023-02-27 initial release (v 41.45)`, `4390970 2023-02-28 initial release (v 41.45)`, `122b595 2023-02-28 initial release (v 41.45)`다. PDF 매뉴얼의 대조 기준은 `7ee8981 2024-09-02 initial release (v 41.51)`이다. 후속 공개 소스는 `2444143 2024-09-10 updated src (v 41.51)`이다. 현재 HEAD의 원문은 `43e9bbb 2026-07-13 Merge branch 'master' into 'main'`이다. patch B 소스 변경의 원문은 `0dabfa4 2026-07-13 updated src (patch B)`이다. 행 끝의 소스 변경 표지는 git 커밋 날짜로 사용하지 않는다.

D는 해당 행이 주장한 명령·자료·직접 계산이 조사 범위에 없다는 판정이다. D는 관련 물리 효과 전체가 없다는 뜻이 아니다. F는 같은 기능이나 식을 다른 변수 또는 계산 순서로 구현했다는 판정이다. A는 삭제 전 구현과 삭제 커밋을 확인한 경우에 적용한다. 아래 원문 인용과 검색 결과는 근거다. 마지막 열의 한국어 문장은 이 근거에 따른 판정문이다.

표의 27개 이력 검색에는 대소문자 확장 검색도 적용했다. 이 검색은 각 영문자를 `a`에서 `[aA]`처럼 바꾼 정규식을 같은 범위의 `git log -G`에 전달했다. `-S` 문자열은 정규식 특수문자를 이스케이프한 뒤 같은 방식으로 확장했다. 확장한 27개 검색의 일치 커밋 수는 모두 0이다. 이 수는 표에 인용한 27개 검색 조건을 중복 제거하여 센 결과다.
