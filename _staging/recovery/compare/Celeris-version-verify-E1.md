# Celeris E 행의 코드 이력·반대 증거 판정

## 1 요약

대상 보고서의 지정 결론 절에서 E 행 19개를 추출했다. 보고서별 행 수는 2017 대조 3개, 2020 대조 2개, 2026 대조 2개, 아키텍처 대조 7개, 소스 문서 대조 4개, 호출 흐름 대조 1개다. 아래 판정 표는 같은 원인을 다룬 행도 별도로 센다.

확정 결론은 E 유지(강함) 6개, E 유지(중간) 9개, E 유지(약함) 0개, H 재분류 4개다. A·B·C·F 재분류는 각각 0개다. CP1-022와 CP1-023은 같은 혼합 미분 계수를 다룬다. CD1-1301과 RF-012는 같은 퇴적물 단계 전달을 다룬다.

판정은 AI의 정적 분석이다. 백틱 안은 원문 인용이다. 코드 경로의 기준 디렉터리는 `models/Celeris/raw/source_code/Celeris-WebGPU/`다. 현재 코드 기준은 `ebca435`다. 이력 검색은 이 저장소의 `git log --follow --format='%h %ad %s' --date=short -- <파일>`과 `git log -S'<문자열>' --format='%h %ad %s' --date=short -- <파일>`을 사용했다. 변경 내용은 `git show HASH:<파일>`과 `git show HASH -- <파일>`로 대조했다. `--follow`가 사본 생성 이전의 원본 경로까지 추적한 경우에는 사본의 최초 커밋과 원본 계보를 구분했다. 반대 증거 칸의 검색 경로는 이 기준 디렉터리 아래다.

H는 현재 호출되지 않는 대체 코드 또는 보조 함수를 현재 실행의 결함 후보에서 제외한다는 판정이다. H는 해당 파일의 식이나 선언이 올바르다는 뜻이 아니다. 이전 논문과 구현의 연도 차이만으로 A를 부여하지 않았다. 현재 코드 내부의 독립적인 모순이 남는 행은 E로 판정했다.
