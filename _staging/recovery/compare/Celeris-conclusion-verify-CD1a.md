# Celeris 차이 결론 재대조 — CD1-001–175

## 1 요약

대상은 `celeris-docs-architecture-vs-code.md`의 `## 5 차이 결론`에 실제로 수록된 CD1-001–175 행이다. 해당 절에서 센 대상은 76행이다. 같은 번호 범위의 본문에만 있는 일치 행은 대상에 포함하지 않았다. 기존 출력 파일은 없었다.

아래 행별 표에서 집계한 최종 결론은 다음과 같다.

| 최종 결론 | 행 수 |
|---|---:|
| A 판 차이 | 0 |
| B 문서 오기 | 12 |
| C 문서 누락 | 0 |
| D 문서에만 있음 | 0 |
| E 코드 결함 후보 | 0 |
| F 표기 차이 | 0 |
| H 코드 대조 대상 아님 | 59 |
| 일치 | 5 |
| 합계 | 76 |

보고서 결론에서 바뀐 행은 7행이다. 분류를 바꾼 행은 CD1-095·136·143·150·153의 5행이다. 분류를 유지하면서 결론 문장의 실행 위치와 조건을 보완한 행은 CD1-139·140의 2행이다. 표의 `바뀜`은 이 두 경우를 모두 포함한다. 출처를 추가한 것만으로는 변경으로 세지 않았다. 유지한 행은 69행이다.

인용 글자 또는 줄번호를 고친 행은 0행이다. 본문과 차이 결론의 인용 글자는 원문과 같았다. CD1-010·011은 같은 문장을 나눈 인용이므로 README.md:11 전체에서 문맥을 확인했다. CD1-139·140의 빠진 실행 조건 보완은 위의 결론 문장 변경 2행으로 집계했다.

원문 경로의 기준은 `models/Celeris/raw/source_code/Celeris-WebGPU/`다. 현재 판은 `ebca435`다. 판 인용은 `HASH:파일:줄`로 적었다. `AD2`는 `Celeris-version-verify-AD2.md`의 확정 결론이다. AD1·AD3·E1·E2에는 이번 대상 ID의 판정이 없다. `Celeris-external-sources.md`의 CP3-013·CP3-017은 이번 대상 ID에 해당하지 않는다.

CD1-073의 논문 근거는 Tavakkol 2017 PDF p.1의 쪽 이미지를 직접 열어 확인했다. 코드와 문서의 대조에는 로컬 원문 읽기와 git의 log·show·diff만 사용했다. 모델 실행과 네트워크 접근은 수행하지 않았다.
