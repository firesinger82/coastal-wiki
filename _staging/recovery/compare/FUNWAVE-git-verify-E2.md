## 1 요약

지정한 결론 표의 E 행은 43개다.
보고서별 행 수는 inputs 16개, examples 5개, v21-manual 11개, v21-examples 2개, aux-docs-build 7개, callflow 2개다.

같은 코드 문제를 다루는 별도 행 ID도 각각 집계했다.

이 보고서는 AI의 정적 판정 기록이다.
백틱 안의 문장은 원문 인용이다.
그 밖의 판정·계산·강도 설명은 분석자의 해석이다.
강함은 명시한 발생 조건에서 독립 근거 둘 이상과 모순하는 경우에만 부여했다.
Smagorinsky 생산 누락의 FV1-277·444·510·578과 고립파 중심의 FV2-136은 중간으로 낮췄다.
관측점 버퍼의 명시적 채움값은 표본 누락과 구분했다.

현재 TVD 인용의 기준 경로는 `models/FUNWAVE/raw/source_code/FUNWAVE-TVD/`다.
현재 GPU 인용의 기준 경로는 `models/FUNWAVE/raw/source_code/FUNWAVE-GPU/`다.
TVD 공개 사본의 HEAD는 `b4c322e`다.
`git rev-list --count HEAD`로 TVD의 554개 커밋을 셌다.
GPU 공개 사본의 HEAD는 `7f892ba`다.
GPU 공개 이력은 3개 커밋이다.
각 행은 현재 원문과 일반 `git blame HEAD -L`을 먼저 대조했다.
공백·줄끝 변경이 도입 시점을 가리면 `git blame -w`와 이전 객체를 추가로 대조했다.
이력 검색은 로컬 refs 전체의 `git log --all --full-history -m -G`와 관련 커밋 원문을 사용했다.
파일 경로 검색에는 이동 전 루트 파일과 이동 후 src 파일을 함께 포함했다.
관련 단어의 커밋 메시지도 검색했다.

과거 인용의 `REV:src/X.F:N`은 경로를 정규화한 표기다.
`cab9425`와 `2e72b18`의 실제 객체는 `REV:X.F`다.
src 복사와 루트 사본 제거는 각각 다음 커밋이다.
`b9c035d 2016-11-03 new structure for entire repo, added doc folder, added Dan Topa's report, added and cleaned up examples`는 루트 소스를 src로 복사했다. `8d5a857 2016-11-03 updated .gitignore and moved/removed source from main directory and put it in /src dir`는 루트 사본을 제거했다.
