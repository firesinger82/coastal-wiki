# CADMAS-SURF E 행 판정

## 1 요약

대상 보고서의 차이 결론 절에서 E 행 19개를 집계했다. 3D 이론 보고서는 0개이다. 3D 프로그램 보고서는 1개이다. 3D 입력 보고서는 3개이다. 2F 이론 보고서는 10개이다. 2F 프로그램 보고서는 3개이다. 2F 입력 보고서는 2개이다. 같은 문제를 가리키는 별도 행 ID도 각각 집계했다.

확정 결론은 E 유지 19개이다. 강함은 5개이다. 중간은 11개이다. 약함은 3개이다. A·B·C·F·H 재분류는 각각 0개이다. 이 개수는 §2의 판정 열을 집계한 값이다. 강도는 코드 결함 후보에 대한 증거의 강도이다.

표의 코드 경로에서 `3D/`는 `models/CADMAS-SURF/raw/source_code/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/CADMAS-SURF-3D/Source code/`이다. `2F/`는 같은 Simulators 아래 `CADMAS-SURF-3D2F/Source code/`이다. 보고서 링크는 이 출력 파일과 같은 디렉터리를 기준으로 한다.

매뉴얼의 EN은 `_staging/recovery/extract/CADMAS-SURF/pdf/cad-3d-manual.txt` 또는 `cad-2f-manual.txt`에 대응하는 영어 PDF이다. JP는 `_staging/recovery/extract/CADMAS-SURF/pdf-jp/CADMAS-SURF3D_Manual_Japanese.txt` 또는 `CADMAS-2F_Manual_Japanese.txt`에 대응하는 일본어 PDF이다. p.는 PDF 순번이다. 괄호의 인쇄 쪽은 이미지에서 읽은 번호이다. 식의 인용은 이미지의 해당 항을 그대로 전사했다.

일본어 3D p.128(370)의 예제 시작 문구는 `##### CADMAS-SURF/3D-MG Ver.1.0 START. ######`이다. 일본어 2F p.132(132)의 예제 시작 문구는 `##### CADMAS-SURF/3D-2F Ver.1.0 START. ######`이다. 현재 `3D/vf_a1main.f:366`은 `      IF (MGRANK.EQ.0) WRITE(*,*) '*** ver4.9.1 ***'`이다. 현재 `2F/vf_a1main.f:293`은 `      IF (MGRANK.EQ.0) WRITE(*,*) '*** 2fc ver5.3.1 ***'`이다. 이 문구는 문서 예제와 현재 실행 배너가 다름을 입증한다. 이 문구만으로 각 E 행의 동작 변경 시점을 정하지 않는다.

날짜 검색은 해당 파일에 `rg -n '20[01][0-9][./][01][0-9]'`를 적용했다. `3D/vf_a1main.f:33–35`의 `C----------------------------------------------------------2012.03 start`와 `C----------------------------------------------------------2012.03 end` 사이에는 `      INCLUDE 'VF_ASEABT.h'`가 있다. `2F/vf_a1main.f:33–35`의 `C----------------------------------------------------------2016.09 start`와 `C----------------------------------------------------------2016.09 end` 사이에도 같은 INCLUDE가 있다. 이 블록은 해저 지형 관련 선언의 표지이다. 이 블록은 다른 파일의 압축항이나 초기화 누락을 둘러싸지 않는다. PDF 생성일과 단일 git 커밋 날짜는 개별 동작의 변경일로 사용하지 않았다.

영어 이미지의 기준 폴더는 `/tmp/claude-1000/-home-firesinger-coastal-wiki/338e5a20-3378-4629-86f1-592f9d629b53/scratchpad/cadpages/`이다. 일본어 이미지의 기준 폴더는 같은 scratchpad 아래 `cadjp/`이다. 이 작업에서 만든 일본어 이미지는 `E1-3d-NNN.png`와 `E1-2f-NNN.png`이다. 표에서 인용한 식·수치·표는 해당 쪽 이미지로 판정했다.

다른 시뮬레이터 검색은 Simulators 아래 STR3D와 AGENT의 Fortran 소스 및 헤더를 대상으로 했다. 검색식 `SUBROUTINE VF_(V1EOS\|VPDRDT)\|DRHODT\|ILPON\|CWMTB\|VF_SDIFF`의 결과는 0건이었다. 동일 쟁점의 대체 구현 근거는 아래 표의 3D·2F 사본과 같은 사본의 다른 경로에서 인용한다.
