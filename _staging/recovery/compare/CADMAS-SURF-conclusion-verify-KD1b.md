보고서 §5에서 KD1-154–306을 센 대상은 153행이다. 아래 행별 최종 결론 표에서 분류를 센 결과는 다음과 같다.

보고서 결론의 분류를 유지한 행은 72행이다. 분류를 바꾼 행은 81행이다. 인용의 해석이나 빠진 조건을 보정한 행은 43행이다. 해당 행의 이유 칸에는 `[인용 보정]`을 표시했다. 직접 인용된 코드 줄의 문자열과 본문의 diff는 원본 두 사본과 일치했다.

E·강함은 KD1-160, KD1-190, KD1-224이다. 각 행에는 자기 주석과 다른 코드 경로의 모순을 기록했다. 각 행에는 의도된 설계를 뒷받침할 반대 경로의 검토 결과도 기록했다.

A는 두 상별 값·물성·압력 처리의 변경과 MG/2FC 연성 표지로 연결되는 사본 차이에 적용했다. 이동 장애물 처리와 별도 입출력 동작은 C로 구분했다. 같은 사본 diff가 있다는 이유만으로 두 상 기능과 무관한 행을 A로 유지하지 않았다.

`3D`와 `3D2F`는 `models/CADMAS-SURF/raw/source_code/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/` 아래 각 `CADMAS-SURF-3D/Source code/`와 `CADMAS-SURF-3D2F/Source code/`를 뜻한다. 파일:줄은 이 경로를 기준으로 한다.

대상은 보고서 §5의 KD1-154–306이다. 근거는 같은 ID의 앞 절과 해당 원본 코드다. 이 행들의 문서 칸은 3D 소스 사본을 인용한다. 대상 행에는 매뉴얼 쪽 인용이 없다. 외부 원문 판정의 X 8행은 이 ID 범위에 포함되지 않는다.

`바뀜`은 보고서의 최종 분류 변경을 센다. 보고서 이유에 이미 있는 E 강도의 표기 보충은 분류 변경으로 세지 않는다. `인용 보정`은 인용의 의미·조건·수량을 고친 행을 뜻한다. 식을 원문 표기로 펼친 것과 A 판 근거를 추가한 것은 인용 보정으로 세지 않는다.
