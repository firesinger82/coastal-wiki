## 1 요약

대상은 [입력 대조 보고서](swash-inputs-setup-vs-code.md)의 §5 E 행 10개이다.
대상은 [출력 대조 보고서](swash-outputs-vs-code.md)의 §5 E 행 16개를 포함한다.
전체 대상 행 수는 두 보고서의 §5에서 추출한 고유 행 ID 26개이다.
같은 결함을 다룬 행도 행 ID별로 집계한다.
이 문서는 원문 인용과 AI의 정적 판정을 구분한 기록이다.

각 행의 핵심 조건·식은 11.01 배포본에도 존재한다.

A가 0인 근거는 표에 제시한 전체 이력과 배포본 대조이다.
회귀 도입 커밋의 존재만으로 현재 12.01 문서와 같은 시점의 결함을 A로 바꾸지 않았다.

`fefa39d 2024-08-01 remove folder from repository`은 src 디렉터리를 삭제한다.

따라서 표의 도입 커밋은 `git blame main -L N,M -- src/X`의 귀속 커밋과 `git log --all -S/-G`·`git show`로 확인한 최초 등장을 함께 적는다.

외부 파일의 상대 경로 기준은 `_staging/recovery/extract/SWASH/external/`이다.

`problems_and_fixes.htm:29` `Any future updates, including fix bugs and resolved issues, will be added to the`는 이후 수정을 GitLab에 반영한다고 알린다.
