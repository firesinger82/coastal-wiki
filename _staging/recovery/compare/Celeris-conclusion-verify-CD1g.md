# Celeris 차이 결론 원문 재대조 — CD1-1051–1225

## 1 요약

대상은 `celeris-docs-architecture-vs-code.md`의 `## 5 차이 결론`에 있는 CD1-1051–CD1-1225다. 대상 행 수는 175행이다. 이 범위의 보고서 분류는 모두 C다. 기존 H 행은 이 범위에 없다.

| A 판 차이 | 0 |
| B 문서 오기 | 0 |
| C 문서 누락 | 153 |

집계는 아래 행별 최종 결론 표의 175개 ID를 기준으로 했다. `바뀜`은 분류 또는 결론 문장의 사실·조건이 달라진 경우다. 인용 수정 1행은 CD1-1051의 주석 조건 보완이다. 원문 인용 문자열 자체의 수정은 0행이다. 해당 행의 최종 분류는 H다. 보고서의 결론 문장 오류를 원문 문서의 오기 B로 세지 않았다.

코드와 저장소 문서의 기준 경로는 `models/Celeris/raw/source_code/Celeris-WebGPU/`다. 판은 `ebca435d02b258768e0352fbaf27404f2f135799`다. `git log -1`로 확인한 커밋 날짜는 2026-07-20이다. 인용은 `ebca435:파일:줄` 형식을 썼다. 확인한 파일의 현재 내용과 이 판 사이에는 `git diff ebca435 -- <확인 파일>` 차이가 없었다.

본문의 같은 ID에서 찾은 HTML 인용 1,356개를 원문 줄과 대조했다. 결론 절의 HTML 인용 294개도 원문 줄과 대조했다. 이 수에는 반복된 select 시작 줄이 포함된다. 공백 들여쓰기를 제외한 인용 문자열은 모두 일치했다. HTML 주석 범위와 호스트 입력 연결을 추가로 확인했다. 모델을 실행하지 않았다.

문서 누락의 대상은 보고서가 지정한 `README.md`, `ARCHITECTURE.md`, `docs/README.md`, `docs/architecture/CONFIGURATION.md`, `DATA_AND_TEXTURES.md`, `REFERENCE_PAPERS.md`, `SIMULATION_PIPELINE.md`, `WEBGPU_BINDING_PATTERN.md`다. 이 8문서의 원문을 읽었다. C는 해당 입력의 숫자 대응 또는 HTML 고정 기본값 유무 같은 세부가 이 문서들에 빠진 경우다. 기능 개요가 있는 경우에는 이유 칸에 구별해 적었다. 관련 `docs/source/` 가이드도 분류의 보조 근거로 확인했다. HTML value 속성이 없다는 문장은 실행 중 값이나 JavaScript 기본값이 없다는 뜻이 아니다. 호스트는 `ebca435:js/main.js:4652–4669`에서 현재 값을 입력에 반영한다.

화면의 색상·지도·화살표·로고·Explorer 표시 항목은 H로 분류했다. `showBreaking`은 스칼라 상태에도 영향을 주므로 C로 유지했다. GIF·JPEG 출력 입력은 파일 저장과 render_step 제어에 연결되므로 C로 유지했다. 문서가 숫자와 모델 동작의 대응을 이미 설명한 입사파 종류 0·1, 방향별 경계 종류 5, 방정식 종류 0·1은 일치로 바꿨다.

`Celeris-version-verify-AD1.md`, `AD2.md`, `AD3.md`, `E1.md`, `E2.md`에서 대상 ID에 해당하는 판 판정 행은 없었다. 표의 판 판정 결론은 모두 `-`다. 대상 행은 논문 문장·식·표를 인용하지 않는다. 논문 쪽 이미지와 CP3-013·CP3-017의 외부 문헌은 이 범위의 판정 근거로 사용하지 않았다.
