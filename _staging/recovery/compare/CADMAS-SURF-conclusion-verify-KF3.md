# CADMAS-SURF KF3 차이 결론 원문 재대조

## 1 요약

대상은 `cadmas-2f-manual-input-vs-code.md`의 §5에 있는 KF3-002–198 중 114행이다.
최종 결론은 A 판 차이 16행, B 문서 오기 42행, C 문서 누락 29행이다.
D 문서에만 있음은 0행이다.
E 코드 결함 후보는 강함 1행, 중간 0행, 약함 0행이다.
F 표기 차이는 0행이다.
H 코드 대조 대상 아님은 26행이다.
일치는 0행이다.
위 개수는 아래 행별 표의 최종 결론 칸에서 집계했다.

보고서 결론에서 분류가 바뀐 행은 9행이다.
해당 행은 KF3-040·045·061·063·066·093·096·186·198이다.
보고서의 분류를 유지한 행은 105행이다.
인용 또는 조건 해석을 고친 행은 9행이다.
해당 행은 KF3-005·049·066·131·161·174·178·185·198이다.

`바뀜`은 보고서 §5와 비교한 분류 또는 E 강도의 변경이다.
인용 수정은 원문 인용이나 조건 해석을 바로잡은 행이며 이유 칸에 표시한다.
판 근거와 설명을 추가한 것만으로는 인용 수정으로 세지 않는다.

코드 경로의 `2F/`는 `models/CADMAS-SURF/raw/source_code/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/CADMAS-SURF-3D2F/Source code/`다.
`3D/`는 같은 Simulators 아래 `CADMAS-SURF-3D/Source code/`다.
EN은 CADMAS-2F 영어 매뉴얼의 PDF 쪽이다.
JP는 CADMAS-2F 일본어 매뉴얼의 PDF 쪽이다.
EN 쪽 이미지는 지정된 `cadpages/cad-2f-manual-NNN.png`를 사용했다.
JP 쪽 이미지는 지정된 `cadjp/`의 해당 쪽을 사용했다.
AD2와 E1은 같은 디렉터리의 `CADMAS-SURF-version-verify-AD2.md`와 `CADMAS-SURF-version-verify-E1.md`다.
외부 원문 판정 파일의 최종 8행에는 KF3 행이 없다.
