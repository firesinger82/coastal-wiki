# Celeris 차이 결론 재대조 — CD1f

## 1 요약

대상은 보고서 §5의 CD1-876–CD1-1050이다. 대상 행 수는 아래 표에서 센 175행이다.

| 최종 결론 | 행 수 |
|---|---:|
| A 판 차이 | 1 |
| B 문서 오기 | 0 |
| C 문서 누락 | 83 |
| D 문서에만 있음 | 0 |
| E 코드 결함 후보 | 0 |
| F 표기 차이 | 0 |
| H 코드 대조 대상 아님 | 91 |
| 일치 | 0 |
| 합계 | 175 |

보고서의 분류를 유지한 행은 84행이다. 보고서의 분류를 바꾼 행은 91행이다. 표의 ‘바뀜’은 분류의 변경을 뜻한다. 결론 문장의 인용·조건을 고친 행은 122행이다. 이 개수는 이유 칸에 ‘인용·조건 보정’을 적은 행을 센 값이다. 이 개수에는 원문 식의 명시, 빠진 조건의 보충, 본문 인용의 숨김·주석 상태 보충을 포함한다. 분류 변경과 인용·조건 보정은 중복될 수 있다.

코드와 저장소 문서의 짧은 경로는 `models/Celeris/raw/source_code/Celeris-WebGPU/` 기준이다. 기준판은 `ebca435d02b258768e0352fbaf27404f2f135799`이다. 해당 커밋 날짜는 2026-07-20이다. 확인한 원문 범위에 대한 `git diff ebca435 --stat` 결과는 비어 있었다.

C의 문서 범위는 원 보고서의 대상 8문서다. 대상은 `README.md`, `ARCHITECTURE.md`, `docs/README.md`, `docs/architecture/CONFIGURATION.md`, `docs/architecture/DATA_AND_TEXTURES.md`, `docs/architecture/REFERENCE_PAPERS.md`, `docs/architecture/SIMULATION_PIPELINE.md`, `docs/architecture/WEBGPU_BINDING_PATTERN.md`이다. 이 문서들의 원문을 읽었다. C는 저장소의 모든 source guide에 해당 설명이 없다는 뜻이 아니다. 표의 문서 칸에서 ‘대상 8문서’나 한국어 항목명은 보고서의 분석 표제다. 원문 인용문으로 취급하지 않았다.

AD1·AD2·AD3·E1·E2 판 판정 파일에는 이 대상 행 ID의 확정 결론이 없다. 따라서 해당 칸은 모두 `-`다. CP3-013·CP3-017은 다른 대조 행의 판정이다. 그 판정을 CD1-933·CD1-938의 코드 설명에 옮기지 않았다.

논문 대조가 필요한 CD1-941은 Tavakkol 2020의 p.1·p.3·p.4 쪽 이미지를 직접 열었다. 이미지 경로의 기준은 `/tmp/claude-1000/-home-firesinger-coastal-wiki/338e5a20-3378-4629-86f1-592f9d629b53/scratchpad/celpages/`이다. 판독 기록은 쪽 위치를 찾는 색인으로만 사용했다. 이 범위의 나머지 행은 논문 문장·식·표를 직접 인용하지 않는다.

판정은 정적 원문 대조다. 모델과 브라우저는 실행하지 않았다. 수치 정확도와 성능은 시험하지 않았다. 원 보고서와 원자료는 수정하지 않았다. 표는 30행씩 나누어 기록했다. 마지막 표는 25행이다.
