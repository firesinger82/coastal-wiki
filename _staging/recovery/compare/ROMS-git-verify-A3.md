# ROMS 대조 보고서 A 행의 git 이력 확정 A3

## 1 요약

대상은 사용자 지정 131행이다. 원 결론은 모두 A 판 차이이다. 확정 결론은 A 122행, B 4행, C 0행, D 2행, F 3행, H 0행이다. 이 수량은 2절의 고유 행 ID를 센 값이다. 지정 행의 누락과 중복은 없다. 대상 문서는 모두 Options.wiki이다. ChangeLog 행은 없다.

B는 RBH-1193·RBH-1198·RBH-1305·RBH-1308이다. D는 RBH-1217·RBH-1302이다. F는 RBH-1288·RBH-1289·RBH-1290이다. 나머지 행은 A로 확정했다.

이 문서는 AI가 작성한 판정 기록이다. 백틱 안의 원문과 한국어 결론을 구분한다. 코드 기준은 `57aecf58 2026-09-18 Reporting Computer Memory Availability and Usage (#81)`이다. 코드 경로는 `models/ROMS/raw/source_code/roms/`를 기준으로 쓴다. `wiki-revid-6053`은 `models/ROMS/raw/manuals/wiki/manifest.json`의 Options 쪽 revid이다. 위키 경로는 `models/ROMS/raw/manuals/wiki/wikitext/`를 기준으로 쓴다. 사본 수집일은 2026-05-03이다. 이 날짜를 위키 서술의 작성일로 사용하지 않는다.

각 옵션의 `git log -S` 또는 `git log -G`를 조회했다. 공개 태그의 파일은 `git show TAG:path`로 대조했다. roms-2.0부터 roms-2.2까지는 `Include/`, `Nonlinear/`, `Modules/` 경로를 사용한다. 그 뒤의 판은 `ROMS/` 아래 경로를 사용한다. 표의 변경 커밋은 해당 서술과 현재 코드의 차이를 만든 커밋이다. 날짜는 저자 날짜이다.
