# Celeris E 행 git 이력·반대 증거 판정

## 1 요약

아래 판정 표의 45행은 E 유지 6행과 재분류 39행으로 확정했다.
E 유지 6행의 강도는 모두 강함이다.
E 유지 중간은 0행이다.
E 유지 약함은 0행이다.
재분류는 A 판 차이 34행과 H 비교 대상 아님 5행이다.
B·C·F 재분류는 각각 0행이다.
E 유지 행 ID는 CT1-183·CT1-196·CT1-224·CT1-336·CT1-358·CT1-362다.
CT1-358은 CT1-196의 코드 문제를 다시 인용한다.
CT1-362는 CT1-183의 코드 문제를 다시 인용한다.
CT1-224와 CT1-336은 여러 차이를 포함한 행이다.
두 행의 E 근거와 A 성격의 부수 변경은 판정 표에서 구분했다.

대상은 `celeris-transect-vs-main.md`의 「## 5 차이 결론」에서 원 결론이 E인 45행이다.
행 수는 결론 표의 행 ID를 센 값이다.
같은 코드 문제를 다시 인용한 노트 행도 별도 행으로 센다.
현재 원문의 기준은 로컬 원자료 저장소의 `ebca435`다.
코드 경로는 `models/Celeris/raw/source_code/Celeris-WebGPU/`를 기준으로 쓴다.
표의 인용은 원문이다.
인용 밖의 판정과 결론 문장은 AI 분석이다.

A는 이번 요청의 정의를 적용한다.
본판에만 후속 변경이 들어간 경우에는 결함 수정이라는 커밋 메시지가 있어도 A로 분류한다.
H는 현재 진입점에서 호출되지 않는 보존 코드를 활성 모델 비교에서 제외한다.
각 파일의 전체 `git log --follow`를 조회했다.
표의 도입 열에는 transect 경로가 생긴 뒤의 파일 변경 목록을 적는다.
복제 이전의 본판 이력은 transect 경로의 최초 추가와 구분한다.
표의 후속 변경 열에는 해당 줄을 바꾼 본판 커밋을 적는다.
