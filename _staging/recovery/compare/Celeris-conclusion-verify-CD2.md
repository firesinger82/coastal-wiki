# Celeris CD2 차이 결론 재대조

## 1 요약

대상은 보고서 §5의 CD2-001–999 중 실제로 있는 119행이다. 아래 행별 표의 최종 결론은 A 1행, B 11행, C 45행, D 0행, E 2행, F 2행, H 57행, 일치 1행이다. E 2행의 강도는 모두 강함이다.

아래 표에서 보고서의 분류를 유지한 행은 108행이다. 보고서의 분류에서 바뀐 행은 11행이다. 변경 행은 CD2-371·390·422·428·456·462·474·475·477·482·483이다.

인용을 고친 행은 7행이다. 집계 대상은 인용문의 출처 귀속 또는 코드 인용의 조건·식 해석을 고친 CD2-292·431·448·451·452·480·481이다. 단순 문장 정리와 원문에 이미 있던 조건·식의 추가 인용은 이 수에 넣지 않았다.

재개 시 완료되어 있던 90행은 보존했다. 이번 재개에서는 나머지 29행의 원문을 대조했다. 모델 실행과 수치 검증은 하지 않았다.

코드·저장소 문서의 상대 경로 기준은 models/Celeris/raw/source_code/Celeris-WebGPU/다. 현재 판은 ebca435다. NOTE 인용은 models/Celeris/ 아래 실제 노트 경로로 표시한다. 바뀜은 보고서와 최종 분류의 차이다. 문장 보완과 E 강도 명시는 분류 변경 수에 넣지 않는다.
