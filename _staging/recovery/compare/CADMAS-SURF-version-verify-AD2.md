아래 수치는 §2–§4의 판정 표에서 집계했다.

확정 결론은 A 44행, B 132행, D 1행, F 1행이다.
분류가 바뀐 행은 15행이다.
마지막 줄의 “그 밖 재분류”는 A→B 10행과 A→F 1행의 합계다.

날짜 표지는 해당 기능을 감싼 블록에만 적용했다.
`2016.09 start`가 있는 MAIN의 `INCLUDE 'VF_ASEABT.h'` 블록을 다른 기능의 변경일로 사용하지 않았다.
사본의 차이는 대응 원문을 나란히 인용했다.
주석으로 남은 이전 문장은 활성 문장과 구분했다.
영어판만 일본어판·코드와 다르면 B를 적용했다.
D 행의 주석 호출 흔적은 사용자 지정 기준에 따라 A로 판정했다.

문서 쪽 번호는 별도 표시가 없으면 PDF 쪽 번호다.
2F 영어판 PDF p.1의 인쇄 쪽 번호는 `463`이다.
2F 일본어판 PDF p.1의 인쇄 쪽 번호는 `1`이다.
2F 영어판 p.145와 일본어판 p.132의 `Ver.1.0`은 실행 예제의 배너다.
배포 코드의 `IVR001=  0, IVR002=  2`와 `*** 2fc ver5.3.1 ***`은 서로 다른 출력 표지다.
이 차이는 KF3-113에 인용했다.
PDF 생성일과 단일 git 커밋 날짜는 기능 변경일의 근거로 사용하지 않았다.

코드 경로의 기준 `S`는 `models/CADMAS-SURF/raw/source_code/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators`다.
`3D 파일:줄`은 `S/CADMAS-SURF-3D/Source code/파일`을 뜻한다.
`2F 파일:줄`은 `S/CADMAS-SURF-3D2F/Source code/파일`을 뜻한다.
영어판과 일본어판은 `S/CADMAS-SURF-3D2F/Manual/`의 `CADMAS-2F_Manural_English.pdf`와 `CADMAS-2F_Manual_Japanese.pdf`다.
식·숫자·표의 문서 인용은 쪽 이미지와 대조했다.
수식은 원문의 첨자와 연산자를 보존해 옮겼다.
압축성 노트는 `models/CADMAS-SURF/manual-notes/cadmas-2f-manual-compressibility.md`다.
“노트에 쓸 결론 문장”은 제안 문장이다.
