이 파일은 AI가 원문을 다시 대조하여 작성한 판정 기록이다.

## 1 요약

대상은 `lisflood-par-vs-code.md`의 `## 5 차이 결론`에 있는 LI1 행 전부이다.
대상 행 수는 해당 절의 고유 행 ID를 세어 181행으로 확인했다.
최종 결론별 개수는 아래 행별 표에서 집계했다.

| 최종 결론 | 행 수 |

| A | 31 |
| B | 15 |
| C | 109 |
| D | 2 |
| E | 13 |
| F | 2 |
| H | 9 |
| 일치 | 0 |

E의 강도는 강함 12행, 중간 1행, 약함 0행이다.
LI1-317의 E는 v8.2에 한정된 판정이다.
이 행의 결함은 현재 8.3에서 수정됐다.
보고서 결론에서 바뀐 행은 42행이다.
보고서 결론을 유지한 행은 139행이다.
인용을 고친 행은 23행이다.

`바뀜`은 보고서와 분류, E 강도, 또는 결론의 사실·조건이 달라진 경우이다.
출처 추가와 문체 정리만 한 경우는 유지로 센다.
`인용 교정`은 원문 인용의 글자·위치 또는 결론에서 빠진 조건·수량을 고친 행이다.
해당 행의 이유에 `인용 교정`을 표시한다.

코드 상대 경로의 기준은 `models/LISFLOOD-FP/raw/source_code/LISFLOOD-FP/`이다.
`v8.0:`의 기준은 `_staging/recovery/extract/LISFLOOD-FP/external/v8.0/LISFLOOD-FP-trunk/`이다.
