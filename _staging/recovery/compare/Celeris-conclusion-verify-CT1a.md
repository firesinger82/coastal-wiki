# Celeris 차이 결론 재대조 — CT1-001–127

## 1 요약

대상은 보고서 §5의 CT1-001–127 전부다. 아래 표에서 센 대상 행은 127행이다. 최종 판정의 유지 행은 96행이다. 최종 판정의 변경 행은 31행이다.

| 최종 결론 | 행 수 |
|---|---:|
| A 판 차이 | 48 |
| B 문서 오기 | 0 |
| C 문서 누락 | 0 |
| D 문서에만 있음 | 0 |
| E 코드 결함 후보 | 2 |
| F 표기 차이 | 59 |
| H 코드 대조 대상 아님 | 17 |
| 일치 | 1 |
| 합계 | 127 |

E의 강함은 CT1-087의 1행이다. E의 중간은 CT1-122의 1행이다. E의 약함은 0행이다.

인용을 고친 행은 아래 행별 이유의 ‘인용 보정’을 센 17행이다. 이 수는 잘못된 근거 위치·함수 귀속·원문 요약과 빠진 조건을 고친 행을 센다. 정확한 조건문을 단순히 덧붙인 행과 A의 커밋만 보완한 행은 이 수에 넣지 않았다. 해당 행은 CT1-054, CT1-055, CT1-056, CT1-057, CT1-067, CT1-080, CT1-084, CT1-087, CT1-088, CT1-089, CT1-090, CT1-091, CT1-096, CT1-105, CT1-113, CT1-122, CT1-126이다.

검증 기준은 이번 사용자 지시다. 원문 경로의 기준 디렉터리는 `models/Celeris/raw/source_code/Celeris-WebGPU/`다. `ebca435`는 현재 본판과 transect 사본을 함께 담은 커밋이다. `git diff ebca435 -- .`의 출력은 없었다. 판 판정 열의 AD3·E2는 각각 `Celeris-version-verify-AD3.md`·`Celeris-version-verify-E2.md`의 확정 결론을 뜻한다. 참고 대상으로 지정된 AD1·AD2·E1에는 이 대상의 대응 판정 행이 없었다.

바뀜 열은 보고서와 최종 판정의 분류 또는 E 강도가 달라졌는지를 뜻한다. 문장·인용 보완은 별도로 집계했다. 개행 차이 52행은 양쪽 원파일의 CRLF 바이트를 다시 셌다. 나머지 75행은 같은 ID의 본문 diff와 결론 인용을 원파일에서 다시 대조했다. 본문 CT1-064의 공통 문맥에는 원파일 행 끝 공백 두 글자가 생략돼 있었다. 이 공백은 결론의 내용과 인용 보정 행 수에 영향을 주지 않는다.

이 대상의 직접 근거는 코드와 커밋이다. 논문 문장·식·표를 판정하는 행은 이 대상에 없다. 논문 쪽 이미지와 CP3의 외부 문헌 판정은 사용하지 않았다. 모델 실행과 수치 결과 검증은 수행하지 않았다. 아래 결과는 원문에 근거한 정적 판정이다.
