# ShorelineS A·E 행 git 이력 판정

## 1 요약

대상은 두 보고서의 지정 표에서 추출한 23행이다.
이론 보고서의 대상은 A 7행과 E 7행이다.
흐름 보고서의 대상은 A 3행과 E 6행이다.
2절 판정표의 A 확정은 0행이다.
2절 판정표의 A 재분류는 B 문서 오기 4행과 C 문서 누락 6행이다.
3절 판정표의 E 유지는 강함 10행과 중간 3행이다.
3절 판정표의 E 재분류는 0행이다.
집계는 보고서별 행 ID를 기준으로 했다.
이론 K025와 흐름 V04는 같은 코드 문제를 가리키지만 각각 한 행으로 집계했다.

이론은 [ShorelineS-theory-vs-code.md의 5절](ShorelineS-theory-vs-code.md#5-차이-결론)을 뜻한다.
흐름은 [ShorelineS-callflow.md의 8절](../flow/ShorelineS-callflow.md#8-차이-결론)을 뜻한다.
코드 기준은 `models/ShorelineS/raw/source_code/shorelines`의 `f3ec8638`이다.
`git rev-list --count HEAD`의 결과는 47이다.
`git diff 7bf4481 f3ec8638 --stat`의 변경 파일은 `doc/ShorelineS_manual_v1.0.pdf` 하나이다.
원문 줄은 `git show REV:functions/X.m | iconv -f latin1 -t utf8 | sed -n 'N,Mp'`로 확인했다.
도입 시점은 현재 줄의 `git blame -w` 결과와 이전 리비전의 원문을 함께 대조했다.
표의 커밋 날짜는 Git의 커밋 날짜이다.

문서 시점 커밋은 `git rev-list -1 --before=DATE HEAD`로 선택했다.
FMarS2020의 기준일은 PDF 1쪽의 `published: 03 July 2020`이다.
