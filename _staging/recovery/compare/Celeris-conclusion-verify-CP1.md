# Celeris 2017 대조 보고서 차이 결론 재확인

## 1 요약

대상은 `celeris-tavakkol2017-vs-code.md`의 「## 5 차이 결론」에 있는 CP1-001–999 표 행이다. 원 보고서에서 128행을 추출했다. 이 파일의 행 ID 집합은 대상 행 ID 집합과 같다. 누락과 중복은 없다.

최종 결론별 개수는 제2절의 최종 결론 열에서 집계했다.

| 최종 결론 | 행 수 |
|---|---:|
| A 판 차이 | 37 |
| B 문서 오기 | 26 |
| C 문서 누락 | 30 |
| D 문서에만 있음 | 0 |
| E 코드 결함 후보 | 3 |
| F 표기 차이 | 4 |
| H 코드 대조 대상 아님 | 27 |
| 일치 | 1 |
| 합계 | 128 |

E의 강도는 강함 2행과 중간 1행이다. 보고서 결론을 유지한 행은 125행이다. 보고서 결론에서 바뀐 행은 3행이다. CP1-143은 F에서 B로 바뀌었다. CP1-147은 A에서 B로 바뀌었다. CP1-150은 F에서 일치로 바뀌었다.

인용을 고친 행은 제2절 이유 열의 ‘인용 보완’ 또는 ‘인용 교정’ 표시를 기준으로 16행이다. 해당 행은 CP1-014·022·023·055·109·112·113·114·116·120·128·131·132·147·160·168이다.

이번 재개 시점에는 대상 128행의 판정 기록이 모두 있었다. 완료된 행을 건너뛰라는 지시에 따라 기존 행별 기록을 유지했다. 이번 재개에서는 원문을 다시 열지 않았다. 대상 행과 기록 행의 대응 및 표의 집계를 확인했다. 요약 집계와 마지막 완료 문장을 추가했다.

이 파일은 AI가 원문을 대조한 판정 기록이다. 백틱 안의 코드와 문구는 원문 인용이다. 이유와 결론 문장은 판정자의 서술이다. 모델은 실행하지 않았다.

코드 상대 경로의 기준은 `models/Celeris/raw/source_code/Celeris-WebGPU/`이다. 현재 코드는 `ebca435`이다. `위키 HASH:models/...`는 저장소 루트의 노트 이력이다. P17은 `docs/Tavakkol_2017_Celeris_GPU_accelerated_Computer_Physics_Communications.pdf`이다. P20은 `docs/Tavakkol_2020_Celeris_Base_interactive_Computer_Physics_Communications.pdf`이다. P26은 `docs/lynett-et-al-2026-an-interactive-nearshore-wave-simulator-for-rapid-design-prototyping-and-natural-hazard-education.pdf`이다. 쪽 번호는 PDF 첫 쪽을 1로 센 값이다. P17 p.1–11, P20 p.1·3, P26 p.1은 지정된 `celpages` 쪽 이미지를 직접 열었다.

판 판정 열의 A·B는 `Celeris-version-verify-AD1.md`에서 가져왔다. E는 `Celeris-version-verify-E1.md`에서 가져왔다. AD2·AD3·E2에는 이 대상 행의 별도 판정이 없다. CP3-013·CP3-017은 대상이 아니므로 외부 문헌으로 판정 범위를 넓히지 않았다. C의 누락 기준은 각 행이 지정한 2017 논문 또는 위키 노트이다. 다른 현행 문서의 설명 유무와 혼동하지 않는다.

‘바뀜’은 보고서의 분류 또는 E 강도가 달라졌는지를 뜻한다. 인용 수정은 글자·식·줄 위치의 교정과 판단에 필요한 조건의 보완을 센다. A의 필수 판 구분 문장과 E의 필수 강도 표기만 추가한 경우는 인용 수정으로 세지 않는다. 인용 수정 행의 이유에는 ‘인용 보완’ 또는 ‘인용 교정’을 적는다.
