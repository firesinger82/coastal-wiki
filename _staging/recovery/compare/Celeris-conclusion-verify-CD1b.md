# Celeris 차이 결론 원문 재대조 — CD1-176–350

## 1 요약

대상은 `celeris-docs-architecture-vs-code.md`의 `## 5 차이 결론`에 있는 CD1-176–350 중 49행이다. 같은 범위의 본문 175행 전체를 뜻하지 않는다. 대상 ID는 아래 표에 모두 기록한다.

현재 원문 기준은 `models/Celeris/raw/source_code/Celeris-WebGPU/`의 `ebca435`다. 현재 코드 판의 날짜는 `git log -1`에서 확인한 2026-07-20이다. 표의 `HASH:파일:줄`은 이 원문 저장소를 기준으로 한다. 판 판정 열의 AD2는 `Celeris-version-verify-AD2.md`다. AD1·AD3·E1·E2에는 대상 ID의 판정이 없다.

아래 표 49행의 최종 분류는 A 0행, B 5행, C 0행, D 0행, E 0행, F 0행, H 38행, 일치 6행이다. 보고서 결론의 분류를 유지한 행은 42행이다. 분류를 바꾼 행은 7행이다. 변경 ID는 CD1-307·316·326·330·335·340·342다.

직접 인용의 글자를 고친 행은 0행이다. 본문과 결론에서 추출한 파일·줄·인용문 조합 351개를 현재 원문 줄과 대조했다. 이 횟수에는 본문과 결론의 중복 인용이 포함된다. 인용의 Markdown 표 이스케이프는 원래 문자로 되돌려 비교했다. 문장 도입 판과 문서 갱신 판의 코드도 별도로 열었다. 결론 문장의 조건·대상·판정 범위 보완은 각 행의 이유에 기록했다.

대상 행의 본문 인용과 결론 인용을 각각 원문 줄에서 확인했다. 대상 행에는 논문 쪽이나 CP3-013·CP3-017의 외부 문헌 인용이 없다. 따라서 이번 판정에는 논문 판독 기록이나 2차 문헌을 근거로 사용하지 않았다. 현재 인용 파일에 대한 `git diff ebca435 -- …` 결과는 비어 있었다. 모델 실행은 하지 않았다.
