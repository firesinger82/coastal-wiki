# CADMAS-SURF E 행 판·반대 증거 재판정

## 1 요약

세 대상 보고서의 `## 5 차이 결론`에서 결론 열이 E인 행 28개를 집계했다. STR 이론 보고서는 2행이다. STR 데이터표 보고서는 11행이다. AGENT 보고서는 15행이다. 같은 결함을 반복한 행도 행 ID별로 셌다.

아래 판정 표의 확정 결론은 E 유지 23행이다. 강함은 21행이다. 중간은 1행이다. 약함은 1행이다. 재분류는 B 1행과 C 4행이다. A·F·H는 각각 0행이다. 강도는 정적 근거의 강도다.

보고서 이름 `STR 이론`, `STR 데이터표`, `AGENT`는 각각 이 폴더의 `cadmas-str-docs-theory-vs-code.md`, `cadmas-str-datatable-vs-code.md`, `cadmas-agent-docs-vs-code.md`를 뜻한다. 코드 경로의 공통 접두사는 `models/CADMAS-SURF/raw/source_code/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/`이다. `2F/`, `3D/`, `STR/`, `AGENT/`는 각각 그 아래 `CADMAS-SURF-3D2F/Source code/`, `CADMAS-SURF-3D/Source code/`, `STR3D/Source code/`, `AGENT/Source code/`를 뜻한다. 인용 뒤의 한국어 문장은 원문에 대한 판정이다.

문서 쪽은 PDF 쪽 번호다. 인쇄 쪽 번호가 다르면 함께 적었다. `영문 AGENT`는 `pdf/cad-agent-manual.txt`에 대응한다. `일문 AGENT`는 `pdf-jp/CADMAS-AGENT_Manual_Japanese.txt`에 대응한다. 두 디렉터리의 공통 접두사는 `_staging/recovery/extract/CADMAS-SURF/`이다. 표와 숫자는 사용자 지정 `scratchpad/cadpages/` 이미지와 이번에 만든 `scratchpad/cadjp/*e2*.png`에서 판독했다.

판 표지의 공통 근거는 다음과 같다. `AGENT/main.f90:13`은 `write(*,*)"agent_ver3.5 start"`다. 일문 튜토리얼 PDF p.3은 `Inputデータ ※マニュアルver3.5参照`라고 적는다. 같은 튜토리얼 p.10·17에는 `Inputデータ ※マニュアルver3.3参照`가 남아 있다. 영문 AGENT p.30과 일문 AGENT p.31의 인용 문헌에는 `APAC2023, 2023. (in press)`가 있다. 이는 문서 내용에 포함된 시점의 근거다. PDF 생성일을 코드 변경일로 사용하지 않았다.

`diff -u`로 연 `3D/vf_a1main.f`와 `2F/vf_a1main.f`에는 각각 `C----------------------------------------------------------2012.03 start`와 `C----------------------------------------------------------2016.09 start`가 있다. 판 출력문은 각각 366행의 `IF (MGRANK.EQ.0) WRITE(*,*) '*** ver4.9.1 ***'`와 293행의 `IF (MGRANK.EQ.0) WRITE(*,*) '*** 2fc ver5.3.1 ***'`다. 이 표지는 본 표의 SF·STR·AGENT 결함 줄을 둘러싸지 않는다. `cadmas-3d2f-identical-to-3d.txt`와 두 소스 디렉터리의 파일명을 대조했다. 본 표의 결함 본문에는 3D·3D2F 공통 사본이 없다. 다른 구현 경로가 있는 경우에는 해당 행에 따로 인용했다.

각 행의 근거 파일에 `rg -n '20[01][0-9][./][01][0-9]'`를 적용했다. 대상 결함 줄을 둘러싼 날짜 블록은 없었다. 판 주석 검색에서 관련 파일에 남은 표지는 `AGENT/remesh.f90:110`의 `!!! modify ver3.4`였다. 그 표지와 옛 주석 줄의 적용 범위는 KA1-434에서 판정했다. 날짜가 없는 차이를 시간 순서만 추정해서 A로 분류하지 않았다.
