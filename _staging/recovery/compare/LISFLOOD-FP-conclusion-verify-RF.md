# LISFLOOD-FP 흐름 보고서 차이 결론 최종 대조

## 1 요약

대상은 `_staging/recovery/flow/LISFLOOD-FP-callflow.md`의 §8.2 차이 결론 표다.
대상은 RF-001부터 RF-030까지 30행이다.
H로 분류된 RF-011·RF-012도 포함했다.

최종 분류별 개수는 §2의 최종 결론 열에서 집계했다.

| 최종 결론 | 행 수 |
|---|---:|
| A | 6 |
| B | 8 |
| C | 7 |
| D | 0 |
| E | 6 |
| F | 1 |
| H | 2 |
| 일치 | 0 |
| 합계 | 30 |

보고서 결론에서 바뀐 행은 4행이다.
RF-003·RF-004는 B에서 A로 바뀌었다.
RF-030은 C에서 B로 바뀌었다.
RF-005는 E의 강함에서 중간으로 바뀌었다.
바뀜 열은 분류 또는 E 강도의 변경을 뜻한다.
이 기준으로 유지한 행은 26행이다.
E의 최종 강도는 강함 5행과 중간 1행이다.

인용을 고친 행은 10행이다.
해당 행은 RF-003·RF-004·RF-005·RF-007·RF-009·RF-014·RF-019·RF-021·RF-022·RF-030이다.
이 개수는 §2 이유 열의 `인용 보정:` 표시에서 집계했다.
인용 보정에는 인용 글자·문서 판 귀속·빠진 조건·인용 줄 위치·계산 위치 해석의 수정을 포함했다.
보고서 본문에 이미 있는 조건을 결론 문장에 옮긴 경우는 별도의 인용 보정으로 세지 않았다.
인용 보정 행 수와 결론 변경 행 수는 서로 중복될 수 있다.

문서 문장·식·표는 쪽 이미지에서 직접 확인했다.
판독 기록은 쪽을 찾는 색인으로만 사용했다.
Word는 기존 5.9 판 이력과 5.9.6 본문에 8.0 변경 추적 삽입문을 포함한다.
Word의 기존 문장 전체를 8.0 판의 새 설명으로 취급하지 않았다.
RF-002·RF-006은 삽입문과 배포본 코드를 대조했다.
8.0 이전 판의 코드 배포본이 없는 RF-001·RF-003·RF-004는 그 한계를 결론 문장에 적었다.
코드 대조는 정적 판독으로 수행했다.
모델 실행과 수치 재현 검증은 하지 않았다.
기존 보고서·기록·노트·원자료는 수정하지 않았다.
