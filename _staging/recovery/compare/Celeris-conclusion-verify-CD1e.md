# Celeris 차이 결론 재대조 — CD1-701–CD1-875

## 1 요약

대상은 `celeris-docs-architecture-vs-code.md`의 §5에 있는 CD1-701–CD1-875의 175행이다.
본문의 같은 ID 175행도 함께 대조했다.
이 범위의 보고서 결론은 모두 C 문서 누락이다.
원래 H로 분류된 대상 행은 0행이다.

| 최종 결론 | 행 수 |
|---|---:|
| A 판 차이 | 0 |
| B 문서 오기 | 0 |
| C 문서 누락 | 122 |
| D 문서에만 있음 | 0 |
| E 코드 결함 후보 | 0 |
| F 표기 차이 | 0 |
| H 코드 대조 대상 아님 | 46 |
| 일치 | 7 |
| 합계 | 175 |

보고서의 분류를 유지한 행은 122행이다.
보고서의 분류를 바꾼 행은 53행이다.
변경은 C에서 H로 바꾼 46행과 C에서 일치로 바꾼 7행이다.
이 개수는 §2의 최종 결론 열에서 셌다.
표의 ‘바뀜’은 분류 변경을 뜻한다.
정확한 식의 전개나 설명 보강만 한 행은 분류 변경 수에 포함하지 않았다.

인용을 고친 행은 7행이다.
해당 ID는 CD1-841·842·843·872·873·874·875다.
이 7행은 생략된 분기 조건이나 중간값 정의를 보완한 행이다.
보고서가 인용한 코드·HTML의 글자와 선언값 자체에서 오기는 발견하지 않았다.
보고서 항목 칸의 ‘기본값 누락’과 ‘파생식’은 분석 항목명으로 읽었다.
이 항목명을 문서의 직접 인용으로 취급하지 않았다.

원문 경로의 공통 루트는 `models/Celeris/raw/source_code/Celeris-WebGPU/`다.
표의 `ebca435:파일:줄`은 이 루트의 현재 판을 뜻한다.
`git log -1`에서 현재 판 ebca435와 날짜 2026-07-20을 확인했다.
읽은 원문과 ebca435 사이의 차이는 `git diff`로 확인했다.
본문과 결론의 각 코드·HTML 인용을 해당 파일의 실제 줄과 다시 비교했다.
CONFIGURATION.md는 1–105행 전체를 읽었다.
기본값 누락 판정의 문서 범위는 해당 CONFIGURATION.md다.
다른 문서 전체에서 같은 값이 없다는 뜻으로 확대하지 않았다.

AD1·AD2·AD3·E1·E2의 판 판정 파일에는 대상 ID의 판정이 없다.
따라서 판 판정 열은 모두 `-`다.
외부 문헌 판정 CP3-013·CP3-017은 이 범위의 설정 행과 관련이 없다.
대상 행에는 논문 문장·식·표 인용이 없다.
따라서 이번 범위에서는 PDF 쪽 이미지 판독이 필요하지 않았다.
모델 실행과 수치 검증은 하지 않았다.
