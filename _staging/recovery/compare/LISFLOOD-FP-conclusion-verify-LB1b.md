# LISFLOOD-FP bridge 대조 보고서 결론 재검증 — LB1b

## 1 요약

대상은 `lisflood-bridge-docx-vs-code.md`의 §5 차이 결론에 실린 LB1-241–999 범위의 161행이다. 해당 범위의 보고서 H 행은 0행이다. 보고서 결론을 유지한 행은 146행이다. 보고서 결론에서 바뀐 행은 15행이다. 인용을 고친 행은 14행이다. 집계 근거는 §2의 행별 표이다.

| 최종 결론 | 행 수 |
|---|---:|
| A 판 차이 | 18 |
| B 문서 오기 | 11 |
| C 문서 누락 | 117 |
| D 문서에만 있음 | 0 |
| E 코드 결함 후보 — 강함 | 8 |
| E 코드 결함 후보 — 중간 | 3 |
| E 코드 결함 후보 — 약함 | 0 |
| F 표기 차이 | 1 |
| H 코드 대조 대상 아님 | 1 |
| 일치 | 2 |
| 합계 | 161 |

E 강함 중 LB1-378은 v8.2 후보가 v8.3에서 수정된 행이다. 집계 단위는 독립 결함이 아니라 행 ID이다.

이 문서는 원문 대조에 따른 AI 판정 기록이다. `바뀜`은 보고서 대비 최종 분류·E 강도·대상 판의 변경을 센다. 인용 수정은 이유 칸의 `인용 수정:`으로 표시한다. 단순한 출처 추가와 A 판 기준 문구 추가는 인용 수정으로 세지 않는다.

코드의 접두어 없는 경로는 `models/LISFLOOD-FP/raw/source_code/LISFLOOD-FP/` 기준이다. `v8.0:`·`v8.1:`·`v8.2:`는 사용자가 지정한 Zenodo 추출 배포본 기준이다. `패치:`는 `_staging/recovery/extract/LISFLOOD-FP/external/v8.3/LISFLOOD-FP-8.3/` 기준이다. `노트:`는 `models/LISFLOOD-FP/` 기준이다. bridge는 `user manual +bridge.docx`이다. PDF는 `LISFLOOD-FP user manual.pdf`이다. 문서 쪽수는 지정된 쪽 이미지의 번호이다. AD1·AD2·E1·E2·E3는 `LISFLOOD-FP-version-verify-{이름}.md`의 확정 결론이다. 문서 판은 bridge p.1의 4.3.6·2008-04-25를 기준으로 한다. 후대 내용을 담은 교량 절은 그 절의 판 정보를 함께 적는다.
