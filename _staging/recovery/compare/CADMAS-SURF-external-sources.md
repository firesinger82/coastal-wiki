# CADMAS-SURF 외부 원문 필요(X) 8행 해소 기록

작성일 2026-11-04. 대상 행은 KS1-241, KS1-242, KS1-243, KS1-244, KS1-271, KS1-450(cadmas-3d-manual-theory-vs-code.md)과 KT1-747, KT1-748(cadmas-str-docs-theory-vs-code.md)이다.
모델 코드는 실행하지 않았다. 아래 판정은 읽은 문서와 코드 행에만 근거한다.

## 1. KS1-241~244, KS1-450 (면적보간 기호 대 코드의 선형보간)

### 1.1 읽은 출처

1. 일본어 매뉴얼 PDF `models/CADMAS-SURF/raw/source_code/Multiscale-and-Multiphysics-Integrated-Simulator-for-Tsunami/Simulators/CADMAS-SURF-3D/Manual/CADMAS-SURF3D_Manual_Japanese.pdf` PDF 27쪽(인쇄 p.269)을 150dpi 이미지로 렌더하여 읽었다. 같은 내용의 텍스트는 `_staging/recovery/extract/CADMAS-SURF/pdf-jp/CADMAS-SURF3D_Manual_Japanese.txt:1280-1310`에 있다.
2. 같은 PDF 30쪽(인쇄 p.272, 식 (3.41)~(3.44))과 33쪽(인쇄 p.275, 식 (3.63)~(3.71))을 이미지로 읽었다.
3. 코드 `.../CADMAS-SURF-3D/Source code/vf_vflxdu.f`, `vf_vflxdw.f`, `vf_vgene.f`를 읽었다.
4. 공개 웹: CDIT 운용지침 PDF(https://www.cdit.or.jp/program/pdf/operational_guidelines_release_ver1.0.1.pdf)를 내려받아 텍스트로 변환했다. 이 PDF에서 "面積補間"과 "線形補間"은 한 곳도 찾지 못했다. 이 PDF는 판정에 쓰지 않았다.
5. 공개 웹: 2001년 CDIT 원본 매뉴얼과 2010년 CADMAS-SURF/3D 보고서(沿岸技術ライブラリー No.39)는 서지 정보(https://ndlsearch.ndl.go.jp/en/books/R100000002-I026065660)만 확인했다. 본문은 공개되어 있지 않아 읽지 못했다.

### 1.2 매뉴얼이 면적보간과 선형보간을 정의하는 방식

매뉴얼 PDF 27쪽(인쇄 p.269)의 식 (3.29), (3.30)을 이미지에서 읽은 그대로 옮긴다.

- 식 (3.29): `{f}^{Δx}_{i,j,k} = Δx_{i-1}/(Δx_{i-1}+Δx_i) f_{i,j,k} + Δx_i/(Δx_{i-1}+Δx_i) f_{i-1,j,k}`
- 식 (3.30): `⌊f⌋^{Δx}_{i,j,k} = Δx_i/(Δx_{i-1}+Δx_i) f_{i,j,k} + Δx_{i-1}/(Δx_{i-1}+Δx_i) f_{i-1,j,k}`

매뉴얼 본문(텍스트 파일 1304-1308행)은 두 식의 용도를 다음과 같이 적는다.

> 式(3.29)はセル中心で定義された値をセル界面に線形補間する場合，式(3.30)はセル中心で定義された値をセル界面に面積補間する場合，式(3.31)はセル界面で定義された値をセル中心に線形補間（面積補間も同じ）する場合に対応する．

매뉴얼은 `{ }`가 선형보간이고 `⌊ ⌋`가 면적보간이라고 정의한다.
매뉴얼은 어느 항에 어느 보간을 쓰는지 규칙으로 적지 않는다. 항마다 기호로만 구분한다.
매뉴얼은 균일 격자에서 두 보간이 같다고 따로 적지 않는다. 식 (3.29)와 (3.30)에서 Δx_{i-1}=Δx_i이면 두 가중치가 모두 1/2이 되므로 같다. 이것은 식에서 계산한 결론이다.

### 1.3 매뉴얼 식 대 코드

매뉴얼 PDF 30쪽에서 읽은 식은 다음과 같다.

- 식 (3.41): `(λ_y v u) = ⟨⌊λ_y v⌋^{Δx} | u_{i,j-1,k}, u_{i,j,k}⟩`
- 식 (3.42): `{γ_y ν_e(∂u/∂y+∂v/∂x)} = ⌊γ_y⌋^{Δx} {{ν_e}^{Δx}}^{Δy} [ (u_{i,j,k}-u_{i,j-1,k})/δy_j + (v_{i,j,k}-v_{i-1,j,k})/δx_i ]`
- 식 (3.43), (3.44)도 같은 구조이며 z방향이다.

식 (3.42)에서 매뉴얼은 γ_y에는 `⌊ ⌋`(면적보간)를, ν_e에는 `{ }`(선형보간)를 쓴다.

코드 `vf_vflxdu.f:108-110`은 다음과 같다.

```
CAKIY         ? 線形補間
              WIN=XX(6,I)*( XX(2,I-1)*GLY(I  ,J,K)*VV(I  ,J,K)
     &                     +XX(2,I  )*GLY(I-1,J,K)*VV(I-1,J,K))
```

`vf_vflxdu.f:117-119`은 다음과 같다.

```
C             ? 線形補間
              GG=XX(6,I)*(XX(2,I-1)*GGY(I,J,K)+XX(2,I)*GGY(I-1,J,K))
```

`vf_vflxdu.f:236`, `:245`, `vf_vflxdw.f:103`, `:112`에도 같은 주석 `? 線形補間`이 있다. `vf_vflxdu.f:109`의 `XX(2,I-1)`은 `f_i`에 곱해진다.
`vf_cdtcal.f:96`의 `DX =XX(2,I)`로 `XX(2,I)`가 셀 폭 Δx_i임을 확인했다.
따라서 `XX(2,I-1)*f_i + XX(2,I)*f_{i-1}`은 가중치 Δx_{i-1}/(Δx_{i-1}+Δx_i)를 f_i에 준다. 이것은 식 (3.29)다.

같은 파일들은 `? 線形補間` 주석을 8곳 이상 붙여 flux 항을 선형보간으로 표시한다. 물음표는 코드 작성자가 이 선택에 확신이 없었다는 표시다. 이 해석은 주석 형태에서 나온 추정이다.

코드 `vf_vgene.f`의 압력항은 다르다. `vf_vgene.f:90-91`은 다음과 같다.

```
C             * 面積補間する
              GV=XX(6,I)*(XX(2,I)*GGV(I,J,K)+XX(2,I1)*GGV(I1,J,K))
```

`vf_vgene.f:166`, `:242`에도 같은 `面積補間する` 주석이 있다. 여기서 `f_I`에 주는 가중치는 Δx_I로, 식 (3.30)이다. 매뉴얼 식 (3.45) `⌊γ_v⌋^{Δx}`와 대응한다.
따라서 코드는 두 보간을 모두 구현하며 구분해서 쓴다. 압력항과 감쇠·항력 계수는 면적보간이고, 교차 운동량 flux와 교차 점성항(γ_y, γ_z 포함)은 선형보간이다.

기하 검토: 셀 중심값을 셀 경계로 옮길 때 경계에서 가까운 중심에 큰 가중치를 주는 보간이 식 (3.29)다. 이 계산은 위 식에서 직접 유도한다. 식 (3.30)은 f_i에 자기 폭을 가중치로 주므로 반대 방향이다.
이 검토는 (3.41)·(3.43)의 속도 v·w 보간에는 선형보간이 점값 보간으로 자연스럽다는 것만 보인다. 문서 쪽 `⌊ ⌋` 기호가 오기인지 의도인지를 가르는 근거는 읽은 출처 어디에도 없다.

### 1.4 판정

- KS1-241, KS1-243: 매뉴얼은 `⌊λ_y v⌋`, `⌊λ_z w⌋`(면적보간)을 적고 코드는 선형보간(식 (3.29))을 쓴다. 균일 격자에서는 같고 비균일 격자에서만 다르다. 코드가 자기 주석으로 선형보간임을 밝히고 있고 같은 코드에서 압력항은 면적보간을 쓰므로 구현 선택이 의도적이다. 판정은 A 판 차이다.
- KS1-242, KS1-244: 매뉴얼은 `⌊γ_y⌋^{Δx}`, `⌊γ_z⌋^{Δx}`를 적고 코드는 `GG`를 선형보간한다. ν_e의 `{ }`는 코드와 같다(코드 ANR·ANL·AN은 선형). 판정은 A 판 차이다.
- KS1-450: 같은 현상이 vf_vflxdv.f와 vf_vflxdw.f의 대응 행 7곳에 나타난다(코드 주석 `? 線形補間`). 판정은 A 판 차이다.
- 코드 결함 후보(E)로 올리지 않는다. 코드를 틀렸다고 볼 근거가 없고, 코드가 자기 선택을 주석으로 밝히며, 균일 격자에서 식이 같기 때문이다.

## 2. KS1-271 (식 (3.71) 부력항)

### 2.1 읽은 출처

1. 일본어 매뉴얼 PDF 33쪽(인쇄 p.275)을 이미지로 읽었다. 식 (3.71)은 `(γ_v ρ* g/ρ)_{i,j,k} = ⌊γ_v ρ*/ρ⌋^{Δz}_{i,j,k} g`이다. 곱 `γ_v ρ*/ρ` 전체를 `⌊ ⌋`로 묶는다.
2. 같은 매뉴얼의 ρ* 정의: 텍스트 336행 `ρ* ：浮力を考慮する密度`. 입력 설명 5440행 `浮力用密度は RHO=RHO0-DRDT*(T-T0)-DRDC*(C-C0)から計算する`. 이 식에서 ρ*는 T와 C의 1차식이다.
3. 코드 `vf_vgene.f:241-243`, `:296-328`.

### 2.2 코드

`vf_vgene.f:242-243`은 `* 面積補間する`와 `GV=ZZ(6,K)*(ZZ(2,K)*GGV(I,J,K)+ZZ(2,K1)*GGV(I,J,K1))`이다. γ_v만 면적보간한다.
`vf_vgene.f:296-300`은 `QW(I,J,K)=QW(I,J,K)-GV*GRZ0`로 중력항을 더한다.
`vf_vgene.f:319-327`은 온도를 `T=ZZ(6,K)*(ZZ(2,K)*TT(I,J,K1)+ZZ(2,K1)*TT(I,J,K))`로 보간한다. `TT(I,J,K)`에 곱하는 가중치가 `ZZ(2,K1)`이므로 선형보간이다. 이어서 `DR=DR-TDR0*(T-TDT0)`와 `QW(I,J,K)=QW(I,J,K)-GV*GRZ0*DR/RHO0`를 계산한다.
즉 코드는 `⌊γ_v⌋ g (1 + (ρ*-ρ0)/ρ0)`를 계산한다. 이때 ρ*는 선형보간한 T, C로 만든다. 매뉴얼은 곱 전체를 면적보간한다.

### 2.3 판정

- 두 식은 γ_v와 ρ*가 함께 변할 때 다르다. 예를 들어 셀 폭이 같고 γ_v가 1과 0.5, ρ*/ρ가 1과 2이면 매뉴얼식은 0.5×(1×1+0.5×2)=1이고 코드식은 0.75×1.5=1.125다. 이 값은 두 식을 산술로 비교한 결과다. 모델 실행 결과가 아니다.
- 코드는 두 인자를 서로 다른 성질로 보간한다. γ_v는 면적 투과율이라 면적보간이고, T·C는 셀 중심 점값이라 선형보간이다. ρ*가 T·C의 1차식이므로 코드의 ρ*는 점값을 선형보간한 것과 같다.
- 매뉴얼의 곱 전체 면적보간이 의도된 정식인지, 표기 단순화인지를 가르는 외부 원문은 읽지 못했다. 코드가 두 인자를 분리한 구조를 주석으로 명시(`-Gv*gz(dr/r)の計算`)하므로 구현 의도는 분명하다.
- 판정은 A 판 차이다. 코드 결함 후보로 올리지 않는다.

## 3. KT1-747 (PENTA 전단 보간, MacNeal 1976)

### 3.1 읽은 출처

1. `_staging/recovery/extract/CADMAS-SURF/pdf-jp/CADMAS-STR_Program_Instructions_Japanese.txt:268-270`:
   > また５面体要素の内挿関数，せん断歪の計算方法については“MacNeal, R.H., The PENTA Solid Element, MSC Internal Memo No. RHM-43, Oct. 22, 1976”を参照のこと．
   같은 문서 593-595행은 "５面体要素の内挿関数については" 같은 참조를 적는다.
2. 코드 `Simulators/STR3D/Source code/src/trpn1s.f:1-3`의 헤더: `GQD : OUT : [E] (γyz,γzxの変換行列)`. `trpn1s.f:8-13`은 삼각형 변 중점 `X2 = ( X(1,2) + X(1,5) ) * .5D0` 등을 구한다.
3. 공개 웹 검색: 이 사내 메모(MSC Internal Memo RHM-43)는 검색에서 나타나지 않았다. MacNeal 1994 "Finite Elements: Their Design and Performance"(https://archive.org/details/finiteelementsth0000macn)는 대출용 서지만 확인했고 본문은 읽지 못했다. 검색 결과 요약에 "transverse shear strains are interpolated from displacement-dependent strains defined at the mid-side of element edges"(assumed natural strain, MacNeal 1978·1982)가 있다. 이 문장은 검색 도구 요약이며 원문 쪽은 읽지 못했다.

### 3.2 판정

- CADMAS-STR 문서는 이 항목에서 식이나 값을 적지 않고 "참조하라"는 서지 지시만 한다. 대조할 단언이 문서에 없다.
- 코드 `trpn1s.f`는 요소 변 중점 좌표(`X2`, `X3`)와 방향 코사인(`COS2`, `SIN2`, `COS3`, `SIN3`)으로 γyz, γzx 변환행렬 `GQD=G×Q×D`를 만든다. 이 구조는 변 중점에서 샘플한 전단변형률을 보간하는 방식과 같은 종류다. 이 일치는 구조 비교이며 계수 대조가 아니다.
- RHM-43 원문을 읽지 못했으므로 G, A, B, Q, D 행렬의 계수를 원전과 대조하지 않았다. 판정은 문서가 서지 참조만 하는 사실에서 나온다.
- 판정은 H 코드 대조 대상 아님이다.

## 4. KT1-748 (소성 구성행렬, 山田嘉昭 1995 p.93)

### 4.1 읽은 출처

1. `CADMAS-STR_Program_Instructions_Japanese.txt:409-410`:
   > ※ 塑性の場合の [𝐷] は“山田嘉昭，塑性・粘弾性，有限要素法の基礎と応用シリーズ 6，培風館，1995，pp. 93”を参照
   이 문서는 [D]의 식을 적지 않고 서지를 가리킨다.
2. 코드 `Simulators/STR3D/Source code/src/sol2.f:18-28`을 읽었다. `WK2 = aᵀDe`(`HARFC(WK2,DFDS,DE,1,6)`), `DRDE = WK2/(HD + WK2·a)`, `DEPDE = a ⊗ DRDE`, `D = DE - De·DEPDE`이다. 이를 풀면 `Dp = De − De a aᵀ De / (HD + aᵀ De a)`이다.
3. 공개 웹: Neto, Peric, Owen, "Computational Methods for Plasticity", 2008, p.154 식 (6.67)을 읽었다(https://wp.kntu.ac.ir/fz_kalantary/Source/Finite%20element%20method/Books-Numerical/Computational%20Methods%20for%20Plasticity%20(Neto,%20Peric%20and%20Owen%202008).pdf를 내려받아 텍스트로 변환). 원문:
   > Dep = De − (De : N) ⊗ (De : ∂Φ/∂σ) / (∂Φ/∂σ : De : N − ∂Φ/∂A ∗ ρ̄∂²ψ^p/∂α² ∗ H)
   같은 책 Remark 6.1: "if the plastic flow rule is associative, i.e. if N ≡ ∂Φ/∂σ, then the continuum elastoplastic tangent operator is symmetric."
4. 山田 1995(培風館)와 Yamada, Yoshimura, Sakurai 1968(Int. J. Mech. Sci. 10, 343-354)은 본문을 읽지 못했다. 1968년 논문의 서지와 "Prandtl-Reuss 식을 역변환해 얻은 소성 응력-변형률 행렬"이라는 설명은 검색 요약으로만 확인했다.

### 4.2 판정

- 코드의 `Dp = De − De a aᵀ De / (HD + aᵀ De a)`는 Neto 식 (6.67)에서 N=∂Φ/∂σ=a(연합 흐름)이고 경화항을 HD로 둔 경우와 같다. 이 일치는 식 구조 비교다. `HD`가 山田 규약의 경화율과 같은 정의인지는 山田 원문을 읽지 못해 대조하지 않았다.
- CADMAS-STR 문서는 서지 참조만 하며 식 번호나 값을 적지 않는다. 대조할 문서 단언이 없다.
- 판정은 H 코드 대조 대상 아님이다.
