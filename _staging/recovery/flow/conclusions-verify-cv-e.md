# EFDC 10-12 결론 검증 기록

검증 기준은 작업 시작 시 `git diff -U0 HEAD -- <노트>`의 추가 줄이다.
기준 HEAD는 `ba72e827b37dfdcd7b7d3866cf1a9415e3ee216b`이다.
대상은 아래 30개 노트의 995줄이다.
내용이 있는 줄은 702줄이다.
빈 줄은 293줄이다.
빈 줄도 대상 목록에 포함했다.
검증 중 새로 넣은 식 6.67의 E 요약 행은 최초 995줄 집계에 넣지 않았다.
이 요약 행의 근거도 확인했다.
수정 후 같은 diff 명령의 추가 줄은 996줄이다.

대상 줄의 원문 인용을 `nl -ba`로 대조했다.
조건·연산자·값·호출 인자와 A–H 판정을 확인했다.
D는 보조 프로그램과 유틸리티를 포함한 `models/EFDC/raw/` 전체에서 `rg -uuu -i -n`으로 다시 검색했다.
E는 의도 변경 기록·보정 경로·단위 변환을 함께 확인했다.
모델은 실행하지 않았다.
실행 영향과 의도가 확인되지 않은 항목은 후보로 남겼다.

## 집계 기준

정정 N은 기존 사실·분류·근거 해석을 바꾼 최초 추가 줄 수이다.
보완 M은 조건·근거·판본·지시어·정본 링크를 보충한 최초 추가 줄 수이다.
같은 줄에 정정과 보완이 있으면 정정으로 한 번만 센다.
이상 없음 L은 나머지 최초 추가 줄 수이다.
L에는 빈 줄 293줄과 내용이 있는 줄 420줄이 포함된다.
분류 변경 K는 보고서 §5의 표 행 수이다.
하나의 표 행에 여러 ID가 묶여 있으면 K에서 한 번만 센다.
분류가 바뀐 표 행은 10개이다.
그 표 행에 묶인 개별 ID는 15개이다.
N+M+L=995이다.
K는 별도 집계이므로 이 합에 더하지 않는다.

`PB_COEF == 0.0`이면 `BLOCKAGE_RATIO = 1.0 + (ZMAXMHK(M,L)-ZMINMHK(M,L))/HP(L)`이다.
ELSE는 `BLOCKAGE_RATIO = PB_COEF`이다.
이 값은 수직 평균을 뺀 내부 힘에 곱해진다.
따라서 ‘수심 점유 비율 자체’라는 설명은 실제 연산과 다르다.
Theory 식 10.17–10.25에서는 이 배율의 독립 정의를 찾지 못했다.
1을 더한 것이 계산 오류인지 설계 선택인지는 미확인이다.
별도 E로 확정하지 않았다.
근거는 [MHK 보고서 행 L446–L464·L622](/home/firesinger/coastal-wiki/_staging/recovery/compare/EFDC-theory-wq-vs-code.md:787)이다.
