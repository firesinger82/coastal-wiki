# EFDC 노트 추가 줄 전수 검증

대상 커밋은 `f3c6397a`이다.
대상은 `git show -U0 f3c6397a -- models`의 추가 줄 647개이다.
추가 줄은 30개 노트에 있다.
빈 줄을 제외한 추가 줄은 449개이다.
빈 줄은 198개이다.

커밋의 줄 번호를 현재 노트의 같은 문장과 연결했다.
수정 직전 현재 EFDC 노트는 대상 커밋의 내용과 같았다.
이번 수정은 줄을 추가하거나 삭제하지 않았으므로 아래 노트 줄 번호는 현재 파일에도 그대로 적용된다.

코드 인용은 `nl -ba`로 인용 줄과 주변 조건을 열어 대조했다.
PDF와 Confluence 문서의 뜻은 `_staging/recovery/read/EFDC/` 판독 기록으로 대조했다.
수식의 연산자, 분기 순서, 바깥 조건, 변수, 수치, 단위와 Mermaid 상자의 호출 위치를 확인했다.
같은 문장이 여러 노트에 있으면 각 추가 줄을 별도로 집계했다.

`정정`, `보완`, `이상 없음`의 집계 단위는 커밋의 물리적 추가 줄이다.
한 추가 줄에 정정과 보완이 함께 있으면 정정으로 한 번 집계했다.
정정 목록의 새 요지에는 같은 줄에서 수행한 보완도 포함했다.
이상 없음에는 빈 줄 198개와 수정이 필요하지 않은 비어 있지 않은 줄 370개가 포함된다.

근거의 짧은 코드 경로는 `models/EFDC/raw/source_code/EFDCPlus_Stable/EFDC/`를 기준으로 한다.
`EFDC-GVC/` 경로는 `models/EFDC/raw/source_code/`를 기준으로 한다.
문서 근거의 `_staging/` 경로는 저장소 루트를 기준으로 한다.
