# XBeach·SFINCS 노트 추가 행 전수 대조

검증일: 2026-10-12.

대상은 `git show -U0 <커밋> -- models`의 추가 행이다. `+++` 파일 헤더는 제외했다. 빈 줄·제목·표 구분·Mermaid 구문도 행 수에 포함했다. 현재 노트에 남아 있는 문장을 기준으로 수정했다.

총 추가 행은 551행이다. 현재 문장이 남은 550행을 대조했다. 사라진 1행은 별도로 기록했다. 집계의 단위는 **커밋의 물리적 추가 행**이다. 한 행에 여러 문장이 있어도 한 건으로 센다. 한 행에 정정과 보완이 함께 있으면 정정으로 센다. 새로 나눈 문장과 추가한 근거 행을 다시 세지 않는다.

정정 30행과 보완 83행을 11개 노트에 반영했다. 이상 없음 437행은 기술 서술·도식 308행과 구조·메타데이터 129행이다. 구조·메타데이터는 빈 줄 89행, 제목 9행, 코드 울타리 6행, Mermaid 방향 선언 3행, 표 머리글 4행, 표 구분선 4행, 메타데이터 14행이다. 메타데이터의 과거 판독 수행 자체를 재현했다는 뜻은 아니다.
