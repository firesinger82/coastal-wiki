[확인] git 명령은 사용하지 않았다.

[확인] 노트 인용의 기준 디렉터리는 `models/SFINCS/source-analysis/`다.

[확인] 원본은 `sfincs_lib.f90:98` `build_date     = "$Date: 2026-06-11"`에 빌드 날짜를 둔다.

[확인] 이하 표의 호출 위치·정의 위치·조건식은 원본 확인 결과다.
[해석] 변수 표의 선후 판정은 확인한 호출 순서와 대입문을 결합한 해석이다.
