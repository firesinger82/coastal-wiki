## 반영한 실질 변경

1. **실제 구조부터 조사.** 초안에 빠진 standards·data·references·도구·설정 역할을 확인했다. models INDEX의 10/13 누락, 검색 allowlist, 교과서 변환본의 별도 검색 취급을 현황에 기록하고 계획을 수정했다.
2. **새 WORKPLAN 철회.** 다섯 번째 상태 원장을 만들지 않고 기존 plan 최상단에 현재 작업 포인터만 두는 안으로 바꿨다. 상세 상태는 원래 원장에 남기며 현재 사용자 지시가 우선한다.
3. **탐색과 근거 구분.** 이론 노트 직접 진입, 다른 토픽의 모델 비교, 모델→개념 역링크를 추가하는 예시를 만들었다. claim 복제·layer/depends_on 변경 없이 기존 §8.1의 탐색 링크 규칙을 적용한다.
4. **상태와 유일한 정보 보존.** 두 INDEX 모두 상태 컬럼·초안/미확인·disclosed-gap를 숨기지 않는다. 단언 보존 위치의 실제 내용까지 확인한 경우에만 상세를 축약한다. 감사 원장의 완료를 문서의 citation_status로 대체하지 않는다.
5. **작업 범위를 파일·절별로 고정.** 첫 묶음은 8개 파일, 정책 묶음은 5개 파일이다. 목표 구조 표가 모든 모델 README나 교과서 노트를 편집하라는 지시로 읽히지 않게 제한했다. 겹치는 plan.md의 변경 역할도 나눴다.
6. **기존 규칙과 새 delta를 구분.** 템플릿의 두 파일 시작은 이미 승인된 §8 정정이다. 개별 정정의 조기 반영은 기존 R3에 있다. 이번 제안은 이를 공통 규칙과 우선순위 운영에 명시하는 것이며 기존 전수 분모·종료 조건의 무단 완화가 아니다.
7. **파일럿 확대 방지.** 12문항 기준선은 P1 이전 동결, 구조 검사는 전역 변경 대상 전부, 문항 평가는 waves–XBeach 탐색으로 한정한다. 수정은 P1의 파일·허용 변경 안에서 1회. 범위 밖 발견을 R1 자동 재개로 바꾸지 않는다.
8. **누락 영역 보강.** BOUNDARY·RUNS-CHANNEL·SYNC와 감사/승격 skill 안내를 운영 영역에 포함했다. 루트 SWAN 문서 두 개는 이번에 처분하지 않는다. standards는 기준 변환본으로 표현하고 검색 확대는 유보했다.

## 그대로 따르지 않은 제안·시점 차이

- 초기 Claude의 “템플릿 수정은 새 정책이므로 P2” 의견은 기존 §8과 대조해 P1의 규약 불일치 정정으로 유지했다. 후속 Claude도 이를 인정했다.
- 초기 의견의 “상태값·verified 수를 축약에서 무조건 제외”는 오래된 집계까지 보존할 수 있다. **상태 공개는 유지하고 값은 실제 노트 근거로 확인**하는 안으로 반영했다.
- 후속 의견의 “models INDEX 상태를 AUDIT-LEDGER에 위임”은 감사 완료와 문서 인용 상태가 다른 점을 보강했다. 전자는 원장, 후자는 실제 frontmatter가 기준이다.
- 파일 도달 여부만 평가하라는 제안은 초안/근거 부족을 숨기는 결과를 놓칠 수 있어 상태 노출·과잉 단정도 포함했다. 과학적 정합성 전체 평가로 확대하지 않는다.
- 후속 Claude가 읽을 당시 navigation-preview.md는 아직 생성되지 않았으나 현재 [예시](navigation-preview.md)가 존재하고 로컬 링크를 검사했다. 이는 미해결 결함으로 남기지 않는다.
