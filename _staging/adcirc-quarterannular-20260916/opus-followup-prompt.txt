앞선 사실 추출을 이어간다. 현재 사용자는 Claude Max 구독의 CLI 사용만 승인했으며 별도 API 키 호출은 금지했다. 현재와 같은 CLI 세션에서만 작업하라. 모델은 Opus, 상위 Codex가 고급 판단·문서 반영을 맡는다.

이번에는 Bash 도구로 원문 다운로드와 PDF 텍스트/이미지 추출이 가능하다. 허용 쓰기 범위는 /tmp/adcirc-quarterannular-20260916/뿐이다. canonical·설정·git은 수정하지 말고 모델 실행이나 패키지 설치도 하지 말라. 네트워크는 공개 1차 출처 다운로드만 한다.

1. mkdir -p /tmp/adcirc-quarterannular-20260916 후 curl -fL로 https://ccht.ccee.ncsu.edu/wp-content/uploads/sites/10/2019/05/Lynch-1978-JHY.pdf 를 그 폴더에 lynch1978.pdf로 저장한다. pdfinfo, pdftotext -layout로 크기/페이지를 확인하고 텍스트를 만든다. 필요한 페이지가 스캔이면 pdftoppm -f N -l N -r 120 -png 로 필요한 페이지만 이미지화하고 Read로 읽는다. 원문 전체를 요약하지 말고 polar geometry / h proportional r² / uniform periodic tidal elevation 조건의 해당 절과 식만 판독한다. 풍응력 해를 조석해로 대체하지 말라.
2. 원문의 선형 방정식, 수심식, Coriolis/마찰 조건, 조석 경계, 무유량 경계, 조화시간의 복소 부호, 정확한 해의 식과 식 번호·인쇄 페이지·PDF 페이지(1-based)를 보고한다. 읽기 어려운 부호는 추정하지 말고 해당 페이지 이미지를 남긴다. 부모 Codex가 식의 타당성과 로컬 비선형 입력에 적용 가능한지 판단한다. 원문 전체 복제는 불필요하다. 다운로드 SHA256도 보고한다.
3. NetCDF header의 기계 추출 자료가 _staging/adcirc-quarterannular-20260916/control-metadata.json 에 있다. 6개 모두 version=v56.0.1-21-gbcb79a8, source=CircleCI라는 global attr를 가진다. 앞선 ASCII 헤더 미확인과 이 추가 사실을 구분해 확인하라. 파일의 self-reported version이 compiler/build 옵션을 전부 입증하는 것은 아니다.
4. NOUT*=5와 NHSTAR=5는 실제 실행 확인이 아닌 입력/파일 계약 해석용으로만 S/src/read_input.F의 해당 값 처리·NetCDF 플래그 설정 위치를 좁게 찾아 정확한 file:line을 반환하라. 출력 라이브러리 내부는 읽지 말라.

출력은 (A) 원문 해석해 사실·식·페이지, (B) 추가 NetCDF/입력 코드 사실, (C) 남은 접근/판독 갭으로 한정한다. 완료 주장·정책/문서 변경은 상위 Codex가 맡는다. subagent 없이 직접 이 한정 수집을 끝내라.
