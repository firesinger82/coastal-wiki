# 근거 판정·검토 반영

## Opus 자료 수집에 대한 Codex 판정

- 실제 주 모델은 두 실행 모두 `claude-opus-5`다. 첫 CLI 결과의 Haiku 항목은 보조 호출이며 주 모델 대체가 아니다. 기존 `claude.ai` / Max 로그인으로 CLI를 실행했고 별도 API 키 호출을 사용하지 않았다.
- 첫 보고의 PDF·NetCDF 미확인 항목은 전체 작업의 영구 갭으로 채택하지 않았다. PDF는 후속 Opus 이미지 판독, NetCDF는 읽기 전용 header 추출로 보완했다. 다운로드 SHA는 부모 실행자가 계산해 `lynch1978-provenance.json`에 고정했다.
- 공식 예제 설명이 선형 문제의 해석해를 언급한다고 해서 모든 비선형 해석해의 존재를 부정하지 않는다. 새 노트는 이 원문의 **선형 방정식과 선택된 비선형 회귀 입력의 조건 차이**만 판단한다.
- 원문 n=2·j=0 해를 무차원 반경으로 도출하고 속도는 같은 원문의 운동량식에서 유도했다. 반복근/분모 영점은 식의 적용 대상에서 제외했다. 원문의 다른 Cartesian·startup 해나 전체 논문을 읽었다고 하지 않는다.
- 선형 마찰률 tau와 Q의 이차 마찰계수 0.0025는 서로 대체하지 않는다. ramp는 tanh이며 cold-start/ramp를 해석해의 주기 정상응답과 동일시하지 않는다.
- Opus가 일반 지식으로 붙인 NumPy rtol 숫자는 후보에서 사용하지 않았다. 실제 코드가 rtol을 지정하지 않았다는 사실과 런타임 기본값을 고정해야 한다는 비교 조건만 기록했다.
- NetCDF의 version/git_hash는 파일 내 자기기록이다. 입력의 오래된 RUNID와도 구분하고 완전한 빌드 provenance 또는 현재 S 판본의 실행 증거로 취급하지 않는다.
- 수식 확인은 세 임의 선형 마찰률에서 연속방정식의 유량 유한차분 잔차와 양쪽 반경 경계를 확인했다. 이는 ADCIRC·수렴률·물리 허용오차의 검증이 아니다.

## 독립 최종 검토

Codex 읽기 전용 최종 검토는 신규 주장과 설치기 변경에서 수정이 필요한 발견 사항이나 차단 요인이 없다고 판단했다([결과](codex-final-review.txt)). 검토된 candidate의 SHA를 고정한 manifest로 정확히 두 문서를 설치했고, 원 소유권/권한을 보존했다. 과학적 사람 승인·모델 전체 완료는 발급하지 않는다.
