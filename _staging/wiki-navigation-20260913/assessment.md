# 고정 탐색 비교 — 외부 검토 완료

질문·기대 문서·문서 해시는 변경 전에 동결했다. 같은 스크립트로 [변경 전](navigation-before.json)·[변경 후보](navigation-candidate.json)를 각각 한 번 평가했다. 직접 링크와 README/INDEX를 통한 3회 이내 이동은 모두 **4/12 → 12/12**다. 탐색 개선이며 새 결함 탐지율·정확도·XBeach 완료율이 아니다. 검색 엔진 평가나 사용자 실험도 아니다.

| 문항 | 변경 전 → 후보 | 표시의 해석 |
|---|---|---|
| N01·N03 | 3회 내 경로 없음 → 직접 링크 | 이론 노트 verified, 갭 필드 부재는 미감사로 노출 |
| N02 | 3회 내 경로 없음 → 직접 링크 | verified, has_source_needed false 표시. 물리 자체를 이번에 재검증했다는 뜻 아님 |
| N04–N06 | 3회 내 경로 없음 → 직접 링크 | V*와 미감사 표시: 기존 verified 이력, 새 AI 정정 승인 미발급, 갭 unknown |
| N07–N08 | 3회 내 경로 없음 → 직접 링크 | verified지만 공개된 갭(true) 존재 |
| N09–N10 | 직접 링크 유지 | D 네 편과 사람 검토 대기 노출. 승인 완료 또는 전체 수식 검증 완료 근거로 쓸 수 없다는 문장을 추가 |
| N11–N12 | 직접 링크 유지 | tides·SST의 기존 선택 경로 보존만 확인. 이 토픽 전체의 상태 노출·모든 링크를 개선한 것이 아님 |

외부 검토자는 위 해석과 실제 후보의 범례·링크 문장을 대조한다. 원출처의 한정 위치 대조는 [locator-checks.json](locator-checks.json)에 기록했다. 원문의 전체 과학적 지지를 평가한 성적이 아니다.

루트 INDEX의 다른 70행과 기존 모델 10개의 도메인·격자 셀, waves·XBeach의 기존 본문을 보존했다. 13개 모델의 진입점과 추가 안내의 상대 문서 링크를 확인했다([구조 확인](structural-checks.json)). 기존 SST의 별도 깨진 링크는 [범위 밖 기록](out-of-scope-findings.md)에 남겼다.

Opus 작성 후 검토 준비 과정에서 루트 두 행을 실제로 축약하고 SWAN library 원문 표현을 보존했다. 세 모델의 갭 미감사 혼재, XBeach 각 노트의 갭 범례를 명확히 했으며 README의 과도한 “모든 영역” 표현을 줄였다. 12문항과 기술 노트는 바꾸지 않았다. 이는 전후 평가 이전 후보 정리이며 회귀 수정 회차를 수행한 것으로 세지 않는다.

[Fable 검토](fable-review.md)는 위 상태 해석과 후보 메타데이터를 대조해 반영 가능으로 판정했다. [Codex 검토](codex-review.txt)도 탐색 변경의 도입 결함을 찾지 않았다. 의미 정확도나 새 사람 승인을 부여한 것은 아니다.
