# XBeach local `REFUTED_UNVERIFIED` closure

`closure/deferred-inputs.json`에 고정된 로컬 8건만 재판정한 후속 원장이다. 기존 crosswalk, expanded verdict, 승인 영수증, canonical 및 `models/XBeach/raw/` 원본은 수정하지 않았다. 인용의 줄 번호는 CRLF 원본을 줄 단위로 읽어 LF로 표시한 논리 줄 번호이며, SHA-256은 원본 바이트에 대한 값이다.

| 최종 처분 | 수 | 안정 ID |
|---|---:|---|
| `REFUTATION_CONFIRMED` | 5 | spaceparamsdef, drifters, IFX dynamic project, legacy dynamic project, README.parallel |
| `NARROWED_WARNING_RETAINED` | 2 | vegetation, vsm_u_XB |
| `SPLIT_PARTIAL_REFUTATION_WARNING_RETAINED` | 1 | bundled netcdf_attributes |

기계 판독 원장은 [resolution-ledger.json](resolution-ledger.json)이다. 각 항목은 고정 입력의 ID·crosswalk 해시·배열 인덱스·A/B ID, 원 주장, 과거 미검증 반증과 중립화 인용, 실제 소스 인용과 바이트 해시, 호출 경로, 최종 판정 및 canonical-ready 한국어 문구를 포함한다.

netCDF 항목의 외부 동작은 XBeach 솔버 동작으로 귀속하지 않는다. 배열 속성 API와 inquiry 오류 계약은 Unidata의 공식 netCDF-Fortran 문서에 귀속한다.
