# 색상·정렬 예외의 조건부 구조 추적

2026-09-11 AI 진단. [결과](native-conditional-probe.json), [판독기](inspect_conditional_records.py), [재현](probe_conditional_records.py), [검증](validate_conditional_records.py).

기존 strict 판독에서 거부한 20개를 별도의 명시적 진단 옵션으로 추적했다. 기본 동작은 여전히 해당 원본을 거부하며, 원본을 수정하거나 검증 기준을 변경하지 않는다.

- 정렬 8개: LINE/PILE의 RULER 옵션 뒤 바이트는 `01 00 e8 14`다. 이를 태그 없는 탭 목록으로 읽으면 count=1, type=0, offset=5352가 되고 이후 본문이 끝까지 읽힌다. 원본에 7 태그가 없다는 표시와 조건부 해석임을 구조에 저장한다. 이것이 모든 MTEF의 허용 형식이라고 단정하지 않는다.
- 색상 12개: COLOR 인덱스 0을 기본색으로 치환하지 않고 `unresolved_color_reference`로 저장하면 이후 본문 구조가 끝까지 읽힌다. 색상 의미는 여전히 미해결이다.

이제 매뉴얼 486개는 strict 구조 판독 463개, 확장 접두부를 보존한 3개, 이 진단의 조건부 20개로 대응한다. 486개가 모두 의미/렌더 검증을 통과했다는 뜻은 아니다. 23개의 조건·미해석 내용을 유지한 채 원본 preview와 대조할 수 있도록 구조 전체와 바이트 좌표를 확보했다.

통합 검증은 원본 재추출·전체 결과 재현, 20개 모두 strict 거부 유지, 각 예외 표시 존재, 두 부류 대표 스트림의 전체 절단·후행 바이트 거부를 확인한다. 기존 파서·영수증·원본과 전체 gate NOT_PASSED를 보존한다. 신규 사람 승인 없음.
