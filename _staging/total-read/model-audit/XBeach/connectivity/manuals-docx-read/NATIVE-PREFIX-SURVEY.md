# Native 설정 영역 경계 조사

2026-09-11 AI 기계적 분석. [영수증](native-prefix-survey.json), [재현 스크립트](survey_native_prefixes.py). 이전 고정 offset 조사는 그대로 보존했다.

본문 시작을 무조건 220으로 두지 않고, offset 40–512의 후보에서 기존 설정 파서가 끝까지 읽고 FULL 레코드로 끝나는지 검증했다. 실제 본문의 END를 바꾸지 않는다. 설정 영역에 합성 END를 붙이는 검사는 경계 탐색에만 사용한다. 유일한 경계가 없으면 거부한다. 기존 설정/본문 판독기 코드는 변경하지 않았다.

| 본문 시작 offset | 오브젝트 수 |
|---|---:|
| 218 | 2 |
| 219 | 3 |
| 220 | 394 |
| 228 | 4 |
| 229 | 80 |
| 미해결 | 3 |

이 방법으로 이전 거부분 60개가 추가 수용됐다. 총 361개 기계적 수용, 본문 미지원 122개, 접두부 미해결 3개다. 기존 수용 301개는 모두 그대로 수용된다. 수학적 의미나 렌더 충실도를 확인했다는 뜻은 아니다.

본문 거부의 첫 오류는 options 1(74개), options 2(8개), options 5(6개), record 16(18개), record 5(12개), record 9(4개)다. 하나의 수식에 후속 미지원 항목이 더 있을 수 있다. 접두부 미해결은 Master oleObject1/45/48이며, 현재 설정 파서는 offset 41의 tag 100을 지원하지 않는다. 이것을 손상으로 판단하거나 건너뛰지 않았다.

검증은 원본 486개 재추출·결과 재현, 입력/파서 해시, 이전 수용 집합 보존과 다섯 경계별 절단·FULL 변조·버전 변조 거부를 포함한다. 원본 및 기존 판독 기록은 보존한다. 전체 gate NOT_PASSED·신규 사람 승인 없음. 다음은 미지원 레코드/옵션 명세 확인 후 한정 지원을 검증하고 개별 식을 원문/렌더와 대조하는 작업이다.
