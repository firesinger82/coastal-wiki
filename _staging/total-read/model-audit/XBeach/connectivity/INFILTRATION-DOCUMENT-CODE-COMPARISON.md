# 침투식의 원본 표기와 구현 대조

2026-09-12 AI 판독 보충. [원본 구간·SHA·대수 검산](infiltration-document-code-comparison.json), [수식 이미지](manuals-docx-read/conditional-visual-read/README.md).

원본 WMF와 Native에서 Kingsday oleObject133, Master143/81의 분수 뒤 1 앞 연산자가 빠져 있다. Kingsday70 대응식은 +1을 쓴다. 현재 코드의 기본 관계는 **더하기 1**이다. 이를 문서의 원래 의도를 확정하거나 원본을 자동 수정하는 근거로 확대하지 않는다.

`groundwater.F90:1554–1573`의 주석은 불포화 침투에 대해 w = K(1 + h/(d + D w)), D = dt/por를 명시한다. `:1574–1630`의 실제 양의 근 계산도 다음 이차식과 일치한다.

D w² + (d − D K)w − K(d+h) = 0

양의 근은 (−d + D K + √(d² + 2D dK + 4D hK + D²K²))/(2D)다. K>0, d>0, h≥0, D>0 범위에서의 대수 비교다. 세 수치 예의 잔차는 0 또는 약 3.4e−17이며, 이는 Fortran 실행 시험이 아니다. 코드의 laminar 분기와 turbulent 첫 추정에는 par%kz, 난류 반복에는 갱신한 kze가 들어간다.

문서의 간단한 순간 식을 전체 구현과 동일시하면 안 된다. `:1631–1643`에서 불포화 시간 비율을 적용하고 남은 표층수로 제한한다. 호출은 비연결·젖은 셀에서 지하수위가 바닥 아래인 경우다(`:610–624`). 침투가 양수일 때 침투층은 dt×infil/por만큼 증가하며 아니면 리셋된다(`:628–638`). 양의 infil은 해수에서 지하수 방향이다(`:283–285`). 따라서 이 판독은 문서의 빠진 기호에 대한 **구현 측 대응**이며, 압력/수두 변수·시간 이산화를 생략한 직접 등가 판정은 아니다.

기존 canonical `xbeach_groundwater.md`의 교환 분기·부호 설명은 유지한다. 이번 상세 비교는 판독 보충 근거로 남기고 전체 판독 뒤 canonical 검토 대상으로 삼는다. 전체 gate NOT_PASSED·신규 사람 승인 없음. 원본/기존 승인 기록을 수정하지 않는다.
