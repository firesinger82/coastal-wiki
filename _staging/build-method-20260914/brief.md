## 반드시 보존할 경계

- 모델의 공식 기능 목록을 먼저 지도화한다. 일부 질문에 맞춘 선택만으로 모델 전체를 정리했다고 하지 않는다. 기능별 포함/보류/대상외 이유와 판본을 명시하고, 선택한 원문 범위는 식·조건·한계까지 충실히 읽는다.
- 모든 동봉 파일 소진이 기본 공정이 아니다. 필요한 모델 driver·옵션·MPI 실행 경로는 포함하되 부속 MPI/Jumpshot·라이브러리 내부로 자동 확대하지 않는다.
- 문서상 지원, 코드상 구현, 특정 입력으로 실제 실행 확인, 수치 검증, 관측/실험과 물리 검증은 다른 증거다. 입력자료 불확실성도 기록한다. 검증 기준·허용 오차·출처는 비교 결과를 보기 전에 정하고 미확정이면 명시한다.
