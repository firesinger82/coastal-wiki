# ADCIRC 외부 조석 자료 규약·검증 근거 보강

상태: **Fable 5.1 내용 검토·Codex 최종 검토 후 세 문서에 반영 완료**. 입력/실행/수치/물리 검증 완료가 아니다.

현재 승인된 다음 묶음은 기존 조석 입력 노트의 외부 DB 정의·품질/변환 근거와 독립 관측·오차 기준 보강이다. 기존 FES2022b·NAO99Jb·TPXO 주장을 판본별 공식 문서에 대조한다. 우선 FES2022b의 제품 정의와 예측 규약을 정확히 정리하고, 다른 제품은 확인한 범위만 대비한다. 관측자료의 동화/보정 사용 이력과 검증 독립성, 진폭/위상·복소 오차/시계열 지표를 출처와 연결한다.

기존 파일의 한정 인용 보강이므로 CLAUDE.md의 미세 노트·출처 보강 예외에 따라 새 거버넌스 계획 사이클은 반복하지 않는다. Fable 5.1 내용 검토 및 Codex 최종 변경 검토는 수행한다. 실제 데이터 대용량 다운로드·모델 실행·개인 검증 결과는 이번 산출물이 아니다. 필요한 원문 규약을 확인할 때만 공급기관 예측 구현의 해당 수식/입력 인터페이스를 읽고 범용 라이브러리 내부로 확장하지 않는다.

완료: 기존 조석 노트에 판본별 자료 규약과 변환/독립 검증 방법이 출처로 뒷받침되고, 위험한 무근거 일반화는 정정/갭 표시, 기능 지도의 해당 갭·현재 포인터 갱신, 검토·필수 검사·커밋·푸시. 실제 해역·자료·오차 허용치가 미지정이면 이를 미확정으로 남기고 보편 수치를 발급하지 않는다. 과거 감사와 기존 미커밋 6줄·interfaces-20260912는 그대로 보존한다.

## 반영 내용과 확인 한계

- harmonic-prep: FES2022b handbook Issue 2.0의 cm/lag/mask/결측·radial, NAO99Jb의 성분/영역/UTC/정수 scale·lag 변환, TPXO10-atlas-v2의 제품·포맷 확인 한계. 공급기관 예측과 비교할 분조/보정/시각을 명시했다.
- 같은 노트에 UHSLC QC·datum/timing, 동화/보정과 검증 독립성, 순환 위상·복소거리/한 주기 RMS·RSS·표본 RMSE·Rayleigh 조건을 연결했다. 실제 허용오차 수치는 미선정이다.
- forcing: FES와 NAO의 위상 규약이 서로 다르다는 무근거 단정을 정정하고 제품별 근거로 연결했다. FES radial loading을 fort.24로 직접 이전할 물리량 대응은 미입증으로 구분했다.
- 기능 지도: F04/F05와 조석 진입점의 확보 근거·미해결 사항을 갱신했다. source-needed 상태와 과거 검증/사람 승인 비승계 유지.
- 기존 1개월/분기 갱신·지역별 정확도·일괄 SAL 정량 권고는 제거하거나 근거 미확정으로 정리했다. 실제 atlas/경계/관측 파일·변환 결과, TPXO 개별 encoding, SAL 물리량 대응, 기준해·보존/민감도와 목적별 허용치는 아직 미확인이다.
