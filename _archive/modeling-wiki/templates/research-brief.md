# Research Brief

Use this brief when asking a bot or agent to gather foundational material.

## Objective

What modeling question should the research support?

## Scope

- domain:
- solver / model family:
- physics:
- numerical methods:

## Source Types To Gather

- papers
- reports
- source code
- examples
- manuals

## What To Extract

- governing assumptions
- parameter ranges
- stability conditions
- validation setups
- implementation details
- known failure modes

## What To Avoid

- marketing summaries
- generic tutorial fluff
- unverified claims without primary support

## Output Format

1. Put originals in `raw/`.
2. Create one source note per important item.
3. Flag anything that should become an experiment candidate.
4. Separate facts from interpretation.
