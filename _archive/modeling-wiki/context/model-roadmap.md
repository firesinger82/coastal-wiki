# Model Roadmap

## Active Model

- ADCIRC

## Sequence Rule

- only one active model at a time
- build foundation first, then collect experiments
- move to the next model only after the current model has:
  - foundational sources ingested
  - at least one experiment card
  - at least one promoted knowledge note

## Queued Models

- EFDC
- XBeach
- SWAN (as a supporting wave-model lane if needed)

## Exit Criteria For ADCIRC Foundation Phase

- 3 to 5 foundational ADCIRC sources ingested
- source notes created for each important source
- first narrow ADCIRC theme selected
- first minimum viable ADCIRC experiment defined
